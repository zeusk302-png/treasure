# 여러분을 위한 웹개발 가이드

> 바이브코딩 4일 부트캠프 **그다음** — "AI로 한 번 만들어봤다"에서 **"상용 수준으로 옳게 시키고 검증할 줄 안다"** 로.

비전공자를 위한 상용 웹개발 **백과사전 · 길라잡이 · 해설**입니다. 코드를 직접 짜는 책이 아니라, **AI에게 무엇을·왜 시킬지 판단하고 결과를 검증하는 안목**을 길러주는 지도입니다.

!!! tip "처음 오셨나요?"
    13권 + 실습 337선이라 어디서 시작할지 막막하다면 → [**시작 가이드 — 어디서부터 읽을까**](guide/index.md) 에서 *목표별 추천 동선*부터 보세요.

## 이 책이 풀려는 문제

비전공자의 진짜 약점은 문법이 아니라 **"있는 줄도 몰라서 AI에게 물어볼 생각조차 못 하는 것"** 입니다. 이 책의 임무는 그 **모르는 것들을 눈에 보이게** 만드는 것입니다.

## 어떻게 읽나 — 3층 구조

1. **무엇을 만들까(정문)** — 쇼핑몰·SaaS·웹게임… 만들 것마다 필요한 개념으로 안내합니다.
2. **분야 백과사전** — 각 개념을 *있는 것 → 한 줄 해설 → 길라잡이 판정*으로 펼칩니다.
3. **추천 동선** — 처음부터 따라 읽고 싶은 사람을 위한 순서.

!!! tip "길라잡이 판정 기호"
    🟢 너의 메인 · 🟡 대안 · 🔵 나중에 · ⚪ 몰라도 됨

## 모든 페이지의 8칸 틀

① 한 줄 정의 → ② 왜 중요한가(디렉터 관점) → ③ 비유 → ④ 최소한 알 것 → ⑤ AI에게 이렇게 시켜라 → ⑥ 흔한 함정/AI가 틀리는 것 → ⑦ 검증하는 법 → ⑧ 더 깊이
