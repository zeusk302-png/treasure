# SEO 한눈에 — 구글·네이버에 내 사이트가 뜨게 하기

**① 한 줄 정의**
SEO(검색 엔진 최적화)는 **사람이 검색했을 때 내 사이트가 결과에 나오도록** 페이지를 정리하는 일입니다.

**② 왜 중요한가 (디렉터 관점)**
아무리 잘 만들어도 **검색에 안 뜨면 아무도 못 옵니다.** 광고를 안 산다면, 방문자의 대부분은 구글·네이버 검색에서 옵니다. 그런데 SEO는 *존재 자체를 모르면* AI에게 시킬 생각조차 못 하는 대표적인 영역입니다.

**③ 비유**
SEO는 **도서관 사서에게 내 책을 제대로 등록시키는 일**입니다. 책이 아무리 좋아도 분류·색인이 안 돼 있으면 아무도 못 찾습니다.

**④ 최소한 알 것 — 검색에 뜨려면 해야 할 것**

| 할 일 | 무엇 | 판정 |
|---|---|---|
| 페이지별 제목·설명 | 고유한 `<title>` + meta description | 🟢 필수 |
| 대표 이미지/공유 미리보기 | Open Graph 태그 (카톡·SNS) | 🟢 필수 |
| 사이트맵·robots | `sitemap.xml`, `robots.txt` 자동 생성 | 🟢 필수 |
| canonical | 중복 주소 정리 | 🟡 권장 |
| 구조화 데이터 | JSON-LD (Article/Organization) | 🟡 권장 |
| **구글 서치콘솔** | 사이트 등록 + 사이트맵 제출 | 🟢 필수 |
| **네이버 서치어드바이저** | 사이트 등록 + 소유확인 + 사이트맵 제출 | 🟢 **한국 필수** |

!!! warning "구글만 하면 절반만 한 것"
    한국 방문자는 **네이버**로도 많이 검색합니다. 구글 서치콘솔만 하면 네이버에선 잘 안 뜹니다. **네이버 서치어드바이저**에 따로 등록해야 합니다.

**⑤ AI에게 이렇게 시켜라**

```text
이 사이트의 SEO를 점검해줘. 페이지별 title·description·canonical,
Open Graph 태그, sitemap.xml과 robots.txt 자동 생성, 이미지 alt를 확인하고
빠진 건 고쳐줘. 그리고 구글 서치콘솔과 네이버 서치어드바이저에
등록·사이트맵 제출하는 방법을 단계별로 알려줘.
```

**⑥ 흔한 함정 / AI가 틀리는 것**
- **네이버를 빼먹습니다.** AI는 구글 중심으로 답하는 경향이 있어, 시키지 않으면 네이버 서치어드바이저를 안 알려줍니다.
- **FAQ 구조화 데이터를 권합니다.** 구글 FAQ 리치결과는 2026년 폐지되어 효과가 없는데, 옛 학습 데이터 때문에 여전히 추천합니다.
- production에 `noindex`가 남아 검색에서 통째로 빠지기도 합니다.

**⑦ 검증하는 법**
- 구글에 `site:내도메인` 으로 검색 → 내 페이지가 색인됐는지 확인.
- 구글 서치콘솔 / 네이버 서치어드바이저의 '수집·색인' 현황 확인.
- 카톡에 링크를 보내 제목·이미지가 뜨는지(OG) 확인.
