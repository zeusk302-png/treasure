# 이용약관과 전자상거래법 필수 고지 — 사이트 푸터가 법정 게시판이다

!!! warning "교육용 안내이며 법정 자문이 아닙니다"
    전자상거래법의 표시 의무 항목·환불 규정은 시점성 정보입니다. **공정거래위원회 공식 안내**로 확인하세요(확인 날짜 기록).

**(1) 한 줄 정의**
전자상거래로 물건·서비스를 팔 때, 사업자 정보(상호·대표자·주소·연락처·사업자등록번호 등)와 약관을 사이트에 표시해야 하는 법적 의무이며, 그 자리가 보통 사이트 '푸터(맨 아래 영역)'입니다.

**(2) 왜 중요한가(디렉터 관점)**
푸터는 디자인 마감이 아니라 '법정 게시판'입니다. 여기에 빠뜨리면 안 되는 정보가 있고, 잘못된 환불 문구(예: "단순 변심 환불 불가")는 위법일 수 있습니다. 디렉터는 "푸터에 무엇이 반드시 들어가야 하는지"를 체크리스트로 알고, AI가 만든 푸터가 그걸 충족했는지 검증해야 합니다.

**(3) 비유**
가게 출입문에 의무적으로 붙여야 하는 '사업자 정보 게시판'과 같습니다. 인테리어가 아무리 예뻐도 이 게시판이 없거나 틀리면 영업 위반입니다.

**(4) 최소한 알 것**

| 항목 | 한 줄 해설 | 판정 |
|---|---|---|
| 사업자 정보 표시 | 상호·대표자·주소·연락처·이메일·사업자등록번호 등 | 🟢메인 |
| 약관·처리방침 링크 | 이용약관과 개인정보 처리방침으로 연결 | 🟢메인 |
| 청약철회(환불) 안내 | 소비자 환불권을 막는 위법 문구 금지 | 🟢메인 |
| 사업자정보 공개페이지 | 통신판매 사업자 정보 확인 링크 연결 | 🟡대안 |

!!! warning "필수 표시 항목·환불 규정은 직접 확인"
    "초기화면에 상호·대표자·주소 등을 표시" 같은 구체 의무와 청약철회 기간(예: 7일)은 공정위 공식 자료로 재확인하세요. 표시 누락이나 위법 문구는 제재 대상이 될 수 있습니다.

**(5) AI에게 이렇게 시켜라**

```text
나는 한국에서 전자상거래로 유료 서비스를 판다.
내 사이트 공통 푸터(footer) 컴포넌트를 만들되, 전자상거래법상 표시 의무를 충족시켜줘.
1) 반드시 들어가야 하는 사업자 정보 항목을 '빈칸 자리표시자'로 만들어 내가 채우게 해줘
   (상호/대표자/주소/연락처/이메일/사업자등록번호/통신판매업 신고번호 등)
2) 이용약관·개인정보 처리방침으로 가는 링크 포함
3) 환불(청약철회) 안내는 소비자 권리를 침해하는 위법 문구가 없도록
미국식 두 줄 푸터로 끝내지 말고, 한국 법정 표시 항목을 빠짐없이. 의무 항목·환불 규정은 '공식 확인 필요'로 표시해줘.
```

**(6) 흔한 함정·AI가 틀리는 것**
AI는 푸터를 '디자인 요소'로만 다뤄 법정 표시 항목을 누락합니다. 학습 데이터가 영어권 위주라 **미국식 두 줄 푸터**(저작권 표기 정도)만 만들기 쉽고, "단순 변심 시 환불 불가" 같은 **위법한 환불 문구**를 아무렇지 않게 넣습니다.

**(7) 검증하는 법**
공정위가 안내하는 필수 표시 항목 목록을 옆에 놓고, 내 푸터에 항목이 하나씩 다 있는지 체크합니다. 자리표시자(○○○)가 실제 값으로 채워졌는지 확인합니다. 환불·청약철회 문구가 소비자 권리를 부당하게 제한하지 않는지 점검합니다.
