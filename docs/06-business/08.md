# 비용·수익 구조 — 무료 같지만 새는 돈을 한눈에

!!! warning "교육용 안내이며 법정 자문이 아닙니다"
    무료티어 한도·PG 수수료율·세율은 시점성 정보입니다. **각 서비스(Vercel/Supabase/PG사)와 국세청 공식 자료**로 확인하세요(확인 날짜 기록).

**(1) 한 줄 정의**
비용·수익 구조는 도메인·호스팅·DB·결제 수수료·세금 같은 '나가는 돈'과 '들어오는 돈'을 한눈에 정리해, 한 건을 팔 때 실제로 내 손에 남는 돈(손익분기)을 파악하는 것입니다.

**(2) 왜 중요한가(디렉터 관점)**
"바이브코딩은 거의 공짜"는 무료티어 한도 안에서만 참입니다. 트래픽이 늘거나 결제가 일어나면 수수료·세금·초과 요금이 조용히 새기 시작합니다. 디렉터는 "매출 = 이익"이 아니라는 것을 알고, 한 건을 팔 때 실제 실수령액을 계산할 줄 알아야 사업 판단을 합니다.

**(3) 비유**
가게의 '원가·임대료·세금 장부'와 같습니다. 하루 매출이 100만원이라도 재료비·월세·세금을 빼면 손에 남는 건 다릅니다. 이 장부 없이 "매출 = 번 돈"이라 착각하면 흑자 도산합니다.

**(4) 최소한 알 것**

| 항목 | 한 줄 해설 | 판정 |
|---|---|---|
| 고정비 | 도메인(연 갱신)·유료 플랜 등 매달/매년 고정 지출 | 🟢메인 |
| 변동비 | PG 수수료·트래픽 초과 요금 등 팔수록 느는 비용 | 🟢메인 |
| 세금 | 받은 금액 중 부가세 등 떼어둘 몫(권6-7 연결) | 🟢메인 |
| 정산 지연 | PG 매출이 내 통장에 들어오기까지 시차 | 🟡대안 |
| 손익분기 | 비용을 다 빼고도 남기 시작하는 판매량 | 🔵나중 |

!!! warning "한도·수수료는 직접 확인"
    Vercel/Supabase 무료티어 한도와 PG 수수료율은 변동됩니다. 공식 가격표로 재확인하고, 무료티어 초과 시 '과금'인지 '일시정지'인지도 확인하세요(권5-8 연결).

**(5) AI에게 이렇게 시켜라**

```text
내 서비스의 한 달 비용·수익 구조를 표로 만들어줘. 입력값은 다음과 같다.
- 고정비: 도메인(연 ○원→월 환산), 유료 플랜(○원/월)
- 변동비: PG 수수료(판매액의 ○%), 트래픽 초과 요금(있으면)
- 세금: 부가세 등 떼어둘 비율(권6-7 기준, '확인 필요'로)
- 판매가: 1건당 ○원
이걸로 '한 건 팔았을 때 실제 내 손에 남는 실수령액'과 손익분기 판매량을 계산해줘.
'매출 = 이익'으로 보이게 만들지 말고, 수수료·세금·정산 지연을 모두 반영해. 수수료·세율은 '공식 확인 필요'로 표시.
```

**(6) 흔한 함정·AI가 틀리는 것**
AI는 "무료티어로 충분하다"며 안심시키고, **PG 수수료·부가세·정산 지연·무료티어 초과 요금을 누락**해 "매출이 곧 이익"처럼 보이게 만듭니다. 한 건당 실수령액을 계산하지 않으면 가격을 너무 낮게 책정해 팔수록 손해 보는 구조를 모르고 출시하게 됩니다.

**(7) 검증하는 법**
실제 운영 비용을 표로 적고, 한 건 판매 시 (판매가 − PG 수수료 − 세금)으로 실수령액을 직접 계산합니다. Vercel/Supabase Usage 대시보드에서 무료티어 사용량 막대를 확인해 한도에 얼마나 가까운지 점검합니다. 지출 알림·한도를 설정합니다(권5-8 연결).

**(8) 더 깊이**

- Vercel Pricing / Supabase Pricing — 1차 출처
- 각 PG사 수수료·정산 안내 — 1차 출처

!!! tip "자기증명 포인트"
    이 사이트는 실제 운영 비용 표와 '한 건 판매 시 손익' 계산기(수수료·세금을 차감한 실수령액)를 공개해, "공짜처럼 보이지만 새는 돈"을 눈에 보이게 만듭니다.

!!! example "💡 예시로 이해하기"
    도윤이는 PDF 강의를 `5,000원`에 팔며 "원가 0원이니 5,000원이 다 이익"이라 생각했습니다. AI도 "무료티어로 충분해요"라며 거들었죠. 한 건 실수령을 직접 계산해 보기 전까진요.
    실제로는 PG 수수료 약 3.3%(예시) `-165원`, 떼어둘 부가세 약 `-455원`, 거기에 도메인·플랜 같은 고정비를 판매량으로 나눈 몫까지 빠집니다. 5,000원이 손에 들어오는 게 아니라 대략 4,000원대 초반만 남죠.
    게다가 PG 정산은 보통 며칠~몇 주 시차가 있어, 오늘 판 돈이 오늘 통장에 들어오지 않습니다. Vercel/Supabase 무료티어도 트래픽이 한도를 넘으면 조용히 과금되거나 일시정지될 수 있어, Usage 대시보드와 지출 알림을 켜둬야 "새는 돈"에 안 놀랍니다.
