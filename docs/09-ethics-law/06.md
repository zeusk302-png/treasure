# 폰트·이미지·아이콘·음악 — 출처와 상업적 사용, 표시 의무

!!! warning "교육용 정보이며 법률 자문이 아닙니다 — 중요한 결정 전 공식 자료·전문가 확인"
    아래의 라이선스 조건·무료 여부·표시 의무는 2026년 6월 기준이며 서비스 약관은 예고 없이 바뀝니다. 실제 사용 전 각 사이트의 최신 라이선스 페이지를 날짜와 함께 직접 확인하세요.

**한 줄 정의**

폰트·이미지·아이콘·음악 같은 "에셋(asset)"은 거의 전부 누군가의 저작물이며, 각각에 붙은 **라이선스(사용 허락 조건)** 안에서만 쓸 수 있다. 핵심 질문은 항상 셋이다 — ① 상업적으로 써도 되나 ② 출처(저작자)를 표시해야 하나 ③ 수정·재배포해도 되나.

**왜 중요한가 (비전공 디렉터·창업자 관점)**

웹사이트·앱·홍보물 하나를 만들면 폰트, 사진, 아이콘, 배경음악이 자동으로 따라붙는다. 그런데 이 영역은 비전공 창업자가 **가장 자주, 가장 비싸게 사고를 내는 곳**이다.

- **폰트 회사는 자동 크롤링으로 단속한다.** 상업 사이트가 무단으로 유료 폰트를 임베딩하면 봇이 찾아내고, 법무법인 명의의 합의금 청구(흔히 수백만 원대)가 날아온다. 한국에서 "폰트 저작권 합의금"은 소상공인·스타트업 사이에서 유명한 함정이다.
- **"무료"의 종류가 다 다르다.** 무료 사진이라도 "상업용 가능 + 출처 표시 불필요"인지, "비상업용만"인지, "출처 표시 필수"인지가 제각각이다. 한 글자만 잘못 읽어도 침해가 된다.
- **출시 후에 바꾸기가 가장 비싸다.** 디자인 다 끝나고 마케팅까지 돌린 뒤 "이 폰트 못 쓴다"가 되면, 모든 페이지·인쇄물·SNS 카드를 다시 만들어야 한다.

디렉터·창업자는 직접 디자인을 못 해도 **"이 에셋 어디서 받았고, 라이선스가 상업용 맞아요? 캡처해서 보관했어요?"**라고 물을 수 있어야 한다.

**비유**

에셋 라이선스는 **렌터카 약관**과 같다. 차를 빌렸다고(=다운로드했다고) 마음대로 되는 게 아니다. "영업용 운행 가능?"(상업적 사용), "스티커 붙여도 됨?"(수정), "남에게 다시 빌려줘도 됨?"(재배포)이 약관에 다 적혀 있고, 어기면 추가 요금이 아니라 배상 책임이 따른다. "무료 렌트"라도 약관은 있다.

**최소한 알 것 — 네 가지 에셋의 함정 지도**

| 에셋 | 핵심 라이선스 키워드 | 상업 사용 시 가장 흔한 사고 |
|---|---|---|
| 폰트 | 임베딩, 포장지, BI/CI, OFL, 수정(변형) | 웹 임베딩·로고(BI/CI) 사용이 별도 금지인데 그냥 씀 |
| 이미지 | 상업적 사용, 출처 표시, 모델 초상권, 재판매 금지 | "무료 사진"인데 출처 표시 필수 조건을 빠뜨림 |
| 아이콘 | 무료 라이선스(출처 표시 필수), Pro(표시 불필요) | Flaticon 무료를 표시 없이 씀 → 약관 위반 |
| 음악 | 상업적 사용, 표시 의무, 동기화(영상 삽입) 권리 | 유튜브에서 뽑은 음원·인기곡을 영상에 깔음 |

**폰트 — 한국에서 특히 조심**

- **"무료 폰트"여도 허용 범위가 쪼개져 있다.** 한국 폰트 모음 사이트 [눈누(noonnu.cc)](https://noonnu.cc)는 폰트별로 **인쇄 / 웹사이트 / 영상 / 포장지 / 임베딩 / BI·CI / OFL** 같은 항목을 표로 보여준다. 이 표에서 내가 쓸 용도가 "허용"인지 반드시 확인해야 한다. (출처: 눈누)
  - **임베딩**: 웹폰트로 서버에 넣거나 앱·전자책 안에 글꼴 파일을 포함하는 것. 이게 막힌 폰트를 웹에 쓰면 위반.
  - **BI/CI**: 브랜드 로고·회사 로고에 글자를 쓰는 것. 별도 금지·유료인 경우가 많다.
- **OFL(SIL Open Font License)**: 글꼴 자체를 "돈 받고 파는 것"만 빼면 자유롭게 쓰는 오픈 폰트 라이선스. 구글 폰트 상당수가 OFL이라 비교적 안전하다.
- **포맷 변환(TTF→WOFF)도 '수정'일 수 있다.** 일부 폰트는 변형 금지라, 웹용 변환조차 약관 위반 소지가 있으니 "수정 허용" 여부를 확인하라. (출처: 눈누 라이선스 안내)
- **안전한 출발점**: 구글 폰트, 네이버 나눔글꼴, 눈누에서 "상업용 + 웹/임베딩 허용"으로 필터링한 폰트.

**이미지 — '무료'의 함정**

| 사이트 | 상업적 사용 | 출처 표시 | 주의점 (2026 기준) |
|---|---|---|---|
| Unsplash | 가능 | 불필요(권장) | 사진 모아 경쟁 서비스화 금지, 면책(배상)은 없음 |
| Pexels | 가능 | 불필요(API는 표시 규칙) | 식별 가능한 인물·상표·로고는 별도 책임 |
| Pixabay | 가능 | 불필요 | 인물·상표 포함 시 초상권·상표 위험은 사용자 책임 |

(출처: 각 사이트 라이선스 페이지, 2026년 정리 자료)

!!! warning "**약관은 자주 바뀝니다 — 다운로드 시점에 직접 확인하세요**"
    위 표(이미지)와 앞의 폰트 표는 정리 시점 기준이며, 무료 여부·상업적 사용 허용·**출처 표시 의무**는 각 사이트가 예고 없이 바꿀 수 있습니다. "지금은 출처 표시가 불필요"여도 나중에 조건이 달라질 수 있으니, **다운로드하는 그 시점에 각 사이트의 라이선스 페이지를 직접 열어 확인하고 화면을 날짜와 함께 캡처해 두세요.** 표의 값은 참고용 범위로만 보고, 최종 판단은 최신 약관으로 합니다.

- **공통 함정 — "저작권 OK"와 "초상권·상표권 OK"는 다르다.** 무료 사진 사이트는 *사진의 저작권*만 풀어 줄 뿐, **사진 속 사람 얼굴(초상권)**, **브랜드 로고·건물·상표**까지 보장하지 않는다. 사람 얼굴이 또렷한 사진을 광고에 쓰면 초상권 분쟁이 생길 수 있다.
- **면책(indemnification)이 없다.** 무료 사이트는 "문제 생기면 우리가 책임진다"는 보장을 하지 않는다. 위험을 크게 줄이려면 유료 스톡(예: Shutterstock, Getty, 어도비 스톡)을 쓰고 라이선스 증서를 보관한다.

**아이콘**

- **Flaticon 무료 라이선스**: 상업적 사용 가능, 단 **출처 표시(attribution) 필수**. 예: "Icons made by [제작자] from www.flaticon.com". 표시가 싫으면 유료(Premium)로 전환. (출처: Flaticon 라이선스)
- **Font Awesome Free**: MIT(코드)·SIL OFL(폰트)·CC BY 4.0(아이콘) 혼합 라이선스. 상업 사용 가능하며 **출처 표시는 의무가 아니다(권장).** (출처: Font Awesome Free License)
- 그 외 무료 아이콘도 "출처 표시 필수형"과 "표시 불필요형"이 갈리니, 다운로드 페이지의 라이선스 한 줄을 꼭 읽는다.

**음악 — 가장 위험한 영역**

- **검색·유튜브에서 뽑은 음원, 인기 가요는 쓰면 안 된다.** 음악은 권리가 여러 겹(작사·작곡=저작권, 가수·연주=저작인접권, 음반 제작=저작인접권)이라 가장 복잡하고, 권리사의 단속도 강하다.
- **유튜브 오디오 보관함(YouTube Audio Library)**: 유튜브가 제공하는 무료 음원으로 상업적(수익 창출 포함) 사용이 가능하다. 단 **일부 트랙은 출처 표시 필수**이며, 이때는 영상 설명란에 곡명·아티스트·출처를 적어야 한다. 또한 원칙적으로 유튜브 내 사용을 전제로 하니 플랫폼 밖 사용은 조건을 다시 확인하라. (출처: YouTube 고객센터)
- **한국 상업 공간/서비스 BGM**: 매장·앱·웹에 음악을 트는 것은 "공연"이나 "공중송신"에 해당할 수 있어 [한국음악저작권협회(KOMCA)](https://www.komca.or.kr) 등 신탁단체의 사용료 대상이 될 수 있다. (확인 필요 — 매장 규모·용도별로 면제·요율이 다르므로 KOMCA 공식 안내로 확인)
- **안전한 선택**: 로열티 프리 음원 구독(예: Epidemic Sound, Artlist 등)이나 유튜브 오디오 보관함의 "표시 불필요" 트랙. 단, 동기화(영상에 삽입) 권리가 포함되는지 약관에서 확인한다.

**실무에서는 이렇게**

- **에셋 출처 대장을 만든다.** 표 한 장에 〔파일명 / 출처 사이트 / 라이선스 종류 / 상업 가능 여부 / 출처 표시 필요 여부 / 다운로드 날짜〕를 기록한다. 약관이 바뀌어도 "그때는 이랬다"를 증명할 수 있다.
- **라이선스 페이지를 캡처해 둔다.** "상업적 사용 가능"이라고 쓰인 화면을 날짜와 함께 PDF/이미지로 보관한다. 분쟁 시 핵심 증거다.
- **출처 표시가 필요한 에셋은 '크레딧' 페이지를 하나 둔다.** 푸터나 별도 페이지에 사진·아이콘·폰트 출처를 모아 표시하면 깔끔하게 의무를 충족한다.
- **불확실하면 유료로 간다.** 핵심 비주얼(메인 배너, 로고, 광고 영상)은 무료 위험을 떠안지 말고 유료 라이선스로 깔끔하게 확보한다.
- **AI에게 점검을 시킬 때:** "이 프로젝트에서 불러오는 모든 폰트·이미지·아이콘·음악 파일 경로를 나열하고, 각각 어디서 왔는지(코드/설정에서 찾은 출처 URL이나 파일명)만 표로 정리해. 라이선스 판단은 하지 말고 사실만." → 그다음 사람이 라이선스를 확인한다.

**흔한 오해·함정**

- "구글 이미지 검색 = 무료" — **완전히 틀림.** 검색 결과의 이미지는 거의 다 저작물이다. "사용권 필터"를 켜도 라이선스는 직접 확인해야 한다.
- "무료 폰트니까 로고에도 OK" — **아님.** 무료라도 BI/CI(로고) 사용은 별도 금지·유료인 경우가 많다.
- "출처만 표시하면 어떤 음악이든 OK" — **틀림.** 출처 표시는 표시 의무가 있는 자원에 한해 의무를 충족할 뿐, 애초에 상업 사용이 허락된 음원이어야 한다.
- "무료 사진이니 사람 얼굴 광고에 써도 됨" — **위험.** 저작권은 풀렸어도 초상권은 별개다.
- "약관은 안 바뀐다" — **바뀐다.** 그래서 다운로드 시점의 약관을 캡처해 두는 것이다.
- "유튜브 오디오 보관함 음악은 어디서나 무조건 무료" — 대체로 자유롭지만 **일부는 출처 표시 필수**이고, 유튜브 밖 사용 조건은 다를 수 있다.
