# 도메인과 DNS — 인터넷의 전화번호부

**① 한 줄 정의**
**도메인**은 사람이 외우는 이름(예: `example.com`), **DNS**는 그 이름을 컴퓨터가 찾아가는 실제 주소(IP)로 바꿔주는 **전화번호부**입니다.

**② 왜 중요한가 (디렉터 관점)**
도메인 연결은 **배포의 마지막 1cm**입니다. "왜 내 도메인이 안 떠요"의 대부분은 코드가 아니라 DNS 설정과 **전파 시간** 문제입니다. 디렉터가 이걸 알면, 멀쩡한 코드를 헤집는 대신 "DNS 레코드가 맞는지, 전파를 기다려야 하는지"를 먼저 점검하게 됩니다.

**③ 비유**
전화번호부와 같습니다. "홍길동"(도메인)으로 전화를 걸려면 번호부에서 실제 번호(IP)를 찾아야 합니다. 새로 등록한 번호는 모든 번호부에 퍼지는 데 시간이 걸립니다 — 이것이 DNS 전파입니다.

**④ 최소한 알 것**
- 도메인은 **사서 소유하는 게 아니라 매년 갱신해 빌리는** 것에 가깝다.
- DNS 변경은 즉시 반영되지 않고 **전파 시간**(수 분~수십 시간)이 걸린다.
- A 레코드·CNAME 같은 'DNS 레코드'가 이름과 실제 서버를 잇는다.

**⑤ AI에게 이렇게 시켜라**

```text
내가 산 도메인을 Vercel에 연결했는데 아직 안 떠. 코드를 고치기 전에,
이게 'DNS 전파 시간' 문제인지 'DNS 레코드 설정' 문제인지 구분하는 절차를
알려줘. 내가 어떤 레코드(A/CNAME)를 어디에 넣어야 하는지, 전파가 됐는지
확인하는 방법(예: 조회 도구)도 알려줘. 등록업체 화면은 제각각이니 일반 원리로 설명해줘.
```

**⑥ 흔한 함정 / AI가 틀리는 것**
AI는 **'전파 시간'을 안 짚어** 사용자가 바로 안 된다고 코드를 엉뚱하게 고치게 만듭니다. 또 등록업체마다 화면이 달라 특정 업체 기준으로만 설명하다 헷갈리게 합니다.

!!! warning "시점성 정보 주의"
    도메인 가격·갱신 정책, `.co.kr` 같은 국가 도메인의 자격요건, 등록업체별 설정 화면은 **수시로 바뀝니다**. 반드시 등록업체와 호스팅(Vercel) **공식 문서를 확인 날짜와 함께** 확인하세요.

**⑦ 검증하는 법**
DNS 조회 도구나 터미널로 도메인을 조회해 올바른 서버를 가리키는지 확인합니다. 브라우저 주소창에 도메인을 넣어 자물쇠(HTTPS)와 함께 사이트가 뜨면 연결 성공입니다. 이 사이트는 커스텀 도메인 연결의 실제 DNS 레코드를 공개합니다.

!!! example "💡 예시로 이해하기"
    어젯밤 도메인 `myshop.kr`을 사서 Vercel에 연결했는데, 아침에 친구한테 보냈더니 "안 열린다"는 답이 옵니다. 코드를 헤집기 전에 두 가지를 가릅니다. 첫째, 등록업체 화면에서 시킨 대로 `CNAME`을 `cname.vercel-dns.com`으로 넣었나(레코드 설정 문제)? 둘째, 넣은 지 30분밖에 안 됐다면 그냥 기다림(전파 시간)일 수 있습니다 — DNS 변경은 전국 전화번호부에 퍼지는 데 수 분에서 수십 시간이 걸리니까요. 실제로 내 폰에선 이미 열리는데 친구 폰에선 아직 옛 번호부를 봐서 안 열리는 일도 흔합니다. 그래서 "내 컴퓨터에선 되는데 남은 안 됨"은 코드 버그가 아니라 전파 중이라는 신호일 때가 많습니다.
