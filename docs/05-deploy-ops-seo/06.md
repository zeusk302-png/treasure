# 도메인 연결과 HTTPS — vercel.app 주소를 내 이름표로

**(1) 한 줄 정의**

도메인 연결이란 Vercel이 준 기본 주소(예: `내프로젝트.vercel.app`)를 내가 산 고유 주소(예: `내이름.com`)로 바꿔 달고, HTTPS(자물쇠)로 안전하게 잠그는 작업이다.

**(2) 왜 중요한가 (디렉터 관점)**

`vercel.app` 주소는 "연습작" 느낌이지만, 내 도메인은 포트폴리오·취업·사업에서 신뢰를 준다(권8 취업 연계와 직결). 또 `www.내이름.com`과 `내이름.com`을 하나로 통일하지 않으면 검색엔진이 둘을 다른 사이트로 보고 점수를 나눈다(앞 페이지 캐노니컬과 직결). 디렉터는 "주소가 두 개로 보이면 안 된다"를 알아야 한다.

**(3) 비유**

남이 임시로 붙여준 호실 번호(vercel.app)에서 내 가게 간판(내이름.com)으로 바꿔 다는 일이다. 간판은 등기소(도메인 등록업체)에 등록하고, 손님에게 "위조 아닌 진짜 가게"임을 보증하는 인증마크(HTTPS 자물쇠)를 함께 단다.

**(4) 최소한 알 것**

- 도메인은 등록업체에서 사고(연 단위 갱신), DNS 레코드를 Vercel이 안내하는 값으로 설정한다.
- DNS 변경은 즉시가 아니라 전파 시간(수 분~수십 시간)이 걸린다.
- HTTPS 인증서는 Vercel이 자동 발급한다.
- `www` 버전과 루트(`apex`) 버전 중 하나를 대표로 정하고 나머지는 301로 통일한다.

**(5) AI에게 이렇게 시켜라**

```text
Vercel 프로젝트에 내가 산 커스텀 도메인을 연결하려고 해.
1) 도메인 등록업체에서 어떤 DNS 레코드를 어떤 값으로 설정해야 하는지
   (A 레코드/CNAME 중 무엇인지 포함)
2) www 버전과 루트 버전을 하나로 통일(301 리다이렉트)하는 방법과,
   대표 주소는 무엇으로 정하는 게 좋은지
3) DNS '전파 시간' 때문에 바로 안 떠도 정상일 수 있다는 점과,
   얼마나 기다려야 하는지
4) HTTPS 자물쇠가 제대로 걸렸는지 확인하는 방법
등록업체마다 화면이 다를 수 있으니 일반 원칙으로 설명해줘.
```

**(6) 흔한 함정 · AI가 틀리는 것**

!!! warning
    AI는 (1) 등록업체마다 설정 화면이 다른데 한 업체 기준만 단언하고, (2) **DNS 전파 시간**을 안 짚어 "바로 안 뜬다"며 엉뚱하게 코드를 고치게 만들며, (3) www/루트 301 통일을 빠뜨려 검색 점수가 갈라지게 한다. "안 떠요"의 상당수는 코드가 아니라 전파 대기 중이거나 레코드 오타다.

**(7) 검증하는 법**

1. 브라우저에서 `https://내이름.com` 접속 → 주소창에 자물쇠가 보이는지 확인.
2. `www.내이름.com`으로 들어가도 대표 주소로 자동 이동(301)하는지 확인.
3. Vercel → Domains에서 도메인 상태가 'Valid Configuration'인지 확인.
4. 안 뜨면 DNS 전파 조회 도구로 레코드가 퍼졌는지 확인 후 기다린다.

**(8) 더 깊이**

- Vercel Custom Domains 공식 문서 (vercel.com/docs/projects/domains) — 1차 출처
- Let's Encrypt / HTTPS 개념 문서 (letsencrypt.org) — 1차 출처

!!! example "💡 예시로 이해하기"
    디렉터가 도메인 등록업체에서 `myshop.com`을 연 12,000원에 사고, Vercel이 안내한 대로 A 레코드와 CNAME을 설정했다. 5분 뒤 `myshop.com`을 쳐보니 안 뜬다. "AI가 배포를 잘못했나?" 싶어 코드를 헤집기 시작한다 — 하지만 이건 코드 문제가 아니라 DNS 전파 대기다. 보통 수 분~수십 시간 걸린다. 다음 날 아침엔 멀쩡히 떴다.
    또 하나의 함정: `myshop.com`은 잘 뜨는데 `www.myshop.com`은 에러가 난다. www/루트를 하나로 통일(301)하지 않으면 검색엔진이 둘을 다른 사이트로 보고 점수를 갈라 깎는다. Vercel Domains에서 한쪽을 대표로 정하고 나머지를 301로 리다이렉트하면, `www.myshop.com`으로 들어와도 주소창이 자동으로 `myshop.com`으로 바뀐다.
    확인은 눈으로: 주소창에 자물쇠가 보이면 HTTPS 정상, www로 들어가도 대표 주소로 튕겨 나가면 301 통일 완료다.
