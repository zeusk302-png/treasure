# 요금폭탄 방지 — 무료티어 한도와 '사이트가 조용히 멈추는' 시나리오

**(1) 한 줄 정의**

무료티어 운영 리스크란 무료 한도를 넘거나 약관을 어겼을 때, 사이트가 '돈을 더 받는' 게 아니라 '조용히 멈추거나 정지되는' 상황을 미리 알고 막는 것이다.

**(2) 왜 중요한가 (디렉터 관점)**

"바이브코딩 거의 공짜"는 무료티어 안에서만 사실이다. 디렉터는 두 가지 상반된 위험을 알아야 한다. 하나는 어떤 서비스는 초과 시 정지(사이트 다운), 다른 하나는 어떤 서비스는 초과 시 과금(요금 폭탄). 또 무료 플랜은 보통 '비상업적 전용'이라 수익이 나면 약관 위반이 될 수 있다는 점도 알아야 한다.

**(3) 비유**

무료 뷔페 쿠폰 같다. 어떤 식당은 정량 넘으면 그냥 내보내고(정지), 어떤 식당은 넘은 만큼 청구서를 들이민다(과금). 게다가 "개인 손님 전용" 쿠폰을 단체 영업에 쓰면 쿠폰 자체가 취소될 수 있다(약관 위반).

**(4) 최소한 알 것**

| 서비스 | 초과/방치 시 | 판정 |
|---|---|---|
| Vercel Hobby | 한도 초과 시 일시 정지(과금 아님), 비상업 전용 | 🟢 메인 — 수익 나면 유료 플랜 필요 |
| Supabase Free | 약 1주 비활성 시 자동 일시정지 | 🟢 메인 |
| 그 외 종량제 API | 초과 시 과금(요금 폭탄 가능) | 🟡 사용량 알림·한도 설정 필수 |

!!! warning
    **시점성 정보 — 반드시 확인.** 무료티어 한도, 과금/정지 정책, Vercel Hobby의 '비상업적 전용' 제한, Supabase Free 자동 일시정지 조건 등은 모두 자주 바뀐다. Vercel·Supabase 공식 가격표에서 날짜 기준으로 재확인할 것. 수치를 단정하지 말 것.

**(5) AI에게 이렇게 시켜라**

```text
Vercel과 Supabase 무료티어로 사이트를 운영하려고 해.
1) 각 서비스의 무료 한도를 초과하거나 방치하면 '정지'되는지 '과금'되는지
   구분해서 알려줘 (정지면 사이트가 멈추고, 과금이면 돈이 나간다)
2) Vercel Hobby가 비상업적 전용인지, 수익이 나면 어떤 플랜으로 바꿔야 하는지
3) 요금 폭탄을 막기 위한 사용량 알림·지출 한도 설정 방법
각 수치가 '공식 가격표로 확인 가능 / 추정 / 시점에 따라 변동' 중 무엇인지
표시하고, 변동 가능성 있으면 공식 가격표 링크를 알려줘.
```

**(6) 흔한 함정 · AI가 틀리는 것**

!!! warning
    AI는 "무료로 충분합니다"라며 안심시키고, **사용량 알림·지출 한도 설정을 먼저 권하지 않는다.** '정지'와 '과금'의 차이를 구분 안 해 위험을 뭉뚱그리고, 무료 플랜의 비상업 제한을 빠뜨린다. 한도 수치도 옛 기준으로 단언하기 쉽다.

**(7) 검증하는 법**

1. Vercel·Supabase의 Usage 대시보드에서 현재 사용량이 한도의 몇 %인지 막대로 확인.
2. 사용량 알림(예: 80% 도달 시 이메일)을 실제로 켜고 테스트.
3. 종량제 API에는 지출 한도(budget alert)를 설정했는지 확인.
4. 공식 가격표에서 한도·정책을 날짜와 함께 기록해둔다.
