# 디렉터의 자리 — 무엇을·왜는 사람이, 어떻게는 AI가

**① 한 줄 정의**
바이브코딩은 코딩을 *안 하는* 게 아니라, 코딩을 **시키고 책임지는 '디렉터'** 의 자리에 사람이 서는 일입니다.

**② 왜 중요한가 (디렉터 관점)**
AI는 '어떻게'는 잘하지만 '무엇을·왜'는 대신 정해주지 않습니다. 디렉터가 자리를 비우면 AI가 그럴듯한 기본값으로 빈칸을 채우고, 그 결과의 책임은 만든 사람에게 돌아옵니다.

**③ 비유**
당신은 요리사가 아니라 **레스토랑 사장**입니다. 직접 칼질은 안 해도, 무엇을 누구에게 어떤 맛으로 낼지는 사장이 정합니다.

**④ 최소한 알 것**
- 결정(무엇을·왜)은 사람, 실행(어떻게)은 AI.
- 모호한 지시 = 그럴듯한 오답. 맥락과 목표를 먼저 준다.

**⑤ AI에게 이렇게 시켜라**

```text
작업을 시작하기 전에, 네가 어떤 전제를 깔고 만들지 3줄로 먼저 보고하고
내 확인을 받은 뒤 진행해. 내가 정해야 할 결정은 멋대로 정하지 말고 물어봐.
```

**⑥ 흔한 함정 / AI가 틀리는 것**
목표가 모호하면 되묻지 않고 '가장 흔한 정답'(예: IT 스타트업 영문 템플릿)으로 멋대로 채웁니다. 침묵은 '문제없음'이 아닙니다.

**⑦ 검증하는 법**
AI가 보고한 전제 3줄이 *내 의도와 맞는지* 먼저 확인합니다. 어긋나면 코드가 나오기 전에 바로잡습니다.
