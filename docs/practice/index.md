# 실습 — 직접 따라 만들기

읽기만 해서는 늘지 않습니다. 아래 실습을 **순서대로** 따라 하면 *정적 페이지 → 입력 폼 → 진짜 저장(DB)* 까지 손으로 경험합니다. 모든 코드는 공개 저장소에 있어, 그대로 복사해 AI에게 "설명해줘 / 이렇게 바꿔줘"라고 시키며 익히면 됩니다.

| 실습 | 무엇을 만드나 | 배우는 개념 | 코드 |
|---|---|---|---|
| **01. 정적 랜딩페이지** | 카페 소개 한 장 | HTML/CSS 분리 · 반응형 | [examples/01-static-landing](https://github.com/zeusk302-png/treasure/tree/main/examples/01-static-landing) |
| **02. 문의 폼** | 이름·연락처·내용 폼 | `<form>` · 자바스크립트 · 새로고침 막기 | [examples/02-form](https://github.com/zeusk302-png/treasure/tree/main/examples/02-form) |
| **03. Supabase 방명록** | 진짜 저장되는 방명록 | 데이터베이스 · anon 키 · **RLS** | [examples/03-supabase-guestbook](https://github.com/zeusk302-png/treasure/tree/main/examples/03-supabase-guestbook) |

## 어떻게 하나요?

1. 위 링크에서 해당 폴더를 연다(또는 저장소 전체를 내려받는다).
2. 폴더 안의 **`README.md`** 에 *목표 · 따라하는 단계 · 검증법* 이 있습니다. 그대로 따라가세요.
3. 막히면 코드를 통째로 복사해 AI에게 붙여넣고 *"한 줄씩 쉽게 설명해줘"* 라고 물어보세요.

!!! tip "이렇게 활용하세요"
    실습 코드는 '정답'이 아니라 '출발점'입니다. 내 가게·내 주제로 바꿔 보고, AI에게 기능을 더 시켜 보며 망가뜨리고 되돌리는 게 진짜 연습입니다.
