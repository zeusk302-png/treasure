# 시작 가이드 — 어디서부터 읽을까

13권 + 실습 337선이라 처음엔 막막할 수 있습니다.
**무엇을 만들고 싶은지**에 따라 길이 다릅니다. 아래에서 내 목표에 가까운 코스를 골라 **위에서 아래 순서대로** 따라가세요.

!!! tip "이 가이드의 사용법"
    - 책은 **코드를 외우는 곳이 아니라**, *AI에게 무엇을·왜 시킬지 판단하고 결과를 검증하는 안목*을 기르는 곳입니다.
    - 모든 본문 페이지는 같은 **8칸 틀**(① 정의 → ② 왜 중요 → ③ 비유 → ④ 최소한 알 것 → ⑤ AI에게 이렇게 시켜라 → ⑥ 흔한 함정 → ⑦ 검증법 → ⑧ 더 깊이)로 되어 있습니다.
    - 길라잡이 판정 기호: 🟢 너의 메인 · 🟡 대안 · 🔵 나중에 · ⚪ 몰라도 됨
