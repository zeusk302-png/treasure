# 마무리 점검 (qa-check)

아래를 점검하고 각 항목을 ✅/⚠️/❌로 보고한다. ❌는 고친다.

- [ ] 모바일 실기기/좁은 화면에서 레이아웃이 깨지지 않는가
- [ ] 오타·깨진 링크
- [ ] 비밀키가 코드·빌드 산출물에 노출되지 않았는가 (`sb_secret_`, API 키)
- [ ] 파비콘·OG 대표 이미지가 표시되는가
- [ ] 콘솔 에러 (F12 → Console의 빨간 글씨)
- [ ] 접근성: 키보드만으로 탐색 가능, 이미지 alt, 색 대비
