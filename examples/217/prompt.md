# 217. "실행 전에 무엇을 할지 3줄로 먼저 보고해" 지시 프롬프트

> 이 파일은 **AI에게 그대로 붙여넣는 지시문**입니다.
> 핵심은 한 가지 — AI가 **곧바로 코드를 고치지 못하게** 막고,
> "무엇을 / 왜 / 어떻게 바꿀지"를 **먼저 3줄로 보고**하게 만든 뒤,
> 내가 "진행해"라고 승인해야만 실제로 수정하게 하는 것입니다.
>
> 이걸 **"선(先)보고 후(後)실행"** 이라고 부릅니다. 디렉터(나)가 키를 쥐는 방식입니다.

---

## 1단계 — AI에게 보낼 지시 프롬프트 (그대로 복사해서 붙여넣기)

```
[맥락] 순수 HTML/CSS/JS로 만든 1페이지 소개 사이트가 있어. 파일은 index.html 하나야.
아래는 현재 첫 화면(히어로 섹션) 코드의 일부야:

<section class="hero">
  <h1 class="hero-title">우리 동네 반찬가게</h1>
  <p class="hero-tagline">맛있는 반찬을 팝니다</p>
  <a class="hero-btn" href="#menu">메뉴 보기</a>
</section>

[목표] 히어로 섹션의 "한 줄 소개 문구"(hero-tagline의 텍스트)를
좀 더 따뜻하고 신뢰감 있는 한 문장으로 바꾸고 싶어.

[제약 — 가장 중요]
1. 지금 바로 코드를 고치지 마. 먼저 "무엇을 / 왜 / 어떻게" 순서로 딱 3줄로 계획만 보고해.
2. 바꾸는 범위는 hero-tagline 안의 텍스트 한 줄로만 한정해. 다른 태그·클래스·구조는 절대 건드리지 마.
3. 내가 그 계획을 보고 "진행해"라고 답하면, 그때 비로소 바뀐 부분만 보여줘.
4. 새 문구는 과장 광고(최고/1등/100%) 없이, 20자 안팎으로 1개만 제안해.
```

---

## 2단계 — AI가 멋대로 시작하면 다시 잡아주는 한 마디

AI가 계획 보고를 건너뛰고 바로 코드를 뱉으면, 아래 한 줄로 되돌립니다.

```
잠깐, 아직 "진행해"라고 안 했어. 코드 말고 "무엇을 / 왜 / 어떻게" 3줄 계획부터 다시 보여줘.
```

---

## 3단계 — 계획이 마음에 들면 승인

```
좋아, 진행해. hero-tagline 텍스트 한 줄만 바꿔서 그 부분만 보여줘.
```

---

## 왜 이렇게 시키나요? (비전공자용 한 줄 정리)

- AI는 "빨리 끝내려고" 종종 **시키지 않은 것까지** 손댑니다.
- "먼저 3줄로 보고해"라고 하면, 잘못된 방향을 **코드 작성 전에** 바로잡을 수 있습니다.
- 사람은 **무엇을·왜**(방향)를 정하고, AI는 **어떻게**(구현)를 맡는 역할 분담이 명확해집니다.
