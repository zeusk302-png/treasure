# 단계별로 넘어가는 3단계 가입 폼 (스텝 인디케이터)

긴 가입 폼을 **한 화면에 다 쏟아 붓지 않고**, 계정 → 프로필 → 확인의 **3단계로 나눠** 보여 주는 멀티스텝 폼입니다.
'다음' 버튼을 누르면 **그 단계의 입력이 올바를 때만** 다음으로 넘어가고, '이전'으로 돌아가 고칠 수도 있습니다.

> 비유: 은행 창구에서 서류를 한 장씩 받는 것과 같습니다.
> 첫 장(계정)을 제대로 써야 다음 장(프로필)을 주고, 마지막엔 "이렇게 쓰신 게 맞나요?"라고 보여 준 뒤 도장(약관 동의)을 받습니다.
> 위쪽의 동그란 번호(스텝 인디케이터)는 "지금 몇 번째 서류를 쓰는 중인지" 알려 주는 표지판입니다.

## 목표

- 입력 묶음 3개를 HTML에 모두 만들어 두고, **지금 단계만 보이게** 전환하는 법을 익힌다.
- `currentStep` 변수 하나로 **"지금 몇 단계인지"** 를 기억하는 단계 상태 관리를 이해한다.
- '다음'을 누를 때 **그 단계만 검증**하고, 통과해야 넘어가는 단계별 검증 흐름을 만든다.
- 위쪽 스텝 인디케이터에 **지나온 단계(초록) / 지금 단계(파랑)** 를 표시한다.

## 따라하는 단계

1. 이 폴더(`104`)의 `index.html`, `style.css`, `script.js` 세 파일을 같은 폴더에 둡니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다. 처음엔 **1단계(계정)** 만 보이고, '이전' 버튼은 숨겨져 있습니다.
3. **빈 칸인 채로 '다음'** 을 눌러 봅니다. 빨간 안내 문구가 뜨고 넘어가지 않는 것을 확인합니다. (이게 "단계별 검증"입니다.)
4. 이메일은 `example@email.com`처럼, 비밀번호는 **8자 이상**으로 채운 뒤 '다음'을 누릅니다. 2단계로 넘어가고 위쪽 1번 점이 **초록색**으로 바뀝니다.
5. 2단계에서 닉네임(2~10글자)과 나이(14 이상)를 채우고 '다음'을 누릅니다. 중간에 **'이전'** 을 눌러 1단계로 돌아갔다 와도 입력값이 그대로 남아 있는지 확인합니다.
6. 3단계에서는 앞에서 적은 내용이 **요약**으로 보입니다. 약관 동의 체크박스를 켜고 **'가입 완료'** 를 누릅니다.
7. 폼이 사라지고 **"가입이 완료되었습니다"** 메시지가 뜨면 성공입니다.
8. `script.js`를 열어 주석을 따라 읽으며 `currentStep`(지금 단계) → `validateStep`(검증) → `render`(화면 다시 그리기)로 이어지는 흐름을 눈으로 따라갑니다.

## 검증법

- **단계 전환**: '다음'을 누르면 다음 단계만 보이고, '이전'을 누르면 직전 단계로 돌아간다. 첫 단계에선 '이전'이, 마지막 단계에선 '다음'이 보이지 않는다.
- **단계별 검증(핵심)**: 입력이 비었거나 형식이 틀리면 빨간 메시지가 뜨고 **넘어가지 않는다**. 올바르게 채우면 넘어간다.
- **인디케이터 동기화**: 지나온 단계의 점은 **초록**, 지금 단계의 점은 **파랑**, 아직 안 온 단계는 회색으로 보인다.
- **값 유지**: '이전'으로 돌아가도 앞서 입력한 값이 그대로 남아 있다.
- **요약 정확성**: 3단계 요약에 이메일·닉네임·나이가 입력한 그대로 표시된다.
- **완료 처리**: 약관 동의 없이 '가입 완료'를 누르면 막히고, 동의 후 누르면 성공 메시지가 뜬다.
- **오류 없음**: F12 → Console 탭에 빨간 오류가 없어야 한다.

> 다시 처음부터 해 보고 싶으면 브라우저 새로고침(F5)을 누르면 됩니다. (이 실습은 저장 기능이 없어 새로고침하면 초기화됩니다.)
