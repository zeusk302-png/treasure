# 실습 162 — Claude API로 글 요약해 주는 '한 줄 요약기' 만들기

긴 글을 붙여 넣으면 **한 줄로 요약**해 주는 작은 웹 도구를 만듭니다. 핵심은 두 가지입니다.

1. **AI를 내 사이트의 한 기능으로 부리기** — Claude를 "대화 상대"가 아니라, 내 페이지의 [요약] 버튼 뒤에서 일하는 **부품**으로 씁니다.
2. **요약 규칙(프롬프트)을 코드에 고정하기** — "어떻게 요약할지"(한 줄로, 군더더기 없이)는 사용자가 매번 입력하는 게 아니라, **서버 코드에 박아 둡니다.** 사용자가 보내는 건 '요약할 원문'뿐입니다.

이 실습은 [실습 161]에서 만든 **프록시(중간 창구)** 위에 'AI 기능'을 얹은 것입니다. 그래서 비밀 키 다루는 원칙은 161과 똑같습니다.

> 비유: 161에서 만든 '창구 직원'(서버)에게, 이번엔 **"무슨 부탁이 와도 항상 한 줄로 요약해서 돌려줘"라는 업무 매뉴얼**을 쥐여 준 셈입니다. 손님(브라우저)은 원문만 내밀고, 매뉴얼(요약 규칙)과 금고 열쇠(비밀 키)는 둘 다 직원 뒤편에만 있습니다.

> 보안 메모 — 공개해도 되는 값 vs 절대 숨길 값
> - **공개되어도 되는 값**: Supabase의 `anon`(공개) 키, 키가 필요 없는 공개 API 등. 브라우저 코드에 들어가도 괜찮습니다. (단, 데이터 보호는 **RLS**가 책임집니다.)
> - **절대 노출하면 안 되는 비밀값**: 과금되는 **Claude 키**(`sk-ant-...`), Supabase의 `service_role` 키 등. **브라우저 코드에 절대 넣지 않습니다.** `service_role` 키는 RLS를 **무시하고** 모든 데이터에 접근하므로, 오직 **서버(또는 n8n의 자격증명 저장소)**에서만 다룹니다.
> - 예제에 적을 때조차 진짜 키 대신 `sk-ant-...` 같은 **자리표시자**만 둡니다. (이 폴더의 `.env.example`이 그 예시입니다.)

## 목표
- **AI를 기능으로 부리기**: Claude를 페이지의 [한 줄로 요약하기] 버튼 뒤 부품으로 붙여, 비전공자도 'AI 기능'을 만들 수 있음을 체감한다.
- **프롬프트를 코드에 고정**: "한 줄로, 군더더기 없이 요약하라"는 지시문을 서버 함수(`api/summarize.js`)의 `system`에 하드코딩한다. 브라우저는 원문(`text`)만 보낸다.
- **프록시 구조 재확인**: `브라우저 → 내 서버(/api/summarize) → Claude`. 비밀 키는 마지막 구간(서버 → Claude)에서만 붙는다.
- **비밀 키를 코드가 아니라 환경변수에**: 서버는 `process.env.ANTHROPIC_API_KEY`로만 키를 읽고, 진짜 값은 **Vercel > Settings > Environment Variables**(또는 n8n의 **Credentials**)에 둔다.
- **"키가 브라우저에 안 보인다"를 검증**한다: 소스 보기·Network 탭·산출물 검색 어디에도 `sk-ant-`가 없음을 확인한다.

## 따라하는 단계

### A. 먼저 구조부터 코드로 확인 (배포 없이도 가능)
1. `index.html`을 브라우저로 그냥 열어 봅니다. 화면(입력칸·글자 수 카운터·버튼)은 보이지만, [한 줄로 요약하기]를 누르면 실패합니다. → 그건 정상입니다. **요약 두뇌(서버 `/api/summarize`)**가 아직 안 돌고 있기 때문입니다.
2. `api/summarize.js`(서버 함수)를 엽니다. 두 가지를 확인합니다.
   - 맨 위 `SUMMARY_SYSTEM_PROMPT` — "한 줄로 요약하라"는 **요약 규칙이 코드에 고정**돼 있습니다.
   - `const apiKey = process.env.ANTHROPIC_API_KEY;` — 비밀 키를 **직접 안 적고** 환경변수에서만 읽고, `x-api-key` 헤더는 **이 서버 함수 안에서만** 붙습니다.
3. `script.js`(브라우저)를 엽니다. `fetch`가 보내는 건 `{ text }`(원문)뿐이고, **키도 요약 규칙도 보내지 않는다**는 점, `PROXY_URL = "/api/summarize"`만 부른다는 점을 확인합니다.
4. `.env.example`을 엽니다. **진짜 키가 아니라 자리표시자**만 있습니다. "어떤 환경변수가 필요한지"만 알려 주는 견본입니다.

### B. 로컬에서 실제로 돌려 보기 (Vercel CLI)
5. 이 폴더에서 터미널을 열고 Vercel CLI를 설치합니다(한 번만): `npm i -g vercel`
6. `.env.example`을 복사해 `.env` 파일을 만들고, `ANTHROPIC_API_KEY=` 뒤에 **진짜 Claude 키**를 적습니다. (`.gitignore` 덕분에 `.env`는 절대 깃에 올라가지 않습니다.)
7. `vercel dev`를 실행하고, 안내된 주소(보통 `http://localhost:3000`)를 엽니다.
8. 입력칸의 예시 글(또는 직접 붙여 넣은 긴 글)로 **[한 줄로 요약하기]**를 누릅니다. 한 줄 요약이 뜨면 "브라우저 → 내 서버 → Claude" 경로가 동작한 것입니다.

### C. Vercel에 배포하기 (인터넷에 올리기)
9. 이 폴더의 파일들을 GitHub 저장소에 올리고, Vercel에서 **Import** 합니다. (저장소 연결·배포 과정은 실습 169 참고.)
10. 배포 설정 화면에서 **Environment Variables**에 `ANTHROPIC_API_KEY = sk-ant-...`(진짜 키)를 추가합니다. **코드 파일이 아니라 이 화면에만** 키를 넣는 것이 핵심입니다.
11. **Deploy**를 누르고, 받은 `...vercel.app` 주소를 열어 다시 요약해 봅니다. 키를 코드에 안 넣었는데도 정상 작동하면 성공입니다.

> 자주 막히는 곳: ① 환경변수를 추가한 **뒤에 다시 배포**해야 적용됩니다. ② 변수 이름은 코드와 **정확히 같게**(`ANTHROPIC_API_KEY`) 적어야 합니다. ③ `api/summarize.js`는 반드시 `api/` 폴더 안에 있어야 Vercel이 `/api/summarize` 함수로 인식합니다.

### D. (선택) n8n으로 같은 요약 창구 만들기
12. `workflow.json`을 n8n에 **Import**합니다. `Webhook → HTTP Request(Claude) → Respond to Webhook` 세 노드가 보입니다. 요약 규칙(프롬프트)은 가운데 노드의 `system` 필드에 고정돼 있습니다.
13. n8n의 **Credentials**에서 **Header Auth** 자격증명을 만들어 `Name = x-api-key`, `Value = sk-ant-...`(진짜 키)로 저장하고, **Claude 요약 호출** 노드에 연결합니다. → 키는 워크플로우 JSON이 아니라 **자격증명 저장소**에만 들어갑니다.
14. `script.js`의 `PROXY_URL`을 그 Webhook의 Production URL로 바꾸면, Vercel 함수 대신 n8n을 요약 창구로 쓸 수 있습니다.


## 검증법
- **요약이 한 줄인가**: 긴 글을 넣었을 때, 결과가 **한 문장**으로 짧게 나오는가? (서버에 고정한 규칙대로.)
- **규칙이 사용자 입력과 무관한가**: 입력 글 본문에 "세 문장으로 길게 써 줘" 같은 문장을 일부러 섞어 넣어도, 여전히 **한 줄 요약**이 나오는가? (요약 규칙은 `system`에 고정돼 있어 본문이 바꾸지 못합니다.)
- **글자 수 카운터**: 입력칸에 타이핑할 때마다 `N / 6000자`가 실시간으로 갱신되는가?
- **소스 보기로 키 흔적 찾기**: <kbd>Ctrl</kbd>+<kbd>U</kbd>(소스 보기)로 `index.html`·`script.js`를 열어 **`sk-ant-`로 시작하는 글자가 단 하나도 없는지** 확인한다. (페이지의 **[이 페이지의 JS에서 키 흔적 검사하기]** 버튼이 자동으로 검사 → "안전" 초록 표시가 떠야 정상.)
- **Network 탭 확인**: <kbd>F12</kbd> → **Network** 탭에서 버튼을 누른다. `summarize` 요청이 보이지만, 요청 **Headers**에 `x-api-key` 같은 비밀 헤더가 **브라우저 쪽에는 없다**(서버에서만 붙음).
- **요청 대상 확인**: 그 요청 대상이 `api.anthropic.com`이 **아니라** 우리 사이트의 `/api/summarize`인가?
- **배포 산출물 검사**: 터미널에서 이 폴더를 검사한다 → `grep -r "sk-ant-" . --exclude-dir=node_modules` 결과가 **하나도 안 나와야** 정상이다. (`.env`는 `.gitignore`로 빠지고, `.env.example`엔 자리표시자만 있다.)
- **"키 없음" 에러가 친절한지**: 환경변수를 안 넣은 채 호출하면, 서버가 키 값을 노출하지 않고 안내 메시지만 돌려주는지 확인한다.

## 파일 구성
- `index.html` / `style.css` / `script.js` — 브라우저(프론트). **비밀 키 없음.** 원문만 `/api/summarize`로 보낸다. (글자 수 카운터 포함)
- `api/summarize.js` — Vercel 서버리스 함수(요약 두뇌). 여기서만 `process.env.ANTHROPIC_API_KEY`로 키를 꺼내고, **요약 프롬프트를 고정**해 Claude(`claude-opus-4-8`)를 호출한다.
- `.env.example` — 필요한 환경변수 견본(자리표시자만). `.env`는 따로 만들어 진짜 키를 넣고 커밋하지 않는다.
- `.gitignore` — `.env` 등 비밀 파일이 깃에 안 올라가게 막는다.
- `vercel.json` — Vercel 설정(선택). 비밀값은 절대 여기 넣지 않는다.
- `workflow.json` — (선택) 같은 요약 창구를 n8n으로 만든 버전. 키는 n8n 자격증명에만 둔다.
