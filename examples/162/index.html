긴 글을 붙여 넣으면
한 줄로 요약해 주는 요약기

글을 입력하고 버튼을 누르면, 브라우저는 우리 서버의 '중간 창구'(/api/summarize)에만 부탁합니다. 진짜 Claude 호출과 비밀 키 사용은 서버 안에서만 일어나고, "어떻게 요약할지"(한 줄로)는 서버 코드에 고정돼 있습니다.

1. 요약할 글 붙여넣기

0 / 6000자
한 줄 요약

이 버튼이 부르는 곳은 Claude가 아니라 /api/summarize(우리 서버)입니다. 진짜 Claude 호출·비밀 키·요약 규칙(프롬프트)은 모두 그 서버 함수 안에 있습니다.

2. "비밀 키가 안 보인다"를 직접 확인하기

  1. 이 페이지 소스 보기: Ctrl+U(맥은 Cmd+Option+U). sk-ant- 으로 시작하는 글자가 단 한 개도 없어야 정상입니다.
  2. 개발자도구 → Network 탭(F12): 버튼을 누르면 summarize 요청이 보입니다. 요청 Headers를 펼쳐도 x-api-key 같은 비밀 헤더는 없습니다. (그 헤더는 서버에서만 붙습니다.)
  3. 요청 대상: 그 요청이 api.anthropic.com이 아니라 우리 사이트의 /api/summarize 인지 확인합니다. 브라우저는 Claude를 직접 부르지 않습니다.

공개해도 되는 값(예: Supabase anon 키)은 브라우저에 둬도 되지만, 과금되는 AI 키 같은 비밀값은 절대 브라우저에 두지 않습니다. 자세한 원리와 배포 방법은 README.md를 보세요.
