# 사진을 클릭하면 링크로 이동하는 카드 만들기

링크를 만드는 `<a>` 태그 **안에** 사진을 만드는 `<img>` 태그를 넣어, "누르면 이동하는 사진(이미지 링크)"을 만들어 봅니다. 이렇게 태그 안에 태그를 넣는 것을 **중첩(nesting)** 이라고 부르는데, 앞으로 모든 웹페이지의 기본이 되는 아주 중요한 개념이에요.

## 목표

- `<a>`(링크) 태그 안에 `<img>`(사진) 태그를 넣어, 사진을 클릭하면 다른 페이지로 이동하게 만든다.
- 태그 안에 태그를 넣는 **중첩(nesting)** 구조와, "나중에 연 것을 먼저 닫는다"는 규칙을 이해한다.
- 사진뿐 아니라 제목·설명까지 묶어 "카드 전체"를 클릭 영역으로 만들 수 있다.

> 비전공자 눈높이 한 줄 요약: 평소에 `<a>여기 클릭</a>` 처럼 글자를 넣던 자리에, 글자 대신 `<img>` 사진을 넣으면 → `<a><img ... /></a>` 가 되어 **사진 전체가 클릭 버튼**이 됩니다. 상자(`<a>`) 안에 작은 상자(`<img>`)를 넣는다고 생각하면 쉬워요.

## 따라하는 단계

1. `examples/010/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. 첫 번째 예시의 코드를 찾습니다. 모양은 아래와 같습니다.
   ```html
   <a href="https://www.busan.go.kr" target="_blank">
     <img src="그림주소" alt="설명" width="400" />
   </a>
   ```
3. 바깥쪽 `<a href="...">` 부터 `</a>` 까지가 **링크**이고, 그 안에 들어간 `<img ... />` 가 **사진**입니다. 사진이 링크 "안에" 들어가 있어서, 사진을 누르면 링크가 작동합니다. (이게 "중첩"입니다.)
4. `href="..."` 안의 주소가 "사진을 누르면 이동할 곳"입니다. 이 주소를 내가 좋아하는 사이트 주소(예: `https://www.naver.com`)로 바꿔 저장해 봅니다.
5. `target="_blank"` 는 "새 탭에서 열기"라는 뜻입니다. (이전 008번 실습에서 배운 내용을 다시 써봅니다.) 빼면 같은 탭에서 열립니다.
6. 두 번째 예시를 보면 `<a>` 안에 `<img>` 말고도 `<h3>`(제목)과 `<p>`(설명)가 함께 들어가 있습니다. 이렇게 하면 사진·제목·설명을 묶은 **카드 전체**가 하나의 클릭 영역이 됩니다.
7. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 중첩의 핵심 규칙: 안쪽 태그(`<img>`)는 바깥쪽 태그(`<a>...</a>`)의 범위를 넘어가면 안 됩니다. 즉 `<a><img /></a>` 처럼 **안쪽을 먼저 닫고, 바깥쪽을 나중에 닫아야** 합니다. `<a><img /></a>` 는 맞지만, 순서가 엉키면 화면이 깨질 수 있어요.
> 참고: `<img>` 는 닫는 태그(`</img>`)가 없어 한 줄로 끝나며 `/>` 로 닫습니다. 하지만 `<a>` 는 반드시 `</a>` 로 닫아줘야 합니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 첫 번째 사진(부산 풍경) 위에 마우스를 올렸을 때, 마우스 화살표가 **손가락 모양**으로 바뀌는지 확인합니다. → 손가락 모양은 "여기는 클릭할 수 있는 링크"라는 신호입니다.
3. 그 사진을 실제로 클릭했을 때, **새 탭에서 다른 사이트가 열리는지** 확인합니다. → 사진이 링크로 작동한다는 증거입니다.
4. 두 번째 "카드" 예시에서, 사진뿐 아니라 **제목 글자나 설명 글자를 눌러도** 똑같이 이동하는지 확인합니다. → 카드 전체가 하나의 링크라는 뜻입니다.
5. 세 번째 그림(파란 하늘·노란 해·초록 산)은 인터넷이 없어도 **항상 보이며**, 클릭하면 설명서로 이동하는지 확인합니다.
6. (선택) `href` 의 주소를 내가 아는 사이트로 바꾸고 새로고침(F5)한 뒤, 사진을 눌렀을 때 그 사이트로 이동하는지 확인합니다.
7. (선택) 첫 번째·두 번째 사진이 안 보인다면 인터넷 연결을 확인하세요. 인터넷이 없어도 `alt` 에 적은 설명 글자가 대신 보이며, 그 글자를 눌러도 링크는 그대로 작동합니다.
