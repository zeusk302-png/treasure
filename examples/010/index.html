사진을 클릭하면 링크로 이동하기

이번에는 <a>(링크) 태그 안에 <img>(사진) 태그를 넣어볼 거예요. 이렇게 태그를 겹쳐 넣는 것을 "중첩(nesting)"이라고 부릅니다. 사진을 클릭하면 링크로 이동하게 됩니다.

예시 1) 사진을 클릭하면 다른 사이트로 이동

아래 사진을 클릭하면 새 탭에서 다른 사이트가 열립니다.

예시 2) "카드"처럼 사진 + 제목 + 설명 묶기

사진뿐 아니라 제목·설명까지 통째로 묶어 클릭하게 만들 수도 있어요. <a> 안에 <img>, <h3>, <p> 를 모두 넣으면 "카드 전체"가 하나의 클릭 영역이 됩니다. 이것도 똑같은 "중첩"이에요.

웹 개발 공부하러 가기

사진, 제목, 설명까지 카드 전체를 누르면 이동합니다.
