# 실습 01 — 정적 랜딩페이지

가장 기본. 서버도 데이터베이스도 없는 **HTML + CSS** 한 장짜리 소개 페이지입니다.

## 목표
- 웹페이지가 `index.html`(내용)과 `style.css`(꾸밈)로 나뉜다는 걸 몸으로 안다.
- 더블클릭만으로 내 컴퓨터에서 웹페이지가 열린다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭 → 브라우저에서 열린다.
2. `index.html`에서 가게 이름·메뉴·가격을 내 것으로 바꾼다.
3. `style.css`에서 색(`--beige`, `--brown`)을 바꿔 본다.
4. AI에게 시켜 보기:
   > "이 index.html에 '오시는 길' 아래에 인스타그램 링크 버튼을 추가해줘. 색은 기존 갈색 톤에 맞춰서."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 프론트엔드 입문 멘토야. 동네 카페 '햇살카페'의 한 장짜리 정적 랜딩페이지를
  HTML과 CSS만으로(자바스크립트·서버·DB 없이) 만들어줘.
  - 구조: 상단 히어로(가게 이름 + 한 줄 소개 + '메뉴 보기' 버튼),
    메뉴 섹션(메뉴명 왼쪽 / 가격 오른쪽 정렬), 찾아오는 길 섹션, 푸터.
  - 내용(content)은 index.html, 꾸밈(style)은 style.css로 파일을 분리해줘.
  - 색은 베이지/갈색 톤(:root 변수로 정의), 모바일에서도 안 깨지게 max-width로 본문 폭 제한.
  - viewport 메타태그와 한국어 lang 속성을 꼭 넣어줘.
  결과 코드에는 비전공자가 이해할 수 있게 한국어 주석을 달아줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  지금 index.html / style.css 기준으로 아래를 추가·개선해줘.
  - '찾아오는 길' 아래에 인스타그램 링크 버튼을 추가(색은 기존 갈색 톤에 맞춤, 새 탭으로 열리게).
  - 휴대폰 너비에서 히어로 글자가 너무 크면 줄어들도록 반응형으로 다듬어줘.
  기존 구조·색은 유지하고, 바꾼 부분이 왜 필요한지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 더블클릭했는데 글꼴/색이 적용이 안 돼.
  지금 index.html과 style.css 전체를 줄게: (코드 붙여넣기)
  CSS가 안 먹는 이유를 초보가 이해하게 단계별로 진단해줘.
  link 태그 경로, 파일 위치, 파일명 오타 같은 흔한 원인부터 하나씩 확인해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- 브라우저 창을 좁혀도(휴대폰 너비) 글자가 안 깨지는가?
- 메뉴 가격이 오른쪽에 가지런히 정렬되는가?
- "메뉴 보기" 버튼을 누르면 메뉴 영역으로 이동하는가?
