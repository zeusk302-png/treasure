# 실습 01 — 정적 랜딩페이지

가장 기본. 서버도 데이터베이스도 없는 **HTML + CSS** 한 장짜리 소개 페이지입니다.

## 목표
- 웹페이지가 `index.html`(내용)과 `style.css`(꾸밈)로 나뉜다는 걸 몸으로 안다.
- 더블클릭만으로 내 컴퓨터에서 웹페이지가 열린다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭 → 브라우저에서 열린다.
2. `index.html`에서 가게 이름·메뉴·가격을 내 것으로 바꾼다.
3. `style.css`에서 색(`--beige`, `--brown`)을 바꿔 본다.
4. AI에게 시켜 보기:
   > "이 index.html에 '오시는 길' 아래에 인스타그램 링크 버튼을 추가해줘. 색은 기존 갈색 톤에 맞춰서."

## 검증법
- 브라우저 창을 좁혀도(휴대폰 너비) 글자가 안 깨지는가?
- 메뉴 가격이 오른쪽에 가지런히 정렬되는가?
- "메뉴 보기" 버튼을 누르면 메뉴 영역으로 이동하는가?
