# 047 · 모바일 우선으로 1열 → 2열 → 3열 반응형 카드 만들기

휴대폰에서는 카드가 한 줄에 1개, 태블릿에서는 2개, 데스크톱에서는 3개로 자동 정렬되는 카드 그리드를 만듭니다. CSS만으로 화면 크기에 맞춰 레이아웃이 바뀌는 "반응형"을 직접 경험합니다.

## 목표

- **모바일 퍼스트(Mobile First)** 설계 방식을 이해한다. (좁은 화면 기준으로 먼저 만들고, 넓어질 때 규칙을 더한다)
- 미디어쿼리 `@media (min-width: ...)`를 **두 단계**로 써서 1열 → 2열 → 3열로 늘려본다.
- CSS Grid에서 `grid-template-columns`로 열 개수를 정하는 법을 익힌다.

> 왜 "모바일 퍼스트"인가요? 요즘은 웹사이트 방문자 대부분이 휴대폰을 씁니다. 그래서 좁은 화면을 기본으로 먼저 만들고, 화면이 넓어질 때만 규칙을 추가하는 것이 더 안전하고 코드도 단순해집니다.

## 따라하는 단계

1. `examples/047/` 폴더의 `index.html`, `style.css`를 같은 폴더에 둡니다. (이미 만들어져 있습니다)
2. `index.html`을 더블클릭해서 브라우저로 엽니다. 카드 6개가 보이면 성공입니다.
3. `index.html`의 `<head>` 안 `<meta name="viewport" ...>` 한 줄을 확인하세요. 이 한 줄이 있어야 휴대폰에서 화면이 제대로 보입니다. (모바일 퍼스트의 출발점)
4. `style.css`에서 `.card-grid`를 봅니다. 기본값이 `grid-template-columns: 1fr;` 입니다. 이것이 **휴대폰용 1열**입니다. 미디어쿼리 없이 적용되는 이 기본 스타일이 "모바일 퍼스트"의 기준선입니다.
5. 그 아래 `@media (min-width: 600px)` 블록을 봅니다. 화면 폭이 **600px 이상**이 되면 `grid-template-columns: 1fr 1fr;`(2열)로 바뀝니다. (태블릿)
6. 마지막 `@media (min-width: 900px)` 블록을 봅니다. 화면 폭이 **900px 이상**이면 `repeat(3, 1fr)`(3열)로 다시 한 번 바뀝니다. (데스크톱) — 이렇게 미디어쿼리를 단계별로 쌓는 것이 **다단계 미디어쿼리**입니다.
7. 직접 실험해 보세요. 600 / 900 숫자를 700, 1100 등으로 바꾸고 새로고침하면 열이 바뀌는 폭이 달라집니다.

## 검증법

브라우저 창의 **가로 폭을 마우스로 좁혔다 넓혔다** 하면서 다음을 확인하세요.

1. 창을 아주 좁게(휴대폰만큼) 줄이면 → 카드가 **세로로 1줄(1열)**로 쌓인다.
2. 창을 중간 크기(약 600~900px)로 늘리면 → 카드가 **한 줄에 2개(2열)**로 배치된다.
3. 창을 넓게(900px 이상) 늘리면 → 카드가 **한 줄에 3개(3열)**로 배치된다.
4. 어느 크기에서도 카드가 화면 밖으로 삐져나가거나 글자가 잘리지 않는다.

브라우저 개발자 도구(F12)를 열고 좌측 상단의 **기기 모드(휴대폰 아이콘)** 를 켜서 iPhone, iPad 등을 선택해 보면 실제 기기 화면처럼 확인할 수 있습니다.

## 핵심 정리

| 화면 폭 | 적용되는 규칙 | 열 개수 |
| --- | --- | --- |
| 기본(좁은 화면) | `grid-template-columns: 1fr;` | 1열 |
| 600px 이상 | `@media (min-width: 600px)` | 2열 |
| 900px 이상 | `@media (min-width: 900px)` | 3열 |

- 기본 스타일을 좁은 화면 기준으로 두고 `min-width`로 넓어질 때만 덮어쓰는 것 = **모바일 퍼스트**.
- `1fr`은 "남는 공간을 똑같이 나눠 가진 한 칸"이라는 뜻입니다. `1fr 1fr`이면 2칸, `repeat(3, 1fr)`이면 3칸입니다.
