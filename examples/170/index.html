🔄 git push 한 번으로 자동 재배포 확인하기

이 화면이 https://...vercel.app 주소에서 보인다면, GitHub에 올린 코드가 Vercel을 통해 인터넷에 떠 있는 것입니다. 이제 아래 배포 버전 글자를 고치고 git push 해 보세요.

배포 버전: v1 (아직 수정 전)

  1. GitHub(또는 내 PC)에서 위 v1 글자를 v2로 바꾼다
  2. git push 한다 (또는 GitHub 웹에서 Commit changes)
  3. Vercel Deployments 탭에 새 줄이 자동으로 생긴다
  4. 상태가 Ready로 바뀌면 같은 주소를 새로고침한다
  5. 글자가 v2로 바뀌어 있으면 자동 재배포 성공!

비밀 메모: 이 파일에는 비밀값이 없습니다. 정적 페이지라서 누구에게 공개돼도 안전합니다. 나중에 Supabase 등을 쓰게 되면, 공개해도 되는 anon 키와 절대 공개하면 안 되는 service_role 키를 구분해야 하고, 비밀값은 코드가 아니라 Vercel의 Settings → Environment Variables에 넣습니다.
