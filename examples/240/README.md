# 240 — 블로그 다크모드 토글 버튼 만들기

버튼을 한 번 누르면 **밝은 화면(라이트모드)** 과 **어두운 화면(다크모드)** 이
번갈아 바뀌는 토글을 만듭니다. 요즘 거의 모든 앱·사이트(유튜브, 카카오톡, 깃허브 등)에
있는 그 기능입니다.

핵심은 마법이 아니라 **세 가지 약속의 조합**입니다.

1. 버튼이 **눌리면**(이벤트)
2. `<body>`에 `dark`라는 **이름표(클래스)를 붙였다 뗀다**(클래스 토글)
3. 그 이름표가 붙는 순간, 미리 정해 둔 **어두운 색(CSS 변수)** 으로 화면 전체가 갈아끼워진다

- 카테고리: 아키타입 미니프로젝트 (코드 L)
- 난이도: 2 / 5
- 개념: JS 이벤트, 클래스 토글, CSS 변수
- 결과물: **다크모드 토글이 동작하는 페이지** (이 폴더의 `index.html` + `style.css` + `script.js`)

> 이 폴더에는 세 개의 파일이 있습니다. **역할이 딱 나뉘어** 있습니다.
> - `index.html` : 화면의 **구조** (제목, 토글 버튼, 글 카드들)
> - `style.css` : 화면의 **모양** (라이트 색과 다크 색을 둘 다 정의)
> - `script.js` : 화면의 **동작** (버튼이 눌리면 클래스를 붙였다 뗌)
> 세 파일은 **같은 폴더에 함께** 있어야 정상 작동합니다.

---

## 목표

이번에 진짜 배우는 것은 "다크모드 만드는 법" 그 자체가 아니라, **웹이 움직이는 기본 공식**입니다.

> **"무엇이 일어나면(이벤트) → 무엇을 바꾼다(클래스/스타일)."**

좋아요 버튼, 메뉴 열기, 탭 전환 — 화면에서 클릭으로 뭔가 바뀌는 건 거의 다 이 공식입니다.
다크모드는 그 공식을 처음 익히기에 딱 좋은 예제입니다.

그리고 한 가지 더, **CSS 변수(색 이름표)의 쓸모**를 체감합니다.
색을 카드마다 일일이 칠해 두면, 다크모드를 만들 때 그 색을 전부 다시 찾아 바꿔야 합니다.
하지만 색을 `--bg`, `--text` 같은 **이름표 한 곳에 모아 두면**, 다크모드에서는
그 이름표의 **값만 어둡게 갈아끼우면** 페이지 전체가 한 번에 바뀝니다.

- **이벤트(event)**: 사용자가 한 행동(클릭, 입력 등) "그 일이 일어난 순간".
- **클래스 토글(class toggle)**: `dark`라는 이름표를 붙였다 뗐다 하는 것. 붙으면 다크, 없으면 라이트.
- **CSS 변수(custom property)**: `--bg`처럼 색에 붙인 이름표. 값만 바꾸면 그 이름표를 쓰는 모든 곳이 같이 바뀜.

> 비유: 방의 조명 스위치입니다. 스위치를 누르면(이벤트) 방 전체 분위기가 바뀝니다(다크/라이트).
> 우리가 하는 일은 전구를 하나하나 가는 게 아니라, **스위치 하나를 거는 것**뿐입니다.

## 따라하는 단계

### 1단계 — 파일 세 개 확인하고 페이지 열기

1. 이 폴더(`240`) 안에 `index.html`, `style.css`, `script.js` **세 파일**이 있는지 확인합니다.
2. `index.html` 을 **더블클릭**해 브라우저로 엽니다.
3. 처음엔 **밝은(라이트) 화면**에, 오른쪽 위에 **`🌙 다크모드`** 버튼이 보이면 준비 완료입니다.

### 2단계 — 버튼을 눌러 토글 동작 확인하기

1. 오른쪽 위 **`🌙 다크모드`** 버튼을 누릅니다.
2. 배경·카드·글자 색이 **어둡게** 바뀌고, 버튼 글자가 **`☀️ 라이트모드`** 로 바뀝니다.
3. 한 번 더 누르면 **다시 밝아지고** 버튼 글자도 `🌙 다크모드`로 돌아옵니다.
   이렇게 누를 때마다 라이트↔다크가 번갈아 바뀌는 것이 **토글**입니다.

### 3단계 — "이벤트 → 클래스 토글" 한 줄 찾아보기

1. `script.js` 를 메모장(또는 VS Code)으로 엽니다.
2. 다음 두 부분을 눈으로 확인합니다.
   - `toggleButton.addEventListener("click", ... )` → **버튼이 눌리면 실행하라는 약속(이벤트)**
   - `document.body.classList.toggle("dark")` → **`<body>`에 `dark` 이름표를 붙였다 뗌(클래스 토글)**
3. 이 두 줄이 이번 실습의 심장입니다. "클릭되면(위) → dark를 토글한다(아래)" 흐름을 기억하세요.

### 4단계 — 다크모드 색이 어디서 오는지 확인하기

1. `style.css` 를 엽니다.
2. 맨 위에 두 묶음이 있습니다.
   - `:root { --bg: #f5f3ff; ... }` → **라이트모드(기본)** 색 이름표
   - `body.dark { --bg: #16131f; ... }` → **다크모드** 색 이름표(`<body>`에 `dark`가 붙었을 때만 적용)
3. 두 묶음의 **이름표는 똑같고**(`--bg`, `--text` ...), **값(색)만 다르다**는 점을 확인합니다.
   바로 이것 때문에 클래스 하나만 붙여도 화면 전체 색이 바뀌는 것입니다.

### 5단계 — 색 직접 바꿔보기 (내 손으로 실험)

1. `style.css` 의 `body.dark` 안 `--bg` 값을 다른 어두운 색(예: `#0a0a1a`)으로 바꿔 봅니다.
2. 저장한 뒤 브라우저에서 **새로고침(F5)** 하고, 다시 **다크모드 버튼**을 눌러 봅니다.
3. 다크모드 배경색만 바뀌고 라이트모드는 그대로인지 확인합니다.
   (라이트는 `:root`, 다크는 `body.dark`에서 따로 관리되기 때문입니다.)

## 검증법

아래가 모두 맞으면 성공입니다.

- **버튼이 보인다**: 페이지를 열면 오른쪽 위에 `🌙 다크모드` 버튼이 떠 있다.
- **토글이 된다**: 버튼을 누르면 화면이 어두워지고, 다시 누르면 밝아진다.
- **버튼 글자가 바뀐다**: 다크일 때 `☀️ 라이트모드`, 라이트일 때 `🌙 다크모드`로 표시된다.
- **색이 부드럽게 바뀐다**: 색이 톡 튀지 않고 0.25초 정도에 걸쳐 스르륵 바뀐다.
- **카드도 함께 바뀐다**: 배경뿐 아니라 카드·글자·태그 색까지 모두 다크 색으로 따라 바뀐다.

> 흔한 실수
> - **버튼을 눌러도 아무 변화 없음**: `index.html` 맨 아래에 `<script src="script.js"></script>` 줄이
>   있는지, `script.js` 파일 이름 철자가 정확한지 확인하세요. (브라우저 `F12` → Console 탭에 빨간 에러가
>   있으면 그 줄을 읽어 보면 단서가 됩니다.)
> - **색이 하나도 안 입혀짐(글자만 나옴)**: `style.css`가 같은 폴더에 있는지, `<link rel="stylesheet"
>   href="style.css" />` 줄이 있는지 확인하세요.
> - **다크모드에서 글자가 안 보임**: `body.dark`의 `--text`(글자색)와 `--bg`(배경색)가
>   서로 비슷한 밝기면 안 보입니다. 배경이 어두우면 글자는 밝게(반대로) 둬야 합니다.
> - **새로고침하면 라이트로 돌아감**: **정상입니다.** 이번 실습은 선택을 저장하지 않습니다.
>   새로고침해도 유지하는 방법(localStorage)은 아래 '다음으로 권장' 실습에서 배웁니다.
> - **한글이 깨져 보임**: `index.html` 위쪽에 `<meta charset="UTF-8" />` 가 있어야 합니다.
