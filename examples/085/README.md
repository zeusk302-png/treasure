# 할 일 목록 완성 — localStorage로 데이터 영구 저장 + 필터

앞에서 만든 할 일 목록을 **새로고침해도 사라지지 않게** 저장하고, **전체 / 진행 중 / 완료** 필터를 붙여 완성하는 미니 앱입니다.
이 실습은 지금까지 배운 것(배열 다루기, 화면 다시 그리기, 완료 체크, localStorage 저장)을 **한 화면에 모두 합치는 졸업 작품**입니다.

> 비유: 할 일 배열(`todos`)은 "진짜 명단"이고, 화면은 그 명단을 베껴 적은 "칠판"입니다.
> 여기에 더해, 명단이 바뀔 때마다 **서랍(localStorage)에 사본을 한 장 넣어 둡니다.**
> 그래서 다음에 와도 서랍에서 사본을 꺼내 칠판에 다시 옮겨 적을 수 있습니다. 필터는 칠판에서 "보고 싶은 줄만 골라 보는" 안경입니다.

## 목표

- 할 일을 `JSON.stringify`로 글자로 바꿔 **localStorage에 저장**한다.
- 재방문/새로고침 시 `JSON.parse`로 글자를 **다시 객체 배열로 되살려** 그대로 화면에 그린다.
- **전체 / 진행 중 / 완료** 필터로 보고 싶은 항목만 걸러서 보여준다(필터 상태도 변수로 관리).
- "데이터(배열)가 진실의 원본 → 바뀌면 저장하고 다시 그린다"는 핵심 흐름을 끝까지 몸에 익힌다.

## 따라하는 단계

1. 이 폴더(`085`)의 `index.html`, `style.css`, `script.js` 세 파일을 같은 폴더에 둡니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다.
3. 입력칸에 할 일을 2~3개 적어 **추가**합니다. (Enter 키로도 추가됩니다.)
4. 각 항목 왼쪽의 **체크박스**를 눌러 완료 표시(줄긋기)가 되는지 확인합니다.
5. **새로고침(F5)** 을 눌러 봅니다. 적어 둔 할 일과 완료 상태가 **그대로 남아 있어야** 합니다. (이게 핵심입니다.)
6. 위쪽 **전체 / 진행 중 / 완료** 버튼을 차례로 눌러, 보이는 목록이 필터에 맞게 바뀌는지 확인합니다.
7. **완료 항목 비우기** 버튼을 눌러 완료한 항목들이 한 번에 사라지는지 봅니다.
8. `script.js`를 열어 주석을 따라 읽으며, `loadTodos`(불러오기) → `render`(그리기), 추가/체크/삭제 후 `saveTodos`(저장) → `render`의 흐름을 눈으로 따라갑니다.

## 검증법

- **영구 저장(가장 중요)**: 할 일을 추가/완료한 뒤 새로고침해도 목록과 완료 상태가 그대로 유지된다.
- **되살리기**: 브라우저를 완전히 닫았다 다시 열어도 데이터가 남아 있다.
- **필터 동작**: "진행 중"은 미완료만, "완료"는 완료만, "전체"는 모두 보여주고, 선택한 버튼만 파랗게 강조된다.
- **남은 개수**: 필터와 무관하게 "남은 할 일: N개"는 **미완료 항목 수**를 정확히 보여준다.
- **완료 비우기**: 버튼을 누르면 완료된 항목만 사라지고 진행 중 항목은 남는다.
- **저장값 확인(개발자 도구)**: F12 → Application(또는 Storage) 탭 → Local Storage에 `my-todos` 키가 있고, 값이 `[{"id":...,"text":"...","done":true}]` 형태의 JSON이다.
- **오류 없음**: F12 → Console 탭에 빨간 오류가 없어야 한다.

> 저장된 데이터를 초기화하고 싶다면: 개발자 도구의 Local Storage에서 `my-todos` 값을 삭제하거나,
> Console에 `localStorage.removeItem("my-todos")`를 입력한 뒤 새로고침하면 빈 목록으로 돌아갑니다.
