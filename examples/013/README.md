# 인용문과 가로줄로 블로그 글 본문 꾸미기

평범한 문단(`<p>`) 사이에 **인용구(`<blockquote>`)** 와 **가로 구분선(`<hr>`)** 을 끼워 넣어, 읽기 좋은 한 편의 블로그 글 본문을 만들어 봅니다. 글은 그냥 문장만 나열한다고 잘 읽히는 게 아니라, "여기는 남의 말", "여기서 주제가 바뀜" 같은 신호가 있어야 술술 읽힙니다. 그 신호를 만드는 태그가 바로 `<blockquote>` 와 `<hr>` 입니다.

## 목표

- `<p>` 로 글의 기본 덩어리인 **문단**을 만든다.
- `<blockquote>` 로 **남의 말/명언/책 구절을 인용**한다. (브라우저가 자동으로 한 칸 들여써서 본문과 구분해 줌)
- `<hr>` 로 **주제가 바뀌는 지점에 가로 구분선**을 긋는다. (장면 전환 신호)
- `<cite>` 로 인용한 말의 **출처(누가 한 말인지)** 를 적는다. (덤으로 익히는 태그)
- `<hr>` 은 닫는 태그가 없는 **빈 태그**라서 `<hr />` 처럼 스스로 닫는다는 점을 안다.

> 비전공자 눈높이 한 줄 요약: 글(`<p>`) 사이사이에, 남의 말을 끌어올 땐 `<blockquote>`("따옴표 박스")로 감싸고, 이야기가 바뀌는 자리엔 `<hr>`("선 긋기")을 넣으면, 밋밋한 글이 신문 기사처럼 읽기 편해집니다.

## 따라하는 단계

1. `examples/013/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<p> ... </p>` 가 여러 개 보입니다. 이게 글의 기본 단위인 **문단**입니다. 한 문단에는 한 가지 생각을 담는 게 좋아요.
3. `<blockquote> ... </blockquote>` 부분을 찾습니다. 안에 들어 있는 명언이 바로 **인용구**입니다. 인용 내용은 `<blockquote>` 안에 다시 `<p>` 로 적습니다.
4. 인용구 안의 `<cite>노자, 도덕경</cite>` 을 봅니다. 이렇게 **출처**를 `<cite>` 로 적으면 "누구 말인지"가 분명해집니다.
5. `<hr />` 을 찾습니다. 위 이야기(시작)와 아래 이야기(지금)를 나누는 **가로줄**입니다. `<hr />` 은 닫는 태그(`</hr>`)가 없고, 슬래시로 스스로 닫습니다.
6. 나만의 인용구를 추가해 봅니다. 마지막 `<hr />` **위쪽** 아무 데나 아래처럼 한 덩어리를 넣어 보세요.
   ```html
   <blockquote>
     <p>“시작이 반이다.”</p>
     <p>— <cite>한국 속담</cite></p>
   </blockquote>
   ```
7. 주제가 바뀌는 자리에 가로줄을 하나 더 넣어 봅니다. 원하는 문단 사이에 `<hr />` 한 줄을 추가해 보세요.
8. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의 1: `<hr>` 은 내용이 없는 "빈 태그"입니다. `<hr>텍스트</hr>` 처럼 글자를 넣지 마세요. 그냥 `<hr />` 한 줄로 씁니다.
> 주의 2: 인용구는 `<blockquote>` "박스" 자체이고, 그 안의 글은 `<p>` 로 적습니다. `<blockquote>` 안에 바로 글만 쓰는 것보다 `<p>` 로 한 번 더 감싸 주는 게 깔끔합니다.
> 주의 3: `<blockquote>` 와 `<cite>` 는 헷갈리기 쉽습니다. **인용한 말 자체**는 `<blockquote>`, **그 말의 출처(누가)** 는 `<cite>` 로 기억하세요.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 명언("여행의 천 리 길도…")이 적힌 부분이 **본문 문단보다 한 칸 안쪽으로 들여써져** 있는지 확인합니다. → 이게 `<blockquote>` 인용구의 기본 모양입니다.
3. 인용구 아래 출처("— 노자, 도덕경")가 **살짝 기울어진 글씨(이탤릭)** 로 보이는지 확인합니다. → `<cite>` 의 기본 모양입니다.
4. 시작 이야기와 "지금은 매일 한 줄씩…" 사이에 **가로로 그어진 선**이 있는지 확인합니다. → 이게 `<hr>` 입니다.
5. 단계 6에서 직접 추가한 "시작이 반이다" 인용구가 들여써진 형태로 새로 나타나는지 새로고침(F5) 후 확인합니다.
6. (확인 팁) 인용구가 들여써지지 않고 본문과 똑같이 붙어 보인다면, `<blockquote>` 로 감싸지 않았거나 닫는 태그 `</blockquote>` 가 빠졌을 가능성이 높습니다. 태그 짝을 다시 확인하세요.
7. (확인 팁) 가로줄이 안 보인다면 `<hr />` 의 철자나 슬래시(`/`)를 확인하세요.
