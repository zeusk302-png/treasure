# 실습 158 — 지도 라이브러리로 검색한 장소에 핀 찍기

주소나 장소 이름을 입력하면, 그 자리에 **지도 핀(마커)**이 탁 꽂히는 페이지를 만듭니다.
직접 지도를 그리는 게 아니라, 이미 잘 만들어진 **외부 지도 라이브러리(Leaflet)**를 가져다 끼웁니다(임베드).

이 실습의 진짜 핵심은 한 가지 깨달음입니다.
> **컴퓨터는 "부산광역시청"이라는 글자를 모릅니다.** 지도는 오직 **위도·경도(좌표)**라는 숫자만 압니다.
> 그래서 글자(주소)를 좌표 숫자로 바꿔 주는 번역기가 필요한데, 그게 바로 **지오코딩(Geocoding) API**입니다.

> 비유: 택배 기사님께 "부산시청요"라고만 하면 못 찾습니다. **정확한 위경도 좌표(=GPS 핀)**가 있어야 정확히 갑니다.
> 지오코딩 API는 "부산시청 → (위도 35.18, 경도 129.07)"처럼 **주소를 좌표로 번역**해 주는 역할입니다.

이 데모는 키가 필요 없는 무료 공개 API만 씁니다.
- **지도(Leaflet) + 지도 타일(OpenStreetMap)**: 무료 공개 지도 라이브러리. 키 없음.
- **지오코딩(Nominatim / OpenStreetMap)**: 주소를 좌표로 바꿔 주는 무료 공개 API. 키 없음.

그래서 **인터넷 연결만 있으면** 그대로 동작합니다. (가입·키·결제 모두 불필요)

## 목표
- **외부 지도 SDK 임베드**의 3단계를 익힌다.
  - HTML `<head>`에 라이브러리 **CSS**를 불러오고(`leaflet.css`), `</body>` 앞에 **JS**를 불러온다(`leaflet.js`).
  - 지도를 담을 `<div id="map">`에는 반드시 **높이(height)**가 있어야 한다. (높이가 0이면 지도가 안 보이는, 가장 흔한 실수)
  - `L.map("map")` → `L.tileLayer(...)` → `L.marker(...)` 순서로 **지도 생성 → 배경 깔기 → 핀 꽂기**를 한다.
- **지오코딩**의 흐름을 이해한다: 입력한 **글자(주소)**를 API에 보내고, 돌아온 결과에서 **위도(`lat`)·경도(`lon`)**를 꺼낸다.
- **좌표 다루기**: API가 좌표를 **문자열**("35.17")로 주므로 `parseFloat`로 **숫자**로 바꾼 뒤 `[위도, 경도]` 형태로 지도에 넘긴다. (Leaflet은 `[경도, 위도]`가 아니라 `[위도, 경도]` 순서임에 주의)
- **검색할 때마다 이전 핀을 지우고** 새 핀 하나만 남기는 패턴(`map.removeLayer(marker)`)을 익힌다.
- 결과 없음 / 서버 오류 / 인터넷 끊김을 **각각 다른 친절한 안내**로 처리한다(157에서 배운 `try/catch/finally` 그대로 응용).

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭 → 브라우저에서 열린다. (지도 타일과 지오코딩은 인터넷에서 불러오므로 **인터넷 연결이 필요**합니다.)
2. 처음에는 **부산 시청 근처**가 가운데 잡힌 지도가 보인다. (아직 핀은 없음)
3. 예시 칩 중 **[부산광역시청]**을 눌러 본다 → 잠깐 "위치를 찾는 중…"이 뜬 뒤, 지도가 그 자리로 **확대 이동**하고 **핀이 꽂히며** 말풍선에 장소 이름이 뜬다.
4. 입력칸에 직접 **광안리해수욕장**을 적고 **[핀 찍기]**(또는 Enter)를 누른다 → 핀이 광안리로 옮겨 간다. (이전 부산시청 핀은 사라지고 핀은 **항상 하나만** 남는다)
5. 카드 아래에 **위도·경도 숫자**가 표시되는지 본다 → "글자 → 좌표"로 번역됐다는 증거다.
6. **아무 의미 없는 글자**(예: `asdfqwerzxcv`)를 넣고 눌러 본다 → "해당하는 장소를 찾지 못했어요"라는 **빨간 안내**가 뜬다. (결과 없음 처리 확인)
7. `script.js`를 연다. **세 단계 흐름**을 직접 찾아본다.
   - ① 입력값 읽기: `addressInput.value.trim()`
   - ② 지오코딩 호출: `fetch("https://nominatim.openstreetmap.org/search?...&q=" + encodeURIComponent(query))`
   - ③ 핀 꽂기: `map.setView([lat, lng], 16)` → `L.marker([lat, lng]).addTo(map)`
8. AI에게 시켜 보기 (디렉터 연습):
   > "이 `script.js`에서, 핀을 꽂은 뒤 **마커를 마우스로 드래그**할 수 있게 하고(`draggable: true`), 드래그가 끝나면(`dragend`) **새 위치의 위도·경도를 화면 아래 좌표 줄에 갱신**해 줘. 단, **기존의 지오코딩 검색 흐름과 `try/catch/finally`, 핀이 항상 하나만 남는 구조는 그대로 유지**해 줘."

## 검증법
- 예시 칩 **[부산광역시청]**을 누르면 지도가 그 자리로 **이동·확대**되고 **핀 + 말풍선**이 뜨는가?
- 다른 장소를 검색하면 **이전 핀이 사라지고** 새 핀만 남는가? (핀이 여러 개로 쌓이지 않는가)
- 검색 성공 시 카드 아래에 **위도·경도 숫자**가 보이는가?
- **빈 칸**으로 [핀 찍기]를 누르면 "먼저 장소나 주소를 입력해 주세요"가 뜨고, 헛된 요청을 보내지 않는가?
- **의미 없는 글자**를 넣으면 "찾지 못했어요" **빨간 안내**가 뜨는가? (성공일 땐 초록, 실패일 땐 빨강으로 색이 다른가)
- 지도가 **회색 깨진 모양이 아니라** 실제 거리 지도로 보이는가? (안 보이면: `leaflet.css`를 불러왔는지, `#map`에 `height`가 있는지 점검 → 아래 "흔한 함정" 참고)
- `F12`(개발자 도구) → **Console 탭**을 열고 일부러 인터넷을 끊은 뒤 검색하면, 자세한 원인이 `핀 찍기 실패: ...`로 **콘솔에만** 찍히고 화면에는 친절한 한 줄만 나오는가?

## 흔한 함정 (지도가 안 보일 때 90%는 여기)
- **`#map`에 높이가 없음**: 지도 박스 높이가 0이면 지도는 그려져도 0px라 안 보입니다. `style.css`의 `#map { height: 360px; }`가 핵심입니다.
- **`leaflet.css`를 안 불러옴**: JS만 불러오고 CSS를 빼면 지도가 회색 조각처럼 깨져 보입니다. `<head>`의 `leaflet.css` 줄을 확인하세요.
- **스크립트 순서**: `leaflet.js`(라이브러리)가 우리 `script.js`보다 **먼저** 와야 `L.map(...)`을 쓸 수 있습니다.
- **좌표 순서**: 지오코딩 결과의 `lat`(위도), `lon`(경도)을 Leaflet에는 **`[위도, 경도]`** 순서로 넘깁니다. 뒤집으면 엉뚱한 곳(바다 한가운데 등)에 핀이 찍힙니다.

## 공개 API와 비밀값 — 보안 메모
이 실습은 **키가 필요 없는 공개 API**(Leaflet·OpenStreetMap·Nominatim)만 써서, 브라우저 코드에 그대로 둬도 안전합니다.
하지만 **유료 지도/지오코딩 서비스(예: Google Maps, Mapbox 등)**로 바꾸면 이야기가 달라지므로 원칙을 정리해 둡니다.

- **공개되어도 되는 값**(예: Supabase의 `anon`(공개) 키, 키 없는 OSM): 브라우저 코드에 들어가도 괜찮습니다. 단, 데이터 보호는 **RLS(행 수준 보안)**가 책임집니다. anon 키만 믿고 RLS를 끄면 누구나 데이터를 읽고 쓸 수 있어 위험합니다.
- **절대 노출하면 안 되는 비밀값**(예: Supabase의 `service_role` 키, 과금되는 유료 지도 API 키): **브라우저 코드에 절대 넣지 않습니다.** 브라우저 코드는 `F12`로 누구나 들여다볼 수 있어, 비밀키를 넣으면 그대로 도둑맞아 **요금 폭탄·데이터 유출**로 이어집니다. `service_role` 키는 RLS를 **무시하고** 모든 데이터에 접근하므로, 오직 서버(또는 n8n 같은 자동화 도구의 자격 증명 저장소)에서만 다룹니다.
- 유료 지오코딩으로 바꾼다면: 브라우저 → **내 서버(또는 n8n 워크플로)** → 유료 API 순으로 호출해, 키는 서버 쪽에만 둡니다.
- 예제에 적을 때조차 진짜 키 대신 `YOUR_API_KEY` 같은 **자리표시자**만 둡니다.

```js
// 키가 필요한 '유료' 지오코딩으로 바꾸는 경우 — 이렇게 하면 안 됩니다 (브라우저에 키 노출!)
// const url = "https://api.example.com/geocode?key=진짜키&q=" + query;  // ❌ 금지

// 올바른 방향: 키는 코드에 넣지 말고 내 서버/n8n을 거쳐 호출합니다.
const API_KEY = "YOUR_API_KEY"; // ← 자리표시자. 실제 비밀키는 절대 브라우저 코드에 넣지 않는다.
// (이 키는 브라우저가 아니라 서버 환경변수에만 존재해야 합니다.)
```

> 정리: **이 실습의 OSM/Nominatim은 키가 없으니 브라우저에서 직접 불러도 안전**합니다. 하지만 **키가 붙는 순간, 그 호출은 서버(또는 n8n) 뒤로 숨겨야** 합니다.
