# 103. 드래그앤드롭 파일 첨부 영역과 미리보기 UI

점선으로 표시된 영역에 파일을 마우스로 끌어다 놓거나, 영역을 클릭해서 파일을 고르면 아래에 첨부 목록이 쌓입니다. 이미지 파일은 작은 미리보기 썸네일로, PDF·텍스트 같은 다른 파일은 아이콘과 함께 파일명·크기로 보여 줍니다. 메일 첨부, 게시글 사진 올리기, 프로필 사진 변경처럼 어디서나 쓰이는 "파일 끌어다 놓기" UI의 기본 원리를 직접 만들어 봅니다.

## 목표

- 화면에서는 숨긴 `input[type=file]`을 클릭으로 대신 눌러 파일 선택창을 여는 패턴을 익힙니다.
- `dragover` / `drop` 이벤트에서 `preventDefault()`로 브라우저 기본 동작(파일을 그냥 열어버리기)을 막는 이유를 이해합니다.
- 끌어다 놓은 파일이 `e.dataTransfer.files`에 들어 있다는 것을 확인합니다.
- `FileReader`의 `readAsDataURL`로 이미지를 읽어 미리보기 썸네일을 만드는 법을 배웁니다.
- 고른 파일을 배열에 담고, 삭제하면 배열에서 빼고 화면을 다시 그리는 흐름을 경험합니다.

## 따라하는 단계

1. `103` 폴더 안에 `index.html`, `style.css`, `script.js` 세 파일이 같은 위치에 있는지 확인합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 점선 박스와 "아직 첨부된 파일이 없습니다." 안내문이 보입니다.
3. 컴퓨터에서 이미지 파일(jpg, png 등)을 하나 골라 점선 박스 위로 마우스로 끌어다 놓아 봅니다. 끌고 들어오는 순간 박스 테두리가 파랗게 변하는지 봅니다.
4. 놓으면 아래에 그 이미지의 작은 미리보기와 파일명, 크기(예: `1.2 MB`)가 카드로 나타나는지 확인합니다.
5. 이번에는 점선 박스를 클릭해 봅니다. 파일 선택창이 뜨면 여러 파일을 한 번에 골라(Ctrl/Shift로 다중 선택) 첨부해 봅니다.
6. PDF나 텍스트 파일도 첨부해 보고, 이미지가 아닌 파일은 미리보기 대신 아이콘(📕 📄 등)으로 표시되는지 봅니다.
7. 각 파일 오른쪽의 `✕` 버튼을 눌러 하나씩 지워 봅니다. 모두 지우면 다시 "아직 첨부된 파일이 없습니다." 안내문이 돌아오는지 확인합니다.
8. `script.js`를 열어 `dragover`/`drop`의 `preventDefault()`, `e.dataTransfer.files`, `FileReader`/`readAsDataURL` 부분의 주석을 천천히 읽어 봅니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 순서대로 시키면 됩니다.

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 프런트엔드 강사야. 비전공 수강생이 따라 만들 수 있게,

  요구사항:
  - 화면 가운데 카드 안에 점선 테두리(border: dashed)의 드롭 영역을 둔다.
  - 드롭 영역 안에는 안내 아이콘과 "여기로 파일을 끌어다 놓으세요 / 또는 클릭해서 선택" 문구를 넣는다.
  - 실제 input[type=file]은 multiple 속성을 주되 화면에서는 숨긴다(접근성을 위해 display:none 말고 sr-only 방식으로).
  - 드롭 영역을 클릭하면 숨긴 input을 코드로 눌러(input.click()) 파일 선택창이 뜨게 한다.
  - 첨부 파일이 쌓일 빈 목록(ul)과, 하나도 없을 때 보여줄 "아직 첨부된 파일이 없습니다." 안내문을 둔다.
  - 키보드로도 쓸 수 있게 드롭 영역에 tabindex와 role을 단다.

  각 코드가 무엇이고 왜 그렇게 했는지 한국어 주석으로 한 줄씩 설명해 줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  방금 만든 드래그앤드롭 영역에 실제 동작을 붙여 줘.

  - 드롭 영역에 dragover / dragleave / drop 이벤트를 단다.
    dragover와 drop에서는 preventDefault()를 호출해 브라우저가 파일을 새 탭에서 열어버리는 기본 동작을 막는다(이유를 주석에 적어 줘).
  - 드래그가 들어오면 영역 테두리를 파랗게 강조하는 클래스를 토글한다.
  - 끌어다 놓은 파일은 e.dataTransfer.files에, 선택창으로 고른 파일은 input.files에 들어 있다. 둘 다 같은 함수로 처리한다.
  - 고른 파일을 배열에 모으고, 배열을 기준으로 목록을 다시 그린다(render 함수).
  - 이미지 파일이면 FileReader.readAsDataURL로 읽어 작은 미리보기 썸네일을 보여주고,
    이미지가 아니면 PDF/텍스트/zip 등 종류에 맞는 이모지 아이콘을 보여준다.
  - 각 파일 옆에 파일명과 보기 좋은 크기(B/KB/MB)와 ✕ 삭제 버튼을 둔다.
  - 같은 파일을 다시 골라도 인식되도록 change 처리 후 input.value를 비운다.
  - 파일명은 textContent로 출력해 XSS를 막는다.

  왜 그렇게 했는지 주석으로 설명해 줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  드래그앤드롭이 동작하지 않아. 증상은 이래:
  "파일을 영역에 놓으면 미리보기가 뜨지 않고, 브라우저가 그 파일을 새 탭에서 그냥 열어버린다."

  내 script.js를 붙여넣을게. 비전공자도 알아듣게 단계별로 원인을 짚어 줘:

  2) 파일을 e.dataTransfer.files에서 제대로 꺼내고 있는지
  3) FileReader의 onload 안에서 src를 넣고 있는지(비동기라서)
  가장 의심되는 한 줄을 먼저 알려주고, 고친 코드와 그 이유를 함께 줘.

  (코드 붙여넣기)
  ```

## 검증법

- 처음 화면: 점선 박스와 "아직 첨부된 파일이 없습니다." 안내문이 보인다.
- 파일을 박스 위로 끌고 들어오면: 테두리가 파란색으로 강조되고, 박스 밖으로 나가거나 놓으면 원래대로 돌아온다.
- 이미지를 놓으면: 작은 미리보기 썸네일 + 파일명 + 크기가 표시된다.
- 박스를 클릭하면: 파일 선택창이 열리고, 여러 파일을 한 번에 첨부할 수 있다.
- 이미지가 아닌 파일(PDF/텍스트/zip): 미리보기 대신 종류에 맞는 아이콘이 표시된다.
- 같은 파일을 다시 첨부해도 정상적으로 추가된다(입력칸을 비워 주기 때문).
- `✕` 버튼을 누르면 그 파일만 목록에서 사라지고, 전부 지우면 안내문이 다시 나타난다.

## 더 알아두기

- `dragover`에서 `preventDefault()`를 빼먹으면, 파일을 놓는 순간 브라우저가 그 파일을 새 탭에서 그냥 열어버립니다. 드래그앤드롭에서 가장 흔한 실수이니 꼭 기억하세요.
- `FileReader`는 파일을 "비동기"로 읽습니다. 즉 `readAsDataURL`을 호출한 순간 바로 결과가 나오지 않고, 다 읽으면 `reader.onload`가 실행됩니다. 그래서 `src`를 `onload` 안에서 넣는 것입니다.
- 지금은 파일이 브라우저 안에만 있고 어디에도 올라가지 않습니다. 실제로 저장하려면 Supabase Storage 같은 곳에 업로드해야 합니다. 그때도 "파일을 고르고 미리보기를 보여주는" 이 화면 부분은 그대로 재사용할 수 있습니다.
- 큰 파일을 막고 싶다면 `addFiles`에서 `file.size`를 검사해 일정 크기(예: 5MB)를 넘으면 추가하지 않고 안내하면 됩니다. 크기 단위 변환은 이미 `formatSize`에 있습니다.
- 파일을 올릴 때 진짜 보안 검증(허용 확장자·용량 제한 등)은 반드시 서버(또는 Supabase의 정책)에서 한 번 더 해야 합니다. 브라우저의 `accept` 속성은 선택창을 편하게 해 줄 뿐, 공격을 막아 주지는 못합니다.
