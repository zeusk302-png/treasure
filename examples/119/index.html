방명록 — RLS(보안)를 켜고 정책으로 다시 열기

이 화면 자체는 실습 118과 똑같이 동작합니다(글 남기면 목록 즉시 갱신). 달라진 건 서버 쪽 보안입니다. 표에 RLS(행 수준 보안)를 켜면 정책이 없을 땐 글이 안 보이고(빈 목록), 글쓰기도 막힙니다. schema.sql로 읽기 정책 + 쓰기 정책을 추가해야 다시 정상 동작합니다.

실험해 보세요: schema.sql의 1단계(RLS 켜기)만 실행하면 아래 목록이 텅 비고 글쓰기가 에러가 납니다. 이어서 2~3단계(정책 추가)까지 실행하면 다시 멀쩡해집니다. "정책이 없으면 데이터가 안 보인다"를 직접 눈으로 확인하는 것이 이번 실습의 핵심입니다.
