# 실습 322 — Claude API로 글 요약 버튼 만들기

긴 글을 붙여넣고 **요약 버튼**을 누르면, 우리 서버가 **Claude API**(모델 `claude-opus-4-8`)를 대신 호출해 **3줄 요약**을 돌려주는 작은 앱을 만듭니다. 핵심은 결과물 자체보다 **구조**입니다. **API 키는 브라우저에 절대 두지 않고 서버에만** 둬서, `F12`로 소스를 봐도 키가 새지 않게 하는 "서버 경유(프록시)" 패턴을 몸에 익히는 것이 목표입니다.

> 한 줄 그림: **사용자가 긴 글 입력 → 우리 서버(`/api/summarize`)로 전송 → 서버가 비밀 키로 Claude API 호출 → 3줄 요약을 받아 브라우저로 회신 → 화면에 표시**

> 비유: Claude API 키는 **회사 법인카드**입니다. 직원(브라우저)에게 카드 실물을 쥐여 주면 잃어버리거나 도용당합니다. 그래서 카드는 **경리부(서버)** 금고에만 두고, 직원은 "이거 결제해 주세요"라고 **요청**만 합니다. 경리부가 카드로 긁고(=API 호출) 영수증(=요약)만 돌려주는 거죠.

> 보안 메모 — 공개해도 되는 값 vs 절대 숨겨야 하는 값
> - **절대 노출하면 안 되는 비밀값**: `ANTHROPIC_API_KEY`(Claude API 키). 이건 곧 **돈이 나가는 키**라서 브라우저 코드(`index.html`/JS)에 박으면 누구나 훔쳐 쓸 수 있습니다. 그래서 이 키는 **서버의 `.env` 파일**에만 두고, 서버 코드(`server.js`)만 읽습니다.
> - **공개되어도 되는 값**: 브라우저가 호출하는 **우리 서버 주소**(`/api/summarize`). 이건 그냥 "요약해 줘"라고 부르는 초인종일 뿐이라 보여도 괜찮습니다. 진짜 비밀 키는 그 초인종 너머 서버에만 있습니다.
> - 이 폴더의 `.env.example`에는 진짜 키가 아니라 **자리표시자**(`sk-ant-...여기에-실제-키`)만 들어 있습니다. 진짜 값은 직접 만든 `.env`에만 적고, `.env`는 `.gitignore`로 깃에서 빠집니다.

## 목표
- **서버 경유 호출 구조를 이해한다**: 브라우저 → 우리 서버 → Claude API → 우리 서버 → 브라우저. 왜 한 단계를 거치는지(=키 보호)를 안다.
- **API 키를 코드가 아니라 환경변수에 둔다**: 키는 `server.js`에 박지 않고 `.env`의 `ANTHROPIC_API_KEY`로 읽으며, `.env`는 깃에 올리지 않는다.
- **Claude API를 한 번 실제로 호출해 본다**: 긴 글을 넣어 모델 `claude-opus-4-8`이 3줄 요약을 만들어 주는 걸 직접 확인한다.
- **안전한 화면 출력을 익힌다**: 사용자가 넣은 글과 받은 요약을 `textContent`로 출력해 XSS(악성 스크립트 실행)를 막는다.

## 따라하는 단계

### A. 준비물 챙기기
1. **Node.js 설치 확인**: 터미널에서 `node -v`를 쳐서 버전(예: `v20.x`)이 나오면 됩니다. 없으면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치하세요.
2. **Claude API 키 발급**: [console.anthropic.com](https://console.anthropic.com) 가입 → 좌측 **API Keys** → **Create Key**로 키(`sk-ant-...`)를 하나 만들어 복사해 둡니다. (이 키는 비밀입니다. 화면 공유/스크린샷 주의!)

### B. 프로젝트 켜기
3. 이 폴더(`examples/322`)에서 터미널을 열고 의존성을 설치합니다.
   ```bash
   npm install
   ```
4. `.env.example`을 복사해 **`.env`** 파일을 만들고, 그 안의 자리표시자를 방금 발급한 **진짜 키**로 바꿉니다.
   ```bash
   cp .env.example .env
   # 그런 다음 .env 를 열어 ANTHROPIC_API_KEY=sk-ant-... 형태로 실제 키를 붙여넣기
   ```
   > `.env`는 `.gitignore`에 들어 있어 깃에 올라가지 않습니다. 키가 깃허브로 새는 사고를 막아 줍니다.

### C. 서버 실행하고 써 보기
5. 서버를 켭니다.
   ```bash
   npm start
   ```
   터미널에 `http://localhost:3000 에서 실행 중` 같은 메시지가 뜨면 성공입니다.
6. 브라우저에서 `http://localhost:3000` 을 엽니다. 텍스트칸에 **긴 글**(뉴스 기사, 강의 노트 등 한 문단 이상)을 붙여넣고 **요약하기** 버튼을 누릅니다.
7. 잠깐 기다리면 아래 **요약** 칸에 3줄짜리 요약이 나타납니다. 끝!

### D. 키가 안 새는지 직접 확인 (가장 중요)
8. 브라우저에서 `Ctrl`+`U`(소스 보기)를 눌러 `index.html`을 봅니다. **`sk-ant-`로 시작하는 키가 한 글자도 없어야** 정상입니다. (키는 서버에만 있으니까요.)
9. `F12` → **Network** 탭에서 요약 요청을 클릭해 보면, 브라우저는 우리 서버(`/api/summarize`)만 부르지 **api.anthropic.com을 직접 부르지 않습니다**. 키는 그 안쪽 서버에서만 쓰입니다.

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 Node.js 백엔드 멘토야. 비전공자도 따라 할 수 있게, "글 요약 버튼" 웹앱의 뼈대를 만들어 줘.

  [요구사항]
  - 서버: Express(Node.js). 정적 파일(public 폴더의 index.html)을 서빙하고, POST /api/summarize 엔드포인트를 둔다.
  - /api/summarize 는 { text } 를 받아 Anthropic Claude API(공식 SDK @anthropic-ai/sdk)를 호출해 그 글을 한국어 3줄로 요약하고 { summary } 를 JSON으로 돌려준다.
  - 모델은 정확히 "claude-opus-4-8" 을 쓴다. SDK는 client.messages.create(...) 를 쓴다.
  - 프론트(public/index.html): 텍스트 입력칸 + "요약하기" 버튼 + 결과 표시 영역. fetch 로 /api/summarize 를 호출한다.

  [보안 규칙 — 매우 중요]
  - Claude API 키는 절대 프론트(브라우저) 코드에 넣지 마. 서버에서 process.env.ANTHROPIC_API_KEY 로만 읽어.
  - 키 자리표시자만 담은 .env.example 과, .env 를 무시하는 .gitignore 도 같이 만들어 줘.
  - 사용자 입력과 결과는 화면에 textContent 로 출력해(innerHTML 금지) — XSS 방지.

  [설명 방식]
  - 코드만 주지 말고, 초보가 막힐 만한 줄에는 "무엇을(기능) + 왜(넣은 이유)" 한국어 주석을 달아 줘.
  - 마지막에 실행 순서(npm install → .env 작성 → npm start)를 단계로 정리해 줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 글 요약 앱을 이렇게 개선해 줘. 각 변경마다 왜 그렇게 했는지 한국어 주석으로 설명해 줘.

  1) 요약 길이 옵션: 프론트에 "3줄 / 5줄 / 한 문장" 드롭다운을 추가하고, 선택값을 서버로 보내 프롬프트에 반영해.
  2) 로딩 상태: 버튼을 누르면 "요약 중..."을 보여주고 버튼을 잠시 비활성화해서 중복 클릭을 막아.
  3) 입력 검증: 빈 글이나 너무 짧은 글(예: 20자 미만)은 서버 호출 없이 "더 긴 글을 넣어 주세요" 안내를 띄워. (불필요한 API 호출=불필요한 비용을 막기 위함.)
  4) 에러 처리: Claude API가 실패하면(키 오류, 한도 초과 등) 서버는 친절한 한국어 메시지를 JSON으로 돌려주고, 프론트는 그걸 빨간 글씨로 보여줘. 단, 진짜 키나 내부 오류 원문은 사용자에게 노출하지 마.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  글 요약 앱이 안 돼. 아래 정보를 보고 원인을 단계별로 짚어 주고, 비전공자가 알아듣게 한 줄씩 풀어서 설명해 줘.

  - 증상: (예) 버튼을 누르면 "요약 중..."에서 멈추거나, 화면에 "요약 실패"가 떠.
  - 서버 터미널에 찍힌 에러 메시지(있으면 그대로 붙여넣기):
    여기에-에러-붙여넣기
  - 브라우저 F12 → Console / Network 탭에 보이는 빨간 에러:
    여기에-붙여넣기

  특히 이것들을 점검해 줘:
  1) .env 파일이 있고 ANTHROPIC_API_KEY 값이 sk-ant- 로 시작하는지 (서버 재시작은 했는지)
  2) 401/403 이면 키가 틀렸거나 권한 문제, 429 면 한도 초과 — 각각 어떻게 확인/해결하는지
  3) 모델 이름이 정확히 claude-opus-4-8 인지 (오타가 나면 404)
  4) 프론트가 부르는 주소(/api/summarize)와 서버 라우트가 일치하는지
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **요약이 실제로 나오는지**: 긴 글을 넣고 버튼을 누르면 3줄 요약이 화면에 표시된다. (몇 초 걸릴 수 있음.)
- **키가 코드에 안 보이는지**: 브라우저에서 `Ctrl`+`U`(소스 보기)와 `F12`로 `index.html`/JS를 뒤져도 `sk-ant-`로 시작하는 키가 **한 글자도 없다**. (보이면 잘못된 것 — 키는 서버에만 있어야 한다.)
- **브라우저가 Anthropic을 직접 안 부르는지**: `F12` → **Network** 탭에서 요청 대상이 우리 서버(`localhost:3000/api/summarize`)뿐이고 `api.anthropic.com`은 **없어야** 정상이다.
- **`.env`가 깃에 안 올라가는지**: 이 폴더에서 `git status`를 보면 `.env`는 목록에 **없어야** 한다(=`.gitignore`가 막고 있음).
- **악성 입력이 실행되지 않는지**: 입력칸에 `<img src=x onerror=alert(1)>` 같은 걸 넣어도 **그냥 글자로** 보여야 하고, 경고창이 뜨면 안 된다. (`textContent` 출력이 잘 되고 있다는 뜻.)

## 파일 구성
- `server.js` — Express 서버. `POST /api/summarize`에서 `ANTHROPIC_API_KEY`(서버 전용)로 Claude API를 호출해 3줄 요약을 돌려준다. 키는 환경변수로만 읽는다.
- `public/index.html` — 요약 버튼 화면. `fetch`로 우리 서버만 호출하고, 입력·결과는 `textContent`로 안전하게 출력한다. (Claude 키는 들어 있지 않다.)
- `package.json` — 의존성(`express`, `@anthropic-ai/sdk`, `dotenv`)과 `npm start` 스크립트.
- `.env.example` — 필요한 비밀값 견본(자리표시자만). 복사해 `.env`를 만들고 진짜 키는 거기에만 넣는다.
- `.gitignore` — `.env`와 `node_modules`가 깃에 안 올라가게 막는다.
