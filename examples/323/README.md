# 실습 323 — Claude API 스트리밍 챗봇 UI 만들기

Claude API의 **스트리밍 응답**을 받아 글자가 **타이핑되듯 흘러나오는** 챗봇 화면을 만듭니다. 시스템 프롬프트(챗봇의 성격·규칙)를 바꿔 말투가 통째로 변하는 걸 체험하고, 지금까지의 대화를 매번 같이 보내는 **대화 맥락**의 원리를 익힙니다. 비밀값인 API 키는 화면이 아니라 **작은 서버**에만 두는 안전한 구조를 함께 만듭니다.

> 한 줄 그림: **사용자가 메시지 입력 → (브라우저) 서버로 전달 → (서버) 키를 쥐고 Claude 호출 → Claude가 글자 조각을 흘려보냄 → 서버가 그대로 브라우저로 중계 → 화면에 한 글자씩 타이핑**

> 비유: **서버는 비밀 금고(API 키)를 쥔 주방장**, **브라우저는 주문만 넣는 손님**입니다. 손님(브라우저)은 절대 금고(키)를 보지 못합니다. 또 Claude는 "기억이 없는 가게"라서, 손님이 올 때마다 **지난 대화 메모지(대화 맥락)를 통째로** 다시 건네줘야 이어서 대답합니다. 그리고 답은 다 적힌 뒤 한 번에 주는 게 아니라 **말하면서 받아쓰듯(스트리밍)** 흘려보내, 화면이 타이핑되는 느낌이 납니다.

> 보안 메모 — 공개해도 되는 값 vs 절대 숨겨야 하는 값
> - **절대 노출하면 안 되는 비밀값**: `ANTHROPIC_API_KEY`(Claude API 키). 이 키가 있으면 누구나 **내 요금**으로 Claude를 호출할 수 있습니다. 그래서 `index.html`·`script.js`(브라우저 코드)에 박으면 안 됩니다 — `F12`로 그대로 보여 도용당합니다.
> - **키는 오직 서버에만**: 키는 서버(`server.js`)가 `.env` 파일을 통해서만 읽습니다. 브라우저는 키를 **한 글자도** 받지 않습니다. 그래서 화면은 `/api/chat`(내 서버 주소)만 부르고, 진짜 Claude 호출은 서버가 대신 합니다.
> - 이 폴더의 `.env.example`에도 진짜 키가 아니라 **자리표시자**(`sk-ant-여기에_진짜_키를_넣으세요`)만 있습니다. 진짜 키는 복사해 만든 `.env`에만 적고, `.env`는 `.gitignore`로 깃에서 빠집니다.
> - (참고) Supabase의 `anon` 키처럼 "공개되어도 되는 키"도 세상엔 있지만, **Claude API 키는 공개 가능한 키가 아닙니다.** 반드시 서버 전용으로 다룹니다.

## 목표
- **스트리밍을 이해한다**: 답을 다 기다렸다 한 번에 받지 않고, 글자 조각이 도착하는 즉시 화면에 그려 "타이핑 효과"를 만든다.
- **시스템 프롬프트의 힘을 체험한다**: 같은 모델이라도 시스템 프롬프트만 바꾸면 챗봇의 말투·역할이 통째로 바뀌는 것을 눈으로 확인한다.
- **대화 맥락을 직접 관리한다**: Claude API는 기억이 없으므로, 지금까지의 user/assistant 메시지를 배열로 쌓아 매 요청마다 함께 보낸다.
- **비밀값을 코드 밖(서버 .env)에 둔다**: API 키를 브라우저가 아니라 서버에서만 읽게 하여, 화면을 아무리 들여다봐도 키가 보이지 않게 만든다.

## 따라하는 단계

### A. 준비물 설치
1. [Node.js](https://nodejs.org)를 설치합니다(LTS 버전). 터미널에서 `node -v`가 버전을 출력하면 OK입니다.
2. 이 폴더에서 터미널을 열고 `npm install`을 실행합니다. (`package.json`에 적힌 라이브러리 3개를 자동으로 깝니다: `@anthropic-ai/sdk`, `express`, `dotenv`.)

### B. 키 발급하고 .env 만들기 (가장 중요)
3. [Anthropic Console](https://console.anthropic.com)에서 가입 후 **API Keys** 메뉴에서 키를 하나 발급합니다(`sk-ant-...`로 시작).
4. 이 폴더의 `.env.example`을 복사해 같은 폴더에 **`.env`** 라는 파일을 만듭니다.
5. `.env` 안의 `ANTHROPIC_API_KEY=` 뒤 자리표시자를 **진짜 키**로 바꿉니다. → 진짜 키는 `.env`에만 있고, `.gitignore` 덕분에 깃에는 올라가지 않습니다.

### C. 서버 켜고 화면 열기
6. 터미널에서 `npm start`를 실행합니다. `서버 실행 중: http://localhost:3000`이 보이면 성공입니다.
7. 브라우저에서 `http://localhost:3000`을 엽니다. 챗봇 화면이 나옵니다.
8. 아래 입력창에 "안녕, 너는 누구야?" 같은 말을 보내 봅니다. 답이 **한 글자씩 흘러나오면** 스트리밍 성공입니다.

### D. 시스템 프롬프트·맥락 가지고 놀기
9. 위쪽 **시스템 프롬프트** 칸을 `너는 부산 사투리를 쓰는 까칠한 여행 가이드야.`로 바꾸고 다시 질문해 봅니다. 말투가 통째로 달라집니다.
10. "방금 내가 뭐라고 했지?"라고 물어, 챗봇이 **이전 대화를 기억**(맥락 유지)하는지 확인합니다. (브라우저가 대화 전체를 매번 같이 보내기 때문에 가능한 것입니다.)

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 Node.js와 프론트엔드를 잘 아는 페어 프로그래머야. 비전공 초보가 따라할 수 있는
  "Claude 스트리밍 챗봇"의 뼈대를 만들어줘.

  요구사항:
  - 구성: Express 서버(server.js) 1개 + 브라우저 화면(index.html, script.js, style.css).
  - 서버는 POST /api/chat 한 개를 가진다. 받은 system 프롬프트와 messages 배열을
    공식 SDK(@anthropic-ai/sdk)로 Claude에 보내고, 응답을 "스트리밍"으로 받아
    SSE(text/event-stream)로 브라우저에 그대로 흘려보낸다.
  - 모델은 claude-opus-4-8, max_tokens는 1024로 한다.
  - 보안: Claude API 키는 비밀값이다. 코드에 절대 박지 말고 .env의 ANTHROPIC_API_KEY로만
    읽어라. .env.example(자리표시자)와 .gitignore(.env, node_modules 제외)도 함께 만들어라.
  - 브라우저(script.js)는 fetch로 /api/chat을 호출하고, 돌아오는 글자 조각을 받아
    말풍선에 한 글자씩 채워 "타이핑 효과"를 낸다.
  - 화면에 사용자 입력을 출력할 때는 반드시 textContent를 써라(innerHTML 금지, XSS 방지).
  - 코드만 주지 말고, 초보가 막힐 만한 줄에는 "무엇을 하는지 + 왜 그렇게 했는지" 한국어 주석을
    달아줘. 파일 맨 위에는 이 파일이 무엇이고 왜 있는지 요약 주석을 한 블록 넣어줘.
  - 마지막에 실행 순서(npm install → .env 만들기 → npm start)를 알려줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 챗봇에 기능을 더해줘. 각 변경마다 "무엇을/왜" 한국어 주석을 붙이고,
  비밀값 노출 없이(키는 계속 서버 .env에만) 동작하게 유지해줘.

  1) 대화 맥락 유지: 브라우저가 지금까지의 user/assistant 메시지를 history 배열에 쌓아
     매 요청마다 messages로 함께 보내, Claude가 이전 대화를 기억하게 해줘.
  2) 시스템 프롬프트 입력칸: 화면 상단에서 챗봇의 성격/규칙을 바꿔 보낼 수 있게 하고,
     서버가 그 값을 system으로 Claude에 전달하게 해줘.
  3) UX: 응답을 받는 동안 입력창과 보내기 버튼을 잠그고(중복 전송 방지), 끝나면 다시 풀어줘.
     새 메시지가 오면 항상 맨 아래로 스크롤해줘.
  4) 에러 처리: 서버나 네트워크 오류, 키 미설정 시 사용자에게 보이는 안내 문구를 말풍선에 띄워줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  Claude 스트리밍 챗봇이 동작하지 않아. 아래 증상과 에러 로그를 붙여넣을 테니,
  원인을 단계별로 진단하고 가장 가능성 높은 것부터 고치는 법을 알려줘.
  비전공자가 이해하도록 한 줄씩 풀어서 설명해줘.

  [증상] (예: 답이 안 나옴 / 401 인증 오류 / 글자가 한 번에 다 나옴 / 화면이 안 뜸)
  [터미널 로그] (여기에 붙여넣기)
  [브라우저 콘솔(F12) 오류] (여기에 붙여넣기)

  특히 다음을 점검 항목으로 확인해줘:
  - .env 파일이 server.js와 같은 폴더에 있고 ANTHROPIC_API_KEY 값이 들어가 있는지(401이면 키 문제)
  - npm install을 했는지, npm start로 서버가 켜져 있는지, 포트가 3000인지
  - 모델 ID가 claude-opus-4-8 로 정확한지(오타면 404)
  - 스트리밍이 안 되면 서버가 SSE 헤더(text/event-stream)를 보내는지, 브라우저가 reader로 조각을 읽는지
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **타이핑 효과 확인**: 메시지를 보냈을 때 답이 **한 번에 뚝** 나오지 않고 **한 글자씩 흘러나오면** 스트리밍이 동작하는 것이다.
- **시스템 프롬프트 효과 확인**: 시스템 프롬프트를 바꾸기 전/후로 **같은 질문**을 던져, 말투·역할이 **확실히 달라지는지** 본다.
- **대화 맥락 확인**: "내 이름은 민수야"라고 알려준 뒤, 다음 메시지에서 "내 이름이 뭐였지?"라고 물어 **기억하는지** 확인한다.
- **키가 화면에 안 보이는지 확인 (가장 중요)**: 브라우저에서 `Ctrl`+`U`(소스 보기)로 `index.html`을, `F12`로 `script.js`를 열어 **`sk-ant-`로 시작하는 키가 한 글자도 없는지** 본다. (보이면 안 된다 — 키는 서버에만 있어야 한다.)
- **레포에 비밀값이 없는지 확인**: 이 폴더에서 아래를 실행하면 **자리표시자/이름만** 나와야 정상이다.
  - `grep -rn "sk-ant-" . --exclude-dir=node_modules` → 진짜 키가 아니라 `.env.example`의 **자리표시자**만 나와야 한다.
  - `git status`에 `.env`가 **추적되지 않는지**(Untracked로도 안 뜨고 무시되는지) 확인한다.

## 파일 구성
- `server.js` — 키를 쥐고 Claude를 대신 호출하는 작은 중계 서버. `/api/chat`에서 스트리밍 응답을 SSE로 브라우저에 흘려보낸다.
- `index.html` — 챗봇 화면 구조(시스템 프롬프트 칸 + 대화 영역 + 입력 줄). 키는 한 글자도 없다.
- `script.js` — 전송·스트리밍 수신·대화 맥락 관리. 출력은 `textContent`로만(XSS 방지).
- `style.css` — 말풍선·색·여백 등 화면 꾸미기(디자인 토큰 사용).
- `package.json` — 의존성 목록과 `npm start` 스크립트.
- `.env.example` — 필요한 비밀값 견본(자리표시자만). 복사해 `.env`를 만들고 진짜 키는 거기에만 넣는다.
- `.gitignore` — `.env`·`node_modules`가 깃에 안 올라가게 막는다.
