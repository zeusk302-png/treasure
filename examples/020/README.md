# style 속성으로 글자 색·크기 바꾸기

지금까지(001~019)는 글자를 "쓰기"만 했다면, 이번에는 글자를 **꾸미기** 시작합니다.
가장 쉬운 첫걸음은 태그 안에 `style="..."`를 직접 적는 **인라인(inline) 스타일**입니다.
별도의 CSS 파일도, `<style>` 태그도 필요 없이, 꾸미고 싶은 태그 바로 그 자리에 옷을 입히는 방식이에요.

> 한 줄 요약: `<p style="color: red; font-size: 24px;">글자</p>` → 이 문단 글자를 **빨간색**에 **24px 크기**로 만듭니다.

## 목표

- 태그에 `style` 속성을 붙여 **그 태그 하나만** 꾸밀 수 있다. (= 인라인 스타일)
- `color`로 **글자 색**을, `font-size`로 **글자 크기**를 바꿀 수 있다.
- `style="속성: 값;"` 문법을 이해한다. 콜론(`:`)으로 속성과 값을 잇고, 세미콜론(`;`)으로 여러 속성을 구분한다.
- 색은 영어 단어(`red`, `green`)로도, 코드값(`#2563eb`)으로도 쓸 수 있다는 걸 안다.

색·크기 속성을 한눈에 정리하면 이렇습니다.

| 속성 | 무엇을 바꾸나 | 값 예시 |
| --- | --- | --- |
| `color` | 글자 색 | `red`, `green`, `#2563eb`, `rgb(37,99,235)` |
| `font-size` | 글자 크기 | `16px`, `24px`, `40px`, `1.2em` |

> `px`는 픽셀(점)의 약자로, 화면에서의 크기 단위입니다. 숫자가 클수록 글자가 커집니다. 보통 본문은 16px 안팎입니다.

## 따라하는 단계

1. `examples/020/` 폴더의 `index.html`을 메모장이나 VS Code 같은 편집기로 엽니다.
2. 맨 위 `<h1>` 태그를 봅니다. `style="color: #2563eb; font-size: 40px;"`가 붙어 있어 제목이 **파란색**에 **40px**로 큼지막하게 나옵니다.
3. 문법을 뜯어봅니다 — `style="` 로 열고, `color: #2563eb;` (색 지정), `font-size: 40px;` (크기 지정), `"`로 닫습니다. 속성 사이는 세미콜론(`;`)으로 구분합니다.
4. 두 번째 문단(`color`만 있는 `<p>`)과 세 번째 문단(`font-size`만 있는 `<p>`)을 비교합니다. 색만 바꿀 수도, 크기만 바꿀 수도, 둘 다 바꿀 수도 있습니다.
5. 직접 바꿔 봅니다 — 색 실험: `<h1>`의 `color: #2563eb` 를 `color: red` 로 고친 뒤 저장하고, 브라우저에서 새로고침(F5)해 제목이 빨개지는지 봅니다.
6. 직접 바꿔 봅니다 — 크기 실험: 같은 `<h1>`의 `font-size: 40px` 를 `font-size: 60px` 로 키운 뒤 저장·새로고침해 제목이 더 커지는지 봅니다.
7. 직접 바꿔 봅니다 — 부분 강조: 6번 항목의 `<span style="color: #7c3aed; font-size: 28px;">이 부분만</span>` 처럼, 문장 전체가 아니라 `<span>`으로 감싼 **일부 글자만** 색·크기를 바꿔 봅니다.
8. 저장한 뒤 `index.html` 파일을 더블클릭해 브라우저(크롬 등)로 엽니다.

> 주의 1: `style` 값 안에서 속성과 값은 **콜론(`:`)** 으로 잇습니다. `color = red` 가 아니라 `color: red` 입니다.
> 주의 2: 속성을 여러 개 쓸 때는 **세미콜론(`;`)** 으로 구분합니다. `style="color: red; font-size: 24px;"` 처럼요. 세미콜론을 빠뜨리면 둘째 속성이 무시될 수 있습니다.
> 주의 3: `font-size` 값에는 **단위**가 꼭 필요합니다. `font-size: 24` (X) → `font-size: 24px` (O).
> 주의 4: 인라인 스타일은 "그 태그 하나"에만 적용됩니다. 같은 모양을 여러 태그에 반복하려면 매번 적어야 하므로, 나중에는 CSS 파일(B 단원)로 옮겨 한 번에 관리하는 법을 배웁니다. 지금은 "스타일이 글자를 어떻게 바꾸는가"를 눈으로 익히는 단계입니다.

## 검증법

1. 브라우저에서 `index.html`을 엽니다.
2. 맨 위 제목 **"안녕하세요, 인라인 스타일입니다"** 가 **파란색**이고, 다른 글자보다 눈에 띄게 **크면** `color`와 `font-size`가 함께 적용된 것입니다.
3. 회색 문단, 큰 글씨 문단, 빨간 문단이 각각 **다른 색·크기**로 보이는지 확인합니다. 모두 검정·같은 크기로 보인다면 `style` 속성 철자(`stlye` 등 오타)나 콜론·세미콜론을 점검하세요.
4. "이 부분만"이라는 글자가 같은 문단 안에서 **보라색에 더 큰 크기**로 튀어 보이는지 확인합니다. 이게 `<span>` 부분 강조입니다.
5. 단계 5~6을 했다면, 새로고침 후 제목 색·크기가 실제로 **바뀌었는지** 확인합니다. 안 바뀌면 파일을 **저장(Ctrl+S)** 했는지, 새로고침(F5)했는지 먼저 점검하세요.
6. (확인 팁) 브라우저에서 글자를 우클릭 → "검사"(개발자도구, F12)를 누르면, 그 태그에 `style="color: ...; font-size: ...;"` 가 그대로 붙어 있는 것을 볼 수 있습니다.
