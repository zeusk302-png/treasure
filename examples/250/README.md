# 실습 250 — 쇼핑몰 장바구니를 localStorage로 담고 빼고 합계 계산하기

쇼핑몰에서 가장 핵심이 되는 화면, **장바구니**를 자바스크립트로 직접 만들어 봅니다.
상품을 **담고(추가), 빼고(삭제), 수량을 늘리고 줄이며**, 그때마다 **총 개수와 합계 금액**이 자동으로 다시 계산됩니다.
게다가 **새로고침하거나 브라우저를 껐다 켜도** 담아둔 내용이 그대로 남습니다(= `localStorage`에 저장하기 때문).

> 비유: 장바구니는 **메모지 한 장(`cart` 배열)** 입니다.
> 상품을 담고 빼는 모든 행동은 이 메모지 한 장만 고칩니다.
> 메모지가 바뀌면 → 화면을 **처음부터 다시 그리고** → 그 내용을 **서랍(`localStorage`)에 통째로 넣어** 둡니다.
> 다음에 페이지를 열면 서랍에서 메모지를 꺼내 와 이어서 씁니다.

이 폴더에 있는 파일:

- `README.md` — 이 안내문
- `index.html` — 왼쪽 상품 목록 + 오른쪽 장바구니 화면 뼈대
- `style.css` — 보기 좋은 레이아웃 (좁은 화면에서는 위아래로 쌓임)
- `script.js` — **이번 실습의 핵심.** 담기/빼기/수량변경/합계계산/저장 로직 전부

## 목표

- 장바구니 데이터를 **`cart`라는 배열 하나(=상태)** 로 관리하고, 모든 동작(담기·빼기·수량변경)이 이 배열만 고치게 하는 **클라이언트 상태 관리** 패턴을 익힌다.
- `cart` 배열을 한 바퀴 돌며 **총 개수**와 **합계 금액(`가격 × 수량`의 합)** 을 구하는 **계산 로직**을 직접 작성한다.
- `JSON.stringify` / `JSON.parse`로 배열을 문자열로 바꿔 **`localStorage`에 저장·복원**해, 새로고침해도 장바구니가 유지되게 한다.

## 따라하는 단계

1. **파일을 연다.** 이 폴더의 `index.html`을 **더블클릭**해 브라우저로 엽니다. (서버·설치 없이 그냥 열리는 정적 페이지입니다.)
2. **담아 본다.** 왼쪽 상품 카드의 **[담기]** 버튼을 눌러 보세요. 오른쪽 장바구니에 항목이 생기고, 아래 **합계 금액**이 바로 바뀝니다.
3. **수량을 바꿔 본다.** 장바구니 항목의 **[+] / [−]** 버튼으로 수량을 늘리고 줄여 보세요. 항목 소계와 전체 합계가 즉시 다시 계산됩니다. 수량이 **0이 되면 항목이 자동으로 빠집니다.**
4. **빼 본다.** 항목 오른쪽 **[✕]** 버튼으로 그 상품만 빼거나, 아래 **[장바구니 비우기]** 로 전부 비웁니다.
5. **저장을 확인한다.** 상품 몇 개를 담은 뒤 브라우저를 **새로고침(F5)** 해 보세요. 장바구니가 **그대로 남아 있으면 성공**입니다.
6. **코드를 들여다본다.** `script.js` 맨 위 주석의 "큰 그림 4단계"를 읽고, `cart` 배열을 고치는 함수(`addToCart` · `changeQty` · `removeFromCart`)가 마지막에 모두 `update()`를 부르는 것을 확인하세요. `update()`는 **화면 다시 그리기 + localStorage 저장**을 한 번에 합쳐 둔 곳입니다.

> 내 것으로 바꿔 보기: `script.js` 맨 위 `PRODUCTS` 배열의 이름·가격·이모지를 **내 가게 메뉴**로 바꿔 보세요. 화면이 그대로 따라옵니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고 **1단계 → 2단계 → (막히면) 디버깅** 순서로 단계별로 부탁하는 것이 핵심입니다.

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 친절한 프론트엔드 멘토야. 비전공자도 이해할 수 있게 도와줘.
  HTML/CSS/순수 자바스크립트(프레임워크·라이브러리·빌드도구 없이)만으로
  "미니 쇼핑몰 장바구니" 정적 페이지를 만들어줘.

  요구사항:
  - 왼쪽에 상품 카드 목록(이름·가격·이모지·[담기] 버튼), 오른쪽에 장바구니.
  - 상품 데이터는 코드 안에 PRODUCTS 배열로 6개 정도 하드코딩(서버 없음).
  - 장바구니 "상태"는 cart 배열 하나로만 관리하고, 각 항목은 { id, qty } 모양으로 둬.
    가격·이름은 cart에 저장하지 말고 id로 PRODUCTS에서 찾아 써(한쪽만 바뀌어 어긋나는 걸 막기 위해).
  - [담기]를 누르면 cart에 추가하고, 합계(총 개수 / 총 금액)를 자동으로 다시 계산해 보여줘.
  - 파일은 index.html, style.css, script.js 세 개로 나눠줘.

  제약: 한 줄씩 무엇을 왜 하는지 한국어 주석으로 설명하고, 변수·함수 이름은 영어로 해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  좋아, 여기에 기능을 더 붙여줘.
  1) 장바구니 항목마다 [+] / [−] 수량 버튼과 [✕] 빼기 버튼을 추가해줘.
  2) 수량이 0이 되면 그 항목은 장바구니에서 자동으로 빠지게 해줘.
  3) [장바구니 비우기] 버튼으로 전체를 한 번에 비울 수 있게 해줘.
  4) 핵심: 새로고침하거나 브라우저를 껐다 켜도 장바구니가 유지되도록
     localStorage에 저장/복원해줘. (저장은 JSON.stringify, 불러오기는 JSON.parse)
  5) 상태(cart)를 바꾸는 모든 함수는 마지막에 "화면 다시 그리기 + 저장"을
     한 곳(update 함수)에서 처리하게 묶어줘. 왜 그렇게 묶는지 주석으로 설명해줘.
  6) 좁은 화면(모바일)에서는 좌우가 위아래로 쌓이도록 반응형으로 만들어줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  장바구니가 기대대로 동작하지 않아. 아래 증상과 코드(또는 콘솔 에러)를 붙여넣을게.
  무엇이 원인인지 비전공자도 알게 한 단계씩 짚어주고, 고친 코드와 "왜 그게 문제였는지"를 같이 알려줘.

  증상 예시(해당하는 것만 적기):
  - 같은 상품을 또 담으면 수량이 +1 안 되고 새 줄이 또 생긴다.
  - 합계 금액이 담아도 안 바뀐다.
  - 새로고침(F5)하면 장바구니가 사라진다.
  - 콘솔에 빨간 에러가 뜬다: (여기에 에러 메시지 그대로 붙여넣기)

  점검해줬으면 하는 것: cart를 고친 뒤 update()를 불렀는지, save()를 불렀는지,
  저장/불러오기에서 STORAGE_KEY가 똑같은지, 가격을 id로 PRODUCTS에서 찾는지.
  ```

> 프롬프트 팁: "코드만 주지 말고 **왜 그렇게 했는지 주석으로 설명해줘**", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과를 검증하고 학습하기 훨씬 좋습니다.

## 검증법

- **담기 동작:** [담기]를 누르면 오른쪽 장바구니에 항목이 생기고, 같은 상품을 또 담으면 **수량이 +1** 되는가? (새 줄이 또 생기면 안 됨)
- **합계 계산:** 아메리카노(3,000원) 2개 + 쿠키(2,000원) 1개를 담으면 **합계가 8,000원**, 상품 수가 **3개**로 뜨는가?
- **수량 0 처리:** 수량이 1인 항목에서 **[−]** 를 누르면 0이 아니라 **항목 자체가 사라지는가?**
- **저장 유지(핵심):** 상품을 담고 **F5(새로고침)** 했을 때 장바구니가 **그대로** 인가? 브라우저를 완전히 껐다 켜도 유지되는가?
- **개발자 도구로 직접 확인** (윈도우 `F12`):
  - **Console** 탭에서 `localStorage.getItem("mini-cart-250")` 를 쳐 보면, 담은 내용이 `[{"id":"p1","qty":2}, ...]` 같은 **문자열(JSON)** 로 저장돼 있는가?
  - **Application(또는 저장소) → Local Storage** 항목에서 `mini-cart-250` 키 값이 장바구니와 일치하는가?
- **비우기 확인:** [장바구니 비우기]를 누르면 목록이 비고, 합계가 **0개 / 0원**으로 돌아오며, 새로고침해도 빈 상태가 유지되는가?
- **자주 하는 실수:**
  - 합계가 안 바뀐다 → 상태를 고친 뒤 `update()`(= `renderCart()`)를 안 불렀을 때. 모든 변경 함수 끝에 `update()`가 있는지 확인.
  - 새로고침하면 사라진다 → `save()`를 안 불렀거나, `STORAGE_KEY`가 저장/불러오기에서 서로 다를 때.
  - 가격이 어긋난다 → 장바구니에 **가격을 직접 저장하지 말고**, `id`로 `PRODUCTS`에서 찾는 방식인지 확인. (가격을 두 군데 적으면 한쪽만 바뀌어 어긋납니다.)
