# 블로그 글 상세 페이지와 목록↔상세 링크 연결하기

여러 개의 HTML 페이지를 만들고, **목록에서 글을 클릭하면 상세 페이지로 이동**하도록 연결하는 실습입니다. 웹사이트가 "여러 화면"으로 이루어지고, 링크로 화면 사이를 오가는 **라우팅(routing)의 기초**를 배웁니다.

## 목표

- 목록 페이지(`index.html`)와 상세 페이지(`detail.html`)로 이루어진 **다중 페이지 구조**를 만든다.
- 글 제목을 누르면 상세 페이지로 이동하고, 다시 목록으로 돌아올 수 있게 한다.
- 주소(URL) 뒤에 붙는 `?id=숫자` 값으로 "어떤 글을 보여줄지"를 결정하는 원리를 이해한다.

> 라우팅이란? "어떤 주소로 가면 어떤 화면을 보여줄지"를 정하는 규칙입니다. 여기서는 가장 단순한 형태인 **링크 이동 + 주소에 담긴 글 번호**로 라우팅을 직접 경험합니다.

## 따라하는 단계

1. `242` 폴더를 만들고 그 안에 `index.html`, `detail.html`, `style.css`, `script.js` 네 파일을 둔다. (이 폴더에 이미 준비되어 있습니다.)
2. **목록 페이지(`index.html`)** 를 연다. 글 목록의 각 링크가 `detail.html?id=1`, `detail.html?id=2` 처럼 **같은 상세 페이지로 가되 번호만 다르게** 가리키는 것을 확인한다.
3. **상세 페이지(`detail.html`)** 를 연다. 제목·날짜·본문이 들어갈 빈 자리(`id="post-title"` 등)만 있고, 내용은 비어 있는 것을 확인한다.
4. **`script.js`** 를 연다. `URLSearchParams`로 주소에서 `id` 값을 읽고, 그 번호에 맞는 글 데이터를 빈 자리에 채워 넣는 흐름을 따라 읽는다.
5. `index.html`을 브라우저로 열고(파일을 더블클릭), 글 제목을 클릭한다. 주소창이 `detail.html?id=...`로 바뀌며 해당 글이 표시되는지 본다.
6. 상세 페이지에서 **"← 목록으로 돌아가기"** 를 눌러 다시 `index.html`로 돌아온다. 목록 ↔ 상세 왕복이 되면 성공이다.
7. (응용) `index.html`에 글 항목을 하나 더 추가하고, `script.js`의 `posts` 객체에도 같은 번호로 글을 추가해 본다.

## 🤖 바이브코딩 프롬프트

이 실습(목록↔상세 다중 페이지 + `?id=` 라우팅)을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS/순수 자바스크립트만 쓰는 웹 강사야. 비전공 초보가 이해할 수 있게 만들어줘.
  "내 블로그" 예제를 만들려고 해. 빌드 도구나 프레임워크 없이 파일 4개로만 구성해줘.
  - index.html : 글 목록 페이지. 글 3개를 보여주고, 각 제목은 detail.html?id=1, ?id=2, ?id=3 처럼
    같은 상세 페이지로 가되 번호만 다르게 링크를 건다.
  - detail.html : 글 상세 페이지. 제목/날짜/본문이 들어갈 빈 자리(id="post-title" 등)만 두고,
    "← 목록으로 돌아가기" 링크를 둔다.
  - style.css : 두 페이지가 함께 쓰는 공통 스타일(카드 형태 목록, 가운데 정렬 본문).
  - script.js : 지금은 빈 파일이어도 됨(다음 단계에서 채운다).
  코드만 주지 말고, 초보가 막힐 만한 부분(특히 ?id= 가 무슨 뜻인지)은 한국어 주석으로 풀어서 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  이제 script.js를 채워줘. detail.html 에서만 동작하는 라우팅 스크립트야.
  1) 주소(URL) 뒤의 ?id=숫자 값을 URLSearchParams 로 읽는다.
  2) posts 라는 객체에 글 3개를 { 번호: { title, date, body } } 형태로 임시로 담아 둔다.
     (실제 서비스라면 데이터베이스에서 가져온다는 점도 주석으로 알려줘.)
  3) id 에 맞는 글을 찾아 제목/날짜/본문 자리에 채운다.
     이때 화면에 글자를 넣을 때 innerHTML 말고 textContent 를 쓰고, 왜 그게 더 안전한지 주석으로 설명해줘.
  4) 존재하지 않는 id(예: ?id=99)면 "글을 찾을 수 없어요" 안내를 보여 준다.
  각 단계마다 왜 그렇게 했는지 한국어 주석으로 한 줄씩 풀어서 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  상세 페이지가 항상 "글을 찾을 수 없어요" 만 떠. 아래 상황과 코드를 보고 단계별로 원인을 진단해줘.
  - 주소는 detail.html?id=1 로 들어갔어.
  - script.js 에서 const post = posts[id]; 로 글을 찾고 있어.
  먼저 의심 가는 원인을 우선순위대로 나열하고(예: URLSearchParams 로 읽은 id 는 문자열 "1"인데
  posts 의 키와 타입/형태가 안 맞는 경우), 브라우저 개발자도구 콘솔에서 console.log 로
  무엇을 찍어 확인하면 되는지 순서대로 알려줘. 고친 코드는 바뀐 줄에 한국어 주석을 달아줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- `index.html`에서 글 제목 3개가 목록으로 보인다.
- 첫 번째 글을 클릭하면 주소가 `detail.html?id=1`로 바뀌고, 상세 페이지에 "HTML이 처음인 사람에게" 글이 보인다.
- 주소창의 `id=1`을 `id=2`, `id=3`으로 직접 바꿔도 그에 맞는 글로 내용이 바뀐다.
- 상세 페이지에서 "← 목록으로 돌아가기"를 누르면 `index.html`로 돌아온다.
- 존재하지 않는 번호(예: `detail.html?id=99`)로 들어가면 "글을 찾을 수 없어요" 안내가 뜬다.

> 팁: 가능하면 로컬 서버로 여세요. VS Code의 Live Server 확장을 쓰거나, 터미널에서 `npx serve` 후 안내된 주소로 접속하면 됩니다. 파일을 그냥 더블클릭해도 이 실습은 동작합니다.
