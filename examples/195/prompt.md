# 195. AI를 'SEO·접근성 감사관'으로 세우는 점검 프롬프트 템플릿

> 이 파일은 **AI(Claude 등)에게 그대로 붙여넣는 지시문**입니다.
> 핵심은 한 가지 — AI를 **상시 감사관**으로 세워, 내 사이트의 모든 페이지를
> **정해진 체크리스트(seo-check 기준)** 로 점검하고, **점수표 + 고칠 곳 + 수정안**을
> 표로 보고하게 만드는 것입니다.
>
> 디렉터(나)는 "무엇을·왜"(어떤 기준으로 볼지)를 정하고,
> AI는 "어떻게"(코드를 한 줄씩 대조)를 맡습니다.

```
[역할] 너는 내 웹사이트의 "SEO·접근성 감사관"이야. 점수를 후하게 주지 말고, 기준에 따라 냉정하게 채점해.

3. 페이지에 <h1> 이 정확히 1개 있는가? (0개·2개 이상이면 감점)
4. <html lang="ko"> 처럼 언어 속성이 지정돼 있는가?
5. <meta name="viewport"> 가 있어 모바일에서 깨지지 않는가?
6. 캐노니컬 링크(<link rel="canonical">)가 있는가? (1페이지면 권고)

B. 접근성 (모두가 쓸 수 있게)
7. 모든 <img> 에 의미 있는 alt 텍스트가 있는가? (장식용 이미지는 alt="" 허용)
8. 모든 폼 입력칸(<input>, <textarea>, <select>)에 연결된 <label> 이 있는가?
9. 링크 텍스트가 "여기 클릭" 같은 모호한 말 대신 목적지를 설명하는가?
10. 제목 위계(h1→h2→h3)가 단계를 건너뛰지 않는가? (h1 다음 바로 h3 금지)
11. 버튼/링크가 키보드 Tab 으로 접근 가능한 진짜 <button>/<a> 인가? (div 클릭 금지)
```

## 2단계 — 채점이 끝나면, 한 항목씩 수정 승인하기

AI가 채점표를 보여주면, 고치고 싶은 항목만 골라 승인합니다.
(전부 한꺼번에 맡기면 엉뚱한 곳까지 건드릴 수 있으니, 우선순위 '높음'부터 하나씩)

```
좋아, 수정 진행해. 단 "높음" 우선순위 항목(예: 6번 - alt 없는 이미지)만 먼저 고치고,
바뀐 부분만 before/after 로 보여줘. 다른 태그·구조는 절대 건드리지 마.
```

## 왜 이렇게 시키나요? (비전공자용 한 줄 정리)

- SEO·접근성은 "느낌"이 아니라 **체크리스트로 채점**해야 빠뜨리지 않습니다.
- AI에게 **채점 기준을 먼저 고정**해 주면, 매번 같은 잣대로 점검해 줍니다(= 상시 감사관).
- **채점 먼저, 수정은 승인 후** — 디렉터가 키를 쥐는 "선(先)보고 후(後)실행" 원칙입니다.
- 사람이 못 보는 빠진 alt, 빠진 label, 깨진 제목 위계를 AI가 한 줄씩 대조해 잡아냅니다.

> 한 단계 더: 점검을 사람이 매번 시키지 않고 **정해진 시간에 자동으로** 돌리고 싶다면,
> 같은 폴더의 `workflow.json`(n8n 정기점검)을 함께 보세요.
