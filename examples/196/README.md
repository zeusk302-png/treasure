# n8n 클라우드 첫 워크플로우 만들고 실행하기

n8n 클라우드에 가입한 뒤, 노드 2개짜리(수동 실행 → 값 채우기) 워크플로우를 만들고 **실행 버튼**으로 결과를 눈으로 확인합니다. 이 실습으로 자동화의 가장 기본 개념인 **노드(블록)**, **연결(선)**, **실행**을 익힙니다.

이 폴더의 `workflow.json` 은 n8n에 그대로 **Import** 할 수 있는 완성본입니다. 처음엔 직접 만들어 보고, 막히면 이 파일을 불러와 비교해 보세요.

## 목표

- n8n 클라우드 계정을 만들고 첫 워크플로우 화면을 연다.
- "수동 실행(Manual Trigger)" 노드와 "값 채우기(Edit Fields / Set)" 노드를 추가하고 선으로 잇는다.
- 실행 버튼을 눌러 두 번째 노드에 `name`, `greeting` 값이 들어 있는지 눈으로 확인한다.
- 자동화의 뼈대인 "트리거(언제 시작) → 액션(무엇을 할지)" 흐름을 체감한다.

## 따라하는 단계

1. 브라우저에서 n8n 클라우드(`https://n8n.io` → "Get started" / "Start free")에 접속해 이메일로 가입한다. 무료 체험으로 충분하다.
2. 로그인하면 작업 공간(workspace)이 열린다. 오른쪽 위 **"Create Workflow"**(또는 "+ Add workflow") 버튼을 눌러 빈 워크플로우 화면(캔버스)을 연다.
3. 캔버스 가운데의 **"Add first step"** 을 누르고, **"Trigger manually"**(수동 실행) 를 선택한다. → 캔버스에 첫 번째 노드가 생긴다.
4. 그 노드 오른쪽의 **＋(플러스)** 버튼을 눌러 검색창에 `Edit Fields` 를 입력하고 **"Edit Fields (Set)"** 노드를 추가한다. 두 노드는 자동으로 선(연결)으로 이어진다.
5. "Edit Fields" 노드를 더블클릭해 설정 창을 연다. **"Add Field"** 를 눌러 항목 두 개를 만든다.
   - 첫 번째: 이름 `name`, 타입 `String`, 값 `세영` (원하는 이름으로 바꿔도 된다)
   - 두 번째: 이름 `greeting`, 타입 `String`, 값 칸 오른쪽의 **표현식(Expression)** 모드를 켜고 `{{ $json.name }}님, n8n에 오신 걸 환영합니다!` 를 입력한다.
6. 설정 창을 닫고, 화면 아래(또는 위)의 **"Test workflow"**(실행) 버튼을 누른다.
7. 두 노드 위에 초록색 체크가 뜨면 성공이다. "Edit Fields" 노드를 눌러 **출력(Output)** 탭을 보면 `name: 세영`, `greeting: 세영님, n8n에 오신 걸 환영합니다!` 가 들어 있다.
8. (선택) 직접 만든 것과 정답을 비교하려면: 캔버스 우측 위 **"..." 메뉴 → Import from File** 에서 이 폴더의 `workflow.json` 을 불러온다.

## 검증법

- 실행 후 두 노드 모두에 **초록색 체크 표시**가 떠야 한다. 빨간색이면 노드 설정에 오류가 있는 것이다.
- "Edit Fields" 노드의 **Output 탭(또는 INPUT/OUTPUT의 오른쪽)** 에 아래처럼 한 줄(item 1개)이 보이면 통과:

  ```json
  {
    "name": "세영",
    "greeting": "세영님, n8n에 오신 걸 환영합니다!"
  }
  ```

- `greeting` 값이 `세영님, ...` 처럼 **앞에 이름이 실제로 채워져** 있어야 한다. `{{ $json.name }}님, ...` 글자가 그대로 보인다면 표현식(Expression) 모드를 켜지 않은 것이니, 그 칸 오른쪽의 "Expression" 토글을 다시 확인한다.
- `name` 값을 다른 이름으로 바꿔 다시 실행했을 때 `greeting` 의 이름 부분도 따라 바뀌면, 두 노드가 데이터로 잘 연결된 것이다.
