# 실습 001 — 내 첫 HTML 문서 만들기 (Hello, World)

웹페이지의 가장 기본 뼈대를 직접 만들어 봅니다. 코드는 단 한 파일(`index.html`)이고, 서버도 데이터베이스도 필요 없습니다. 메모장만 있어도 됩니다.

## 목표
- HTML 문서의 기본 골격인 `<html>` / `<head>` / `<body>` 세 칸의 역할을 구분한다.
- `<title>`이 화면 본문이 아니라 **브라우저 탭 이름**이라는 것을 눈으로 확인한다.
- 내가 만든 `.html` 파일을 더블클릭하면 내 컴퓨터에서 웹페이지가 열린다는 것을 체험한다.

세 칸을 집에 비유하면 이렇습니다.

| 태그 | 역할 | 비유 |
|---|---|---|
| `<html>` | 문서 전체를 감싸는 바깥 상자 | 집 전체 |
| `<head>` | 화면에 **안 보이는** 설정 (제목·인코딩 등) | 문패·설정함 |
| `<body>` | 화면에 **보이는** 실제 내용 | 거실(눈에 보이는 공간) |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다.
2. 화면 본문에 큰 글씨 "Hello, World!"와 그 아래 한 문장이 보이는지 확인합니다.
3. 브라우저 **탭 위쪽**에 "내 첫 HTML 문서"라고 적혀 있는지 봅니다. (이게 `<title>`입니다.)
4. `index.html`을 메모장(또는 VS Code)으로 열어 `<title>` 안 글자와 `<h1>` 안 글자를 내 이름으로 바꿔 저장합니다.
5. 브라우저로 돌아와 **새로고침(F5)** → 바뀐 내용이 반영되는지 확인합니다.
6. AI에게 시켜 보기:
   > "이 index.html의 body 안에, 제가 좋아하는 것 3가지를 점 목록(ul, li)으로 추가해줘. head는 그대로 두고 body만 바꿔줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 웹 입문자를 돕는 강사야. HTML을 처음 배우는 비전공자를 위해,
  파일 하나(index.html)로 동작하는 가장 기본적인 HTML 문서를 만들어줘.
  조건:
  - <!DOCTYPE html> 선언, <html lang="ko">, <head>, <body> 골격을 모두 포함할 것
  - <head> 안에 한글이 안 깨지도록 <meta charset="UTF-8">와 모바일용 viewport 설정을 넣을 것
  - <title>은 브라우저 탭에 "내 첫 HTML 문서"로 보이게 할 것
  - <body> 안에는 <h1>으로 큰 제목 "Hello, World!"와 <p> 한 문단을 넣을 것
  - 서버·데이터베이스 없이 더블클릭만으로 열리게 할 것
  각 줄이 무슨 역할인지 한국어 주석으로 한 줄씩 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html의 <head>는 그대로 두고 <body>만 수정해줘.
  - 내가 좋아하는 것 3가지를 점 목록(<ul>, <li>)으로 추가
  - <h1> 제목 아래에 자기소개 한 문단(<p>)을 더 넣기
  - 탭 제목(<title>)도 내 이름이 들어가게 바꿔줘
  바꾼 부분이 왜 그렇게 되는지 주석으로 설명하고, 기존 골격(html/head/body 구조)은 깨지 않게 해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 브라우저로 열었더니 한글이 ???나 깨진 글자로 보여.
  내 코드 전체를 아래에 붙여넣을게. 무엇이 문제인지 한 단계씩 짚어주고,
  비전공자도 알아듣게 원인과 고친 코드를 함께 알려줘.
  (여기에 index.html 내용 전체를 붙여넣기)
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- 화면 본문(`<body>`)에 "Hello, World!" 제목과 문단이 보이는가?
- 브라우저 **탭 제목**(`<title>`)과 화면 안 큰 제목(`<h1>`)이 **서로 다른 위치**에 나오는 것을 확인했는가?
- 브라우저에서 `F12 → Elements` 탭을 열어, `<html>` 안에 `<head>`와 `<body>`가 **나란히** 들어 있는 구조를 눈으로 확인한다.
- (선택) 한글이 깨져 보인다면 `<meta charset="UTF-8" />` 줄이 빠지지 않았는지 본다.
