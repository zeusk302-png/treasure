# AI 디렉팅 프롬프트 템플릿 — "디자인 시스템으로 일관된 컴포넌트 만들기"

당신은 코드를 직접 짜는 사람이 아니라, AI에게 **"이렇게 만들어 줘"라고 지시하는 디렉터**입니다.
디자인을 일관되게 만드는 비결은 간단합니다. 버튼·카드·폼을 각각 따로 꾸미는 게 아니라,
**색·간격·폰트 규칙(디자인 토큰)을 먼저 한 곳에 정해 두고** 모든 컴포넌트가 그 규칙만 쓰게 하는 것입니다.

아래 프롬프트를 Claude에 그대로 복사해 붙여 넣으면, 이 폴더의 `style.css`와 비슷한 결과를 받게 됩니다.

> 핵심: 색 코드(`#2563eb`)나 여백 숫자(`16px`)를 컴포넌트마다 직접 적지 말라고 못 박는 것이 디렉팅의 전부입니다.

---

## 프롬프트 1 — 디자인 토큰부터 정의시키기 (복사해서 사용)

```text
당신은 신입 비전공 개발자를 돕는 프론트엔드 디자인 시스템 전문가입니다.
순수 HTML/CSS만 사용하고(프레임워크·외부 라이브러리 금지), 한국어 주석을 답니다.

먼저 "디자인 토큰"을 CSS 변수로 :root 에 정의해 주세요. 다음을 포함합니다.
- 색: 메인 색 1개(+hover용 진한 색, +옅은 배경색), 본문 글자색, 보조 글자색,
  테두리 회색, 페이지 배경색, 카드 배경색, 에러색, 성공색
- 간격: 4px 배수로 5단계 (--space-1 ~ --space-5)
- 폰트: 글꼴 패밀리, 글자 크기 3단계(sm/base/lg), 굵기 2단계, 줄간격
- 모서리 둥글기 2단계, 그림자 2단계

규칙:
- 앞으로 만들 모든 컴포넌트는 색 코드나 여백 숫자를 직접 쓰지 말고
  반드시 위에서 정의한 var(--토큰) 만 사용할 것.
- 설명은 짧게, 코드 위주로.
```

---

## 프롬프트 2 — 그 토큰으로 컴포넌트 3종 생성시키기 (이어서 사용)

```text
좋아요. 방금 정의한 디자인 토큰만 사용해서, 아래 3가지 컴포넌트를 만들어 주세요.
색·여백·폰트·둥글기·그림자는 전부 var(--토큰) 으로만 지정하세요.

1) 버튼(.btn): 공통 모양 1개 + 색만 다른 변형 3개
   (.btn--primary 메인 / .btn--secondary 외곽선 / .btn--danger 빨강)
   hover와 클릭(active) 상태도 포함.
2) 카드(.card): 제목(.card__title) + 본문(.card__body) + 안에 버튼을 넣을 수 있게.
   배경·테두리·그림자·안쪽 여백은 토큰 사용.
3) 폼(.form): 라벨(.form__label) + 입력칸(.form__input) + 도움말(.form__help).
   입력칸을 클릭(focus)하면 메인 색으로 강조되게 하고, 그 강조색은 버튼과 같은 토큰을 쓸 것.

마지막으로 이 컴포넌트들을 한 번에 보여 주는 index.html 데모 페이지도 만들어 주세요.
클래스 이름은 BEM 스타일(블록__요소--변형)로 통일하세요.
```

---

## 프롬프트 3 — 일관성 점검 요청하기 (선택)

```text
방금 만든 CSS에서 디자인 토큰(var(--...))을 쓰지 않고
색 코드(#으로 시작)나 px 숫자를 직접 적은 곳이 있는지 전부 찾아서,
해당 줄을 알맞은 토큰으로 바꾼 수정본을 보여 주세요.
(그림자처럼 토큰이 없으면 새 토큰을 :root 에 추가하는 방식으로요.)
```

## 받은 코드가 잘 됐는지 보는 체크리스트 (디렉터의 눈)

- [ ] `:root` 에 색·간격·폰트 **토큰**이 한곳에 모여 있다.
- [ ] 버튼·카드·폼 코드에 `#색코드`나 `16px` 같은 값이 **직접** 박혀 있지 않고 `var(--토큰)`만 쓴다.
- [ ] 버튼의 강조색과 폼 입력칸 focus 강조색이 **같은 토큰**(`--color-primary` 계열)을 쓴다.
- [ ] 클래스 이름이 `.btn--primary`, `.card__title`처럼 일관된 규칙(BEM)을 따른다.
- [ ] `--color-primary` 한 줄만 바꿔도 버튼·폼·강조가 **한꺼번에** 바뀐다. (← 가장 중요한 시험)

> 참고: AI는 토큰을 정의하라고 해도 가끔 컴포넌트에서 색을 직접 박아 넣습니다.
> 그럴 때 "디렉터"인 내가 프롬프트 3으로 다시 고치게 시키는 것이 이 실습의 진짜 핵심입니다.
