# 실습 033 — flexbox로 버튼 3개 가로로 나란히 놓기

버튼이나 글 같은 요소는 아무 설정이 없으면 **위에서 아래로 한 줄씩 쌓입니다.** 그런데 우리가 보는 거의 모든 사이트의 메뉴·버튼·카드는 **가로로 나란히** 놓여 있죠. 그 마법의 정체가 바로 **flexbox(플렉스박스)**입니다. 방법은 의외로 간단합니다. 나란히 놓고 싶은 요소들을 하나의 **부모 상자**로 감싼 뒤, 그 부모 상자에 `display: flex;` 한 줄만 적으면 됩니다. 그러면 안에 든 자식들이 가로로 줄을 섭니다. 이번 실습에서는 빨강·초록·파랑 버튼 3개를 두 상자에 넣고, `display:flex`가 **있는 상자**와 **없는 상자**를 나란히 비교해 그 차이를 눈으로 확인합니다. 파일은 `index.html` 하나뿐이고 서버도 인터넷도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 요소를 가로로 정렬하려면 자식이 아니라 **자식을 감싸는 부모 상자**에 `display: flex;`를 줘야 한다는 핵심 규칙을 이해한다.
- `display:flex`가 **있는 상자(가로)**와 **없는 상자(세로)**를 직접 비교해, flex가 정확히 무슨 일을 하는지 눈으로 체감한다.
- `flex-direction`(정렬 방향: `row`=가로 / `column`=세로)이 무엇인지 알고, 값을 바꿔 가로↔세로를 직접 전환해 본다.

핵심은 딱 한 줄, "**부모에게** `display: flex;`"입니다.

```
부모 상자 .row {
  display: flex;          ← 이 한 줄이 안의 버튼들을 가로로 나란히 만든다
  flex-direction: row;    ← 정렬 방향: row(가로). 기본값이라 생략해도 가로가 됨
  gap: 12px;              ← 버튼 사이 간격
}
```

| 상자 | 설정 | 결과 |
|---|---|---|
| ① `.row` | `display: flex;` 있음 | 버튼 3개가 **가로로 나란히** |
| ② `.row-block` | `display: flex;` 없음 | 버튼 3개가 **세로로 쌓임** |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다. (인터넷 연결이 필요 없습니다.)
2. 위쪽 **①번 상자**를 봅니다. → 빨강·초록·파랑 버튼이 **가로로 나란히** 놓여 있습니다. 이 상자에는 `display: flex;`가 들어 있기 때문입니다.
3. 아래쪽 **②번 상자**를 봅니다. → 똑같은 버튼인데 **세로로 하나씩 쌓여** 있습니다. 이 상자에는 `display: flex;`가 **없기** 때문입니다. 두 상자의 유일한 차이가 바로 그 한 줄입니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어, `.row` 규칙 안의 `display: flex;` 줄 맨 앞에 슬래시별(`/* ... */`)을 붙여 주석으로 막아 봅니다. 즉 `display: flex;` → `/* display: flex; */` 로 바꾸고 저장한 뒤, 브라우저에서 **새로고침(F5)** 합니다. → ①번 상자도 버튼이 세로로 쌓이는 것을 확인합니다. 가로 정렬이 오직 그 한 줄 덕분이었음을 알 수 있습니다. 확인했으면 주석을 풀어 원래대로 되돌리세요.
5. 이번엔 `.row` 규칙의 `flex-direction: row;`를 `flex-direction: column;`으로 바꿔 저장하고 새로고침합니다. → `display: flex;`는 그대로 있어도, 방향이 세로(column)로 바뀌어 버튼이 위아래로 쌓입니다. 다시 `row`로 되돌려 보세요.
6. 버튼 사이 간격이 궁금하면 `.row`의 `gap: 12px;` 숫자를 `0px`이나 `40px`로 바꿔 새로고침해 보세요. → 버튼 사이가 딱 붙거나 멀리 떨어집니다.
7. AI에게 시켜 보기:
   > "이 index.html의 `.row` 상자에 버튼을 하나 더(예: 노랑) 추가하고, 버튼들이 화면 가운데로 모이도록 `justify-content`를 추가해줘. `display: flex;`는 그대로 두고."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 순서대로 시키면 됩니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 처음 배우는 비전공자를 돕는 강사야.
  index.html 파일 하나로 끝나는, 서버나 인터넷 없이 더블클릭만 하면 열리는 예제를 만들어줘.
  목표: flexbox(display:flex)가 무슨 일을 하는지 '눈으로 비교'해서 이해하기.
  - 빨강·초록·파랑 버튼 3개를 만들어.
  - 똑같은 버튼 3개를 '두 개의 부모 상자'에 각각 넣어.
  - ①번 상자에는 부모에 display: flex; 를 줘서 버튼이 가로로 나란히 놓이게 해.
  - ②번 상자에는 display: flex; 를 주지 마. 그래서 버튼이 세로로 쌓이게 해.
  - 두 상자 위에 각각 "① flex 있음 — 가로", "② flex 없음 — 세로" 같은 설명 제목을 붙여.
  - CSS는 <style> 태그 안에 함께 넣고, 한국어 주석으로 각 부분이 뭘 하는지 적어줘.
  중요: 코드만 주지 말고, 왜 그렇게 했는지 한 줄씩 주석으로 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html을 이어서 개선해줘. (기존 코드는 지우지 말고 더하기만 해)
  1) ①번 flex 상자에 '노랑' 버튼을 하나 더 추가해.
  2) ①번 상자의 부모에 justify-content: center; 를 줘서 버튼들이 가로 가운데로 모이게 해.
  3) flex-direction 값을 row(가로) ↔ column(세로)로 바꾸면 어떻게 달라지는지
     주석으로 설명을 달아줘.
  각 속성이 '무엇을 하고 왜 넣었는지'를 비전공자가 이해하게 한 줄씩 풀어서 주석으로 적어줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  버튼이 가로로 안 놓이고 세로로 쌓여. 내 index.html 코드를 아래에 붙여넣을게.
  [여기에 코드 전체 붙여넣기]
  무엇이 문제인지 단계별로 짚어줘:
  - display: flex; 가 '자식(버튼)'이 아니라 '부모 상자'에 들어가 있는지 확인해줘.
  - class 이름 오타(.row vs .raw 같은)나 세미콜론(;) 빠짐이 있는지 봐줘.
  - 고친 부분만 콕 집어서, 왜 그게 문제였는지 비전공자가 이해하게 설명해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **눈으로 확인**: ①번 상자의 버튼 3개가 **가로 한 줄**, ②번 상자의 버튼 3개가 **세로 줄**로 보이면 성공입니다. 두 상자가 똑같이 세로로 보인다면 ①번 상자의 `display: flex;`가 빠졌거나 오타가 난 것입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 ①번 상자(`<div class="row">`)를 클릭한 뒤, 오른쪽 `Styles`(스타일) 탭에서 `display: flex;`가 적용돼 있는지 봅니다. → 적용돼 있으면 flex가 켜진 증거입니다. 같은 자리에서 `display: flex;` 옆 체크박스를 껐다 켰다 하면 화면이 가로↔세로로 즉시 바뀌는 것도 확인할 수 있습니다.
- **방향 전환 검증**: 4·5번 단계처럼 `display: flex;`를 끄면 ①번이 세로가 되고, `flex-direction`을 `column`으로 바꾸면 다시 세로가 되며, `row`로 되돌리면 가로로 돌아오면, 두 속성의 역할을 제대로 다루고 있는 것입니다.
