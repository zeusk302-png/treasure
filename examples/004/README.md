# 004. 오늘 할 일 체크리스트(번호 없는 목록) 만들기

## 목표

`ul`과 `li` 태그로 오늘 할 일을 **점(•) 목록**으로 나열한 페이지를 만듭니다. 이 실습을 끝내면 "여러 항목을 줄줄이 나열할 때는 목록 태그를 쓴다"는 감각을 익히게 됩니다.

- `ul` = Unordered List(순서 없는 목록)의 줄임말. **여러 항목을 담는 바구니**라고 생각하세요.
- `li` = List Item(목록 항목)의 줄임말. 바구니 안에 들어가는 **낱개 항목 하나**입니다.
- `ul` 안에 `li`들을 넣으면, 브라우저가 각 항목 앞에 **자동으로 점(•)을 붙여줍니다.** 점을 직접 타이핑할 필요가 없습니다.

비유하자면, 장바구니(`ul`)에 사과·우유·빵(`li`)을 하나씩 담는 것과 똑같습니다. 순서가 바뀌어도 상관없는 목록(할 일, 장 볼 물건 등)에 씁니다. 1·2·3 번호가 꼭 필요한 순서(요리 순서 등)는 다음 실습 `005`에서 배우는 `ol`을 씁니다.

## 따라하는 단계

1. 이 폴더의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<body>` 안에 `<h1>오늘 할 일</h1>` 처럼 제목을 하나 적습니다.
3. 그 아래에 목록 바구니를 엽니다: `<ul>` 을 한 줄에 적습니다.
4. 바구니 안에 항목을 하나씩 넣습니다: `<li>아침 운동 30분 하기</li>` 처럼 `<li>`로 시작하고 `</li>`로 닫습니다.
5. 4번을 반복해서 할 일을 5개 정도 추가합니다.
6. 마지막에 바구니를 닫습니다: `</ul>` 을 적습니다. (`<ul>`과 `</ul>` 사이에 모든 `<li>`가 들어가야 합니다.)
7. 파일을 저장한 뒤, `index.html`을 더블클릭해서 브라우저(크롬 등)로 엽니다.

  ```text

  그리고 목록 위에 <p>로 "오늘 꼭 해야 할 일들"이라는 한 줄 설명을 넣어줘.
  ```

## 검증법

- 브라우저로 `index.html`을 열었을 때 할 일 항목들이 **각각 앞에 점(•)이 붙은 채로** 세로로 나열되면 성공입니다.
- 점은 내가 직접 입력한 것이 아니라 `<ul>`이 자동으로 붙여준 것입니다. (HTML 안에 `•` 글자를 적지 않았는지 확인해 보세요.)
- 브라우저 탭 제목에 "오늘 할 일 체크리스트"가 떠 있는지 확인합니다.
- (선택) 페이지 위에서 마우스 오른쪽 클릭 후 "검사"를 누르면, `<ul>` 안에 `<li>` 들이 들어가 있는 구조를 직접 볼 수 있습니다.

### 흔한 실수 체크

- `<li>`는 반드시 **`<ul>` 바구니 안**에 있어야 합니다. `<ul>` 밖에 `<li>`를 두면 목록이 제대로 표시되지 않습니다.
- 각 `<li>`는 **시작 태그와 끝 태그가 짝**이어야 합니다. 예: `<li>물 마시기</li>`. 끝 태그(`</li>`)를 빠뜨리지 않았는지 확인하세요.
- 점(•)을 보이게 하려고 직접 `•` 글자를 타이핑하지 마세요. `<ul>`을 쓰면 점은 자동으로 생깁니다.
- 바구니를 닫는 `</ul>`을 빠뜨리면 그 뒤의 다른 내용까지 목록 안으로 빨려 들어갈 수 있습니다.
