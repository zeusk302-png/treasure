# 254. 예약 시스템: 날짜·시간 선택 UI 만들기

미용실·병원·식당 예약 화면처럼, **달력에서 날짜를 고르고 → 가능한 시간대를 버튼으로 선택**하는 입력 화면을 만듭니다. 코드는 HTML 1개 + CSS 1개 + JavaScript 1개로 끝나는 **한 단계짜리 미니 결과물**입니다.

이번 실습은 **화면(UI)만** 만듭니다. 고른 예약을 실제로 데이터베이스에 저장하고 중복을 막는 것은 바로 다음 실습(255)에서 이어집니다.

## 목표

- `<input type="date">`로 **달력 날짜 선택칸**을 만들고, 오늘 이전 날짜는 못 고르게 막는다.
- 시간대 버튼들을 JavaScript로 **자동으로 그려 내고**, 한 번에 하나만 선택되게(토글) 만든다.
- "이미 찬 시간"은 버튼을 **비활성화**해 누를 수 없게 표시한다.
- 날짜와 시간을 **둘 다 골라야만** '예약하기' 버튼이 활성화되는 흐름을 익힌다.

## 따라하는 단계

1. 이 폴더(`254`)의 **`index.html` 파일을 더블클릭**해 브라우저로 엽니다. 별도 설치나 서버가 필요 없습니다.
2. **1. 날짜 선택** 칸을 눌러 달력에서 **오늘 또는 그 이후 날짜**를 하나 고릅니다. (어제 날짜는 회색으로 막혀 있어 선택되지 않습니다.)
3. 날짜를 고르면 아래 **2. 시간 선택** 영역에 10:00부터 18:00까지 시간 버튼들이 한 번에 나타납니다.
4. 시간 버튼 하나를 눌러 봅니다. 누른 버튼만 **파란색(선택됨)** 으로 바뀌고, 다른 시간을 누르면 선택이 그쪽으로 옮겨 갑니다.
5. `12:00`과 `15:00` 버튼은 **회색에 취소선**이 그어져 눌리지 않습니다. 이것이 "이미 예약이 찬 시간"입니다.
6. 날짜와 시간을 모두 고르면 중간에 **선택 요약 박스**가 뜨고, 아래 **예약하기** 버튼이 파란색으로 켜집니다.
7. **예약하기** 버튼을 눌러 화면 아래에 완료 메시지가 뜨는지 확인합니다.
8. (직접 바꿔 보기) `script.js` 맨 위의 `BOOKED_TIMES` 목록에 `"14:00"`을 추가해 저장한 뒤 새로고침하면, 14시 버튼도 막히는 것을 확인합니다.

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] 날짜 칸에서 **어제 날짜가 선택되지 않는다.** (과거 날짜 차단)
- [ ] 날짜를 고르기 전에는 "먼저 날짜를 선택하세요." 안내가 보이고, **예약하기 버튼이 회색(비활성)** 이다.
- [ ] 시간 버튼을 누르면 **그 버튼 하나만** 파란색이 된다. (두 개가 동시에 파래지면 안 됨)
- [ ] `12:00`·`15:00` 버튼은 **눌러도 선택되지 않는다.**
- [ ] 날짜+시간을 둘 다 고른 뒤에야 **예약하기 버튼이 파란색으로 켜진다.**
- [ ] 예약하기를 누르면 화면 아래에 **"예약 신청 완료: ..."** 메시지가 뜬다.

> 빠른 자가 점검: 개발자도구(F12) → Console 탭에 빨간 오류가 없으면 코드가 정상 동작 중입니다.
