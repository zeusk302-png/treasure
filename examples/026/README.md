# 실습 026 — 글자 색·배경색·글꼴 크기 바꿔보기

CSS를 처음 만나는 실습입니다. 거창한 도구나 서버는 필요 없어요. 파일은 단 하나(`index.html`)이고, `<style>` 칸에 **딱 3줄**만 적어서 한 문단의 모양을 바꿔봅니다. 이걸로 CSS의 기본 문법을 평생 기억하게 됩니다.

## 목표
- CSS의 기본 문법인 **선택자 → 속성 → 값** 3단 구조를 눈으로 익힌다.
- 글자를 꾸미는 가장 기본 속성 3가지를 구분한다.
  - `color` : 글자 자체의 색
  - `background-color` : 글자 뒤 바탕(배경) 색
  - `font-size` : 글자 크기
- `<style>` 안에 쓴 한 줄이 화면의 어떤 글자를 어떻게 바꾸는지 연결 지어 이해한다.

CSS 한 줄을 한국어로 읽으면 이렇습니다.

```
p { color: white; }
└┬┘  └─┬─┘  └─┬─┘
선택자  속성   값
```

> "p(모든 문단)의 / color(글자 색)을 / white(흰색)으로 바꿔라."

| 속성 | 무엇을 바꾸나 | 이 실습에서 쓴 값 | 비유 |
|---|---|---|---|
| `color` | 글자 색 | `white` (흰색) | 펜 잉크 색 |
| `background-color` | 글자 뒤 바탕 색 | `#2563eb` (파랑) | 형광펜으로 칠한 바탕 |
| `font-size` | 글자 크기 | `24px` | 글자를 몇 호로 쓸지 |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**해서 브라우저로 엽니다.
2. 꾸미지 않은 큰 제목("CSS 첫걸음") 아래에, **파란 배경 + 흰 글자 + 큰 글씨**로 바뀐 문단 2개가 보이는지 확인합니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어 `<style>` 칸을 찾습니다.
4. `color: white;` 를 `color: yellow;` 로 바꾸고 저장한 뒤, 브라우저에서 **새로고침(F5)** → 글자 색이 노란색으로 바뀌는지 봅니다.
5. `background-color: #2563eb;` 를 `background-color: black;` 으로, `font-size: 24px;` 를 `font-size: 40px;` 로 바꿔 저장하고 다시 새로고침 → 배경이 검정, 글자가 더 커지는지 확인합니다.
6. (한 걸음 더) 선택자 `p` 를 `h1` 로 바꿔 저장해 봅니다. 이번에는 **문단이 아니라 제목**이 꾸며지는 것을 보며 "선택자가 곧 '누구를 꾸밀지'를 정한다"는 것을 체감합니다.
7. AI에게 시켜 보기:
   > "이 index.html의 `<style>` 안에서 p 문단을 가운데 정렬(text-align: center)하고 글자를 굵게(font-weight: bold) 만들어줘. 다른 부분은 그대로 둬."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 웹 입문 강사야. CSS를 처음 배우는 비전공자를 위해, 파일 하나(index.html)로 끝나는 가장 단순한 예제를 만들어줘.
  요구사항:
  - <!DOCTYPE html>로 시작하는 완전한 HTML 문서 한 개.
  - <head> 안의 <style> 태그에 CSS를 직접 적어. (외부 CSS 파일 없이 한 파일로)
  - 꾸미지 않은 <h1> 제목 1개와, 꾸밀 <p> 문단 2개를 <body>에 넣어줘.
  - p 선택자에 color(글자색), background-color(배경색), font-size(글자크기) 딱 3개 속성만 적용해.
  - 한국어 본문, 영어 식별자. 서버나 빌드 도구는 쓰지 말고 더블클릭으로 바로 열리게 해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html의 <style> 안에서 p 문단을 더 보기 좋게 개선해줘. 기존 color/background-color/font-size 3줄은 그대로 두고 아래만 추가해.
  - 문단을 가운데 정렬(text-align: center), 글자를 굵게(font-weight: bold).
  - 글자 주변에 여백(padding)과 둥근 모서리(border-radius)도 줘.
  - 선택자가 무엇을 가리키는지, 각 속성이 화면의 무엇을 바꾸는지 한 줄씩 한국어 주석으로 설명해줘. HTML/CSS 구조는 바꾸지 말고 style 안만 손대줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 브라우저로 열었는데 글자 색/배경색이 전혀 안 바뀌어. 무엇이 문제인지 단계별로 짚어줘.
  - 아래에 내 <head>~</head> 전체와 꾸미려는 <p> 태그를 그대로 붙여넣을게.
  - 선택자(p) 철자, 세미콜론(;)·중괄호({ }) 누락, <style>이 <head> 안에 있는지, 저장 후 새로고침(F5)을 했는지 같은 흔한 원인부터 하나씩 확인해줘.
  - 고친 코드와 함께, 왜 그게 원인이었는지 비전공자가 이해하게 풀어서 설명해줘.

  [여기에 코드 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- 제목("CSS 첫걸음")은 **꾸며지지 않은 검은 기본 글자**, 그 아래 문단들은 **파란 배경 + 흰 글자 + 큰 글씨**로 서로 확실히 달라 보이는가?
- 색 이름(`white`)을 바꿔 저장하고 새로고침했을 때 화면 글자 색이 실제로 바뀌는가? → CSS와 화면이 연결돼 있다는 증거입니다.
- 선택자를 `p`에서 `h1`으로 바꿨을 때, 꾸며지는 대상이 **문단에서 제목으로** 옮겨가는가?
- 브라우저에서 `F12 → Elements`(또는 검사)에서 문단을 클릭하면, 오른쪽에 `color / background-color / font-size` 값이 그대로 적용돼 있는 것을 확인할 수 있다.
