# 메뉴 안에 메뉴(중첩 목록)로 사이트 메뉴 만들기

목록(`<ul>`) 항목 안에 또 다른 목록(`<ul>`)을 통째로 넣어서, 큰 분류(대분류) 아래에 작은 분류(소분류)가 들여써지는 **메뉴 트리**를 만들어 봅니다. 쇼핑몰 카테고리, 사이트 내비게이션 메뉴, 책 목차처럼 "큰 항목 안에 작은 항목"이 있는 구조에 딱 맞는 방식입니다. 이렇게 목록 안에 목록을 넣는 것을 **중첩 목록(nested list)** 이라고 부릅니다.

## 목표

- `<ul>` 안의 `<li>` 안에 또 `<ul>` 을 넣어 대분류 → 소분류 구조를 만든다.
- 안쪽 `<ul>` 은 반드시 **바깥 `<li>` 의 닫는 태그(`</li>`) 앞**에 들어가야 함을 안다. (가장 중요한 규칙)
- 들여쓰기(스페이스)는 "사람이 보기 좋으라고" 넣는 것일 뿐, 메뉴의 깊이는 **태그가 어디 안에 들어갔는지**로 결정됨을 안다.
- 소분류 안에 또 `<ul>` 을 넣어 3단계 이상으로 깊게 만들 수도 있음을 안다.

> 비전공자 눈높이 한 줄 요약: 큰 서랍(`<li>의류`) 을 닫기 전에, 그 서랍 안에 작은 칸막이 상자(`<ul>...</ul>`) 를 통째로 넣고 나서 서랍을 닫는다(`</li>`)고 생각하면 됩니다. 그러면 브라우저가 작은 항목들을 한 칸 안쪽으로 들여써서 "메뉴 안의 메뉴"처럼 보여줍니다.

## 따라하는 단계

1. `examples/012/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. 가장 바깥쪽 `<ul> ... </ul>` 을 찾습니다. 이게 사이트 메뉴 전체를 감싸는 바구니입니다.
3. 첫 번째 항목 `<li>의류` 를 봅니다. 이 `<li>` 가 **아직 닫히지 않은 상태**에서 바로 아래에 소분류 목록 `<ul>`(티셔츠/셔츠/바지)이 들어가 있는 것을 확인합니다.
4. 그 소분류 `</ul>` 다음에야 비로소 `</li>` 로 "의류" 항목이 닫히는 것을 확인합니다. 이 **순서(소메뉴를 넣고 → li 를 닫는다)** 가 중첩 목록의 핵심입니다.
5. "신발" 항목 안의 "슬리퍼"를 봅니다. 소분류(`<li>슬리퍼`) 안에 또 `<ul>` 이 들어가 **3단계(대 → 소 → 소소)** 로 더 깊어진 예입니다.
6. 직접 만들어 봅니다. 맨 아래 "도서" 메뉴는 소분류가 비어 있습니다. `<li>도서</li>` 의 닫는 태그 앞에 아래처럼 소분류를 넣어 보세요.
   ```html
   <li>도서
     <ul>
       <li>소설</li>
       <li>만화</li>
       <li>잡지</li>
     </ul>
   </li>
   ```
7. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의 1: 안쪽 `<ul>` 은 `<li>...</li>` **밖**(li 와 li 사이)에 두면 안 됩니다. 반드시 항목 `<li>` 가 닫히기 **전(안)** 에 넣으세요. 밖에 두면 소메뉴가 엉뚱한 위치에 붙거나 들여쓰기가 어긋납니다.
> 주의 2: `<ul>` 안에는 `<li>` 만 직접 들어갈 수 있습니다. 글자나 다른 태그는 `<li>` 로 한 번 감싸서 넣으세요.
> 주의 3: 여는 태그와 닫는 태그는 항상 짝입니다. 깊어질수록 `</ul>`, `</li>` 닫는 태그를 빠뜨리기 쉬우니, 들여쓰기를 맞춰 두면 짝을 찾기 쉽습니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. "의류 / 신발 / 가방 / 고객센터"가 **대분류로 왼쪽 끝**에 나오고, 그 아래 소분류(티셔츠·셔츠·바지 등)가 **한 칸 안쪽으로 들여써져** 보이는지 확인합니다. → 이게 중첩 목록의 기본 모양입니다.
3. "신발 > 슬리퍼" 아래의 "실내용 슬리퍼 / 여름용 샌들"이 **한 칸 더 깊이 들여써져** 있는지 확인합니다. → 3단계 중첩이 제대로 된 것입니다.
4. 소분류가 없는 "고객센터"는 들여쓰기 없이 대분류 줄에 그대로 보이는지 확인합니다.
5. 단계 6에서 직접 추가한 "도서 > 소설/만화/잡지"가 다른 대분류처럼 소분류로 들여써져 새로 나타나는지 새로고침(F5) 후 확인합니다.
6. (확인 팁) 만약 소분류가 들여써지지 않고 대분류와 같은 줄 높이로 붙어 보인다면, 안쪽 `<ul>` 을 `<li>` **안**이 아니라 **밖**에 넣었거나 `</li>` / `</ul>` 닫는 태그가 빠졌을 가능성이 높습니다. 태그가 들어간 위치와 짝을 다시 확인하세요.
