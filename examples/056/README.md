# 버튼 누르면 알림창 띄우기 (첫 이벤트)

웹페이지에서 일어나는 가장 기본적인 "사건(이벤트)"을 처음 체험하는 실습입니다.
버튼을 1개 만들고, 그 버튼을 클릭하면 알림창(alert)이 뜨게 만들어 봅니다.

## 목표

- "이벤트"가 무엇인지 몸으로 느끼기: **사용자가 버튼을 누르는 순간**이 바로 하나의 이벤트입니다.
- 자바스크립트가 화면의 버튼을 어떻게 찾는지 알기 (`getElementById`).
- "이 버튼을 누르면(click) 이걸 해줘"라고 연결하는 방법 익히기 (`addEventListener`).

## 따라하는 단계

1. 이 폴더의 `index.html` 파일을 더블클릭해서 웹 브라우저(크롬 등)로 엽니다.
2. 화면 가운데에 있는 **"눌러보세요"** 버튼을 클릭합니다.
3. 화면 위쪽에 "안녕하세요! 첫 이벤트가 동작했어요 🎉" 라는 알림창이 뜨면 성공입니다.
4. 코드를 직접 살펴봅니다.
   - `index.html`: 버튼 태그 `<button id="helloBtn">눌러보세요</button>` 가 있고, 맨 아래에서 `script.js`를 불러옵니다.
   - `script.js`: 버튼을 찾고(`getElementById`), 클릭 이벤트를 연결합니다(`addEventListener`).
5. (실험) `script.js`의 `alert(...)` 안에 들어간 문장을 내 이름으로 바꾼 뒤, 브라우저를 **새로고침(F5)** 하고 다시 눌러봅니다. 바뀐 메시지가 뜨면 코드와 화면이 연결되어 있다는 걸 확인한 것입니다.

## 검증법

- 버튼을 클릭했을 때 알림창이 **뜨면 정상**입니다.
- 알림창이 안 뜬다면 아래를 확인하세요.
  - `index.html`의 버튼 id(`helloBtn`)와 `script.js`에서 찾는 id가 **똑같이** 적혀 있는지 (대소문자까지 동일해야 합니다).
  - `<script src="script.js"></script>` 줄이 `</body>` 바로 위, 즉 **버튼보다 아래쪽**에 있는지. (자바스크립트가 버튼보다 먼저 실행되면 버튼을 못 찾습니다.)
  - 브라우저에서 `F12`를 눌러 개발자 도구 > Console 탭에 빨간 에러 메시지가 없는지.

## 핵심 정리

- **이벤트(event)**: 클릭, 마우스 올리기, 키보드 입력처럼 화면에서 일어나는 "사건".
- **addEventListener("click", 함수)**: "이 요소에서 click이 일어나면 이 함수를 실행해줘"라고 등록하는 명령.
- 화면(HTML)을 먼저 만든 뒤 자바스크립트를 불러와야, 자바스크립트가 그 요소를 찾을 수 있습니다.
