# 이번 주 시간표(표) 만들기

`<table>` · `<tr>` · `<th>` · `<td>` 네 가지 태그만으로 **요일과 교시가 들어간 시간표**를 만들어 봅니다. 표는 우리가 엑셀이나 학교 시간표에서 늘 보던 "격자(가로줄 × 세로칸)" 그 자체예요. 핵심은 **표가 "가로 한 줄(행)을 차곡차곡 쌓는" 방식으로 만들어진다**는 감각과, **제목 칸(`<th>`)과 내용 칸(`<td>`)을 구분하는 눈**을 기르는 것입니다.

> 비전공자 눈높이 한 줄 요약: `<table>` 은 "표 전체(바깥 테두리)", `<tr>` 은 "가로 한 줄", `<th>` 는 "제목 칸(굵게)", `<td>` 는 "내용 칸" 입니다. 표는 위에서 아래로 **가로줄(`<tr>`)을 한 줄씩 쌓아** 만듭니다.

## 목표

- `<table>` 로 표 전체를 감싼다.
- `<tr>`(table row) 로 **가로 한 줄**을 만든다. 표는 이 가로줄을 위에서부터 쌓아 완성된다.
- `<th>`(table header) 로 **제목 역할을 하는 칸**(요일 머리글, 'N교시' 라벨)을 만든다. → 자동으로 굵게·가운데 정렬된다.
- `<td>`(table data) 로 **실제 내용 칸**(과목명)을 만든다.
- "제목 칸은 위쪽이든 왼쪽이든 모두 `<th>`, 실제 데이터는 `<td>`" 라는 구분 기준을 이해한다.
- 한 줄(`<tr>`) 안의 **칸 개수를 모든 줄에서 똑같이 맞춰야** 표가 반듯해진다는 것을 안다.

## 따라하는 단계

1. `examples/017/` 폴더의 `index.html` 을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<table> ... </table>` 을 찾습니다. 이 안쪽 전체가 "표 한 개" 입니다.
3. 첫 번째 `<tr>` 을 봅니다. 안에 `<th>교시</th> <th>월</th> ... <th>금</th>` 처럼 **제목 칸(`<th>`) 6개**가 들어 있습니다. 이게 맨 윗줄(요일 머리글)입니다.
4. 두 번째 `<tr>`(1교시 줄)을 봅니다. 맨 앞 `<th>1교시</th>` 는 그 줄의 **제목**이라 `<th>`, 그 뒤 과목들(`<td>국어</td>` 등)은 **내용**이라 `<td>` 인 점을 확인합니다.
5. 줄마다 칸이 **모두 6개**(교시 라벨 1 + 요일 5)인지 세어 봅니다. 표가 반듯하려면 모든 `<tr>` 의 칸 수가 같아야 합니다.
6. 과목을 바꿔 봅니다. 예를 들어 1교시 화요일 칸의 `<td>수학</td>` 을 `<td>영어</td>` 로 고쳐 저장합니다.
7. 새 교시(가로줄)를 하나 추가해 봅니다. 마지막 `</table>` **바로 위**에 아래 한 줄(`<tr>`)을 통째로 붙여 넣습니다. (칸 6개를 반드시 맞추세요)
   ```html
   <tr>
     <th>5교시</th>
     <td>독서</td>
     <td>코딩</td>
     <td>역사</td>
     <td>실험</td>
     <td>토론</td>
   </tr>
   ```
8. 저장한 뒤 `index.html` 파일을 더블클릭해 브라우저(크롬 등)로 엽니다.

> 주의 1: 표는 **`<tr>`(가로줄) 단위로 쌓습니다.** 세로 열을 따로 만드는 태그는 없어요. "월요일 세로줄"은 각 `<tr>` 의 2번째 칸들이 위아래로 모여 자연스럽게 보이는 것입니다.
> 주의 2: 모든 `<tr>` 의 칸(`<th>`+`<td>`) 개수를 **똑같이** 맞추세요. 한 줄만 칸이 모자라거나 넘치면 표가 어긋나 보입니다.
> 주의 3: `<th>` 와 `<td>` 를 혼동하지 마세요. **제목/라벨이면 `<th>`, 그냥 데이터면 `<td>`.** `<th>` 는 시키지 않아도 굵게·가운데로 표시됩니다.
> 주의 4: `<style>` 안의 테두리·색은 칸을 눈에 보이게 하는 보조 장치일 뿐입니다. 이 실습의 본질은 `table → tr → (th/td)` 구조입니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 표 위에 "○○님의 한 주 학습 시간표" 라는 **표 제목(`<caption>`)** 이 보이는지 확인합니다.
3. 맨 윗줄에 **요일 머리글**(교시 · 월 · 화 · 수 · 목 · 금)이 진한 색 배경 + 흰 글씨로 보이면 성공입니다. (이게 `<th>` 의 효과)
4. 맨 왼쪽 세로줄의 '1교시' · '2교시' ... 라벨도 진한 색(즉 `<th>`)으로 보이고, 가운데 과목 칸들은 흰 배경(`<td>`)인지 확인합니다.
5. 모든 줄의 칸이 **세로로 가지런히 정렬**되어 격자가 반듯한지 봅니다. 한 칸이라도 삐뚤면 그 줄의 칸 개수를 다시 세어 보세요.
6. 단계 6에서 바꾼 과목명이 화면에 그대로 반영됐는지 확인합니다.
7. 단계 7에서 추가한 **'5교시' 줄**이 표 맨 아래에 한 줄 더 생겼는지 확인합니다. (안 보이면 새로고침 F5)
8. (확인 팁) 추가한 5교시 줄이 오른쪽으로 삐져나오거나 빈칸이 생긴다면, 그 `<tr>` 안의 칸 개수가 6개가 맞는지 다시 세어 보세요. 다른 줄과 칸 수가 같아야 합니다.
9. (확인 팁) 개발자도구(F12)의 Elements 탭에서 `table > tr > th/td` 중첩 구조가 그대로 보이는지 확인해도 좋습니다.
