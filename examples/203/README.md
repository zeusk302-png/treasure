# Slack 채널로 자동 메시지 보내기

앞 실습(202)에서는 자동화가 만든 내용을 **이메일**로 받아 봤습니다. 이번에는 같은 일을 **Slack(슬랙)** 으로 해 봅니다. 슬랙은 회사·동아리·팀이 함께 쓰는 단체 채팅방인데, 여기에 사람이 직접 타이핑하지 않고 **n8n이 대신 메시지를 올리게** 만드는 것입니다.

예를 들어 "오늘 밤 서버 점검 있습니다" 같은 공지를, 정해진 채널(예: `#공지`)에 자동으로 띄울 수 있습니다. 이메일 말고도 **알림을 보낼 통로(채널)는 여러 개**라는 걸 체감하는 게 이번 실습의 핵심입니다.

> **이 워크플로우는 노드 3개입니다.**
> `시작 (Manual Trigger)` → `보낼 메시지 만들기 (Set)` → `Slack 메시지 보내기 (Slack)`
>
> 비유하자면: ① 버튼을 누른다(시작) → ② 무슨 말을 할지 종이에 적는다(메시지 작성) → ③ 그 종이를 단체 채팅방 게시판에 붙인다(Slack 발송). 데이터는 물처럼 왼쪽 노드에서 오른쪽 노드로 흘러갑니다.

> **이번엔 일부러 '버튼을 눌러 실행하는' 트리거(Manual Trigger)를 썼습니다.** 슬랙 연결이 잘 됐는지 먼저 손으로 눌러 확인하는 게 안전하기 때문입니다. "매일 자동으로" 보내고 싶다면, 이 시작 노드만 앞 실습(201/202)에서 배운 **Schedule Trigger**로 바꿔 끼우면 됩니다. 부품을 갈아 끼우는 것이지, 전체를 새로 만드는 게 아닙니다.

## 목표

- n8n의 **Slack 노드**에 내 슬랙 계정(봇) 자격증명을 연결해, 지정한 **채널에 메시지를 자동으로 올리는** 흐름을 만든다.
- 이메일 외에도 **Slack 같은 다른 알림 채널**을 똑같은 방식(노드 + 자격증명)으로 붙일 수 있다는 것을 이해한다.
- 슬랙 접속에 쓰이는 **토큰(비밀값)은 노드가 아니라 `Credentials`(자격증명) 금고**에 넣어야 한다는 보안 원칙을 익힌다.

## 따라하는 단계

1. **슬랙 쪽 준비물(봇) 먼저 만들기.** n8n이 내 슬랙에 글을 쓰려면, 슬랙이 발급하는 '출입 토큰'이 필요합니다.
   - 브라우저에서 슬랙 앱 관리 페이지(`api.slack.com/apps`)에 들어가 **`Create New App` → `From scratch`** 로 앱(봇)을 하나 만듭니다. 내 워크스페이스를 고릅니다.
   - 왼쪽 메뉴 **`OAuth & Permissions`** 로 가서, `Bot Token Scopes`에 **`chat:write`**(메시지 쓰기) 권한을 추가합니다.
   - 같은 화면 위쪽의 **`Install to Workspace`** 를 눌러 설치하면, **`Bot User OAuth Token`**(보통 `xoxb-`로 시작) 이 발급됩니다. 이게 비밀값입니다. **남에게 보여주거나 파일에 적지 마세요.**
   - 메시지를 보낼 채널(예: `#공지`)에 들어가 채팅창에 `/invite @만든봇이름` 을 입력해 **봇을 채널에 초대**합니다. (초대하지 않으면 권한이 있어도 그 채널엔 못 씁니다.)
2. **n8n에 로그인**합니다. (n8n Cloud 또는 직접 설치한 n8n 모두 가능)
3. 화면 오른쪽 위 **`...`(점 3개) → `Import from File`** 을 눌러 이 폴더의 **`workflow.json`** 을 불러옵니다. 노드 3개가 일렬로 연결되어 나타납니다.
4. **`Slack 메시지 보내기 (Slack)` 노드를 더블클릭**합니다. 여기만 직접 설정이 필요합니다.
   - **`Credential to connect with`(자격증명)**: `Create New Credential` 을 누르고, 방금 발급받은 **`Bot User OAuth Token`(`xoxb-...`)** 을 붙여 넣고 저장합니다. **이 토큰은 이 자격증명 금고에만 저장되고, 노드 화면이나 `workflow.json`에는 들어가지 않습니다.**
   - **`Resource`**: `Message`, **`Operation`**: `Post`(채널에 게시) 로 이미 설정돼 있습니다.
   - **`Channel`**: 메시지를 보낼 채널을 고릅니다. 자격증명이 연결되면 목록에서 `#공지` 같은 채널을 직접 선택할 수 있습니다. (파일에는 `C0000000000` 이라는 가짜 채널 ID 자리표시자가 들어 있으니, **반드시 내 채널로 다시 골라 주세요.**)
   - `Text`(보낼 내용)는 이미 `{{ $json.메시지 }}` 로 앞 노드와 연결돼 있으니 건드리지 않아도 됩니다.
5. **`보낼 메시지 만들기 (Set)` 노드를 클릭**해 봅니다. `메시지` 칸에 '서버 점검 알림' 문구가 들어 있습니다. 내 상황에 맞게 문구를 자유롭게 바꿔도 됩니다. (`{{ $now.format(...) }}` 부분은 보낸 시각을 자동으로 채워 넣는 표현입니다.)
6. 캔버스 아래의 **`Test workflow`(전체 실행)** 버튼을 누릅니다. 세 노드에 모두 초록 체크가 뜨고, **내 슬랙 채널에 메시지가 한 줄 올라오면 성공**입니다.
7. (선택) "매일 자동으로" 보내고 싶다면, `시작 (Manual Trigger)` 노드를 지우고 그 자리에 **`Schedule Trigger`** 노드를 넣어 `보낼 메시지 만들기 (Set)` 에 이어 준 뒤, 캔버스 오른쪽 위 **`Active`(활성) 토글을 켜면** 됩니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI(예: ChatGPT/Claude)에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. n8n 워크플로우는 JSON 한 덩어리라서, AI에게 "Import할 JSON으로 달라"고 또렷이 요구하는 게 핵심입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 n8n 자동화 도우미야. 비전공자가 Slack 채널에 자동으로 메시지를 올리는
  n8n 워크플로우를 만들 거야. 노드는 정확히 3개로 단순하게 해줘.
    1) Manual Trigger (버튼으로 실행 — 연결 확인을 손으로 먼저 하려고)
    2) Set 노드 (보낼 메시지 텍스트를 담는다)
    3) Slack 노드 (Resource=Message, Operation=Post로 채널에 게시)
  제약:
    - Slack 봇 토큰(xoxb-...) 같은 비밀값은 절대 JSON 안에 직접 넣지 마라.
      자격증명 id 자리에는 REPLACE_WITH_YOUR_SLACK_CREDENTIAL_ID 같은 자리표시자를,
      채널에는 C0000000000 같은 가짜 ID를 넣어줘.
    - Set 노드의 메시지는 Slack 노드의 Text에 {{ $json.메시지 }}로 이어줘.
  산출물: n8n에서 'Import from File'로 바로 불러올 수 있는 완성된 workflow.json 전체.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  좋아. 이제 두 가지를 개선해줘.
    1) 메시지 맨 아래에 보낸 시각을 자동으로 붙여줘.
       n8n 표현식 {{ $now.format('yyyy-MM-dd HH:mm') }} 를 써줘.
    2) "매일 아침 9시에 자동으로" 보내는 버전도 알려줘.
       Manual Trigger 대신 Schedule Trigger로 바꾸려면 JSON에서 어디를
       어떻게 고치면 되는지, 트리거 노드만 갈아 끼우는 방식으로 설명해줘.
  기존 노드 구조와 채널·자격증명 자리표시자는 그대로 유지해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  n8n에서 Test workflow를 눌렀더니 Slack 노드에서 아래 에러가 났어.
  비전공자도 이해하게 (1) 무슨 뜻인지 (2) 어디를 고치면 되는지
  단계별로 알려줘. 추측만 하지 말고 가능한 원인을 순서대로 체크하게 해줘.

  [여기에 빨간 에러 메시지를 그대로 붙여넣기]
  (예: channel_not_found / not_in_channel / missing_scope / invalid_auth)
  ```
> 프롬프트 팁: 끝에 **"코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"** 를 덧붙이면, 결과물을 그냥 받기만 하는 게 아니라 직접 검증할 수 있어 학습에 훨씬 좋습니다.

## 검증법

1. **자격증명 연결 확인:** Slack 노드의 `Credential` 옆에 초록 점/`Connection tested successfully` 같은 표시가 뜨면 토큰 연결은 정상입니다. 빨간 에러가 나면 `xoxb-` 토큰을 다시 확인하세요.
2. **채널 선택 확인:** `Channel` 칸이 `C0000000000`(자리표시자)이 아니라 **내 실제 채널(예: `#공지`)** 로 바뀌어 있는지 봅니다. 자리표시자 그대로 두면 `channel_not_found` 에러가 납니다.
3. **메시지 도착 확인(가장 확실한 증거):** `Test workflow`를 누른 뒤 **슬랙 채널**을 봅니다. 아래 같은 메시지가 봇 이름으로 올라오면 성공입니다. (시각은 실행한 때에 따라 달라집니다.)
   ```
   🚨 서버 점검 알림 🚨

   오늘 밤 23:00 ~ 24:00 사이 서버 점검이 예정되어 있습니다.
   점검 시간 동안 서비스 접속이 잠시 중단될 수 있습니다.

   보낸 시각: 2026-06-18 14:30
   ```
4. **흔한 실패 두 가지:**
   - `not_in_channel` / 메시지가 안 옴 → 봇을 그 채널에 **초대(`/invite`)** 하지 않았을 때입니다. 1단계 마지막 항목을 다시 하세요.
   - `missing_scope` → 슬랙 앱에 **`chat:write` 권한**을 안 줬을 때입니다. `OAuth & Permissions`에서 권한을 추가하고 **다시 설치(Reinstall)** 하세요.

## 핵심만 짚기 (디렉터 관점)

- **알림 통로는 갈아 끼우는 부품입니다.** 202의 이메일을 이번엔 Slack으로 바꿨을 뿐, '노드 + 자격증명' 이라는 구조는 똑같습니다. 다음에 카카오톡·디스코드를 붙여도 패턴은 동일합니다.
- **트리거도 부품입니다.** 손으로 누르는 Manual Trigger를 Schedule Trigger로 바꾸면 그대로 '정기 자동 공지'가 됩니다. 무엇으로 시작할지(트리거)와 무엇을 할지(액션)는 따로 고를 수 있습니다.
- **권한은 최소로.** 봇에 준 권한은 '메시지 쓰기(`chat:write`)' 하나뿐입니다. 필요 없는 권한을 잔뜩 주지 않는 것이 사고를 줄이는 기본입니다.

## 보안 — 어떤 값이 비밀이고, 어디에 넣나

자동화에서 가장 자주 사고가 나는 지점은 '비밀값을 잘못된 곳에 적는 것'입니다. 이 실습에는 두 종류의 값이 있습니다.

- **공개해도 되는 값(노드에 그대로 둬도 됨):** 채널 이름/ID, 메시지 문구, 보낸 시각. 채널 ID가 새어도 토큰이 없으면 남이 글을 쓸 수 없으므로, 이 값들은 `workflow.json`에 적어도 괜찮습니다. (Supabase로 치면 브라우저에 노출돼도 되는 **`anon`(공개) 키**와 같은 성격입니다.)
- **새면 절대 안 되는 비밀값(반드시 금고에):** 슬랙 **봇 토큰(`xoxb-...`)**. 이 토큰을 가진 사람은 누구든 내 워크스페이스에 봇 이름으로 글을 쓸 수 있습니다. (Supabase로 치면 모든 권한을 가진 **`service_role`(비밀) 키**와 같은 급으로 다뤄야 합니다.) 그래서 이 토큰은 노드 화면이 아니라 n8n의 **`Credentials`(자격증명) 금고**에만 저장합니다. 금고에 넣어 두면 노드에서는 "내 Slack 봇"이라는 이름표만 고를 뿐, 실제 토큰은 `workflow.json`에 절대 들어가지 않습니다.

> **그래서 이 파일의 비밀 자리에는 자리표시자만 들어 있습니다.** `workflow.json`의 자격증명 id는 `REPLACE_WITH_YOUR_SLACK_CREDENTIAL_ID`, 채널은 가짜 ID `C0000000000`으로 채워 두었습니다. 실제 값으로 바꿔 쓰되, **진짜 `xoxb-` 토큰을 노드 파라미터나 파일 본문에 직접 적는 일은 절대 하지 마세요.**

> **한 줄 원칙:** 공개해도 되는 값(채널·문구)은 노드에, 새면 안 되는 값(슬랙 토큰·API 키)은 `Credentials` 금고에.
