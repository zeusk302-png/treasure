## 2. 맨 윗줄(최신 배포) 상태 배지 읽기

상태 배지 색/글자에 동그라미 표시:

- [ ] 초록 **Ready** (성공 — 지금 인터넷에 떠 있음)
- [ ] 빨강 **Error** (실패 — 사이트에 반영 안 됨)
- [ ] 회색/노랑 **Building** 또는 **Queued** (작업 중 — 기다리면 바뀜)
- [ ] **Canceled** (취소됨 — 보통 새 push가 들어와 멈춤)

내 맨 윗줄 상태: ______

## 보안 메모 (스크린샷 찍을 때 주의)

- [ ] 이번 스크린샷 대상(Deployments 탭 / Build Logs)에는 **비밀값이 노출되지 않음**을 확인했다.
- [ ] **Settings → Environment Variables** 화면에서 `service_role` 같은 **비밀 키 값이 보이는 화면은 스크린샷/공유하지 않는다**는 걸 안다.
- 기억: 공개해도 되는 건 **anon 키 (+ 반드시 RLS 켜기)**, 절대 공개 금지는 **service_role 키**.
  비밀값은 코드가 아니라 환경변수에 자리표시자처럼: `SUPABASE_SERVICE_ROLE_KEY = <여기에_실제_비밀키_절대_공유_금지>`
