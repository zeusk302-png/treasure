# 실습 035 — 로고-메뉴-버튼이 양끝 배치된 내비바 만들기

우리가 보는 거의 모든 사이트의 맨 위에는 **상단 띠(내비게이션 바, 줄여서 내비바)**가 있습니다. 모양은 한결같습니다. **왼쪽에 로고**, **가운데에 메뉴**, **오른쪽에 로그인/가입 버튼**. 이 "양끝으로 쫙 벌어진" 배치는 어떻게 만들까요? 비밀은 단 두 줄입니다. 세 덩어리(로고·메뉴·버튼)를 하나의 **부모 상자**로 감싸고, 그 부모에게 `display: flex;`와 `justify-content: space-between;`을 주면 끝입니다. `space-between`은 "남는 가로 공간을 덩어리 **사이사이**에 똑같이 나눠 끼운다"는 뜻이라, 첫 덩어리는 왼쪽 끝, 마지막 덩어리는 오른쪽 끝으로 자동으로 밀려납니다. 이번 실습에서는 글자 로고 · 메뉴 4개 · 로그인 버튼으로 진짜 사이트 같은 내비바 한 줄을 만들어 봅니다. 파일은 `index.html` 하나뿐이고 서버도 인터넷도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 내비바는 **세 덩어리를 한 줄로 놓는 flex 부모**라는 구조를 이해한다. (로고 / 메뉴 / 버튼 = 자식 3개)
- `justify-content: space-between;`이 "남는 공간을 사이사이에 나눠 끼워 양끝으로 밀어낸다"는 동작을 눈으로 확인한다.
- `align-items: center;`로 높이가 제각각인 로고·메뉴·버튼을 **세로 가운데**로 맞추는 법을 익힌다.
- 메뉴(`ul`)처럼 내비바 안에 **또 다른 작은 flex**가 들어가는 중첩 구조를 경험한다.

핵심은 부모 상자에 주는 딱 두 줄입니다.

```
.navbar {
  display: flex;                   ← 로고·메뉴·버튼을 가로 한 줄로 놓는다
  justify-content: space-between;  ← 남는 공간을 사이사이에 끼워 양끝으로 벌린다(핵심!)
  align-items: center;            ← 세 덩어리를 세로 가운데로 맞춘다
}
```

| 자식(덩어리) | 위치 | 정체 |
|---|---|---|
| ① 로고 `.logo` | 왼쪽 끝 | 글자 로고(`<a>`) |
| ② 메뉴 `.menu` | 가운데 | `<ul>` 목록(그 자체가 작은 flex) |
| ③ 버튼 `.cta` | 오른쪽 끝 | 로그인 `<button>` |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열리고, 맨 위에 흰색 내비바가 화면 폭에 꽉 차게 나타납니다. (인터넷 연결이 필요 없습니다.)
2. 내비바를 봅니다. → **로고는 맨 왼쪽**, **로그인 버튼은 맨 오른쪽**, **메뉴 4개는 그 사이**에 놓여 있고, 세 덩어리의 높이가 세로로 가지런히 가운데 정렬되어 있으면 정상입니다.
3. 브라우저 창 너비를 마우스로 **넓혔다 줄였다** 해봅니다. → 가운데 빈 공간만 늘고 줄어들 뿐, 로고와 버튼은 늘 양끝에 딱 붙어 있습니다. 이것이 `space-between`의 힘입니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어, `.navbar` 규칙의 `justify-content: space-between;` 줄을 잠시 주석으로 막아 봅니다. 즉 `/* justify-content: space-between; */` 로 바꾸고 저장한 뒤, 브라우저에서 **새로고침(F5)** 합니다. → 세 덩어리가 양끝으로 안 벌어지고 **왼쪽에 옹기종기 붙어** 버립니다. 양끝 배치가 오직 이 한 줄 덕분이었음을 알 수 있습니다. 확인했으면 주석을 풀어 되돌리세요.
5. 이번엔 같은 자리에서 `justify-content`의 값만 바꿔 가며 새로고침해 보세요. → `center`(가운데로 모임), `flex-end`(오른쪽으로 모임), `space-around`(양끝에도 절반 간격이 생김)가 각각 어떻게 다른지 비교합니다. 다 본 뒤 `space-between`으로 되돌립니다.
6. `.navbar`의 `align-items: center;`를 잠시 주석 처리하고 새로고침해 보세요. → 로고·메뉴·버튼이 위쪽으로 들쭉날쭉 정렬되는 것을 보고, 세로 가운데 정렬이 왜 필요한지 체감합니다. 확인 후 되돌립니다.
7. 메뉴가 가로로 펴지는 이유도 확인해 봅니다. `.menu` 규칙의 `display: flex;`를 잠시 주석 처리하고 새로고침하면, 메뉴 4개가 다시 세로로 쌓입니다. → 내비바 안에 **또 하나의 작은 flex**가 들어 있었다는 걸 알 수 있습니다. 되돌리세요.
8. AI에게 시켜 보기:
   > "이 index.html의 내비바에서, 화면 너비가 좁아지면(@media max-width: 600px) 가운데 메뉴(.menu)를 숨기고 오른쪽 로그인 버튼만 남도록 CSS를 추가해줘. 기존 `display: flex;`와 `justify-content: space-between;`은 그대로 두고."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 단계씩 이어서 시키면 됩니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 웹 프론트엔드 강사야. 외부 라이브러리·인터넷 연결 없이 더블클릭만 하면 열리는
  index.html 한 파일을 만들어줘. 요구사항:
  - 페이지 맨 위에 상단 내비게이션 바(navbar)를 둔다.
  - 내비바는 세 덩어리로 구성: 왼쪽=글자 로고("부산코딩"), 가운데=메뉴 4개(홈/소개/강의/문의), 오른쪽=로그인 버튼.
  - 양끝 배치는 부모 상자에 display: flex; 와 justify-content: space-between; 두 줄로 구현한다.
  - align-items: center; 로 세 덩어리의 세로 높이를 가운데로 맞춘다.
  - CSS는 <style> 태그 안에 함께 넣어 한 파일로 만든다. 한글이 안 깨지게 charset=UTF-8을 넣는다.
  비전공자가 읽을 거라, 핵심 줄(특히 flex 관련)에는 "이 줄이 무슨 일을 하는지" 한국어 주석을 달아줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 내비바를 개선해줘. 기존 display: flex; 와 justify-content: space-between; 구조는 그대로 두고:
  1) 가운데 메뉴(.menu)도 작은 flex로 만들어 항목들을 가로로 펴고 gap으로 사이 간격을 준다.
  2) 메뉴 글자에 마우스를 올리면 색이 진해지는 :hover 효과를 넣는다.
  3) 화면 너비가 600px 이하로 좁아지면(@media max-width: 600px) 가운데 메뉴는 숨기고
     로고와 로그인 버튼만 양끝에 남게 한다.
  바꾼 줄마다 "왜 이렇게 했는지"를 한국어 주석으로 설명해줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내비바를 만들었는데 로고·메뉴·버튼이 양끝으로 안 벌어지고 전부 왼쪽에 옹기종기 붙어 있어.
  아래 내 HTML/CSS를 붙여넣을 테니, 원인을 단계별로 짚어줘:
  - display: flex; 가 부모(.navbar)에 제대로 들어갔는지
  - justify-content 철자/값(space-between)이 맞는지
  - 자식이 정확히 3개인지(감싸는 부모가 빠지진 않았는지)
  고친 코드와 함께, 왜 그게 문제였는지 비전공자가 이해하게 한 줄씩 풀어서 설명해줘.

  [여기에 내 index.html 코드 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- **눈으로 확인**: 로고가 **맨 왼쪽 끝**, 로그인 버튼이 **맨 오른쪽 끝**, 메뉴가 그 사이에 있으면 성공입니다. 세 덩어리가 전부 왼쪽에 붙어 있다면 `justify-content: space-between;`이 빠졌거나 오타가 난 것입니다.
- **창 크기 검증**: 4번 단계처럼 창 너비를 늘렸다 줄였다 할 때, 로고와 버튼이 **항상 양끝에 붙어** 있고 가운데 공간만 변하면 `space-between`이 제대로 동작하는 것입니다.
- **세로 정렬 검증**: 로고 글자·메뉴 글자·버튼의 **세로 중심선이 한 줄로** 맞아 있으면 `align-items: center;`가 잘 적용된 것입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 `<header class="navbar">`를 클릭한 뒤, 오른쪽 `Styles`(스타일) 탭에서 `display: flex;`와 `justify-content: space-between;`이 적용돼 있는지 봅니다. 같은 자리에서 `justify-content` 값을 `center`, `flex-end` 등으로 바꿔보면 화면이 즉시 바뀌는 것도 확인할 수 있습니다.
