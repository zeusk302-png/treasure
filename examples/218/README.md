# 218. 한 단어/한 화면만 콕 집어 고치라고 지시하기

## 목표

"사이트 전부 다 손봐줘" 대신 **"푸터 연락처 이메일 한 군데만"** 식으로,
바꿀 곳을 **한 군데로 좁혀** 지시하는 법을 연습합니다.

범위를 좁히면 좋은 점이 두 가지입니다.

- 멀쩡히 잘 돌아가던 부분을 AI가 슬쩍 건드려 망가뜨리는 일(**회귀**, "고치다가 도로 망가뜨림")을 막습니다.
- 바뀐 곳이 적으니 **확인이 쉽고**, "여기만 바뀌었나?" **한눈에 비교**됩니다.

이 실습에는 새로 짤 코드가 거의 없습니다. **범위를 좁혀 잘 지시하는 글쓰기**가 곧 실습입니다.
결과물은 "지정한 한 군데만 바뀌고 나머지는 그대로"인 **before/after 비교**입니다.

이 폴더의 파일은 셋입니다.

- [`prompt.md`](prompt.md) — AI에게 그대로 붙여넣는 "한 군데만 고쳐" 지시 프롬프트
- [`conversation.md`](conversation.md) — AI가 "바뀐 줄만" 보여준 대화 캡처(예시)
- [`index.html`](index.html) — 푸터 이메일 한 군데만 바뀐 결과물 (변경 전 이메일은 주석으로 남겨 둠)

## 따라하는 단계

1. [`index.html`](index.html)을 더블클릭해 브라우저로 엽니다. 맨 아래 푸터의 이메일이 `hello@onepage-books.kr`인 것을 확인합니다. (이게 *바꾼 뒤* 모습입니다.)
2. [`prompt.md`](prompt.md)의 **1단계 지시 프롬프트**를 통째로 복사합니다. 핵심은 제약 1·2번 — "이메일 한 군데만, 나머지는 한 글자도 건드리지 마"입니다.
3. 복사한 프롬프트를 실제 Claude(또는 쓰는 AI)에 붙여넣습니다.
4. AI가 전화번호·주소까지 "겸사겸사" 손대거나 페이지 전체를 다시 뱉으면, [`prompt.md`](prompt.md)의 **2단계 한 마디**로 "이메일 한 군데만, 바뀐 줄만 보여줘"라고 다시 좁혀 줍니다.
5. AI가 `변경 전 / 변경 후`로 **바뀐 줄만** 보여주면, 진짜로 이메일만 바뀌었는지 읽어 확인합니다. (예시는 [`conversation.md`](conversation.md))
6. AI가 준 줄로 [`index.html`](index.html)의 푸터 `mailto:` 링크와 보이는 이메일 글자 **그 한 줄만** 바꿔 저장하고, 브라우저를 새로고침해 확인합니다.
7. (제출용) 푸터의 이메일은 새 주소이고 전화번호·주소·저작권·다른 섹션은 그대로인 **before/after 두 화면**을 캡처해 두면, 이 실습의 핵심 증거가 됩니다.

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] 실제로 바뀐 것은 **푸터 이메일 한 군데뿐**이다 — `mailto:` 링크와 보이는 글자가 새 주소(`hello@onepage-books.kr`)로 함께 바뀌었다.
- [ ] **전화번호(02-123-4567)·주소·저작권 문구**, 그리고 **footer 바깥의 제목·추천 책·운영 시간**은 한 글자도 바뀌지 않았다.
- [ ] AI가 **페이지 전체가 아니라 "바뀐 줄만"** `변경 전 / 변경 후`로 보여줬다.
- [ ] [`index.html`](index.html)을 브라우저로 열면 새 이메일이 보이고, 주석에 **변경 전 이메일**이 함께 남아 있어 before/after가 비교된다.

> 빠르게 자가 점검: 바뀐 부분을 손가락으로 짚었을 때 **이메일 한 줄에서 멈추면** 통과입니다.
> 여기저기 가리키게 된다면 범위가 새어 나간 것이니, 2단계 한 마디로 "한 군데만"을 다시 거세요.
