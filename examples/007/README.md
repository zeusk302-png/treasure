# 다른 사이트로 가는 링크 모음 페이지

좋아하는 사이트 3곳으로 이동하는 "링크 모음" 페이지를 만들면서, 웹의 가장 기본이 되는 하이퍼링크(`<a>` 태그)가 어떻게 동작하는지 익혀봅니다.

## 목표

- `<a>` 태그와 `href` 속성으로 외부 사이트로 이동하는 링크를 만든다.
- 글자(링크 이름)를 누르면 `href`에 적은 주소로 이동하는 원리를 이해한다.
- 목록(`<ul>`/`<li>`)을 이용해 여러 링크를 깔끔하게 나열한다.

> 비전공자 눈높이 한 줄 요약: `<a href="주소">보이는 글자</a>` 이렇게 쓰면, "보이는 글자"를 누를 때 "주소"로 이동하는 파란 글씨(링크)가 만들어집니다.

## 따라하는 단계

1. `examples/007/` 폴더 안에 있는 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<a href="...">...</a>` 부분을 찾습니다. 이게 바로 "링크"를 만드는 코드입니다.
3. `href="..."` 안의 주소가 "어디로 갈지"입니다. 예: `href="https://www.google.com"` → 누르면 구글로 이동.
4. `>` 와 `</a>` 사이에 적힌 글자(예: `구글 (검색)`)가 화면에 보이는 링크 글자입니다. 이 글자를 누르면 이동합니다.
5. 주소(`href`)와 보이는 글자를 내가 좋아하는 사이트로 바꿔봅니다. 예를 들어 `<a href="https://www.github.com">깃허브</a>` 처럼요.
6. 링크를 하나 더 추가하고 싶으면 `<li> ... </li>` 한 줄을 통째로 복사해서 붙여넣고, 안의 주소와 글자만 바꾸면 됩니다.
7. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의: `href` 의 주소는 반드시 `https://` 로 시작하는 전체 주소를 적어야 외부 사이트로 정확히 이동합니다. `www.google.com` 처럼 `https://` 를 빼면 같은 폴더 안의 파일을 찾으려고 해서 링크가 깨질 수 있어요.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 링크 글자 3개가 파란색(또는 밑줄)으로 보이는지 확인합니다. 이렇게 보이면 `<a>` 태그가 제대로 적용된 것입니다.
3. 링크 글자에 마우스를 올렸을 때, 브라우저 왼쪽 아래에 이동할 주소가 미리 보이는지 확인합니다.
4. 링크를 하나씩 눌러서, 각각 구글 / 유튜브 / 네이버(또는 내가 바꾼 사이트)로 실제로 이동하는지 확인합니다.
5. 인터넷이 연결되어 있어야 외부 사이트로 이동합니다. 이동이 안 되면 인터넷 연결과 `href` 주소의 오타(`htps`, 띄어쓰기 등)를 확인하세요.
