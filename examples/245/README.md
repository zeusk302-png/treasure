# 랜딩페이지를 모바일 반응형으로 만들기

## 목표
하나의 랜딩페이지가 **폰·태블릿·PC** 어디서 봐도 깨지지 않고 보기 좋게 나오도록 **반응형(responsive)** 으로 만듭니다. 새로운 페이지를 만드는 게 아니라, CSS만으로 화면 크기에 맞춰 레이아웃이 스스로 바뀌게 하는 것이 핵심입니다.

이 실습에서 쓰는 세 가지 핵심 도구를 한 줄로 정리하면 이렇습니다.

- **viewport 메타 태그** (`<meta name="viewport" ...>`): 폰이 페이지를 강제로 축소하지 않게 해주는 "반응형의 첫 단추"입니다. 이게 없으면 미디어쿼리를 아무리 잘 써도 폰에서 글자가 깨알같이 작게 나옵니다.
- **유연한 레이아웃** (`flex-wrap`, `%`, `clamp()`): 너비를 `px`로 딱 고정하지 않고 비율(`%`)이나 `flex`로 정해두면, 화면이 좁아지면 카드가 자동으로 아래로 쌓이고 글자 크기도 부드럽게 줄어듭니다.
- **미디어쿼리** (`@media (min-width: ...)`): "화면 가로폭이 ○○px 이상일 때만 이 스타일을 추가로 적용해라"라는 조건 분기입니다. 화면이 넓어질 때마다 레이아웃을 한 단계씩 펼칩니다.

이 예제는 **모바일 퍼스트(mobile-first)** 방식입니다. 기본 CSS는 폰 화면 기준으로 작성하고, 화면이 넓어질 때만 `@media (min-width)`로 규칙을 덧칠합니다. 그래서 특징 카드 3개가 **폰 1열 → 태블릿 2열 → PC 3열**로 펼쳐집니다.

## 따라하는 단계
1. `C:\Users\김세영\Desktop\부산코딩스쿨_강의자료\treasure\examples\245\` 폴더의 `index.html`을 더블클릭해 브라우저로 엽니다. 같은 폴더에 `style.css`가 있어야 디자인이 적용됩니다.
2. `index.html`을 VS Code나 메모장으로 열어 맨 위 `<head>` 안의 `<meta name="viewport" content="width=device-width, initial-scale=1.0" />` 줄을 확인합니다. 이 한 줄이 반응형의 시작입니다.
3. 브라우저 창의 오른쪽 가장자리를 마우스로 잡고 **창 너비를 좁게/넓게 천천히 드래그**합니다. 특징 카드 3개가 넓을 때 가로 3열, 중간일 때 2열, 좁을 때 1열(세로)로 바뀌는지 봅니다.
4. `style.css`를 열어 맨 아래 두 개의 `@media (min-width: 640px)`와 `@media (min-width: 960px)` 블록을 찾습니다. 이 안에서 `.feature-card`의 `flex` 값이 바뀌는 것이 열 개수가 달라지는 비밀입니다.
5. `@media (min-width: 640px)`의 숫자 `640px`를 `500px`로 바꿔 저장하고 새로고침합니다. 더 좁은 창에서도 2열로 바뀌는지(분기점이 앞당겨지는지) 확인합니다.
6. `.hero-title`의 `font-size: clamp(28px, 6vw, 48px);`에서 가운데 값 `6vw`를 `10vw`로 바꿔 저장하고, 창 너비를 줄였다 늘렸다 하며 제목 글자 크기가 화면에 따라 부드럽게 변하는 것을 봅니다. (`vw`는 화면 너비의 1% 단위)
7. (브라우저 개발자 도구로 폰 보기) 페이지에서 `F12`를 누르고 왼쪽 위 **기기 모드 아이콘**(휴대폰 모양)을 클릭한 뒤, 상단에서 'iPhone' 같은 기기를 골라 실제 폰처럼 보이는지 확인합니다.

## 검증법
- 브라우저 창을 **넓게(1000px 이상)** 했을 때 특징 카드 3개가 한 줄에 가로로 나란히 보이면 데스크톱 레이아웃이 정상입니다.
- 창을 **중간 폭(약 700px)** 으로 줄이면 카드가 2열(2개+1개)로 재배치되면 태블릿 분기가 동작하는 것입니다.
- 창을 **아주 좁게(약 400px)** 줄이면 카드가 1열로 세로로 쌓이고, 페이지 아래에 **가로 스크롤바가 생기지 않으면** 반응형이 제대로 된 것입니다. (가로 스크롤이 생기면 어딘가 너비가 `px`로 고정돼 화면을 삐져나간 것입니다.)
- 제목 글자가 좁은 화면에서 너무 커서 줄을 마구 넘기지 않고, 넓은 화면에서도 과하게 커지지 않으면 `clamp()`가 잘 동작하는 것입니다.
- `F12` 기기 모드에서 폰 화면으로 봤을 때 글자와 버튼이 손가락으로 누를 만한 크기로 적당히 보이면 성공입니다.
