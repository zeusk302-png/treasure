# 인라인 스타일로 상품 소개 카드 디자인하기

이미지, 제목, 설명, 가격을 한 박스에 모아 "상품 카드" UI를 만듭니다.
이번엔 별도의 CSS 파일 없이, 태그 안에 `style="..."`로 직접 꾸미는 **인라인 스타일**만 사용합니다.

## 목표

- 여러 요소(이미지, 제목, 설명, 가격, 버튼)를 하나의 박스(`div`)로 묶는다.
- `border-radius`(둥근 모서리), `box-shadow`(그림자), `text-align`(글자 정렬)을 직접 적용해본다.
- 쇼핑몰에서 흔히 보는 카드 UI가 어떤 속성들의 조합인지 눈으로 익힌다.

## 따라하는 단계

1. `index.html` 파일을 메모장이나 VS Code로 엽니다.
2. `<body>` 안에 있는 카드 바깥 박스 `div`를 봅니다. 여기에 카드의 핵심 속성 3가지가 들어 있어요.
   - `border-radius: 16px;` → 모서리를 둥글게 깎습니다. 숫자를 키우면 더 둥글어집니다.
   - `box-shadow: 0 8px 24px rgba(0,0,0,0.12);` → 카드 아래에 그림자를 넣어 "떠 있는" 느낌을 줍니다.
     (순서: 가로위치 / 세로위치 / 번짐 / 색·투명도)
   - `text-align: center;` → 박스 안의 글자와 버튼을 가운데로 정렬합니다.
3. 그 안에 순서대로 `img`(상품 사진), `h2`(제목), `p`(설명), `p`(가격), `a`(담기 버튼)가 들어 있습니다.
4. 사진 아래 글자 영역 `div`의 `padding: 20px;`는 **안쪽 여백**입니다. 사진과 글자가 너무 붙지 않게 띄워줍니다.
5. 파일을 저장한 뒤, 파일을 더블클릭해 브라우저로 엽니다.
6. 직접 바꿔보며 익히기:
   - 가격 색 `color: #2563eb;`를 `#e11d48`(빨강)으로 바꿔보세요.
   - `border-radius` 값을 `0px`으로 바꿔 모서리가 각지는 것을 확인하세요.
   - `box-shadow`를 지웠다 넣었다 하며 그림자 유무 차이를 봅니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 HTML/CSS를 가르치는 친절한 튜터야. 비전공자가 처음 배우는 단계라고 생각하고 만들어줘.
  요청: 외부 CSS 파일 없이 "인라인 스타일"(태그 안에 style="...")만 사용해서, 쇼핑몰에서 흔히 보는 상품 카드 하나를 만들어줘.
  카드 안에는 위에서부터 상품 이미지 → 제목(h2) → 설명(p) → 가격(p) → "담기" 버튼(a) 이 순서로 들어가야 해.
  제약:
  - 카드 바깥 박스(div)는 고정 너비(약 280px), 화면 가운데 정렬(margin: 0 auto), 흰 배경.
  - 둥근 모서리(border-radius), 연한 그림자(box-shadow), 글자 가운데 정렬(text-align: center)을 꼭 넣어줘.
  - 이미지는 인터넷 샘플 이미지(picsum.photos)를 src로 쓰고, alt 설명도 적어줘.
  산출물: index.html 한 파일 전체. 각 style 속성이 무엇을 하는지 한국어 주석으로 한 줄씩 설명해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  방금 만든 상품 카드에 이어서 개선해줘. 기존 카드 구조는 그대로 두고 아래만 추가/변경해줘.
  1) "담기" 버튼에 마우스를 올리면(:hover) 색이 살짝 진해지게 해줘. (인라인 스타일로 :hover가 어려우면 왜 어려운지 설명하고 대안을 알려줘.)
  2) 카드를 가로로 2개 나란히 보여주고 싶어. 두 번째 카드를 추가하고, 두 카드가 옆으로 나란히 놓이게 해줘.
  3) 같은 스타일을 두 번 복사해서 붙여야 하는 게 불편한데, 왜 그런지와 style.css로 분리하면 뭐가 좋아지는지 비유로 설명해줘.
  각 변경마다 "무엇을 왜 바꿨는지" 주석으로 남겨줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  상품 카드가 내가 의도한 대로 안 나와. 아래 증상 중 하나가 나는데 원인과 고치는 법을 단계별로 알려줘.
  - 카드가 화면 왼쪽에 붙어 있고 가운데로 안 옴.
  - 모서리가 둥글지 않고 각져 있음.
  - 이미지가 카드 폭을 안 채우거나 찌그러져 보임.
  - 그림자가 안 보임.
  내 index.html 코드는 아래에 붙여넣을게. (코드 붙여넣기)
  어디를 어떻게 고쳐야 하는지 한 군데씩, 왜 그렇게 고치는지 이유와 함께 알려줘.
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- 브라우저로 열었을 때 흰색 카드가 회색 배경 **가운데**에 놓여 있다.
- 카드의 **네 모서리가 둥글고**, 카드 아래에 **연한 그림자**가 보인다.
- 위에서부터 사진 → 제목 → 설명 → 가격 → 파란 "담기" 버튼이 차례로, **가운데 정렬**되어 보인다.
- 이미지는 인터넷에서 불러오므로(picsum.photos) 잠깐 로딩될 수 있습니다. 안 보이면 `alt` 설명 텍스트가 대신 뜹니다.
