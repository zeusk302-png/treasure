# 239 — 블로그 글 목록 페이지를 HTML 카드 리스트로 만들기

여러 개의 글(제목·요약·날짜·태그)을 **똑같은 모양의 카드로 반복해서 나열한**
블로그 홈 화면을 만듭니다. 인터넷의 블로그·쇼핑몰·뉴스 사이트에서
**가장 많이 쓰이는 화면**이 바로 이런 "카드 리스트"입니다.

핵심은 거창한 기술이 아니라 **"같은 구조를 여러 번 반복한다"** 는 깨달음입니다.
카드 한 개의 구조(제목 → 날짜·태그 → 요약 → 더 읽기)를 만들어 두면,
나머지는 그 덩어리를 복사해 내용만 바꾸면 됩니다.

- 카테고리: 아키타입 미니프로젝트 (코드 L)
- 난이도: 1 / 5
- 개념: 리스트 UI, 반복 구조
- 결과물: **블로그 글 목록 HTML 페이지** (이 폴더의 `index.html` + `style.css`)

> 이 폴더에는 두 개의 파일이 있습니다.
> - `index.html` : 글 카드들의 **내용과 구조**
> - `style.css` : 그 카드들의 **모양(색·여백·정렬)**
> 두 파일은 **같은 폴더에 함께** 있어야 디자인이 적용됩니다.

---

## 목표

블로그 홈에 들어가면 **글이 한 줄로 길게 늘어선 게 아니라**,
네모난 카드들이 격자처럼 나란히 놓여 있는 걸 본 적이 있을 겁니다.
이번 목표는 그런 **"카드 리스트" 화면을 직접 만드는 것**입니다.

여기서 진짜 배우는 것은 한 가지 사고방식입니다.

> **"화면에 똑같이 생긴 게 여러 개라면, 그건 하나를 만들어 반복한 것이다."**

블로그 글 목록, 쇼핑몰 상품 목록, 유튜브 영상 목록 — 모두 이 원리로 만들어집니다.
나중에 데이터베이스(Supabase)에서 글을 불러와 자동으로 카드를 찍어내게 될 텐데,
그 전에 **"반복되는 카드 한 칸이 어떻게 생겼는지"** 를 손으로 만들어 보는 단계입니다.

- **카드(card)**: 글 하나를 담은 네모 상자. 제목·날짜·요약이 한 덩어리로 묶여 있습니다.
- **리스트(list)**: 그 카드들을 여러 개 늘어놓은 목록.
- **반복 구조**: 카드 하나의 HTML 모양을 똑같이 되풀이하는 것. (`<article>` 한 덩어리가 카드 한 개)

> 비유: 카드 한 장은 **붕어빵 틀**입니다. 틀(구조)은 똑같고, 안에 넣는 팥·슈크림(내용)만 다릅니다.
> 우리는 틀 하나를 잘 만들어 두고, 같은 틀로 여러 개를 찍어낼 뿐입니다.

---

## 따라하는 단계

### 1단계 — 폴더와 파일 확인하기

1. 이 폴더(`239`) 안에 `index.html` 과 `style.css` **두 파일**이 있는지 확인합니다.
2. `index.html` 을 **더블클릭**해 브라우저로 엽니다. 보라색 제목과 카드 4개가 보이면 준비 완료입니다.

### 2단계 — 카드 한 개의 구조 들여다보기

1. `index.html` 을 메모장(또는 VS Code)으로 엽니다.
2. `<article class="post-card">` 로 시작해 `</article>` 로 끝나는 덩어리를 찾습니다.
   이 한 덩어리가 **카드 한 개**입니다. 안에는 항상 같은 순서가 들어 있습니다.
   - `<h2 class="post-title">` : 글 **제목**
   - `<p class="post-meta">` : **날짜**(`<time>`)와 **태그**(`<span class="tag">`)
   - `<p class="post-summary">` : 글 **요약** 한두 줄
   - `<a class="read-more">` : **더 읽기** 링크
3. 카드 4개가 모두 이 순서를 **그대로 반복**하고 있다는 점을 눈으로 확인합니다.

### 3단계 — 카드 내용 바꿔보기

1. 첫 번째 카드의 제목 `HTML 첫 페이지를 만들었다` 를 본인 이야기로 바꿔 봅니다.
2. 날짜(`2026년 6월 14일`)와 태그(`HTML`)도 원하는 값으로 바꿉니다.
3. 저장하고 브라우저에서 **새로고침(F5)** 하면 바뀐 내용이 보입니다.

### 4단계 — 카드 한 개 더 늘리기 (반복 구조 체험)

1. `<article class="post-card"> ... </article>` 한 덩어리를 **통째로 복사**합니다.
   (`<article>`부터 짝이 되는 `</article>`까지 전부)
2. 마지막 카드 아래(`</main>` 바로 위)에 **붙여넣기** 합니다.
3. 새로 붙인 카드의 제목·날짜·요약을 바꿉니다.
4. 저장 후 새로고침 → 카드가 **5개**로 늘어납니다.
   이렇게 **같은 구조를 복사해 내용만 바꾸는 것**이 반복 UI의 전부입니다.

### 5단계 — 화면 크기 바꿔보기 (반응형 맛보기)

1. 브라우저 창의 가로 폭을 **좁게** 줄여 봅니다.
2. 가로로 여러 개 놓였던 카드가 **자동으로 한 줄(세로)로 정리**됩니다.
   - 이건 `style.css`의 `.post-list`에 쓴
     `grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));` 덕분입니다.
   - "카드 한 칸의 최소 너비는 260px, 들어갈 수 있는 만큼만 채워라"는 뜻이라
     화면이 좁아지면 칸 수가 알아서 줄어듭니다.

## 🤖 바이브코딩 프롬프트

이 카드 리스트 페이지를 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.
한 번에 다 시키지 말고 **1단계 → 2단계** 순서로 나눠 시키면 결과가 훨씬 깔끔합니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 가르치는 강사야. 비전공자가 이해할 수 있는 가장 단순한 코드로 만들어줘.
  "블로그 글 목록" 페이지를 index.html과 style.css 두 파일로 만들어줘.

  조건:
  - 맨 위에 블로그 제목(h1)과 한 줄 소개가 들어간 header
  - 글 카드 4개를 나열한 main 영역
  - 카드 한 개는 <article> 한 덩어리이고, 안에 제목 → 날짜·태그 → 요약 → "더 읽기" 링크 순서
  - 모든 카드가 똑같은 구조를 반복하도록(복사-붙여넣기 하기 쉽게)
  - CSS는 별도 style.css 파일에 두고 index.html에서 <link>로 연결
  - 자바스크립트는 쓰지 마(HTML/CSS만)

  코드만 주지 말고, 각 부분이 무엇이고 왜 그렇게 했는지 한국어 주석으로 설명해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  좋아. 이제 카드 목록을 더 보기 좋게 개선해줘.

  - 카드들을 CSS grid로 배치해서, 화면이 넓으면 여러 줄, 좁으면 한 줄로 자동 정리되게 해줘
    (grid-template-columns에 repeat(auto-fill, minmax(...)) 사용)
  - 마우스를 카드 위에 올리면 살짝 위로 떠오르고 그림자가 진해지게 해줘
  - 태그는 알약(둥근) 모양 라벨로 보이게 해줘
  - 색은 CSS 변수(:root)로 한곳에 모아 나중에 바꾸기 쉽게 해줘

  바꾼 CSS마다 "왜 이렇게 했는지"를 주석으로 한 줄씩 달아줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 브라우저로 열었는데 카드 모양이 안 나오고 글자만 줄줄이 나와.
  아래는 내 index.html의 <head> 부분과 style.css 파일이야.

  (여기에 코드 붙여넣기)

  뭐가 문제인지 비전공자도 알 수 있게 한 단계씩 짚어주고,
  고친 코드와 "왜 그게 원인이었는지" 이유도 함께 알려줘.
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면, AI가 답을 던지기만 하는 게 아니라 **학습 자료**로 바뀝니다.

## 검증법

아래가 모두 맞으면 성공입니다.

- **카드가 보인다**: `index.html`을 열면 흰 카드들이 격자로 나란히 떠 있다.
  (글자만 줄줄이 나오고 카드 모양이 없다면 `style.css`가 같은 폴더에 없거나
  `index.html`의 `<link rel="stylesheet" href="style.css" />` 줄이 빠진 것입니다.)
- **모든 카드 구조가 같다**: 카드마다 제목 → 날짜·태그 → 요약 → 더 읽기가 **같은 순서**로 들어 있다.
- **카드를 늘릴 수 있다**: `<article>` 덩어리를 복사·붙여넣기 하면 카드가 하나 더 생긴다.
- **반응형이 된다**: 창을 좁히면 카드가 여러 줄 → 한 줄로 자동 정리된다.
- **마우스 올리면 떠오른다**: 카드 위에 커서를 올리면 살짝 위로 뜨고 그림자가 진해진다.

> 흔한 실수
> - **디자인이 빠진 채 글자만 나옴**: `style.css`가 `index.html`과 **같은 폴더**에 있는지,
>   파일 이름 철자(`style.css`)가 정확한지 확인하세요.
> - **카드를 복사했는데 깨짐**: `<article>` 의 짝인 `</article>` 까지 **함께** 복사했는지 보세요.
>   여는 태그만 복사하면 구조가 어긋나 화면이 망가집니다.
> - **"더 읽기" 눌러도 아무 일 없음**: 지금은 `href="#"`(제자리 링크)라 정상입니다.
>   실제 글 페이지로 연결하는 것은 다음 단계 실습에서 다룹니다.
> - **태그가 깨져 보임**: `index.html` 첫 줄에 `<meta charset="UTF-8" />` 가 있어야
>   한글이 깨지지 않습니다.
