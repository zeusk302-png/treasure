# 할 일 목록 업그레이드 — 완료 체크와 개수 표시

앞에서 만든 "추가·삭제만 되는 할 일 목록"에 **완료 체크**와 **남은 개수 표시**를 더한 한 단계 업그레이드 버전입니다.
각 할 일이 "완료했는지" 여부를 스스로 기억하게 만들고(객체 배열), 완료되지 않은 것만 골라 세어(필터링 집계) 화면에 보여줍니다.

## 목표

- 할 일 하나하나를 `{ id, text, done }` 모양의 **객체**로 다루고, 그 객체들을 모은 **객체 배열**을 이해한다.
- 체크박스를 켜고 끄면 해당 항목의 `done` 값이 바뀌고, 완료된 줄에 **취소선**이 그어지게 한다.
- `filter`로 완료되지 않은 항목만 골라 세어 **"남은 할 일 N개"** 를 실시간으로 보여준다.
- "데이터(배열)를 바꾸면 → 화면을 다시 그린다(`render`)"는 흐름을 몸에 익힌다.

## 따라하는 단계

1. 이 폴더의 `index.html`을 더블클릭해 브라우저로 엽니다. (`index.html`, `style.css`, `script.js` 세 파일이 같은 폴더에 있어야 합니다.)
2. 입력칸에 할 일을 적고 **추가** 버튼이나 **Enter** 키를 누르면 목록에 한 줄이 추가됩니다.
3. 각 줄 왼쪽의 **체크박스**를 눌러 보세요. 글자에 가운데 줄(취소선)이 생기고 회색으로 바뀝니다 = 완료 처리.
4. 체크박스를 다시 누르면 완료가 풀리고 줄이 사라집니다.
5. 항목을 체크/해제할 때마다 위쪽의 **"남은 할 일 N개"** 숫자가 즉시 바뀌는지 확인하세요.
6. 오른쪽 **×** 버튼을 누르면 그 줄이 삭제됩니다.
7. 코드를 이해하려면 `script.js`를 위에서 아래로 읽어 보세요. 특히 다음 세 함수가 핵심입니다.
   - `addTodo` : 새 객체를 배열에 추가
   - `toggleDone` : 그 항목의 `done`을 반대로 뒤집기
   - `updateCounter` : `filter`로 미완료 개수 세기

## 검증법

- [ ] 할 일을 3개 추가하면 화면에 3줄이 보이고, "남은 할 일 3개"로 표시된다.
- [ ] 그중 1개를 체크하면 그 줄에 취소선이 생기고 "남은 할 일 2개"로 줄어든다.
- [ ] 체크를 해제하면 취소선이 사라지고 다시 "남은 할 일 3개"가 된다.
- [ ] × 버튼으로 1개를 삭제하면 줄이 사라지고 남은 개수도 그에 맞게 바뀐다.
- [ ] 모든 할 일을 삭제하면 "아직 할 일이 없어요" 안내 문구가 나타난다.
- [ ] 빈 칸(공백만)인 채로 추가를 눌러도 아무 항목도 추가되지 않는다.

> 참고: 이 단계에서는 데이터를 브라우저에 저장하지 않으므로 **새로고침하면 목록이 사라집니다.** 데이터를 영구 저장하는 방법은 다음 단계(085번, localStorage 영속화)에서 다룹니다.
