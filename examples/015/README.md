# 내비게이션 바와 섹션으로 한 페이지 사이트 뼈대 만들기

상단 **메뉴(`<nav>`)** 와 **본문 구역들(`<section>`)**, 그 안의 **독립된 글 토막(`<article>`)** 으로, 우리가 흔히 보는 "한 페이지 사이트(랜딩 페이지)"의 뼈대를 만들어 봅니다. 핵심은 `<div>` 처럼 의미 없는 상자를 쓰는 대신, **이름만 봐도 무슨 영역인지 알 수 있는 태그**(이걸 "시맨틱 = 의미가 담긴" 태그라고 부릅니다)를 골라 쓰는 감각입니다.

> 비전공자 눈높이 한 줄 요약: 식당으로 비유하면 `nav` 는 "입구의 메뉴판", `main` 은 "홀 전체", `section` 은 "코너(주제별 구역)", `article` 은 "그 코너에 놓인 완성된 음식 한 접시" 입니다.

## 목표

- `<nav>` 로 **상단 내비게이션(메뉴) 바**를 만든다. 메뉴 항목은 `<ul><li>` 목록과 `<a>` 링크로 적는다.
- `<main>` 으로 페이지의 **진짜 본문**을 한 번에 묶는다. (한 페이지에 `main` 은 딱 하나)
- `<section>` 으로 **주제가 같은 한 덩어리**(소개 / 기능 / 후기)를 나눈다.
- `<article>` 로 section 안의 **그것만 떼어 내도 말이 되는 독립된 글 한 토막**(기능 카드, 후기 등)을 만든다.
- `<footer>` 로 페이지 맨 아래 **바닥글** 영역을 만든다.
- 메뉴의 `href="#소개"` 와 section의 `id="소개"` 가 짝이 되어 **누르면 그 구역으로 점프**한다는 것을 이해한다.

## 따라하는 단계

1. `examples/015/` 폴더의 `index.html` 을 메모장이나 VS Code 같은 편집기로 엽니다.
2. 맨 위의 `<nav> ... </nav>` 를 찾습니다. 안에 `<ul><li><a>...</a></li></ul>` 형태로 **메뉴 3개**(소개·기능·후기)가 들어 있습니다. 이게 "내비게이션 바"입니다.
3. 그 아래 `<main> ... </main>` 을 찾습니다. 페이지의 본문 전체가 이 안에 묶여 있습니다. 메뉴(`nav`)와 바닥글(`footer`)은 `main` **바깥**에 있다는 점을 확인하세요.
4. `<main>` 안에 `<section id="소개">`, `<section id="기능">`, `<section id="후기">` 세 개가 있습니다. 각각이 "주제가 같은 한 덩어리"입니다. 보통 덩어리마다 제목 `<h2>` 를 하나씩 둡니다.
5. `<section id="기능">` 안을 보면 `<article>` 두 개가 들어 있습니다. 기능 설명 카드 한 장 한 장이 **독립된 글 토막(article)** 입니다.
6. 메뉴의 `href="#기능"` 과 섹션의 `id="기능"` 이 같은 단어로 짝지어진 것을 확인합니다. → 그래서 메뉴를 누르면 그 구역으로 이동합니다.
7. 나만의 구역을 하나 더 추가해 봅니다. 먼저 메뉴에 항목을 한 줄 넣습니다.
   ```html
   <li><a href="#문의">문의</a></li>
   ```
8. 이어서 `</main>` **바로 위**에 짝이 되는 구역을 추가합니다. (메뉴의 `#문의` 와 같은 `id="문의"` 를 붙이는 게 핵심)
   ```html
   <section id="문의">
     <h2>문의하기</h2>
     <article>
       <h3>이메일</h3>
       <p>hello@example.com 으로 연락 주세요.</p>
     </article>
   </section>
   ```
9. 저장한 뒤 `index.html` 파일을 더블클릭해 브라우저(크롬 등)로 엽니다.

> 주의 1: `section` 과 `article` 헷갈리지 않기 — **여러 항목을 묶는 "구역"** 은 `section`, 그 안의 **완결된 한 토막**은 `article` 입니다. (구역 안에 토막들이 들어 있는 구조)
> 주의 2: `nav` 메뉴의 `href="#이름"` 과 점프할 구역의 `id="이름"` 은 **글자가 완전히 같아야** 작동합니다. (대소문자·띄어쓰기까지 동일)
> 주의 3: `<style>` 안의 색칠은 "어느 영역인지 보이게" 하려는 보조 장치일 뿐, 이 실습의 본질이 아닙니다. 태그 구조 자체에 집중하세요.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. (직접 한 줄씩 타이핑하기보다, 아래처럼 "무엇을·왜·어떤 제약으로" 시키고 결과가 옳은지 판별하는 연습을 하세요.)

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML 초보를 가르치는 강사야. 시맨틱 태그만으로 "한 페이지 사이트(랜딩 페이지)"의 뼈대를 만들어줘.
  요구사항:
  - 맨 위에 <nav> 메뉴 바를 두고, 그 안에 <ul><li><a> 로 "소개·기능·후기" 3개 메뉴를 만들어줘.
  - <main> 안에 <section id="소개">, <section id="기능">, <section id="후기"> 세 구역을 만들고, 각 section엔 <h2> 제목을 하나씩 넣어줘.
  - 메뉴의 href="#소개" 와 section의 id="소개" 가 짝이 되어 누르면 그 구역으로 점프하게 해줘.
  - <div> 같은 의미 없는 상자 말고 nav/main/section/article/footer 같은 의미가 담긴 태그를 써줘.
  - 맨 아래엔 <footer> 바닥글을 둬줘. (footer 와 nav 는 main 밖에)
  제약: 파일 하나(index.html)로 끝나게 하고, CSS는 영역 구분이 눈에 보일 정도의 간단한 <style> 만 넣어줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 코드에 "문의" 구역을 하나 더 추가해줘.
  - nav 메뉴에 <li><a href="#문의">문의</a></li> 를 한 줄 넣고,
  - </main> 바로 위에 id="문의" 인 <section> 을 만들어 그 안에 <article> 로 이메일 안내 카드를 넣어줘.
  - 그리고 <section id="기능"> 안의 기능 카드(article)를 하나 더 늘려서 총 3장으로 만들어줘.
  - href 의 # 이름과 section 의 id 이름이 글자까지 똑같이 맞는지 꼭 확인해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  메뉴를 눌러도 해당 구역으로 점프가 안 돼. 아래 내 코드를 보고 원인을 한 단계씩 짚어줘.
  특히 nav 의 href="#이름" 과 section 의 id="이름" 글자가 정확히 같은지(대소문자·띄어쓰기 포함),
  그리고 section 이 정말 <main> 안에 있는지 확인해줘. 고친 부분이 왜 문제였는지도 설명해줘.
  (여기에 내 index.html 코드 전체를 붙여넣기)
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 맨 위에 **가로로 늘어선 메뉴 3개**(소개·기능·후기)가 진한 색 바(`nav`) 안에 보이는지 확인합니다.
3. 메뉴의 **"기능"** 을 클릭합니다. → 화면이 '주요 기능' 구역(`#기능`)으로 **점프(이동)** 하면 성공입니다. ("소개", "후기"도 눌러 확인)
4. '주요 기능' 구역 안에 **카드 두 장**(빠른 시작 / 깔끔한 구조)이 각각 왼쪽에 세로선이 있는 박스(`article`)로 보이는지 확인합니다.
5. 페이지 맨 아래에 회색 **바닥글(`footer`)** 이 있는지 확인합니다.
6. 단계 7~8에서 직접 추가한 "문의" 메뉴를 새로고침(F5) 후 눌렀을 때, 새로 만든 "문의하기" 구역으로 점프하면 성공입니다.
7. (확인 팁) 메뉴를 눌러도 화면이 안 움직인다면, 메뉴의 `href="#문의"` 와 구역의 `id="문의"` 글자가 정확히 같은지 다시 확인하세요. 한 글자라도 다르면 점프하지 않습니다.
8. (확인 팁) 영역 색이 안 보여도 괜찮습니다. 이 실습의 성공 기준은 "색"이 아니라 **태그 구조가 nav → main → (section → article) → footer 순서로 올바른가** 입니다. 브라우저 개발자도구(F12)의 Elements 탭에서 이 중첩 구조가 그대로 보이는지 확인해도 좋습니다.
