# 실습 032 — 색 팔레트와 CSS 변수로 테마 색 관리하기

웹페이지를 만들다 보면 같은 색(예: 파란 버튼, 파란 제목, 파란 머리말)이 여러 군데에 등장합니다. 이때 색을 `#2563eb` 같은 '코드'로 여기저기 직접 적어 두면, 나중에 브랜드 색을 바꾸고 싶을 때 파일 전체를 뒤져 일일이 고쳐야 하고, 하나라도 빠뜨리면 색이 안 맞습니다. **CSS 변수(custom property)** 는 이 문제를 해결합니다. 색에 `--main-color` 같은 **이름표**를 붙여 한곳(`:root`)에 모아 두고, 페이지 곳곳에서는 `var(--main-color)`로 그 색을 **꺼내 쓰기**만 합니다. 그러면 색을 바꾸고 싶을 때 **한 곳의 값만** 고쳐도 페이지 전체 색이 한 번에 바뀝니다. 이번 실습 파일은 `index.html` 하나뿐이고, 서버도 인터넷 연결도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- `:root`에 `--main-color`, `--accent-color`, `--text-color` 같은 **CSS 변수**로 브랜드 색 3~4개를 정의하는 법을 익힌다. (이름 앞에 빼기표 두 개 `--`를 붙이면 변수가 됩니다.)
- 색을 직접 `#...`로 적는 대신 `var(--이름)`으로 **꺼내 쓰는** 흐름을 이해한다. 핵심은 "**한 곳에 정의(`:root`) → 여러 곳에서 사용(`var()`)**" 두 단계입니다.
- 한 변수가 머리말 배경·소제목 글자·버튼 색에서 **함께 재사용**되어 색이 자동으로 통일되고, 변수 한 줄만 바꾸면 페이지 전체 색이 **한꺼번에** 바뀐다는 것을 눈으로 확인한다.

```
1단계(정의): :root { --main-color: #2563eb; }           ← 색에 이름표를 붙여 한곳에 모은다
2단계(사용): .btn { background-color: var(--main-color); } ← 그 이름표를 곳곳에서 꺼내 쓴다
```

| 변수 이름 | 쓰임 | 이 페이지에서 적용된 곳 |
|---|---|---|
| `--main-color` | 주조색(가장 많이 쓰는 대표 색) | 머리말 배경, 소제목 글자, 버튼 |
| `--main-dark` | 메인의 어두운 버전 | 버튼에 마우스 올렸을 때 |
| `--accent-color` | 강조색(가끔 쓰는 포인트) | `NEW` 배지 |
| `--text-color` | 본문 글자색 | 본문 전체 글자 |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다. (인터넷 연결이 필요 없습니다.)
2. "1. 우리 브랜드 색 팔레트"의 **색 견본 4칸**을 봅니다. → 이 네 칸의 색은 전부 CSS 변수로 칠한 것입니다. 코드를 안 봐도 "이 페이지는 이 색들로 통일돼 있구나"를 알 수 있습니다.
3. "2. 같은 색이 곳곳에서 재사용됩니다"를 봅니다. → **소제목 글자색**, 맨 위 **머리말 배경색**, 아래 **버튼 색**이 모두 같은 파랑입니다. 셋 다 `var(--main-color)` 하나에서 나오기 때문입니다. 버튼에 **마우스를 올리면** 조금 더 어두운 파랑(`--main-dark`)으로 바뀝니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어 맨 위 `:root` 안의 `--main-color: #2563eb;`를 `--main-color: #16a34a;`(초록)로 바꿔 저장하고, 브라우저에서 **새로고침(F5)** 합니다. → 머리말 배경, 소제목, 버튼, 색 견본의 첫 칸이 **한꺼번에 초록으로** 바뀝니다. 파일 곳곳을 뒤지지 않고 한 줄만 고쳤다는 점에 주목하세요. 확인했으면 다시 `#2563eb`로 되돌려 보세요.
5. 이번엔 `--accent-color`(주황)를 좋아하는 색 코드로 바꿔 저장·새로고침합니다. → `NEW` 배지의 색만 바뀝니다. 변수마다 '맡은 영역'이 있다는 것을 확인합니다.
6. AI에게 시켜 보기:
   > "이 index.html의 `:root`에 다크모드용 색 세트를 추가하고 싶어. `--main-color`, `--bg-color`, `--surface-color`, `--text-color`를 어두운 테마에 맞는 값으로 바꾼 버전을 제안해줘. HTML 구조는 그대로 두고 `:root`의 색 값만 바꿔서 보여줘."

## 검증법
- **색이 통일됐는지 눈으로 확인**: 머리말 배경, 소제목 글자, 버튼이 모두 같은 색이면 변수가 제대로 재사용되고 있는 것입니다. 색 견본 첫 칸(`--main-color`)과도 같은 색이어야 합니다.
- **'한 곳만 바꾸기' 검증(가장 중요)**: 4번 단계처럼 `:root`의 `--main-color` **한 줄만** 바꿨을 때, 머리말·소제목·버튼·견본이 **모두 함께** 바뀌면 변수가 올바르게 연결된 것입니다. 어느 하나만 색이 안 바뀐다면, 그 부분이 `var(--main-color)` 대신 색 코드를 직접 적고 있다는 뜻입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 버튼(`.btn`)을 클릭한 뒤 오른쪽 `Styles` 패널을 보면 `background-color: var(--main-color)`라고 표시되고, 그 옆에 실제로 계산된 색(작은 네모 견본)이 함께 보입니다. → 변수가 실제 색으로 풀려 적용된 증거입니다.
- **호버 검증**: 버튼에 마우스를 올렸을 때 색이 조금 더 어두워지면 `--main-dark`가 `:hover`에서 제대로 쓰이고 있는 것입니다.
