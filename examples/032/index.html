색 팔레트와 CSS 변수로 테마 색 관리하기

이 페이지의 모든 색은 :root에 모아 둔 변수 한 곳에서 나옵니다.

1. 우리 브랜드 색 팔레트

아래 네 칸의 색은 전부 CSS 변수로 칠해진 것입니다. 코드를 한 줄도 안 봐도, 이 견본만 보면 "이 페이지는 이 색들로 통일돼 있구나"를 알 수 있습니다.

--main-color
--main-dark
--accent-color
--text-color

2. 같은 색이 곳곳에서 재사용됩니다

이 소제목의 글자색, 위 머리말의 배경색, 아래 버튼의 색은 모두 var(--main-color) 하나에서 나옵니다. 그래서 셋이 자동으로 똑같은 파랑으로 맞춰집니다.

가끔 시선을 끌고 싶을 땐 NEW 처럼 강조색(--accent-color)을 살짝 씁니다.

3. 색을 바꾸려면 한 곳만 고치면 됩니다

이 파일을 메모장이나 VS Code로 열어 맨 위 :root 안의 --main-color: #2563eb;를 #16a34a(초록)로 바꿔 저장하고 브라우저를 새로고침(F5) 해 보세요. 머리말 배경, 소제목 글자, 버튼이 한꺼번에 초록으로 바뀝니다. 파일 곳곳을 뒤질 필요가 없다는 것 — 이것이 CSS 변수를 쓰는 이유입니다.
