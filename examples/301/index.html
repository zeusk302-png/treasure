실습 301 — "본인 데이터만" RLS 검증

같은 공개(publishable/anon) 키를 쓰지만, 누구로 로그인했느냐에 따라 보이는 메모가 달라지는 것을 확인합니다. A로 로그인하면 A 메모만, B로 로그인하면 B 메모만 보이고, 남의 메모는 0건으로 막혀야 성공입니다.

① 로그인 / 가입 — 검증을 위해 서로 다른 두 이메일로 계정 2개를 만드세요.

현재 로그인: 로그아웃 상태

가입 시 Supabase 설정에 따라 이메일 인증이 필요할 수 있습니다. 실습용이면 대시보드 Authentication → Providers → Email 에서 "Confirm email"을 잠시 꺼두면 편합니다.

② 메모 추가 — 지금 로그인한 사람 이름으로 한 줄 저장됩니다(user_id 자동 입력).

아직 추가하지 않음

③ 내 메모 조회 — RLS가 "내 줄만" 돌려줍니다.

읽힌 줄 수: -

아직 조회하지 않음
A로 로그인 → 추가 → 조회하면 A 메모만 보입니다.
로그아웃 후 B로 로그인 → 조회하면 A 메모는 안 보이고 0건(또는 B 것만)이 나와야 합니다 = 남의 행 차단 증거.
