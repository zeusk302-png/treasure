AI 도움봇

내가 올린 문서(FAQ·가이드)를 근거로 답하는 AI 챗봇입니다. 로그인부터 API 키 보호, 대화 기록 저장까지 직접 설계했습니다.

🔐

로그인 / 사용자 구분

Supabase Auth로 이메일 로그인을 붙여 사용자마다 자기 대화만 보이도록 분리했습니다.

🛡️

API 키 보호 (서버 중계)

AI 비밀 키를 브라우저에 노출하지 않고, 서버 함수(Edge Function)가 대신 호출하게 만들었습니다.

💬

대화 이력 저장

주고받은 대화를 데이터베이스에 저장해 다시 들어와도 이전 대화를 이어볼 수 있습니다.

📚

문서 기반 답변(RAG)

내가 올린 문서에서 관련 내용을 찾아 그 근거로만 답하게 해, 엉뚱한 답(환각)을 줄였습니다.

사용 기술

HTML / CSS / JavaScript Supabase (DB · Auth) Supabase Edge Function RLS (행 수준 보안) AI 모델 API Vercel 배포 커스텀 도메인 · HTTPS

내가 직접 한 일

  • 채팅 말풍선 UI와 비동기(fetch) 요청 흐름을 설계·구현
  • AI 비밀 키를 프론트에서 분리해 서버 함수로 안전하게 중계
  • RLS 정책으로 "내 데이터는 나만" 보이도록 권한 설계
  • GitHub → Vercel 자동배포 파이프라인 구성
  • vercel.app 기본 주소를 구매한 커스텀 도메인 + HTTPS로 연결

이 프로젝트로 배운 점

  • "공개해도 되는 키"와 "절대 숨겨야 하는 키"의 차이를 코드로 구분
