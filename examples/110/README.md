# 실습 110 — 할 일 목록을 배열로 localStorage에 저장하기 (JSON)

할 일을 여러 개 입력해서 **목록으로 쌓고**, 그 목록을 브라우저에 저장해서 **새로고침해도 사라지지 않게** 만드는 실습입니다.
앞 실습(106)에서는 이름 하나만 저장했다면, 이번에는 **여러 개의 데이터를 '배열'에 담아 한 번에 저장**하는 방법을 배웁니다.

## 목표
- 여러 개의 데이터는 **배열**(예: `["우유 사기", "운동 가기"]`)에 모아서 다룬다는 걸 이해한다.
- 새 할 일을 `배열.push(...)`로 배열 끝에 추가하는 흐름을 익힌다.
- localStorage에는 **글자(문자열)만** 저장된다는 한계를 알고, 배열을 저장하려면
  `JSON.stringify`로 글자로 바꿔 저장하고, 꺼낼 땐 `JSON.parse`로 다시 배열로 되돌린다는 패턴을 익힌다.

> 왜 JSON이 필요한가요?
> localStorage는 배열이나 객체를 그대로 못 받고 "글자"만 받습니다.
> 그래서 `JSON.stringify`로 배열 → 글자, `JSON.parse`로 글자 → 배열로 변환해 주는 한 쌍을 씁니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. 입력칸에 할 일을 적고 **[추가]** 버튼(또는 **Enter** 키)을 누른다 → 아래 목록에 한 줄 추가된다.
3. 할 일을 **3~4개** 더 추가해서 목록이 차곡차곡 쌓이는지 확인한다.
4. 키보드 **F5**(새로고침)를 누른다 → 방금 추가한 할 일들이 그대로 남아 있는지 확인한다.
5. 브라우저 창을 완전히 닫았다가 다시 `index.html`을 열어 본다 → 그래도 목록이 남아 있다.
6. AI에게 시켜 보기:
   > "이 index.html의 할 일 목록에서, 각 할 일 옆에 '삭제' 버튼을 만들어 줘.
   > 삭제하면 배열에서 그 항목을 빼고(`filter`) 다시 저장되도록 해 줘."

  ```text
  - 외부 라이브러리(React, jQuery 등) 없이 순수 HTML + CSS + 자바스크립트만 쓴다.
  ```

  ```text

  - 브라우저 localStorage에 "todos"라는 키로 저장한다.

  - Enter 키로도 추가되게 해 줘.
  왜 JSON.stringify / JSON.parse가 필요한지 주석으로 이유까지 설명해 줘.
  ```

  ```text
  아래 코드 전체를 붙여넣을게. <index.html 코드 붙여넣기>
  ```

## 검증법
- 할 일을 여러 개 추가하면 목록에 줄이 하나씩 늘어나는가?
- 할 일을 추가한 뒤 **새로고침**해도 목록이 그대로 보이는가?
- 빈 칸에서 [추가]를 누르면 "할 일을 입력해 주세요." 경고가 뜨는가?
- 브라우저 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage**에 `todos`라는 항목이 생기고,
  값이 `["우유 사기","운동 가기"]`처럼 **대괄호로 묶인 글자**로 저장돼 있는가?
- (실험) 개발자도구 Local Storage에서 `todos` 값을 직접 지우고 새로고침하면 "아직 할 일이 없어요." 로 바뀌는가?

## 핵심 코드 한 줄로 보기
```js
let todos = [];                 // 여러 데이터를 담는 배열
todos.push("우유 사기");          // 배열 끝에 추가

// 저장: 배열 → 글자
localStorage.setItem("todos", JSON.stringify(todos));

// 꺼내기: 글자 → 배열
const saved = localStorage.getItem("todos"); // "[\"우유 사기\"]"
todos = JSON.parse(saved);                     // ["우유 사기"]
```
