# 실습 236 — 한 장짜리 자기소개 포트폴리오 페이지 만들기

이름·한 줄 소개·연락처가 담긴 **정적 HTML 한 페이지**를 만들어 봅니다. 파일은 단 하나(`index.html`)뿐이고, 서버도 데이터베이스도 필요 없습니다. 메모장만 있어도 됩니다. "정적(static)"이란 누가 봐도 똑같은, 미리 만들어 둔 페이지라는 뜻입니다.

이 실습의 핵심은 **시맨틱 태그**입니다. 시맨틱(semantic) = "의미가 정해진" 이라는 뜻으로, 칸마다 역할이 정해진 이삿짐 상자에 비유할 수 있습니다.

| 태그 | 역할 | 비유 |
|---|---|---|
| `<header>` | 페이지 맨 위, 나를 대표하는 영역 (이름·한 줄 소개) | 명함의 윗부분 |
| `<main>` | 이 페이지의 핵심 본문 (한 페이지에 하나) | 명함의 본문 |
| `<section>` | 비슷한 내용끼리 묶는 칸 (소개 / 연락처) | 본문 안의 소단락 |
| `<footer>` | 페이지 맨 아래 영역 (저작권 등) | 명함 아랫부분 |

`<div>`로 다 만들 수도 있지만, 시맨틱 태그를 쓰면 **사람도 검색엔진도 화면읽기 프로그램도** "여기는 머리, 여기는 본문"이라고 바로 이해합니다.

## 목표
- `<header>` / `<main>` / `<section>` / `<footer>` 시맨틱 태그로 페이지를 의미 있는 칸으로 나눈다.
- 제목은 위계 순서대로(`<h1>` → `<h2>`) 쓴다는 규칙을 익힌다. (`<h1>`은 페이지에 하나, 이름에 사용)
- 연락처처럼 항목이 여러 개인 정보는 목록(`<ul>`/`<li>`)과 링크(`<a>`, `mailto:`)로 표현한다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 자기소개 페이지가 열립니다.
2. 화면에 큰 이름(`<h1>`), 그 아래 한 줄 소개, "소개"와 "연락처" 두 묶음이 보이는지 확인합니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어 다음을 **내 정보로** 바꿔 저장합니다.
   - `<h1>홍길동</h1>` → 내 이름
   - `class="tagline"` 문단 → 나를 한 줄로 표현하는 문장
   - 연락처 목록의 이메일·GitHub 주소 → 실제 내 주소
   - `<title>` 안 글자 → "내이름 — 자기소개" (이건 브라우저 **탭** 이름)
4. 브라우저로 돌아와 **새로고침(F5)** → 바뀐 내용이 반영되는지 확인합니다.
5. (선택) AI에게 한 칸만 더 부탁해 보기. 한 단계짜리 미니 프로젝트라 욕심내지 말고 딱 한 섹션만 추가합니다.
   > "이 index.html의 `<main>` 안에, '관심 분야'라는 `<section>`을 하나 더 추가해줘. `<h2>`와 점 목록(ul, li) 3개로. 나머지는 그대로 둬."

## 검증법
- 화면에 이름(`<h1>`) → 한 줄 소개 → 소개 → 연락처 순서로 보이는가?
- 브라우저 **탭 제목**(`<title>`)과 화면 안 큰 제목(`<h1>`)이 서로 다른 위치에 나오는 것을 확인했는가?
- 연락처의 이메일을 클릭하면 메일 작성 창이 뜨는가? (`mailto:` 링크 동작 확인)
- 브라우저에서 `F12 → Elements` 탭을 열어, `<body>` 안에 `<header>` · `<main>` · `<footer>`가 **나란히** 들어 있고, `<main>` 안에 `<section>` 두 개가 들어 있는 구조를 눈으로 확인한다.
- (선택) 한글이 깨져 보인다면 `<meta charset="UTF-8" />` 줄이 빠지지 않았는지 본다.
