# 실습 164 — 여러 외부 API를 엮은 'AI 여행 한 컷' 미니앱 완성하기

도시 이름 하나를 넣으면 **날씨·지도·사진·AI 추천 한마디**가 한 화면에 뜨는 작은 웹앱을 만듭니다. 이 실습은 지금까지 배운 것을 모으는 **종합 캡스톤**입니다. 핵심은 두 가지입니다.

1. **여러 외부 연동을 '하나의 흐름'으로 묶기** — 위치 찾기 → (날씨 + 사진) 동시 호출 → AI 코멘트를, 한 서버 함수가 차례로/동시에 처리해 한 장의 결과로 모읍니다.
2. **부분 실패를 견디게 설계하기** — 사진 API 하나가 죽어도 날씨와 AI 코멘트는 그대로 나오게 합니다. 받은 조각만 화면에 보여 주고, 못 받은 조각은 조용히 비웁니다.

> 비유: 한 명의 '여행 비서'(서버 함수)에게 도시 이름만 말하면, 비서가 ① 지도에서 위치를 찾고, ② 날씨와 ③ 사진을 **동시에** 알아보러 보내고, ④ 그 정보를 모아 AI에게 "오늘 한마디 부탁해"라고 시킨 뒤, ⑤ 모은 것을 한 장으로 정리해 돌려줍니다. 심부름꾼 하나가 빈손으로 와도, 비서는 나머지로 보고서를 완성합니다.

> 보안 메모 — 공개해도 되는 값 vs 절대 숨길 값
> - **공개되어도 되는 값**: 키가 필요 없는 **공개 API**(이 앱의 날씨·지오코딩·지도·사진), Supabase의 `anon`(공개) 키 등. 브라우저 코드에 들어가도 괜찮습니다. (단, 데이터 보호는 **RLS**가 책임집니다.)
> - **절대 노출하면 안 되는 비밀값**: 과금되는 **Claude 키**(`sk-ant-...`), Supabase의 `service_role` 키 등. **브라우저 코드에 절대 넣지 않습니다.** `service_role` 키는 RLS를 **무시하고** 모든 데이터에 접근하므로, 오직 **서버(또는 n8n의 자격증명 저장소)**에서만 다룹니다.
> - 이 앱에서 비밀이 필요한 곳은 **AI 코멘트(Claude) 한 군데뿐**입니다. 그래서 비밀 키도 `ANTHROPIC_API_KEY` 하나만 환경변수에 둡니다. 예제에 적을 때조차 진짜 키 대신 `sk-ant-...` 같은 **자리표시자**만 둡니다. (이 폴더의 `.env.example`이 그 예시입니다.)

## 목표
- **여러 API를 한 흐름으로 묶기**: 도시 이름 하나로 지오코딩(위치) → 날씨 → 사진 → 지도 → AI 코멘트까지, 서로 다른 외부 서비스를 한 서버 함수가 조립한다.
- **병렬 호출 익히기**: 날씨와 사진은 서로 기다릴 필요가 없으므로 `Promise.allSettled`로 **동시에** 부른다(차례로 부르는 것보다 빠르다).
- **부분 실패 견디기**: 한 조각이 실패해도 전체를 멈추지 않는다. 실패한 조각만 비우고, 나머지는 살려서 200으로 돌려준다. 브라우저는 받은 것만 그린다.
- **AI를 한 기능으로 부리기**: Claude를 "대화 상대"가 아니라 '여행 한마디 생성 부품'으로 붙인다. 코멘트 규칙(프롬프트)은 서버에 고정한다.
- **비밀 키를 코드가 아니라 환경변수에**: 서버는 `process.env.ANTHROPIC_API_KEY`로만 키를 읽고, 진짜 값은 **Vercel > Settings > Environment Variables**에 둔다. 브라우저에는 키가 없다.

## 따라하는 단계

### A. 먼저 구조부터 코드로 확인 (배포 없이도 가능)
1. `index.html`을 브라우저로 그냥 열어 봅니다. 입력칸·버튼은 보이지만, [여행 한 컷 만들기]를 누르면 실패합니다. → 정상입니다. **두뇌(서버 `/api/travel-snapshot`)**가 아직 안 돌고 있기 때문입니다.
2. `api/travel-snapshot.js`(서버 함수)를 엽니다. 흐름을 위에서 아래로 읽습니다.
   - **1단계 지오코딩**: 도시 이름 → 위도·경도. 이게 있어야 날씨·지도를 부를 수 있습니다. (키 없는 공개 API)
   - **2단계 병렬 호출**: `const tasks = [...]`에 날씨·사진 호출을 담고 `await Promise.allSettled(tasks)`로 **동시에** 기다립니다. 하나가 실패해도 멈추지 않습니다.
   - **3단계 AI 코멘트**: 모은 정보(`factLine`)를 Claude에 보내 한마디를 받습니다. 코멘트 규칙(`COMMENT_SYSTEM_PROMPT`)은 코드에 고정돼 있습니다.
   - **부분 실패 처리**: 각 호출이 `.catch(...)`로 감싸여, 실패하면 `result.errors`에 메시지만 넣고 그 조각은 `null`로 둡니다. 마지막엔 무조건 `200`으로 돌려줍니다.
   - `const apiKey = process.env.ANTHROPIC_API_KEY;` — 비밀 키를 **직접 안 적고** 환경변수에서만 읽고, `x-api-key` 헤더는 **이 서버 함수 안에서만** 붙습니다.
3. `script.js`(브라우저)를 엽니다. `fetch`가 보내는 건 `{ city }`(도시 이름)뿐이고 **키는 보내지 않는다**는 점, `PROXY_URL = "/api/travel-snapshot"`만 부른다는 점, `render()`가 **있는 조각만 보여 주고 없는 조각은 숨긴다**(`showOrHide`)는 점을 확인합니다.
4. `.env.example`을 엽니다. **진짜 키가 아니라 자리표시자**만 있습니다. 필요한 환경변수가 `ANTHROPIC_API_KEY` 하나뿐임을 확인합니다(나머지 API는 공개라 키가 없음).

### B. 로컬에서 실제로 돌려 보기 (Vercel CLI)
5. 이 폴더에서 터미널을 열고 Vercel CLI를 설치합니다(한 번만): `npm i -g vercel`
6. `.env.example`을 복사해 `.env` 파일을 만들고, `ANTHROPIC_API_KEY=` 뒤에 **진짜 Claude 키**를 적습니다. (`.gitignore` 덕분에 `.env`는 절대 깃에 올라가지 않습니다.)
7. `vercel dev`를 실행하고, 안내된 주소(보통 `http://localhost:3000`)를 엽니다.
8. 도시 이름(예: `부산`, `Tokyo`)으로 **[여행 한 컷 만들기]**를 누릅니다. 위치·날씨·지도·사진·AI 한마디가 한 화면에 뜨면, "여러 API → 하나의 흐름" 조립이 동작한 것입니다.

### C. 부분 실패를 일부러 만들어 보기 (이 실습의 하이라이트)
9. **AI만 끄기**: `.env`의 `ANTHROPIC_API_KEY` 값을 잠깐 비우거나 가짜로 바꾼 뒤 다시 호출합니다. → 날씨·지도·사진은 그대로 뜨고, **AI 한마디만 비고** 아래 '일부 정보를 못 가져왔어요'에 이유가 표시됩니다. (다른 조각은 안 죽습니다.)
10. **이상한 도시 넣기**: `asdfqwer` 같은 없는 도시를 넣어 봅니다. → 위치를 못 찾으니 날씨·지도는 비지만, 앱은 죽지 않고 "위치를 찾지 못했어요" 안내를 보여 줍니다. 확인 후 `.env`의 키를 원래대로 되돌립니다.

### D. Vercel에 배포하기 (인터넷에 올리기)
11. 이 폴더의 파일들을 GitHub 저장소에 올리고, Vercel에서 **Import** 합니다. (저장소 연결·배포 과정은 실습 169 참고.)
12. 배포 설정 화면에서 **Environment Variables**에 `ANTHROPIC_API_KEY = sk-ant-...`(진짜 키)를 추가합니다. **코드 파일이 아니라 이 화면에만** 키를 넣는 것이 핵심입니다.
13. **Deploy**를 누르고, 받은 `...vercel.app` 주소를 열어 다시 여행 한 컷을 만들어 봅니다. 키를 코드에 안 넣었는데도 정상 작동하면 성공입니다.

> 자주 막히는 곳: ① 환경변수를 추가한 **뒤에 다시 배포**해야 적용됩니다. ② 변수 이름은 코드와 **정확히 같게**(`ANTHROPIC_API_KEY`) 적어야 합니다. ③ `api/travel-snapshot.js`는 반드시 `api/` 폴더 안에 있어야 Vercel이 `/api/travel-snapshot` 함수로 인식합니다.

### E. (선택) n8n으로 같은 창구 만들기
14. `workflow.json`을 n8n에 **Import**합니다. `Webhook → (지오코딩 → 날씨) → Claude → Respond` 흐름이 보입니다. 코멘트 규칙은 Claude 노드의 `system` 필드에 고정돼 있습니다.
15. n8n의 **Credentials**에서 **Header Auth** 자격증명을 만들어 `Name = x-api-key`, `Value = sk-ant-...`(진짜 키)로 저장하고, **Claude 코멘트** 노드에 연결합니다. → 키는 워크플로우 JSON이 아니라 **자격증명 저장소**에만 들어갑니다.

  ```text
  목표: 도시 이름 하나를 입력하면 '날씨·지도·사진·AI 한마디'를 한 화면에 모아 보여 주는 '여행 한 컷' 미니앱.

  - 프론트(index.html / style.css / script.js): 비밀 키를 절대 두지 않는다. 브라우저는 외부 API를 직접 부르지 않고, 우리 서버 함수 /api/travel-snapshot 에만 도시 이름({ city })만 POST 한다.

  코드만 주지 말고 각 부분이 무엇이고 왜 그렇게 했는지 한국어 주석으로 한 줄씩 풀어서 설명해 줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  이제 서버 함수 api/travel-snapshot.js 의 실제 로직을 채워 줘.
  흐름: ① 지오코딩(도시 이름 → 위도·경도, 키 없는 Open-Meteo 공개 API) → ② 날씨와 ③ 사진을 Promise.allSettled 로 '동시에'(병렬) 호출 → ④ 모은 정보를 Claude(claude-opus-4-8)에게 보내 '그날의 한마디'를 받기.
  ```

## 검증법
- **한 화면에 다 모이나**: 도시를 넣었을 때 위치 제목·날씨·기온·지도·사진·AI 한마디가 한 카드에 함께 뜨는가?
- **AI 한마디가 날씨와 어울리나**: 비 오는 도시면 "우산을 챙기세요" 같은 날씨 맞춤 팁이 한마디에 자연스럽게 섞여 나오는가? (코멘트 규칙은 서버 `system`에 고정돼 있어 사용자가 못 바꿉니다.)
- **부분 실패를 견디나 (핵심)**: 단계 9처럼 AI 키만 비워도 **날씨·지도·사진은 그대로** 뜨고 AI 한마디만 비는가? 단계 10처럼 없는 도시를 넣어도 앱이 **죽지 않고** 안내만 보이는가? 못 받은 조각의 이유가 '일부 정보를 못 가져왔어요'에 표시되는가?
- **동시에(병렬) 부르나**: <kbd>F12</kbd> → **Network** 탭에서 보면, 브라우저가 부르는 건 `travel-snapshot` **한 번뿐**입니다. (여러 외부 호출은 서버가 안에서 동시에 처리합니다.)
- **소스 보기로 키 흔적 찾기**: <kbd>Ctrl</kbd>+<kbd>U</kbd>로 `index.html`·`script.js`를 열어 **`sk-ant-`로 시작하는 글자가 단 하나도 없는지** 확인한다. 페이지의 **[이 페이지의 JS에서 키 흔적 검사하기]** 버튼이 자동 검사 → "안전" 초록 표시가 떠야 정상.
- **요청 대상 확인**: Network 탭의 그 요청 대상이 `api.anthropic.com`이나 `open-meteo.com`이 **아니라** 우리 사이트의 `/api/travel-snapshot`인가? 브라우저는 외부 API를 직접 부르지 않습니다.
- **배포 산출물 검사**: 터미널에서 이 폴더를 검사한다 → `grep -r "sk-ant-" . --exclude-dir=node_modules` 결과가 **하나도 안 나와야** 정상이다. (`.env`는 `.gitignore`로 빠지고, `.env.example`엔 자리표시자만 있다.)

## 파일 구성
- `index.html` / `style.css` / `script.js` — 브라우저(프론트). **비밀 키 없음.** 도시 이름만 `/api/travel-snapshot`으로 보내고, 받은 조각만 화면에 그린다(부분 실패 견디기).
- `api/travel-snapshot.js` — Vercel 서버리스 함수(두뇌). 지오코딩→(날씨+사진 병렬)→AI 코멘트를 한 흐름으로 묶고, 실패한 조각만 비워 200으로 돌려준다. 여기서만 `process.env.ANTHROPIC_API_KEY`로 키를 꺼낸다.
- `.env.example` — 필요한 환경변수 견본(자리표시자만). `.env`는 따로 만들어 진짜 키를 넣고 커밋하지 않는다.
- `.gitignore` — `.env` 등 비밀 파일이 깃에 안 올라가게 막는다.
- `vercel.json` — Vercel 설정(선택). 비밀값은 절대 여기 넣지 않는다.
- `workflow.json` — (선택) 같은 창구를 n8n으로 만든 버전. 키는 n8n 자격증명에만 둔다.
