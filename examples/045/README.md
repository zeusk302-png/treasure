# 045. 오른쪽 아래 떠 있는 플로팅 액션 버튼(FAB)

스마트폰 앱이나 웹사이트를 보면 화면 **오른쪽 아래 모서리에 동그란 버튼**이 떠 있는 걸 자주 봅니다. 카카오톡의 새 채팅 버튼, 블로그의 '글쓰기' 버튼, '맨 위로 가기' 버튼 같은 것들이죠. 이렇게 화면 모서리에 둥둥 떠서 **스크롤을 내려도 항상 같은 자리에 머무는 둥근 버튼**을 FAB(Floating Action Button, 플로팅 액션 버튼)라고 부릅니다. 이번 실습에서는 단 한 가지 핵심 도구로 이 버튼을 만듭니다. 바로 `position: fixed`(화면에 딱 고정해라) 입니다. 여기에 `right`/`bottom`(어느 모서리에서 얼마나 떨어질지)을 짝으로 써서 위치를 정합니다.

## 목표

- `position: fixed`가 **본문이 아니라 화면(브라우저 창)을 기준으로 요소를 고정한다**는 동작을 이해한다.
- `fixed`는 `right`/`bottom`(또는 `left`/`top`) **위치 값과 짝으로** 써야 원하는 모서리에 붙는다는 것을 익힌다.
- `width`·`height`를 같게 주고 `border-radius: 50%`로 **완전한 원** 모양을 만드는 법을 익힌다.
- `z-index`로 버튼을 본문 위 층에 올려 **항상 보이게** 하는 법을 익힌다.
- 044에서 배운 `position: sticky`(평소엔 제자리, 닿으면 붙음)와 `fixed`(처음부터 둥둥 떠 있음)의 **차이**를 구분한다.

## 따라하는 단계

1. `index.html`과 `style.css`가 **같은 폴더(045)** 안에 있는지 확인합니다. HTML 위쪽의 `<link rel="stylesheet" href="style.css" />` 한 줄이 두 파일을 연결해 줍니다.
2. `index.html`을 더블클릭해 브라우저(크롬 등)로 엽니다. 본문이 보이고, 화면 **오른쪽 아래에 보라색 둥근 `+` 버튼**이 떠 있으면 준비 완료입니다.
3. 마우스 휠이나 스크롤바로 **페이지를 아래로 천천히 내려 봅니다.** 본문 글은 위로 흘러 올라가지만, 오른쪽 아래 버튼은 화면의 **같은 자리에 그대로 떠 있는 것**을 확인합니다. 이것이 `fixed`의 핵심 동작입니다.
4. 버튼을 클릭해 봅니다. "FAB가 눌렸습니다!"라는 알림창이 뜨면 버튼이 정상 동작하는 것입니다. (실제 서비스라면 이 자리에 글쓰기 화면 열기 등의 기능이 들어갑니다.)
5. `style.css`의 `.fab` 안에 있는 핵심 값을 직접 바꿔보며 원리를 확인합니다. (확인 후 꼭 원래대로 되돌리세요.)
   - `position: fixed;`를 잠깐 `static`으로 바꾸면 → 버튼이 더 이상 떠 있지 않고 본문 흐름 속(맨 아래)으로 들어가, 스크롤하면 같이 움직입니다. → `fixed`가 "화면에 고정하는 스위치"임을 알 수 있습니다.
   - `right: 24px;`를 `left: 24px;`로 바꾸면 → 버튼이 오른쪽 아래에서 **왼쪽 아래**로 옮겨 갑니다. → `right`/`left`가 "가로로 어느 쪽 모서리에 붙을지"를 정하는 값임을 알 수 있습니다.
   - `bottom: 24px;`를 `bottom: 100px;`로 바꾸면 → 버튼이 화면 아래에서 **더 위로** 떠오릅니다. → `bottom`이 "아래 모서리에서 얼마나 떨어질지"를 정하는 값임을 알 수 있습니다.
   - `border-radius: 50%;`를 잠깐 `0`으로 바꾸면 → 동그라미가 **네모**로 바뀝니다. → `50%`가 원을 만드는 비결임을 알 수 있습니다.
6. (이해 포인트) 044의 `sticky`와 비교해 봅니다. `sticky`는 평소엔 자기 자리에 있다가 스크롤이 닿을 때만 붙지만, `fixed`는 **페이지 맨 위에서부터 끝까지 처음부터 줄곧 화면에 떠 있다**는 점이 다릅니다.

> 참고: `fixed` 효과는 '스크롤할 거리'가 있어야 눈에 잘 띕니다. 그래서 예제 본문은 일부러 화면보다 길게 만들었습니다. 별도 이미지나 인터넷 연결 없이 `index.html`만 열어도 바로 동작합니다.

## 검증법

- 브라우저로 `index.html`을 열면 화면 **오른쪽 아래에 보라색 둥근 `+` 버튼**이 보인다.
- 페이지를 위아래로 스크롤해도 버튼은 **항상 화면의 같은 자리(오른쪽 아래)** 에 그대로 떠 있다.
- 버튼이 **완전한 원** 모양이고, 마우스를 올리면 살짝 커지며 그림자가 진해진다.
- 버튼을 클릭하면 "FAB가 눌렸습니다!" 알림창이 뜬다.
- 개발자도구(F12) > Elements에서 `.fab`를 선택하면 `position: fixed`, `right: 24px`, `bottom: 24px`, `border-radius: 50%`, `z-index: 1000`이 적용된 것을 확인할 수 있다.
- 브라우저 창 너비를 모바일 크기(480px 이하)로 줄이면 버튼이 조금 작아지고 모서리에 더 가깝게 붙는다.

### 흔한 실수 체크

- `position: fixed`만 쓰고 `right`/`bottom`을 안 적으면, 버튼이 원하는 모서리가 아니라 **원래 있던 자리에 그대로 떠 버립니다.** `fixed`는 항상 위치 값과 **짝**으로 써야 합니다.
- `width`와 `height`를 **다른 값**으로 주면 `border-radius: 50%`를 줘도 원이 아니라 **타원(럭비공 모양)** 이 됩니다. 정원을 원하면 두 값을 같게 주세요.
- `z-index`를 빼면, 본문에 그림자나 배경이 진한 요소가 있을 때 버튼이 그 아래로 **가려질 수 있습니다.** FAB는 항상 맨 위에 보여야 하므로 큰 `z-index` 값을 줍니다.
