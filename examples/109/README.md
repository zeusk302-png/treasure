# 실습 109 — 한 줄 메모장: 글 저장하고 지우기 버튼

`textarea`에 쓴 메모를 **[저장]** 버튼으로 브라우저에 넣고, **[지우기]** 버튼으로 다시 없애는 실습입니다.
앞 실습(108)에서 "숫자"를 다뤘다면, 이번에는 **글(텍스트)을 저장하고 삭제하는 짝**을 직접 경험하는 게 목표예요.
핵심은 딱 두 가지, **저장은 `setItem`, 삭제는 `removeItem`** 입니다.

## 목표
- `localStorage.setItem(키, 값)` 으로 입력한 글을 브라우저에 **저장**한다.
- `localStorage.removeItem(키)` 으로 저장한 글을 **삭제**한다.
- 페이지를 새로고침하거나 창을 닫았다 다시 열어도, 저장한 메모가 **그대로 남아 있는** 것을 확인한다.

> setItem 과 removeItem 은 짝꿍입니다.
> `setItem("myMemo", "내용")` 은 "myMemo"라는 **이름표(키)** 에 글자를 넣는 것이고,
> `removeItem("myMemo")` 은 그 이름표에 넣어 둔 것을 **통째로 빼는** 것입니다.
> 그래서 저장할 때와 지울 때 **같은 이름표(키)** 를 써야 합니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. 입력칸에 아무 메모나 한 줄 적고 **[저장]** 을 누른다 → "저장했어요" 안내가 뜬다.
3. 키보드 **F5**(새로고침)를 눌러 본다 → 적었던 메모가 사라지지 않고 그대로 다시 채워지는지 확인한다.
4. 브라우저 창을 완전히 닫았다가 다시 `index.html`을 열어 본다 → 여전히 메모가 남아 있는지 확인한다.
5. **[지우기]** 를 누른 뒤 새로고침한다 → 입력칸이 빈 칸으로 시작하는지 확인한다.
6. AI에게 시켜 보기:
   > "이 index.html에서 메모를 저장할 때 '저장한 시각'도 함께 localStorage에 넣어서, 메모 아래에 '마지막 저장: 오후 3시 12분' 처럼 보여 주는 기능을 추가해줘."

## 검증법
- **[저장]** 후 새로고침(F5)했을 때, 적었던 메모가 그대로 다시 나타나는가?
- 브라우저 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage** 에 `myMemo` 항목이 생겼고, 그 값이 내가 적은 글과 같은가?
- **[지우기]** 를 누르면 Local Storage 목록에서 `myMemo` 항목이 사라지는가? (이게 `removeItem`의 효과)
- **[지우기]** 후 새로고침하면 입력칸이 빈 칸으로 시작하는가?

## 핵심 코드 한 줄로 보기
```js
const text = memoEl.value;                 // 입력칸에 적은 글자를 꺼내기
localStorage.setItem("myMemo", text);      // ★ 저장: "myMemo" 이름표에 글자 넣기
localStorage.getItem("myMemo");            // 꺼내기: 저장해 둔 글자 다시 읽기 (없으면 null)
localStorage.removeItem("myMemo");         // ★ 삭제: "myMemo" 이름표 통째로 빼기
```
