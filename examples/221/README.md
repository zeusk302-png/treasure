# 221. AI에게 "내가 안 물어봐도 놓치기 쉬운 위험 5가지" 먼저 말하게 하기

## 목표

"방문자 이메일을 받는 랜딩 페이지"를 **만들기 전에**, 내가 **물어볼 줄도 몰랐던** 위험을
**AI가 자발적으로 먼저 5개** 꺼내 놓게 만들고, 그중 막을 것을 골라 `PLAN.md`에 반영하는 연습입니다.

비전공자에게 가장 무서운 건 "내가 틀린 것"이 아니라
**"존재하는 줄도 몰라서 *아예 묻지도 못한* 것"** 입니다. (이걸 Unknown Unknowns라고 합니다.)
예를 들어 "이메일 받는 폼 만들어줘"라고만 하면, AI는 폼은 잘 만들지만
**보안(누가 데이터를 보나)·개인정보(동의받았나)·비용(요금이 새나)** 같은 숨은 위험은
**알아서 경고하지 않습니다.** 그래서 이번엔 AI를 **"먼저 위험을 경고하는 감리자"** 로 부립니다.

이 실습에는 새로 짤 코드가 없습니다. **AI에게서 숨은 위험을 끌어내는 질문 설계**가 곧 실습입니다.

이 폴더의 파일은 넷입니다.

- [`prompt.md`](prompt.md) — AI를 "위험 감리자"로 만드는, 그대로 붙여넣는 지시 프롬프트
- [`conversation.md`](conversation.md) — AI가 위험 5개를 먼저 짚어준 대화 캡처(예시)
- [`RISKS.md`](RISKS.md) — **이 실습의 결과물 ①.** AI가 먼저 제시한 숨은 위험 5개 목록
- [`PLAN.md`](PLAN.md) — **이 실습의 결과물 ②.** 그 위험을 "막을 것 / 미룰 것"으로 반영한 기획서
- `README.md` — 지금 읽는 이 안내문

## 따라하는 단계

1. [`prompt.md`](prompt.md)를 열어 **1단계 지시 프롬프트**를 통째로 복사합니다. 핵심 제약은 "지금은 코드/만드는 법 말고, 네가 알아서 위험 5개를 먼저 짚어라. 보안·개인정보·비용은 꼭 포함"입니다.
2. 복사한 프롬프트를 실제 Claude(또는 쓰는 AI)에 붙여넣습니다.
3. AI가 **만드는 법을 설명하지 않고 위험부터 5개** 짚는지 봅니다. 각 위험에 "그냥 두면 무슨 일이 나는지"와 "첫 버전 최소 대비책 1줄"이 붙어 있어야 합니다.
4. 만약 AI가 위험을 건너뛰고 **바로 폼 만드는 법을 뱉으면**, [`prompt.md`](prompt.md)의 **2단계 한 마디**("아직 만드는 법 안 물었어, 위험부터 5개")로 다시 잡아 줍니다.
5. 받은 위험 5개를 사람이 한 줄씩 읽고 **"이게 정말 내 사이트에 해당하나?"** 를 판단해, [`RISKS.md`](RISKS.md)처럼 정리합니다. (특히 위험 3의 **공개 키 vs 비밀 키** 구분은 꼭 확인)
6. [`prompt.md`](prompt.md)의 **3단계 한 마디**로 그 위험을 `PLAN.md`에 반영하도록 요청합니다. "첫 버전에 막을 것 / 다음으로 미룰 것"으로 나누는 게 핵심입니다.
7. AI가 만든 초안을 같은 폴더의 [`PLAN.md`](PLAN.md)처럼 **내 결정으로 바꿔** 저장합니다. 안 정한 건 **"더 확인할 것"** 으로 남깁니다.
8. **가장 중요한 마무리:** 위험을 **부풀려 겁주거나, 반대로 중요한 걸 빠뜨린 곳**이 없는지 사람이 직접 검토합니다. 이메일은 개인정보라서 "동의받았나 / 어디 저장되나 / 누가 볼 수 있나"는 반드시 한 번 짚고 넘어갑니다.

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] AI가 **코드/만드는 법을 바로 설명하지 않고**, 먼저 **위험 5개**를 짚었다.
- [ ] 5개 안에 **보안·개인정보·비용**이 모두 포함됐다.
- [ ] 각 위험에 **(그냥 두면 무슨 일이 나는지)** 와 **(첫 버전 최소 대비책 1줄)** 이 붙어 있다.
- [ ] [`RISKS.md`](RISKS.md)에 위험 5개가 정리되고, 각 위험에 **"내 경우에 해당하나"** 를 사람이 표시했다.
- [ ] [`PLAN.md`](PLAN.md)에 위험이 **"첫 버전에 막을 것 / 다음으로 미룰 것"** 으로 나뉘어 들어갔다.
- [ ] 위험 3에서 **공개 키(anon, 공개해도 됨)** 와 **비밀 키(service_role, 절대 프론트/깃허브 금지)** 를 정확히 구분했다.
- [ ] 안 정한 것은 억지로 채우지 않고 **"더 확인할 것"** 에 남겼다.

> 빠르게 자가 점검: 받은 위험 목록만 보고 **"첫 버전에서 뭘 먼저 막아야 하는지 한눈에 보이면"** 통과입니다.
> "그래서 뭐가 위험한 거지?"가 안 잡히면, AI에게 "더 쉽게, 내 규모 기준으로 다시 5개" 라고 다시 시키세요.
