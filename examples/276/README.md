# 실습 276 — 닫는 태그 빠진 HTML 고치기 (화면이 통째로 기울어진 페이지)

> **디버깅 챌린지 (난이도 1)** · 분류: 디버깅 챌린지 · 개념: HTML 태그 짝, 마크업 구조

이 폴더에는 **일부러 고장 낸 파일**(`broken.html`)과 **고친 정답 파일**(`index.html`)이 들어 있습니다.
먼저 `broken.html`을 열어 무엇이 이상한지 직접 찾아보고, 그다음 `index.html`과 비교하세요.

> **한 줄 메모(무엇이 빠졌나):** 첫 번째 `<div class="card">` 를 닫아 주는 `</div>` 한 개가 빠져 있었습니다. 그래서 뒤따라오는 모든 상자가 첫 카드 **안으로 빨려 들어가** 레이아웃이 계단처럼 어긋났습니다.

## 목표
- HTML의 거의 모든 상자 태그는 **여는 태그(`<div>`)와 닫는 태그(`</div>`)가 한 짝**이라는 것을 이해한다.
- 닫는 태그 하나가 빠지면 **그 뒤의 내용이 통째로 안쪽으로 밀려 들어간다**는 현상을 눈으로 확인한다.
- 브라우저 개발자도구(F12)로 실제 화면 구조를 열어 보고, **어디서 상자가 안 닫혔는지** 찾는 법을 익힌다.

### 비유로 이해하기
`<div>`는 **상자**, `</div>`는 그 **상자의 뚜껑**입니다.
첫 번째 상자(메뉴 카드)에 뚜껑을 안 닫고 그 위에 두 번째 상자(찾아오는 길)를 올리면,
두 번째 상자가 첫 번째 상자 **안에** 들어가 버립니다. 안에 들어간 상자는 또 안쪽 여백(padding)을 받아
오른쪽으로 한 칸 더 밀려, 화면이 계단처럼 기울어 보입니다.

## 따라하는 단계
1. `broken.html`을 **더블클릭**해서 브라우저로 엽니다. → '찾아오시는 길' 카드가 '오늘의 메뉴' 카드 **안쪽으로** 들어가 한 칸 밀려 보입니다.
2. `F12`를 눌러 개발자도구를 열고 **Elements(요소)** 탭을 봅니다. 두 번째 `.card`가 첫 번째 `.card`의 **자식**으로 들어가 있는(들여쓰기가 더 깊은) 것을 확인합니다.
3. `broken.html`을 메모장이나 VS Code로 엽니다.
4. `<h2>오늘의 메뉴</h2>` 가 있는 첫 번째 카드를 찾고, 그 카드가 **어디서 닫혀야 하는지** 생각합니다. → 메뉴 가격 `<p>` 바로 다음 줄에서 닫혀야 합니다.
5. 가격 문단(`<p>...4,500원...</p>`) 바로 아래에 **`</div>` 한 줄을 추가**합니다.
6. 저장하고 브라우저에서 **새로고침(F5)** → 두 카드가 위아래로 나란히 정렬되면 성공입니다.
7. 정답이 궁금하면 같은 폴더의 `index.html`을 열어 내 수정과 비교합니다.
8. AI에게 검토 시켜 보기:
   > "이 HTML에서 여는 태그와 닫는 태그 짝이 맞는지 검사해줘. 짝이 안 맞는 태그가 있으면 몇 번째 줄인지 알려줘."

## 검증법
- 고친 뒤 `index.html`(또는 수정한 `broken.html`)에서 **두 카드(메뉴 / 찾아오는 길)가 같은 너비로 위아래로 정렬**되는가? (한쪽이 오른쪽으로 밀려 있지 않은가)
- `F12 → Elements`에서 두 개의 `.card`가 **서로 형제(같은 들여쓰기 단계)**로, 둘 다 `.container` 안에 나란히 들어 있는가? (한쪽이 다른 쪽 안에 들어가 있으면 아직 안 고쳐진 것)
- 여는 `<div>` 개수와 닫는 `</div>` 개수가 같은지 세어 본다. (이 페이지는 `.container` 1개 + `.card` 2개 = 여는 `<div>` 3개, 닫는 `</div>`도 3개여야 한다.)
- (보너스) VS Code라면 여는 `<div>`에 커서를 두면 짝이 되는 `</div>`가 함께 강조됩니다. 짝을 못 찾으면 닫는 태그가 빠진 것입니다.
