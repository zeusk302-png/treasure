# required로 필수 입력 막기 (빈 칸이면 제출 안 됨)

빈 칸으로는 폼이 제출되지 않도록, HTML의 `required` 속성 하나로 막아보는 실습입니다. JavaScript를 한 줄도 쓰지 않아도 브라우저가 알아서 검사하고 안내 풍선을 띄워줍니다.

## 목표

- `required` 속성을 붙인 입력란은 비워두면 제출이 막힌다는 것을 직접 확인한다.
- "코드로 검사하기 전에 브라우저가 먼저 막아주는" HTML 기본 검증(HTML5 validation)의 개념을 익힌다.
- 필수 항목(`required`)과 선택 항목(속성 없음)의 차이를 눈으로 비교한다.

## 따라하는 단계

1. `index.html` 파일을 더블클릭해서 웹 브라우저로 엽니다. (별도 설치나 서버가 필요 없습니다.)
2. 아무것도 입력하지 않은 상태에서 파란색 **가입하기** 버튼을 눌러봅니다.
3. 첫 번째 빈 칸(이름) 옆에 "이 입력란을 작성하세요" 같은 안내 풍선이 뜨고, 제출이 막히는 것을 확인합니다. 이것이 `required`의 효과입니다.
4. 이름만 입력하고 다시 눌러봅니다. 이번엔 이메일 칸에서 막힙니다. 즉, 필수 칸을 하나씩 채워야 다음으로 넘어갑니다.
5. 이메일 칸에 `abc`처럼 형식에 안 맞는 값을 넣고 눌러봅니다. `type="email"`이라서 "@를 포함하라"는 안내가 추가로 뜹니다.
6. **가입 이유** 칸(선택 항목)은 비워둔 채로 둡니다. 이 칸에는 `required`가 없으므로 비어 있어도 제출을 막지 않습니다.
7. 이름·이메일·지역 3개 필수 항목을 모두 채우고 버튼을 누르면 "가입 완료!" 초록 메시지가 나타납니다.
8. `index.html`을 열어 `<input ... required />`에서 `required` 글자를 지운 뒤 저장하고 새로고침해, 그 칸이 더 이상 제출을 막지 않는 것을 확인해봅니다. (확인 후 다시 되돌려 두세요.)

## 검증법

- 모든 칸이 빈 상태로 **가입하기**를 누르면 제출되지 않고 첫 빈 칸에 안내 풍선이 뜬다 → `required`가 작동하는 것입니다.
- 필수 항목(이름·이메일·지역)을 모두 채우면 초록색 "가입 완료!" 메시지가 보인다.
- 선택 항목(가입 이유)을 비워둬도 제출이 잘 된다 → `required`가 없는 칸은 막지 않는다는 증거입니다.
- 이메일 칸에 `@`가 없는 값을 넣으면 형식 안내가 추가로 뜬다 → `type="email"`과 `required`가 함께 검사하는 모습입니다.

## 핵심 정리

- `required`는 input, textarea, select 같은 폼 요소에 붙이는 **속성**입니다. 값(`=...`) 없이 단어만 적으면 됩니다: `<input type="text" required />`
- 검증은 그 요소들이 `<form>` 태그 안에 있고, 제출 버튼이 `type="submit"`일 때 자동으로 동작합니다.
- 이 검사는 **사용자 편의를 위한 1차 방어선**일 뿐입니다. 실제 서비스에서는 데이터를 받는 서버(예: Supabase) 쪽에서도 반드시 다시 검사해야 합니다. 브라우저 검증만으로 보안이 끝나지 않는다는 점을 기억하세요.
