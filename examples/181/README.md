# 181 — 내 페이지에 title과 meta description 한 줄 달기

정적 HTML의 `<head>` 안에 **고유한 `<title>`** 과 **`meta description`** 을 넣어,
구글 검색결과에 보일 "제목·설명"을 직접 만들어 보는 실습입니다.

- 카테고리: SEO·성능·접근성 (코드 I)
- 난이도: 1 / 5
- 개념: `title`, `meta description`
- 결과물: `<head>`에 title·description이 채워진 HTML 페이지

## 목표

검색결과에 내 페이지가 어떻게 보일지는 본문 디자인이 아니라
`<head>` 안의 두 줄이 결정합니다.

- **`<title>`**: 구글 검색결과의 **파란 제목 글자**이자 **브라우저 탭에 뜨는 이름**.
  페이지마다 "고유하게" 적습니다. (권장: 한글 30자 안팎)
- **`meta description`**: 검색결과에서 제목 아래에 보이는 **설명 두 줄**.
  순위에 직접 미치는 영향은 작지만, 사람이 클릭할지 말지를 결정합니다. (권장: 한글 70~80자 안팎)

이 두 줄을 직접 채워 넣고, 브라우저 탭과 미리보기에서 결과를 눈으로 확인하는 것이 목표입니다.

## 따라하는 단계

1. 이 폴더의 `index.html`을 브라우저로 엽니다 (파일을 더블클릭하면 됩니다).
2. **브라우저 탭**에 표시되는 글자를 확인합니다. 이 글자가 바로 `<title>`의 내용입니다.
3. `index.html`을 메모장이나 에디터로 열어, `<head>` 안의 다음 두 줄을 찾습니다.
   ```html
   <title>햇살카페 — 동네 골목 끝 수제 디저트 카페</title>
   <meta name="description" content="동네 골목 끝 작은 카페, 햇살카페입니다. ..." />
   ```
4. `<title>` 안의 글자를 **내 사이트 이름**으로 바꿉니다.
   예: `<title>김세영의 포트폴리오 — 웹 개발 입문</title>`
5. `meta description`의 `content="..."` 안의 글자를 **내 사이트를 한두 문장으로 소개**하는 문구로 바꿉니다.
   예: `content="비전공자가 만든 첫 포트폴리오 사이트입니다. 만든 프로젝트와 연락처를 정리했어요."`
6. 저장한 뒤 브라우저에서 새로고침(F5)하여 탭 제목이 바뀌었는지 확인합니다.

## 검증법

- **브라우저 탭 확인**: 탭에 적은 `<title>` 글자가 그대로 보이면 성공입니다.
- **소스 확인**: 페이지에서 마우스 오른쪽 클릭 → "페이지 소스 보기"를 누르면,
  `<head>` 안에 `<title>`과 `<meta name="description" ...>` 두 줄이 들어 있는지 확인할 수 있습니다.
- **검색 미리보기 확인**: title은 30자, description은 80자를 넘으면 실제 검색결과에서 `...`로 잘립니다.
  너무 길지 않은지 글자 수를 세어 봅니다.
- **고유성 확인**: 사이트에 페이지가 여러 개라면, 모든 페이지가 같은 title을 쓰면 안 됩니다.
  페이지마다 내용을 다르게 적었는지 확인합니다.
