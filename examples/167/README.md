# 167 — 완성한 index.html을 드래그앤드롭으로 GitHub에 올리기

이미 만들어 둔 정적 페이지 파일(`index.html`, `style.css`)을 **GitHub 웹 화면에서 마우스로 끌어다 놓아(드래그앤드롭)** 올려 보는 실습입니다.
명령어(터미널)나 Git 프로그램 설치 없이, 인터넷 화면에서 파일을 끌어다 놓는 것만으로 "내 코드가 인터넷에 저장됐다"를 눈으로 확인합니다.

- 카테고리: 배포·운영·도구 (코드 H)
- 난이도: 1 / 5
- 개념: 파일 업로드, 커밋(commit)
- 결과물: `index.html`과 `style.css`가 들어간 내 GitHub 저장소

> 이 폴더 안의 `index.html`과 `style.css`가 바로 **올릴 파일**입니다. 이 두 파일을 그대로 사용하면 됩니다.

---

## 목표

166번 실습에서 만든 **빈 저장소(repository)** 에, 이번에는 실제 코드 파일을 넣어 봅니다.

핵심 단어 두 개만 기억하면 됩니다.

- **업로드(upload)**: 내 컴퓨터에 있는 파일을 인터넷(GitHub) 쪽으로 끌어올려 보내는 것.
- **커밋(commit)**: "이 파일들을 저장소에 **확정해서 저장한다**"고 도장을 찍는 것. 커밋을 눌러야 비로소 저장이 끝납니다. (사진을 고르고 "보내기"를 눌러야 전송되는 것과 같습니다.)

> 비유: 166번에서 빌린 사물함(빈 저장소)에, 이번에는 물건(코드 파일)을 넣고 사물함 문을 닫아 잠그는(=커밋) 것입니다.
> 파일을 끌어다 놓기만 하고 커밋을 안 누르면, 사물함 앞에 물건만 놓고 문을 안 닫은 상태라 저장되지 않습니다.

이번에 올리는 파일은 두 개입니다. **반드시 두 개를 함께 올려야** 디자인까지 제대로 보입니다.

- `index.html` — 페이지의 내용(글·구조)
- `style.css` — 페이지의 디자인(색·여백·글꼴)

`index.html` 안에 `<link rel="stylesheet" href="style.css" />` 한 줄이 있어서, 두 파일이 **같은 저장소에 함께** 있어야 짝이 맞습니다. 하나만 올리면 글자만 나오고 디자인이 빠진 채로 보입니다.

---

## 따라하는 단계

### 1단계 — 올릴 파일 두 개를 한 폴더에 준비하기

1. 이 폴더(`examples/167`)에 있는 **`index.html`** 과 **`style.css`** 를 내 컴퓨터에서 찾기 쉬운 곳(예: 바탕화면의 새 폴더)에 복사해 둡니다.
2. (선택) `index.html`을 더블클릭해 브라우저로 열어, 디자인이 입혀진 카드가 보이는지 미리 확인합니다.
3. (선택) 내 정보로 바꾸고 싶다면 `index.html`의 `[내 이름]`, `[날짜]` 부분만 고쳐 저장합니다. 안 고쳐도 실습에는 문제없습니다.

### 2단계 — 내 GitHub 저장소 화면 열기

1. **https://github.com** 에 로그인합니다.
2. 166번에서 만든 저장소(예: `https://github.com/내아이디/my-first-website`)로 들어갑니다.
   - 아직 저장소가 없다면 먼저 166번 실습으로 빈 저장소를 하나 만들고 오세요.

### 3단계 — 업로드 화면 열기

1. 저장소 화면에서 **Add file**(파일 추가) 버튼을 누릅니다.
2. 펼쳐진 메뉴에서 **Upload files**(파일 업로드)를 선택합니다.
   - (또는 주소창에 `https://github.com/내아이디/저장소이름/upload` 를 직접 입력해도 같은 화면이 나옵니다.)

### 4단계 — 파일 두 개를 드래그앤드롭으로 끌어다 놓기

1. 1단계에서 준비한 폴더를 열어, **`index.html`과 `style.css`를 함께 선택**합니다.
   - (한 번에 선택: 첫 파일을 클릭한 뒤 `Ctrl`을 누른 채 두 번째 파일을 클릭)
2. 선택한 파일들을 마우스로 **드래그**해서, GitHub 화면 가운데의 점선 박스
   (**"Drag files here to add them to your repository"**) 안으로 **끌어다 놓습니다(드롭)**.
3. 박스 아래에 `index.html`과 `style.css`, 파일 두 개의 이름이 나타나면 업로드 준비가 끝난 것입니다.

### 5단계 — 커밋(저장 도장 찍기)

1. 화면 아래쪽 **Commit changes**(변경사항 커밋) 영역으로 내려갑니다.
2. 첫 칸(커밋 메시지)에 무엇을 했는지 짧게 적습니다. 예: `Add index.html and style.css`
   - 비워 두면 `Add files via upload` 같은 기본 문구가 자동으로 들어가니, 비워 둬도 괜찮습니다.
3. **Commit directly to the `main` branch**(main에 바로 커밋)가 선택된 상태에서, 초록색 **Commit changes** 버튼을 누릅니다.
4. 잠깐 기다리면 저장소 첫 화면으로 돌아오고, 파일 목록에 `index.html`과 `style.css`가 보이면 성공입니다.

## 🤖 바이브코딩 프롬프트

이 실습은 "이미 만든 파일을 GitHub에 올리는" 손작업이라 코드를 새로 짤 일은 거의 없습니다. 그래서 프롬프트는 ① 올릴 파일을 AI에게 만들게 하고, ② 올리는 절차를 차근차근 안내받고, ③ 막혔을 때 진단받는 용도로 씁니다. 아래 블록을 그대로 복사해 AI(Claude, ChatGPT 등)에게 붙여 넣으세요.

- **1단계(뼈대 만들기)** — 올릴 파일부터 만들기 프롬프트:
  ```text
  너는 웹 입문자를 돕는 친절한 멘토야.
  GitHub에 드래그앤드롭으로 올려 볼 아주 간단한 정적 페이지를 만들어 줘.
  - 파일 2개로 나눠 줘: index.html(내용)과 style.css(디자인)
  - index.html 안에서 <link>로 style.css를 불러오게 해 줘
  - 화면 가운데에 "안녕하세요" 인사와, 내 이름·만든 날짜를 적는 카드 한 장
  - 외부 라이브러리·CDN 없이 순수 HTML/CSS만, 비전공자가 읽을 수 있게
  제약: 비밀번호나 API 키 같은 비밀값은 절대 넣지 마. 공개 저장소에 올릴 코드야.
  결과물: index.html 전체 코드, style.css 전체 코드, 그리고 두 파일을 어디에 저장하는지 한 줄 설명.
  ```
- **2단계(기능 추가/개선)** — 올리는 절차 안내받기 프롬프트:
  ```text
  방금 만든 index.html과 style.css를 GitHub 웹사이트에서 마우스 드래그앤드롭으로 올리려고 해.
  터미널·Git 설치 없이, 브라우저 화면만으로 하는 방법을 1번부터 순서대로 알려 줘.
  - 어느 버튼을 누르는지(Add file → Upload files), 어디에 파일을 끌어다 놓는지
  - 마지막에 'Commit changes'(커밋)를 왜 꼭 눌러야 하는지 비유로 설명
  - 두 파일을 반드시 함께 올려야 하는 이유도 한 줄로
  내 GitHub 저장소 주소는 https://github.com/내아이디/my-first-website 야.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  GitHub에 파일을 올렸는데 문제가 생겼어. 무엇이 잘못됐는지 단계별로 진단해 줘.
  증상: (예) 저장소에 index.html은 보이는데 디자인이 하나도 안 입혀지고 글자만 나와.
  내가 한 것: (예) 파일을 끌어다 놓고 초록색 Commit changes 버튼을 눌렀어.
  - 가장 흔한 원인부터 순서대로 짚어 주고(파일 누락? 커밋 안 함? 파일명 오타?)
  - 각 원인을 내가 화면에서 어떻게 확인하는지 알려 줘
  - 어떻게 고치는지까지 단계로 알려 줘
  ```

> 프롬프트 팁: 코드를 받을 땐 "코드만 주지 말고 왜 그렇게 했는지 줄마다 주석으로 설명해 줘", "비전공자가 이해하게 한 줄씩 풀어 줘"를 덧붙이면 단순히 따라 하는 게 아니라 원리를 익히게 됩니다.

## 검증법

아래가 모두 맞으면 성공입니다.

- **파일 목록 확인**: 저장소 첫 화면의 파일 목록에 **`index.html`** 과 **`style.css`** 두 개가 보인다.
- **내용 확인**: `index.html`을 클릭하면 코드 내용이 보이고, 그 위에 "안녕하세요" 같은 우리 코드 글자가 들어 있다.
- **커밋 기록 확인**: 파일 목록 위쪽에 방금 적은 커밋 메시지(예: `Add index.html and style.css`)와 "방금 전" 같은 시간이 보인다 → 커밋이 저장된 증거입니다.
- **개수 확인**: 166번 직후에는 파일이 `README.md` 한 개뿐이었는데, 이번 실습 후에는 파일이 더 늘어났다.

> 흔한 실수
> - **커밋을 안 누름**: 파일을 끌어다 놓기만 하고 초록색 **Commit changes**를 안 누르면 저장되지 않습니다. 마지막에 꼭 커밋을 누르세요.
> - **파일을 하나만 올림**: `index.html`만 올리면 디자인이 빠진 채 글자만 나옵니다. `style.css`도 **함께** 올려야 합니다.
> - **폴더째 끌어다 놓음**: 폴더가 아니라 **파일 두 개**를 선택해서 끌어다 놓으세요. (폴더를 올리고 싶다면 폴더를 열어 그 안의 파일들을 선택)
> - **비밀값 업로드 금지**: 이번 파일에는 비밀번호·API 키가 없지만, 앞으로도 공개 저장소에는 비밀번호나 API 키 같은 **비밀값을 절대 올리지 않습니다.** 코드만 올립니다. (비밀값은 나중에 배울 환경변수로 따로 보관합니다.)
