# 비밀번호 강도 막대 (약함 · 보통 · 강함)

회원가입 화면에서 비밀번호를 입력하면 그 아래 막대가 빨강 → 주황 → 초록으로 바뀌는 것을 본 적이 있을 겁니다. 이걸 "비밀번호 강도 미터"라고 합니다. 이 실습에서는 입력한 비밀번호가 **길이·숫자·특수문자·대문자** 같은 조건을 얼마나 만족하는지 점수로 매기고, 그 점수에 따라 막대의 길이와 색을 **실시간으로** 바꾸는 로직을 만들어 봅니다. (실제 가입은 아직 하지 않는 화면 연습용 예제입니다.)

## 목표

- 여러 조건을 **정규식(test)** 으로 각각 검사한다 (숫자 있는지, 특수문자 있는지 등).
- 만족한 조건 개수를 더해 **점수로 환산(조건 점수화)** 하고, 점수를 약함/보통/강함 3단계로 나눈다.
- 단계에 따라 막대의 너비(`style.width`)와 **동적 클래스**(`weak`/`medium`/`strong`)를 바꿔 색을 교체한다.
- `input` 이벤트로 글자가 바뀔 때마다 **실시간**으로 막대와 글자, 조건 체크리스트가 갱신되게 한다.

## 따라하는 단계

1. `099` 폴더 안의 `index.html` 파일을 마우스로 더블클릭해 브라우저(크롬 등)로 엽니다. 비밀번호 입력칸과 회색 막대, "비밀번호를 입력하세요" 안내문, 그리고 4개짜리 조건 체크리스트가 보입니다.
2. 입력칸에 짧은 글자(예: `abc`)를 입력해 봅니다. 막대가 1/3만 **빨갛게** 차고 글자가 "강도: 약함"으로 바뀌면 1단계가 작동하는 것입니다.
3. 숫자를 섞어 더 길게(예: `abcd1234`) 입력합니다. 조건 중 "8자 이상", "숫자 포함" 앞이 초록 ✓로 바뀌고, 막대가 2/3 **주황색**으로 차며 "강도: 보통"이 되는지 봅니다.
4. 대문자와 특수문자까지 넣어(예: `Abcd1234!`) 입력합니다. 네 조건이 모두 ✓가 되고 막대가 끝까지 **초록색**으로 차며 "강도: 강함"이 되면 성공입니다.
5. 입력칸을 모두 지웁니다. 막대가 다시 비고 "비밀번호를 입력하세요" 안내문으로 되돌아가면 비어 있는 경우 처리까지 정상입니다.
6. (코드 읽기) `script.js`의 `checkStrength` 함수를 천천히 읽어 보세요. (1) 정규식으로 조건 검사 → (2) `score`로 점수 합산 → (3) 체크리스트 `toggle` → (5) 점수로 단계 결정 → (6)(7) 막대·글자 색 교체, 이렇게 단계가 나뉘어 있는 것이 핵심입니다.
7. (응용) `score <= 1`, `score <= 3` 같은 **기준 숫자**를 바꿔 보거나, 새 조건(예: 소문자 포함)을 하나 더 추가해 점수 만점을 5점으로 늘려 보세요.

## 검증법

- **단계 전환**: `abc`(약함·빨강) → `abcd1234`(보통·주황) → `Abcd1234!`(강함·초록) 순으로 입력하며 막대 길이와 색이 단계별로 바뀌면 점수화 로직이 맞는 것입니다.
- **실시간 반응**: 버튼을 누르지 않아도 글자를 한 자 칠 때마다 막대·글자·체크리스트가 즉시 바뀌면 `input` 이벤트가 잘 연결된 것입니다.
- **체크리스트 일치**: 만족한 조건만 정확히 초록 ✓로 바뀌어야 합니다. 예를 들어 특수문자가 없으면 "특수문자 포함" 항목은 회색 ○로 남아 있어야 합니다.
- **빈 칸 복원**: 입력을 전부 지웠을 때 막대가 비고 안내문이 처음 상태로 돌아오면 빈 값 처리가 된 것입니다.
- 브라우저 개발자 도구(F12)의 콘솔에 빨간 오류 메시지가 없으면 코드가 깨진 곳 없이 잘 작동하는 것입니다.

> 참고: 이 막대는 사용자에게 "더 강한 비밀번호를 쓰라"고 안내하는 화면 장치일 뿐, 실제 보안 검증은 아닙니다. 진짜 가입에서는 입력값을 서버(예: Supabase)로 보내 안전하게 처리해야 하며, 비밀번호 같은 비밀값은 화면 코드에 절대 적어 두지 않습니다.
