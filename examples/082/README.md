# 할 일 목록(To-Do) 만들기 — 추가와 삭제

입력한 할 일을 목록에 추가하고, 각 항목의 "삭제" 버튼으로 지우는 작은 웹앱입니다.
이 실습의 진짜 목표는 화면을 만드는 것이 아니라, **데이터(배열)를 다루고 그 데이터로 화면을 다시 그리는 방식**을 몸에 익히는 것입니다.

## 목표

- 입력칸에 적은 할 일을 **배열에 추가(push)** 한다.
- 삭제 버튼을 누르면 그 항목만 **배열에서 빼고(filter)** 나머지는 남긴다.
- 배열이 바뀔 때마다 **화면을 처음부터 다시 그린다(render)** 는 핵심 패턴을 이해한다.
- `document.createElement`로 새 요소를 **코드로 직접 만들어** 화면에 붙이는 법을 익힌다.

> 비유하자면, 배열(`todos`)은 "진짜 명단"이고 화면은 그 명단을 그대로 베껴 적은 "칠판"입니다.
> 명단이 바뀌면 칠판을 지우고 다시 옮겨 적습니다. 칠판만 몰래 고치지 않는 것이 실수를 줄이는 비결입니다.

## 따라하는 단계

1. 이 폴더(`082`)에 있는 `index.html`, `style.css`, `script.js` 세 파일을 같은 폴더에 둡니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다.
3. 입력칸에 "장보기"라고 적고 **추가** 버튼을 누릅니다. 목록에 "장보기" 줄이 생기는지 봅니다.
4. 글자를 적고 **Enter 키**만 눌러도 추가되는지 확인합니다. (입력칸을 `<form>`으로 감싸서 가능합니다.)
5. 빈 칸이거나 공백(스페이스)만 있는 상태에서 추가를 눌러 봅니다. 아무것도 추가되지 않아야 합니다.
6. 할 일을 2~3개 더 추가한 뒤, 가운데 항목의 **삭제** 버튼을 눌러 그 줄만 사라지는지 확인합니다.
7. 모든 항목을 삭제하면 "아직 할 일이 없어요" 안내 문구가 다시 나타나는지 봅니다.
8. `script.js`를 열어 주석을 따라 읽으며, `addTodo`(추가) → `render`(다시 그리기), `removeTodo`(삭제) → `render`의 흐름을 눈으로 따라갑니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고, 아래 순서대로 단계를 나눠 시키면 AI도 덜 헷갈리고 여러분도 흐름을 따라가기 좋습니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 자바스크립트를 처음 배우는 비전공자를 돕는 친절한 강사야.
  순수 HTML/CSS/JS만으로(외부 라이브러리 없이) "할 일 목록(To-Do)" 웹앱의 기본 뼈대를 만들어줘.

  요구사항:
  - 파일은 index.html, style.css, script.js 세 개로 분리해줘.
  - 화면에는 (1) 할 일 입력칸 + "추가" 버튼, (2) 할 일이 표시될 빈 목록(ul), (3) 안내 문구 자리가 있어야 해.
  - 입력칸과 추가 버튼은 <form>으로 감싸서, 나중에 Enter 키로도 추가되게 준비해줘.
  - 아직 추가/삭제 동작은 넣지 말고, 화면 구조와 기본 스타일(가운데 정렬된 카드 모양)만 먼저 만들어줘.
  - 비전공자가 읽을 수 있게 각 부분에 한국어 주석을 달고, 변수나 id 이름은 영어로 해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  좋아. 이제 script.js에 실제 동작을 추가해줘.

  - 할 일들을 todos라는 "배열"에 { id, text } 객체로 저장해줘.
  - 배열이 바뀔 때마다 화면을 처음부터 다시 그리는 render() 함수를 만들어줘.
    (목록을 비우고 → 배열을 돌면서 li를 다시 만들어 붙이는 방식)
  - 추가 버튼이나 Enter를 누르면 입력값을 배열에 push하고, 입력칸을 비워줘.
  - 빈 칸이나 공백만 입력하면 추가되지 않게 막아줘.
  - 각 항목에 "삭제" 버튼을 만들어서, 누르면 그 항목만 배열에서 빼고(filter) 다시 그려줘.
  - 할 일이 0개면 안내 문구를 보여주고, 화면 아래에 "남은 할 일: N개"를 표시해줘.
  - 왜 화면을 직접 고치지 않고 "배열을 바꾼 뒤 다시 그리는지" 이유를 주석으로 설명해줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내 To-Do 앱이 동작하지 않아. 추가 버튼을 눌러도 목록에 아무것도 안 생겨.
  아래는 내 script.js 전체 코드야. (코드 붙여넣기)

  브라우저 F12 → Console 탭에 이런 빨간 오류가 떠: (오류 메시지 붙여넣기)

  - 무엇이 문제인지 비전공자도 이해하게 한 줄씩 풀어서 설명해줘.
  - 어디를 어떻게 고쳐야 하는지 정확한 줄을 알려주고, 고친 코드를 보여줘.
  - 한꺼번에 다 바꾸지 말고, 가장 가능성 높은 원인부터 하나씩 확인하는 순서로 알려줘.
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과 코드가 학습에 훨씬 도움이 됩니다.

## 검증법

- 추가: 글자를 넣고 추가하면 목록에 줄이 늘고, **입력칸이 자동으로 비워지며** 커서가 다시 입력칸에 머문다.
- 삭제: 특정 항목의 삭제 버튼을 누르면 **그 항목만** 사라지고 나머지 순서는 그대로 유지된다.
- 빈 입력 방지: 빈 칸이나 공백만으로는 추가되지 않는다.
- 개수 표시: 화면 아래 "남은 할 일: N개" 숫자가 추가/삭제할 때마다 정확히 맞게 바뀐다.
- 빈 목록 안내: 할 일이 0개가 되면 안내 문구가 보이고, 1개라도 있으면 숨겨진다.
- (개발자 도구 확인) F12 → Console 탭에 빨간 오류가 없어야 한다.

> 참고: 이 실습은 새로고침하면 목록이 사라집니다. **새로고침해도 유지**되도록 저장하는 방법은
