# 다크모드 토글 버튼 만들기

버튼 한 번으로 밝은 화면 ↔ 어두운 화면을 번갈아 바꾸는 작은 페이지입니다. 자바스크립트의 `classList.toggle`로 화면에 CSS 클래스를 **붙였다 뗐다** 하면서 상태를 켜고 끄는 패턴을 익힙니다.

## 목표

- 화면의 모양을 통째로 바꾸는 일을 **CSS 클래스 하나**로 처리하는 법을 익힙니다.
- 버튼을 누를 때마다 "다크모드 켬 ↔ 끔" 상태가 번갈아 바뀌는 **토글(toggle)** 흐름을 이해합니다.
- `classList.toggle("dark")`가 "있으면 떼고, 없으면 붙이는" 일을 한 줄로 해 준다는 것을 체감합니다.

## 따라하는 단계

1. 이 폴더(`059`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. 밝은 배경의 카드 글과 그 아래 "🌙 어두운 모드로 바꾸기" 버튼이 보이는지 확인합니다.
3. `style.css`를 살펴봅니다. 위쪽은 밝은 모드(기본) 색이고, 아래쪽 `body.dark ...` 규칙들은 **`body`에 `dark` 클래스가 붙어 있을 때만** 적용되는 어두운 색입니다.
4. `script.js`를 엽니다. 코드는 세 단계입니다.
   - `document.body` 로 화면 전체를, `getElementById("themeBtn")` 으로 버튼을 찾습니다.
   - 버튼에 `addEventListener("click", ...)` 로 클릭 동작을 연결합니다.
   - 클릭될 때 `body.classList.toggle("dark")` 로 `dark` 클래스를 붙이거나 뗍니다. 반환값(`isDark`)으로 지금 켜졌는지 확인해 버튼 글자도 "어두운 모드로 ↔ 밝은 모드로"로 바꿉니다.
5. 브라우저로 돌아가 버튼을 눌러봅니다. 배경과 글자가 어둡게 바뀌고 버튼 글자가 "☀️ 밝은 모드로 바꾸기"로 바뀌면 성공입니다.
6. 버튼을 다시 눌러 밝은 모드로 되돌아오는지 확인합니다.
7. (더 해보기) `style.css`의 `body.dark` 색 값(`#15181d` 등)을 다른 색으로 바꿔 나만의 다크 테마를 만들어 봅니다. `script.js`는 고치지 않아도 됩니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 아래 순서대로 한 단계씩 시키면 됩니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 웹 초보를 돕는 프론트엔드 멘토야.
  index.html / style.css / script.js 세 파일로 "다크모드 토글" 페이지를 만들어 줘.
  요구사항:
  - 가운데 정렬된 카드 안에 제목과 설명 글이 있다.
  - 카드 아래에 "🌙 어두운 모드로 바꾸기" 버튼(id="themeBtn")이 있다.
  - style.css는 위쪽에 밝은 모드(기본) 색, 아래쪽에 body에 dark 클래스가 붙었을 때만 적용되는 어두운 색 규칙을 둔다.
  - 색은 transition으로 부드럽게 전환되게 한다.
  제약: 자바스크립트로 색을 직접 지정하지 말고, 디자인은 전부 CSS에 두고 JS는 클래스만 켜고 끄게 해.
  각 줄에 왜 그렇게 했는지 한국어 주석을 달아 줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  좋아. 이제 script.js를 추가해서 버튼을 누르면 다크모드가 켜졌다 꺼졌다 번갈아 바뀌게 해 줘.
  요구사항:
  - body.classList.toggle("dark") 한 줄로 클래스를 붙였다 뗐다 한다.
  - 토글 반환값으로 지금 다크모드인지 판단해서 버튼 글자를
    "☀️ 밝은 모드로 바꾸기" ↔ "🌙 어두운 모드로 바꾸기"로 바꾼다.
  - 접근성을 위해 버튼의 aria-pressed 값도 true/false로 같이 바꾼다.
  왜 toggle 한 줄이면 if문으로 add/remove 하는 것보다 간단한지 주석으로 설명해 줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  버튼을 눌러도 화면 색이 안 바뀌어. 콘솔에 이런 에러가 떠:
  "Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')"
  내 index.html, style.css, script.js 전체를 붙여넣을게. (여기에 붙여넣기)
  무엇이 문제인지 한 가지씩 짚어서 알려주고, 비전공자가 이해하게 한 줄씩 풀어서 고쳐 줘.
  특히 <script> 태그 위치, 버튼 id 철자(themeBtn), 세 파일이 같은 폴더에 있는지를 확인해 줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과를 그냥 받기만 하지 않고 직접 판별할 수 있어 학습에 훨씬 좋습니다.

## 검증법

- 처음 화면: 밝은 배경 + "🌙 어두운 모드로 바꾸기" 버튼이면 정상입니다.
- 버튼을 누르면: 배경·글자·카드 색이 어두워지고 버튼 글자가 "☀️ 밝은 모드로 바꾸기"로 바뀌면 정상입니다.
- 버튼을 다시 누르면: 처음의 밝은 화면으로 정확히 되돌아오면 정상입니다.
- 여러 번 연달아 눌러도 밝음/어둠이 매번 정확히 번갈아 일어나면 토글이 제대로 된 것입니다.
- 색이 톡 끊기지 않고 부드럽게 전환되는지 확인합니다(이 효과는 `style.css`의 `transition`이 담당합니다).
- 만약 동작하지 않는다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html` 안의 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지, 그리고 버튼 `id`가 HTML(`themeBtn`)과 자바스크립트에서 똑같이 적혔는지 확인하세요.

## 핵심 개념

- `classList.toggle("dark")` : 요소에 클래스가 없으면 붙이고, 있으면 뗍니다. "확인 후 켜거나 끄기"를 한 줄로 해 주는 토글 도구입니다. 반환값은 토글 후 클래스가 붙어 있으면 `true`, 없으면 `false`입니다.
- CSS 클래스로 모양 바꾸기 : 색을 자바스크립트에서 일일이 지정하지 않고, `body.dark`에 묶어 둔 CSS 규칙을 클래스 하나로 켜고 끕니다. 디자인은 CSS에, 동작은 JS에 나눠 두면 관리가 쉬워집니다.
- `classList.add` / `remove` / `contains` : 각각 무조건 붙이기 / 무조건 떼기 / 있는지 확인하기입니다. `toggle`은 이 셋을 합친 편리한 단축 도구로 볼 수 있습니다.
- `aria-pressed` : 지금 버튼이 눌린(켜진) 상태인지(`true`)/아닌지(`false`)를 화면 낭독기 같은 보조기기에 알려주는 접근성 표시입니다.
