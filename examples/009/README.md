# 이미지 한 장 넣고 설명(alt) 달기

사진을 화면에 띄우는 `<img>` 태그를 익혀봅니다. 그림이 보일 때는 어떻게 크기를 정하는지(`width`), 그림이 안 보일 때를 대비해 왜 설명 글자(`alt`)를 꼭 적어야 하는지를 직접 눈으로 확인합니다.

## 목표

- `<img>` 태그와 `src` 속성으로 사진을 화면에 띄운다.
- `alt`(대체 텍스트)에 그림 설명을 적어, 그림이 안 보일 때 무슨 그림인지 알 수 있게 한다.
- `width` 로 그림의 가로 너비를 정한다.

> 비전공자 눈높이 한 줄 요약: `<img src="그림주소" alt="그림설명" width="400" />` 이렇게 쓰면, "그림주소"의 사진이 가로 400픽셀 크기로 보이고, 혹시 그림이 안 뜨면 "그림설명" 글자가 대신 나타납니다. `<img>` 는 `<a>...</a>` 처럼 닫는 태그가 없고 한 줄로 끝나요.

## 따라하는 단계

1. `examples/009/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<img ... />` 부분을 찾습니다. 이게 바로 그림을 띄우는 코드입니다. (파일 안에 예시가 3개 있어요.)
3. `src="..."` 안의 주소가 "어떤 그림을 보여줄지"입니다. 예: `src="https://picsum.photos/seed/busan/400/300"` → 인터넷에 있는 그림을 불러옵니다.
4. `alt="..."` 안의 글자는 "그림 설명"입니다. 그림이 안 보일 때 이 글자가 대신 나타납니다.
5. `width="400"` 의 숫자가 그림의 가로 크기(픽셀)입니다. 숫자를 `200` 으로 바꿔 저장하면 그림이 더 작아집니다. (높이는 비율에 맞게 자동으로 줄어요.)
6. 내 사진을 넣고 싶다면, 사진 파일(예: `cat.jpg`)을 `index.html` 과 같은 폴더에 넣고 `src="cat.jpg"` 처럼 파일 이름만 적으면 됩니다.
7. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의 1: `<img>` 는 닫는 태그(`</img>`)가 없습니다. 한 줄로 끝나며, 끝을 `/>` 로 닫아주면 깔끔합니다.
> 주의 2: `alt` 는 빼먹기 쉽지만 꼭 적으세요. 눈이 불편한 분들이 쓰는 화면 읽기 프로그램이 이 글자를 읽어주고, 그림이 깨졌을 때도 무슨 그림인지 알려줍니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 맨 위 "인터넷에 있는 그림"이 보이는지 확인합니다. (인터넷이 연결되어 있어야 보입니다.)
3. 두 번째 "직접 그린 그림"(파란 하늘·노란 해·초록 산)은 인터넷이 없어도 **항상** 보이는지 확인합니다. 이건 그림이 코드 안에 통째로 들어있어서 그렇습니다.
4. 세 번째 "일부러 깨뜨린 그림"에서, 그림 자리에 사진 대신 **`alt` 에 적은 설명 글자가 나타나는지** 확인합니다. → 이게 `alt` 가 하는 일입니다.
5. `width="300"` 의 숫자를 `150` 으로 바꿔 저장하고 새로고침(F5)했을 때, 그림이 절반 크기로 작아지는지 확인합니다.
6. (선택) 첫 번째 그림이 안 보인다면 인터넷 연결과 `src` 주소의 오타를 확인하세요. 그래도 두 번째·세 번째 예시는 학습 목적상 그대로 작동합니다.
