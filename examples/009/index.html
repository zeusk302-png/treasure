이미지 넣어보기

아래는 <img> 태그로 넣은 사진입니다.

위 사진은 인터넷에 있는 그림을 불러온 것입니다. 인터넷이 끊기면 안 보일 수 있어요.

인터넷 없이도 보이는 그림 (직접 그린 그림)

아래 그림은 글자로 직접 그린 그림이라, 인터넷이 없어도 항상 보입니다. 같은 <img> 태그에 alt 와 width 가 들어있어요.

일부러 깨뜨린 그림 (alt 의 중요성 확인)

아래 그림은 주소(src)가 존재하지 않는 가짜 주소라 그림이 안 나옵니다. 하지만 alt 에 적은 설명 글자가 대신 나타나는 것을 볼 수 있어요. 이래서 alt 가 중요합니다.
