# 실습 241 — 다크모드 선택을 localStorage에 저장해 새로고침해도 유지하기

다크모드 버튼은 많이들 만들어 봅니다. 그런데 **새로고침하면 다시 밝은 화면으로 돌아가** 버린 적 있지 않나요? 그 이유는 간단합니다. 페이지를 다시 불러오면 자바스크립트도 처음부터 다시 실행되어, 내가 방금 어둡게 바꾼 "기억"이 사라지기 때문입니다.

이번 실습에서는 그 기억을 **브라우저 안의 작은 메모장**에 적어 둡니다. 그 메모장의 이름이 바로 **localStorage** 입니다.

| 비유 | 진짜 이름 | 하는 일 |
|---|---|---|
| 메모장에 적기 | `localStorage.setItem("theme", "dark")` | 내가 고른 값을 저장 |
| 메모장에서 읽기 | `localStorage.getItem("theme")` | 저장해 둔 값을 다시 꺼냄 |
| 메모는 안 지워짐 | localStorage 특성 | 탭을 닫거나 컴퓨터를 꺼도 그대로 남음 |

저장한 값은 그 브라우저(내 컴퓨터) 안에만 남습니다. 서버나 데이터베이스가 전혀 필요 없어서, 비밀번호 같은 설정 없이도 바로 해볼 수 있는 가장 쉬운 "데이터 저장" 경험입니다.

## 목표
- `localStorage.setItem` / `getItem` 으로 값을 **저장하고 다시 불러오는** 한 사이클을 익힌다.
- "새로고침해도 유지된다"는 것이 결국 **페이지가 열릴 때 저장된 값을 다시 읽어 화면에 적용**하는 것임을 이해한다.
- 색은 CSS 변수와 `data-theme` 표시로 바꾸고, 자바스크립트는 그 표시를 켜고 끄며 저장만 담당한다 — 역할이 나뉘는 구조를 본다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**해 브라우저에서 엽니다. (세 파일 `index.html` · `style.css` · `script.js` 가 같은 폴더에 함께 있어야 합니다.)
2. 오른쪽 위 **🌙 어둡게** 버튼을 눌러 봅니다. → 화면 전체 색이 어두워지고 버튼 글자가 **☀️ 밝게** 로 바뀝니다.
3. 이제 핵심 확인입니다. 키보드 **F5**(새로고침)를 누릅니다. → 밝은 화면으로 되돌아가지 않고 **어두운 화면이 그대로 유지**됩니다.
4. 한 번 더 확인. 브라우저 **탭을 완전히 닫았다가** 다시 `index.html`을 열어도 마지막에 고른 테마로 열립니다.
5. 화면 아래 "지금 저장된 값" 칸을 봅니다. 버튼을 누를 때마다 `dark` ↔ `light` 로 바뀌는 것이 보입니다. 이것이 실제 메모장(localStorage)에 적힌 값입니다.
6. (코드 들여다보기) `script.js`를 메모장이나 VS Code로 엽니다. 위에서부터 **1단계(열릴 때 읽기) → 2단계(누를 때 저장)** 순서로 주석을 따라 읽어 보세요.
7. (선택) AI에게 한 단계만 더 부탁해 보기. 욕심내지 말고 딱 하나만:
   > "이 script.js에서, localStorage에 저장된 테마가 하나도 없을 때는 사용자의 운영체제 설정(밝게/어둡게)을 따르도록 `window.matchMedia('(prefers-color-scheme: dark)')`로 기본값을 정하게 고쳐줘. 저장·불러오기 동작은 그대로 둬."

## 검증법
- 버튼을 눌러 테마를 바꾼 뒤 **F5(새로고침)** 해도 같은 테마가 유지되는가? (가장 중요한 확인)
- 어두운 모드로 둔 채 **브라우저를 껐다 켜고** 다시 열어도 어두운 모드로 시작하는가?
- 화면 아래 "저장된 값"이 버튼을 누를 때마다 `dark` ↔ `light` 로 정확히 바뀌는가?
- 개발자 도구로 직접 확인하기: `F12 → Application(애플리케이션) 탭 → 왼쪽 Local Storage → 이 페이지 주소`를 클릭하면 `theme` 이라는 이름으로 값이 저장된 것이 보입니다. 그 줄을 지우고 새로고침하면 다시 기본값(밝은 모드)으로 돌아갑니다.
- 한글이 깨져 보인다면 `index.html`의 `<meta charset="UTF-8" />` 줄이 빠지지 않았는지 확인합니다.
