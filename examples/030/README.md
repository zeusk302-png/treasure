# 실습 030 — 그림자 넣은 떠 있는 카드 만들기

똑같이 생긴 흰색 카드 4장을 나란히 두는데, `box-shadow` 한 줄만 다르게 줍니다. 그러면 어떤 카드는 배경에 평평하게 붙어 보이고, 어떤 카드는 종이처럼 **살짝 떠 있는** 느낌이 납니다. 이 차이를 만드는 그림자 값 `x(가로) y(세로) blur(번짐) 색`을 직접 비교하면서, "그림자를 어느 방향으로 얼마나, 얼마나 부드럽게 줄지"를 숫자로 조절하는 법을 익힙니다. 파일은 `index.html` 하나뿐이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- `box-shadow`의 값이 `x y blur 색` **순서**로 적힌다는 것을 이해한다.
- `x`(오른쪽/왼쪽)와 `y`(아래/위)가 그림자를 **어느 방향으로** 미는지, `blur`가 가장자리를 **얼마나 부드럽게 번지게** 하는지 눈으로 확인한다.
- 그림자 색에 `rgba(0, 0, 0, 0.2)`처럼 **투명도**를 줘서 자연스러운 그림자를 만드는 법을 배운다.
- `y`와 `blur`를 키울수록 카드가 **더 높이 떠 있는** 느낌이 난다는 디자인 감각을 익힌다.

네 카드는 모양·크기·색이 모두 똑같습니다. 차이는 오직 아래 한 줄뿐입니다.

| 카드 | box-shadow 값 | 보이는 느낌 |
|---|---|---|
| 1번 | `none` | 그림자 없음 → 배경에 **평평하게** 붙어 보임 |
| 2번 | `0 8px 0 rgba(0,0,0,.25)` | blur가 0 → 가장자리가 **칼처럼 또렷한** 그림자 |
| 3번 | `0 8px 16px rgba(0,0,0,.18)` | blur가 큼 → 종이처럼 **부드럽게 떠 있음** (실무에서 가장 흔함) |
| 4번 | `0 16px 32px rgba(0,0,0,.22)` | y·blur가 더 큼 → **더 높이** 떠 있는 느낌 |

> 값 읽는 메모: `rgba(0, 0, 0, 0.2)`는 "검정색을 20%만 진하게(80% 투명하게)"라는 뜻입니다. 맨 뒤 투명도 숫자가 **작을수록 옅은** 그림자, **클수록 진한** 그림자가 됩니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 네 카드가 나란히 열립니다.
2. **1번 → 2번 → 3번 → 4번 순서로** 카드 아래·뒤쪽을 비교해 봅니다. 오른쪽으로 갈수록 그림자가 더 부드럽고 넓게 퍼져, 카드가 점점 더 **떠 있는** 것처럼 보입니다.
3. **2번과 3번을 콕 집어 비교**합니다. 둘 다 `y`는 8px로 같지만, 2번은 `blur 0`(또렷), 3번은 `blur 16px`(뿌옇게). → `blur` 숫자 하나가 "또렷한 그림자 / 부드러운 그림자"를 가른다는 것을 확인합니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어 맨 아래 `.playground` 규칙의 그림자를 찾습니다.
   ```
   box-shadow: 6px 10px 24px rgba(0, 0, 0, 0.2);
   ```
5. 다음 세 가지를 **하나씩** 바꿔 저장한 뒤 브라우저에서 **새로고침(F5)** 하며 변화를 관찰합니다.
   - `6px`(x)를 `-6px`로 바꾸기 → 그림자가 **왼쪽**으로 이동합니다.
   - `24px`(blur)를 `0`으로 바꾸기 → 그림자 가장자리가 **칼처럼 또렷**해집니다.
   - `0.2`(투명도)를 `0.05`로, 다시 `0.6`으로 바꾸기 → 그림자가 **옅어졌다 진해졌다** 합니다.
6. AI에게 시켜 보기:
   > "이 index.html에, `.playground`와 똑같은 흰 카드를 하나 더 추가하고 마우스를 올리면(`:hover`) 그림자가 더 커지면서 위로 살짝 떠오르는 효과를 넣어줘. 기존 카드는 그대로 두고 새 규칙만 추가하고, `transition`으로 부드럽게 변하게 해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. (직접 다 외우지 말고, 무엇을 시킬지를 정확히 적는 '디렉터'가 되는 연습이에요.)

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 CSS를 처음 배우는 비전공자에게 box-shadow를 설명하려는 강사야.
  index.html 한 파일짜리(서버·DB·외부 라이브러리 없음, 더블클릭으로 열림)로
  '그림자 비교 카드' 예제를 만들어줘. 요구사항:
  - 모양·크기·색이 똑같은 흰색 카드 4장을 가로로 나란히(flex, 좁으면 줄바꿈) 둔다.
  - 4장의 차이는 오직 box-shadow 한 줄뿐이다:
    1번 none(그림자 없음) / 2번 0 8px 0(blur 0, 또렷) /
    3번 0 8px 16px(blur 큼, 부드럽게 떠 있음) / 4번 0 16px 32px(더 높이 떠 있음).
  - 그림자 색은 rgba(0,0,0, 투명도)로 주고, 각 카드에 자기 box-shadow 값을 <code>로 같이 보여준다.
  - 배경은 밝은 회색(#f4f5f7)이라 흰 카드의 그림자가 잘 보이게 한다.
  - 한국어 주석을 달되, 코드만 주지 말고 "왜 그렇게 했는지"를 주석으로 함께 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html에 이어서 작업해줘. 기존 카드 4장과 규칙은 그대로 두고(삭제·수정 금지),
  아래만 '추가'해줘:
  - 값을 직접 바꿔보는 실험용 큰 카드(.playground)를 하나 추가하고
    box-shadow: 6px 10px 24px rgba(0,0,0,0.2); 를 준다(x로 오른쪽, y로 아래로 민 예).
  - 이 실험용 카드에 마우스를 올리면(:hover) 그림자가 더 커지면서 위로 살짝 떠오르게
    transform: translateY(-4px) 와 더 큰 box-shadow를 주고, transition으로 부드럽게 변하게 한다.
  - 맨 아래에 'box-shadow: x y blur 색' 값 읽는 법을 정리한 안내 박스(.legend)를 추가한다.
  각 줄이 왜 필요한지 한국어 주석으로 한 줄씩 풀어서 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 더블클릭해서 열었는데 카드에 그림자가 전혀 안 보여. (또는 4장이 다 똑같이 보여.)
  내 <style> 부분과 카드 HTML을 아래에 붙여넣을게. 바로 고치지 말고,
  (1) box-shadow 값의 'x y blur 색' 순서가 맞는지, (2) blur가 0이라 안 보이는 건 아닌지,
  (3) class 이름(.card-1 등)이 HTML과 CSS에서 똑같이 적혔는지,
  (4) 배경이 흰색이라 흰 그림자가 안 보이는 건 아닌지를 하나씩 짚어가며 원인을 진단해줘.
  그다음 가장 가능성 높은 원인 한 가지를 고친 코드와, 왜 그게 문제였는지 설명해줘.

  [여기에 내 코드와 화면 상태를 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과를 그대로 베끼지 않고 직접 판별하는 힘이 길러집니다.

## 검증법
- **눈으로 확인**: 1번 카드(그림자 없음)는 배경과 경계가 흐릿하게 평평해 보이고, 3·4번 카드는 아래·바깥쪽에 부드러운 회색 그림자가 보이며 떠 있는 느낌이 나나요? → `box-shadow`가 적용되고 있다는 증거입니다.
- **방향 확인**: 4번 카드의 그림자는 `y`가 16px이라 **카드 아래쪽**에 더 많이 깔려 있어야 합니다. 5번 단계에서 x를 음수로 바꿨다면 그림자가 **왼쪽**으로 옮겨갔는지 확인합니다.
- **blur 확인**: 2번 카드의 그림자 가장자리는 **또렷한 선**처럼 보이고, 3번은 **뿌옇게 번져** 있어야 합니다. 둘이 똑같아 보인다면 `blur` 값을 잘못 본 것이니 다시 비교합니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 3번 카드를 클릭하면 오른쪽 Styles 패널에 `box-shadow: 0px 8px 16px ...` 규칙이 보입니다. 그 값을 직접 클릭해 숫자를 바꾸면 화면 그림자가 **실시간**으로 변하는데, 이렇게 하면 새로고침 없이 x·y·blur가 각각 어떤 역할인지 바로 체감할 수 있습니다.
