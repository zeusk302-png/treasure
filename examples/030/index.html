box-shadow: 카드에 그림자를 넣어 '떠 있게' 만들기

아래 네 카드는 모양·크기·색이 모두 똑같습니다. 다른 점은 단 한 줄, box-shadow 값뿐입니다. 그림자 값은 보통 x(가로) y(세로) blur(번짐) 색 순서로 적습니다. 왼쪽부터 오른쪽으로 갈수록 그림자가 더 부드럽고 멀어져, 카드가 점점 더 높이 떠 있는 느낌이 나는 것을 비교해 보세요.

1 · 그림자 없음

평평하게 배경에 붙어 보여요.

box-shadow: none;

2 · 또렷한 그림자

blur가 0이라 가장자리가 칼처럼 또렷해요.

box-shadow: 0 8px 0 rgba(0,0,0,.25);

3 · 부드럽게 떠 있음

blur가 커서 종이처럼 살짝 떠 보여요.

box-shadow: 0 8px 16px rgba(0,0,0,.18);

4 · 더 높이 떠 있음

y와 blur가 더 커서 더 높이 뜬 느낌이에요.

box-shadow: 0 16px 32px rgba(0,0,0,.22);

직접 바꿔보는 실험용 카드

이 카드의 그림자는 box-shadow: 6px 10px 24px rgba(0, 0, 0, 0.2); 입니다. x를 6px 줘서 그림자가 살짝 오른쪽으로, y를 10px 줘서 아래쪽으로 밀려 있습니다.
파일을 열어 이 숫자들을 바꿔 저장하고 새로고침하면, 그림자가 어디로 어떻게 움직이는지 바로 보입니다.

그림자 값 읽는 법 한눈에: box-shadow: x y blur 색;
· x = 그림자를 오른쪽(+)/왼쪽(-)으로 미는 거리 · y = 아래(+)/위(-)로 미는 거리 · blur = 가장자리를 흐리게 번지는 정도(클수록 뿌옇게) · 색 = 보통 rgba(0,0,0,0.2)처럼 검정 + 투명도(작을수록 옅음)
