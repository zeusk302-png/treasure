# 실습 315 — 디자인 토큰(CSS 변수)으로 테마 시스템 만들기

색·간격·글꼴을 코드 여기저기에 직접 박지 않고, **CSS 변수(디자인 토큰)** 한 곳에 모아 정의합니다. 그리고 페이지의 모든 요소가 그 토큰을 **참조만** 하게 만듭니다. 그러면 토큰 값 하나만 바꿔도 버튼·링크·배경·글자색이 **한꺼번에 일관되게** 바뀌는 테마 체계가 완성됩니다. 이 실습에서는 인디고/에메랄드/로즈/다크 **4개 테마**를 버튼 하나로 갈아끼우고, 선택을 기억하게 만들어 봅니다.

> 한 줄 그림: **색·간격을 토큰 한 곳에 정의 → 버튼·카드·링크는 토큰 이름만 참조 → 테마 버튼 클릭 → `data-theme` 한 글자 변경 → 화면 전체 색이 동시에 바뀜**

> 비유: 디자인 토큰은 **회사 색연필 통**입니다. "1번 연필 = 브랜드색"이라고 통에 정해 두면, 디자이너 여러 명이 전부 "1번 연필"이라고만 부릅니다. 어느 날 1번 연필을 파랑에서 초록으로 바꿔 꽂으면, 모두가 자동으로 초록을 쓰게 됩니다. 색을 매번 "#4f46e5"처럼 손으로 칠하면, 색을 바꿀 때 모든 그림을 한 장씩 다시 칠해야 하고 꼭 몇 장은 빠뜨립니다.

## 목표
- **토큰을 한 곳에 정의한다**: 색·간격·글꼴을 `:root`와 `[data-theme="..."]`의 CSS 변수로 모은다.
- **값을 직접 박지 않고 참조한다**: 버튼·카드·링크가 `var(--color-brand)`처럼 토큰 이름만 보게 한다.
- **테마를 통째로 교체한다**: `data-theme` 속성 하나만 바꾸면 4개 테마가 자유롭게 전환되는 구조를 만든다.
- **선택을 기억한다**: 사용자가 고른 테마를 `localStorage`에 저장해 다시 열어도 유지되게 한다.
- **일관성을 체감한다**: 토큰 한 줄을 바꿔 화면 전체 톤이 동시에 바뀌는 것을 눈으로 확인한다.

## 따라하는 단계

### A. 파일 열고 구조 파악하기
1. 이 폴더의 `index.html`, `style.css`, `script.js`를 봅니다. 역할이 나뉘어 있습니다.
   - `index.html` = **무엇을 보여줄지**(버튼, 카드)
   - `style.css` = **어떻게 보일지(토큰 정의 + 토큰 사용)**
   - `script.js` = **동작**(테마 전환, 기억, 미리보기)
2. `index.html`을 더블클릭해 브라우저로 엽니다. 서버 없이 바로 열려도 됩니다(순수 프론트라 비밀값·빌드가 없습니다).

### B. 토큰이 어떻게 정의되어 있는지 보기
3. `style.css` 맨 위 `:root`를 봅니다. 여기에 **간격(`--space-4`)·글꼴(`--font-lg`)·모서리(`--radius`)** 같은, 테마가 바뀌어도 같은 값들이 모여 있습니다.
4. 그 아래 `[data-theme="indigo"]`, `[data-theme="emerald"]` … 를 봅니다. **같은 이름의 색 토큰**(`--color-brand` 등)에 테마마다 다른 값이 들어 있습니다. 사용부는 항상 이름만 보므로, 테마를 바꿔도 한 줄도 안 고칩니다.

### C. 토큰이 어떻게 쓰이는지 보기
5. `style.css` 아래쪽 `.btn-primary`를 봅니다. 색을 `#4f46e5`처럼 직접 쓰지 않고 `background: var(--color-brand);`로 **참조**만 합니다. 이게 핵심입니다.

### D. 테마 전환 동작 확인하기
6. 브라우저에서 상단의 **인디고 / 에메랄드 / 로즈 / 다크** 버튼을 눌러 봅니다. 버튼·링크·배지·배경이 **동시에** 바뀝니다.
7. 페이지 아래 **"지금 적용된 토큰"** 영역을 봅니다. 색 칩이 실제 토큰 값을 읽어와 보여 줍니다. 테마를 바꾸면 이 칩도 같이 바뀝니다.
8. 다크 테마를 고른 뒤 **브라우저를 새로고침**합니다. 선택이 `localStorage`에 기억되어 다크가 유지됩니다.

### E. 토큰 하나 바꿔 '일관성' 체감하기
9. `style.css`의 `[data-theme="indigo"]`에서 `--color-brand` 값을 다른 색(예: `#0ea5e9`)으로 바꾸고 저장한 뒤 새로고침합니다. **버튼·링크·배지·헤더가 한 번에** 그 색으로 바뀌는 걸 확인합니다. (이게 "값 하나만 바꿔도 전체가 일관되게" 입니다.)

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 프론트엔드 멘토야. 비전공자가 이해할 수 있게 만들어 줘.
  순수 HTML/CSS/JS(빌드 도구·프레임워크 없이)로 "디자인 토큰 테마 데모" 페이지를 만들어 줘.
  요구사항:
  - 색(브랜드색, 배경, 카드, 글자, 보조글자, 경계선)과 간격, 글꼴 크기, 모서리를
    CSS 변수(디자인 토큰)로 정의해 줘. 간격·글꼴 등 테마와 무관한 값은 :root에,
    색은 [data-theme="indigo"] 같은 선택자에 테마별로 정의해.
  - 버튼·카드·링크·배지 같은 요소는 색을 직접 쓰지 말고 전부 var(--토큰)으로 참조하게 해.
  - 상단에 테마 전환 버튼(인디고/에메랄드/로즈/다크)을 두고, 누르면 body의 data-theme만
    바꿔서 화면 전체 색이 한꺼번에 바뀌게 해.
  파일은 index.html, style.css, script.js로 나눠 줘.
  코드만 주지 말고, 왜 그렇게 했는지(특히 토큰을 쓰는 이유)를 한국어 주석으로 한 줄씩 설명해 줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 디자인 토큰 데모에 기능을 더해 줘.
  1) 사용자가 고른 테마를 localStorage에 저장해서, 페이지를 다시 열어도 유지되게 해 줘.
  2) 현재 선택된 테마 버튼은 aria-pressed="true"로 표시하고 시각적으로도 강조해 줘(접근성 포함).
  3) 페이지 하단에 "지금 적용된 토큰" 미리보기를 추가해 줘. getComputedStyle로 실제 적용된
     색 토큰 값(--color-brand 등)을 읽어와 작은 색 네모 + "토큰이름 = 값" 형태로 보여 주고,
     테마를 바꾸면 이 미리보기도 같이 갱신되게 해 줘.
  주의: 글자를 화면에 넣을 때는 innerHTML 말고 textContent를 써서 XSS를 막아 줘.
  색·간격 같은 '값'은 JS에 두지 말고 CSS 토큰이 단일 진실의 원천이 되게 유지해 줘.
  추가/변경한 부분에 왜 그렇게 했는지 한국어 주석을 달아 줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  디자인 토큰 테마가 동작이 이상해. 아래 증상 중 하나야:
  - 테마 버튼을 눌러도 색이 안 바뀐다 / 일부 요소만 바뀐다
  - 새로고침하면 선택한 테마가 풀려서 기본 테마로 돌아간다
  - "지금 적용된 토큰" 미리보기 값이 비어 있거나 안 바뀐다
  내 index.html / style.css / script.js를 붙여넣을게. 다음 순서로 진단해 줘:
  1) data-theme 속성이 실제로 바뀌는지, CSS의 [data-theme="..."] 선택자 이름과 정확히 일치하는지
  2) 색이 안 바뀐 요소가 var(--토큰)을 쓰는지, 아니면 색을 직접 박았는지(=토큰을 안 쓰는지)
  3) localStorage 저장/읽기 key가 같은지
  4) getComputedStyle로 토큰을 읽을 때 대상 요소가 맞는지
  원인을 한국어로 설명하고, 고친 코드와 "왜 이게 문제였는지"를 알려 줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **동시 변경 확인**: 테마 버튼을 누르면 헤더·버튼·링크·배지·배경·글자색이 **한 번에** 바뀌는가? 일부만 바뀌면 그 요소는 토큰을 안 쓰고 색을 직접 박은 것이다(찾아서 `var(--토큰)`으로 고친다).
- **토큰 한 줄 테스트**: `style.css`의 한 테마에서 `--color-brand` 한 줄만 바꿔 저장 → 그 테마의 모든 강조 요소가 동시에 바뀌면 토큰 체계가 제대로 동작하는 것이다.
- **기억 확인**: 다크 테마를 고르고 새로고침해도 다크가 유지되는가? (개발자도구 → Application → Local Storage에 `practice315-theme` 값이 저장됐는지도 본다.)
- **미리보기 일치**: 하단 "지금 적용된 토큰"의 색 칩 값이, 화면에 실제 보이는 색과 일치하고 테마 변경 시 함께 바뀌는가?
- **하드코딩 점검**: `style.css`의 "(2) 토큰 사용부"에서 `#`으로 시작하는 색 코드가 거의 없어야 정상이다(색은 토큰에만 있어야 한다). 흰색(`#fff`)처럼 의도적으로 둔 것만 예외.
  - 이 폴더에서 `grep -nE "#[0-9a-fA-F]{3,6}" style.css` 로 색 코드 위치를 보고, 사용부에 색이 직접 박혀 있지 않은지 점검한다.

## 파일 구성
- `index.html` — 데모 페이지의 구조. `data-theme` 속성과 테마 전환 버튼이 들어 있다.
- `style.css` — **핵심.** 위쪽은 토큰 정의(색·간격·글꼴), 아래쪽은 그 토큰을 `var(--토큰)`으로 참조하는 모든 스타일.
- `script.js` — 테마 전환, 선택 기억(`localStorage`), 현재 토큰 값 미리보기. 색 '값'은 두지 않고 어떤 테마를 켤지만 바꾼다.

> 비밀값이 필요 없는 순수 프론트 실습이라 `.env.example`·`.gitignore`는 만들지 않았습니다. (API 키나 토큰을 다루는 실습에서만 그 파일들이 필요합니다.)
