디자인 토큰 테마 데모

색·간격·글꼴을 한 곳에 모아 두고, 버튼 하나로 전체 톤을 바꿉니다.

버튼 — 토큰을 참조

버튼 색은 직접 박지 않고 --color-brand 토큰을 봅니다.

강조 텍스트

이 문단의 링크와 배지도 모두 같은 브랜드 토큰을 씁니다.

그래서 위에서 테마를 바꾸면 여기까지 한꺼번에 바뀝니다.

간격·글꼴도 토큰

카드 안쪽 여백은 --space-4, 제목 크기는 --font-lg처럼 간격·글꼴도 토큰으로 통일했습니다.

값 하나만 바꾸면 모든 카드의 여백이 동시에 넓어지거나 좁아집니다.

지금 적용된 토큰

아래 색 칩은 실제 CSS 변수 값을 그대로 읽어와 보여 줍니다. 테마를 바꾸면 이 칩도 같이 바뀝니다.
