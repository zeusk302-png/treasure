# 225. 디자인 시안 이미지 한 장 주고 똑같이 만들라고 시키기

## 목표

디자인을 **글로 설명하지 않고**, 화면을 **스크린샷(이미지) 한 장으로 보여 주고** AI에게
"이것과 똑같이 만들어줘"라고 시키는 **멀티모달(이미지로 지시) 프롬프트**를 연습합니다.

말로 "보라색 카드인데 위에 띠가 있고 동그란 사진이 걸쳐 있고…"라고 설명하면 열 줄을 써도
색·간격·정렬이 애매하게 전달됩니다. 하지만 **이미지 한 장**이면 AI가 레이아웃·색 계열·둥근 정도·
정렬을 한 번에 알아봅니다. 이번엔 참고 카드 UI 스크린샷을 첨부해, **설명 대신 이미지로** 지시하는
법을 익힙니다.

이 폴더의 파일은 다섯입니다.

- [`reference.html`](reference.html) — **디자인 시안(참고 이미지) 역할.** 브라우저로 열고 **가운데 카드만 스크린샷**으로 캡처해서 AI에게 줍니다. (정답 코드를 베끼라고 주는 게 아니라, 캡처할 "화면"을 만들어 주는 용도)
- [`prompt.md`](prompt.md) — 이미지를 첨부하고 "똑같이 만들어줘"라고 시키는, 그대로 복사하는 **멀티모달 지시 프롬프트**
- [`index.html`](index.html) — 그 시안을 보고 **재현한 정답 예시** (HTML 구조)
- [`style.css`](style.css) — 재현본의 스타일 (색·간격은 스크린샷을 보고 눈대중으로 맞춘 값)
- `README.md` — 지금 읽는 이 안내문

> 이 실습은 **새 디자인을 발명하는 게 아니라, 머릿속·화면 속 디자인을 "이미지로 정확히 전달"하는** 연습입니다.
> 그래서 결과물도 `시안 이미지 → 이미지로 지시 → 재현본 비교`라는 흐름 그대로입니다.

## 따라하는 단계

1. [`reference.html`](reference.html)을 브라우저로 엽니다. (파일을 더블클릭하면 됩니다) 가운데에 보라색 배너 + 둥근 아바타 + 숫자 3칸 + 알약 버튼이 있는 **프로필 카드**가 보입니다.
2. 그 **카드 부분만** 스크린샷으로 캡처합니다. **Windows는 `Win`+`Shift`+`S`**, **Mac은 `Cmd`+`Shift`+`4`** 를 누르고 카드 영역을 드래그하세요.
3. Claude(또는 쓰는 AI)의 채팅창에 방금 캡처한 **이미지를 먼저 첨부**합니다. (드래그 앤 드롭하거나 클립/`+` 버튼 사용)
4. 같은 메시지에 [`prompt.md`](prompt.md)의 **1단계 지시문**을 복사해 붙여넣고 보냅니다. "이미지와 똑같이, HTML+CSS만, 파일 2개로"라는 제약이 들어 있는지 확인합니다.
5. AI가 먼저 **"이미지에서 읽어낸 디자인 요소"** 를 글머리표로 정리하는지 봅니다. (예: 위쪽 보라 그라데이션 배너, 배너에 걸친 둥근 아바타, 숫자 3칸, 알약 버튼) 잘못 본 게 있으면 여기서 바로 지적합니다.
6. AI가 준 `index.html`과 `style.css`를 새 폴더(예: `my-card/`)에 저장하고, `index.html`을 브라우저로 엽니다.
7. 내가 만든 결과를 [`reference.html`](reference.html)(시안)과 **나란히 띄워 눈으로 비교**합니다. 다른 곳이 있으면 [`prompt.md`](prompt.md)의 **2단계**처럼 **다른 부분만** 콕 집어 다시 시킵니다. (필요하면 비교 스크린샷을 한 장 더 첨부)
8. 마지막으로 [`prompt.md`](prompt.md)의 **3단계**로 좁은 화면(360px)에서도 안 넘치게 다듬습니다.
9. 막히면 이 폴더의 [`index.html`](index.html) / [`style.css`](style.css)(정답 예시)와 비교해 어디가 다른지 확인합니다. **픽셀까지 똑같을 필요는 없습니다** — 레이아웃 구조·색 계열·간격 느낌이 맞으면 성공입니다.

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] `reference.html`을 열어 **카드만 스크린샷**으로 캡처했다.
- [ ] AI에게 줄 때 **이미지를 먼저 첨부**했다. (글로만 설명하지 않았다 = 멀티모달 연습이 맞다)
- [ ] 지시문에 **스택 제약**(HTML+CSS만, 외부 라이브러리 금지, flexbox, 파일 2개)이 들어 있었다.
- [ ] AI가 코드를 주기 전에 **"이미지에서 읽어낸 요소"** 를 먼저 정리했다. (잘못 본 부분을 미리 잡을 기회)
- [ ] AI 결과물을 브라우저로 열어 **시안과 나란히 비교**했고, 핵심 요소(보라 그라데이션 배너 / 배너에 걸친 둥근 아바타 / 숫자 3칸 / 알약 버튼)가 **모두 재현**됐다.
- [ ] 다를 때는 **다른 부분만** 골라 다시 시켰다. (멀쩡한 곳은 안 건드렸다)
- [ ] 좁은 화면에서도 카드가 화면 밖으로 **넘치지 않는다.**
- [ ] (보안) 캡처한 시안에 **진짜 개인정보·비밀 값**(실명·이메일·전화·결제정보·API 키/토큰)이 없다. 있었다면 가짜 값으로 바꾸거나 가린 뒤 올렸다.

> 빠른 자가 점검: 내가 만든 카드와 `reference.html`을 두 창으로 나란히 띄워 보세요.
> **한눈에 "거의 같은 카드네"** 싶으면 통과입니다. (색 HEX가 1~2 다른 건 괜찮습니다)
