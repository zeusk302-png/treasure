# 그대로 붙여넣는 지시 프롬프트 (225. 디자인 시안 이미지 한 장 주고 똑같이 만들라고 시키기)

> 핵심 원칙: 디자인을 **글로 길게 설명하지 말고**, 화면을 **스크린샷(이미지) 한 장으로 보여 주고**
> "이것과 똑같이 만들어줘"라고 시킵니다. 이것이 **멀티모달(이미지로 지시)** 프롬프트입니다.
> 말로 "보라색 카드에 동그란 사진이 있고…"라고 설명하면 열 줄을 써도 애매하지만,
> **이미지 한 장**이면 색·간격·정렬·둥근 정도를 AI가 한 번에 알아봅니다.

---

## 0단계 — 먼저 이미지를 "첨부"부터 한다 (가장 중요)

말보다 **이미지 첨부가 먼저**입니다. 채팅창에 이미지를 끌어다 놓거나(드래그 앤 드롭),
클립 모양 / `+` 버튼으로 캡처한 스크린샷을 올립니다.

- 캡처법: **Windows = `Win`+`Shift`+`S`**, **Mac = `Cmd`+`Shift`+`4`**
- 이 폴더의 `reference.html`을 브라우저로 열고, **가운데 카드 부분만** 캡처하세요.

> 이미지를 안 붙이고 글로만 시키면 멀티모달 연습이 아닙니다. 반드시 **이미지부터** 올리세요.

## 1단계 — 이미지 + 한 줄 지시 (이미지로 지시하기)

이미지를 첨부한 그 메시지에, 아래를 복사해 붙여넣으세요.

```
첨부한 이미지는 내가 만들고 싶은 "프로필 카드" 디자인 시안이야.
이 이미지와 최대한 똑같이 보이도록, 순수 HTML과 CSS로 만들어줘.

제약(우리 스택):
- 프레임워크 없이 HTML + CSS만. (Tailwind나 부트스트랩 같은 외부 CSS 라이브러리 쓰지 마)
- 레이아웃은 flexbox로. (테이블 레이아웃, position 떡칠 금지)
- 파일은 index.html과 style.css 두 개로 분리해줘.
- 색 HEX 값은 이미지에서 본 색과 비슷하게 네가 정해줘. 내가 일일이 안 줘도 돼.
- 한글 텍스트와 이모지는 이미지에 보이는 그대로 넣어줘.

먼저 "이미지에서 네가 읽어낸 디자인 요소"를 글머리표로 정리하고(예: 위쪽 보라 그라데이션 배너,
둥근 아바타가 배너에 걸쳐 있음, 숫자 3칸, 알약 모양 버튼 등),
그다음에 코드를 줘. 추측한 부분이 있으면 표시해줘.
```

> 왜 "읽어낸 요소부터 정리"시키나: AI가 이미지를 **무엇으로 봤는지** 먼저 말하게 하면,
> 잘못 본 부분(예: 그라데이션을 단색으로 오해)을 코드 받기 전에 잡을 수 있습니다.
> 이건 [디렉터의 자리]의 "무엇을·왜는 사람이 확인한다"를 이미지 버전으로 적용한 것입니다.

## 2단계 — 결과가 시안과 다를 때, 다시 이미지로 짚기

AI 결과를 브라우저로 열어 시안과 나란히 비교한 뒤, **다른 부분만** 콕 집어 말합니다.
(이때도 새 스크린샷을 한 장 더 붙이면 훨씬 잘 알아듣습니다.)

```
시안과 비교해보니 세 군데가 달라. (필요하면 비교 스크린샷 첨부)
1) 위쪽 배너가 단색인데, 시안은 왼쪽 위 → 오른쪽 아래로 가는 "보라색 그라데이션"이야.
2) 아바타가 배너 아래에 떨어져 있는데, 시안은 배너에 "절반쯤 걸쳐" 있어. (margin-top 음수)
3) 버튼 모서리가 약간만 둥근데, 시안은 양끝이 완전히 둥근 "알약 모양"이야.
이 세 가지만 시안에 맞게 고쳐줘. 나머지는 건드리지 마.
```

> "다른 곳만, 나머지는 건드리지 마"가 핵심입니다. 멀쩡한 부분까지 다시 짜면
> 오히려 새 차이가 생깁니다. (참고: AI는 매번 조금씩 다르게 만드는 '확률기계'입니다.)

## 3단계 — 마무리 점검 시키기 (반응형 한 줄 보너스)

```
마지막으로, 폭이 좁은 화면(360px)에서도 카드가 화면 밖으로 넘치지 않는지 확인하고,
넘치면 카드 width를 고정값 대신 max-width로 바꿔서 작은 화면에 맞게 줄어들게 해줘.
```

## 붙여넣을 때 지켜야 할 것 (중요)

- **이미지 먼저, 말은 짧게.** 디자인은 글로 설명할수록 애매해집니다. **스크린샷 한 장 + 한 줄 지시**가 가장 정확합니다.
- **AI가 "이미지에서 읽어낸 것"을 먼저 말하게** 합니다. 잘못 본 걸 코드 받기 전에 잡는 장치입니다.
- **고칠 땐 다른 부분만.** "1·2·3만 고치고 나머지는 그대로"라고 못 박습니다.
- **스택을 명시**합니다(HTML/CSS만, flexbox, 파일 2개). 안 적으면 AI가 멋대로 Tailwind 같은 걸 끌어옵니다.
- **개인정보·비밀 값이 담긴 화면은 캡처하지 않습니다.** 시안에 진짜 이름·이메일·전화번호·결제정보,
  또는 화면 한쪽의 API 키·토큰이 보인다면, 캡처 전에 **모자이크 처리하거나 가짜 값(예: `홍길동`, `<여기에-키-가림>`)으로 바꾼 뒤** 올리세요.
  업로드한 이미지도 외부 서비스로 나가는 데이터라는 점을 잊지 마세요.
