# 075 · 이미지 슬라이더 만들기 (이전/다음 버튼)

여러 장의 사진을 좌우 버튼으로 한 장씩 넘기고, 마지막 사진에서 "다음"을 누르면 다시 첫 사진으로 돌아오는(순환) 슬라이더를 만듭니다. 자바스크립트의 **배열 인덱스**와 **나머지 연산(%)**, 그리고 CSS **transform**으로 화면을 미는 원리를 배웁니다.

## 목표

- "지금 몇 번째 사진인가"를 숫자 하나(`index`)로 기억하는 방법을 이해한다.
- 버튼 클릭으로 `index`를 바꾸고, 그 값에 맞춰 화면을 다시 그리는 흐름을 익힌다.
- 나머지 연산(`%`)으로 끝에서 처음으로 자연스럽게 순환시키는 기법을 익힌다.
- `transform: translateX()`로 여러 이미지를 통째로 좌우로 미는 방법을 이해한다.

## 따라하는 단계

1. **폴더 열기**: `examples/075` 폴더 안에 `index.html`, `style.css`, `script.js` 세 파일이 있습니다. `index.html`을 브라우저에서 더블클릭해 엽니다. (별도 설치 없이 바로 열립니다.)
2. **구조 보기**: `index.html`에서 `.viewport`(보이는 창) 안에 `.track`(이미지 5장을 가로로 늘어놓은 띠)이 들어 있는 구조를 확인합니다. 창은 한 장 크기만 보여주고, 나머지는 `overflow: hidden`으로 잘라 숨깁니다.
3. **CSS 핵심 확인**: `style.css`에서 `.track`에 `display: flex`(가로로 한 줄)와 `transition`(부드럽게 움직임)이, `.slide`에 `width: 100%`(한 장이 창을 꽉 채움)가 있는지 봅니다.
4. **JS 흐름 따라가기**: `script.js`에서 `index`(현재 번호)와 `total`(전체 장수)을 확인합니다.
5. **다음 버튼 원리**: `index = (index + 1) % total;` 한 줄이 핵심입니다. 마지막(4)에서 `(4 + 1) % 5 = 0`이 되어 처음으로 돌아갑니다.
6. **이전 버튼 원리**: `index = (index - 1 + total) % total;` 로 처음(0)에서 `(0 - 1 + 5) % 5 = 4`가 되어 마지막으로 갑니다. (`+ total`은 음수가 되는 것을 막는 장치입니다.)
7. **화면 갱신**: `update()` 함수가 `track.style.transform = translateX(-${index * 100}%)` 로 띠를 왼쪽으로 밀어 해당 사진을 보여주고, 아래 "1 / 5" 표시도 갱신합니다.
8. **직접 바꿔보기**: 이미지를 늘리거나 줄여도 코드는 그대로 동작합니다. `index.html`의 `.track` 안에 `<img class="slide">`를 한 줄 더 추가한 뒤 새로고침해 보세요. 전체 개수와 순환이 자동으로 맞춰집니다.

## 검증법

- "다음 ❯" 버튼을 5번 누르면 1 → 2 → 3 → 4 → 5 → **다시 1**로 돌아오는지 확인합니다.
- 첫 화면(1번)에서 "❮ 이전" 버튼을 누르면 곧장 **마지막(5번)**으로 넘어가는지 확인합니다.
- 사진이 바뀔 때마다 아래 표시가 `1 / 5`, `2 / 5` … 처럼 정확히 올라가는지 봅니다.
- 키보드 좌/우 화살표 키로도 똑같이 넘어가는지 확인합니다.
- 사진이 끊기지 않고 옆으로 **부드럽게 미끄러지며** 전환되는지 봅니다.
