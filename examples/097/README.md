# 097. 비밀번호 보기/숨기기 토글 버튼 만들기

비밀번호 입력칸 옆에 눈(👁) 버튼을 붙여, 누를 때마다 가려진 점(••••)과 실제 글자가 번갈아 보이도록 만듭니다. 로그인·회원가입 화면에서 흔히 보는 바로 그 기능입니다. 핵심은 입력칸의 `type` 속성을 `password`와 `text` 사이에서 바꾸는 것뿐입니다.

## 목표

- 입력칸의 `type` 속성을 JavaScript로 `password` ↔ `text`로 바꾸는 법을 익힙니다.
- 버튼 `click` 이벤트에 동작을 연결하는 법을 복습합니다.
- "지금 보이는 중인가?"를 기억하는 변수를 `true`/`false`로 뒤집는 **토글** 패턴을 경험합니다.

## 따라하는 단계

1. `097` 폴더 안에 `index.html`, `style.css`, `script.js` 세 파일이 같은 위치에 있는지 확인합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 가운데에 흰 카드와 비밀번호 입력칸, 오른쪽에 눈 버튼이 보입니다.
3. 입력칸에 아무 비밀번호(예: `mypassword1`)를 적습니다. 글자가 점(••••)으로 가려지는지 봅니다.
4. 오른쪽 눈 버튼(👁)을 한 번 누릅니다. 점이 실제 글자로 바뀌고, 아이콘이 🙈(가리기)로, 버튼 색이 보라색으로 바뀝니다.
5. 같은 버튼을 한 번 더 누릅니다. 다시 점으로 가려지고 아이콘이 👁로 돌아옵니다. 이렇게 누를 때마다 번갈아 바뀌는 것이 "토글"입니다.
6. `script.js`를 열어 `isVisible = !isVisible;`(상태 뒤집기)과 `input.type = "text"` / `input.type = "password"` 부분의 주석을 천천히 읽어 봅니다.

## 검증법

- 처음 화면: 입력한 글자가 점(••••)으로 가려져 있고, 버튼 아이콘은 👁이다.
- 눈 버튼을 1번 누름: 글자가 그대로 보이고, 아이콘이 🙈, 버튼이 보라색(강조)으로 바뀐다.
- 눈 버튼을 1번 더 누름: 다시 점으로 가려지고, 아이콘이 👁, 강조색이 사라진다.
- 버튼을 여러 번 눌러도 매번 정확히 보임/숨김이 번갈아 바뀐다.
- 눈 버튼을 눌러도 페이지가 새로고침되지 않는다(버튼이 `type="button"`이라서).
- "로그인" 버튼을 누르면 새로고침 없이 안내창(alert)만 뜬다.

## 더 알아두기

- 눈 버튼에 `type="button"`을 꼭 붙입니다. 폼 안의 버튼은 기본값이 "제출"이라, 빼먹으면 누를 때마다 페이지가 새로고침되어 토글이 작동하지 않는 것처럼 보입니다.
- `type="text"`로 바뀌면 비밀번호가 화면에 그대로 노출됩니다. 공공장소나 화면 공유 중에는 주의해야 한다는 점도 사용자 경험(UX)의 일부입니다.
- 여기서는 비밀번호를 화면에 "보여주기만" 합니다. 실제 로그인은 입력값을 서버로 보내 검증해야 합니다. 다음 단계에서 이 폼을 Supabase 인증(로그인)과 연결할 수 있습니다.
