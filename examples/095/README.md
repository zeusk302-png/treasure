# 입력하는 순간 글자 수 카운터 보여주기

타이핑할 때마다 "23/100"처럼 글자 수가 실시간으로 바뀌는 입력칸을 만듭니다. 트위터, 인스타그램 소개글, 문의 폼에서 흔히 보는 바로 그 기능입니다.

## 목표

- `input` 이벤트가 "글자가 바뀌는 순간마다" 실행된다는 것을 체험한다.
- 입력칸에 적힌 글자 개수를 `value.length`로 읽는 법을 익힌다.
- 읽은 숫자를 `textContent`로 화면에 다시 그려 넣는 법을 익힌다.

## 따라하는 단계

1. `index.html`, `style.css`, `script.js` 세 파일이 같은 폴더(`095`)에 있는지 확인합니다.
2. `index.html`을 더블클릭해 웹 브라우저로 엽니다. 입력칸 아래에 `0/100`이 보입니다.
3. 입력칸에 아무 글자나 한 글자 타이핑합니다. 곧바로 왼쪽 숫자가 `1`로 바뀝니다.
4. 계속 입력하면서 숫자가 글자 수에 맞춰 올라가는지 봅니다. (예: "안녕하세요"를 적으면 `5/100`)
5. 90자 이상 입력하면 카운터 글자가 빨간색으로 바뀌는지 확인합니다(한계가 가까워졌다는 경고).
6. `script.js`를 열어 동작 원리를 살펴봅니다. 핵심은 아래 두 줄입니다.
   - `const length = textarea.value.length;` -> 입력칸의 글자 수를 읽음
   - `countEl.textContent = length;` -> 그 숫자를 화면에 표시
7. 직접 바꿔보기: `script.js`의 `MAX` 값과 `index.html`의 `maxlength` 값을 둘 다 `50`으로 바꾸고, `<span id="max">100</span>`도 `50`으로 고쳐 50자 제한 버전으로 만들어 봅니다.

## 검증법

- 입력칸이 비어 있을 때 `0/100`으로 표시되면 정상입니다(초기 상태).
- 글자를 하나 칠 때마다 왼쪽 숫자가 즉시 1씩 늘어나면 `input` 이벤트가 잘 연결된 것입니다.
- 입력칸 내용을 모두 지우면 다시 `0/100`으로 돌아와야 합니다.
- 100자까지 채우면 `maxlength` 때문에 더 이상 입력되지 않고 숫자가 `100`에서 멈춥니다.
- 90자를 넘기면 카운터 색이 빨갛게 변합니다.
- (참고) 띄어쓰기와 줄바꿈도 한 글자로 세어집니다. 한글 한 글자도 1로 셉니다.
