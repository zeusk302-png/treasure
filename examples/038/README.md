# 본문은 자동, 사이드바는 고정인 2단 레이아웃 만들기

블로그, 쇼핑몰, 관리자 화면에서 가장 많이 쓰는 **"본문 + 사이드바" 2단 레이아웃**을 CSS flexbox로 만들어 봅니다. 본문(왼쪽)은 화면 크기에 따라 자동으로 넓어지고, 사이드바(오른쪽)는 항상 같은 너비를 유지합니다.

## 목표

- `display: flex` 로 부모를 **flex 컨테이너**로 만들어 자식들을 가로로 나란히 놓는다.
- 사이드바에는 `width`(고정 너비) + `flex-shrink: 0`(줄어들지 않게)을 줘서 **고정 영역**으로 만든다.
- 본문에는 `flex: 1` 을 줘서 **남은 공간을 모두 차지하는 가변 영역**으로 만든다.
- "고정 칸 + 가변 칸"이라는 실무에서 가장 흔한 레이아웃 패턴을 손에 익힌다.

## 따라하는 단계

1. `examples/038/` 폴더 안의 `index.html`, `style.css` 두 파일을 준비합니다. (이미 만들어져 있습니다)
2. **HTML 뼈대 이해하기**: `index.html`에서 `<div class="layout">` 이 부모(컨테이너)이고, 그 안에 본문 `<main class="content">` 와 사이드바 `<aside class="sidebar">` 두 칸이 들어 있습니다. 이 두 칸을 좌우로 나눌 것입니다.
3. **부모를 flex로 만들기**: `style.css`에서 `.layout` 에 `display: flex;` 를 줍니다. 이 한 줄 덕분에 본문과 사이드바가 위아래가 아니라 **가로로 나란히** 놓입니다.
4. **사이드바를 고정하기**: `.sidebar` 에 `width: 240px;` 로 너비를 정하고, `flex-shrink: 0;` 을 추가합니다. `flex-shrink: 0` 은 "공간이 부족해도 절대 줄어들지 마라"는 뜻이라 사이드바가 항상 240px을 유지하게 됩니다. (이게 없으면 화면이 좁을 때 사이드바도 같이 쪼그라듭니다.)
5. **본문을 가변으로 만들기**: `.content` 에 `flex: 1;` 을 줍니다. 사이드바가 가져간 240px을 뺀 **나머지 공간 전부**를 본문이 차지하게 됩니다.
6. **간격 주기**: `.layout` 에 `gap: 20px;` 을 줘서 본문과 사이드바 사이에 보기 좋은 틈을 만듭니다.
7. **브라우저로 열기**: `index.html` 을 더블클릭하거나 브라우저로 끌어다 놓아 화면을 확인합니다.
8. **(보너스) 모바일 대응**: 맨 아래 `@media (max-width: 768px)` 부분에서 `flex-direction: column;` 으로 바꿔, 화면이 좁아지면 본문 위에 사이드바가 세로로 쌓이게 했습니다.

## 검증법

- 브라우저로 `index.html` 을 열면 **왼쪽에 넓은 본문, 오른쪽에 좁은 사이드바**가 좌우로 나란히 보입니다.
- 브라우저 창의 가로 너비를 마우스로 **늘였다 줄여보세요.** 본문은 같이 넓어지고 좁아지지만, **사이드바는 항상 240px로 똑같은 너비**를 유지하면 성공입니다.
- 창을 아주 좁게(768px 이하) 줄이면 사이드바가 본문 아래로 **세로로 쌓이면** 보너스 모바일 대응까지 정상 동작하는 것입니다.
- 개발자 도구(F12)로 `.sidebar` 를 클릭해 보면 너비가 240px로 고정되어 있는지 확인할 수 있습니다.

## 자주 하는 실수

- `.layout` 에 `display: flex` 를 깜빡하면 본문과 사이드바가 좌우가 아니라 위아래로 쌓입니다.
- 사이드바에 `flex-shrink: 0` 을 빼먹으면, 화면이 좁아질 때 사이드바도 240px보다 작아져 버립니다. "고정"이 되려면 이 한 줄이 꼭 필요합니다.
- `flex: 1` 은 본문(가변)에만 줘야 합니다. 사이드바에도 주면 둘 다 공간을 나눠 가져 고정 너비가 깨집니다.
