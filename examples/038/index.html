오늘 배운 것

화면을 좌우 두 칸으로 나누는 가장 흔한 방법이 바로 "본문 + 사이드바" 레이아웃입니다. 블로그, 쇼핑몰, 관리자 화면 대부분이 이 구조를 씁니다.

이 페이지에서 본문(왼쪽)은 화면이 넓어지면 같이 넓어지고, 좁아지면 같이 좁아집니다. 반면 사이드바(오른쪽)는 항상 240px 너비를 유지합니다. 브라우저 창 너비를 마우스로 늘였다 줄여보세요.

이 레이아웃의 비밀

  • 부모(.layout)에 display: flex 를 줍니다.
  • 사이드바에는 width: 240px; flex-shrink: 0; → 고정 너비.
  • 본문에는 flex: 1; → 남은 공간을 전부 차지.
