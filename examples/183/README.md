# 실습 183 — 모든 이미지에 의미 있는 alt 텍스트 붙이기

사이트의 모든 `<img>`에 "이 사진에 무엇이 보이는지"를 설명하는 **alt 텍스트**를 달아, 눈으로 화면을 볼 수 없는 사람(스크린리더 사용자)과 검색엔진이 이미지를 이해하게 만드는 실습입니다. (난이도 1, 카테고리: SEO·성능·접근성)

> alt(alternative text, 대체 텍스트)는 이미지가 안 보일 때 대신 읽히는 글자예요. 이미지가 깨져서 안 뜰 때 화면에 나타나는 글자, 시각장애인이 쓰는 스크린리더가 소리내어 읽어주는 글자, 그리고 구글이 이미지를 이해하는 단서가 모두 이 alt입니다.

## 목표
- 내용을 전달하는 이미지에는 "무엇이 보이는지"를 한 문장으로 적은 `alt`를 단다.
- 순수 장식용 이미지(아무 정보 없는 점·선·배경 같은 것)는 `alt=""`(빈 값)으로 비워 스크린리더가 건너뛰게 한다.
- 흔한 실수 5가지(alt 없음 / 파일명 / "이미지"라고만 씀 / 장식인데 글자 넣음 / title로 대신함)를 깨진 예시(`broken.html`)에서 직접 찾아 고친다.

## 따라하는 단계
1. 이 폴더의 `broken.html`을 더블클릭해 브라우저로 연다. (이미지 파일은 일부러 넣지 않아 회색 박스로 보이지만, 실습 목적상 문제없다 — 우리가 볼 것은 **태그 안의 alt 글자**다.)
2. 브라우저에서 마우스 우클릭 → "페이지 소스 보기"를 하거나, 코드 편집기로 `broken.html`을 연다. 그리고 `<img` 가 몇 개 있는지, 각각 `alt` 가 어떻게 적혀 있는지 본다.
3. 아래 "무엇이 틀렸나" 표를 보며 5군데를 직접 고친다.
   - 로고 → `alt="우리 빵집 로고"` 를 추가한다.
   - `alt="IMG_2034.jpg"` → 사진 내용을 설명하는 문장으로 바꾼다. (예: `alt="겉이 노릇하게 구워진 통밀 식빵"`)
   - `alt="이미지"` → 실제로 보이는 것(크루아상)을 설명하는 문장으로 바꾼다.
   - 장식용 점 아이콘의 `alt="장식 이미지"` → `alt=""`(빈 값)으로 바꾼다.
   - `title` 만 있고 `alt` 가 없는 커피 사진 → `alt="..."` 를 추가한다. (title은 남겨둬도 되지만 alt를 대신하지는 못한다.)
4. 고친 `broken.html`을 새로고침한 뒤, 정답 파일 `index.html`과 한 줄씩 비교해 본다.
5. AI에게 점검을 시켜 본다:
   > "이 HTML의 모든 `<img>`에 의미 있는 alt가 있는지 점검해줘. 파일명·'이미지'처럼 쓸모없는 alt, 장식용인데 비우지 않은 alt, alt가 없는 이미지를 찾아 고쳐줘."

## 무엇이 틀렸나 / 어떻게 고치나 (broken.html)
| # | 문제 | 왜 나쁜가 | 고치는 법 |
| --- | --- | --- | --- |
| 1 | 로고에 `alt`가 아예 없음 | 스크린리더가 파일 경로(`logo.png`)를 그대로 읽어버림 | `alt="우리 빵집 로고"` 추가 |
| 2 | `alt="IMG_2034.jpg"` (파일명) | 사진이 무엇인지 전혀 알 수 없음 | `alt="겉이 노릇하게 구워진 통밀 식빵"` 처럼 내용 설명 |
| 3 | `alt="이미지"` | "이미지"라는 말은 정보가 0 | `alt="결이 살아 있는 황금빛 버터 크루아상"` 처럼 구체적으로 |
| 4 | 장식용 점인데 `alt="장식 이미지"` | 의미 없는 이미지를 스크린리더가 굳이 읽어 거슬림 | `alt=""` (빈 값)으로 비워서 건너뛰게 |
| 5 | `title`만 있고 `alt` 없음 | `title`은 마우스 올렸을 때 잠깐 뜨는 보조일 뿐, alt를 대체 못 함 | `alt="하얀 잔에 담긴 따뜻한 핸드드립 커피"` 추가 |

> alt 한 줄 요약: **"이미지가 안 보여도 글만 읽어서 같은 정보를 얻을 수 있게"** 적으면 된다. 단, 아무 정보 없는 장식은 `alt=""`로 비운다.

## 검증법
- 코드에서 `<img` 를 모두 찾았을 때, **빠짐없이 `alt=` 속성이 있다.** (장식용은 `alt=""`로 비어 있어야 한다 — 속성 자체가 없는 것과 다르다.)
- 어떤 alt에도 파일 이름(`.jpg`, `.png`)이나 "이미지", "사진", "그림"만 달랑 적혀 있지 않다.
- (눈으로 확인) `broken.html`에서 `src`를 일부러 틀린 주소로 바꿔 새로고침하면, 깨진 이미지 자리에 alt 글자가 그대로 보인다 → alt가 잘 적혔는지 직접 눈으로 확인 가능.
- (선택) 크롬 개발자도구(F12) → Lighthouse → Accessibility를 돌리면 "Image elements have `[alt]` attributes" 항목이 통과(초록)로 뜬다.
