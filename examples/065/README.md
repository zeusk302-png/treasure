# 065 · + − 버튼으로 숫자 카운터 만들기

쇼핑몰의 수량 선택 같은 "숫자를 1씩 올리고 내리는" 위젯을 만들어 봅니다. 버튼을 누르면 자바스크립트가 숫자를 기억하고(변수), 화면에 다시 그려주는 흐름을 처음부터 끝까지 경험합니다.

## 목표

- `+` 버튼을 누르면 숫자가 1 늘고, `−` 버튼을 누르면 1 줄어드는 카운터를 만든다.
- 현재 값을 변수 하나에 저장해 두고(상태), 값이 바뀔 때마다 화면에 반영하는 흐름을 익힌다.
- 핵심 개념: 변수에 상태 저장, 증감 연산(`+ 1`, `- 1`), 그리고 "값 변경 → 화면 다시 그리기" 패턴.

## 따라하는 단계

1. 폴더 `065` 안에 `index.html`, `style.css`, `script.js` 세 파일이 있는지 확인합니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다. 가운데 카드에 `−  0  +` 모양의 카운터와 "0으로 초기화" 버튼이 보입니다.
3. `script.js`를 열어 위에서부터 읽어 봅니다.
   - `document.getElementById(...)`로 숫자 칸과 버튼들을 코드로 붙잡습니다.
   - `let count = 0;` 이 한 줄이 지금 카운터의 값을 **기억하는 변수**입니다.
   - `render()` 함수는 `count` 변수의 값을 화면(span)에 다시 써 주는 역할만 합니다.
4. `+` 버튼 부분을 봅니다. `count = count + 1;`로 값을 1 늘린 뒤 `render()`를 불러 화면을 갱신합니다. (이것이 **증가 연산**입니다.)
5. `−` 버튼은 `count = count - 1;`로 값을 1 줄인 뒤 똑같이 `render()`를 부릅니다. (**감소 연산**)
6. 직접 바꿔 보기: `count = count + 1;`을 `count = count + 2;`로 고치고 저장한 뒤 브라우저를 새로고침하면 한 번에 2씩 올라갑니다. 다시 1로 되돌려 둡니다.
7. (도전) 숫자가 0보다 작아지지 않게 하고 싶다면, `−` 버튼 안에서 `if (count > 0) { count = count - 1; }` 처럼 조건을 걸어 봅니다.

## 검증법

- 브라우저에서 `+`를 3번 누르면 숫자가 `3`이 되고, `−`를 1번 누르면 `2`가 되는지 확인합니다.
- "0으로 초기화" 버튼을 누르면 어떤 값이든 즉시 `0`으로 돌아가는지 확인합니다.
- 버튼을 빠르게 여러 번 눌러도 숫자가 정확히 누른 횟수만큼 변하는지 봅니다. (변수 `count`가 상태를 제대로 기억한다는 뜻)
- 6단계 실험: 코드를 `+ 2`로 바꿨을 때 실제로 2씩 증가하면, 화면이 변수 값을 그대로 따라간다는 것을 확인한 것입니다.
