실습 300 — Supabase RLS, 켜기 전과 후 비교

아래 공개(publishable/anon) 키로 같은 테이블을 조회합니다. SQL Editor에서 schema.sql의 단계를 실행할 때마다 여기서 버튼을 눌러 결과가 어떻게 달라지는지(=몇 줄이 보이는지)를 캡처하세요.

① 내 Supabase 값 넣기 — Settings → API 에서 복사한 값으로 아래 두 줄을 바꾸세요.

여기 넣는 건 publishable(anon) 키입니다. service_role(secret) 키는 절대 넣지 마세요.

② secret_notes 조회 (원래 새면 안 되는 개인 데이터)

읽힌 줄 수: -

아직 조회하지 않음
1단계(RLS 끔) 상태에서는 전화번호 3줄이 다 보입니다 = 새는 증거.
2단계(RLS 켬) 실행 후 다시 누르면 0줄 = 막힌 증거. 키는 그대로인데 결과가 달라집니다.

③ public_posts 조회 (원래 누구나 읽어도 되는 공개 데이터)

읽힌 줄 수: -

아직 조회하지 않음
3단계 실행 후, "읽기 허용 정책"이 있어서 RLS를 켜도 2줄이 보입니다. RLS는 "전부 막기"가 아니라 "필요한 행만 열기"입니다.
