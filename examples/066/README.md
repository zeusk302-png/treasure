# 066 · 좋아요 하트 토글 + 개수 세기

인스타그램이나 유튜브에서 보던 "하트를 누르면 빨갛게 채워지고 좋아요 수가 1 올라가는" 버튼을 직접 만들어 봅니다. 이번 실습의 핵심은 **두 가지 상태를 함께 다루기**입니다. 하나는 "지금 좋아요를 눌렀나?(켜짐/꺼짐)"라는 토글 상태이고, 다른 하나는 "좋아요가 몇 개인가?"라는 숫자 상태입니다.

## 목표

- 하트 버튼을 누르면 빈 하트(♡)가 빨간 하트(♥)로 바뀌고, 다시 누르면 원래대로 돌아가는 **토글**을 만든다.
- 좋아요를 누르면 개수가 +1, 취소하면 -1 되도록 **숫자 상태**를 함께 관리한다.
- 핵심 개념: 참/거짓을 뒤집는 토글(`liked = !liked`), 숫자를 더하고 빼는 카운트, 그리고 "상태가 바뀌면 → 화면을 다시 그린다"는 패턴.

## 따라하는 단계

1. 폴더 `066` 안에 `index.html`, `style.css`, `script.js` 세 파일이 있는지 확인합니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다. 사진 카드 아래에 회색 하트와 "12명이 좋아합니다"가 보입니다.
3. 하트를 한 번 눌러 봅니다. 하트가 빨갛게 채워지고 숫자가 `13`으로 올라갑니다. 다시 누르면 회색으로 돌아가고 `12`로 줄어듭니다.
4. `script.js`를 열어 위에서부터 읽어 봅니다.
   - `let liked = false;` — 지금 좋아요를 눌렀는지 기억하는 **토글 상태**입니다. 처음엔 안 눌렀으니 `false`.
   - `let likeCount = 12;` — 좋아요가 몇 개인지 기억하는 **숫자 상태**입니다.
   - `render()` 함수는 이 두 변수의 값을 보고 화면(하트 색·모양과 숫자)을 다시 그려 주는 역할만 합니다.
5. 버튼을 눌렀을 때 부분(`addEventListener`)을 봅니다.
   - `liked = !liked;` 가 **토글의 핵심**입니다. 느낌표(`!`)는 "반대로 뒤집기"라는 뜻이라, `false`면 `true`로, `true`면 `false`로 바뀝니다.
   - 그 아래 `if`에서 `liked`가 참이면 `likeCount + 1`, 거짓이면 `likeCount - 1`로 숫자를 함께 바꿉니다.
   - 마지막에 `render()`를 불러 두 상태를 한 번에 화면에 반영합니다.
6. 직접 바꿔 보기: `let likeCount = 12;`를 `let likeCount = 0;`으로 고치고 저장한 뒤 새로고침하면 0부터 시작합니다. 다시 12로 되돌려 둡니다.
7. (도전) 좋아요 수가 100을 넘으면 "100+"로 표시하고 싶다면, `render()` 안 숫자 표시 부분을 `countEl.textContent = likeCount > 100 ? "100+" : likeCount;` 처럼 바꿔 봅니다.

## 검증법

- 하트를 눌렀을 때 (1) 하트가 빨갛게 채워지고 **동시에** (2) 숫자가 1 올라가면 두 상태가 함께 잘 움직이는 것입니다.
- 한 번 더 누르면 하트가 회색으로 돌아가고 숫자가 1 줄어드는지 확인합니다. (토글이 정확히 켜짐↔꺼짐을 오가는지)
- 하트를 빠르게 여러 번(예: 6번) 눌러 봅니다. 짝수 번 누르면 처음 숫자(12)로, 홀수 번 누르면 +1(13)로 정확히 돌아오는지 확인합니다. (상태가 어긋나지 않는다는 뜻)
- 6단계 실험: 시작값을 0으로 바꿨을 때 화면도 0부터 시작하면, 화면이 변수 값을 그대로 따라간다는 것을 확인한 것입니다.
