# 268. 웹게임: 숫자 맞히기 미니게임 만들기

컴퓨터가 1부터 100 사이에서 몰래 정한 숫자를 맞히는 **미니게임**입니다.
내가 입력한 숫자가 정답보다 크면 "더 작게", 작으면 "더 크게" 힌트를 주고,
**시도 횟수**와 **경과 시간(타이머)**이 화면에서 실시간으로 움직입니다.

게임을 만들 때 항상 등장하는 세 가지 재료 — **상태(정답·시도 횟수)**, **게임 루프(입력→비교→힌트 반복)**, **타이머** — 를 가장 단순한 형태로 한 번에 경험하는 한 단계짜리 실습입니다. 설치도, 인터넷 연결도 필요 없습니다.

## 목표

- "지금 게임이 어떤 상태인가"(정답이 무엇인지, 몇 번 시도했는지, 끝났는지)를 **변수에 담아 관리**하는 감을 잡는다.
- 입력 → 정답과 비교 → 힌트 표시를 정답이 나올 때까지 반복하는 **게임 루프**가 어떻게 돌아가는지 본다.
- `setInterval`로 경과 시간을 0.1초마다 갱신하고, 게임이 끝나면 `clearInterval`로 **타이머를 멈추는** 법을 익힌다.
- 빈 칸이나 범위 밖(예: 0, 200) 입력을 막아 **잘못된 입력을 걸러내는** 기본기를 갖춘다.

## 따라하는 단계

1. 이 폴더(`268/`)의 `index.html` 파일을 **더블클릭**해서 웹 브라우저(크롬, 엣지 등)로 엽니다.
2. 페이지가 열리면 게임이 **자동으로 시작**됩니다. 가운데 칸에 `1`부터 `100` 사이의 숫자를 적고 **[확인]** 버튼을 누르거나 **엔터** 키를 칩니다.
3. 힌트를 보고 다시 시도합니다.
   - 빨간 "**더 큰 숫자예요! ↑**" → 내가 적은 수보다 정답이 **큽니다**.
   - 파란 "**더 작은 숫자예요! ↓**" → 내가 적은 수보다 정답이 **작습니다**.
   - 이 힌트를 활용해 범위를 절반씩 좁혀 가면 보통 7번 안에 맞힐 수 있습니다.
4. 위쪽 상태판에서 **시도 횟수**가 1씩 늘고, **경과 시간**이 멈추지 않고 흐르는지 확인합니다. 시도할 때마다 아래에 기록(예: `50 (UP)`)이 쌓입니다.
5. 정답을 맞히면 초록색으로 "**정답! 73 (5번 만에, 8.2초)**" 같은 메시지가 뜨고, 타이머가 **그 시각에 멈춥니다**. 입력칸도 잠깁니다.
6. 맨 아래 **[새 게임 시작]** 버튼을 누르면 새 정답이 정해지고, 횟수와 타이머가 0으로 초기화되어 처음부터 다시 할 수 있습니다.
7. (실험) `game.js`를 메모장으로 열어 `Math.floor(Math.random() * 100) + 1`에서 `100`을 `10`으로 바꿔 저장하고 브라우저를 **새로고침(F5)** 해 보세요. → 1~10 사이의 더 쉬운 게임으로 바뀝니다. 범위를 내가 정할 수 있다는 걸 확인했으면 다시 `100`으로 되돌립니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고 **1단계 → 2단계 → (막히면) 디버깅** 순서로 나눠서 시키면, 중간 결과를 직접 눈으로 보며 옳은지 판별할 수 있습니다.

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 바닐라 자바스크립트(라이브러리·설치 없이) 웹게임을 만드는 조수야.
  파일은 index.html(화면+CSS)과 game.js(로직) 둘로 나눠 줘.
  목표: "숫자 맞히기 미니게임".
  규칙:
  - 컴퓨터가 1~100 사이 무작위 정수 하나를 정답으로 정한다.
  - 사용자가 칸에 숫자를 적고 [확인]을 누르면, 정답보다 작으면 "더 큰 숫자예요",
    크면 "더 작은 숫자예요", 같으면 "정답"이라고 알려 준다.
  - 화면 위쪽에 '시도 횟수'를 표시하고, 맞힐 때마다 1씩 늘린다.
  먼저 가장 단순한 동작만 되게 만들고, 코드만 주지 말고 왜 그렇게 했는지
  한국어 주석으로 한 줄씩 설명해 줘(변수·함수 이름은 영어로).
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  위 게임에 아래 기능을 추가해 줘. 기존 코드를 망가뜨리지 말고 필요한 부분만 더해 줘.
  1) 경과 시간 타이머: 게임이 시작되면 0.1초마다 흐르는 '경과 시간'을 화면에 보여 주고,
     정답을 맞히는 순간 타이머를 멈춰 줘(setInterval로 시작, clearInterval로 멈춤).
  2) 잘못된 입력 막기: 빈 칸이거나 1~100 범위 밖(예: 0, 200)이면
     "1부터 100 사이의 숫자를 입력하세요"를 띄우고 시도 횟수는 늘리지 마.
  3) [새 게임 시작] 버튼: 누르면 정답·시도 횟수·타이머를 모두 0으로 초기화하고
     새 정답을 정해 줘.
  4) 엔터 키로도 [확인]이 눌리게 해 줘.
  각 기능마다 "왜 이 코드가 필요한지"를 주석으로 설명해 줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  버튼을 눌러도 아무 반응이 없어. 브라우저에서 F12 > Console 탭에 뜬 빨간 에러는 아래와 같아:
  (여기에 에러 메시지를 그대로 붙여넣기)
  무엇이 문제인지 비전공자도 알아듣게 한 단계씩 짚어 주고,
  고친 코드와 "왜 이렇게 고쳤는지" 이유를 함께 알려 줘.
  추측하지 말고, index.html의 <script src="game.js"></script> 위치와
  요소 id(guessInput, guessBtn 등)가 game.js와 일치하는지부터 확인해 줘.
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과물을 검증하는 눈이 길러집니다.

## 검증법

- **게임 진행 확인**: 숫자를 입력하면 힌트("더 크게"/"더 작게")가 색깔과 함께 바뀌고, 정답을 적으면 초록색 성공 메시지가 뜬다.
- **상태 변화 확인**: [확인]을 누를 때마다 상단의 **시도 횟수가 정확히 1씩** 증가한다. 아래 기록 목록에도 한 줄씩 쌓인다.
- **타이머 확인**: 게임 중에는 경과 시간이 **0.1초 단위로 계속 흐르고**, 정답을 맞히는 **순간 멈춰서** 더 이상 올라가지 않는다.
- **초기화 확인**: [새 게임 시작]을 누르면 시도 횟수와 타이머가 **0으로 돌아가고**, 입력칸이 다시 활성화되며, 정답도 새로 바뀐다(이전 정답으로는 못 맞힌다).
- **잘못된 입력 확인**: 빈 칸으로 [확인]을 누르거나 `0`, `200`처럼 범위 밖 숫자를 넣으면 "1부터 100 사이의 숫자를 입력하세요."가 뜨고, **시도 횟수는 늘지 않는다**.
- **에러가 날 때**: 버튼을 눌러도 아무 반응이 없으면 `F12`(개발자 도구) → **Console** 탭에 빨간 에러가 있는지 보고, `index.html` 맨 아래에 `<script src="game.js"></script>` 줄이 있는지, 파일 이름이 `game.js`가 맞는지 확인합니다.

## 핵심 정리

- **상태(state)**: `answer`(정답), `tries`(시도 횟수), `isPlaying`(진행 중 여부)처럼 "지금 게임이 어떤 형편인지"를 담은 변수들입니다. 게임은 결국 이 값들을 바꿔 가는 일입니다.
- **게임 루프**: 한 번의 [입력 → 정답과 비교 → 힌트 표시]가 루프의 한 바퀴(`handleGuess` 함수)입니다. 정답을 맞힐 때까지 사용자가 이 바퀴를 계속 돌립니다.
- **타이머**: `setInterval(updateTimer, 100)`은 "0.1초마다 시간을 다시 그려줘"라는 명령이고, `clearInterval(timerId)`은 "이제 그만 멈춰"입니다. **시작한 타이머는 반드시 멈춰 줘야** 합니다(안 그러면 게임이 끝나도 계속 흐릅니다).
