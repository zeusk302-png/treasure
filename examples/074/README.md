# 별점(★) 평점 입력 위젯 만들기

쇼핑몰 리뷰나 앱 평가에서 흔히 보는 **별점 입력기**를 만드는 실습입니다.
별 위에 마우스를 **올리면** 그 별까지 미리보기로 채워지고, **클릭하면** 그 점수로 고정됩니다.

이번 실습의 핵심은 **"마우스를 올림(mouseover) / 치움(mouseout) / 클릭(click)을 조합해서, 몇 번째 별까지 채울지(인덱스) 정하는 것"** 입니다.

## 목표

- 별마다 적어 둔 점수(`data-value="3"`)를 자바스크립트로 **읽어** 활용하기.
- `mouseover`(마우스 올림)로 그 별까지 **미리보기** 채우기.
- `mouseout`(마우스 치움)으로 미리보기를 지우고, **클릭으로 고정한 점수**로 되돌리기.
- `click`으로 점수를 **고정 저장**하고(`selectedValue` 변수), 화면에 "N / 5 점" 글자로 보여 주기.
- "별 N개 채우기"를 함수 하나(`paintStars`)로 만들어 **세 가지 동작이 같은 함수를 재사용**하게 하기 (인덱스 기반 채움).

## 따라하는 단계

1. 이 폴더(`074`)에 있는 세 파일을 확인합니다.
   - `index.html` : 화면 뼈대 (별 5개 버튼 + 점수 표시 문구).
   - `style.css`  : 별 색(빈 별 회색 / 채운 별 노랑)과 크기 꾸밈.
   - `script.js`  : 마우스를 올리고/치우고/클릭할 때의 동작.
2. `index.html` 파일을 더블클릭해서 웹 브라우저(크롬 등)로 엽니다. (인터넷 연결이 없어도 됩니다)
3. 별 위에 마우스를 **올려** 봅니다. 마우스가 가리키는 별까지 **노랗게** 채워지면 정상입니다. (예: 3번째 별에 올리면 1·2·3번 별이 채워짐)
4. 마우스를 별 영역 **바깥으로 치워** 봅니다. 아직 클릭한 적 없으면 별이 **전부 회색**으로 돌아갑니다.
5. 별 하나를 **클릭**합니다. 그 점수로 **고정**되고, 아래에 "N / 5 점을 선택했어요" 가 뜹니다.
6. 다시 다른 별 위에 마우스를 올렸다 치워 봅니다. 미리보기가 보였다가, 마우스를 치우면 **방금 클릭해 고정한 점수**로 되돌아가야 합니다.
7. 코드를 직접 살펴봅니다.
   - `index.html`의 별 버튼마다 `data-value="1"`, `"2"` … 가 붙어 있습니다. 이게 "이 별이 몇 점짜리인지" 이름표입니다.
   - `script.js`의 `paintStars(value)` 함수가 핵심입니다. `value` 이하인 별에만 `.filled` 클래스를 붙여 노랗게 칠합니다.
   - `mouseover`는 `paintStars(올린 별 점수)`, `mouseout`은 `paintStars(selectedValue)`(고정 점수), `click`은 `selectedValue`를 바꾼 뒤 다시 칠합니다. **같은 함수를 세 곳에서 재사용**하는 점을 확인하세요.
8. (실험) `script.js`의 별 개수를 늘려 봅니다. `index.html`에서 별 버튼을 복사해 `data-value="6"`을 추가하고, `click`의 표시 글자 `" / 5 점..."`을 `" / 6 점..."`으로 바꾼 뒤 **새로고침(F5)** 하면 6점 만점 위젯이 됩니다. 자바스크립트는 별 개수를 자동으로 따라갑니다.

## 검증법

- 마우스를 별에 올리면 **그 별까지** 노랗게 채워지고, 그 위 별들은 회색으로 남아야 합니다.
- 마우스를 치우면(아직 클릭 전) **전부 회색**으로 돌아가야 합니다.
- 별을 클릭하면 점수가 **고정**되고, 마우스를 치워도 그 점수만큼은 노란색으로 **유지**되어야 합니다.
- 아래 글자가 "3 / 5 점을 선택했어요"처럼 **클릭한 점수와 일치**하면 성공입니다.
- 키보드 `Tab`으로 별 사이를 이동하고 `Enter`/`Space`로 클릭해도 동작하면(버튼이라서) 접근성까지 통과입니다.
- 잘 안 될 때 점검할 곳:
  - 색이 안 바뀌면: `style.css`의 `.star.filled` 클래스 이름과 `script.js`의 `classList.add("filled")` 철자가 **똑같은지** 확인합니다.
  - 미리보기는 되는데 클릭 고정이 안 되면: `script.js`에서 `selectedValue = starValue;` 줄이 `click` 안에 있는지 확인합니다.
  - 마우스를 치워도 안 비워지면: `mouseout`을 **별 하나하나**가 아니라 **별 상자(`ratingBox`)에 한 번만** 걸었는지 확인합니다. (별마다 걸면 옆 별로 옮길 때 깜빡입니다)
  - 그래도 안 되면 브라우저에서 `F12` → **Console** 탭에 빨간 에러가 있는지 봅니다. (보통 id/클래스 철자 오타입니다)

## 핵심 정리

- **`mouseover` vs `mouseout`**: 마우스가 요소 위로 "들어올 때"와 "벗어날 때" 일어나는 이벤트입니다. 둘을 짝지으면 "올리면 미리보기, 치우면 원상복구"가 됩니다.
- **고정 상태 변수**: 클릭으로 정한 점수를 변수(`selectedValue`)에 따로 보관합니다. 미리보기는 화면만 바꾸고, 진짜 점수는 이 변수에 있습니다.
- **함수 재사용**: "별 N개 채우기"를 `paintStars(N)` 함수 하나로 만들면, 미리보기·복구·고정 세 동작이 전부 이 함수를 부르기만 하면 됩니다. (코드가 짧고 헷갈리지 않습니다)
- **`data-*` 속성과 `dataset`**: HTML에 `data-value="3"`처럼 정보를 숨겨 두고, 자바스크립트에서 `요소.dataset.value`로 꺼냅니다. (꺼낸 값은 글자라서 `Number(...)`로 숫자 변환)
