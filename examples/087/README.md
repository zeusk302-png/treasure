# 실습 087 — 입력 종류 6종 모아보기 (이메일·전화·숫자·날짜·색상·범위)

입력칸(`<input>`)은 사실 **한 가지 모습이 아닙니다.** `type` 속성 한 곳만 바꾸면 같은 입력칸이 이메일 칸도, 전화 칸도, 달력도, 색상 선택기도, 슬라이더도 됩니다. 이번 실습에서는 자주 쓰는 6가지 종류를 한 페이지에 모아 놓고 직접 눌러 보며 차이를 체험합니다.

코드는 단 한 파일(`index.html`)이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭으로 바로 열 수 있어요.

> **핵심 한 줄:** 6개 입력칸의 진짜 차이는 오직 `type="..."` 한 글자뿐입니다. 나머지(글씨·여백)는 보기 좋게 꾸민 것일 뿐이에요.

| `type` 값 | 어떤 칸이 되나 | 눌러 보면 |
|---|---|---|
| `email` | 이메일 입력칸 | 모바일 자판에 **@ 기호**가 보임 |
| `tel` | 전화번호 입력칸 | 모바일에서 **전화 숫자 키패드**가 올라옴 |
| `number` | 숫자 입력칸 | 칸 오른쪽에 **위·아래 화살표**가 생김 |
| `date` | 날짜 입력칸 | 누르면 **달력**이 펼쳐짐 |
| `color` | 색상 선택칸 | 누르면 **색상 팔레트**가 뜸 |
| `range` | 범위 슬라이더 | **손잡이를 좌우로** 끌어 값 조절 |

## 목표
- `<input>`의 `type` 속성을 바꾸면 입력칸 모습이 통째로 달라진다는 것을 눈으로 확인한다.
- `email` / `tel` / `number` / `date` / `color` / `range` 6가지 입력 종류의 쓰임새를 구분할 수 있다.
- (모바일) `type`에 따라 **올라오는 키패드(자판) 모양**이 달라지는 것을 체험한다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 입력칸 6개가 나열된 페이지가 열립니다.
2. **이메일 칸**을 클릭해 글자를 적어 봅니다. (PC에서는 보통 칸 모양이 같아 보여요. 차이는 휴대폰에서 더 잘 보입니다.)
3. **나이(숫자) 칸**을 클릭하고, 칸 오른쪽 끝의 **위·아래 화살표**를 눌러 숫자가 1씩 오르내리는지 봅니다.
4. **생년월일(날짜) 칸**을 클릭합니다. → **달력**이 펼쳐지면 아무 날짜나 골라 봅니다.
5. **좋아하는 색(색상) 칸**의 작은 색 네모를 클릭합니다. → **색상 팔레트**가 뜨면 다른 색을 골라 네모 색이 바뀌는지 봅니다.
6. **소리 크기(범위) 슬라이더**의 손잡이를 **좌우로 끌어** 봅니다. → 손잡이가 움직이는지 확인합니다.
7. **(가장 추천!) 휴대폰으로 보기:** 이 `index.html` 파일을 휴대폰으로 열거나, 같은 화면을 폰에서 띄워 이메일 칸과 전화 칸을 차례로 눌러 봅니다. → **자판 모양이 서로 다르게** 올라오는 걸 확인합니다.
8. `index.html`을 메모장(또는 VS Code)으로 열어, **나이 칸의 `type="number"`** 를 `type="text"`로 바꿔 저장하고 **새로고침(F5)** 합니다. → 위·아래 화살표가 사라지는지(= 평범한 글자 칸이 되는지) 확인합니다. 차이를 본 뒤 다시 `number`로 되돌려 두세요.
9. AI에게 시켜 보기:
   > "이 index.html의 입력칸 목록 맨 아래에, 같은 `.field` 모양으로 '웹사이트 주소' 입력칸을 하나 더 추가해줘. `type`은 `url`로, label의 `for`와 input의 `id`는 `website`로 맞추고, placeholder는 '예: https://example.com'으로 해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  역할: 너는 HTML을 처음 배우는 비전공자를 돕는 웹 강사야.
  목표: 한 파일(index.html)짜리 학습용 페이지를 만들어줘. 서버나 데이터베이스 없이 더블클릭으로 열리게 해줘.
  내용: <input> 태그의 type 속성을 바꾸면 입력칸 모습이 달라진다는 걸 보여주는 페이지야.
        type을 email / tel / number / date / color / range 6가지로 한 칸씩, 위에서 아래로 나열해줘.
  제약:
    - 각 입력칸에는 한국어 label을 붙이고, label의 for와 input의 id를 같은 이름으로 맞춰줘(이름표를 눌러도 칸이 활성화되게).
    - 글씨·여백 정도만 간단히 꾸미고(스타일은 head 안 <style>), 핵심은 type 속성이라는 걸 알 수 있게 해줘.
    - <meta charset="UTF-8">과 휴대폰 대응 viewport 메타 태그를 꼭 넣어줘.
  산출물: index.html 한 파일 전체 코드. 그리고 코드만 주지 말고, 각 부분이 무엇이고 왜 넣었는지 한국어 주석으로 한 줄씩 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  지금 만든 index.html에 이어서 작업해줘.
  1) 입력칸 목록 맨 아래에, 기존과 똑같은 .field 모양으로 '웹사이트 주소' 입력칸을 하나 더 추가해줘.
     - type은 url, label의 for와 input의 id는 둘 다 website로 맞추고, placeholder는 '예: https://example.com'으로 해줘.
  2) number 칸에는 min/max를, range 칸에는 min/max/value를 넣어 값의 범위를 제한해줘.
  3) 각 입력칸 아래에 "휴대폰에서 누르면 자판이 어떻게 달라지는지" 한 줄 힌트(.hint)를 한국어로 달아줘.
  기존 코드는 지우지 말고 자연스럽게 덧붙여줘. 추가한 부분마다 왜 그렇게 했는지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내 index.html에서 label 글자를 눌러도 입력칸이 활성화되지 않아. (또는 날짜 칸을 눌러도 달력이 안 떠.)
  아래 내 코드를 붙여넣을게: (여기에 해당 부분 코드 붙여넣기)
  무엇이 문제인지 한 가지씩 짚어주고, label의 for와 input의 id가 정확히 같은지, type 철자가 맞는지부터 점검해줘.
  비전공자가 이해하게 원인과 고치는 법을 한 줄씩 풀어서 설명해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- 화면에 **이메일·전화번호·나이·생년월일·좋아하는 색·소리 크기** 6개 입력칸이 위에서 아래로 보이는가?
- **나이 칸** 오른쪽에 **위·아래 화살표(스피너)** 가 나타나고, 눌러서 숫자가 바뀌는가?
- **생년월일 칸**을 누르면 **달력**이 펼쳐지는가?
- **색상 칸**을 누르면 **색상 팔레트**가 뜨고, 색을 고르면 네모 색이 바뀌는가?
- **범위 슬라이더**의 손잡이가 좌우로 끌리는가?
- 브라우저에서 `F12 → Elements` 탭을 열어, 6개 `<input>`이 **딱 `type` 값만 서로 다르고** 나머지 구조는 같은지 눈으로 확인한다. (이게 "type 한 곳만 바꿨다"는 증거입니다.)
- (모바일) 이메일 칸과 전화 칸을 차례로 눌렀을 때 **자판 모양이 다르게** 올라오는가?
