# 실습 107 — 다크모드 토글 상태를 localStorage로 기억하기

버튼 하나로 **라이트 모드 ↔ 다크 모드**를 바꾸고, 고른 테마를 브라우저에 저장해서
**다음에 다시 방문해도 마지막 테마가 그대로 유지되게** 만드는 실습입니다.
"화면 모양(상태)도 데이터처럼 저장해 둘 수 있다"는 감각을 잡는 게 목표예요.

## 목표
- `body`에 `dark` 클래스를 **붙였다 뗐다** 하는 방식으로 테마를 바꾸는 패턴을 익힌다.
- 고른 테마를 `localStorage.setItem`으로 **저장**하고, 페이지를 열 때 `localStorage.getItem`으로 다시 **불러온다**.
- 새로고침(F5)이나 창을 껐다 켜도 마지막 선택이 남는다는 걸 눈으로 확인한다.

> 참고: localStorage는 "내 브라우저에만" 저장됩니다. 다른 기기·다른 사람에게도 같은 설정을
> 보여 주려면 다음 단계인 Supabase 같은 진짜 데이터베이스(또는 로그인한 사용자별 저장)가 필요합니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. **[다크 모드로]** 버튼을 누른다 → 배경이 어두워지고, 버튼 글자가 **[라이트 모드로]** 로 바뀐다.
3. 키보드 **F5**(새로고침)를 누른다 → 방금 고른 다크 모드가 그대로 유지되는지 확인한다.
4. 다시 버튼을 눌러 라이트 모드로 바꾼 뒤, 브라우저 창을 완전히 닫았다가 다시 `index.html`을 열어 본다 → 마지막 테마(라이트)가 남아 있다.
5. 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage** 에서 `theme` 값이 `dark`/`light`로 바뀌는 걸 직접 본다.
6. AI에게 시켜 보기:
   > "이 index.html에서 처음 방문하는 사람에게는 컴퓨터의 OS 설정(어두운 테마 선호)을 따르게 하고 싶어. `window.matchMedia('(prefers-color-scheme: dark)')`를 써서, localStorage에 저장된 값이 없을 때만 OS 설정을 기본값으로 쓰도록 고쳐줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS/JS 초급 강사야. 비전공자가 한 파일만으로 실행할 수 있는 index.html 하나를 만들어줘.
  목표: 버튼을 누르면 라이트 모드와 다크 모드가 토글되는 페이지.
  요구사항:
  - 외부 라이브러리 없이 순수 HTML+CSS+JS 한 파일(<style>, <script> 인라인).
  - body에 'dark' 클래스를 add/remove 하는 방식으로 테마를 바꾸기(인라인 style 직접 조작 금지).
  - 라이트/다크 두 색 세트를 CSS에 정의하고, 배경·글자색이 0.3초 transition으로 부드럽게 바뀌게.
  - 버튼 글자가 현재 테마에 따라 "다크 모드로" ↔ "라이트 모드로" 로 바뀌고, 현재 테마를 보여 주는 문구도 표시.
  코드만 주지 말고 왜 그렇게 했는지 비전공자가 이해하게 한 줄씩 주석으로 풀어서 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 다크모드 토글 페이지에, 고른 테마를 브라우저에 기억하는 기능을 추가해줘.
  - 버튼을 눌러 테마를 바꿀 때마다 localStorage.setItem("theme", "dark" 또는 "light")로 저장.
  - 페이지가 열리자마자 localStorage.getItem("theme")로 마지막 테마를 꺼내서, 저장된 값이 없으면(null) 라이트 모드로 시작.
  - 저장할 때 쓰는 키("theme")는 상수 변수로 한 번만 정의해서 오타로 안 깨지게 해줘.
  새로고침(F5)이나 창을 껐다 켜도 마지막 테마가 유지되는 이유를 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  다크모드 토글은 되는데 새로고침하면 테마가 매번 라이트로 돌아가. 아래 코드와 함께,
  개발자도구(F12) → Application → Local Storage 에 'theme' 값이 실제로 저장되는지 확인하는 방법도 알려줘.
  setItem/getItem을 부르는 위치와 키 이름이 맞는지 단계별로 진단해줘.
  (여기에 내 index.html 전체 코드를 붙여넣기)
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- 테마를 바꾼 뒤 **새로고침**해도 화면 색이 그대로 유지되는가?
- 버튼 글자가 현재 테마에 맞게 **[다크 모드로]** ↔ **[라이트 모드로]** 로 정확히 바뀌는가?
- 개발자도구(F12) → Application → Local Storage 에 `theme` 항목이 생기고, 누를 때마다 `dark`/`light`로 값이 바뀌는가?
- 브라우저 창을 완전히 닫았다 다시 열어도 마지막 테마가 남아 있는가?

## 핵심 코드 한 줄로 보기
```js
document.body.classList.toggle("dark");      // body에 dark 클래스 붙이기/떼기
localStorage.setItem("theme", "dark");       // 고른 테마 저장
localStorage.getItem("theme");               // 페이지 열 때 다시 꺼내기 → "dark" 또는 null
```
