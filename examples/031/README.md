# 실습 031 — 구글 폰트로 제목·본문 타이포그래피 꾸미기

내 컴퓨터에는 깔려 있지만 방문자 컴퓨터에는 없는 폰트를 쓰면, 방문자 화면에서는 엉뚱한 글꼴로 보입니다. **웹폰트**는 이 문제를 해결합니다. 글꼴 파일을 인터넷에서 함께 내려받아, 누가 보든 똑같은 폰트로 보여 주는 방식이죠. 이번 실습에서는 무료 폰트 창고인 **Google Fonts**에서 제목용·본문용 폰트를 불러와, 제목과 본문에 **다른 폰트·다른 굵기·다른 줄간격**을 입혀 봅니다. 파일은 `index.html` 하나뿐이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭만 하면 됩니다. (단, 폰트를 인터넷에서 가져오므로 **인터넷 연결**은 필요합니다.)

## 목표
- `<link>`로 Google Fonts에서 한글 폰트를 불러오고, CSS의 `font-family`로 그 폰트를 실제 글자에 **적용**하는 2단계 흐름을 이해한다.
- 제목(`h1`)과 본문(`p`)에 **서로 다른 폰트**를 주면 화면에 위계와 리듬이 생겨 전문적으로 보인다는 것을 체험한다.
- `font-weight`(굵기 400·700)와 `line-height`(줄간격)를 조절해 같은 글의 **가독성**이 어떻게 달라지는지 눈으로 확인한다.

핵심은 "주문(`<link>`) → 적용(`font-family`)" 두 단계라는 점입니다.

```
1단계: <link href="...Noto+Sans+KR...&family=Black+Han+Sans..."> 로 폰트를 가져온다
2단계: body { font-family: "Noto Sans KR"; }  h1 { font-family: "Black Han Sans"; } 로 적용한다
```

| 어디에 | 폰트 | 굵기(font-weight) | 줄간격(line-height) |
|---|---|---|---|
| 제목 `h1` | Black Han Sans (굵은 제목용) | 폰트 자체가 굵음 | `1.25` (좁게) |
| 부제 `h2` | Noto Sans KR | `700` (굵게) | `1.4` |
| 본문 `p` | Noto Sans KR | `400` (보통) | `1.7` (시원하게) |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다. (인터넷이 연결돼 있어야 폰트가 제대로 나옵니다.)
2. 맨 위 **큰 제목**과 아래 **본문**의 글꼴 모양이 서로 다른지 봅니다. → 제목은 두툼한 `Black Han Sans`, 본문은 깔끔한 `Noto Sans KR`입니다. 이것이 "제목과 본문 폰트를 다르게 쓴다"의 뜻입니다.
3. "3. 줄간격" 항목 아래의 **두 비교 박스**를 봅니다. 왼쪽(줄간격 1.1)은 글이 빽빽해 답답하고, 오른쪽(줄간격 1.9)은 줄 사이가 넉넉해 시원합니다. → 같은 글인데 `line-height` 하나로 읽기 편함이 달라집니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어 `body` 규칙의 `line-height: 1.7;`을 `line-height: 1.0;`으로 바꿔 저장하고, 브라우저에서 **새로고침(F5)** 합니다. → 본문 전체가 빽빽해지는 것을 확인합니다. 다시 `1.7`로 되돌려 보세요.
5. 이번엔 `<head>` 안의 `<link href="...">` 세 줄을 잠깐 지우고(또는 앞에 `<!-- -->`로 주석 처리) 저장 후 새로고침합니다. → 글꼴이 시스템 기본 고딕체로 바뀌는 것을 보고 "웹폰트를 불러와야 비로소 그 폰트가 보인다"는 것을 체감합니다. 확인했으면 다시 살려 두세요.
6. AI에게 시켜 보기:
   > "이 index.html에서 본문 폰트를 Google Fonts의 `Gowun Dodum`으로 바꿔줘. `<link>` 주문서와 `body`의 `font-family`를 둘 다 수정하고, 제목 폰트는 그대로 둬."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS 강사야. 비전공자가 더블클릭만 하면 열리는 index.html 한 파일을 만들어줘.
  - 서버·빌드·외부 라이브러리 없이, <style> 태그 안에 CSS를 인라인으로 넣어 한 파일로 완결되게 해줘.
  - Google Fonts에서 한글 폰트 2종을 <link>로 불러와줘: 제목용 'Black Han Sans', 본문용 'Noto Sans KR'(굵기 400·700 둘 다).
  - body에는 본문 폰트(Noto Sans KR)를, h1 제목에는 제목 폰트(Black Han Sans)를 font-family로 적용해줘.
  - 흰 카드(max-width로 폭 제한, 가운데 정렬) 안에 큰 제목 1개와 짧은 설명 문단 2~3개를 넣어줘.
  - 한글이 안 깨지게 <meta charset="UTF-8">와 모바일용 viewport meta를 넣어줘.
  - 비전공자가 읽을 수 있게 코드만 주지 말고 왜 그렇게 했는지 한국어 주석으로 한 줄씩 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html을 이어서 개선해줘. (기존 구조는 유지)
  - 본문 줄간격(line-height)을 1.7로 두되, line-height 1.1짜리와 1.9짜리 비교 박스 두 개를 가로로 나란히 보여줘서
    줄간격 차이가 가독성을 어떻게 바꾸는지 눈으로 비교되게 해줘. (화면이 좁아지면 위아래로 쌓이게 flex-wrap도 넣어줘)
  - 강조할 단어는 font-weight 700(굵게)으로, 본문은 400(보통)으로 둬서 시선 위계를 만들어줘.
  - 웹폰트를 못 불러왔을 때를 대비해 font-family 끝에 sans-serif 폴백을 꼭 넣어줘.
  - 추가한 부분도 '무엇을 했는지 + 왜 넣었는지' 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  index.html을 열었는데 제목·본문이 둘 다 똑같은 밋밋한 고딕체로 보이고 내가 주문한 폰트가 안 먹어.
  아래 <head>의 <link>와 CSS의 font-family 부분을 붙여넣을게. [여기에 코드 붙여넣기]
  무엇이 원인일 수 있는지(폰트 이름 철자, <link> 주소 오타, 인터넷 연결, font-family 누락 등) 가능성을 하나씩 짚어주고,
  F12 개발자도구의 Network/Computed 탭으로 어디를 확인하면 되는지 비전공자도 따라할 수 있게 단계별로 알려줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- **폰트가 적용됐는지 눈으로 확인**: 제목과 본문의 글꼴 모양이 분명히 다르면 두 폰트가 모두 적용된 것입니다. 둘 다 똑같은 밋밋한 고딕으로 보인다면 인터넷 연결이 끊겼거나 `<link>` 주소에 오타가 있는 것입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 제목(`h1`)을 클릭한 뒤 오른쪽 `Computed`(계산됨) 탭에서 `font-family`를 찾으면 `"Black Han Sans"`가, 본문(`p`)을 클릭하면 `"Noto Sans KR"`가 보입니다. → 의도한 폰트가 실제로 먹은 증거입니다.
- **네트워크 탭으로 폰트 로딩 확인**: `F12 → Network` 탭을 연 채로 새로고침(F5)하면 `fonts.gstatic.com`에서 폰트 파일(`.woff2`)을 내려받는 요청이 보입니다. → 웹폰트를 실제로 가져왔다는 증거입니다.
- **줄간격 검증**: 4번 단계처럼 `line-height`를 `1.0` ↔ `1.7`로 바꿨을 때 본문 줄 사이 간격이 눈에 띄게 달라지면, 줄간격이 제대로 적용되고 있는 것입니다.
