# 096. 이메일 실시간 검증: 입력 중 형식 맞으면 초록 체크

타이핑하는 도중에 이메일 형식이 맞는지 즉시 알려주는 입력칸을 만듭니다. 형식이 맞으면 초록 체크(✓), 틀리면 빨강 안내(✕)가 실시간으로 바뀝니다. 가입 버튼은 형식이 맞을 때만 눌립니다.

## 목표

- `input` 이벤트로 "타이핑할 때마다" 코드를 실행하는 법을 익힙니다.
- 정규식(패턴)과 `정규식.test(값)`으로 이메일 형식이 맞는지 참/거짓을 판단합니다.
- 검사 결과에 따라 화면(테두리 색·아이콘·안내문·버튼)을 즉시 바꾸는 실시간 피드백을 경험합니다.

## 따라하는 단계

1. `096` 폴더 안에 `index.html`, `style.css`, `script.js` 세 파일이 같은 위치에 있는지 확인합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 가운데에 흰 카드와 이메일 입력칸이 보입니다.
3. 입력칸에 `hong` 까지만 적어 봅니다. 빨강 테두리와 ✕, "형식이 올바르지 않습니다" 안내가 뜹니다.
4. 이어서 `@example.com`을 마저 적어 `hong@example.com`을 완성합니다. 초록 테두리와 ✓, "올바른 이메일 형식입니다" 안내로 즉시 바뀝니다.
5. 형식이 맞아지는 순간 아래 "가입하기" 버튼이 회색(잠김)에서 초록(활성)으로 바뀌는지 봅니다.
6. 글자를 모두 지우면 표시가 사라지고 버튼이 다시 잠기는지 확인합니다(중립 상태).
7. `script.js`를 열어 정규식 `emailPattern`과 `input.addEventListener("input", ...)` 부분의 주석을 천천히 읽어 봅니다.

## 검증법

- 빈 칸일 때: 아이콘·안내문이 없고 버튼이 잠겨 있다(회색).
- `abc` 입력: 빨강 테두리 + ✕ + 빨강 안내문, 버튼 잠김.
- `abc@` 입력: 여전히 실패 상태(@ 뒤가 비어 있어 형식 미완성).
- `abc@d.co` 입력: 초록 테두리 + ✓ + 초록 안내문, 버튼 활성화.
- 활성화된 상태에서 "가입하기"를 눌러도 페이지가 새로고침되지 않고 완료 안내문이 뜬다.
- 글자를 지우면 다시 중립 상태로 돌아온다.

## 더 알아두기

- 여기서는 "형식"만 검사합니다. 실제로 존재하는 이메일인지, 중복 가입인지는 서버에서 확인해야 합니다. 다음 단계에서 입력값을 Supabase로 보내 저장·검사하도록 확장할 수 있습니다.
- 정규식은 완벽한 검증 도구가 아닙니다. 일반적인 형식을 빠르게 걸러주는 1차 안내로 쓰고, 최종 확인은 서버(백엔드)에서 한 번 더 하는 것이 안전합니다.
