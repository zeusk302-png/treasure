# 실습 278 — 세미콜론·따옴표 빠진 JS 한 줄 고치기 (아무 버튼도 안 눌리는 페이지)

> **디버깅 챌린지 (난이도 1)** · 분류: 디버깅 챌린지 · 개념: SyntaxError, 콘솔 에러 읽기

이 폴더에는 **일부러 고장 낸 파일**(`broken.html`)과 **고친 정답 파일**(`index.html`)이 들어 있습니다.
먼저 `broken.html`을 열어 버튼이 왜 먹통인지 직접 찾아보고, 그다음 `index.html`과 비교하세요.

> **한 줄 메모(무엇이 잘못됐나):** `<script>` 안에 **구문 오류(SyntaxError)** 가 2개 있습니다. ① `"click` 의 닫는 따옴표가 빠졌고, ② '리셋' 버튼 함수의 닫는 `}` 와 `)` 가 빠졌습니다. JavaScript는 **한 줄만 깨져도 그 스크립트 전체를 실행하지 않기 때문에**, 멀쩡해 보이는 '좋아요' 버튼까지 같이 먹통이 됩니다.

## 목표
- JS에 구문 오류가 **한 곳이라도** 있으면, 그 파일의 스크립트가 **통째로 안 돌아간다**는 것을 체감한다. (CSS 오타는 그 줄만 무시되지만, JS 구문 오류는 전체가 멈춥니다.)
- 버튼을 눌러도 아무 반응이 없을 때, 가장 먼저 **F12 → Console(콘솔)** 의 **빨간 줄**을 읽는 습관을 들인다.
- 콘솔 에러 메시지에 적힌 **파일명:줄번호** 를 보고 문제 위치를 빠르게 찾는 법을 익힌다.

### 비유로 이해하기
JS 스크립트는 **문법이 정확해야만 읽히는 외국어 편지**와 같습니다.
편지 한 문장에 괄호나 따옴표 짝이 안 맞으면, 받는 사람(브라우저)은 **"이 편지는 해석 불가"** 라며 편지 전체를 덮어 버립니다. 그래서 뒤에 멀쩡하게 적힌 '좋아요 버튼' 안내문까지 **하나도 실행되지 않습니다.** 깨진 한 문장만 손해 보는 게 아니라 편지 전체가 버려지는 셈입니다.

### 고친 오류 목록 (틀린 코드 → 정답)
| 위치 | 틀린 코드 | 올바른 코드 | 콘솔에 뜨는 에러 |
| --- | --- | --- | --- |
| 좋아요 버튼 등록 | `addEventListener("click, function () {` | `addEventListener("click", function () {` | `Uncaught SyntaxError: missing ) after argument list` (또는 `Invalid or unexpected token`) |
| 리셋 버튼 함수 끝 | `  countEl.textContent = count;` 다음에 `});` 없음 | `  countEl.textContent = count;` 다음에 `});` 추가 | `Uncaught SyntaxError: Unexpected end of input` |

> 참고: 따옴표 짝이 깨지면(①) 브라우저가 그 줄부터 끝까지 한 덩어리로 잘못 읽기 때문에, **콘솔에는 보통 마지막 에러 하나만** 먼저 보입니다. 첫 번째 에러를 고치고 새로고침하면 두 번째 에러가 새로 나타날 수 있습니다. **에러는 위에서부터 하나씩 고치고 → 새로고침 → 다시 확인** 하는 것이 정석입니다.

## 따라하는 단계
1. `broken.html`을 **더블클릭**해서 브라우저로 엽니다. → '좋아요 +1', '리셋' 버튼이 보이지만, **눌러도 숫자가 0에서 안 바뀝니다.**
2. `F12`(또는 마우스 오른쪽 → 검사)를 눌러 개발자도구를 열고 **Console(콘솔)** 탭으로 갑니다.
3. **빨간색 글씨**로 뜬 `Uncaught SyntaxError: ...` 줄을 읽습니다. 줄 오른쪽 끝의 **`broken.html:줄번호`** 를 클릭하면 문제가 난 위치로 이동합니다.
4. `broken.html`을 메모장이나 VS Code로 엽니다.
5. **오류 ① (따옴표 짝):** `likeBtn.addEventListener("click, function () {` 줄에서, `click` 뒤에 닫는 큰따옴표를 넣어 `"click"` 으로 고칩니다. → `addEventListener("click", function () {`
6. **오류 ② (괄호 짝):** 맨 아래 `resetBtn` 함수에서 `countEl.textContent = count;` 다음 줄이 그냥 `</script>` 로 끝나 있습니다. 그 사이에 함수와 괄호를 닫는 `});` 를 넣어 줍니다.
7. 저장하고 브라우저에서 **새로고침(F5)** → '좋아요 +1'을 누르면 숫자가 1씩 오르고, '리셋'을 누르면 0으로 돌아가면 성공입니다.
8. **콘솔 에러 캡처(제출물):** 고치기 **전** 콘솔에 떴던 빨간 `SyntaxError` 화면을 캡처해 1장 저장하세요. (Windows: `Win + Shift + S`) → 어떤 에러를 보고 어디를 고쳤는지 설명할 수 있어야 합니다.
9. 정답이 궁금하면 같은 폴더의 `index.html`을 열어 내 수정과 비교합니다.
10. AI에게 검토 시켜 보기:
    > "이 자바스크립트 코드에 구문 오류(SyntaxError)가 있는지 찾아줘. 따옴표·괄호·세미콜론 짝이 안 맞는 곳을 알려주고 고쳐줘."

## 검증법
- 고친 뒤 **'좋아요 +1' 버튼**을 누르면 숫자가 `0 → 1 → 2 ...` 로 올라가는가?
- **'리셋' 버튼**을 누르면 숫자가 `0` 으로 돌아가는가?
- `F12 → Console` 에 **빨간 SyntaxError 가 더 이상 안 뜨는가?** (한 줄이라도 빨간 줄이 남아 있으면 아직 구문 오류가 있다는 뜻 — 그 줄번호를 다시 확인하세요.)
- (개념 확인) 고치기 전에는 멀쩡해 보이던 '좋아요' 버튼까지 **왜 같이 안 됐는지** 설명할 수 있는가? → JS는 구문 오류가 있으면 스크립트 **전체**가 실행되지 않기 때문입니다.
- 제출물인 **콘솔 에러 캡처 1장**을 준비했는가?
