# 실습 284 — 이벤트가 두 번 실행되는 버그 (좋아요가 +2씩 오르는 버튼)

> **디버깅 챌린지 (난이도 2)** · 분류: 디버깅 챌린지 · 개념: 이벤트 리스너 중복, 멱등성

이 폴더에는 **일부러 고장 낸 파일**(`broken.html`)과 **고친 정답 파일**(`index.html`)이 들어 있습니다.
먼저 `broken.html`을 열어 무엇이 이상한지 직접 찾아보고, 그다음 `index.html`과 비교하세요.

> **한 줄 메모(원인):** 같은 버튼에 `btn.addEventListener("click", addLike)` 줄을 **두 번** 써서, 클릭 한 번에 `addLike()`가 두 번 실행돼 좋아요가 +2씩 올랐습니다. → 등록 줄을 **한 번만** 남기면 해결됩니다.

## 목표
- 버튼에 이벤트를 등록하는 `addEventListener`는 **부른 횟수만큼 핸들러가 쌓인다**는 것을 이해한다.
- 같은 함수를 두 번 등록하면 클릭 한 번에 **두 번 실행된다**는 현상을 눈으로 확인한다.
- 브라우저 개발자도구(F12) 콘솔에서 핸들러가 몇 번 도는지 확인하며, **클릭 결과는 항상 똑같이(멱등하게) 나와야 한다**는 감각을 익힌다.

### 비유로 이해하기
`addEventListener("click", addLike)`는 버튼에게 **"클릭되면 이 사람(함수)을 불러줘"** 라고 메모를 붙이는 것입니다.
같은 메모를 두 장 붙이면, 버튼은 한 번 눌릴 때 **두 사람을 다 부릅니다.** 그래서 좋아요가 한꺼번에 +2가 됩니다.
메모는 **딱 한 장만** 붙여야 합니다.

## 따라하는 단계
1. `broken.html`을 **더블클릭**해서 브라우저로 엽니다.
2. `❤️ 좋아요` 버튼을 한 번 누릅니다. → 숫자가 `0`에서 **`2`** 로 뜁니다. (한 번 더 누르면 `4`, `6` … 계속 2씩 오릅니다)
3. `F12`를 눌러 콘솔을 열어 둔 채로, `addLike` 함수 안에 잠깐 `console.log("실행됨!")`를 넣어 보면 클릭 한 번에 **"실행됨!"이 두 줄** 찍히는 것을 확인할 수 있습니다.
4. `broken.html`을 메모장이나 VS Code로 엽니다. 맨 아래 `<script>` 안을 봅니다.
5. 똑같은 등록 줄이 **두 번** 있는 것을 찾습니다.
   ```js
   btn.addEventListener("click", addLike);
   btn.addEventListener("click", addLike);   // ← 이 줄을 지운다
   ```
6. **두 줄 중 한 줄을 삭제**해 `addEventListener`가 한 번만 남게 합니다.
7. 저장하고 브라우저에서 **새로고침(F5)** → 클릭할 때마다 `1, 2, 3 …` 으로 **1씩** 오르면 성공입니다.
8. 정답이 궁금하면 같은 폴더의 `index.html`을 열어 내 수정과 비교합니다.
9. AI에게 검토 시켜 보기:
   > "이 JS에서 같은 요소에 같은 이벤트 핸들러가 중복 등록된 곳이 있는지 찾아줘. 클릭 한 번에 한 번만 실행되도록 고쳐줘."

## 🤖 바이브코딩 프롬프트
이 실습(좋아요 버튼 + 이벤트 중복 버그 찾기)을 AI에게 시켜 만들거나 고칠 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  HTML 파일 하나로 "좋아요 버튼" 데모를 만들어줘.
  - 화면 가운데 카드 안에 "🤍 좋아요" 버튼 1개와 "좋아요 N개" 숫자 표시가 있어야 해.
  - 버튼을 누르면 숫자가 1씩 올라가고, 버튼 글자가 "❤️ 좋아요"로 바뀌면 좋겠어.
  - CSS는 같은 파일 <style> 안에, 자바스크립트는 같은 파일 <script> 안에 넣어줘(파일 하나로 더블클릭만 하면 열리게).
  - 비전공자가 읽을 거라서, 코드만 주지 말고 각 줄이 무슨 일을 하는지 한국어 주석으로 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 좋아요 버튼에서, "이벤트 리스너가 중복 등록되면 클릭 한 번에 두 번 실행되는" 버그를 일부러 만든 broken 버전과,
  그걸 고친 정답 버전 두 개를 만들어줘.
  - broken 버전: btn.addEventListener("click", addLike) 를 두 번 써서 클릭마다 +2가 오르게 해줘.
  - 정답 버전: 등록을 한 번만 남겨 +1씩 오르게 해줘.
  - 두 파일 모두, 문제가 되는 줄에 "이게 버그다 / 이렇게 고쳤다"를 왜 그렇게 했는지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내 좋아요 버튼이 한 번 누를 때마다 숫자가 2씩 올라가. 1씩만 오르게 하고 싶어.
  아래 코드를 붙여넣을게. 원인을 한 단계씩 짚어주고, 어디를 어떻게 고쳐야 하는지 알려줘.
  특히 같은 요소에 같은 핸들러를 중복으로 등록한 곳이 있는지 확인해줘.
  (여기에 내 <script> 코드를 붙여넣기)
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- 새로고침 후 버튼을 한 번 누르면 숫자가 **정확히 1만** 오르는가? (2가 오르면 아직 안 고쳐진 것)
- 여러 번 눌렀을 때 `1 → 2 → 3 → 4`처럼 **누른 횟수와 숫자가 일치**하는가?
- (콘솔 확인) `addLike` 안에 `console.log("실행됨!")`를 넣고 한 번 클릭했을 때 로그가 **한 줄만** 찍히는가?
- 코드에서 `addEventListener("click", addLike)` 가 **딱 한 번만** 등장하는가?
