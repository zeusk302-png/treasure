# 자동 재생 캐러셀 만들기 (점 인디케이터 포함)

배너 광고나 쇼핑몰 메인 화면에서 사진이 일정 시간마다 스르륵 넘어가는 것을 본 적 있죠? 그게 바로 "자동 재생 캐러셀"입니다. 이번 실습에서는 슬라이드가 3초마다 자동으로 넘어가고, 아래쪽 점(인디케이터)으로 지금 몇 번째인지 보여주는 캐러셀을 직접 만듭니다.

## 목표

- 슬라이드가 **일정 간격으로 자동으로** 넘어가게 만든다. (타이머 = `setInterval`)
- **지금 몇 번째 슬라이드인지**를 숫자 하나(`index`)로 기억하고, 그 값에 맞춰 화면을 다시 그린다.
- 하단 **점 인디케이터가 현재 위치와 항상 일치**하도록 동기화한다.
- 점이나 좌/우 버튼을 누르면 원하는 슬라이드로 바로 이동한다.

> 핵심 개념: `setInterval` 자동 전환 + 인덱스 상태와 인디케이터 동기화

## 따라하는 단계

1. **세 개의 파일을 한 폴더에 둔다.** `index.html`, `style.css`, `script.js`를 같은 폴더(`076`)에 둡니다. HTML이 나머지 둘을 불러옵니다.
2. **슬라이드 띠(track) 구조를 이해한다.** 슬라이드 4장은 가로로 한 줄에 길게 늘어서 있습니다(`display:flex`). 바깥 박스에 `overflow:hidden`을 줘서 화면에는 한 장만 보이게 잘라냅니다.
3. **"미는" 방식으로 슬라이드를 바꾼다.** 띠 전체를 왼쪽으로 `translateX`만큼 밀면 다른 슬라이드가 보입니다. 2번째를 보려면 `-100%`, 3번째를 보려면 `-200%`처럼, `index × -100%`만큼 밀면 됩니다. (`script.js`의 `update()` 함수)
4. **점을 코드로 자동 생성한다.** 슬라이드 개수만큼 반복문으로 점 버튼을 만들어 넣습니다. 슬라이드가 5장으로 늘어도 HTML을 고칠 필요가 없습니다.
5. **인덱스를 1씩 늘려 자동 재생한다.** `setInterval(next, 3000)`은 3초마다 `next()`를 실행합니다. `next()`는 `index`를 1 늘리고 화면을 다시 그립니다.
6. **끝에서 처음으로 순환시킨다.** `index = (i + total) % total` 한 줄이 핵심입니다. 마지막 다음으로 가면 자동으로 0번(처음)으로 돌아옵니다.
7. **항상 `update()`로 화면을 맞춘다.** 버튼이든 점이든 자동이든, 결국 `index`만 바꾸고 `update()`를 부르면 슬라이드 위치와 점 강조가 한 번에 맞춰집니다. 이렇게 "상태 한 곳, 그리기 한 곳"으로 나누면 코드가 단순해집니다.
8. **마우스를 올리면 멈추게 한다.** `mouseenter`에서 타이머를 끄고(`clearInterval`), `mouseleave`에서 다시 켭니다. 사용자가 보던 슬라이드가 갑자기 넘어가는 답답함을 막아줍니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고, 아래처럼 **단계로 나눠서** 시키는 것이 핵심입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 초보 웹개발자를 돕는 짝꿍 개발자야.
  HTML/CSS/순수 자바스크립트(라이브러리 금지)로 "이미지 캐러셀"의 기본 뼈대를 만들어줘.
  요구사항:
  - 슬라이드 4장이 가로 한 줄로 늘어선 띠(track) 구조. 바깥 박스는 overflow:hidden 으로 한 장만 보이게 자른다.
  - 슬라이드를 바꿀 때는 track 에 transform: translateX(index * -100%) 를 줘서 왼쪽으로 미는 방식.
  - 좌/우 이동 버튼(이전/다음)을 넣고, 누르면 한 장씩 넘어가게 한다.
  - 파일은 index.html, style.css, script.js 세 개로 나눈다.
  - 지금 몇 번째인지는 index 변수 하나로 기억하고, update() 함수 하나가 화면을 다시 그리도록 구조를 잡아줘.
  결과물: 위 3개 파일 전체 코드. 비전공자도 읽게 각 부분에 한국어 주석을 달아줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  앞에서 만든 캐러셀에 아래 기능을 추가해줘. 기존 구조(index 변수 + update 함수)는 그대로 살려서 확장해줘.
  1) 3초마다 자동으로 다음 슬라이드로 넘어가게 setInterval 로 자동 재생을 추가한다.
  2) 마지막 슬라이드 다음에는 처음(0번)으로 순환한다. (index = (i + total) % total 활용)
  3) 슬라이드 개수만큼 하단에 점(dot) 인디케이터를 반복문으로 자동 생성하고,
     현재 슬라이드의 점만 .active 로 강조한다. 점을 누르면 그 슬라이드로 바로 이동한다.
  4) 마우스를 캐러셀 위에 올리면 자동 재생을 멈추고(clearInterval), 떼면 다시 시작한다.
  각 코드가 왜 필요한지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  자동 캐러셀이 의도대로 안 돼. 아래 증상 중 하나를 진단해줘.
  - 증상: (예) 슬라이드는 넘어가는데 아래 점이 강조 안 됨 / 마지막에서 처음으로 안 돌아옴 / 마우스를 올려도 안 멈춤.
  내 script.js 코드는 이거야: (여기에 코드 붙여넣기)
  무엇이 원인인지 한 줄씩 짚어주고, 고친 부분만 보여줘.
  그리고 왜 그렇게 고쳤는지 비전공자가 이해하게 한 줄씩 풀어서 설명해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

1. `index.html`을 더블클릭해 브라우저로 엽니다. (별도 서버 필요 없음)
2. **자동 재생**: 가만히 두면 3초마다 슬라이드 1 → 2 → 3 → 4 → 1 순서로 넘어가는지 확인합니다.
3. **점 동기화**: 슬라이드가 넘어갈 때마다 아래쪽 점 중 **현재 슬라이드에 해당하는 점만** 커지고 하얗게 강조되는지 봅니다.
4. **점 클릭 이동**: 3번째 점을 누르면 곧바로 슬라이드 3으로 이동하는지 확인합니다.
5. **좌/우 버튼**: `❮` `❯` 버튼으로 한 장씩 넘어가고, 마지막에서 다음을 누르면 처음으로 순환하는지 확인합니다.
6. **마우스 멈춤**: 캐러셀 위에 마우스를 올리고 5초 이상 기다려도 안 넘어가는지, 마우스를 떼면 다시 자동 재생되는지 확인합니다.
7. (선택) 개발자도구(F12) Console 탭에 빨간 오류가 없는지 봅니다.

## 직접 바꿔보기

- `script.js`의 `const DELAY = 3000;`을 `1500`으로 바꾸면 1.5초마다 넘어갑니다.
- `index.html`의 `.track` 안에 `<div class="slide" ...>슬라이드 5</div>`를 추가하면, 점도 5개로 자동으로 늘어납니다. (4번 단계의 효과)
