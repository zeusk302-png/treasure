# 박스 색깔 바꾸기 버튼 3개 만들기

빨강·초록·파랑 버튼을 누르면 가운데 박스의 배경색이 그 색으로 바뀌는 작은 페이지입니다. 자바스크립트로 화면 요소의 `style`(스타일)을 직접 바꾸는 첫 경험을 합니다.

## 목표

- 버튼을 누르면 무언가 반응하는 "이벤트 연결"을 익힙니다.
- 자바스크립트로 요소의 `style.backgroundColor` 값을 바꿔서 화면을 변화시키는 법을 익힙니다.
- 비슷한 버튼이 여러 개일 때, 하나하나 코드를 쓰지 않고 한 번에 처리하는 방법을 맛봅니다.

## 따라하는 단계

1. 이 폴더(`058`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. 회색 박스 1개와 빨강·초록·파랑 버튼 3개가 보이는지 확인합니다.
3. `index.html`을 살펴봅니다. 색이 바뀔 박스에는 `id="colorBox"`가 붙어 있고, 각 버튼에는 `data-color="#색상코드"`로 바꿀 색이 적혀 있습니다.
4. `script.js`를 엽니다. 코드는 딱 세 단계입니다.
   - `document.getElementById("colorBox")` 로 박스를 찾습니다.
   - `document.querySelectorAll(".btn")` 로 버튼 3개를 한꺼번에 찾습니다.
   - 각 버튼에 `addEventListener("click", ...)` 로 클릭 동작을 연결하고, 그 안에서 `box.style.backgroundColor = color;` 로 박스 색을 바꿉니다.
5. 브라우저로 돌아가 빨강·초록·파랑 버튼을 차례로 눌러봅니다. 누를 때마다 박스 색이 바뀌면 성공입니다.
6. (더 해보기) `index.html`의 버튼에 `data-color="#ff9800"` 처럼 새 색상 코드를 적은 버튼을 하나 더 추가해 봅니다. `script.js`는 고치지 않아도 새 버튼이 바로 작동합니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS/JS 기초를 가르치는 튜터야. 비전공자가 이해할 수 있게 만들어줘.
  목표: 가운데에 정사각형 박스 1개가 있고, 그 아래 "빨강/초록/파랑" 버튼 3개가 가로로 나란히 있는 한 페이지를 만들어줘.
  제약:
  - 파일은 index.html, style.css, script.js 세 개로 나눠줘.
  - 박스에는 id="colorBox"를 붙이고, 처음 색은 회색(#cfcfcf)으로.
  - 각 버튼에는 class="btn"과 data-color="#색상코드"를 넣어줘(빨강 #e53935, 초록 #43a047, 파랑 #1e88e5).
  - 아직 클릭 동작(JS)은 넣지 말고 화면(HTML/CSS)만 먼저 완성해줘.
  산출물: 위 세 파일의 전체 코드. 각 부분이 무슨 역할인지 한국어 주석으로 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  이제 버튼을 누르면 박스 색이 바뀌게 script.js를 작성해줘.
  요구사항:
  - document.getElementById로 박스를 찾고, document.querySelectorAll(".btn")로 버튼 3개를 한 번에 찾아줘.
  - 버튼마다 addEventListener("click", ...)를 걸고, 그 버튼의 data-color 값(button.dataset.color)을 읽어서 box.style.backgroundColor에 넣어줘.
  - 버튼이 늘어나도 코드를 안 고쳐도 되게, 버튼을 하나하나 따로 쓰지 말고 반복(forEach)으로 처리해줘.
  - 색이 부드럽게 전환되도록 style.css의 .box에 transition도 추가해줘.
  코드만 주지 말고 왜 그렇게 했는지 한 줄씩 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  버튼을 눌러도 박스 색이 안 바뀌어. 내 index.html과 script.js 전체를 붙여넣을게.
  무엇이 문제인지 초보가 이해하게 단계별로 진단해줘.
  특히 이런 흔한 원인부터 점검해줘: <script src="script.js">가 </body> 바로 위에 있는지,
  세 파일이 같은 폴더에 있는지, id/class 철자가 HTML과 JS에서 똑같은지, 브라우저 개발자도구(F12) 콘솔에 빨간 에러가 있는지.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

- 빨강 버튼을 누르면 박스가 빨갛게, 초록은 초록, 파랑은 파랗게 바뀌면 정상입니다.
- 색이 부드럽게 전환되는지 확인합니다(이 효과는 `style.css`의 `transition`이 담당합니다).
- 아무 버튼도 누르지 않은 처음 상태에서는 박스가 회색(`#cfcfcf`)인지 확인합니다.
- 만약 색이 안 바뀐다면: `index.html` 안에서 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지, 그리고 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지 확인하세요.

## 핵심 개념

- `element.style.backgroundColor = "색"` : 자바스크립트로 요소의 배경색을 직접 바꿉니다.
- `addEventListener("click", 함수)` : 버튼이 클릭될 때 실행할 동작을 연결합니다.
- `data-color` 속성 + `button.dataset.color` : 버튼마다 다른 값을 HTML에 적어두고 자바스크립트에서 꺼내 쓰는 깔끔한 방법입니다.
