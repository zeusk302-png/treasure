# 실습 029 — box-sizing으로 박스 크기 계산 이해하기

똑같이 `width: 300px`라고 적은 두 박스인데, 하나는 화면에서 **350px**로 보이고 다른 하나는 **300px** 그대로 보입니다. 이 차이를 만드는 단 한 줄 `box-sizing`을 직접 비교하면서, "내가 적은 width 숫자에 `padding`과 `border`가 더해지는지 / 안에 포함되는지"라는 **박스모델의 핵심 원리**를 눈으로 이해합니다. 파일은 `index.html` 하나뿐이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 브라우저 기본값인 `content-box`에서는 내가 적은 `width`에 **`padding`과 `border`가 바깥으로 더해져** 박스가 더 커진다는 것을 체험한다.
- `box-sizing: border-box`를 주면 `padding`과 `border`가 **적은 `width` 안에 포함되어** 박스 크기가 그대로 유지된다는 것을 체험한다.
- 그래서 크기 계산이 직관적인 `border-box`를 실무에서 더 많이 쓰는 이유를 이해한다.

두 박스 모두 아래처럼 **똑같은 값**을 가집니다. 차이는 `box-sizing` 한 줄뿐입니다.

```
width: 300px;   padding: 20px;   border: 5px;
```

| box-sizing | 내가 적은 300px의 의미 | padding·border는? | 실제 화면 너비 |
|---|---|---|---|
| `content-box` (기본값) | **내용 영역**의 너비 | 300px **바깥에 더해짐** | 300 + 40 + 10 = **350px** |
| `border-box` | **테두리까지 포함한** 전체 너비 | 300px **안에 포함됨** | **300px** 그대로 |

> 계산 메모: `padding: 20px`는 좌우 합쳐 40px, `border: 5px`는 좌우 합쳐 10px입니다. content-box에서는 이 50px이 모두 바깥으로 더해져 350px가 됩니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다.
2. 위쪽 **주황 점선**이 "내가 `width`로 적은 300px가 어디까지인지" 표시해 줍니다. 이 점선을 기준선으로 삼습니다.
3. **1번 박스(`content-box`)**: 오른쪽 끝이 주황 점선보다 **더 튀어나가** 있습니다. → 300px라고 적었지만 실제로는 350px가 된 것입니다. (padding·border가 바깥으로 더해짐)
4. **2번 박스(`border-box`)**: 오른쪽 끝이 주황 점선에 **거의 딱 맞습니다.** → 300px라고 적은 그대로 보이는 것입니다. (padding·border가 300px 안에 포함됨)
5. `index.html`을 메모장(또는 VS Code)으로 열어 `.box` 규칙의 `padding: 20px;`을 `padding: 50px;`으로 바꿔 저장하고, 브라우저에서 **새로고침(F5)** 합니다. → 1번(content-box)은 더 넓게 튀어나가지만, 2번(border-box)은 **여전히 300px 폭**을 유지한 채 글자만 안쪽으로 밀리는 것을 확인합니다.
6. AI에게 시켜 보기:
   > "이 index.html에, `box-sizing: border-box`이면서 `width: 300px`, `padding: 40px`인 3번 박스를 추가해줘. 기존 박스는 그대로 두고 새 `.box-3`만 추가하고, 폭이 여전히 300px로 유지되는지 비교할 수 있게 해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 단계씩 순서대로 시키면 됩니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 CSS 박스모델을 가르치는 강사야. 비전공 초보가 box-sizing 차이를 눈으로 보게
  하는 index.html 한 파일을 만들어줘.

  요구사항:
  - 서버·라이브러리 없이 더블클릭으로 열리는 HTML 한 파일(CSS는 <style> 안에 같이).
  - 똑같이 width: 300px, padding: 20px, border: 5px 를 가진 박스 2개를 위아래로 배치.
  - 1번 박스는 box-sizing: content-box, 2번 박스는 box-sizing: border-box 로만 다르게.
  - 두 박스 위에 "여기까지가 width로 적은 300px"를 표시하는 주황 점선 기준선을 두어,
    1번은 점선보다 튀어나가고(=350px) 2번은 점선에 딱 맞는(=300px) 차이가 보이게.
  - 한국어 본문, 비전공자도 알아보게 박스 안에 계산식(300+40+10=350)을 글자로 써줘.

  코드만 주지 말고 왜 그렇게 했는지 한국어 주석으로 한 줄씩 풀어서 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html에, 기존 박스는 그대로 두고 아래를 추가해줘.
  - box-sizing: border-box 이면서 width: 300px, padding: 40px 인 3번 박스(.box-3)를 추가.
  - padding을 키웠는데도 전체 폭이 여전히 300px로 유지되는지 1·2번과 비교할 수 있게 배치.
  - 각 박스 아래에 "실제 화면 너비: ___px" 라벨을 달아 한눈에 비교되게 해줘.
  기존 .box / .box-content / .box-border 규칙은 절대 건드리지 말고 새 .box-3만 추가해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  두 박스 크기가 똑같이 보여서 box-sizing 차이가 안 나타나. 아래 index.html 전체를 붙여넣을게.
  (여기에 index.html 내용 붙여넣기)
  무엇이 문제인지 한 번에 고치지 말고, (1) 의심되는 원인 3가지, (2) 각각 어떻게 확인하는지,
  (3) 개발자도구(F12) 상자모델로 검증하는 방법 순서로 비전공자가 따라할 수 있게 알려줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **눈으로 확인**: 1번 박스의 오른쪽 끝은 주황 점선보다 튀어나가고, 2번 박스의 오른쪽 끝은 점선에 맞나요? → `content-box`는 커지고 `border-box`는 그대로라는 증거입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 1번 박스를 클릭하면 오른쪽에 **상자 모델 그림**이 나옵니다. 가운데 content가 `300 × ...`, 그 바깥 padding `20`, border `5`로 표시되고, 위쪽에 보이는 전체 박스 크기가 **350**에 가깝게 나오면 content-box가 맞습니다.
- 이번엔 2번 박스를 클릭하면, content 영역이 `300`보다 **작게**(300에서 padding·border를 뺀 값) 표시되고 전체 박스 크기는 **300**으로 나옵니다. → border-box가 padding·border를 안쪽으로 넣어 전체를 300px로 맞췄다는 증거입니다.
- (선택) 5번 단계처럼 `padding`을 키웠을 때, 1번은 전체 폭이 커지고 2번은 전체 폭이 그대로인지 다시 한 번 비교해 봅니다.
