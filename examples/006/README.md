# 굵게·기울임·강조로 문장 꾸미기

문단(`<p>`) 한 덩어리 안에서 **특정 단어만 강조**하거나 **줄을 바꾸는** 방법을 배웁니다.
강조에는 두 가지가 있어요. 중요해서 굵게 보이는 `<strong>`, 어조를 살려 기울여 보이는 `<em>`.
그리고 문단을 새로 만들지 않고 줄만 바꾸고 싶을 때 쓰는 `<br>`까지 함께 익힙니다.

## 목표

- `<strong>`(strong, 중요 강조 → 보통 굵게)과 `<em>`(emphasis, 어조 강조 → 보통 기울임)의 의미 차이를 이해한다.
- `<br>`(break, 줄바꿈)로 같은 문단 안에서 줄만 바꾸는 법을 익힌다.
- 강조 태그는 문단 전체가 아니라 **꾸미고 싶은 단어만 감싼다**는 점을 눈으로 확인한다.

## 따라하는 단계

1. 이 폴더(`examples/006`) 안에 있는 `index.html` 파일을 마우스로 더블클릭해서 웹 브라우저(크롬 등)로 엽니다.
2. 화면에서 일부 단어가 **굵게**(`<strong>`), 일부 단어가 *기울어져*(`<em>`) 보이는지 확인합니다.
3. 코드를 열어 강조하고 싶은 단어만 태그로 감쌌다는 것을 살펴봅니다. 문장 전체가 아니라 단어만 감쌉니다.
   ```html
   <p>이번 주 모임은 <strong>토요일 오후 2시</strong>에 시작합니다.</p>
   ```
4. 직접 단어 하나를 강조해 봅니다. 아무 문단에서 단어 하나를 골라 아래처럼 `<em>`으로 감싸고 저장한 뒤 새로고침(F5)하세요.
   ```html
   준비물은 <em>각자 마실 음료</em> 정도면 충분합니다.
   ```
   감싼 단어만 기울어져 보이면 성공입니다.
5. 줄바꿈을 직접 만들어 봅니다. 한 문장 중간에 `<br />`를 넣고 저장 후 새로고침하면, 그 자리에서 줄이 한 칸 내려갑니다.
   ```html
   첫 번째 안내입니다.<br />두 번째 안내입니다.
   ```
6. (비교 실험) `<br />`를 지워보세요. 줄이 내려가지 않고 한 줄로 이어집니다. HTML에서는 코드에서 엔터를 쳐도 화면에서 줄이 바뀌지 않으며, 줄을 바꾸려면 `<br>`가 필요하다는 점을 기억하세요. (확인 후 다시 넣어둡니다.)

## 검증법

- 브라우저 화면에서 `<strong>`으로 감싼 단어는 **굵게**, `<em>`으로 감싼 단어는 *기울어져* 보이면 성공입니다.
- 감싼 단어만 모양이 바뀌고, 나머지 글자는 그대로면 정상입니다. (문장 전체가 굵어졌다면 닫는 태그 `</strong>` 위치를 확인하세요.)
- `<br />`를 넣은 자리에서 줄이 한 칸 내려가면 줄바꿈이 제대로 된 것입니다.
- `<strong>` 안에 `<em>`을 넣으면 굵고 동시에 기울어진 글자가 됩니다. 두 강조를 겹쳐 쓸 수 있다는 뜻입니다.

> 메모: `<strong>`은 `<b>`(단순 굵게), `<em>`은 `<i>`(단순 기울임)와 화면 모양은 비슷합니다.
> 하지만 `<strong>`·`<em>`은 "이 단어가 중요하다/강조된다"는 **의미**를 담고 있어, 검색엔진·화면낭독기가 더 잘 이해합니다.
> 그래서 그냥 모양만 바꾸는 `<b>`·`<i>`보다 의미가 있는 `<strong>`·`<em>`을 먼저 쓰는 습관을 권합니다.
