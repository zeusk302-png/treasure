# 094. 에러 안내문에 빨강 테두리·아래 메시지 스타일 입히기

> 분류: 폼·입력·검증 (D) · 난이도 2/5
> 핵심 개념: `:invalid`, `:valid`, `:focus`

## 목표

입력칸에 적은 값이 **형식에 맞는지 틀린지**를 CSS만으로 색으로 보여줍니다.

- 형식이 **틀리면** 입력칸이 **빨간 테두리**가 되고, 아래에 **빨간 안내 메시지**가 나타납니다.
- 형식이 **맞으면** 입력칸이 **초록 테두리**로 바뀝니다.
- 지금 누른 입력칸은 **파란 테두리**(`:focus`)로 강조됩니다.

자바스크립트(JS) 없이 **CSS의 의사클래스(가짜 상태 선택자)** 만으로 이 모든 걸 처리하는 게 이번 실습의 핵심입니다.

> 의사클래스란? 요소의 "상태"에 따라 자동으로 켜졌다 꺼졌다 하는 표시입니다.
> 예) `input:focus` = "지금 선택된 입력칸", `input:invalid` = "형식이 틀린 입력칸".

## 따라하는 단계

1. 이 폴더(`094`)에 있는 `index.html`을 더블클릭해 브라우저로 엽니다. (`style.css`가 같은 폴더에 있어야 자동으로 함께 적용됩니다.)
2. **이메일** 칸에 `abc` 처럼 `@`가 없는 잘못된 값을 적어 봅니다. → 칸이 **빨개지고** 아래에 안내 메시지가 뜨는지 확인합니다.
3. 이어서 `abc@example.com` 처럼 올바른 형식으로 고쳐 적습니다. → 칸이 **초록색**으로 바뀌고 메시지가 사라지는지 확인합니다.
4. **비밀번호** 칸에 7글자만 적으면 빨강, 8글자 이상 적으면 초록으로 바뀌는지 봅니다. (`minlength="8"` 덕분입니다.)
5. **휴대폰 번호** 칸에 `01012345678`(하이픈 없음)을 적으면 빨강, `010-1234-5678` 형식이면 초록이 되는지 봅니다. (`pattern` 덕분입니다.)
6. `style.css`를 열어 핵심 3줄을 직접 바꿔 보며 익힙니다.
   - `input:focus { border-color: #2563eb; }` → 선택했을 때 색
   - `input:invalid:not(:placeholder-shown) { border-color: #dc2626; }` → 틀렸을 때 색
   - `input:valid:not(:placeholder-shown) { border-color: #16a34a; }` → 맞았을 때 색

### 왜 `:not(:placeholder-shown)`을 붙였나요? (중요)

`required`(필수 입력)가 걸린 칸은 **아직 아무것도 안 쓴 빈 칸**도 "형식이 틀림(`:invalid`)"으로 잡힙니다. 그러면 페이지를 열자마자 모든 칸이 빨개져서 보기 안 좋습니다.

`:placeholder-shown`은 "placeholder(흐린 안내문)가 보이는 = 아직 안 쓴 빈 칸" 상태입니다. 여기에 `:not(...)`을 붙이면 **"무언가 입력한 칸"만** 골라낼 수 있습니다. 그래서 `input:invalid:not(:placeholder-shown)` 은 **"입력은 했는데 형식이 틀린 칸"** 만 빨갛게 칠합니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 가르치는 강사야. 비전공 학습자가 따라할 수 있게,
  자바스크립트 없이 CSS 의사클래스만으로 폼 입력 검증 상태를 색으로 보여주는
  회원가입 폼을 만들어줘.

  요구사항:
  - 입력칸 3개: 이메일(type="email"), 비밀번호(type="password", minlength="8"),
    휴대폰 번호(type="tel", pattern으로 010-0000-0000 형식 강제)
  - 모든 칸은 required, 각 칸 아래에 형식이 틀렸을 때 보여줄 안내 메시지 <p>를 둘 것
  - <form>에 novalidate를 붙여 브라우저 기본 경고창은 끄고, 우리가 만든 색/메시지로만 안내
  - 파일은 index.html, style.css 두 개로 분리

  코드만 주지 말고, 비전공자가 막힐 만한 줄에 "무엇을 하는지 + 왜 그렇게 했는지"를
  한국어 주석으로 한 줄씩 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 폼에 CSS만으로 검증 상태 스타일을 입혀줘.

  - 지금 선택된 칸은 파란 테두리(:focus)
  - 형식이 틀린 칸은 빨간 테두리 + 옅은 빨강 배경, 그 칸 아래 안내 메시지를 보이게
  - 형식이 맞는 칸은 초록 테두리(:valid)
  - 중요: 페이지를 처음 열었을 때 아직 아무것도 안 쓴 빈 칸이 빨갛게 되면 안 돼.
    required 때문에 빈 칸도 :invalid로 잡히니까, :not(:placeholder-shown)을 함께 써서
    "무언가 입력한 칸"만 색을 바꾸도록 해줘.

  왜 :not(:placeholder-shown)이 필요한지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  페이지를 열자마자 모든 입력칸이 빨갛게 보여. 아직 아무것도 안 썼는데도 그래.
  내 style.css와 index.html을 붙여넣을게. 무엇이 원인인지, 어디를 어떻게 고쳐야
  빈 칸은 빨갛지 않고 "입력했는데 형식이 틀린 칸"만 빨개지는지 단계별로 알려줘.

  [여기에 style.css, index.html 코드 붙여넣기]
  ```

## 검증법

- 이메일 `abc` 입력 → 입력칸 빨간 테두리 + 아래 빨간 메시지 표시되면 성공.
- 이메일 `abc@example.com` 입력 → 입력칸 초록 테두리 + 메시지 사라지면 성공.
- 비밀번호 `1234567`(7자) → 빨강 / `12345678`(8자) → 초록 이면 성공.
- 휴대폰 `01012345678` → 빨강 / `010-1234-5678` → 초록 이면 성공.
- 아무 칸이나 클릭(선택)했을 때 파란 테두리가 잠깐 생기면 `:focus`가 동작하는 것입니다.
- 페이지를 처음 열었을 때 빈 칸들이 빨갛지 않아야 정상입니다. (만약 다 빨갛다면 `:not(:placeholder-shown)`이 빠진 것입니다.)
