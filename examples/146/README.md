# 실습 146 — 공개 명언 API 한 줄 받아서 화면에 띄우기

버튼을 누르면 인터넷 어딘가의 서버(API)에서 명언 한 줄을 받아와 화면에 보여주는 한 장짜리 페이지입니다.
서버도 데이터베이스도 직접 만들지 않습니다. **이미 공개된 남의 API를 주문해서 쓰는 것**이 핵심입니다.

## 목표
- `fetch`로 API를 **한 번 호출**해 응답을 받아오는 흐름을 몸으로 안다.
- 응답으로 온 **JSON(자바스크립트 객체)에서 필요한 값 한 줄**을 꺼내 화면에 표시한다.
- "API 호출 = 남의 주방에 음식 한 접시 주문"이라는 감을 잡는다.
  - `fetch(주소)` = 주방에 주문서 보내기
  - `await` = 음식이 나올 때까지 기다리기
  - `res.json()` = 받은 접시의 포장을 풀어 내용물 꺼내기

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭 → 브라우저에서 열린다. (인터넷 연결 필요)
2. **"명언 받기" 버튼**을 누른다 → 잠깐 "받아오는 중…"이 보이고, 곧 명언과 말한 사람이 뜬다.
3. 버튼을 여러 번 눌러 본다 → 누를 때마다 다른 명언이 나온다.
4. `script.js`를 열어 `fetch(...)` 줄을 찾아, 어떤 주소(`https://api.quotable.io/random`)를 주문하는지 확인한다.
5. `data.content`(명언)와 `data.author`(말한 사람) 두 값을 화면에 넣는 부분을 눈으로 따라가 본다.
6. AI에게 시켜 보기:
   > "이 script.js에서 명언을 받아올 때마다 '글자 수: 42자'처럼 명언의 길이도 화면에 같이 표시되게 고쳐줘."

## 검증법
- 버튼을 누르면 안내 문구가 **실제 명언으로 바뀌는가?**
- 버튼을 다시 누르면 **다른 명언**이 나오는가?
- 받아오는 동안 버튼이 잠깐 **비활성화(흐리게)** 되었다가 다시 눌리는가?
- (실패 확인) 와이파이를 끄고 버튼을 누르면 빨간 에러 대신 **"명언을 가져오지 못했어요…"** 안내가 뜨는가?
- 브라우저에서 `F12`(개발자 도구) → **Network 탭**을 켜고 버튼을 누르면 `random` 요청이 한 번 가는 게 보이는가?

## 키(API Key)는 필요 없어요
이 실습이 쓰는 명언 API는 **누구나 열쇠 없이** 부를 수 있는 **공개 API**입니다.
그래서 코드에 비밀값(`YOUR_API_KEY` 같은 것)을 넣지 않습니다.
나중에 유료 API나 내 데이터를 다루는 API를 쓸 때는 키가 필요하고,
그 키는 화면 코드(브라우저에 그대로 노출됨)에 넣으면 안 됩니다. 그건 뒤 실습에서 다룹니다.
