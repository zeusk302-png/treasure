# 이미지 갤러리 라이트박스 만들기

작은 사진(썸네일)을 누르면 큰 사진이 화면 위에 모달(라이트박스)로 떠오르고,
좌우 버튼이나 키보드 화살표로 사진을 한 장씩 넘길 수 있는 갤러리를 만드는 실습입니다.

쇼핑몰 상품 사진, 여행 사진첩, 포트폴리오에서 흔히 보는 바로 그 기능입니다.
이번 실습의 핵심은 **"클릭한 썸네일이 몇 번째인지(인덱스)를 읽어, 큰 사진의 주소(src)를 바꿔치기"** 하는 것입니다.

## 목표

- 썸네일에 적어 둔 정보(`data-index`)를 자바스크립트로 **읽어** 활용하기.
- 큰 사진의 `src`를 바꿔서 화면의 사진을 **교체**하기 (이미지 src 교체).
- 지금 몇 번째 사진을 보는지 변수(`currentIndex`)로 **기억**하고, +1 / -1 로 **이전·다음으로 이동**하기 (인덱스 이동).
- 마지막 사진에서 다음을 누르면 처음으로 **순환**되게 만들기 (나머지 연산 `%`).
- 모달을 열고 닫기: X 버튼, 검은 배경(오버레이) 클릭, 키보드 ESC.

## 따라하는 단계

1. 이 폴더(`073`)에 있는 세 파일을 확인합니다.
   - `index.html` : 화면 뼈대 (썸네일 5개 + 숨겨진 라이트박스).
   - `style.css`  : 갤러리와 라이트박스 꾸밈.
   - `script.js`  : 클릭하면 큰 사진을 띄우고 넘기는 동작.
2. `index.html` 파일을 더블클릭해서 웹 브라우저(크롬 등)로 엽니다. (인터넷 연결이 없어도 사진이 보입니다)
3. 색이 칠해진 **썸네일 5장** 중 하나를 클릭합니다. 화면 전체가 어두워지면서 큰 사진이 떠야 합니다.
4. 큰 사진 양옆의 **‹ (이전) / › (다음)** 버튼을 눌러 사진을 넘겨봅니다. 아래 "3 / 5" 숫자가 함께 바뀝니다.
5. 마지막(5번) 사진에서 **›** 를 누르면 다시 1번으로 돌아가는지 확인합니다. (순환)
6. 키보드로도 조작해 봅니다. **← →** 로 넘기고, **ESC** 로 닫습니다. 사진 주변의 검은 배경을 눌러도 닫힙니다.
7. 코드를 직접 살펴봅니다.
   - `index.html`의 썸네일 버튼마다 `data-index="0"`, `"1"` … 이 붙어 있습니다. 이게 "몇 번째 사진인지" 이름표입니다.
   - `script.js`의 `showImage(index)` 함수가 `lightboxImg.src = images[index].src;` 로 큰 사진을 **교체**합니다.
   - `showNext()` / `showPrev()`가 `% totalImages` 로 끝과 처음을 이어줍니다.
8. (실험) `script.js`에서 큰 사진을 띄울 때 위치 표시 글자를 바꿔봅니다.
   `counter.textContent = (index + 1) + " / " + totalImages;` 에서 `(index + 1)`을 `index`로 바꾸고
   브라우저를 **새로고침(F5)** 하면, 사람이 보는 번호가 0부터 시작하게 됩니다. (컴퓨터는 0부터 센다는 걸 확인)
   확인 후엔 다시 `(index + 1)`로 되돌려 두세요.

## 검증법

- 썸네일을 클릭하면 **그 색의 큰 사진**이 모달로 떠야 합니다. (1번을 누르면 빨강, 4번을 누르면 파랑)
- ‹ › 버튼으로 사진이 바뀌고, 동시에 **"N / 5" 숫자**가 같이 바뀌면 정상입니다.
- 마지막 사진에서 다음 → 처음으로, 첫 사진에서 이전 → 마지막으로 **순환**되면 인덱스 이동이 잘 된 것입니다.
- X 버튼 / 검은 배경 클릭 / ESC 키 **세 가지 모두**로 닫히면 성공입니다.
- 잘 안 될 때 점검할 곳:
  - 클릭해도 모달이 안 뜨면: `index.html`의 `data-index`와 `<button class="thumb">` 클래스 이름이 그대로인지, `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지 확인합니다.
  - 큰 사진이 안 바뀌면: `script.js`의 id(`lightboxImg`)와 `index.html`의 `<img id="lightboxImg">` id가 **똑같은 철자**인지 확인합니다.
  - 그래도 안 되면 브라우저에서 `F12` → **Console** 탭에 빨간 에러가 있는지 봅니다. (보통 id 철자 오타입니다)

## 핵심 정리

- **`data-*` 속성과 `dataset`**: HTML 요소에 `data-index="2"`처럼 정보를 숨겨 두고, 자바스크립트에서 `요소.dataset.index`로 꺼내 씁니다. (꺼낸 값은 글자라서 `Number(...)`로 숫자 변환)
- **이미지 교체**: `img.src = "새 주소"`만 바꾸면 화면의 사진이 즉시 교체됩니다.
- **인덱스 순환**: `(현재 + 1) % 전체개수`로 "끝 다음은 처음"을 한 줄로 만듭니다.
- **모달 닫기 3종**: 버튼 클릭, 오버레이(배경) 클릭, 키보드 이벤트(`keydown`의 `Escape`).
