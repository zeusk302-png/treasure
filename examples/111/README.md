# 실습 111 — 할 일 항목 개별 삭제와 완료 체크 토글

앞 실습(110)에서는 할 일을 **목록으로 쌓아 저장**하기까지 했습니다.
이번에는 한 단계 더 나아가, 각 할 일에 **완료 체크박스**와 **삭제 버튼**을 붙입니다.
"이미 있는 목록(배열)에서 **특정 한 줄만 골라 바꾸거나 빼는**" 방법을 배우는 실습입니다.

이걸 위해 할 일을 글자 하나가 아니라 **작은 정보 묶음(객체)** 으로 다룹니다.

```js
{ id: 1718000000000, text: "우유 사기", done: false }
```
- `id`: 할 일을 구별하는 고유 번호 (삭제·토글할 때 "어느 줄인지" 찾는 열쇠)
- `text`: 할 일 내용
- `done`: 완료했는지 여부 (`true` = 완료, `false` = 진행 중)

## 목표
- 할 일을 **객체 `{ id, text, done }`** 로 표현하고, 그 객체들을 배열에 담아 다룬다.
- **삭제**는 `filter`로 한다: "지울 항목만 빼고 나머지를 남긴 **새 배열**"을 만든다.
- **완료 토글**은 `map`으로 한다: "내가 누른 항목만 `done` 값을 뒤집고 나머지는 그대로 둔 **새 배열**"을 만든다.
- 배열을 바꿀 때마다 **다시 저장(`saveTodos`) → 다시 그리기(`render`)** 하는 흐름이 몸에 배게 한다.

> `filter`와 `map`이 헷갈려요!
> - `filter` = **거르기**. 조건이 맞는 항목만 남기고 나머지는 버립니다. → **개수가 줄 수 있음** (삭제에 사용)
> - `map` = **하나씩 가공하기**. 모든 항목을 살펴보며 새 값으로 바꿔 돌려줍니다. → **개수는 그대로** (완료 토글에 사용)
> 둘 다 원래 배열을 직접 고치지 않고 **새 배열을 만들어** `todos`에 다시 담는다는 공통점이 있습니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. 입력칸에 할 일을 적고 **[추가]** 버튼(또는 **Enter** 키)을 눌러 **3~4개** 추가한다.
3. 아무 할 일의 **왼쪽 체크박스**를 켜 본다 → 글자에 **취소선**이 생기고 회색으로 바뀐다.
4. 맨 아래 "남은 할 일: N개" 숫자가 체크할 때마다 **줄어드는지** 확인한다.
5. 어떤 할 일의 **[삭제]** 버튼을 눌러 본다 → 그 줄만 사라지고 나머지는 그대로 남는다.
6. 키보드 **F5**(새로고침)를 누른다 → 남은 할 일과 **완료 체크 상태까지** 그대로 유지되는지 확인한다.
7. AI에게 시켜 보기:
   > "이 index.html에서 '완료된 할 일만 한 번에 지우는' [완료 항목 비우기] 버튼을 추가해 줘.
   > `filter`로 `done`이 `false`인 것만 남기고 다시 저장되도록 해 줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 자바스크립트 입문자를 돕는 친절한 강사야.
  HTML 파일 하나(index.html)로만 동작하는 "할 일 목록"을 만들어 줘. 조건은 이렇게:
  - 입력칸 + [추가] 버튼이 있고, Enter 키로도 추가된다.
  - 할 일은 글자가 아니라 객체 { id, text, done } 로 다루고, 그 객체들을 배열 todos 에 담는다.
    (id는 Date.now() 로 만들어 항목마다 겹치지 않게 한다.)
  - 화면을 다시 그리는 render() 함수가 todos 배열을 보고 <li> 목록을 만든다.
  - 각 줄에는 [완료 체크박스] + [할 일 글자] + [삭제 버튼] 이 들어간다.
  외부 라이브러리 없이 순수 HTML/CSS/JS로만, 한 파일로 만들어 줘.
  비전공자가 읽을 수 있게 각 함수 위에 "무엇을 하고 왜 필요한지" 한국어 주석을 달아 줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 할 일 목록에 아래 기능을 추가해 줘. 기존 코드는 최대한 그대로 두고 필요한 부분만 더해 줘.
  1) 완료 토글: 체크박스를 누르면 그 항목만 done 값이 뒤집힌다. map 을 써서 "누른 id 만 done 을 반대로 바꾼 새 배열"을 만들어 todos 에 다시 담아 줘.
  2) 개별 삭제: [삭제] 버튼을 누르면 그 줄만 사라진다. filter 를 써서 "그 id 만 빼고 나머지를 남긴 새 배열"을 만들어 줘.
  3) 저장 유지: 배열이 바뀔 때마다 localStorage(키 이름 todos_v2)에 JSON.stringify 로 저장하고, 페이지를 열 때 JSON.parse 로 다시 불러와서 새로고침해도 완료 상태까지 유지되게 해 줘.
  4) 맨 아래에 "남은 할 일: N개"를 보여 줘. (done 이 false 인 것만 세면 된다.)
  왜 map 과 filter 를 각각 썼는지 주석으로 한 줄씩 설명도 달아 줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내 할 일 목록이 이상하게 동작해. 아래 증상 중 하나가 생겨.
  - [삭제]를 눌렀더니 그 줄이 아니라 다른 줄이 사라진다.
  - 체크박스를 눌러도 취소선이 안 생기거나, 새로고침하면 완료 상태가 풀린다.
  내 index.html 전체 코드를 붙여넣을 테니, 무엇이 문제인지 한 단계씩 짚어 줘.
  특히 id 비교(=== 인지 == 인지), map/filter 가 새 배열을 todos 에 다시 담고 있는지,
  바꾼 뒤에 saveTodos() 와 render() 를 부르고 있는지를 확인해 줘.
  고친 부분은 "왜 이게 문제였는지"를 비전공자가 이해하게 한 줄로 설명해 줘.

  [여기에 내 코드 / 콘솔(F12) 에러 메시지를 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- 체크박스를 켜면 해당 줄에 취소선이 생기고, 다시 끄면 원래대로 돌아오는가?
- [삭제]를 누르면 **그 줄만** 사라지고 다른 줄은 그대로 남는가?
- 완료 체크와 삭제를 한 뒤 **새로고침**해도 상태가 그대로인가? (완료 표시까지 유지되어야 함)
- "남은 할 일: N개" 숫자가 체크/삭제할 때마다 정확히 바뀌는가?
- 개발자도구(F12) → **Application 탭 → Local Storage** 에 `todos_v2` 키가 있고,
  값이 `[{"id":...,"text":"우유 사기","done":true}, ...]` 처럼 **객체 배열 글자**로 저장돼 있는가?
- (실험) Local Storage에서 `todos_v2` 값을 직접 지우고 새로고침하면 "아직 할 일이 없어요."로 바뀌는가?

## 핵심 코드 한 줄로 보기
```js
// 추가: 글자가 아니라 객체로 만들어 push
todos.push({ id: Date.now(), text: "우유 사기", done: false });

// 완료 토글: 누른 항목(id 일치)만 done을 뒤집기 — map
todos = todos.map(t => t.id === id ? { ...t, done: !t.done } : t);

// 개별 삭제: 지울 항목만 빼기 — filter
todos = todos.filter(t => t.id !== id);

// 바꿨으면 항상 저장 → 다시 그리기
localStorage.setItem("todos_v2", JSON.stringify(todos));
```
> 위 한 줄짜리 화살표 함수(`t => ...`)는 `index.html` 안에서는 초보자가 읽기 쉽도록
> `function (todo) { ... }` 형태로 풀어 써 두었습니다. 둘은 똑같이 동작합니다.
