# 라면 끓이는 순서(번호 목록) 만들기

조리 순서처럼 "1번 먼저, 2번 다음, 3번 그다음..." 순서가 중요한 내용을 보여줄 때 쓰는
**순서 있는 목록(`<ol>`)** 을 만들어 봅니다. 번호는 우리가 손으로 적는 게 아니라
브라우저가 자동으로 1, 2, 3... 붙여줍니다.

## 목표

- `<ol>`(ordered list, 순서 있는 목록)과 `<li>`(list item, 목록 항목)의 관계를 이해한다.
- `<li>` 항목을 추가하거나 순서를 바꾸면 번호가 자동으로 다시 매겨지는 것을 눈으로 확인한다.
- 점(`•`)으로 나오는 `<ul>`(순서 없는 목록)과의 차이를 구분한다.

## 따라하는 단계

1. 이 폴더(`examples/005`) 안에 있는 `index.html` 파일을 마우스로 더블클릭해서 웹 브라우저(크롬 등)로 엽니다.
2. 화면에 "라면 맛있게 끓이는 순서"라는 큰 제목과, 그 아래에 **1부터 6까지 번호가 붙은 목록**이 보이는지 확인합니다.
3. 코드를 열어 구조를 살펴봅니다. 바깥을 감싸는 `<ol> ... </ol>` 안에, 각 줄을 `<li>...</li>`로 감싼 형태입니다.
   ```html
   <ol>
     <li>냄비에 물을 붓습니다.</li>
     <li>물을 끓입니다.</li>
   </ol>
   ```
4. 직접 항목을 하나 추가해 봅니다. `</ol>` 바로 위에 아래 한 줄을 끼워 넣고 저장한 뒤 브라우저를 새로고침(F5)하세요.
   ```html
   <li>다 먹은 그릇은 바로 설거지합니다.</li>
   ```
   번호 `7`이 자동으로 붙는 것을 확인합니다. (직접 숫자를 적지 않았다는 점이 핵심!)
5. 항목 두 개의 위치를 위아래로 바꿔보고 새로고침해서, 번호가 위치에 맞게 다시 매겨지는지 확인합니다.
6. (비교 실험) `<ol>`을 `<ul>`로, `</ol>`을 `</ul>`로 바꿔 저장하고 새로고침하면, 번호 대신 점(`•`)으로 바뀝니다.
   순서가 중요하면 `<ol>`, 순서가 상관없으면 `<ul>`을 쓴다는 차이를 기억하세요. (확인 후 다시 `<ol>`로 되돌립니다.)

## 검증법

- 브라우저 화면에서 각 줄 앞에 **1, 2, 3...** 숫자가 자동으로 붙어 있으면 성공입니다.
- `<li>` 항목을 추가하거나 순서를 바꾼 뒤 새로고침했을 때, 번호가 알아서 1부터 다시 매겨지면 정상입니다.
- 숫자를 손으로 적은 곳이 한 군데도 없는데 번호가 나온다면 `<ol>`을 제대로 쓴 것입니다.
- 점(`•`)이 나온다면 `<ol>`이 아니라 `<ul>`로 되어 있는 것이니 태그를 확인하세요.
