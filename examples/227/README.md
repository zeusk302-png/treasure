# 227. AI에게 "까다로운 심사위원"으로 내 PLAN.md 코드리뷰 시키기

## 목표

내가 만든 기획서 `PLAN.md`를 **AI에게 그대로 칭찬받지 말고**,
**칭찬을 금지**한 채 **약점 3가지**와 **내가 물었어야 할 질문**을 콕 집어 지적하게 만들어,
AI의 **아첨(sycophancy) 답변을 피하는 비판 프롬프트**를 익히는 연습입니다.

비전공자가 AI에게 가장 많이 듣는 말은 **"좋은데요!", "잘 만드셨어요!"** 입니다.
하지만 이건 AI가 **나를 기분 좋게 해주려는 성향** 때문이지, 내 기획이 진짜 좋아서가 아닙니다.
**"이거 괜찮죠?"** 라고 물으면 AI는 거의 항상 **"네 괜찮아요"** 라고 답합니다(아첨).
그래서 이번엔 **질문의 역할을 바꿔서**, AI를 친절한 도우미가 아니라
**떨어뜨리려고 작정한 까다로운 심사위원**으로 세웁니다.

다만 AI의 비판도 항상 옳은 건 아닙니다. 무엇을 고치고 무엇을 미룰지는 **사람(디렉터)이 결정**합니다.
이 실습에는 새로 짤 코드가 없습니다. **AI에게서 솔직한 비판을 끌어내는 질문 설계**가 곧 실습입니다.

이 폴더의 파일은 다섯입니다.

- [`prompt.md`](prompt.md) — AI를 "까다로운 심사위원"으로 만드는, 그대로 붙여넣는 지시 프롬프트
- [`PLAN.md`](PLAN.md) — **리뷰할 재료.** 220번 실습에서 만든 기획서 예시(여러분 것으로 바꿔 넣으세요)
- [`conversation.md`](conversation.md) — AI가 칭찬을 빼고 약점을 짚어준 대화 캡처(예시)
- [`REVIEW.md`](REVIEW.md) — **이 실습의 결과물.** 약점 3가지 + 개선안 + 내 결정이 담긴 리뷰 메모
- `README.md` — 지금 읽는 이 안내문

## 따라하는 단계

1. 리뷰할 재료를 준비합니다. 같은 폴더의 [`PLAN.md`](PLAN.md)를 쓰거나, **내가 직접 만든 진짜 PLAN.md**(220번 실습 결과)를 준비합니다.
2. [`prompt.md`](prompt.md)를 열어 **1단계 지시 프롬프트**를 통째로 복사하고, `[여기에 내 PLAN.md 내용을 붙여넣기]` 자리에 위 기획서를 통째로 넣습니다. 핵심 제약은 **"칭찬 금지, 약점 3개를 무엇이/왜/개선안으로, 그리고 내가 안 물은 질문 3개"** 입니다.
3. 완성한 프롬프트를 실제 Claude(또는 쓰는 AI)에 붙여넣습니다.
4. AI가 **칭찬 없이 약점부터** 짚는지 봅니다. 각 약점에 "어디가 / 왜 문제인지 / 1줄 개선안"이 붙어 있어야 합니다.
5. 만약 AI가 **"전반적으로 좋네요, 다만…"** 하고 칭찬으로 시작하거나 **"보완하면 좋을 것 같다"** 처럼 두루뭉술하게 넘어가면, [`prompt.md`](prompt.md)의 **2단계 한 마디**("칭찬 빼고 약점만 다시")로 다시 잡아 줍니다. (대화 예시는 [`conversation.md`](conversation.md))
6. 약점을 다 받았으면 [`prompt.md`](prompt.md)의 **3단계 한 마디**로 "약점 / 개선안 / 내 결정" 표를 정리시키고, **AI가 과한 지적을 했는지도 자진 신고**하게 합니다.
7. AI가 정리한 것을 같은 폴더의 [`REVIEW.md`](REVIEW.md)처럼 옮기되, **"내 결정" 칸(고친다 / 다음에 / 동의 안 함)은 내가 직접** 채웁니다.
8. **가장 중요한 마무리:** AI 비판을 그대로 다 따르지 말고, **"이게 내 첫 버전·내 규모에 진짜 해당하나?"** 를 사람이 가립니다. 과한 비판이면 미루고, 진짜 약점이면 PLAN.md를 고칩니다. **승인 권한은 디렉터(나)에게** 있습니다.

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] AI가 **칭찬·덕담 없이** 약점부터 지적했다. (처음에 칭찬했다면 2단계 한 마디로 교정했다)
- [ ] 약점이 정확히 **3가지**이고, 각각 **(무엇이 / 왜 문제인지 / 1줄 개선안)** 이 붙어 있다.
- [ ] **"내가 디렉터로서 안 물은 질문 3개"** 가 나왔다.
- [ ] AI가 **"좋다 / 괜찮다 / 보완하면 좋다"** 같은 두루뭉술한 말로 비판을 피하지 않았다.
- [ ] 마지막에 **"예 / 아니오 / 조건부 예"** 한 줄 결론이 나왔다.
- [ ] [`REVIEW.md`](REVIEW.md)에 약점 3개 + 개선안이 정리되고, **"내 결정" 칸을 사람이 직접** 채웠다.
- [ ] AI 비판 중 **과한 지적**이 있는지 사람이 한 번 가렸다. (전부 무조건 수용하지 않았다)

> 빠르게 자가 점검: 받은 리뷰만 보고 **"PLAN.md에서 뭘 먼저 고쳐야 하는지 한눈에 보이면"** 통과입니다.
> AI가 "좋네요"만 반복하고 약점이 안 나왔다면, 아직 **아첨에 걸린 것**입니다. [`prompt.md`](prompt.md)의 2단계로 더 세게 압박하세요.
