# 민지 포트폴리오 사이트 기획서 (PLAN.md)

> 이 파일은 **AI에게 리뷰시킬 "재료"** 입니다.
> 220번 실습에서 만든 기획서 예시를 그대로 가져온 것입니다.
> 여러분은 이 자리에 **여러분이 직접 만든 PLAN.md**를 넣고 리뷰시키면 됩니다.

## 목표
- 디자인 분야 취업 지원 시, 이력서 대신 링크 하나로 내 작업물을 보여준다.

## 대상(누가 보는가)
- 회사 채용 담당자 (휴대폰으로 열어볼 수도 있음)

## 페이지·섹션
- 한 장짜리(one-page), 위에서 아래로 스크롤
  1. 상단: 이름 + 한 줄 소개
  2. 소개: 나를 설명하는 한 문단
  3. 작업물: 프로젝트 3개 (이미지 + 제목 + 설명)
  4. 연락: 이메일 주소(텍스트로 표시)

## 꼭 들어갈 것
- 내 소개 한 문단
- 작업물 3개
- 이메일 주소
- 휴대폰에서도 안 깨지게(반응형)

## 범위 밖 (이번엔 안 함)
- 연락처 수집 폼 / 자동 메일 (다음 버전)
- 블로그, 방문자 통계, 로그인, 다국어
