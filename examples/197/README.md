# 고정 텍스트를 내 이메일로 보내는 n8n 워크플로우

수동 실행 버튼을 누르면, 내 이메일 주소로 **"안녕하세요, n8n 테스트입니다."** 라는 고정 메일 1통이 날아갑니다. n8n에서 **자격증명(Credential) 연결**과 **액션 노드**가 무엇인지 처음 익히는 실습입니다.

## 목표

- n8n의 자동화 뼈대인 **트리거(언제 시작) + 액션(무엇을 할지)** 조합을 직접 만든다.
- Gmail 같은 외부 서비스를 **자격증명(Credential)** 으로 안전하게 연결하는 법을 익힌다.
- 워크플로우를 **수동 실행** 해서 메일이 실제로 도착하는지 눈으로 확인한다.

> 이 워크플로우는 노드 2개입니다.
> `수동 실행 (Manual Trigger)` → `Gmail로 메일 보내기`
> 앞 노드가 "지금 시작해!"라는 신호를 주면, 뒤 노드가 메일을 보냅니다.

## 따라하는 단계

1. **n8n에 로그인**합니다. (n8n Cloud 가입형 또는 직접 설치한 n8n 모두 가능)
2. 화면 오른쪽 위 **`...` (점 3개) → `Import from File`** 을 눌러 이 폴더의 **`workflow.json`** 파일을 불러옵니다. 노드 2개가 화면에 나타납니다.
3. **Gmail 자격증명을 등록**합니다. (한 번만 등록하면 다음부터 재사용됩니다)
   - `Gmail로 메일 보내기` 노드를 더블클릭 → `Credential to connect with` → `Create New Credential` 선택.
   - `Sign in with Google` 버튼을 눌러 본인 구글 계정으로 로그인하고 권한을 허용합니다.
   - 메일을 보낼 권한만 허용하면 됩니다(**최소 권한**: 메일 읽기·삭제 권한까지 줄 필요 없음).
4. **받는 사람 주소를 내 메일로 바꿉니다.** 노드 안의 `To` 칸에 적힌 `YOUR_EMAIL@example.com` 을 **내가 받아볼 실제 이메일 주소**로 고칩니다.
5. (선택) `Subject`(제목)와 `Message`(본문) 글자를 원하는 문장으로 바꿔 봅니다.
6. 캔버스 아래쪽 **`Test workflow`(수동 실행)** 버튼을 누릅니다.
7. 내 메일함을 열어 **"n8n 테스트 메일입니다"** 제목의 메일이 도착했는지 확인합니다.

## 🤖 바이브코딩 프롬프트

이 워크플로우를 직접 손으로 만들거나 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. (n8n은 노드를 클릭으로 잇는 도구지만, 구조 설계·JSON 점검·디버깅을 AI에게 시키면 훨씬 빠릅니다.)

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 n8n 자동화 설계를 도와주는 멘토야. 비전공자인 내가 처음 만드는 워크플로우다.
  목표: 내가 수동 실행 버튼을 누르면, 고정된 텍스트("안녕하세요, n8n 테스트입니다.")가
  내 Gmail로 메일 1통 발송되는 가장 단순한 워크플로우를 만들고 싶어.
  제약:
  - 노드는 딱 2개만: '수동 실행(Manual Trigger)' → 'Gmail로 메일 보내기'.
  - 실제 키/비밀번호는 절대 적지 말고, 자격증명(Credential)은 자리표시자만 쓸 것.
  산출물: ① n8n에서 어떤 노드를 어떤 순서로 추가하고 연결하는지 클릭 단계,
  ② import해서 쓸 수 있는 workflow.json 예시.
  각 단계가 왜 필요한지 한 줄씩 설명을 붙여줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  위 워크플로우를 한 단계 발전시키고 싶어. 다음 중 하나씩 골라서 방법을 알려줘.
  ① 매일 아침 9시에 자동으로 메일이 가도록 '수동 실행'을 'Schedule(스케줄) 트리거'로 바꾸기.
  ② 메일 제목/본문에 오늘 날짜를 자동으로 넣기(예: "2026-06-19 일일 점검").
  ③ Gmail 대신 네이버/회사 메일을 쓰도록 'Send Email(SMTP)' 노드로 교체하기.
  각 방법마다 어떤 노드의 어떤 칸을 어떻게 바꾸는지, 그리고 왜 그렇게 하는지 설명해줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  n8n에서 워크플로우를 실행했는데 'Gmail로 메일 보내기' 노드가 빨간색 오류로 멈췄어.
  오류 메시지: (여기에 화면의 빨간 에러 메시지를 그대로 붙여넣기)
  비전공자도 알아듣게, 가능한 원인을 가능성 높은 순서로 정리하고,
  각 원인을 어떻게 확인하고 고치는지 단계별로 알려줘.
  (특히 자격증명 연결 누락, To 주소 비어 있음, 권한 부족을 먼저 점검해줘.)
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

1. 실행 직후 두 노드에 **초록색 체크 표시**가 뜨면 정상 작동한 것입니다.
2. 각 노드를 클릭해 **입력/출력 데이터(INPUT / OUTPUT)** 를 열어, 보낸 주소·제목·본문이 의도대로 들어갔는지 눈으로 확인합니다.
3. 실제 **내 메일함(받은편지함 또는 스팸함)** 에 메일이 도착했는지 확인합니다.
4. 일부러 `To` 주소를 비우고 실행해 보고, 워크플로우가 **빨간색 오류**로 멈추는지 확인합니다. (실패 케이스 점검)

## 자격증명, 왜 이렇게 하나요 (디렉터 관점)

- 메일을 보내려면 비밀번호 같은 **키**가 필요합니다. 이 키를 워크플로우 본문이나 코드에 그대로 적으면 안 됩니다.
- n8n의 **자격증명(Credential)** 은 키를 별도 금고에 보관하고, 노드는 그 금고를 **참조만** 합니다. 그래서 `workflow.json` 안에는 실제 키 대신 자리표시자(`YOUR_GMAIL_CREDENTIAL_ID`)만 들어 있습니다 — 이 파일을 공유해도 내 계정 비밀번호는 새어 나가지 않습니다.
- 키 발급·연결은 본인의 n8n 화면(3단계)에서 직접 합니다. **이 파일을 그대로 가져오면 자격증명은 비어 있으니, 반드시 본인 계정으로 새로 연결해야 합니다.**

## Gmail 대신 일반 SMTP로 보내고 싶다면

회사 메일이나 네이버 메일 등 Gmail이 아닌 계정을 쓰려면 Gmail 노드 대신 **`Send Email`(SMTP)** 노드를 씁니다.
- `Gmail로 메일 보내기` 노드를 지우고, `Send Email` 노드를 추가해 `수동 실행` 노드와 연결합니다.
- 자격증명은 메일 서비스가 알려주는 **SMTP 호스트·포트·아이디·앱 비밀번호**를 입력합니다. (예: 호스트 `smtp.example.com`, 포트 `465`)
- `From`, `To`, `Subject`, `Text`(본문)를 채우고 실행하면 동일하게 메일이 나갑니다.
