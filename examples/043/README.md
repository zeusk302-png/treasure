# 043. 이미지 위에 글자 얹은 히어로 섹션 만들기

사이트를 열었을 때 가장 먼저 보이는 큰 대표 배너를 **히어로(hero) 섹션**이라고 부릅니다. 이번 실습에서는 배경 사진 한 장 위에 **반투명한 막(오버레이)** 을 깔고, 그 위에 **제목·설명·버튼**을 올려 가운데에 띄우는 레이아웃을 만듭니다. 핵심 도구는 `position: relative`(기준 액자)와 `position: absolute`(그 안에서 자유롭게 띄우기) 두 가지입니다.

## 목표

- `position: relative`를 준 박스가 **안쪽 요소들의 기준점(액자)** 이 된다는 것을 이해한다.
- `position: absolute`로 자식 요소를 부모 박스 위에 **겹쳐서 띄우는** 법을 익힌다.
- 사진 위 흰 글자가 잘 보이도록 **반투명 오버레이**(`rgba`로 투명도 조절)를 까는 이유를 이해한다.
- `z-index`로 "어느 층이 위에 올지" 정해 글자가 막에 가려지지 않게 하는 법을 익힌다.

## 따라하는 단계

1. `index.html`과 `style.css`가 **같은 폴더(043)** 안에 있는지 확인합니다. HTML 위쪽의 `<link rel="stylesheet" href="style.css" />` 한 줄이 두 파일을 연결해 줍니다.
2. `index.html`을 더블클릭해 브라우저(크롬 등)로 엽니다. 파란 배경 위에 흰 제목과 노란 버튼이 가운데 떠 있는 큰 배너가 보이면 성공입니다.
3. 히어로의 구조가 **3겹**이라는 점을 코드에서 확인합니다.
   - `.hero` → 배경 사진을 깐 **액자**. `position: relative`가 핵심입니다(기준점 역할).
   - `.hero-overlay` → 사진 위에 덮는 **반투명 검은 막**. `position: absolute; inset: 0;`으로 액자 전체를 꽉 채웁니다.
   - `.hero-content` → 막 위에 얹는 **제목·설명·버튼**. `position: absolute; z-index: 1;`로 막보다 위 층에 띄웁니다.
4. `style.css`의 핵심 두 줄을 직접 바꿔보며 원리를 확인합니다. (확인 후 원래 값으로 되돌리세요.)
   - `.hero-overlay`의 `rgba(0, 0, 0, 0.45)`에서 마지막 숫자 `0.45`를 `0`으로 바꾸면 막이 사라져 사진이 그대로 보이고, `0.8`로 키우면 화면이 더 어두워집니다. → 글자 가독성을 위해 막을 까는 이유를 체감할 수 있습니다.
   - `.hero` 의 `position: relative;`를 잠깐 `static`으로 바꿔보면, 안쪽 `absolute` 요소들이 기준을 잃고 화면 전체를 기준으로 엉뚱한 곳에 붙습니다. → `relative`가 "기준 액자"인 이유를 눈으로 확인할 수 있습니다. (확인 후 꼭 `relative`로 되돌리세요.)
5. 실제 사진으로 바꿔봅니다. `.hero`의 `background-image: url("...")` 안의 긴 SVG 코드 대신 본인 이미지 경로를 넣으면 됩니다.
   ```css
   background-image: url("images/busan.jpg"); /* 또는 인터넷 이미지 주소 */
   ```
6. (선택) 노란 버튼 `href="#start"`는 페이지 안의 `id="start"` 영역으로 이동하는 링크입니다. 버튼을 눌러 아래 본문으로 점프하는지 확인해 봅니다.

> 참고: 예제의 배경은 인터넷 연결 없이도 보이도록 실제 사진 대신 SVG로 그린 그라데이션을 사용했습니다. 그래서 별도 이미지 파일 없이 `index.html`만 열어도 바로 동작합니다.

## 검증법

- 브라우저로 `index.html`을 열면 **배경 사진(파란 그라데이션) 위에 흰 제목·설명·노란 버튼이 가운데 정렬**되어 보인다.
- 사진이 살짝 어둡게 덮여 있어 **흰 글자가 또렷하게 읽힌다** (반투명 오버레이가 적용된 상태).
- 노란 버튼에 마우스를 올리면 색이 살짝 진해지고, 클릭하면 아래 본문(`#start`)으로 이동한다.
- 브라우저 창 너비를 모바일 크기(600px 이하)로 줄이면 배너 높이와 글자 크기가 작아진다.
- 개발자도구(F12) > Elements에서 `.hero`를 선택하면 `position: relative`가, `.hero-overlay`/`.hero-content`를 선택하면 `position: absolute`가 적용된 것을 확인할 수 있다.
