# 이름 입력하면 인사말 출력하기

입력칸에 이름을 적고 "인사하기" 버튼을 누르면 화면에 "○○님, 안녕하세요!"가 나타나는 작은 페이지입니다. 자바스크립트로 사용자가 적은 입력값(`input.value`)을 읽어와, 그 값을 다른 글자와 이어 붙여(문자열 결합) 한 문장을 만들어 화면에 보여주는 법을 익힙니다.

## 목표

- 입력칸에 적힌 글자를 자바스크립트로 읽어오는 `input.value`를 이해합니다.
- 읽어온 값(이름)을 고정된 글자("님, 안녕하세요!")와 이어 붙이는 문자열 결합(`+`)을 익힙니다.
- 만든 문장을 화면의 빈 자리(`<p>`)에 `textContent`로 표시하는 흐름을 익힙니다.

## 따라하는 단계

1. 이 폴더(`062`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. "이름" 입력칸과 "인사하기" 버튼이 보이는지 확인합니다.
3. 입력칸에 자기 이름(예: 세영)을 적고 "인사하기" 버튼을 누릅니다. 아래에 "세영님, 안녕하세요!"가 나타나면 성공입니다.
4. `index.html`을 살펴봅니다. 이름 입력칸에는 `id="nameInput"`, 버튼에는 `id="greetBtn"`, 인사말이 표시될 빈 문단에는 `id="result"`가 붙어 있습니다. 자바스크립트는 이 id로 각 요소를 찾아냅니다.
5. `script.js`를 엽니다. 동작은 간단합니다.
   - `document.getElementById(...)`로 입력칸·버튼·결과 자리를 찾습니다.
   - 버튼에 `addEventListener("click", ...)`로 클릭 동작을 연결합니다.
   - 클릭하면 `nameInput.value`로 입력칸에 적힌 이름을 읽습니다.
   - 읽은 이름을 `name + "님, 안녕하세요!"`처럼 다른 글자와 이어 붙여(문자열 결합) 문장을 만듭니다.
   - 만든 문장을 `result.textContent`에 넣어 화면에 보여줍니다.
6. 브라우저로 돌아가 이름을 바꿔가며 여러 번 눌러봅니다. 누를 때마다 적은 이름에 맞춰 인사말이 바뀌면 성공입니다.

## 검증법

- 입력칸에 "세영"을 적고 버튼을 누르면 "세영님, 안녕하세요!"가 화면에 표시되는지 확인합니다.
- 이름을 지우고 다른 이름을 적은 뒤 다시 누르면 인사말도 그 이름으로 바뀌는지 확인합니다.
- 아무것도 적지 않고 버튼을 누르면 "이름을 먼저 입력해 주세요."라는 안내가 뜨고 커서가 입력칸으로 돌아오는지 확인합니다(이건 `script.js`의 빈 값 검사 부분이 담당합니다).
- 입력칸에 글자를 적은 상태에서 엔터키를 눌러도 버튼을 누른 것처럼 인사말이 나오는지 확인합니다.
- 만약 인사말이 안 나온다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html` 안에 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지 확인하세요.

## 핵심 개념

- `input.value` : 자바스크립트로 입력칸에 적힌 글자를 읽어옵니다. 이 페이지의 가장 중요한 부분입니다.
- 문자열 결합(`+`) : `이름 + "님, 안녕하세요!"`처럼 글자와 글자(또는 변수)를 더하기 기호로 이어 붙여 한 문장을 만듭니다.
- `element.textContent` : 만든 문장을 화면의 특정 요소 안에 글자로 넣어 보여줍니다.
- `.trim()` : 실수로 입력값 앞뒤에 들어간 빈 칸(스페이스)을 지워, 빈 값인지 정확히 판단하게 해줍니다.
