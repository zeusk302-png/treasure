# 용어 사전(설명 목록) 만들기

"용어 + 그 용어의 설명"이 짝지어진 사전형 목록을 `<dl>` / `<dt>` / `<dd>` 태그로 만들어 봅니다. 일반 목록(`<ul>`, `<ol>`)이 단순히 항목을 나열한다면, 설명 목록은 "이건 무엇이다"라는 **용어-설명 쌍**을 표현할 때 쓰는 전용 구조입니다. 용어 사전, FAQ, 항목 설명에 잘 어울립니다.

## 목표

- `<dl>` 로 설명 목록 전체를 감싼다. (dl = Description List, 설명 목록)
- `<dt>` 에 설명할 **용어(제목)** 를 적는다. (dt = Description Term)
- `<dd>` 에 그 용어의 **설명(내용)** 을 적는다. (dd = Description Details)
- 용어 하나에 설명을 여러 개(`<dd>` 여러 개) 붙일 수도 있음을 안다.

> 비전공자 눈높이 한 줄 요약: `<dl>` 이라는 "바구니" 안에, `<dt>`("단어") 한 줄과 `<dd>`("그 단어 뜻") 한 줄을 짝지어 넣으면, 브라우저가 자동으로 사전처럼 단어는 왼쪽에, 뜻은 한 칸 들여써서 보여줍니다.

## 따라하는 단계

1. `examples/011/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<dl> ... </dl>` 부분을 찾습니다. 이게 설명 목록(용어 사전) 전체를 감싸는 바구니입니다.
3. 바구니 안을 보면 `<dt>HTML</dt>` (용어) 한 줄 바로 아래에 `<dd>...</dd>` (설명) 한 줄이 있습니다. 이 **용어+설명 한 짝**이 반복되는 구조입니다.
4. `<dt>` 와 `<dd>` 사이에는 다른 내용을 넣지 않습니다. 항상 "용어 → 설명" 순서로 짝지어 적으세요.
5. 나만의 용어를 추가해 봅니다. 마지막 `</dl>` 바로 위에 아래처럼 한 짝을 더 적어 보세요.
   ```html
   <dt>서버(Server)</dt>
   <dd>요청을 받아 자료를 보내주는 컴퓨터입니다.</dd>
   ```
6. 두 번째 `<dl>` 의 "태그(Tag)" 예시처럼, 하나의 `<dt>` 아래에 `<dd>` 를 여러 개 적으면 설명이 여러 줄로 들여써집니다. 직접 `<dd>` 한 줄을 더 추가해 보세요.
7. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의 1: `<dt>` 와 `<dd>` 는 반드시 `<dl>` 안에 들어가야 합니다. `<dl>` 밖에 단독으로 쓰면 안 됩니다.
> 주의 2: 세 태그 모두 여는 태그와 닫는 태그가 짝을 이룹니다. (예: `<dt>...</dt>`) 닫는 태그(`</dt>`, `</dd>`, `</dl>`)를 빠뜨리지 않도록 주의하세요.
> 주의 3: `<dt>` 와 `<dd>` 를 헷갈리기 쉽습니다. **t**erm(용어)은 `<dt>`, **d**etails(설명)는 `<dd>` 로 기억하세요.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 코드를 직접 다 외우지 말고, AI에게 "이렇게 만들어줘"라고 시킨 뒤 결과가 맞는지 판별하는 연습을 해 보세요.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML을 가르치는 강사야. 비전공 초보가 따라할 "용어 사전" 한 페이지를 만들어줘.
  - 한 개의 HTML 파일(index.html) 안에 완성된 형태로 줘.
  - 문서 언어는 한국어(<html lang="ko">), 글자 깨짐 방지를 위해 <meta charset="UTF-8">를 넣어줘.
  - 본문에는 <dl> / <dt> / <dd> 태그만 써서 "용어-설명" 짝으로 된 설명 목록을 만들어줘.
  - 용어 4개: HTML, CSS, 자바스크립트, 브라우저. 각 용어마다 한 줄 쉬운 설명을 붙여줘.
  - dt(용어)는 왼쪽, dd(설명)는 들여써지는 사전 기본 모양 그대로 둬(별도 CSS 없이).
  제약: <ul>/<ol>/<table>은 쓰지 말고 반드시 <dl> 구조로만 만들어줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 용어 사전에 이어서 다음을 추가해줘.
  - 두 번째 <dl> 을 만들고, 하나의 <dt>("태그(Tag)") 아래에 <dd> 를 2개 붙여서
    "한 용어에 설명이 여러 개일 수도 있다"는 걸 보여줘.
  - 내가 직접 추가할 수 있게 "서버(Server)" 같은 용어 1개를 예시로 더 넣어줘.
  - 각 줄이 무슨 역할인지(왜 <dl>로 감쌌는지, dt와 dd의 차이) 코드 옆에 한국어 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  설명 목록을 만들었는데 용어 설명이 들여써지지 않고 전부 왼쪽에 붙어서 나와.
  아래 내 코드를 붙여넣을게. 무엇이 잘못됐는지 한 가지씩 짚어주고,
  특히 닫는 태그(</dt> </dd> </dl>)가 빠졌는지, <dt>/<dd>가 <dl> 밖에 있는지 확인해줘.
  고친 코드와 "왜 그게 문제였는지"를 비전공자도 이해하게 설명해줘.
  [여기에 내 HTML 코드 붙여넣기]
  ```
> 프롬프트 팁: 끝에 "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 첫 번째 목록에서 "HTML / CSS / 자바스크립트 / 브라우저" **용어가 왼쪽 끝에 굵게(또는 기본 글씨로)** 표시되고, 그 **설명이 한 칸 안쪽으로 들여써져** 있는지 확인합니다. → 이게 설명 목록의 기본 모양입니다.
3. 용어와 설명이 **1:1로 짝**지어져 보이는지 확인합니다. (용어 바로 아래에 그 용어의 설명이 옵니다.)
4. 두 번째 목록 "태그(Tag)"에서, **하나의 용어 아래에 설명 줄이 2개** 들여써져 있는지 확인합니다. → `<dd>` 를 여러 개 쓰면 이렇게 됩니다.
5. 단계 5에서 직접 추가한 "서버(Server)" 용어와 설명이 사전 형태로 새로 나타나는지 새로고침(F5) 후 확인합니다.
6. (확인 팁) 만약 설명이 들여써지지 않고 모두 왼쪽에 붙어 보인다면, `<dl>` 로 감싸지 않았거나 `<dt>`/`<dd>` 의 닫는 태그가 빠졌을 가능성이 높습니다. 태그 짝을 다시 확인하세요.
