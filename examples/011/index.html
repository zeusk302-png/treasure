나만의 웹 용어 사전

아래는 <dl> 태그로 만든 "설명 목록(용어 사전)"입니다. 용어 하나에 설명 하나가 짝지어진 형태예요.

HTML
웹페이지의 "뼈대"를 만드는 언어입니다. 제목, 글, 사진, 링크처럼 "무엇이 있는지"를 적습니다.
CSS
웹페이지의 "꾸미기"를 담당합니다. 글자 색, 크기, 배치, 여백처럼 "어떻게 보일지"를 정합니다.
자바스크립트(JavaScript)
웹페이지를 "움직이게" 만드는 언어입니다. 버튼을 누르면 반응하는 것 같은 동작을 담당합니다.
브라우저(Browser)
웹페이지를 열어서 보여주는 프로그램입니다. 크롬, 엣지, 사파리 등이 있습니다.

한 용어에 설명이 여러 개일 수도 있어요

하나의 용어(<dt>) 아래에 설명(<dd>)을 여러 개 적을 수도 있습니다. 아래 "태그"가 그 예입니다.

태그(Tag)
HTML에서 명령을 적는 단위입니다. 보통 여는 것과 닫는 것이 짝을 이룹니다.
예: <p>안녕하세요</p> 처럼 <p> 로 열고 </p> 로 닫습니다.
