# 실습 271 — AI 챗봇: 받은 답을 말풍선 UI로 보여주기

> **아키타입 미니프로젝트 (난이도 4)** · 분류: 아키타입 미니프로젝트 · 개념: fetch 비동기, 채팅 UI

질문을 입력하면 **내 말풍선(오른쪽 파란색)** 과 **AI 말풍선(왼쪽 회색)** 이 차례로 쌓이는, 카카오톡처럼 생긴 채팅 화면을 만듭니다.
이 폴더의 `index.html` 은 **인터넷 연결이나 API 키 없이도 바로 동작**합니다(연습용 가짜 답변). 흐름을 익힌 뒤, 마지막 단계에서 진짜 AI를 붙이는 법까지 안내합니다.

## 목표
- **비동기(async/await)** 가 무엇인지 체감한다: "보내기 → 잠깐 기다림(입력 중…) → 답 도착" 의 시간 흐름을 직접 만든다.
- **채팅 UI** 의 기본기를 익힌다: 말풍선을 화면에 하나씩 추가하고(`createElement` + `appendChild`), 새 말풍선이 생기면 **자동으로 맨 아래로 스크롤**한다.
- 폼 제출(`submit`)로 **Enter 키와 보내기 버튼**을 동시에 처리한다.
- (보안) 진짜 AI를 붙일 때 **API 키는 브라우저 코드에 절대 넣지 않는다**는 원칙을 이해한다.

### 비유로 이해하기
- **말풍선**은 게시판에 붙이는 **포스트잇**입니다. 내가 말하면 오른쪽에, AI가 답하면 왼쪽에 새 포스트잇을 붙입니다.
- **`await`(기다리기)** 는 친구에게 카톡을 보내고 **답장이 올 때까지 기다리는 것**과 같습니다. 기다리는 동안 화면이 멈추지 않도록 "입력 중…" 점 3개를 보여 줍니다.

## 따라하는 단계
1. 이 폴더의 `index.html` 을 **더블클릭**해서 브라우저로 엽니다. (서버 설치 필요 없음)
2. 아래 입력칸에 `안녕` 이라고 치고 **보내기**(또는 **Enter**)를 누릅니다. → 오른쪽 파란 말풍선으로 내 말이 뜨고, 잠깐 점 3개가 깜빡인 뒤 왼쪽 회색 말풍선으로 답이 나타납니다.
3. `이름`, `날씨`, `고마워` 등도 보내 보며 답이 어떻게 달라지는지 확인합니다. (`index.html` 의 `askAI` 함수 안 규칙을 바꾸면 답도 바뀝니다.)
4. 코드에서 **말풍선을 만드는 부분**(`addBubble` 함수)과 **답을 기다리는 부분**(`await askAI(...)`)을 찾아 읽어 봅니다. 주석이 한 줄씩 설명해 줍니다.
5. (선택) `askAI` 함수 안 가짜 답변 문구를 내 마음대로 바꿔 저장하고 **새로고침(F5)** 해서 반영되는지 확인합니다.
6. (도전) 진짜 AI 붙이기 — `index.html` 맨 아래 **[실제 API 붙이기]** 주석을 따라 합니다.
   - 핵심: 브라우저는 **중간 서버(n8n 웹훅 또는 Supabase Edge Function)** 의 주소(`REPLACE_WITH_YOUR_WEBHOOK_URL`)로만 요청을 보냅니다.
   - **진짜 API 키(`YOUR_API_KEY`)는 그 중간 서버 안에만** 두고, HTML에는 절대 적지 않습니다.

## 검증법
- 메시지를 보내면 **내 말풍선은 오른쪽 파란색**, **AI 말풍선은 왼쪽 회색**으로 좌우가 구분되는가?
- 보낸 직후 **점 3개("입력 중…")** 가 잠깐 보였다가, 답이 오면 그 자리가 진짜 답풍선으로 바뀌는가? (`typing.remove()` 가 동작하는지 확인)
- 말풍선이 화면을 넘칠 만큼 쌓였을 때 **항상 맨 아래(최신 메시지)가 보이도록 자동 스크롤**되는가?
- **빈 칸으로 보내기**를 누르면 아무 일도 일어나지 않는가? (`if (!text) return;` 가드)
- 답을 기다리는 동안 **보내기 버튼이 잠겼다가**(`disabled`), 답이 오면 다시 풀리는가?
- (보너스) `F12 → Elements` 에서 메시지를 보낼 때마다 `#messages` 안에 `<div class="bubble me">` / `<div class="bubble ai">` 가 하나씩 추가되는지 확인합니다.
- (보안 점검) `index.html` 안에 진짜 키 형태의 문자열(예: `sk-...`)이 들어 있지 않은지 확인합니다. 자리표시자(`YOUR_API_KEY`, `REPLACE_WITH_...`)만 있어야 정상입니다.

## 관련 가이드
- 첫 이벤트 다루기 → 실습 056 "버튼 누르면 알림창 띄우기"
- 화면에 요소를 추가/삭제하기 → 실습 082 "할 일 목록 만들기 — 추가와 삭제" (`createElement`/`appendChild` 패턴)
- 시간차 동작 만들기 → 실습 072 "토스트 알림 만들기 (3초 후 자동 사라짐)" (`setTimeout`)
- 비동기 요청(fetch)의 기초 → 실습 162~164 "공개 API에서 데이터 받아 화면에 그리기"
- API 키를 안전하게 숨기는 법(중간 서버) → 실습 260 "RLS 게시판"의 `anon(공개) vs service_role(비밀)` 설명, 그리고 n8n 웹훅 자동화 시리즈
