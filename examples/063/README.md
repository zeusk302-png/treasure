# 실시간 글자 수 카운터 만들기

자기소개 같은 짧은 글을 적는 입력칸(textarea)을 두고, 글자를 칠 때마다 바로 아래에 `23/100` 처럼 현재 글자 수가 즉시 갱신되는 작은 페이지입니다. 자바스크립트의 `input` 이벤트와 문자열의 `.length`(글자 수)를 이용해 "타이핑하는 순간 화면이 반응하는" 실시간 동작을 익힙니다.

## 목표

- `input` 이벤트가 글자를 한 자 칠 때마다, 지울 때마다, 붙여넣을 때마다 즉시 발생한다는 것을 이해합니다. (버튼의 `click`은 한 번 눌러야 하지만, `input`은 내용이 바뀔 때마다 계속 실행됩니다.)
- 입력칸에 들어 있는 글자 전체는 `입력칸.value`로 읽고, 그 글자 수는 `.length`로 센다는 것을 익힙니다.
- 센 숫자를 `textContent`로 화면의 숫자 자리에 즉시 써넣어 실시간으로 갱신하는 흐름을 익힙니다.

## 따라하는 단계

1. 이 폴더(`063`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. "소개 문구" 입력칸과 그 아래 `0/100` 표시가 보이는지 확인합니다. 처음에는 입력칸이 비어 있으니 `0/100`입니다.
3. `index.html`을 살펴봅니다. 글을 적는 칸에는 `id="message"`, 현재 글자 수가 표시될 자리(`<span>`)에는 `id="count"`가 붙어 있습니다. 자바스크립트는 이 id로 두 요소를 찾아냅니다. 또 `textarea`에는 `maxlength="100"`이 있어 100자를 넘으면 브라우저가 더 입력되지 않게 막아 줍니다.
4. `script.js`를 엽니다. 동작은 간단합니다.
   - `document.getElementById(...)`로 입력칸(`message`)과 숫자 자리(`count`)를 찾습니다.
   - 입력칸에 `addEventListener("input", ...)`로 "내용이 바뀔 때마다 실행할 동작"을 연결합니다.
   - 동작 안에서 `message.value.length`로 지금 글자 수를 세고, `count.textContent = length`로 화면 숫자를 바꿉니다.
5. 브라우저로 돌아가 입력칸에 글자를 한 자씩 쳐 봅니다. 칠 때마다 아래 숫자가 `1`, `2`, `3` … 으로 즉시 올라가고, 지우면 다시 내려가면 성공입니다.

## 검증법

- 입력칸에 글자를 칠 때마다 `0/100`의 앞 숫자가 글자 수와 똑같이 즉시 바뀌면 정상입니다. (한글, 영어, 띄어쓰기 모두 1글자로 셉니다.)
- 글자를 지우면(백스페이스) 숫자가 바로 줄어드는지 확인합니다.
- 다른 곳에서 복사한 글을 붙여넣어도 숫자가 한 번에 정확히 맞춰지는지 확인합니다. (`input` 이벤트는 붙여넣기에도 반응합니다.)
- 100자를 채우면 더 이상 입력되지 않고(=`maxlength`가 막아 줌), 숫자가 빨간색으로 바뀌는지 확인합니다(이건 `script.js`가 `.full` 클래스를 붙여 주는 부분입니다).
- 만약 숫자가 바뀌지 않는다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html` 안에 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지 확인하세요.

## 핵심 개념

- `input` 이벤트 : 입력칸의 내용이 바뀔 때마다(타이핑·삭제·붙여넣기) 즉시 발생하는 이벤트. 실시간 반응의 핵심입니다.
- `입력칸.value` : 입력칸에 현재 들어 있는 글자 전체(문자열).
- `.length` : 문자열의 글자 수. `"안녕".length`는 `2`입니다.
- `textContent` : 화면 요소 안에 보이는 글자를 바꾸는 방법. 여기서는 센 숫자를 화면에 써넣을 때 씁니다.
