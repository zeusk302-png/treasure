# 166 — GitHub 계정 만들고 첫 저장소(repository) 만들기

GitHub에 가입하고, 내 이름으로 된 **빈 저장소(repository)** 하나를 만들어 보는 실습입니다.
코드를 한 줄도 짜지 않습니다. "코드를 보관하는 인터넷 창고"가 무엇인지, 직접 만들어 보며 감을 잡는 것이 전부입니다.

- 카테고리: 배포·운영·도구 (코드 H)
- 난이도: 1 / 5
- 개념: GitHub 계정, 저장소(repo)
- 결과물: 내 이름의 빈 GitHub 저장소 1개 (주소 URL)

---

## 목표

웹 개발을 하다 보면 곧 듣게 되는 말이 "그거 깃허브에 올려놔" 입니다.
**GitHub(깃허브)** 는 내가 만든 코드 파일을 인터넷에 보관하고, 다른 사람과 나누고, 나중에 자동으로 배포까지 연결하는 **"코드 창고(클라우드 드라이브)"** 입니다.

이번 실습에서 만드는 것은 이 창고 안의 **방 한 칸**입니다. 이 방 한 칸을 **저장소(repository, 줄여서 repo)** 라고 부릅니다.

- **계정(account)**: 깃허브에 들어가는 내 아이디. (예: `github.com/내아이디`)
- **저장소(repository)**: 프로젝트 하나당 하나씩 만드는 폴더 같은 공간. 보통 "프로젝트 = 저장소 하나"라고 생각하면 됩니다.

용어가 헷갈려도 괜찮습니다. 이번에는 "**가입하고 → 빈 방 하나 만들고 → 그 방의 주소(URL)를 손에 넣는다**" 딱 이 세 가지만 해내면 성공입니다.

> 비유: 깃허브는 큰 사물함 건물(=계정), 저장소는 그 안의 내 사물함 한 칸(=repo)입니다.
> 이번 실습은 사물함을 하나 빌리고, 그 사물함 번호(주소)를 적어 두는 것까지입니다. 물건(코드)은 다음 실습(167번)에서 넣습니다.

---

## 따라하는 단계

### 1단계 — GitHub 가입하기

1. 브라우저에서 **https://github.com** 에 접속합니다.
2. 오른쪽 위 **Sign up**(가입) 버튼을 누릅니다.
3. 화면이 시키는 대로 입력합니다.
   - **Email**: 평소 쓰는 이메일 (예: `zeusk302@gmail.com`)
   - **Password**: 비밀번호 (남에게 보여 주지 마세요)
   - **Username**: 영문 아이디. 이 아이디가 곧 내 주소가 됩니다. (예: `seyoung-kim` → 주소는 `github.com/seyoung-kim`)
     - 한글은 안 됩니다. 영문 소문자/숫자/하이픈(`-`)만 쓸 수 있고, 나중에 바꾸기 번거로우니 신중하게 정합니다.
4. "사람인지 확인" 퍼즐을 풀고, 이메일로 온 **인증 코드(숫자)** 를 입력합니다.
5. 요금제를 묻는 화면이 나오면 **Free(무료)** 를 고릅니다. 이 실습은 전부 무료로 됩니다.

> 이미 깃허브 계정이 있다면 이 1단계는 건너뛰고 **로그인**만 한 뒤 2단계로 갑니다.

### 2단계 — 빈 저장소 만들기

1. 로그인한 상태에서 화면 오른쪽 위 **`+`** 아이콘을 누르고 **New repository**(새 저장소)를 선택합니다.
   - (또는 주소창에 **https://github.com/new** 를 직접 입력해도 같은 화면이 나옵니다.)
2. **Repository name**(저장소 이름)에 이름을 적습니다.
   - 예: `my-first-website` 또는 `hello-github`
   - 띄어쓰기 대신 하이픈(`-`)을 씁니다. 한글보다 영문이 편합니다.
3. **Description**(설명, 선택사항)에 한 줄 메모를 적습니다. 예: `깃허브 연습용 첫 저장소`
4. 공개 범위를 고릅니다.
   - **Public(공개)**: 누구나 코드를 볼 수 있음. 연습/포트폴리오용으로 무난합니다. → **이번엔 Public 권장**
   - **Private(비공개)**: 나와 내가 초대한 사람만 볼 수 있음.
   - (참고: 공개 저장소라도 **비밀번호·API 키 같은 비밀값은 절대 올리지 않습니다.** 코드만 올립니다.)
5. **"Add a README file"**(README 파일 추가)에 체크합니다.
   - 이걸 체크하면 저장소가 텅 비지 않고, 설명서 파일 한 장과 함께 만들어져서 화면이 한결 보기 편합니다.
   - 무엇을 적으면 좋을지는 이 폴더의 **`README-템플릿.md`** 를 그대로 복사해 쓰면 됩니다.
6. 맨 아래 초록색 **Create repository**(저장소 만들기) 버튼을 누릅니다.

### 3단계 — 내 저장소 주소(URL) 확인하고 적어 두기

1. 저장소가 만들어지면 곧바로 그 저장소 화면으로 이동합니다.
2. 주소창의 주소가 바로 이번 실습의 **결과물**입니다. 형태는 다음과 같습니다.
   ```
   https://github.com/내아이디/저장소이름
   예) https://github.com/seyoung-kim/my-first-website
   ```
3. 이 주소를 복사해 메모장이나 강의 제출 칸에 붙여 둡니다. **이 주소 하나가 이번 실습의 완성품**입니다.

## 검증법

아래 4가지가 모두 맞으면 성공입니다.

- **로그인 확인**: 오른쪽 위에 내 아이디 또는 프로필 아이콘이 보인다 → 가입·로그인 성공.
- **주소 접속 확인**: `https://github.com/내아이디/저장소이름` 주소를 새 탭에 붙여 넣으면 저장소 화면이 열린다.
- **README 보임 확인**: 저장소 화면 아래쪽에 README 내용(설명 글)이 보인다. (5단계에서 체크했다면)
- **빈 저장소 확인**: 아직 코드 파일은 없고 `README.md` 한 개 정도만 있다 → "빈 저장소"가 맞습니다.
  코드 파일을 올리는 것은 다음 실습(167번)에서 합니다.

> 흔한 실수
> - **Username과 Repository를 헷갈림**: 주소는 `github.com/아이디/저장소이름` 순서입니다. 둘 다 들어가야 정상입니다.
> - **이메일 인증을 건너뜀**: 인증을 안 하면 저장소를 못 만들 수 있습니다. 받은 메일의 인증 코드를 꼭 입력하세요.
> - **한글 이름 사용**: 저장소 이름에 한글·공백을 쓰면 나중에 주소가 깨져 보입니다. 영문+하이픈을 권장합니다.
