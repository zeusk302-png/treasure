# 실습 089 — 드롭다운(select)으로 지역 선택 메뉴 만들기

보기가 많을 때(예: 시·도 17개)는 동그라미(라디오 버튼)를 줄줄이 늘어놓으면 화면이 길어지고 답답합니다. 이럴 때 쓰는 것이 **드롭다운(select)** 입니다. 평소엔 한 줄만 보이다가, 누르면 보기 목록이 아래로 펼쳐지는 입력칸이에요.

드롭다운은 두 개의 태그로 만듭니다. 바깥 상자인 **`<select>`** 안에, 보기 하나하나를 **`<option>`** 으로 넣습니다. 그리고 특정 `<option>` 에 **`selected`** 를 붙이면 페이지를 열자마자 그 항목이 **미리 골라진 상태**로 시작합니다.

코드는 단 한 파일(`index.html`)이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭으로 바로 열 수 있어요. (맨 아래 작은 JavaScript는 '내가 고른 값'을 화면에 보여주기 위한 보조 장치일 뿐이고, 드롭다운 자체는 HTML만으로 잘 작동합니다.)

> **핵심 한 줄:** `<select>` 는 상자, `<option>` 은 그 안의 보기 한 개입니다. `<option>` 에 `selected` 를 붙이면 **처음부터 그 항목이 골라진** 상태로 시작합니다.

`<option>` 에는 두 가지 글자가 있다는 점을 꼭 기억하세요.

| 위치 | 예시 | 역할 |
|---|---|---|
| `value="부산"` | `value` 속성 | **실제로 전달/처리되는 값** (코드가 읽는 값) |
| `>부산광역시<` | 태그 사이 글자 | **사람 눈에 보이는 글자** (화면 표시용) |

이 둘을 다르게 적을 수 있어서, 화면에는 "부산광역시"라고 길게 보여 주고 처리할 때는 짧은 `"부산"` 값을 쓰는 식의 정리가 가능합니다.

## 목표
- `<select>`(드롭다운 상자)와 `<option>`(보기 한 개)으로 목록형 입력칸을 만들 수 있다.
- `<option>` 에 `selected` 를 붙여 **기본 선택값**을 지정하는 법을 익힌다.
- 맨 위에 `disabled selected` 인 빈 `<option>` 을 두어 **"-- 선택하세요 --" 안내문**을 만드는 흔한 패턴을 안다.
- `option` 의 `value`(처리용 값)와 화면에 보이는 글자가 **서로 다를 수 있다**는 것을 이해한다.

## 따라하는 단계
1. 이 폴더의 `index.html` 을 **더블클릭**합니다. → 기본 브라우저에서 드롭다운 두 개가 있는 페이지가 열립니다.
2. 첫 번째 드롭다운(**거주 지역**)을 눌러 봅니다. → 시·도 목록이 아래로 펼쳐지는지, 맨 위에 "-- 지역을 선택하세요 --" 안내문이 보이는지 확인합니다. (이 안내문은 회색이고 **고를 수 없게** 되어 있어요.)
3. 목록에서 "부산광역시"를 골라 봅니다. → 펼쳐졌던 목록이 닫히고, 한 줄에 "부산광역시"만 남는지 확인합니다.
4. 두 번째 드롭다운(**가장 좋아하는 여행지**)을 봅니다. → 아직 한 번도 안 눌렀는데도 처음부터 **"부산"** 이 골라져 있나요? 이게 `<option value="부산" selected>` 의 효과입니다. (=기본 선택값)
5. **[선택 확인]** 버튼을 누릅니다. → 아래에 초록색 박스가 나타나며 "1. 거주 지역", "2. 좋아하는 여행지"에 방금 고른 값이 보이는지 확인합니다.
6. 안내문 패턴 체험하기: 1번 드롭다운을 건드리지 않은 채(=안내문 그대로) 바로 **[선택 확인]** 을 눌러 봅니다. → "거주 지역"이 "(아직 선택 안 함)"으로 표시되는지 확인합니다. 안내문 `option` 의 `value=""`(빈 값) 때문이에요.
7. 기본값 직접 바꿔 보기: `index.html` 을 메모장(또는 VS Code)으로 열어, 두 번째 드롭다운의 `selected` 를 `<option value="부산" selected>` 에서 떼어 `<option value="제주" selected>` 로 옮겨 저장하고 **새로고침(F5)** 합니다. → 이제 처음부터 "제주"가 골라져 있는지 확인합니다.
8. AI에게 시켜 보기:
   > "이 index.html에 세 번째 드롭다운을 추가해줘. 라벨은 '문의 유형'이고, `<select>`와 `<option>`으로 '서비스 문의 / 결제 문의 / 기타' 중 하나를 고르게 해줘. 맨 위에는 `disabled selected`인 '-- 유형을 선택하세요 --' 안내문 option을 넣고, 기존처럼 `<label>`의 `for`와 `<select>`의 `id`를 같은 이름으로 맞춰줘."

## 검증법
- 드롭다운을 누르면 보기 목록이 펼쳐지고, 하나를 고르면 그 글자만 한 줄로 남는가?
- 첫 번째 드롭다운 맨 위 "-- 지역을 선택하세요 --"는 **고를 수 없는** 회색 안내문으로 보이는가? (`disabled selected`의 효과)
- 두 번째 드롭다운은 페이지를 열자마자 **"부산"** 이 골라진 상태인가? (`selected`로 정한 기본 선택값)
- **[선택 확인]** 을 누르면 결과 박스에 두 드롭다운의 **현재 고른 값**이 정확히 표시되는가?
- 브라우저에서 `F12 → Elements` 탭을 열어, 두 번째 드롭다운의 `부산` option에 `selected` 가 붙어 있는지 눈으로 확인한다. (이게 "기본 선택값을 selected로 정한다"는 증거입니다.)
