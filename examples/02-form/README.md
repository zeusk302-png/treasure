# 실습 02 — 문의 폼 (저장 없음)

이름·연락처·내용을 받는 폼. 아직 **서버가 없어 저장은 안 되고**, 보내면 "접수되었습니다" 알림만 뜹니다. (진짜 저장은 실습 03)

## 목표
- `<form>`과 입력칸(`<input>`, `<textarea>`)의 기본을 안다.
- 자바스크립트가 "보내기" 순간에 끼어들어 무언가를 한다는 감을 잡는다.
- **새로고침이 일어나지 않는 이유** = `e.preventDefault()`.

## 따라하는 단계
1. `index.html`을 브라우저로 연다.
2. 빈칸으로 제출 → `required` 덕분에 브라우저가 막는다(확인).
3. 다 채우고 제출 → "접수되었습니다" 메시지가 뜬다.
4. AI에게 시켜 보기:
   > "이 폼에 이메일 입력칸을 추가하고, 이메일 형식이 아니면 제출이 안 되게 해줘."

## 검증법
- 제출해도 페이지가 새로고침되지 않는가? (그대로 머무르면 성공)
- 제출 후 입력칸이 비워지는가?

!!! warning "주의"
    이 폼은 입력을 **어디에도 저장하지 않습니다.** 새로고침하면 사라집니다. 데이터를 진짜로 쌓으려면 데이터베이스가 필요 → 실습 03.
