# 실습 02 — 문의 폼 (저장 없음)

이름·연락처·내용을 받는 폼. 아직 **서버가 없어 저장은 안 되고**, 보내면 "접수되었습니다" 알림만 뜹니다. (진짜 저장은 실습 03)

## 목표
- `<form>`과 입력칸(`<input>`, `<textarea>`)의 기본을 안다.
- 자바스크립트가 "보내기" 순간에 끼어들어 무언가를 한다는 감을 잡는다.
- **새로고침이 일어나지 않는 이유** = `e.preventDefault()`.

## 따라하는 단계
1. `index.html`을 브라우저로 연다.
2. 빈칸으로 제출 → `required` 덕분에 브라우저가 막는다(확인).
3. 다 채우고 제출 → "접수되었습니다" 메시지가 뜬다.
4. AI에게 시켜 보기:
   > "이 폼에 이메일 입력칸을 추가하고, 이메일 형식이 아니면 제출이 안 되게 해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 가르치는 멘토야. 비전공자가 따라할 수 있는 "문의 폼" 한 페이지를
  index.html 파일 하나로 만들어줘.
  - 입력칸: 이름(text), 연락처(tel), 문의 내용(textarea) 세 개
  - 세 칸 모두 required(필수)로 빈칸이면 제출이 막히게
  - 보내기 버튼 하나, 모바일에서도 보기 좋게 max-width와 viewport 설정
  - 아직 서버는 없으니 저장 기능은 넣지 말고 폼 화면만
  - 코드만 주지 말고 각 줄이 왜 필요한지 한국어 주석으로 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 폼에 자바스크립트를 추가해줘.
  - 보내기를 눌러도 페이지가 새로고침되지 않게 e.preventDefault()를 써줘
  - 제출되면 "접수되었습니다" 메시지를 화면에 보여주고 입력칸을 비워줘(reset)
  - 이메일 입력칸을 하나 더 추가하고, 이메일 형식이 아니면 제출이 안 되게 해줘
  - 왜 preventDefault가 필요한지, 안 쓰면 어떻게 되는지 주석으로 풀어서 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  보내기를 눌렀더니 "접수되었습니다"가 안 뜨고 페이지가 새로고침돼.
  아래는 내 index.html 전체 코드야. (코드 붙여넣기)
  무엇이 문제인지 한 단계씩 짚어주고, 비전공자도 알아듣게 고친 부분을 설명해줘.
  특히 getElementById의 id 철자, addEventListener 위치, preventDefault 누락을 확인해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- 제출해도 페이지가 새로고침되지 않는가? (그대로 머무르면 성공)
- 제출 후 입력칸이 비워지는가?

!!! warning "주의"
    이 폼은 입력을 **어디에도 저장하지 않습니다.** 새로고침하면 사라집니다. 데이터를 진짜로 쌓으려면 데이터베이스가 필요 → 실습 03.
