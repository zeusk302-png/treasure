키 줍기 게임

이 페이지는 배포된 척하는 연습용 사이트입니다. 화면을 아무리 봐도 키는 안 보입니다. 하지만 브라우저는 키를 이미 다 받아서 가지고 있어요. 개발자도구(F12)를 열어 숨어 있는 두 개의 키를 직접 찾아보세요.

🟢 보여도 괜찮은 키 (공개 출입증)

이 페이지는 아래 publishable(anon) 키로 동작합니다. 이건 화면/코드에 보여도 안전해요.

F12에서 sb_publishable_ 로 시작하는 문자열을 찾으면 됩니다.

🔴 절대 보이면 안 되는 키 (마스터키)

이 사이트에는 누군가 실수로 비밀키(service_role / sb_secret_)를 프론트 코드에 박아두는 잘못을 저질렀습니다. F12로 그걸 찾아내는 게 이 게임의 핵심입니다.

F12에서 sb_secret_ 로 시작하는 문자열을 찾으면 됩니다. (이게 보이면 사고!)

게임 방법

  1. F12를 눌러 개발자도구를 엽니다.
  2. Sources(소스) 탭에서 이 페이지의 코드를 열어 두 키를 눈으로 찾습니다.
  3. Network(네트워크) 탭을 켠 채 F5로 새로고침하면, 키가 통신에 실려 가는 것도 볼 수 있습니다.
  4. 찾은 두 값을 note.md에 "보여도 OK / 절대 안 됨"으로 분류해 적습니다.
