실습 113 · 데이터의 한계 체험

내 브라우저에만 저장되는 "할 일" 메모

이 페이지는 할 일을 localStorage(내 브라우저 안 작은 저장소)에만 저장합니다. 일부러 서버에 보내지 않습니다. 그래서 "다른 곳에서는 안 보이는" 한계를 직접 눈으로 확인할 수 있어요.

1) 할 일 적기

    2) 직접 해 보는 한계 실험

    아래 순서대로 해 보면 "내 브라우저에만 갇혀 있다"는 걸 몸으로 알게 됩니다.

    1. 위에서 할 일을 2~3개 추가한다.
    2. 시크릿(비공개) 창을 새로 연다. (크롬: Ctrl+Shift+N / 엣지: Ctrl+Shift+P) → 거기서 이 index.html을 열면 목록이 텅 비어 있다.
    3. 다른 브라우저(크롬에서 했다면 엣지/사파리 등)로 같은 파일을 연다. → 역시 아무것도 없다.
    4. 가능하면 휴대폰으로 같은 사이트를 본다. → PC에서 적은 할 일이 전혀 안 보인다.

    왜 이럴까요? localStorage는 "그 브라우저 안"에만 저장됩니다. 창이 다르거나 기기가 다르면 서로 다른 저장소라서 공유가 안 돼요. 여러 사람이나 여러 기기가 같은 데이터를 보려면 중앙 서버 데이터베이스(DB)가 필요합니다.

    한계를 확인했다면, 같은 폴더의 prompt.md를 열어 Claude에게 "왜 서버 DB가 필요한지" 설명받고 1쪽 메모로 정리해 보세요.
