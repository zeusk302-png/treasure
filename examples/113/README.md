# 실습 113 — localStorage의 한계 체험과 Supabase로 넘어갈 이유 정리하기

지금까지 만든 "할 일/메모" 앱은 데이터를 **localStorage**(내 브라우저 안 작은 저장소)에 저장했습니다.
이번 실습은 새 기능을 만드는 게 아니라, 그 저장 방식이 **어디까지만 통하는지** 한계를 직접 눈으로 확인하고,
"여러 사람·여러 기기가 같이 보려면 **서버 데이터베이스(DB)** 가 필요하다"는 결론을 **내 말로 1쪽 메모**로 정리하는 것이 목표입니다.

이 폴더에는 세 개의 파일이 있습니다.

- `index.html` — 할 일을 localStorage에만 저장하는 **한계 실험용 페이지** (브라우저로 바로 열기)
- `prompt.md` — Claude에게 "왜 서버 DB가 필요한지" 설명받는 **학습 프롬프트 템플릿**
- `README.md` — 이 안내문 + 아래의 **한계 비교 실험 메모** 양식

## 목표

- localStorage에 저장한 데이터는 **"그 브라우저 안"에만** 갇혀 있다는 사실을 직접 확인한다.
- 같은 데이터가 **시크릿 창 / 다른 브라우저 / 다른 기기**에서는 안 보이는 것을 눈으로 본다.
- 그 경험을 바탕으로 **"여러 사람·여러 기기가 공유하려면 서버 DB가 필요하다"** 를 스스로 설명할 수 있다.
- 다음 단계(Supabase로 옮기기)로 넘어갈 이유를 **1쪽 메모**로 정리한다.

> 한 줄 핵심: localStorage = **내 브라우저 전용 서랍**. 서버 DB = **모두가 함께 쓰는 중앙 창고**.

## 따라하는 단계

1. 이 폴더의 `index.html`을 더블클릭해서 브라우저(크롬 등)로 연다.
2. 입력칸에 할 일을 **2~3개** 적고 [추가]를 눌러 목록에 쌓는다. (F5 새로고침해도 그대로 남아 있는지도 확인)
3. **시크릿 창**을 새로 연다. (크롬: `Ctrl`+`Shift`+`N` / 엣지: `Ctrl`+`Shift`+`P`)
   거기서 같은 `index.html`을 열어 본다 → 목록이 **텅 비어 있다.**
4. **다른 브라우저**(크롬에서 했다면 엣지나 사파리)로 같은 파일을 연다 → 역시 **아무것도 없다.**
5. (가능하면) **휴대폰**으로 같은 사이트를 열어 본다 → PC에서 적은 할 일이 **전혀 안 보인다.**
6. 같은 폴더의 `prompt.md`를 열고, **프롬프트 1**을 복사해 Claude에게 붙여 넣는다.
7. Claude의 답을 읽고, 아래 **"한계 비교 실험 메모"** 빈칸을 **내 말로** 채운다.
8. (선택) `prompt.md`의 **프롬프트 2**로 다음 실습(Supabase)에서 코드가 어떻게 바뀌는지 미리 본다.

## 검증법

- `index.html`에서 추가한 할 일이 **같은 창에서는** 새로고침해도 유지되는가?
- **시크릿 창 / 다른 브라우저 / 다른 기기**에서는 그 할 일이 **안 보이는가?** (안 보이는 게 정상)
- 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage** 에 `practice113_todos` 항목이 보이는가?
  그리고 그 값이 **다른 브라우저에는 없는가?**
- 아래 메모의 빈칸 4개를 **내 문장으로** 모두 채웠는가?

## 한계 비교 실험 메모 (여기를 채워 제출)

### 1) 무엇을 실험했나

- 저장 방식: localStorage (내 브라우저 안)
- 확인한 환경: PC 같은 창 / 시크릿 창 / 다른 브라우저 / 휴대폰

### 2) 결과 — 어디서 보였고, 어디서 안 보였나

| 환경 | 내 할 일이 보였나? |
| --- | --- |
| 같은 브라우저, 같은 창 (새로고침) | 보임 |
| 같은 PC, 시크릿 창 | (직접 적기) |
| 다른 브라우저 | (직접 적기) |
| 다른 기기(휴대폰) | (직접 적기) |

### 3) localStorage: 적합 vs 부적합

| 적합한 경우 (이럴 땐 OK) | 부적합한 경우 (이럴 땐 곤란) |
| --- | --- |
| 예: 다크모드 설정처럼 **나 혼자** 쓰는 작은 값 | 예: 여러 기기에서 **같이 봐야** 하는 데이터 |
| (직접 적기) | (직접 적기) |

### 4) 결론 — 그래서 무엇이 필요한가

> (한 문장으로) 여러 사람·여러 기기가 같은 데이터를 보려면 ______________ 가 필요하다.
> 그래서 다음 실습에서는 ______________ 를 배운다.
