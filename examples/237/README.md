# 실습 237 — 포트폴리오에 프로필 사진·기술스택 뱃지·CSS 카드 스타일 입히기

실습 236에서 만든 "글자만 있는 밋밋한 자기소개 페이지"를, 이번에는 **CSS로 꾸며서 보기 좋은 한 페이지 포트폴리오**로 완성합니다. 프로필 사진은 동그랗게, 기술 스택은 알약 모양 뱃지로, 각 영역은 그림자가 있는 흰 카드로 정돈합니다. 서버도 데이터베이스도 필요 없습니다. 파일은 `index.html`(내용)과 `style.css`(꾸미기) 둘뿐이고, `index.html`을 더블클릭하면 바로 열립니다.

핵심은 **HTML은 "무엇을 담을지(내용·구조)"만, CSS는 "어떻게 보일지(색·여백·테두리·그림자)"만** 맡는다는 역할 분리입니다.

## 목표
- **박스모델**을 눈으로 이해한다. 화면의 모든 요소는 `[내용] + padding(안쪽 여백) + border(테두리) + margin(바깥 여백)` 으로 이루어진 상자다.
- **카드 레이아웃** 공식을 익힌다. `흰 배경 + border-radius(둥근 모서리) + box-shadow(그림자)` 를 주면 화면에서 떠 있는 듯한 "카드"가 된다.
- 자주 쓰는 꾸미기 한 줄 기술 4가지를 구분한다.
  - `border-radius: 50%` → 정사각형 사진을 **완전한 원**으로
  - `border-radius: 9999px` → 작은 박스를 **알약(캡슐) 모양 뱃지**로
  - `display: flex` + `flex-wrap` + `gap` → 뱃지들을 **가로로 나열하고 자동 줄바꿈**
  - `box-sizing: border-box` → 여백을 줘도 박스가 안 커지게 만드는 안전장치

박스모델을 한 장의 그림으로 보면 이렇습니다.

```
┌─────────── margin (바깥 여백, 다른 박스와의 거리) ───────────┐
│  ┌──────── border (테두리) ────────┐                        │
│  │  ┌──── padding (안쪽 여백) ────┐ │                        │
│  │  │        [ 내용/글자 ]        │ │                        │
│  │  └────────────────────────────┘ │                        │
│  └─────────────────────────────────┘                        │
└──────────────────────────────────────────────────────────────┘
```

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**해서 브라우저로 엽니다. → 흰 카드 3장(프로필 / 기술 스택 / 연락처)이 위아래로 정돈되어 보입니다.
2. 화면에서 다음을 하나씩 확인하며 "어떤 CSS가 이걸 만들었나" 연결해 봅니다.
   - 프로필 사진이 **동그란가요?** → `style.css`의 `.avatar { border-radius: 50%; }`
   - 기술 스택이 **알약 모양 뱃지로 가로 나열**되었나요? → `.badge { border-radius: 9999px; }` 와 `.badges { display: flex; }`
   - 각 영역이 **그림자가 있는 흰 카드**로 떠 보이나요? → `.card { box-shadow: ...; border-radius: 16px; }`
3. `index.html`을 메모장(또는 VS Code)으로 열어 `<h1 class="name">김세영</h1>` 의 이름, `tagline`·`bio` 문장, `badge` 목록, 연락처 이메일을 **본인 정보로** 바꿔 저장한 뒤 브라우저에서 **새로고침(F5)** 합니다.
4. 프로필 사진을 본인 것으로 바꿉니다. 사진 파일(예: `me.jpg`)을 이 폴더에 넣고, `index.html`의 `<img>` 의 `src="https://placehold.co/...">` 를 `src="me.jpg"` 로 바꿔 저장 후 새로고침합니다. (사진이 없으면 임시 이미지가 그대로 보여 깨지지 않습니다.)
5. **박스모델 체감 실험**: `style.css`의 `.card { padding: 24px; }` 를 `padding: 8px;` 로 줄여 저장 후 새로고침 → 글자가 테두리에 바짝 붙는 것을 봅니다. 다시 `48px`로 키우면 카드 안이 넉넉해집니다. "padding = 박스 안쪽 숨 쉴 공간"임을 확인합니다.
6. **뱃지 모양 실험**: `.badge { border-radius: 9999px; }` 를 `border-radius: 4px;` 로 바꿔 저장 후 새로고침 → 알약 모양이 **각진 네모 태그**로 바뀝니다. 숫자가 모양을 결정한다는 걸 봅니다.
7. AI에게 시켜 보기:
   > "이 포트폴리오의 style.css에서 강조 색을 파랑(#2563eb)에서 보라(#7c3aed)로 통일해서 바꿔줘. 프로필 사진 테두리, 뱃지, 링크, 제목 밑줄에 쓰인 파랑을 모두 보라로 바꾸고 다른 레이아웃은 그대로 둬."

## 🤖 바이브코딩 프롬프트
이 실습(글만 있던 자기소개를 CSS 카드 포트폴리오로 꾸미기)을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 비전공자에게 친절한 웹 강사야. 서버·DB·빌드 도구 없이 index.html을 더블클릭하면 바로 열리는 "한 페이지 포트폴리오"를 만들어줘.
  - 파일은 index.html(내용·구조)과 style.css(꾸미기) 둘로 나누고, HTML은 내용만, CSS는 색·여백·테두리·그림자만 맡게 역할을 분리해줘.
  - 화면 구조: 프로필 카드(동그란 프로필 사진 + 이름 + 한 줄 소개 + 짧은 자기소개), 기술 스택 카드, 연락처 카드 3개를 위아래로 배치해줘.
  - 프로필 사진은 아직 파일이 없으니 placehold.co 임시 이미지 주소를 쓰고, img에는 alt 설명을 꼭 넣어줘.
  - 비전공자가 읽을 수 있게 각 줄에 "무엇을 하는 코드인지" 한국어 주석을 달아줘. 코드 식별자(class 이름 등)는 영어로.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 포트폴리오에 CSS로 "카드 스타일"을 입혀줘. 박스모델(padding/border/margin)을 비전공자가 눈으로 체감하게 만드는 게 목표야.
  - 각 영역(.card)을 흰 배경 + 둥근 모서리(border-radius) + 옅은 그림자(box-shadow)가 있는 떠 있는 카드로 만들어줘.
  - 프로필 사진은 border-radius: 50%로 완전한 원, 기술 스택은 border-radius: 9999px로 알약 모양 뱃지로 만들어줘.
  - 뱃지들은 display: flex + flex-wrap + gap으로 가로 나열하고 창이 좁아지면 자동 줄바꿈되게 해줘.
  - box-sizing: border-box를 전역(*)에 적용해서 "여백 줬더니 박스가 커지는" 문제를 막아줘.
  - 강조 색은 파랑(#2563eb) 하나로 통일하고, 왜 그 값/속성을 썼는지 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  포트폴리오가 꾸며지지 않고 글자만 보여. 아래 상황을 단계별로 진단해줘. 한 번에 한 가지씩, 무엇을 어디서 확인하는지 비전공자가 이해하게 풀어서 설명해줘.
  - index.html과 style.css가 같은 폴더에 있는지, <link rel="stylesheet" href="style.css" /> 줄의 파일명 철자가 맞는지부터 확인하는 방법을 알려줘.
  - 프로필 사진이 깨져 보이는데, img의 src 경로/파일명이 맞는지, alt가 대신 보이는 건 정상인지 알려줘.
  - 뱃지가 세로로 한 줄씩 쌓여 있어. .badges에 display: flex가 빠진 건지 확인하는 법을 알려줘.
  - F12 개발자도구의 Elements/Styles 패널로 "이 줄이 실제로 적용됐는지" 눈으로 확인하는 절차를 알려줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 결과가 훨씬 학습에 좋습니다.

## 검증법
- 카드 3장이 **모서리가 둥글고 옅은 그림자로 떠 보이는가?** → `border-radius`와 `box-shadow`가 적용된 증거.
- 프로필 사진이 **정사각형이 아니라 완전한 원**인가? → `border-radius: 50%`가 적용된 증거.
- 기술 스택 뱃지들이 **알약 모양으로 가로 나열**되고, 브라우저 창을 좁히면 **자동으로 다음 줄로 내려가는가?** → `flex` + `flex-wrap`이 작동하는 증거.
- 브라우저에서 `F12 → Elements(검사)`로 카드를 클릭하면, 오른쪽 스타일 패널에 `padding / border / border-radius / box-shadow` 값이 `style.css`와 똑같이 적혀 있는지 확인합니다.
- `index.html`의 `<link rel="stylesheet" href="style.css" />` 줄을 잠시 지워 저장하고 새로고침해 보면 **모든 꾸미기가 사라지고 글자만** 남습니다. → HTML(내용)과 CSS(꾸미기)가 분리돼 있다는 가장 확실한 증거입니다. (확인 후 다시 되돌리세요.)
