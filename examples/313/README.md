# 실습 313 — 디바운스 자동완성 검색 UI 만들기

검색창에 글자를 칠 때 **글자 하나마다 서버로 요청을 쏘면** 서버는 순식간에 수십 번 두들겨 맞습니다. 이 실습은 "타이핑을 **잠깐 멈췄을 때만**(예: 0.3초) 한 번 검색을 보내는" **디바운스(debounce)** 기법으로, 구글·유튜브 검색창처럼 **입력 아래로 추천어가 스르륵 뜨는 자동완성 UI**를 만듭니다. 키보드 위/아래로 추천어를 고르고, 늦게 도착한 옛 응답이 화면을 덮어쓰지 않게 막는 **요청 경쟁(race) 처리**까지 다룹니다.

> 한 줄 그림: **사용자가 "부산코"까지 친다 → 0.3초 동안 더 안 치면 → 그때 딱 한 번 검색 요청 → 추천어 목록이 입력창 아래로 뜬다 → 위/아래 키로 고르고 Enter로 선택**

> 비유: 디바운스는 **엘리베이터 문**과 같습니다. 한 사람이 탈 때마다 문을 닫았다 여는 게 아니라, **사람들이 다 타고 잠잠해지면(잠깐 멈추면)** 그때 문을 닫고 출발합니다. "타이핑이 잠잠해지면 그때 검색 출발"이 바로 디바운스입니다.

## 목표
- **디바운스를 손으로 구현한다**: `setTimeout`/`clearTimeout`으로 "마지막 입력 후 0.3초"에만 검색이 나가게 만들어, **요청 수를 글자당 1번 → 멈춤당 1번**으로 줄인다.
- **자동완성 드롭다운을 만든다**: 입력 아래에 추천어 목록을 띄우고, **마우스 클릭**과 **키보드(↑/↓/Enter/Esc)** 둘 다로 고를 수 있게 한다.
- **요청 경쟁(race condition)을 막는다**: 빠르게 칠 때 **늦게 온 옛 응답이 새 결과를 덮어쓰지 않도록** 오래된 요청을 취소(`AbortController`)한다.
- **보안과 접근성을 지킨다**: 사용자가 친 글자를 화면에 넣을 땐 `innerHTML`이 아니라 `textContent`로 넣어 XSS를 막고, 스크린리더용 ARIA 속성을 단다.

## 따라하는 단계

### A. 파일 열고 그냥 켜 보기
1. 이 폴더의 `index.html`을 더블클릭해 브라우저로 엽니다. (서버 없이 파일만으로 동작합니다 — 검색 데이터는 `script.js` 안에 박아 둔 **가짜 목록**을 씁니다.)
2. 검색창에 `부` 또는 `리`처럼 한 글자를 천천히 쳐 봅니다. 잠깐 멈추면 아래로 추천어가 뜹니다.
3. 화면 아래 **"요청 카운터"** 숫자를 보세요. **빠르게 연타할 때는 안 늘고, 멈췄을 때만 1씩 늘어나면** 디바운스가 동작하는 것입니다.

### B. 디바운스 시간(멈춤 기준) 바꿔 보기
4. `script.js` 맨 위 설정에서 `DEBOUNCE_MS` 값을 `300`에서 `1000`으로 바꿔 저장하고 새로고침합니다. 이제 **1초**를 멈춰야 검색이 나갑니다(느려진 게 체감됩니다).
5. 반대로 `50`으로 줄이면 거의 즉시 반응하지만 요청 카운터가 많이 늘어납니다. **"부하 절약 ↔ 즉각 반응"의 트레이드오프**를 눈으로 확인합니다.

### C. 키보드로 고르기
6. 추천어가 떴을 때 키보드 **↓/↑**로 항목을 이동하고, **Enter**로 선택, **Esc**로 닫아 봅니다. 선택한 글자가 입력창에 채워집니다.

### D. (선택) 진짜 서버 검색으로 바꾸기
7. `script.js`의 `searchApi()` 함수에 안내된 대로, 가짜 목록 대신 `fetch('/api/search?q=' + ...)`로 바꾸면 실제 백엔드 검색에 그대로 붙습니다. 이때도 디바운스·요청 취소 로직은 **그대로 재사용**됩니다.

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 비전공자를 가르치는 프론트엔드 멘토야. 외부 라이브러리 없이 순수 HTML/CSS/JS 한 세트(index.html, style.css, script.js)로
  '자동완성 검색 입력창'을 만들어줘. 요구사항:
  - 검색 input 하나와, 그 바로 아래에 뜨는 추천어 드롭다운(ul/li) 구조.
  - 검색 데이터는 아직 서버가 없으니 script.js 안에 한국어 도시/단어 20개짜리 배열을 박아 두고, 입력값을 포함하는 항목만 보여줘.
  - 추천어를 화면에 넣을 때 innerHTML 말고 textContent를 써. 이유(사용자 입력에 <script>가 섞이면 실행돼 XSS 위험)를 주석으로 적어줘.
  - 모든 핵심 코드 줄에 '무엇을 하는지 + 왜 그렇게 했는지' 한국어 주석을 달고, 파일 맨 위엔 이 파일이 뭔지 요약 주석 1블록을 넣어줘.
  - 코드만 주지 말고 한 줄씩 비전공자가 이해하게 풀어서 설명해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 자동완성 검색창에 아래를 추가해줘:
  1) 디바운스: input 이벤트가 올 때마다 바로 검색하지 말고, setTimeout/clearTimeout으로 '마지막 입력 후 300ms'에만 검색이 나가게 해줘.
     상수 DEBOUNCE_MS로 빼서 쉽게 바꾸게 하고, 왜 요청을 아끼는지 주석으로 설명해줘.
  2) 요청 절약 확인용: 실제로 검색이 몇 번 실행됐는지 세는 '요청 카운터'를 화면 하단에 표시해줘.
  3) 키보드 조작: 드롭다운이 열렸을 때 ↑/↓로 항목 이동, Enter로 선택, Esc로 닫기. 현재 선택 항목은 색으로 강조해줘.
  4) 접근성: input에 role=combobox, aria-expanded, aria-activedescendant 같은 ARIA 속성을 적절히 달아줘.
  5) 늦게 온 옛 응답이 새 결과를 덮지 않게(요청 경쟁 방지) AbortController나 '요청 순번' 비교로 막아줘. 이유도 주석으로.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  자동완성 검색창이 이상하게 동작해. 증상과 코드를 줄게. 원인을 추측만 하지 말고, 단계별로 진단하는 방법을 알려줘.
  [증상] 빠르게 타이핑하면 추천 목록이 깜빡이며 '예전 글자'에 맞는 결과가 잠깐 보였다가 바뀜.
  [관련 코드] (여기에 input 이벤트 핸들러와 검색/렌더 함수 붙여넣기)
  확인해줘: (1) 디바운스 타이머를 매 입력마다 clearTimeout 하고 다시 setTimeout 하는지,
  (2) 응답이 도착했을 때 '지금 input 값과 이 응답의 검색어가 같은지' 검사하는지(다르면 무시),
  (3) AbortController로 이전 요청을 취소하는지. 비전공자가 이해하게 한 줄씩 설명하고, 고친 코드에도 이유 주석을 달아줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **요청 절약 확인(핵심)**: 검색창에 글자를 **빠르게 연타**한다. 화면 하단의 "검색 실행 횟수"가 **타자 수만큼 늘지 않고**, 멈출 때마다 1씩만 느는지 본다. (이게 디바운스의 증거다.)
- **디바운스 시간 체감**: `script.js`의 `DEBOUNCE_MS`를 `1000`으로 바꾸면 1초를 멈춰야 결과가 뜨는지, `50`으로 바꾸면 즉시 뜨지만 횟수가 많이 느는지 비교한다.
- **키보드 동작 확인**: 추천어가 뜬 상태에서 **↓/↑**로 강조가 이동하고, **Enter**로 입력창이 채워지고, **Esc**로 목록이 닫히는지 본다.
- **요청 경쟁(race) 확인**: 아주 빠르게 단어를 바꿔 친 뒤, **마지막에 친 글자에 맞는 결과만** 남고 옛 결과가 깜빡이며 남지 않는지 본다.
- **XSS 안전 확인**: 검색창에 `<b>test</b>` 또는 `<img src=x onerror=alert(1)>`를 쳐 본다. 추천 목록이 **글자 그대로 보이고(태그가 실행되지 않고)** 경고창이 뜨지 않으면 `textContent`로 안전하게 출력되는 것이다.

## 파일 구성
- `index.html` — 검색 입력창과 추천 드롭다운 뼈대. `style.css`/`script.js`를 불러온다.
- `style.css` — 드롭다운·강조 항목·요청 카운터 등 화면 스타일. 다크 배경에서도 읽히게 변수로 색을 관리한다.
- `script.js` — 디바운스·자동완성·키보드 조작·요청 경쟁 방지 로직. 검색 데이터는 안에 박은 가짜 목록(서버 없이 동작).
