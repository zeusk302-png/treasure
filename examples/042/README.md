# 042. grid-area로 헤더·사이드·본문·푸터 전체 페이지 골격 짜기

CSS Grid의 `grid-template-areas`를 사용해 **헤더 - 사이드바 - 본문 - 푸터**로 이루어진 전체 페이지 레이아웃 골격을 만드는 실습입니다. 각 영역에 `grid-area`로 "이름표"를 붙이고, 부모 칸에서 그 이름들을 **그림 그리듯** 배치합니다. 실무에서 거의 모든 웹페이지가 이런 뼈대 위에 내용을 채워 만들어집니다.

## 목표

- `grid-area`로 각 요소(헤더/사이드바/본문/푸터)에 "이름표"를 붙일 수 있다.
- `grid-template-areas`에서 따옴표 한 줄이 화면의 한 "행(가로줄)"을 뜻하고, 같은 이름을 옆에 나란히 쓰면 그 칸이 가로로 합쳐진다는 것을 이해한다.
- `grid-template-columns`(가로 나누기)와 `grid-template-rows`(세로 나누기)가 영역의 크기를 정한다는 점을 익힌다.
- 자식의 이름표는 그대로 두고 **부모의 그림(areas)만 바꾸면** 배치가 통째로 바뀐다는 것을, 모바일 화면에서 직접 확인한다.

## 따라하는 단계

1. `index.html`과 `style.css`가 **같은 폴더(042)** 안에 있는지 확인합니다. HTML 위쪽의 `<link rel="stylesheet" href="style.css" />` 한 줄이 두 파일을 연결해 줍니다.
2. `index.html`을 더블클릭해 브라우저(크롬 등)로 엽니다. 위에 파란 헤더, 왼쪽에 흰 메뉴, 가운데에 본문, 아래에 어두운 푸터가 자리 잡으면 성공입니다.
3. `style.css`의 `.layout` 부분을 열어 핵심 두 가지를 확인합니다.
   ```css
   grid-template-columns: 220px 1fr;   /* 왼쪽 메뉴 220px 고정, 본문은 남는 공간 전부 */
   grid-template-areas:
     "header  header"   /* 1행: 헤더가 두 칸을 가로로 차지(맨 위 전체) */
     "sidebar main"     /* 2행: 왼쪽 sidebar, 오른쪽 main */
     "footer  footer";  /* 3행: 푸터가 두 칸을 가로로 차지(맨 아래 전체) */
   ```
   따옴표 한 줄 = 화면의 한 가로줄입니다. 글자를 눈으로 보면 실제 화면 모양과 똑같이 생겼습니다.
4. 각 영역이 "이름표"로 자기 칸을 찾아가는 것을 확인합니다. 예: `.header { grid-area: header; }` 는 위 그림에서 `header`라고 적힌 칸으로 들어갑니다. `sidebar`, `main`, `footer`도 같은 방식입니다.
5. **직접 바꿔보며 원리를 확인합니다.** (확인 후 원래 값으로 되돌리세요.)
   - 사이드바를 오른쪽으로 옮기고 싶다면 2행을 `"main sidebar"`로 바꿔 봅니다. 코드에서 자식은 한 줄도 안 건드렸는데 배치가 바뀝니다.
   - 메뉴 폭을 넓히려면 `grid-template-columns`의 `220px`을 `300px`로 키워 봅니다.
   - `gap: 12px`를 `0`으로 바꾸면 칸 사이 틈이 사라집니다.
6. **브라우저 창의 가로 너비를 700px보다 좁게** 줄여 봅니다. 사이드바가 본문 위로 올라가고, 모든 영역이 세로로 한 줄씩 쌓입니다. `style.css` 맨 아래 `@media (max-width: 700px)` 안에서 **부모의 그림(areas)만** 세로 모양으로 바꿨기 때문입니다. (자식의 `grid-area` 이름표는 그대로입니다.)

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 상황(역할·목표·제약)을 같이 적을수록 결과가 정확해집니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 CSS를 비전공자에게 가르치는 프론트엔드 강사야.
  CSS Grid의 grid-template-areas만 사용해서 전체 페이지 골격을 만들어 줘.
  - 영역은 4개: 헤더(맨 위 가로 전체), 사이드바(왼쪽 세로 메뉴), 본문(가운데 넓은 영역), 푸터(맨 아래 가로 전체).
  - index.html과 style.css 두 파일로 분리하고, HTML에 <link>로 연결해 줘.
  - .layout 한 박스를 display:grid로 만들고 grid-template-columns는 "사이드바 220px 고정 + 본문 1fr",
    grid-template-rows는 "auto 1fr auto", grid-template-areas로 header/sidebar/main/footer를 그림처럼 배치해 줘.
  - 각 자식에는 grid-area로 이름표를 붙여 줘.
  - min-height:100vh로 푸터가 항상 화면 바닥에 붙게 해 줘.
  - 내용은 '우리 동네 정보 사이트' 같은 예시 텍스트로 채워 줘.
  - 한국어 주석을 달되, 단순히 '무엇'이 아니라 '왜 그렇게 했는지'까지 한 줄씩 설명해 줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 grid-template-areas 레이아웃에 모바일 대응을 추가해 줘.
  - @media (max-width: 700px)에서 자식의 grid-area(이름표)는 절대 건드리지 말고,
    부모(.layout)의 grid-template-areas '그림'만 한 칸짜리 세로(header→sidebar→main→footer)로 바꿔 줘.
  - grid-template-columns도 1fr로 바꿔서 한 열이 되게 해 줘.
  - 왜 '자식은 그대로 두고 부모의 areas만 바꾸면' 배치가 통째로 바뀌는지 주석으로 설명해 줘.
  - 사이드바 메뉴 항목에 마우스를 올리면(hover) 배경색이 살짝 바뀌는 효과도 넣어 줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  grid-template-areas로 레이아웃을 짰는데 화면이 의도대로 안 나와.
  내 index.html과 style.css 전체를 붙여넣을게. 아래를 단계별로 점검해 줘.
  1) grid-template-areas의 각 따옴표 줄에 적힌 '칸 개수'가 grid-template-columns 개수와 일치하는지
  2) 자식의 grid-area 이름이 areas 그림에 적힌 이름과 철자까지 똑같은지(오타·대소문자)
  3) 같은 영역 이름이 직사각형으로 모여 있는지(L자 모양이면 무효가 됨)
  무엇이 틀렸는지 알려주고, 고친 코드와 함께 '왜 그게 문제였는지'를 한 줄씩 설명해 줘.

  [여기에 코드와 화면 스크린샷/증상을 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

- 브라우저로 `index.html`을 열면 헤더(위) · 사이드바(왼쪽) · 본문(가운데) · 푸터(아래)가 한 화면에 골격으로 배치된다.
- 헤더와 푸터는 좌우 **전체 가로폭**을 차지하고, 사이드바와 본문은 같은 행에서 좌우로 나뉜다.
- 본문 내용이 길어져도 푸터는 항상 화면 맨 아래에 위치한다. (`min-height: 100vh` + `1fr` 덕분)
- **창 너비를 700px 이하로 줄이면** 4개 영역이 헤더 → 메뉴 → 본문 → 푸터 순서로 세로로 쌓인다. (모바일 레이아웃 전환 확인)
- 개발자도구(F12) > Elements에서 `.layout`을 선택하면 `display: grid`와 그리드 칸 경계선을 확인할 수 있다. 크롬 그리드 오버레이를 켜면 `header`/`sidebar`/`main`/`footer` 영역 이름이 화면에 표시된다.
