# 한 화면 자기소개 페이지(프로필) 종합 완성하기

지금까지 따로따로 배운 HTML 조각들(시맨틱 구조, 이미지, 링크, 문단, 목록, 인라인 스타일)을 **하나로 합쳐** 완성형 1페이지 프로필을 만듭니다. 이 한 장만 있으면 "내가 누구인지"를 보여주는 나만의 명함 페이지가 됩니다.

## 목표

- `header` / `main` / `footer` 시맨틱 태그로 페이지를 위·중간·아래 세 영역으로 나눈다.
- 프로필 이미지(`img`), 소개 문단(`p`), 기술 목록(`ul`/`li`), 링크(`a`)를 한 페이지에 모두 담는다.
- 태그의 `style` 속성(인라인 스타일)으로 색·여백·둥근 모서리·그림자를 직접 입혀 보기 좋게 꾸민다.
- 별도 CSS 파일 없이 `index.html` 한 파일만으로 완성형 페이지를 만들 수 있다는 것을 체험한다.

## 따라하는 단계

1. `024` 폴더 안에 있는 `index.html` 파일을 마우스로 더블클릭해 브라우저(크롬 등)로 엽니다. 보라색 머리말과 동그란 사진이 있는 프로필이 보입니다.
2. **머리말(header) 바꾸기**: 코드에서 `<h1>김부산</h1>` 의 이름을 본인 이름으로, 그 아래 `<p>웹 개발을 배우는 비전공 청년</p>` 을 본인 한 줄 소개로 바꿉니다. 파일을 저장(Ctrl+S)하고 브라우저에서 새로고침(F5)하면 바뀐 내용이 보입니다.
3. **사진 바꾸기**: `<img>` 태그의 `src="..."` 부분을 본인 사진 주소로 바꿉니다. 같은 폴더에 사진을 넣었다면 `src="내사진.jpg"` 처럼 파일 이름만 적어도 됩니다. `alt`(대체 설명)도 본인 이름으로 고칩니다.
4. **소개 문단 쓰기**: "소개" 섹션의 `<p>` 안 문장을 본인 이야기로 바꿉니다.
5. **기술 목록 채우기**: "다룰 줄 아는 것" 섹션의 `<li>` 항목을 본인이 배운 것으로 추가하거나 수정합니다. `<li>새 항목</li>` 줄을 복사해 붙이면 항목이 늘어납니다.
6. **링크 연결하기**: "링크" 섹션의 `<a href="...">` 안 주소를 본인 GitHub·블로그 주소로 바꾸고, `mailto:` 뒤의 메일 주소도 본인 것으로 바꿉니다.
7. 다시 저장 후 새로고침해서 모든 정보가 내 것으로 바뀌었는지 확인합니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고 아래 순서대로 단계를 나눠 시키면 결과를 점검하기 쉽습니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML 입문자를 돕는 멘토야. 별도 CSS 파일 없이 index.html 한 파일만으로
  동작하는 1페이지 자기소개(프로필) 페이지를 만들어줘.
  - 한국어 페이지(<html lang="ko">), <meta charset="UTF-8">와 viewport 메타 태그 포함
  - 시맨틱 태그로 세 영역 구성: header(이름 + 한 줄 소개) / main / footer(저작권)
  - main 안에는 section 4개: 프로필 이미지(img), 소개 문단(p), 기술 목록(ul/li), 링크 목록(a)
  - 사진은 아직 없으니 placehold.co 같은 무료 자리표시자 이미지로 넣어줘
  - 디자인은 전부 태그의 style 속성(인라인 스타일)로만 입혀줘(외부 .css 파일 금지)
  결과는 복사해서 바로 파일로 저장할 수 있는 완성된 index.html 한 개로 줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 프로필 페이지를 더 보기 좋게 다듬어줘. 기존 구조(header/main/footer)와
  인라인 스타일 방식은 그대로 유지하고 아래만 더해줘.
  - 프로필 사진을 동그랗게(border-radius: 50%) 만들고 은은한 그림자 추가
  - 소개·기술·링크 section을 흰 카드 모양(둥근 모서리 + 그림자)으로 감싸기
  - GitHub·블로그 링크는 새 탭에서 열리게(target="_blank"), 이메일은 mailto로 메일 창 열리게
  - 모바일에서도 안 깨지게 main에 max-width를 주고 가운데 정렬
  바꾼 부분이 왜 필요한지 한 줄씩 주석으로 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  내 프로필 페이지가 이상하게 나와. 아래 index.html 전체 코드를 붙여넣을게.
  [여기에 코드 붙여넣기]
  증상: (예) 사진이 안 보이고 깨진 이미지 아이콘만 나와 / 링크를 눌러도 새 탭이 안 열려 /
  카드 그림자가 안 보여.
  무엇이 문제인지 초보도 알게 한 줄씩 짚어주고, 고친 코드와 "왜 그렇게 고쳤는지"를
  같이 알려줘. 한 번에 다 바꾸지 말고 원인부터 설명해줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

- 브라우저로 열었을 때 **위(보라색 머리말) → 가운데(사진·소개·기술·링크) → 아래(저작권 푸터)** 순서로 화면이 나오면 시맨틱 구조가 제대로 잡힌 것입니다.
- 프로필 사진이 **동그란 모양**으로 보이면 인라인 스타일(`border-radius: 50%`)이 적용된 것입니다.
- "링크" 섹션의 **GitHub·블로그를 클릭하면 새 탭**에서 해당 사이트가 열리고, **이메일 보내기를 클릭하면 메일 작성 창**이 뜨면 성공입니다.
- 브라우저 개발자 도구(F12)를 열어 콘솔에 빨간 오류 메시지가 없으면 코드가 깨진 곳 없이 잘 작동하는 것입니다.
- (선택) 모든 태그가 짝을 이뤄 닫혔는지 확인하려면 [W3C HTML 검사기](https://validator.w3.org/#validate_by_input)에 코드를 붙여넣어 오류 0건인지 봅니다.
