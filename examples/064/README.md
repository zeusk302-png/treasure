# 체크박스로 '약관 동의' 버튼 활성화하기

회원가입 화면에서 자주 보는 동작을 그대로 만들어 봅니다. 약관 동의 체크박스를 켜야만 '가입하기' 버튼이 눌리고, 체크를 풀면 다시 버튼이 흐려지면서 눌리지 않게 됩니다. 자바스크립트로 체크박스의 `checked`(켜짐/꺼짐) 상태를 읽어, 다른 요소인 버튼의 `disabled`(비활성화) 속성을 제어하는 흐름을 익힙니다.

## 목표

- 체크박스의 `checked` 값으로 "지금 켜져 있는지(true) / 꺼져 있는지(false)"를 읽는 법을 익힙니다.
- 버튼의 `disabled` 속성으로 버튼을 "눌리는 상태 / 눌리지 않는 상태"로 바꾸는 법을 익힙니다.
- 체크박스가 바뀔 때마다 발생하는 `change` 이벤트로 "한 요소의 상태에 따라 다른 요소를 제어하는" 패턴을 익힙니다. (`버튼.disabled = !체크박스.checked` 한 줄이 핵심입니다.)

## 따라하는 단계

1. 이 폴더(`064`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. 약관 내용, 그 아래 동의 체크박스, 회색으로 흐려진 '가입하기' 버튼이 보이는지 확인합니다. 처음에는 체크를 안 했으므로 버튼이 비활성화 상태입니다.
3. `index.html`을 살펴봅니다. 체크박스에는 `id="agreeCheck"`, 가입 버튼에는 `id="signupBtn"`이 붙어 있습니다. 또 버튼에는 처음부터 `disabled`가 적혀 있어 시작할 때 눌리지 않습니다. 자바스크립트는 이 id들로 두 요소를 찾아냅니다.
4. `script.js`를 엽니다. 동작은 간단합니다.
   - `document.getElementById(...)`로 체크박스(`agreeCheck`)와 버튼(`signupBtn`)을 찾습니다.
   - 체크박스에 `addEventListener("change", ...)`로 "체크가 켜지거나 꺼질 때마다 실행할 동작"을 연결합니다.
   - 동작 안에서 `signupBtn.disabled = !agreeCheck.checked`로, 체크의 반대값을 버튼의 비활성화 여부로 정합니다. (체크됨이면 disabled는 false → 눌림 / 체크 안 됨이면 disabled는 true → 막힘)
5. 브라우저로 돌아가 체크박스를 켜 봅니다. 버튼 색이 파랗게 살아나면서 누를 수 있게 되면 성공입니다. 다시 체크를 풀면 버튼이 회색으로 돌아가 눌리지 않습니다.

## 검증법

- 처음 화면에서 '가입하기' 버튼이 회색이고, 눌러도 아무 일도 일어나지 않으면 정상입니다.
- 체크박스를 켜면 버튼이 파란색으로 바뀌고 마우스를 올렸을 때 손가락 커서로 바뀌면(누를 수 있는 상태) 정상입니다.
- 체크된 상태에서 버튼을 누르면 아래에 "가입이 완료되었습니다!" 안내 문구가 뜨는지 확인합니다.
- 다시 체크를 풀면 버튼이 곧바로 회색(비활성화)으로 돌아가고, 마우스를 올리면 금지 표시(`not-allowed` 커서)가 나오는지 확인합니다.
- 약관 글자(라벨)를 클릭해도 체크박스가 켜지고 버튼이 같이 활성화되는지 확인합니다. (체크박스를 `<label>`로 감쌌기 때문입니다.)
- 만약 버튼이 처음부터 눌리거나 체크를 해도 반응이 없다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html`의 버튼에 `disabled`가 적혀 있는지, `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지 확인하세요.

## 핵심 개념

- `checked` : 체크박스가 켜져 있으면 `true`, 꺼져 있으면 `false`. `체크박스.checked`로 읽습니다.
- `disabled` : 버튼·입력칸 등을 "눌리지 않는 상태"로 만드는 속성. `버튼.disabled = true`면 막히고, `false`면 풀립니다. HTML에 `disabled`만 써 두면 시작부터 막힌 상태입니다.
- `change` 이벤트 : 체크박스·드롭다운 등 선택 상태가 바뀔 때 발생하는 이벤트. 여기서는 체크가 켜지거나 꺼지는 순간을 잡습니다.
- `!` (느낌표, NOT) : 참/거짓을 반대로 뒤집습니다. `!true`는 `false`, `!false`는 `true`. "체크의 반대 = 비활성화 여부"라서 사용합니다.
