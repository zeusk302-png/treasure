# 비밀번호 보기/가리기 눈 아이콘 토글

로그인 폼의 비밀번호 입력칸 오른쪽에 눈 아이콘 버튼을 두고, 그 버튼을 누르면 비밀번호가 점(●●●)으로 가려졌다가 글자로 보였다가 번갈아 바뀌는 작은 페이지입니다. 자바스크립트로 입력칸의 `type` 속성을 동적으로 바꾸는 법을 익힙니다.

## 목표

- 입력칸의 `type` 값을 `password`(가림) ↔ `text`(보임)로 바꾸면 화면 표시가 달라진다는 것을 이해합니다.
- 지금이 "보이는 상태"인지 "가린 상태"인지 기억해 두었다가 누를 때마다 반대로 뒤집는 토글(toggle) 패턴을 익힙니다.
- 버튼의 아이콘과 안내 문구(`aria-label`)를 상태에 맞게 같이 바꿔 사용자가 헷갈리지 않게 만듭니다.

## 따라하는 단계

1. 이 폴더(`061`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. 이메일 칸과 비밀번호 칸, 그리고 비밀번호 칸 오른쪽에 눈 아이콘(🙈) 버튼이 보이는지 확인합니다.
3. 비밀번호 칸에 아무 글자나 몇 자 입력해 봅니다. 처음에는 점(●●●)으로 가려져 보입니다. 이는 `index.html`에서 입력칸이 `type="password"`로 시작하기 때문입니다.
4. `index.html`을 살펴봅니다. 비밀번호 입력칸에는 `id="password"`, 눈 버튼에는 `id="toggleBtn"`, 버튼 안 아이콘에는 `id="toggleIcon"`이 붙어 있습니다. 자바스크립트는 이 id로 각 요소를 찾아냅니다.
5. `script.js`를 엽니다. 동작은 간단합니다.
   - `document.getElementById(...)` 로 입력칸·버튼·아이콘을 찾습니다.
   - 버튼에 `addEventListener("click", ...)` 로 클릭 동작을 연결합니다.
   - 클릭하면 `passwordInput.type`이 `"password"`인지 확인해서, 가려져 있으면 `"text"`로(보이게), 보이고 있으면 다시 `"password"`로(가리게) 바꿉니다. 동시에 아이콘과 안내 문구도 함께 바꿉니다.
6. 브라우저로 돌아가 눈 아이콘을 눌러봅니다. 누를 때마다 비밀번호가 보였다 가려졌다 하고, 아이콘이 🙈 ↔ 🙉 로 바뀌면 성공입니다.

## 검증법

- 비밀번호 칸에 글자를 입력한 뒤 눈 버튼을 누르면 점(●●●)이 실제 글자로 바뀌고, 한 번 더 누르면 다시 점으로 돌아오면 정상입니다.
- 버튼을 누를 때마다 아이콘이 🙈(가림) ↔ 🙉(보임) 으로 번갈아 바뀌는지 확인합니다.
- 버튼을 눌러도 비밀번호 칸의 커서가 사라지지 않고 이어서 입력할 수 있는지 확인합니다(이건 `script.js`의 `passwordInput.focus()`가 담당합니다).
- "로그인" 버튼을 눌러도 페이지가 새로고침되지 않습니다(연습용이라 `onsubmit="return false;"`로 제출을 막아 두었습니다).
- 만약 토글이 안 된다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html` 안에 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지 확인하세요.

## 핵심 개념

- `input.type = "text"` / `input.type = "password"` : 자바스크립트로 입력칸의 종류(속성)를 바꿔 비밀번호를 보이거나 가립니다.
- 토글(toggle) 상태 : "지금 가려져 있나?"를 먼저 확인하고 그 반대로 바꾸는 것이 토글의 기본 패턴입니다.
- `aria-label`, `aria-pressed` : 화면을 못 보는 사용자(스크린 리더 사용자)에게도 버튼의 현재 상태를 알려 주는 접근성 속성입니다.
