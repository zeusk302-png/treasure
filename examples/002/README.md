# 실습 002 — 자기소개 한 문단 페이지 만들기

`<h1>` 제목 한 줄과 `<p>` 문단 하나로, 내 이름과 취미를 적은 **한 화면짜리 자기소개 페이지**를 만듭니다. "제목"과 "문단"이 어떻게 다른지 눈으로 익히는 게 목표예요.

## 목표
- 페이지의 큰 제목은 `<h1>`로 쓴다는 것을 안다.
- 줄글(설명 문장)은 `<p>`(문단) 안에 쓴다는 것을 안다.
- 제목(굵고 큼)과 문단(보통 글씨)이 화면에서 어떻게 다르게 보이는지 확인한다.

## 따라하는 단계
1. 같은 폴더의 `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 맨 위에 크게 보이는 글자가 `<h1>` 제목, 그 아래 줄글이 `<p>` 문단입니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어, `<h1>` 안의 이름과 `<p>` 안의 소개 내용을 **여러분 것으로** 바꿉니다.
4. 저장한 뒤 브라우저에서 새로고침(F5)하면 바뀐 내용이 보입니다.
5. AI에게 시켜 보기:
   > "이 자기소개 페이지에 좋아하는 음식을 적는 문단(`<p>`)을 하나 더 추가해줘."

## 검증법
- 브라우저 **탭 제목**에 "자기소개 — (이름)"이 보이나요? (`<title>` 확인)
- 맨 위 글자가 **나머지 글보다 굵고 크게** 보이나요? (그게 `<h1>` 제목이 맞다는 뜻)
- 그 아래에 **보통 크기의 줄글**이 한 문단 보이나요? (그게 `<p>` 문단)
- 제목과 문단의 내용이 **내 이름·내 취미**로 바뀌어 있나요?
