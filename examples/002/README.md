# 실습 002 — 자기소개 한 문단 페이지 만들기

`<h1>` 제목 한 줄과 `<p>` 문단 하나로, 내 이름과 취미를 적은 **한 화면짜리 자기소개 페이지**를 만듭니다. "제목"과 "문단"이 어떻게 다른지 눈으로 익히는 게 목표예요.

## 목표
- 페이지의 큰 제목은 `<h1>`로 쓴다는 것을 안다.
- 줄글(설명 문장)은 `<p>`(문단) 안에 쓴다는 것을 안다.
- 제목(굵고 큼)과 문단(보통 글씨)이 화면에서 어떻게 다르게 보이는지 확인한다.

## 따라하는 단계
1. 같은 폴더의 `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 맨 위에 크게 보이는 글자가 `<h1>` 제목, 그 아래 줄글이 `<p>` 문단입니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어, `<h1>` 안의 이름과 `<p>` 안의 소개 내용을 **여러분 것으로** 바꿉니다.
4. 저장한 뒤 브라우저에서 새로고침(F5)하면 바뀐 내용이 보입니다.
5. AI에게 시켜 보기:
   > "이 자기소개 페이지에 좋아하는 음식을 적는 문단(`<p>`)을 하나 더 추가해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML을 처음 배우는 비전공자를 돕는 강사야.
  한 화면짜리 "자기소개 페이지"의 index.html을 만들어줘.
  조건:
  - 한국어 페이지(<html lang="ko">), UTF-8, 모바일 대응 viewport 메타태그 포함.
  - 브라우저 탭에 "자기소개 — 홍길동"이 보이도록 <title> 설정.
  - 큰 제목은 <h1> 하나, 자기소개 줄글은 <p> 문단 하나로.
  - 외부 라이브러리 없이 순수 HTML + <style> 안의 간단한 CSS만.
  결과: 파일 하나(index.html)만 코드블록으로 주고, 각 태그가 무엇이고 왜 쓰는지 한국어 주석으로 설명해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 자기소개 페이지를 이어서 개선해줘.
  - 좋아하는 음식을 적는 <p> 문단을 하나 더 추가.
  - 글이 잘 읽히게 본문 폭(max-width)과 줄간격(line-height)만 살짝 손봐줘. h1/p 구조는 그대로 유지.
  - 제목(<h1>)과 문단(<p>)이 화면에서 어떻게 다르게 보이는지 비전공자가 한눈에 알 수 있게.
  바꾼 부분마다 "무엇을 왜 바꿨는지" 한국어 주석으로 설명해줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  자기소개 페이지가 브라우저에서 이상하게 보여. 내 index.html 전체 코드를 아래에 붙여넣을게.
  (여기에 코드 붙여넣기)
  무엇이 문제인지 한 줄씩 짚어주고, 비전공자도 따라 고칠 수 있게 단계별로 알려줘.
  특히 제목이 안 굵게 보이거나, 탭 제목이 안 바뀌거나, 한글이 깨지는(글자 □□) 경우의 원인을 우선 확인해줘.
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법
- 브라우저 **탭 제목**에 "자기소개 — (이름)"이 보이나요? (`<title>` 확인)
- 맨 위 글자가 **나머지 글보다 굵고 크게** 보이나요? (그게 `<h1>` 제목이 맞다는 뜻)
- 그 아래에 **보통 크기의 줄글**이 한 문단 보이나요? (그게 `<p>` 문단)
- 제목과 문단의 내용이 **내 이름·내 취미**로 바뀌어 있나요?
