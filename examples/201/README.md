# 크론(Schedule)으로 매일 아침 자동 실행 설정하기

앞 실습(200)까지는 워크플로우를 돌리려면 직접 **`Test workflow` 버튼을 눌러야** 했습니다. 사람이 안 누르면 아무 일도 안 일어났죠. 이번에는 그 버튼을 **시계에게 맡깁니다.** "매일 오전 8시가 되면 알아서 한 번 돌려라"라고 약속을 걸어 두는 것입니다.

이렇게 **정해진 시간에 스스로 깨어나 도는 자동화**를 만들어 주는 도구가 n8n의 **Schedule Trigger(스케줄 트리거)** 노드입니다. 그리고 이 약속이 실제로 효력을 가지려면, 워크플로우를 **Active(활성)** 상태로 켜 줘야 합니다.

> **크론(Cron)을 한마디로:** "몇 시 몇 분에, 며칠마다, 무슨 요일에 이 일을 해라"라고 적어 두는 **자동 알람 설정표**입니다. 휴대폰 알람을 '평일 오전 7시'로 맞춰 두면 내가 깨우지 않아도 울리는 것과 똑같습니다.
>
> **Active(활성)를 한마디로:** 알람을 **켜 둔 상태**입니다. 워크플로우를 아무리 잘 만들어도 Active를 켜지 않으면, 그건 '알람을 맞춰 놓고 스위치를 안 켠' 것과 같아서 정해진 시각이 와도 울리지 않습니다.

## 목표

- **Schedule Trigger 노드**로 "매일 오전 8시"라는 정기 실행 규칙(크론)을 설정한다.
- 워크플로우를 **Active(활성)** 로 켜서, 내가 버튼을 누르지 않아도 정해진 시각에 스스로 도는 것을 이해한다.
- 매번 다른 **실행 시각**이 기록되는 것을 보며 "정말 자동으로, 주기적으로 돌고 있다"를 눈으로 확인한다.

> 이 워크플로우는 노드 2개입니다.
> `매일 오전 8시 (Schedule Trigger)` → `실행 기록 남기기 (Set)`
> 1번이 "매일 8시에 깨어나라"는 알람이고, 2번은 깨어날 때마다 "몇 시에 돌았는지"를 적어 두는 메모지입니다. 자동 실행이 됐는지 확인하기 쉽도록 둔 것입니다.

## 따라하는 단계

1. **n8n에 로그인**합니다. (n8n Cloud 가입형 또는 직접 설치한 n8n 모두 가능)
2. 화면 오른쪽 위 **`...`(점 3개) → `Import from File`** 을 눌러 이 폴더의 **`workflow.json`** 파일을 불러옵니다. 노드 2개가 연결되어 나타납니다.
3. **`매일 오전 8시 (Schedule Trigger)` 노드를 더블클릭**해서 안을 살펴봅니다. 이렇게 설정되어 있습니다.
   - **`Trigger Rules`(실행 규칙)**: `Trigger Interval`(실행 간격)이 **`Days`(매일)** 로 되어 있습니다.
   - **`Trigger at Hour`(실행 시각: 시)**: `8am` — 오전 8시.
   - **`Trigger at Minute`(실행 시각: 분)**: `0` — 정각 0분.
   - 즉 "매일 오전 8시 0분에 한 번 돌려라"라는 알람입니다.
4. 약속이 잘 걸렸는지 미리 확인합니다. 노드 화면 안의 **`Test step`(이 단계만 실행)** 버튼을 누르면, 8시까지 기다리지 않고 **지금 즉시 한 번** 실행해 흐름이 정상인지 볼 수 있습니다. (이건 어디까지나 테스트일 뿐, 자동 실행과는 별개입니다.)
5. **`실행 기록 남기기 (Set)` 노드를 클릭**합니다. `OUTPUT`에 `실행메시지`, `실행시각`, `오늘요일`이 채워져 있으면 흐름은 정상입니다.
6. 이제 진짜 핵심입니다. 캔버스 화면 **오른쪽 위의 `Active`(활성) 토글 스위치를 켭니다.** 회색이던 스위치가 켜지면, "이 알람을 실제로 작동시킨다"는 뜻입니다. (불러온 파일은 `active: true`로 저장돼 있지만, n8n에 따라 가져온 직후엔 꺼진 상태일 수 있으니 직접 켜져 있는지 확인하세요.)
7. 토글을 켜는 순간부터, 나는 아무것도 누르지 않아도 **매일 오전 8시가 되면 n8n이 알아서** 이 워크플로우를 돌립니다.

## 검증법

1. **규칙 확인:** Schedule Trigger 노드를 열었을 때 `Days` / `8am` / `0분`으로 설정돼 있으면 크론 규칙은 정상입니다.
2. **Active 켜짐 확인:** 캔버스 오른쪽 위 `Active` 토글이 **켜진(색이 들어온)** 상태인지 봅니다. 꺼져 있으면 시각이 와도 돌지 않습니다 — 가장 흔한 실수입니다.
3. **자동 실행 기록 확인:** 왼쪽 메뉴의 **`Executions`(실행 기록)** 화면으로 갑니다. 8시가 지난 뒤 다시 보면, 내가 누르지 않았는데도 실행 한 줄이 **자동으로(Trigger: Schedule)** 쌓여 있습니다. 이게 "스스로 돌았다"는 가장 확실한 증거입니다.
4. **결과 모양 확인:** 그 실행을 눌러 보면 Set 노드 출력이 아래처럼 나옵니다. (시각/요일은 실제 실행된 때에 따라 달라집니다.)
   ```json
   {
     "실행메시지": "매일 오전 8시 자동 실행이 정상적으로 돌았습니다.",
     "실행시각": "2026-06-18 08:00:00",
     "오늘요일": "Thursday"
   }
   ```
5. **8시까지 못 기다릴 때(빠른 확인법):** Schedule Trigger 노드에서 `Trigger Interval`을 잠깐 **`Minutes`(분 단위)** 로 바꾸고 `Minutes Between Triggers`를 `1`로 두면, **1분마다** 실행됩니다. Active를 켠 채 2~3분 두면 `Executions`에 자동 실행이 줄줄이 쌓이는 걸 바로 볼 수 있습니다. 확인이 끝나면 **반드시 다시 `Days` / 8시 / 0분으로 되돌리세요.** (안 그러면 1분마다 계속 돕니다.)

## 핵심만 짚기 (디렉터 관점)

- **트리거가 자동화의 '시작 신호'를 정합니다.** 앞서 본 웹훅이 "남이 나를 부르면 깨어나는" 신호라면, 스케줄/크론은 "정해진 시간이 되면 스스로 깨어나는" 신호입니다. 무엇으로 깨울지를 고르는 게 설계의 첫걸음입니다.
- **만들기와 켜기는 다른 일입니다.** 워크플로우를 잘 만들어도 `Active`를 켜지 않으면 정기 실행은 일어나지 않습니다. "알람을 맞췄다"와 "알람 스위치를 켰다"는 별개라는 점을 꼭 기억하세요.
- **시간대(Timezone) 주의:** '오전 8시'는 어느 지역 기준인지에 따라 달라집니다. n8n 설정의 시간대가 한국(Asia/Seoul)으로 돼 있어야 한국 시각 8시에 돕니다. 자동화가 엉뚱한 시간에 돈다면 십중팔구 시간대 문제입니다.

## 보안, 비밀값은 어떻게 다루나

- 이 실습은 외부 서비스에 접속하지 않고 시각만 기록하므로 **API 키나 비밀번호가 전혀 필요 없습니다.** 그래서 `workflow.json`을 그대로 공유해도 안전합니다.
- 다만 다음 단계로 "매일 8시에 **메일 보내기**"나 "매일 8시에 **외부 API 호출**" 같은 걸 붙이게 되면 비밀값(메일 계정 비밀번호, API 키 등)이 등장합니다. 그때는 절대로 노드 값에 직접 적지 말고, n8n의 **`Credentials`(자격증명) 금고**에 넣어 두고 노드에서 골라 쓰세요. 그러면 비밀값은 금고에만 남고 `workflow.json`에는 새지 않습니다.
- 파일에 예시로 적어야 할 때는 실제 값 대신 **자리표시자**(예: `YOUR_API_KEY`)만 둡니다.
- 한 줄 원칙: **공개해도 되는 값(실행 시각, 메시지 문구)은 노드에, 새면 안 되는 값(비밀번호·API 키·토큰)은 자격증명 금고에.**
