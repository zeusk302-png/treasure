# 실습 277 — 오타 난 CSS 속성 살리기 (색이 하나도 안 먹는 카드)

> **디버깅 챌린지 (난이도 1)** · 분류: 디버깅 챌린지 · 개념: CSS 속성 오타, 개발자도구 요소검사

이 폴더에는 **일부러 고장 낸 파일**(`broken.html`)과 **고친 정답 파일**(`index.html`)이 들어 있습니다.
먼저 `broken.html`을 열어 무엇이 이상한지 직접 찾아보고, 그다음 `index.html`과 비교하세요.

> **한 줄 메모(무엇이 잘못됐나):** CSS 속성명에 **오타**가 5개 있었습니다. `bacground`(→`background`), `colour`(→`color`), `font-sze`(→`font-size`), `opactiy`(→`opacity`), `font-weigth`(→`font-weight`). CSS는 **모르는 속성명을 만나면 에러를 띄우지 않고 그 줄을 조용히 무시**하기 때문에, 카드가 디자인 없이 밋밋하게 나옵니다.

## 목표
- CSS 속성명은 **철자가 한 글자라도 틀리면 통째로 무시**된다는 것을 이해한다. (브라우저가 빨간 에러를 내주지 않는다!)
- 색이 안 먹거나 글씨가 안 굵어질 때, **HTML/CSS가 아니라 속성명 오타**일 수 있다는 의심을 갖는다.
- 브라우저 개발자도구(F12)의 **요소검사**로, 무시된(취소선이 그어진) 속성을 찾아내는 법을 익힌다.

### 비유로 이해하기
CSS 속성명은 **자판기 버튼에 적힌 글자**와 같습니다.
'콜라' 버튼을 누르면 콜라가 나오지만, '콜리'라고 잘못 적힌 버튼은 자판기가 "그런 버튼 없는데?" 하고 **아무것도 안 주고 그냥 넘어갑니다.** 에러음도 안 납니다.
`bacground`, `colour`, `font-weigth`도 마찬가지로 브라우저에게는 "모르는 버튼"이라 **조용히 무시**됩니다. 그래서 배경색·글자색·굵기가 하나도 적용되지 않은 채 기본 모양으로만 보입니다.

### 고친 속성 목록 (오타 → 정답)
| 위치(선택자) | 오타 속성 | 올바른 속성 | 의도한 효과 |
| --- | --- | --- | --- |
| `.card` | `bacground` | `background` | 카드 배경을 보라색으로 |
| `.card` | `colour` | `color` | 글자색을 흰색으로 (`color`는 미국식 철자만 인정) |
| `.card h2` | `font-sze` | `font-size` | 제목 글자를 22px로 키움 |
| `.card .author` | `opactiy` | `opacity` | 지은이 글자를 살짝 연하게 |
| `.card .price` | `font-weigth` | `font-weight` | 가격을 굵게 강조 |

## 따라하는 단계
1. `broken.html`을 **더블클릭**해서 브라우저로 엽니다. → 카드가 **흰 배경에 검은 글씨**로, 디자인이 하나도 안 입혀진 밋밋한 모습으로 보입니다.
2. `F12`를 눌러 개발자도구를 열고 **Elements(요소)** 탭에서 `<div class="card">`를 클릭합니다.
3. 오른쪽 **Styles(스타일)** 패널을 봅니다. `bacground`, `colour` 같은 줄에 **취소선(가운데 줄)**이 그어져 있고, 보통 **노란 경고 아이콘(⚠️)**이 붙어 있습니다. → 브라우저가 "이 속성은 모른다"며 무시했다는 표시입니다.
4. `broken.html`을 메모장이나 VS Code로 엽니다.
5. 취소선이 그어졌던 속성명 5개를 위의 **고친 속성 목록** 표대로 올바른 철자로 고칩니다. (`bacground`→`background`, `colour`→`color`, `font-sze`→`font-size`, `opactiy`→`opacity`, `font-weigth`→`font-weight`)
6. 저장하고 브라우저에서 **새로고침(F5)** → 카드가 **보라색 배경 + 흰 글씨 + 굵은 가격**으로 제대로 디자인되면 성공입니다.
7. 정답이 궁금하면 같은 폴더의 `index.html`을 열어 내 수정과 비교합니다.
8. AI에게 검토 시켜 보기:
   > "이 CSS에서 존재하지 않는(오타 난) 속성명이 있는지 찾아줘. 있으면 올바른 철자로 알려줘."

## 검증법
- 고친 뒤 카드가 **보라색 배경 + 흰색 글씨**로 보이는가? (아직 흰 배경/검은 글씨면 `background`/`color` 오타가 안 고쳐진 것)
- 책 제목('아주 작은 습관의 힘')이 **본문보다 크게** 보이는가? (`font-size` 확인)
- 가격('15,800원')이 **굵게** 보이는가? (`font-weight` 확인)
- `F12 → Elements → Styles`에서 `.card`의 모든 속성에 **취소선이 하나도 없는가?** 취소선이 남아 있으면 그 줄이 아직 오타라는 뜻입니다.
- (보너스) 개발자도구 **Console(콘솔)** 탭에는 CSS 오타에 대한 에러가 **뜨지 않습니다.** "에러가 없는데 스타일이 안 먹는다"면 속성명 오타를 먼저 의심하세요.
