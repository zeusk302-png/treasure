# 나쁜 프롬프트 vs 좋은 프롬프트 3쌍

> AI(Claude 등)에게 일을 시킬 때, 같은 부탁이라도 **어떻게 적느냐**에 따라 결과물이 완전히 달라집니다.
> 핵심은 **프롬프트 3원칙** 입니다.
>
> - **맥락(Context)**: 지금 어떤 상황인가? (어떤 프로젝트, 어떤 파일, 누구를 위해)
> - **목표(Goal)**: 무엇을 만들고 싶은가? (결과물이 무엇이고 어떻게 동작해야 하나)
> - **제약(Constraints)**: 지켜야 할 규칙은? (사용 기술, 분량, 금지 사항, 스타일)
>
> 아래 3쌍을 소리 내어 읽으며 "나쁜 쪽엔 무엇이 빠졌나"를 직접 짚어 보세요.

---

## 1쌍. 다크모드 토글 만들기

### ❌ 나쁜 프롬프트

```
다크모드 토글 만들어줘
```

**무엇이 빠졌나**: 맥락(어떤 사이트인지), 목표(버튼 1개인지 설정 화면인지), 제약(어떤 기술로) 셋 다 없습니다.
AI는 "가장 흔한 정답"을 멋대로 골라 React나 Tailwind 코드를 줄 수도 있습니다.

### ⭕ 좋은 프롬프트

```
[맥락] 순수 HTML/CSS/JavaScript로만 만든 1페이지 소개 사이트를 만들고 있어.
빌드 도구나 프레임워크는 안 쓰고, index.html 한 파일로 끝내고 싶어.

[목표] 화면 오른쪽 위에 '🌙/☀️' 버튼을 두고, 누를 때마다
밝은 테마 ↔ 어두운 테마가 번갈아 바뀌게 해줘. 배경색과 글자색이 같이 바뀌어야 해.

[제약]
- React/Vue 같은 프레임워크 금지, 바닐라 JS만.
- 색은 CSS 변수(--bg, --text)로 관리하고, body의 data-theme 속성으로 전환.
- 주석은 한국어로, 비전공자가 읽어도 이해되게 짧게.
- 새로고침해도 선택이 유지되도록 localStorage에 저장.
```

## 2쌍. 문의 폼 만들기

### ❌ 나쁜 프롬프트

```
문의 폼 좀 만들어줘. 예쁘게.
```

**무엇이 빠졌나**: '예쁘게'는 목표가 아니라 느낌입니다. 어떤 입력칸이 필요한지(맥락·목표),
어디로 데이터를 보낼지, 어떤 검증을 할지(제약)가 전부 빠졌습니다.

### ⭕ 좋은 프롬프트

```
[맥락] Supabase + Vercel로 배포하는 정적 사이트의 '문의하기' 페이지를 만드는 중이야.
프론트는 HTML/CSS/JS이고, 제출하면 Supabase 테이블 contacts에 한 줄 저장할 거야.

[목표] 이름(필수), 이메일(필수, 형식 검증), 메시지(필수, 최대 500자) 입력칸과
'보내기' 버튼이 있는 폼을 만들어줘. 보내기 누르면 '접수되었습니다' 안내가 떠야 해.

[제약]
- 브라우저 기본 검증(required, type=email, maxlength) 먼저 활용.
- Supabase 연결 시 공개되어도 되는 anon(공개) 키(sb_publishable_...)만 프론트에 둘 것.
  service_role 키는 절대 프론트에 넣지 마. (서버/시크릿 전용)
- 코드는 짧고 명확하게, 주석은 한국어.
```

## 3쌍. 사이트 느려요, 고쳐주세요

### ❌ 나쁜 프롬프트

```
내 사이트가 느린데 고쳐줘
```

**무엇이 빠졌나**: 어떤 사이트인지(맥락), '느리다'가 무엇인지(목표·측정값),
무엇을 바꿔도 되고 안 되는지(제약)가 없습니다. AI는 추측만 늘어놓게 됩니다.

### ⭕ 좋은 프롬프트

```
[맥락] Vercel에 올린 정적 사이트(index.html + style.css + 이미지 8장)야.
모바일에서 첫 화면이 뜨기까지 약 6초 걸려. 아래는 내 index.html 상단 코드야: (코드 붙여넣기)

[목표] 첫 화면 로딩을 3초 이내로 줄이고 싶어.
무엇이 원인인지 짚어주고, 우선순위가 높은 순서로 구체적 수정 방법을 알려줘.

[제약]
- 정적 사이트 구조는 유지(서버 도입 금지).
- 이미지 최적화·지연 로딩(loading="lazy") 같은 코드 한 줄 수정 위주로.
- 각 제안마다 '왜 빨라지는지' 한 문장으로 설명해줘.
```

## 정리: 한 줄 체크리스트

프롬프트를 보내기 전 스스로 물어보세요.

- [ ] **맥락** — 지금 무슨 프로젝트/파일/상황인지 적었나?
- [ ] **목표** — 결과물이 무엇이고 어떻게 동작해야 하는지 적었나?
- [ ] **제약** — 기술 스택·금지 사항·분량·말투 등 규칙을 적었나?

세 칸을 다 채우면, AI는 더 이상 "흔한 정답"으로 추측하지 않고 **내가 원하는 것**을 만들어 줍니다.
