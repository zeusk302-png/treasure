# 실습 317 — Tailwind로 반응형 카드 그리드 만들기

유틸리티 CSS(Tailwind) 클래스만으로 **화면 크기에 따라 열 수가 바뀌는 반응형 카드 그리드**를 만듭니다. 별도의 CSS 파일을 길게 쓰지 않고, HTML 태그의 `class`에 `grid`·`sm:grid-cols-2`·`lg:grid-cols-3` 같은 작은 클래스를 조립하는 것만으로 디자인을 완성하는 **유틸리티 CSS의 빠른 스타일링 방식**을 체감하는 것이 목표입니다.

> 한 줄 그림: **태그에 작은 클래스 붙이기 → 모바일에선 카드 1열 → 태블릿(sm)에선 2열 → 데스크톱(lg)에선 3열로 자동 변신 → 창 폭만 줄였다 늘려도 레이아웃이 알아서 바뀜**

> 비유: 유틸리티 CSS는 **레고 블록**입니다. `bg-white`(흰 배경), `rounded-xl`(둥근 모서리), `shadow-sm`(옅은 그림자) 같은 작은 블록을 태그 옆에 끼워 맞춰 원하는 모양을 빠르게 조립합니다. `sm:`·`lg:` 같은 접두사는 "화면이 이만큼 커지면 이 블록을 더 끼워라"라는 **조건부 블록**이고요.

## 목표
- **유틸리티 CSS를 체감한다**: CSS 파일에 선택자를 쓰는 대신, 태그의 `class`에 작은 유틸리티를 붙여 빠르게 스타일링하는 방식을 직접 써 본다.
- **반응형 그리드를 만든다**: `grid-cols-1` → `sm:grid-cols-2` → `lg:grid-cols-3`로, 화면 폭에 따라 카드 열 수가 자동으로 바뀌게 한다.
- **모바일 퍼스트를 이해한다**: 기본값을 모바일(1열)로 두고, 화면이 커질 때 `sm:`·`lg:` 규칙을 "더하는" 현대식 사고를 익힌다.
- **내용과 디자인을 분리한다**: 카드 데이터(`data.js`)와 카드 모양(`script.js`)을 나눠, 데이터만 늘리면 카드가 자동으로 늘어나게 한다.

## 따라하는 단계

### A. 일단 띄워 보기
1. 이 폴더의 `index.html`을 **더블클릭**해서 브라우저로 엽니다. (서버 설치 같은 건 필요 없습니다 — Tailwind를 CDN으로 불러오기 때문입니다.)
2. 카드 6장이 격자로 보이면 성공입니다.

### B. 반응형 확인하기 (이 실습의 핵심 체험)
3. 브라우저 **창의 가로폭을 천천히 줄였다 늘렸다** 해 봅니다.
   - 좁으면 카드가 **1열**, 중간이면 **2열**, 넓으면 **3열**로 바뀝니다.
4. `F12`를 눌러 개발자도구를 열고, 좌상단의 **모바일 아이콘**(기기 툴바)을 켜서 폰 화면으로도 확인해 봅니다.

### C. 열 수·간격 바꿔 보기
5. `index.html`에서 그리드 컨테이너의 클래스를 찾습니다.
   ```html
   <section id="cardGrid" class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-5">
   ```
   - `lg:grid-cols-3`을 `lg:grid-cols-4`로 바꾸면 넓은 화면에서 **4열**이 됩니다.
   - `gap-5`를 `gap-8`로 바꾸면 카드 사이 간격이 넓어집니다.
   - 저장 후 브라우저를 새로고침하면 바로 반영됩니다.

### D. 카드 추가해 보기
6. `data.js`를 열고 `CARDS` 목록 끝에 항목을 하나 더 추가합니다.
   ```js
   { tag: "연습", title: "내가 추가한 카드", desc: "데이터만 늘려도 카드가 늘어납니다." },
   ```
   - 새로고침하면 카드가 7장이 되고, 그리드가 알아서 줄을 채웁니다. (HTML을 손으로 복사·붙여넣기 하지 않아도 됩니다.)

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 비전공 초보를 돕는 프론트엔드 멘토야.
  Tailwind CSS(CDN 방식)만 써서, 별도 CSS 파일 없이 동작하는 한 장짜리 index.html을 만들어 줘.

  [목표] 화면 크기에 따라 열 수가 바뀌는 "반응형 카드 그리드"
  [요구사항]
  - Tailwind는 <script src="https://cdn.tailwindcss.com"></script> 로 불러올 것
  - 그리드: 모바일 1열 → sm 2열 → lg 3열 (모바일 퍼스트 순서로 grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-5)
  - 카드 한 장: 흰 배경, 둥근 모서리, 옅은 그림자, 얇은 테두리, 상단 16:9 이미지 자리, 본문에 작은 태그 배지 + 제목 + 설명
  - 가운데 정렬에 최대 폭 제한(max-w-6xl mx-auto px-4), 상단에 브랜드 색 헤더
  [매우 중요] 코드만 주지 말고, 초보가 막힐 만한 클래스(grid, sm:, lg:, mx-auto, gap 등)에는
  "무엇을 하는지 + 왜 넣었는지"를 한국어 주석으로 한 줄씩 설명해 줘. 파일 맨 위엔 요약 주석을 달아 줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html을 개선해 줘.
  1) 카드 내용을 코드에서 분리: 카드 목록을 data.js의 CARDS 배열(객체: tag, title, desc)로 빼고,
     script.js가 그 배열을 돌며 카드를 만들어 #cardGrid에 채우게 해 줘.
  2) 카드 개수를 data.js에서 늘리면 화면 카드도 자동으로 늘어나게 해 줘(HTML 복붙 없이).
  3) 마우스를 올리면 카드가 살짝 떠오르는 효과(transition hover:shadow-md hover:-translate-y-0.5)를 넣어 줘.
  [보안] 데이터의 글자를 화면에 넣을 때는 innerHTML이 아니라 textContent로 넣어 줘.
         이유(XSS 방지)도 주석으로 적어 줘.
  [설명] 추가/수정한 부분마다 "무엇 + 왜"를 한국어 주석으로 달아 줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:
  ```text
  카드 그리드가 의도대로 안 돼. 아래 상황을 단계별로 진단하고 원인 후보를 짚어 줘.
  [증상] (예: 창을 넓혀도 계속 1열이다 / 카드가 안 보인다 / 스타일이 하나도 안 먹는다)
  [내 코드] (index.html의 <head>와 #cardGrid 부분, script.js 전체를 여기 붙여넣기)
  점검해 줄 것:
  - Tailwind CDN <script>가 <head>에 제대로 들어갔는지(오타/누락)
  - 그리드 클래스 순서가 모바일 퍼스트인지(grid-cols-1 sm:grid-cols-2 lg:grid-cols-3), grid 클래스가 빠지지 않았는지
  - 반응형 접두사(sm:, lg:)가 의도한 폭에서 동작하는지
  - script.js가 data.js보다 "뒤에" 로드되는지, id="cardGrid"가 일치하는지
  원인을 짐작만 하지 말고, 한 번에 하나씩 바꿔 확인하는 순서로 알려 줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **반응형 동작 확인**: 창 가로폭을 줄였다 늘리며 카드가 **1열 → 2열 → 3열**로 바뀌는지 본다. (좁을 때 1열, 넓을 때 3열이면 정상)
- **모바일 확인**: `F12` 개발자도구의 기기 툴바(모바일 보기)에서 폰 화면일 때 **1열**로 보이는지 본다.
- **데이터 분리 확인**: `data.js`의 `CARDS`에 항목을 하나 더 추가하고 새로고침하면 **카드가 자동으로 늘어나는지** 본다.
- **스타일 적용 확인**: 카드에 흰 배경·둥근 모서리·그림자가 보이면 Tailwind가 제대로 동작하는 것이다. (전부 흰 화면에 글자만 보이면 `<head>`의 Tailwind CDN `<script>`가 빠졌거나 오타가 난 것이다.)
- **보안 확인**: `script.js`에서 카드 글자를 넣을 때 `innerHTML`이 아니라 `textContent`를 쓰는지 본다. (사용자/데이터 글자를 `innerHTML`로 넣으면 XSS 위험이라 막은 것이다.)

## 파일 구성
- `index.html` — Tailwind를 CDN으로 불러오는 데모 페이지. 반응형 그리드 컨테이너(`#cardGrid`)와 견본 카드 한 장이 들어 있다.
- `data.js` — 카드에 채울 내용(제목·설명·태그) 목록. 이 배열만 바꿔도 화면이 바뀐다.
- `script.js` — `data.js`의 목록을 돌며 카드 HTML을 만들어 그리드에 채운다. 글자는 `textContent`로 안전하게 넣는다.

> 비밀값이 없는 순수 프론트 실습이라 `.env`/API 키가 필요 없습니다. (그래서 `.env.example`도 두지 않았습니다.)
