# 실습 028 — 테두리·둥근 모서리 가진 명함 박스 만들기

`div` 박스 하나에 `width`/`height`로 크기를 정하고, `border`로 테두리를 두르고, `border-radius`로 모서리를 둥글게 깎아 **종이 명함처럼 보이는 박스**를 만듭니다. 파일은 `index.html` 하나뿐이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- `width`/`height`로 박스의 **가로·세로 크기**를 직접 정한다.
- `border`를 "굵기 · 종류 · 색" 순서로 적어 박스에 **테두리**를 두른다.
- `border-radius`의 숫자를 키우면 모서리가 더 **동그래진다**는 것을 눈으로 확인한다.

`border`는 다음처럼 세 가지를 한 줄에 적습니다.

| 자리 | 뜻 | 예시 값 |
|---|---|---|
| 첫 번째 | 테두리 **굵기** | `2px`, `4px` |
| 두 번째 | 테두리 **종류** | `solid`(실선), `dashed`(점선), `dotted`(점) |
| 세 번째 | 테두리 **색** | `#1f5fd1`, `black`, `red` |

→ 합치면 `border: 2px solid #1f5fd1;` 처럼 됩니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 흰색 명함 박스가 열립니다.
2. 박스 모양을 확인합니다.
   - 파란 **테두리**가 박스를 둘러싸고 있나요? → `border` 덕분입니다.
   - 네 **모서리가 둥글게** 깎였나요? → `border-radius` 덕분입니다.
   - 박스가 명함처럼 **가로로 긴 직사각형**인가요? → `width: 340px; height: 200px;` 덕분입니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어 `.card`의 `border-radius: 16px;`을 `border-radius: 40px;`으로 바꿔 저장합니다.
4. 브라우저로 돌아와 **새로고침(F5)** → 모서리가 더 많이 둥글어졌는지 확인합니다.
5. 이번엔 `.card`의 `border: 2px solid #1f5fd1;`을 `border: 4px dashed #e0457b;`으로 바꿔 저장 후 새로고침 → 테두리가 **굵은 분홍 점선**으로 바뀌었는지 확인합니다.
6. AI에게 시켜 보기:
   > "이 index.html의 명함 박스 안에, 이름 위에 회사 이름을 작은 글씨로 한 줄 추가해줘. 기존 디자인(테두리·둥근 모서리·크기)은 그대로 두고 글자만 추가해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 번에 다 시키지 말고 단계별로 시키면, 결과가 어디서 어떻게 만들어지는지 눈으로 따라갈 수 있어 학습에 훨씬 좋습니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 처음 배우는 비전공자를 가르치는 강사야.
  서버나 데이터베이스 없이, 더블클릭만 하면 브라우저에서 바로 열리는
  index.html 파일 하나만 만들어줘.

  목표: 종이 명함처럼 보이는 박스 하나를 화면에 보여주기.
  요구사항:
  - <div class="card"> 박스 하나를 만들고, 그 안에 이름·직함·연락처(이메일/전화)를 넣어줘.
  - CSS는 별도 파일이 아니라 <head> 안 <style>에 모아줘(한눈에 보려고).
  - .card 에는 다음을 꼭 적용해줘:
    width: 340px; height: 200px;  (명함처럼 가로로 긴 직사각형)
    border: 2px solid 파란색      (테두리: 굵기 · 종류 · 색 순서)
    border-radius: 16px           (모서리 둥글게)
    padding 으로 안쪽 여백, 흰색 배경
  - 한글이 깨지지 않게 <meta charset="UTF-8">, 모바일 대응 viewport 메타태그도 넣어줘.
  코드만 주지 말고, 각 줄이 무엇을 하고 왜 넣었는지 한국어 주석으로 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 index.html을 이어서 개선해줘. 기존 디자인(테두리·둥근 모서리·크기)은
  그대로 두고 아래만 더해줘:
  1. 명함 박스 안, 이름 위에 회사 이름을 작은 회색 글씨로 한 줄 추가.
  2. border 의 굵기/종류/색을 바꿔 점선(dashed) 버전도 주석으로 같이 보여줘
     (예: border: 4px dashed 분홍색 — 적용해보려면 이 줄로 바꾸면 됨, 식으로).
  3. border-radius 를 박스 높이의 절반(100px)으로 주면 양옆이 완전히 둥근
     '알약(캡슐)' 모양이 된다는 걸 주석으로 설명해줘.
  바꾼 부분이 어디인지, 왜 그렇게 했는지 한국어 주석으로 짚어줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  명함 박스를 만들었는데 모서리가 안 둥글거나 테두리가 안 보여. 아래 내 코드를 붙여넣을게.
  무엇이 잘못됐는지 한 줄씩 짚어주고, 비전공자가 이해하게 풀어서 설명해줘.
  특히 이런 것들을 점검해줘:
  - border 를 '굵기 종류 색' 순서로 제대로 적었는지 (예: 2px solid blue)
  - border-radius 에 단위(px)를 빠뜨리지 않았는지
  - .card 라는 class 이름이 HTML(class="card")과 CSS(.card)에서 똑같이 맞는지
  - width/height 가 너무 작아서 글자에 가려 안 보이는 건 아닌지
  고친 코드와, 무엇을 왜 고쳤는지 함께 알려줘.

  [여기에 내 index.html 코드 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면, 결과물을 그냥 받기만 하지 않고 직접 판단할 수 있게 되어 학습에 좋습니다.

## 검증법
- 박스의 **네 모서리가 직각이 아니라 둥근가?** → `border-radius`가 적용된 증거.
- 박스 둘레에 색이 들어간 **테두리 선이 보이는가?** → `border`가 적용된 증거.
- 브라우저에서 `F12 → Elements`로 명함 박스를 클릭하면, 오른쪽 스타일 패널에 `width`, `height`, `border`, `border-radius` 값이 코드와 똑같이 적혀 있는지 확인합니다.
- (선택) `border-radius`를 박스 높이의 절반인 `100px`으로 주면 양옆이 완전히 둥근 **알약(캡슐) 모양**이 됩니다. 한 번 시험해 보세요.
