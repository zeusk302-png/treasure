# 실습 028 — 테두리·둥근 모서리 가진 명함 박스 만들기

`div` 박스 하나에 `width`/`height`로 크기를 정하고, `border`로 테두리를 두르고, `border-radius`로 모서리를 둥글게 깎아 **종이 명함처럼 보이는 박스**를 만듭니다. 파일은 `index.html` 하나뿐이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- `width`/`height`로 박스의 **가로·세로 크기**를 직접 정한다.
- `border`를 "굵기 · 종류 · 색" 순서로 적어 박스에 **테두리**를 두른다.
- `border-radius`의 숫자를 키우면 모서리가 더 **동그래진다**는 것을 눈으로 확인한다.

`border`는 다음처럼 세 가지를 한 줄에 적습니다.

| 자리 | 뜻 | 예시 값 |
|---|---|---|
| 첫 번째 | 테두리 **굵기** | `2px`, `4px` |
| 두 번째 | 테두리 **종류** | `solid`(실선), `dashed`(점선), `dotted`(점) |
| 세 번째 | 테두리 **색** | `#1f5fd1`, `black`, `red` |

→ 합치면 `border: 2px solid #1f5fd1;` 처럼 됩니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 흰색 명함 박스가 열립니다.
2. 박스 모양을 확인합니다.
   - 파란 **테두리**가 박스를 둘러싸고 있나요? → `border` 덕분입니다.
   - 네 **모서리가 둥글게** 깎였나요? → `border-radius` 덕분입니다.
   - 박스가 명함처럼 **가로로 긴 직사각형**인가요? → `width: 340px; height: 200px;` 덕분입니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어 `.card`의 `border-radius: 16px;`을 `border-radius: 40px;`으로 바꿔 저장합니다.
4. 브라우저로 돌아와 **새로고침(F5)** → 모서리가 더 많이 둥글어졌는지 확인합니다.
5. 이번엔 `.card`의 `border: 2px solid #1f5fd1;`을 `border: 4px dashed #e0457b;`으로 바꿔 저장 후 새로고침 → 테두리가 **굵은 분홍 점선**으로 바뀌었는지 확인합니다.
6. AI에게 시켜 보기:
   > "이 index.html의 명함 박스 안에, 이름 위에 회사 이름을 작은 글씨로 한 줄 추가해줘. 기존 디자인(테두리·둥근 모서리·크기)은 그대로 두고 글자만 추가해줘."

## 검증법
- 박스의 **네 모서리가 직각이 아니라 둥근가?** → `border-radius`가 적용된 증거.
- 박스 둘레에 색이 들어간 **테두리 선이 보이는가?** → `border`가 적용된 증거.
- 브라우저에서 `F12 → Elements`로 명함 박스를 클릭하면, 오른쪽 스타일 패널에 `width`, `height`, `border`, `border-radius` 값이 코드와 똑같이 적혀 있는지 확인합니다.
- (선택) `border-radius`를 박스 높이의 절반인 `100px`으로 주면 양옆이 완전히 둥근 **알약(캡슐) 모양**이 됩니다. 한 번 시험해 보세요.
