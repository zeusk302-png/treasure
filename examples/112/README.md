# 실습 112 — 간단 가계부 v1: 수입·지출 입력하고 합계 계산하기

내용·금액·종류(수입/지출)를 입력하면 목록에 쌓이고, **총수입·총지출·잔액이 자동으로 계산**되는 작은 가계부 앱입니다.
입력한 기록은 `localStorage`에 저장되므로 새로고침해도 사라지지 않습니다.
"여러 개의 데이터(객체 배열)를 모아 두고, 그걸 **계산해서** 보여 준다"는 감각을 잡는 게 목표예요.

## 목표
- 데이터를 객체 배열로 모은다. (예: `{ desc: "점심값", amount: 8000, type: "expense" }`)
- `reduce`로 배열의 값을 **하나로 합쳐** 총수입·총지출·잔액을 계산한다.
- `filter`로 "수입만" 또는 "특정 항목 빼고"처럼 배열에서 원하는 것만 골라낸다.
- `JSON.stringify` / `JSON.parse`로 배열을 글자로 바꿔 `localStorage`에 저장·복원한다.

> 참고: `localStorage`는 "내 브라우저에만" 저장됩니다. 다른 기기·다른 사람과 공유하려면
> 다음 단계인 Supabase 같은 진짜 데이터베이스가 필요합니다. (실습 113~ 이후에서 다룹니다)

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. **내용**(예: 용돈), **금액**(예: 50000), **종류**(수입)를 고르고 **[추가]** 를 누른다 → 목록과 합계가 바뀐다.
3. 이번엔 **지출**도 넣어 본다. (예: 점심값 / 8000 / 지출) → 총지출이 올라가고 잔액이 줄어드는지 본다.
4. 잘못 넣은 항목 오른쪽의 **✕** 버튼을 눌러 삭제한다 → 합계가 다시 계산되는지 확인한다.
5. 키보드 **F5**(새로고침)를 눌러도 기록이 그대로 남아 있는지 확인한다.
6. **[전체 지우기]** 로 모두 비우고, 새로고침해서 정말 비워졌는지 본다.
7. AI에게 시켜 보기:
   > "이 index.html의 각 항목에 '날짜'도 함께 저장하고 목록에 같이 보여 주게 고쳐줘. 입력 폼에는 `<input type='date'>`를 추가해줘."

## 검증법
- 수입 5만 원, 지출 8천 원을 넣으면 **총수입 50,000원 / 총지출 8,000원 / 잔액 42,000원**이 표시되는가?
- 항목을 **삭제**하면 합계와 잔액이 즉시 다시 계산되는가?
- **새로고침(F5)** 해도 기록이 그대로 남아 있는가?
- 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage**에 `ledgerItems` 항목이 생겼는가? (값이 `[{...}]` 모양인지 확인)
- 내용이 비었거나 금액이 0 이하일 때 **[추가]** 를 누르면 경고가 뜨고 추가되지 않는가?

## 핵심 코드 한 줄로 보기
```js
// 수입만 골라(filter) 금액을 모두 합치기(reduce)
const totalIncome = items
  .filter(item => item.type === "income")
  .reduce((sum, item) => sum + item.amount, 0);

// 배열을 글자로 바꿔 저장 / 다시 배열로 꺼내기
localStorage.setItem("ledgerItems", JSON.stringify(items));
const items = JSON.parse(localStorage.getItem("ledgerItems"));
```
