# 실습 106 — 이름을 localStorage에 저장하고 새로고침해도 남기기

입력칸에 친 이름을 브라우저에 저장해서, **페이지를 새로고침해도 그 이름이 사라지지 않게** 만드는 실습입니다.
"브라우저 안에 데이터가 저장된다"는 감각을 처음 잡는 게 목표예요.

## 목표
- `localStorage.setItem`으로 값을 **저장**하고, `localStorage.getItem`으로 다시 **꺼내는** 흐름을 익힌다.
- 새로고침(F5)이나 창을 껐다 켜도 데이터가 남는다는 걸 눈으로 확인한다.
- 서버나 데이터베이스 없이도, 내 브라우저 안에 작은 메모장이 있다는 걸 이해한다.

> 참고: localStorage는 "내 브라우저에만" 저장됩니다. 다른 사람·다른 기기에도 보여 주려면
> 다음 단계인 Supabase 같은 진짜 데이터베이스가 필요합니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다.
2. 입력칸에 이름을 적고 **[저장]** 버튼을 누른다 → 아래에 "○○님, 안녕하세요!" 가 뜬다.
3. 키보드 **F5**(새로고침)를 누른다 → 방금 적은 이름이 그대로 남아 있는지 확인한다.
4. 브라우저 창을 완전히 닫았다가 다시 `index.html`을 열어 본다 → 그래도 이름이 남아 있다.
5. **[지우기]** 버튼을 눌러 저장된 값을 삭제하고, 다시 새로고침해서 정말 비워졌는지 확인한다.
6. AI에게 시켜 보기:
   > "이 index.html에 이름과 함께 '좋아하는 색'도 localStorage에 저장하는 입력칸을 추가해줘. 키 이름은 favoriteColor로."

## 검증법
- 이름 저장 후 **새로고침**해도 인사말이 그대로 보이는가?
- 브라우저 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage**에 `savedName`이라는 항목이 생겼는가?
- **[지우기]** 를 누른 뒤 새로고침하면 "아직 저장된 이름이 없어요." 로 바뀌는가?
- 빈 칸에서 [저장]을 누르면 "이름을 입력해 주세요." 경고가 뜨는가?

## 핵심 코드 한 줄로 보기
```js
localStorage.setItem("savedName", "홍길동"); // 저장
localStorage.getItem("savedName");           // 꺼내기 → "홍길동"
localStorage.removeItem("savedName");        // 지우기
```
