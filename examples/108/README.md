# 실습 108 — 방문 횟수 카운터 만들기

이 페이지에 들어올(또는 새로고침할) 때마다 숫자가 **1씩 올라가고**, "○번째 방문입니다!" 가 표시되는 실습입니다.
브라우저에 **숫자**를 저장하고 다시 꺼내 계산하는 과정에서, 초보자가 가장 많이 걸려 넘어지는 **형변환(Number / parseInt)** 을 배우는 게 목표예요.

## 목표
- `localStorage`에 저장한 값은 숫자처럼 보여도 사실 **글자(문자열)** 라는 점을 이해한다.
- `Number(...)` 또는 `parseInt(...)` 로 **글자를 숫자로 바꿔야(형변환)** 제대로 더하기가 된다는 걸 직접 확인한다.
- 페이지를 새로고침/재방문해도 숫자가 이어서 올라가는, "기억하는 페이지"를 만든다.

> 왜 형변환이 필요할까요?
> 저장된 값을 바꾸지 않고 그냥 `"3" + 1` 을 하면 `4`가 아니라 `"31"` 이 됩니다. (글자끼리 이어 붙음)
> `Number("3") + 1` 로 먼저 숫자로 바꿔야 비로소 `4`가 나옵니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해서 브라우저로 연다 → "1번째 방문입니다!" 가 보인다.
2. 키보드 **F5**(새로고침)를 눌러 본다 → 숫자가 2, 3, 4 … 로 계속 올라가는지 확인한다.
3. 브라우저 창을 완전히 닫았다가 다시 `index.html`을 열어 본다 → 마지막 숫자에 이어서 올라간다.
4. **[기록 초기화]** 버튼을 누른 뒤 새로고침한다 → 다시 "1번째 방문입니다!" 부터 시작한다.
5. 코드 안의 `let count = Number(saved) || 0;` 에서 `Number(...)` 를 잠깐 지워 보고(`let count = saved || 0;`) 새로고침해 본다 → 숫자 대신 `"11"`, `"111"` 처럼 글자가 이어 붙는 사고를 직접 목격한다. (확인했으면 다시 `Number`로 되돌리기)
6. AI에게 시켜 보기:
   > "이 index.html에 '마지막 방문 시각'도 localStorage에 함께 저장해서 화면에 보여 주는 기능을 추가해줘."

## 🤖 바이브코딩 프롬프트
이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text

  요구사항:
  - 페이지를 새로고침하거나 다시 방문할 때마다 숫자가 1씩 올라간다.
  - 화면 가운데에 큰 숫자와 "○번째 방문입니다!" 안내 문구를 보여준다.
  - 방문 횟수는 localStorage에 "visitCount" 라는 키로 저장해서, 창을 닫았다 다시 열어도 이어진다.
  제약:
  - 외부 라이브러리/프레임워크 없이 순수 HTML/CSS/JS만 사용.
  ```

  ```text

  1) "기록 초기화" 버튼: 누르면 visitCount를 지우고 다음 새로고침 때 1번부터 다시 센다.
  2) "마지막 방문 시각"도 localStorage에 함께 저장해서 화면에 보여준다. (예: 마지막 방문: 2026-06-19 14:30)
  3) 방문 횟수가 10의 배수가 될 때마다 "축하해요! ○번째 방문!" 같은 특별 메시지를 보여준다.
  각 코드가 무엇을 하고 왜 그렇게 했는지 한국어 주석으로 설명해줘.
  ```

  ```text

  "11", "111" 처럼 글자가 옆으로 이어 붙어. 왜 이런지 한 줄씩 설명해주고,
  어디를 어떻게 고쳐야 하는지 알려줘. (내 코드를 아래에 붙여넣을게)

  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다. 특히 이 실습은 형변환(Number/parseInt)이 핵심이니, "형변환을 왜 하는지 주석으로 강조해줘"라고 시키면 더 좋아요.

## 검증법
- 새로고침할 때마다 큰 숫자가 정확히 **1씩** 증가하는가? (한 번에 2씩 뛰거나 글자가 이어 붙지 않는가)
- 브라우저 개발자도구(F12) → **Application(애플리케이션) 탭 → Local Storage** 에 `visitCount` 항목이 생겼고, 값이 새로고침마다 올라가는가?
- **[기록 초기화]** 후 새로고침하면 다시 1부터 세는가?
- 창을 닫았다 다시 열어도 숫자가 0으로 리셋되지 않고 이어지는가?

## 핵심 코드 한 줄로 보기
```js
const saved = localStorage.getItem("visitCount"); // 저장된 "글자" 꺼내기 (없으면 null)
let count = Number(saved) || 0;                    // ★ 글자 → 숫자로 형변환 (없으면 0)
count = count + 1;                                 // 이번 방문이므로 +1
localStorage.setItem("visitCount", count);         // 늘어난 값을 다시 저장
```
