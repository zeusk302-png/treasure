# 스톱워치 만들기 (시작/정지/리셋)

운동 시간, 공부 시간을 잴 때 쓰는 그 스톱워치를 직접 만듭니다. **시작**을 누르면 시간이 흐르고, **정지**하면 멈추며(다시 시작하면 이어서 잼), **리셋**하면 0으로 돌아갑니다. 1/100초(0.01초)까지 표시합니다. 별도 설치나 서버 없이 `index.html`을 더블클릭하면 바로 동작합니다.

이번 실습의 진짜 핵심은 "타이머를 켜고 끄는 **상태 관리**"입니다. 지금 도는 중인지 멈춰 있는지, 정지했다 다시 시작하면 어떻게 이어서 재는지를 변수로 다뤄 봅니다.

## 목표

- `setInterval`로 **주기적으로 화면을 다시 그리고**, `clearInterval`로 **멈추는** 짝을 익힌다.
- 타이머가 **도는 중인지 / 멈춰 있는지** 상태를 변수 하나(`timerId`)로 판단하는 법을 익힌다.
- 경과 시간을 **"흐른 시간을 누적"이 아니라 `현재시각 - 시작시각`으로 계산**하는 더 정확한 방식을 이해한다.
- 정지했다 다시 시작할 때 **이전 시간에 이어서 재는** 누적(accumulated) 패턴을 익힌다.
- 밀리초(ms)를 사람이 읽는 **`분:초.1/100초`** 형식으로 바꾸는 법을 익힌다.

> 핵심 개념: `setInterval`/`clearInterval`(켜고 끄기) + `timerId`로 상태 판단 + `Date.now()`로 경과시간 계산

## 따라하는 단계

1. **세 개의 파일을 한 폴더에 둔다.** `index.html`, `style.css`, `script.js`를 같은 폴더(`081`)에 둡니다. HTML이 나머지 둘을 불러옵니다.
2. **화면을 만든다.** `index.html`에는 숫자판 `<div id="display">00:00.00</div>`와 버튼 두 개(`시작/정지` 겸용 버튼, `리셋` 버튼)만 있습니다. 나머지는 전부 `script.js`가 움직입니다.
3. **상태 변수 3개를 이해한다.** `script.js` 맨 위의 `timerId`(돌고 있으면 숫자, 멈췄으면 `null`), `startTime`(이번에 시작 누른 시각), `accumulated`(이전까지 모아둔 시간)입니다. 이 셋이 스톱워치의 전부입니다.
4. **경과 시간 계산법을 본다.** `getElapsed()`는 동작 중이면 `accumulated + (Date.now() - startTime)`을, 멈춰 있으면 `accumulated`를 돌려줍니다. "1초마다 +1" 방식이 아니라 **진짜 시계(`Date.now()`)와의 차이**로 재기 때문에 더 정확합니다.
5. **시작 동작을 만든다.** `start()`는 `startTime`에 지금 시각을 기록하고 `setInterval(render, 10)`으로 10ms마다 숫자판을 다시 그립니다. 버튼 글자를 "정지"로 바꾸고 빨간색으로 만듭니다.
6. **정지 동작을 만든다.** `stop()`은 이번 구간에서 흐른 시간을 `accumulated`에 더하고 `clearInterval`로 갱신을 멈춘 뒤, `timerId = null`로 "멈춤"을 표시합니다. 이 누적 덕분에 다시 시작하면 이어서 잽니다.
7. **리셋 동작을 만든다.** `reset()`은 `accumulated`를 0으로 되돌리고 화면을 `00:00.00`으로 그립니다.
8. **버튼을 연결한다.** 시작/정지 버튼은 클릭 시 `timerId`가 `null`이면 `start()`, 아니면 `stop()`을 부릅니다. 한 버튼이 상태에 따라 두 일을 합니다.
9. **시간 형식을 만든다.** `format(ms)`가 밀리초를 분·초·1/100초로 나누고 `padStart(2, "0")`으로 두 자리(`05`처럼)로 맞춥니다.

## 검증법

1. `index.html`을 더블클릭해 브라우저로 엽니다. (별도 서버 필요 없음)
2. **처음 상태**: 숫자판이 `00:00.00`이고, "리셋" 버튼은 흐리게(눌리지 않게) 되어 있어야 합니다.
3. **시작**: "시작"을 누르면 버튼이 "정지"(빨간색)로 바뀌고, 숫자가 빠르게(1/100초 자리가 휙휙) 올라가야 합니다.
4. **정지**: "정지"를 누르면 숫자가 그 자리에 멈추고, 버튼이 다시 "시작"(초록색)으로 바뀌며, "리셋"이 눌리게 활성화됩니다.
5. **이어서 재기**: 멈춘 상태에서 "시작"을 다시 누르면, **0이 아니라 멈췄던 값에서 이어서** 올라가야 합니다.
6. **리셋**: 멈춘 상태에서 "리셋"을 누르면 `00:00.00`으로 돌아가고 "리셋"이 다시 흐려져야 합니다.
7. **정확도 확인**: 스마트폰 스톱워치와 나란히 10초쯤 재 보세요. 큰 오차 없이 비슷해야 합니다. (`setInterval` 오차가 누적되지 않는 이유는 `Date.now()`로 재기 때문입니다.)
8. (선택) 개발자도구(F12) Console 탭에 빨간 오류가 없는지 봅니다.

## 직접 바꿔보기

- `script.js`의 `setInterval(render, 10)`에서 `10`을 `100`으로 바꾸면 1/100초 자리가 덜 매끄럽게 움직입니다. (시간 계산 자체는 그대로 정확합니다 — 화면만 덜 자주 갱신됨)
- `format()`에서 시간 형식을 바꿔 보세요. 예를 들어 시(hour)까지 보여주려면 `minutes`를 60으로 또 나누면 됩니다.
- "랩(lap) 타임" 버튼을 추가해 보세요: 누른 순간의 `getElapsed()` 값을 목록(`<ul>`)에 하나씩 추가하면 구간 기록기가 됩니다.
