# 101. 검색창에 입력하면 목록이 즉시 걸러지는 필터 만들기

검색창에 글자를 적으면, 아래에 늘어선 맛집 목록이 타이핑하는 즉시 걸러집니다. 검색어가 들어간 가게만 화면에 남고 나머지는 사라집니다. 쇼핑몰 상품 검색, 연락처 찾기처럼 어디서나 쓰이는 "실시간 검색"의 기본 원리를 직접 만들어 봅니다.

## 목표

- `input` 이벤트로 "타이핑할 때마다" 코드를 실행하는 법을 익힙니다.
- 배열의 `filter`로 "조건에 맞는 것만 골라내기"를 경험합니다.
- 문자열의 `includes()`로 "검색어가 들어 있는지" 참/거짓을 판단합니다.
- 걸러진 결과에 따라 목록을 보였다 숨겼다 하며 화면을 즉시 바꿔봅니다.

## 따라하는 단계

1. `101` 폴더 안에 `index.html`, `style.css`, `script.js` 세 파일이 같은 위치에 있는지 확인합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 검색창과 맛집 8곳 목록, 오른쪽에 "8곳"이라는 개수가 보입니다.
3. 검색창에 `김밥`을 적어 봅니다. "행복김밥"과 "한입분식"처럼 김밥을 다루는 곳만 남고 개수가 줄어드는지 봅니다.
4. 검색창을 모두 지웁니다. 목록 8곳이 다시 전부 나타나는지 확인합니다.
5. `분식`, `카페`, `치킨`처럼 메뉴나 종류로도 검색해 봅니다. 가게 이름이 아니어도 걸러집니다.
6. `zzz`처럼 어디에도 없는 글자를 적어 "검색 결과가 없습니다" 안내가 뜨는지 확인합니다.
7. `script.js`를 열어 `searchInput.addEventListener("input", ...)`, `filter`, `includes()` 부분의 주석을 천천히 읽어 봅니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 한 단계씩 시키고, 만들어진 결과를 위 "검증법"으로 직접 확인하세요.

- **1단계(뼈대 만들기)** 프롬프트:

  ```text
  너는 HTML/CSS/JavaScript를 가르치는 친절한 선생님이야. 비전공자가 이해할 수 있게 만들어줘.
  목표: "맛집 목록을 실시간으로 걸러내는 검색 필터" 한 페이지를 index.html, style.css, script.js 세 파일로 만들어줘.
  요구사항:
  - 상단에 검색 입력칸(type="search") 하나와 "지금 몇 곳이 보이는지" 표시하는 개수 영역.
  - 그 아래에 맛집 8곳을 ul > li 목록으로 HTML에 직접 적어둬. 각 li에는 가게 이름(strong)과 분류/메뉴 태그(span).
  - 각 li에 data-keywords 속성을 넣어 가게 이름 + 종류 + 대표 메뉴 단어들을 한 줄로 모아둬(검색에 쓸 거야).
  제약:
  - 외부 라이브러리(jQuery 등) 없이 순수 JavaScript만 사용.
  - 카드 형태로 가운데 정렬된 깔끔한 스타일.
  - 아직 검색 동작(JS 로직)은 넣지 말고 화면 구조와 스타일까지만 만들어줘.
  코드만 주지 말고 각 부분이 무엇이고 왜 그렇게 했는지 한국어 주석으로 한 줄씩 설명해줘.
  ```

- **2단계(기능 추가/개선)** 프롬프트:

  ```text
  방금 만든 검색 필터에 실시간 걸러내기 기능을 추가해줘.
  - 검색창에 input 이벤트를 달아서, 글자를 칠 때마다(타이핑/붙여넣기/삭제) 즉시 목록을 다시 거르게 해줘.
  - 입력값은 앞뒤 공백을 없애고 소문자로 통일해서 'Cafe'와 'cafe'를 같게 취급해줘.
  - 각 li의 data-keywords 안에 검색어가 includes()로 포함되면 보이고, 아니면 hidden 처리해줘.
  - 지금 보이는 가게 개수를 "N곳"으로 표시하고, 검색어를 바꿀 때마다 갱신해줘.
  - 결과가 0개면 "검색 결과가 없습니다" 안내문을 보여주고, 결과가 있으면 숨겨줘.
  - 처음 화면이 뜰 때도 전체 개수가 바로 보이게 해줘.
  왜 filter와 includes()를 쓰는지, 왜 소문자로 맞추는지 주석으로 설명해줘.
  ```

- **막혔을 때(디버깅)** 프롬프트:

  ```text
  검색창에 글자를 쳐도 목록이 전혀 걸러지지 않아. 아래 내 코드와 콘솔에 뜬 에러를 붙여넣을게.
  무엇이 문제인지 한 가지씩 단계별로 짚어주고, 비전공자가 이해하게 풀어서 설명해줘.
  특히 이런 부분을 확인해줘:
  - script.js가 index.html에서 제대로 불러와졌는지(<script src> 위치).
  - getElementById로 가져온 요소의 id가 HTML의 id와 정확히 같은지(대소문자 포함).
  - data-keywords 값을 item.dataset.keywords로 잘 읽고 있는지.
  고친 코드와 함께 "왜 이게 문제였는지"를 한 줄씩 주석으로 달아줘.

  [여기에 내 코드와 에러 메시지를 붙여넣기]
  ```

> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- 빈 칸일 때: 목록 8곳이 모두 보이고 개수가 "8곳"으로 표시된다.
- `김밥` 입력: "행복김밥", "한입분식"만 남고 개수가 "2곳"이 된다.
- `카페` 입력: "향기카페" 한 곳만 남고 "1곳"이 된다.
- 대문자/소문자 상관없이 `cafe`나 `CAFE`처럼 적어도 같은 결과가 나온다(코드에서 소문자로 맞춰주기 때문).
- `zzz`처럼 없는 글자: 목록이 모두 사라지고 "검색 결과가 없습니다" 안내가 뜬다.
- 글자를 모두 지우면 다시 8곳 전부로 돌아온다.

## 더 알아두기

- 지금은 목록이 HTML에 미리 적혀 있습니다. 다음 단계에서는 이 목록을 Supabase 같은 데이터베이스에서 불러와 화면에 그린 뒤 똑같이 필터링할 수 있습니다.
- 항목이 수천 개로 많아지면, 글자를 칠 때마다 매번 거르는 대신 "타이핑이 잠깐 멈추면 한 번만 거르기(디바운스)"를 쓰면 더 부드럽습니다. 기본 원리는 여기서 익힌 그대로입니다.
- 검색용 단어를 `data-keywords`에 따로 모아둔 이유: 가게 이름뿐 아니라 메뉴·종류까지 한곳에 적어두면, 그 안 어디에 들어 있어도 `includes()`로 한 번에 찾을 수 있기 때문입니다.
