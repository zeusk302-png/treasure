# 실습 233 — 재사용 프롬프트 템플릿 라이브러리(3종) 정리하기

자주 쓰는 AI 지시를 매번 새로 짜지 말고, **빈칸만 채워 복붙하는 템플릿**으로 만들어 두는 실습입니다. 코드는 없고, `prompts/` 폴더 안에 세 가지 상황별 템플릿(마크다운 글)이 들어 있습니다. AI에게 더 정확하고 안전하게 일을 시키는 "말 거는 법"을 손에 익히는 게 목적입니다.

이 폴더에 담긴 3종 템플릿은 다음과 같습니다.

| 파일 | 이름 | 언제 쓰나 |
|---|---|---|
| `prompts/01_검증요구_template.md` | 검증 요구 | AI가 "완벽합니다 / 잘 됩니다"라고 단정할 때, 증거를 가져오게 되받아칠 때 |
| `prompts/02_비판리뷰_template.md` | 비판 리뷰 | 내(또는 AI) 코드·글을 칭찬 빼고 깐깐하게 두들겨 보고 싶을 때 |
| `prompts/03_선제경고_template.md` | 선제 경고 | 뭔가 만들기 **시작하기 전에**, 함정·비용·되돌리기 어려운 결정을 먼저 듣고 싶을 때 |

## 목표
- 자주 쓰는 AI 지시를 **빈칸형 템플릿**으로 만들어, 상황이 올 때마다 복붙해 재사용하는 습관을 들인다.
- 세 가지 상황(검증 요구 / 비판 리뷰 / 선제 경고)에서 각각 어떤 식으로 AI에게 지시하면 더 정확하고 안전한 답이 나오는지 체감한다.
- 템플릿의 `[[...]]` 빈칸을 내 상황에 맞게 바꿔 끼우는 연습을 한다.

## 따라하는 단계
1. `prompts/` 폴더를 열어 세 개의 `.md` 파일을 메모장(또는 VS Code)으로 하나씩 읽어 봅니다. 각 파일 맨 위의 "언제 쓰나요?" 설명부터 봅니다.
2. 파일 안의 **"빈칸 채우는 법"** 항목을 보고, `[[무엇]]`, `[[성공의 기준]]` 같은 `[[...]]` 칸에 무엇을 넣어야 하는지 확인합니다.
3. **"복붙용 프롬프트"** 안의 텍스트를 통째로 복사한 뒤, `[[...]]` 칸만 내 실제 상황에 맞게 바꿔 채웁니다. (예: `[[무엇]]` → "방금 받은 회원가입 폼 코드")
4. 채운 프롬프트를 AI(Claude 등)에 붙여넣고, 답이 평소보다 더 구체적이고 깐깐하게 나오는지 비교해 봅니다.
5. 세 템플릿을 모두 한 번씩 직접 써 보고, 내가 자주 쓰는 다른 상황이 있다면 같은 형식(언제 쓰나 → 빈칸 → 복붙용 프롬프트)으로 4번째 템플릿을 추가로 만들어 봅니다.
6. 안전 수칙: 어떤 템플릿에도 **진짜 키·토큰·웹훅 주소를 적지 마세요.** 항상 `YOUR_API_KEY` 같은 자리표시자로 둡니다.

## 검증법
- `prompts/` 폴더 안에 템플릿 파일이 **3개** 들어 있는가? (검증 요구 / 비판 리뷰 / 선제 경고)
- 각 템플릿에 **"언제 쓰나요?" → "빈칸 채우는 법" → "복붙용 프롬프트"** 세 부분이 모두 들어 있는가?
- 복붙용 프롬프트에 `[[...]]` 형태의 **빈칸**이 남아 있어, 내 상황만 바꿔 끼우면 바로 쓸 수 있는가?
- 실제로 한 템플릿을 골라 빈칸을 채워 AI에 넣었을 때, 칭찬·단정 대신 **증거·지적·경고** 같은 더 단단한 답이 돌아오는가?
