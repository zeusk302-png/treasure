# AI가 내 Supabase를 직접 조회한 결과 (예시 캡처)

MCP 연결이 제대로 됐다면, Claude에게 **한국어로 부탁만 해도** Claude가 직접 내 DB에
SQL을 날려 결과를 가져옵니다. 아래는 그때 화면에 나와야 하는 모습의 **예시**입니다.
(실제 값은 내 `guestbook` 테이블에 쌓인 데이터에 따라 달라집니다.)

---

## 내가 Claude에게 한 말

> 방명록 테이블 최근 5건 보여줘. 이름이랑 메시지, 작성시간만.

## Claude가 한 일 (도구 호출)

Claude는 사람이 SQL을 안 알려줘도, 연결된 Supabase MCP의 `execute_sql` 도구를 골라
아래 같은 쿼리를 **스스로 만들어** 실행합니다. (이 쿼리는 Claude가 보여 준 것)

```sql
select name, message, created_at
from guestbook
order by created_at desc
limit 5;
```

> MCP 도구를 처음 부를 때, Claude Code는 "supabase 서버의 execute_sql 도구를
> 실행해도 될까요?"라고 **한 번 승인**을 묻습니다. "허용"을 눌러야 실행됩니다.

## Claude가 가져온 결과

| name | message | created_at |
|---|---|---|
| 김민지 | 사이트 잘 봤어요! 디자인 깔끔하네요 | 2026-06-17 21:14:02 |
| 이준호 | 방명록 기능 신기하다 ㅎㅎ | 2026-06-17 18:40:55 |
| 박서연 | 다음 모임 언제예요? | 2026-06-16 09:22:31 |
| 최우진 | 응원합니다 | 2026-06-15 13:05:10 |
| 정하늘 | 처음 와봐요 반가워요 | 2026-06-14 20:51:47 |

> 위 표가 채팅창에 뜨면 성공입니다. **사람이 Supabase 대시보드에 직접 들어가지 않고,
> Claude가 내 DB를 직접 읽어 온 것**입니다.

---

## 이어서 해볼 수 있는 부탁들 (모두 읽기 전용)

- "guestbook 테이블에 몇 건 있어?" → Claude가 `select count(*)` 를 알아서 만들어 실행
- "오늘 작성된 글만 보여줘" → 날짜 조건을 Claude가 직접 붙임
- "이 프로젝트에 어떤 테이블들이 있어?" → MCP의 `list_tables` 도구로 스키마를 훑어 줌

## 주의 (이 실습은 일부러 "읽기 전용"으로 막아 둠)

`.mcp.json` 에 `--read-only` 를 넣었기 때문에, "방명록 다 지워줘" 같은
**삭제·수정 요청은 거부**되어야 정상입니다. AI에게 DB 쓰기 권한까지 주는 것은
훨씬 위험하므로, 처음에는 읽기 전용으로만 연결하는 것이 안전합니다.
