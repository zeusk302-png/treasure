# 디지털 시계 만들기 (실시간 시:분:초)

화면에 "지금 몇 시 몇 분 몇 초"를 보여주고, **1초마다 스스로 갱신**되는 디지털 시계를 만들어 봅니다.
컴퓨터에서 "지금 시각"을 꺼내오는 `Date` 객체와, "일정 시간마다 반복 실행"하는 `setInterval`을 처음 다뤄 보는 실습입니다.

## 목표

- 컴퓨터가 알고 있는 "지금 이 순간"을 꺼내오는 법 익히기 (`new Date()`).
- 그 안에서 시·분·초를 따로따로 꺼내는 법 익히기 (`getHours`, `getMinutes`, `getSeconds`).
- **1초마다 같은 동작을 자동으로 반복**시키는 법 익히기 (`setInterval`).
- 9를 "09"처럼 항상 두 자리로 보이게 다듬어, 시계가 보기 좋게 나오도록 만들기.

## 따라하는 단계

1. 이 폴더의 `index.html` 파일을 **더블클릭**해서 웹 브라우저(크롬 등)로 엽니다. (인터넷 연결이 필요 없습니다.)
2. 화면 가운데에 큰 숫자로 **현재 시각(시:분:초)** 이 뜨고, 그 아래에 **오늘 날짜와 요일**이 보이는지 확인합니다.
3. 가만히 1초만 기다려 봅니다. → **초 숫자가 1씩 올라가면** 시계가 살아 움직이는 것입니다. 성공입니다.
4. 코드를 직접 살펴봅니다.
   - `index.html`: 시각을 보여줄 `<div id="clock">`, 날짜를 보여줄 `<div id="date">`가 있고, 맨 아래에서 `script.js`를 불러옵니다.
   - `script.js`:
     - `new Date()`로 "지금 이 순간"을 가져옵니다.
     - `getHours()` / `getMinutes()` / `getSeconds()`로 시·분·초를 꺼냅니다.
     - `twoDigits()` 함수로 한 자리 숫자(예: 9) 앞에 0을 붙여 "09"로 만듭니다.
     - 맨 아래 `setInterval(showTime, 1000)`이 **1초(1000ms)마다 시각을 다시 그리는** 핵심 한 줄입니다.
5. (실험 1) `script.js`의 `setInterval(showTime, 1000)`에서 `1000`을 `100`으로 바꾼 뒤 저장하고, 브라우저를 **새로고침(F5)** 합니다. → 시계가 0.1초마다 갱신되어 훨씬 자주 깜빡이는 것을 볼 수 있습니다. 확인했으면 다시 `1000`으로 되돌리세요.
6. (실험 2) 시·분·초 외에 더 표시해 보고 싶다면 AI에게 이렇게 시켜 보세요.
   > "이 `script.js`에서 시각을 '오후 3:05:09'처럼 오전/오후가 붙는 12시간제로 바꿔줘. 24시간제 대신."

## 검증법

- **눈으로 확인**: 화면의 초 숫자가 **1초마다 정확히 1씩 증가**하면 정상입니다. 내 컴퓨터 작업표시줄(우측 하단)의 시계와 시·분·초가 똑같이 맞아야 합니다.
- **숫자 자릿수 확인**: 시각이 한 자리일 때(예: 새벽 9시 5분 3초) `9:5:3`이 아니라 **`09:05:03`** 으로 두 자리로 나오면 `twoDigits` 함수가 잘 동작하는 것입니다.
- **갱신이 안 될 때** 아래를 확인하세요.
  - 숫자가 `--:--:--` 그대로 멈춰 있다면: `index.html`의 `id="clock"`과 `script.js`의 `getElementById("clock")`이 **똑같이** 적혀 있는지(대소문자까지) 확인합니다.
  - `<script src="script.js"></script>` 줄이 `</body>` 바로 위, 즉 **div보다 아래쪽**에 있는지 확인합니다. (자바스크립트가 div보다 먼저 실행되면 div를 못 찾습니다.)
  - 브라우저에서 `F12`를 눌러 개발자 도구 > **Console** 탭에 빨간 에러 메시지가 없는지 봅니다.
- **반복 동작 확인**: 5번 실험처럼 `1000`을 `100`으로 바꿨을 때 갱신이 빨라지고, 되돌리면 다시 1초 간격이 되면 `setInterval`의 두 번째 값(간격)을 제대로 이해한 것입니다.

## 핵심 정리

- **`new Date()`**: "지금 이 순간"을 담은 상자. 여기서 `getHours()`, `getMinutes()`, `getSeconds()` 등으로 원하는 값을 꺼냅니다.
- **주의 — 월(月)은 0부터**: `getMonth()`는 1월이 `0`, 12월이 `11`입니다. 그래서 화면에 보일 때는 `+1`을 해줘야 합니다. (초보자가 가장 많이 헷갈리는 부분입니다.)
- **`setInterval(함수, 간격)`**: "이 함수를 정해진 간격(밀리초)마다 계속 반복해줘"라는 명령. `1000`이면 1초마다입니다. 시계처럼 "스스로 움직이는 화면"의 기본 재료입니다.
- 페이지가 열리자마자 `showTime()`을 **한 번 먼저 호출**해 두면, 첫 1초 동안 빈 화면이 보이는 어색함을 없앨 수 있습니다.
