# 실습 088 — 라디오 버튼과 체크박스로 설문 항목 만들기

선택형 입력에는 두 가지가 있습니다. **라디오 버튼(◉)** 은 여러 보기 중 **딱 하나만** 고르는 칸이고, **체크박스(☑)** 는 **여러 개를 동시에** 고를 수 있는 칸입니다. 이번 실습에서는 이 둘을 합쳐 작은 설문 폼을 만들어 봅니다.

가장 중요한 개념은 **`name` 속성**입니다. 같은 `name`으로 묶인 라디오 버튼끼리는 "하나만 켜지는 한 묶음"이 됩니다. 만약 `name`을 서로 다르게 적으면 각자 따로 노는 동그라미가 되어, 둘 다 켜질 수 있게 되어 버려요(=택일이 깨짐).

코드는 단 한 파일(`index.html`)이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭으로 바로 열 수 있어요. (맨 아래 작은 JavaScript는 '내가 고른 값'을 화면에 보여주기 위한 보조 장치일 뿐이고, 라디오·체크박스 자체는 HTML만으로 잘 작동합니다.)

> **핵심 한 줄:** 라디오 버튼은 **같은 `name`으로 묶어야** "하나만 켜지는 한 묶음"이 됩니다. 체크박스는 같은 `name`이어도 여러 개 켤 수 있습니다.

| 입력 종류 | 모양 | 고르는 방식 | `name`을 같게 묶으면 |
|---|---|---|---|
| `radio` | 동그라미 ◉ | **택일**(하나만) | 한 묶음이 되어 하나 켜면 나머지 꺼짐 |
| `checkbox` | 네모 ☑ | **복수 선택**(여러 개) | 같은 묶음이지만 여러 개 동시에 켜짐 |

## 목표
- `radio`(택일)와 `checkbox`(복수 선택)의 쓰임새 차이를 구분할 수 있다.
- 같은 `name`으로 라디오 버튼을 묶으면 **하나만 선택**된다는 원리를 눈으로 확인한다.
- `label`의 `for`와 `input`의 `id`를 같은 이름으로 맞추면 **글자를 눌러도** 선택된다는 것을 익힌다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 두 개의 질문이 있는 설문 폼이 열립니다.
2. **질문 1(라디오)** 에서 '검색'을 켠 뒤 'SNS'를 눌러 봅니다. → '검색'이 **자동으로 꺼지고** 'SNS'만 켜지는지 확인합니다. (택일)
3. 동그라미 옆의 **글자**(예: "지인 추천")를 직접 눌러 봅니다. → 글자만 눌러도 동그라미가 켜지나요? (이게 `label`의 `for`를 맞춰 둔 효과입니다.)
4. **질문 2(체크박스)** 에서 '웹 개발', 'AI', '마케팅'을 차례로 눌러 봅니다. → 라디오와 달리 **여러 개가 동시에** 켜진 채로 남는지 확인합니다. (복수 선택)
5. **[설문 제출]** 버튼을 누릅니다. → 아래에 초록색 박스가 나타나며 "1. 알게 된 경로(택일)"에는 **한 개**, "2. 관심 주제(복수)"에는 **고른 개수만큼**의 값이 보이는지 확인합니다.
6. 차이를 직접 만들어 보기: `index.html`을 메모장(또는 VS Code)으로 열어, 질문 1의 두 번째 라디오(`id="ch-sns"`)의 `name="channel"` 을 `name="channel2"` 로 **일부러 다르게** 바꿔 저장하고 **새로고침(F5)** 합니다. → 이제 '검색'과 'SNS'가 **둘 다 동시에 켜질 수 있게** 되는지(=택일이 깨지는지) 확인합니다. 차이를 본 뒤 다시 `name="channel"`로 되돌려 두세요.
7. AI에게 시켜 보기:
   > "이 index.html에 세 번째 질문을 추가해줘. 질문은 '연령대는?'이고, 라디오 버튼으로 '10대 / 20대 / 30대 이상' 중 하나만 고르게 해줘. 기존처럼 `<fieldset>`과 `<legend>`로 감싸고, 세 라디오의 `name`은 모두 `age`로 같게, 각 `label`의 `for`와 `input`의 `id`도 짝을 맞춰줘."

## 검증법
- 질문 1에서 라디오 보기를 바꿔 누를 때 **항상 하나만** 켜져 있는가? (이전에 켠 것이 자동으로 꺼지는가?)
- 동그라미 옆 **글자만 눌러도** 선택이 켜지는가? (`label`의 `for`와 `input`의 `id`가 맞춰진 증거)
- 질문 2의 체크박스는 **여러 개를 동시에** 켤 수 있는가?
- **[설문 제출]** 을 눌렀을 때 결과 박스에서 "택일" 항목은 **딱 하나** 값만, "복수" 항목은 **고른 개수만큼** 값이 표시되는가?
- 브라우저에서 `F12 → Elements` 탭을 열어, 질문 1의 라디오 3개가 **모두 `name="channel"`** 로 같은지 눈으로 확인한다. (이게 "같은 name으로 묶어 택일을 만든다"는 증거입니다.)
