# 실습 086 — 이름 한 줄 입력칸 만들고 placeholder 넣기

웹에서 사용자가 글자를 적어 넣는 가장 기본 부품인 "입력칸(input)"을 만들어 봅니다. 코드는 단 한 파일(`index.html`)이고, 서버도 데이터베이스도 필요 없습니다. 더블클릭으로 바로 열 수 있어요.

이번 실습의 핵심 부품은 딱 세 가지입니다.

| 부품 | 역할 | 비유 |
|---|---|---|
| `<label>` | 입력칸에 붙는 **이름표** | "여기엔 이름을 적으세요"라고 적힌 안내판 |
| `<input type="text">` | 글자를 **한 줄** 적는 빈 칸 | 종이 양식의 빈 줄 |
| `placeholder` | 적기 전에 흐리게 보이는 **예시 글자** | 빈 줄 위에 연필로 살짝 적어 둔 예시 |

> 주의: `placeholder`는 "예시 안내 글자"일 뿐, 실제로 저장되는 값이 아닙니다. 타이핑을 시작하면 사라집니다.

## 목표
- `<input type="text">`로 한 줄짜리 글자 입력칸을 만들 수 있다.
- `<label>`의 `for`와 `<input>`의 `id`를 같은 이름으로 맞춰 **이름표와 입력칸을 연결**할 수 있다.
- `placeholder`로 "예: 홍길동" 같은 **흐린 예시 안내 글자**를 넣을 수 있다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다.
2. "이름"이라는 글자(이름표) 아래에 빈 입력칸이 있고, 그 안에 흐린 글씨로 **예: 홍길동**이 보이는지 확인합니다.
3. 입력칸을 클릭하고 아무 이름이나 타이핑합니다. → 흐린 안내 글자가 사라지고 내가 친 글자가 보입니다.
4. 입력한 글자를 모두 지웁니다. → 다시 흐린 안내 글자(`placeholder`)가 돌아오는지 확인합니다.
5. `index.html`을 메모장(또는 VS Code)으로 열어 `placeholder="예: 홍길동"`을 `placeholder="여기에 이름을 적어주세요"`로 바꿔 저장하고, 브라우저에서 **새로고침(F5)** 해 바뀌는지 봅니다.
6. AI에게 시켜 보기:
   > "이 index.html의 이름 입력칸 아래에, 같은 모양으로 '전화번호' 입력칸을 하나 더 추가해줘. label의 for와 input의 id를 'phone'으로 맞추고, placeholder는 '예: 010-1234-5678'로 해줘."

## 검증법
- 화면에 **이름표("이름")** 와 그 아래 **빈 입력칸**이 보이는가?
- 입력칸 안에 **흐린 예시 글자**가 보이고, 타이핑하면 사라졌다가 지우면 다시 나타나는가?
- **이름표 글자("이름")를 클릭**했을 때 입력칸에 커서가 들어가는가? (`for`와 `id`가 잘 연결되었다는 증거입니다. 둘이 다르면 클릭해도 반응이 없어요.)
- 브라우저에서 `F12 → Elements` 탭을 열어, `<label for="name">`과 `<input id="name">`의 이름(`name`)이 **서로 같은지** 눈으로 확인한다.
