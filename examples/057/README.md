# 버튼 클릭으로 화면 글자 바꾸기

알림창(alert)을 띄우는 것에서 한 걸음 더 나아가, 버튼을 누르면 **페이지 안의 글자를 직접 바꾸는** 실습입니다.
화면에 있는 `<p>` 문단을 자바스크립트가 찾아서, 그 안의 내용을 다른 문장으로 교체합니다.
이것이 바로 "DOM 조작"의 가장 기본 동작입니다. (DOM = 브라우저가 화면을 다루기 위해 만든 요소들의 목록)

## 목표

- 자바스크립트로 화면의 특정 요소를 찾는 법 익히기 (`getElementById`).
- 찾은 요소의 **글자 내용을 바꾸는 법** 익히기 (`textContent`).
- "버튼을 누르면 → 글자가 바뀐다"라는 이벤트와 화면 변경을 연결해 보기.

## 따라하는 단계

1. 이 폴더의 `index.html` 파일을 더블클릭해서 웹 브라우저(크롬 등)로 엽니다.
2. 화면에 **"아직 버튼을 누르지 않았어요."** 라는 문장과 **"글자 바꾸기"** 버튼이 보입니다.
3. **"글자 바꾸기"** 버튼을 클릭합니다.
4. 위쪽 문장이 **"버튼을 눌러서 글자가 바뀌었어요! 🎉"** 로 바뀌면 성공입니다.
5. 코드를 직접 살펴봅니다.
   - `index.html`: 바뀔 문장 `<p id="message">...</p>` 와 버튼 `<button id="changeBtn">...</button>` 이 있습니다. 둘 다 `id`로 이름표를 붙여 두었습니다.
   - `script.js`: `getElementById`로 문단과 버튼을 찾고, 버튼에 클릭 이벤트를 연결한 뒤 `message.textContent = "..."` 로 글자를 바꿉니다.
6. (실험) `script.js`의 `message.textContent = "..."` 안에 들어간 문장을 내가 원하는 문장으로 바꾼 뒤, 브라우저를 **새로고침(F5)** 하고 버튼을 다시 눌러봅니다. 바뀐 문장이 화면에 뜨면 코드와 화면이 연결되어 있다는 걸 확인한 것입니다.

## 검증법

- 버튼을 클릭했을 때 화면의 문장이 **즉시 바뀌면 정상**입니다.
- 글자가 안 바뀐다면 아래를 확인하세요.
  - `index.html`의 `<p>` id(`message`), 버튼 id(`changeBtn`)와 `script.js`에서 찾는 id가 **똑같이** 적혀 있는지 (대소문자까지 동일해야 합니다).
  - `<script src="script.js"></script>` 줄이 `</body>` 바로 위, 즉 **문단·버튼보다 아래쪽**에 있는지. (자바스크립트가 요소보다 먼저 실행되면 요소를 못 찾습니다.)
  - 브라우저에서 `F12`를 눌러 개발자 도구 > Console 탭에 빨간 에러 메시지가 없는지. (`null` 관련 에러가 보이면 id 철자가 틀린 경우가 많습니다.)

## 핵심 정리

- **getElementById("이름표")**: HTML에서 그 `id`를 가진 요소 하나를 찾아 가져옵니다.
- **textContent**: 그 요소 안에 들어 있는 "글자"를 뜻합니다. 여기에 새 문장을 넣으면(`= "..."`) 화면 글자가 바로 바뀝니다.
- 알림창(alert)은 잠깐 떴다 사라지지만, `textContent`로 바꾼 글자는 **화면에 계속 남습니다.** 이렇게 화면을 직접 고치는 것이 진짜 웹 인터랙션의 시작입니다.
