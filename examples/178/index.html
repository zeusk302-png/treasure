내 도메인 사서 Vercel에 연결하고 HTTPS 자물쇠 확인하기

my-site.vercel.app 같은 긴 주소 대신 내이름.com 같은 내 도메인으로 사이트를 띄우는 흐름의 연습판입니다. 도메인을 사고 → DNS 레코드를 설정하고 → www와 루트(@)를 301로 한쪽으로 통일하고 → HTTPS 자물쇠가 걸리는 과정을 손으로 따라가 봅니다. 실제 도메인 등록업체/Vercel 화면을 흉내 낸 것이라 설치 없이 더블클릭으로 동작합니다. (진짜 도메인은 쓰지 않습니다.)

가장 중요한 한 가지: DNS는 전국 안내소에 새 전화번호가 퍼지는 데 시간이 걸리듯 바로 반영되지 않습니다. 설정 직후 "안 떠도 정상"입니다. 보통 수 분~수 시간, 길면 하루(최대 48시간)까지 기다립니다. 이 연습판의 "전파 기다리기" 버튼이 그 느낌을 보여줍니다.

0) 지금 상태 — 사이트는 vercel.app 주소로 이미 살아 있습니다

앞 실습(예: 169~170)에서 GitHub 저장소를 Vercel에 연결해 https://my-site.vercel.app 주소가 이미 살아 있는 상태입니다. 이번 실습은 거기에 내 도메인을 얹는 한 걸음입니다.

지금 주소 (기본 제공)

🔒 https://my-site.vercel.app

Vercel이 공짜로 준 주소. 작동은 하지만 길고 기억하기 어렵습니다.

목표 주소 (내 도메인)

🔓 https://내이름.com

아직 연결 전. 아래 단계를 끝내면 여기 자물쇠(🔒)가 채워집니다.

1) 도메인 사기 — "내이름.com" 1년 빌리기

도메인은 등록업체(레지스트라)에서 1년 단위로 빌리는 주소입니다. (예: Cloudflare Registrar, Namecheap, 가비아 등) 가격은 보통 .com 기준 연 1만~2만 원대입니다.

아직 구매 전입니다. 위 버튼을 눌러 보세요.

2) Vercel 프로젝트에 도메인 추가하기

Vercel 대시보드 → 프로젝트 → Settings → Domains 에 내 도메인을 입력하면, Vercel이 "이 레코드들을 등록업체에 넣으세요" 라고 알려줍니다. 그 안내를 그대로 따라 하는 단계입니다.

1번(도메인 구매)을 먼저 끝내야 활성화됩니다.

3) DNS 레코드 넣기 — 주소록에 "어디로 가라" 적기

DNS 레코드는 "이 도메인은 이 서버로 보내라"는 주소록입니다. 등록업체의 DNS 설정 화면에 아래 두 줄을 똑같이 넣습니다. (값은 본인 Vercel 안내 화면 기준 — 여기 값은 형식만 보여주는 예시입니다.)

종류(Type)이름(Name)값(Value)뜻
A @ (루트) 76.76.21.21 내이름.com → Vercel 서버 IP
CNAME www cname.vercel-dns.com www.내이름.com → Vercel 별칭

⚠️ 이 값들은 공개돼도 안전한 정보입니다(IP·별칭). 비밀번호·API 키 같은 비밀값은 DNS에 넣지 않습니다. 비밀값은 코드가 아니라 Vercel Settings → Environment Variables 에 자리표시자로 넣어 관리합니다.

2번(Vercel에 도메인 추가)을 먼저 끝내야 활성화됩니다.

4) www와 루트를 한쪽으로 통일하기 (301 리다이렉트)

손님은 내이름.com 으로도, www.내이름.com 으로도 들어옵니다. 둘 다 살려 두면 같은 사이트가 두 주소로 보여 검색엔진(SEO)에 안 좋습니다. 그래서 한쪽을 대표로 정하고, 다른 쪽은 301(영구 이동)로 대표 주소로 자동 넘겨줍니다. Vercel Domains 화면에서 클릭 한 번으로 설정됩니다.

3번(DNS 레코드 저장)을 먼저 끝내야 활성화됩니다.

5) 전파 기다리기 → HTTPS 자물쇠 확인

설정을 다 해도 DNS가 전 세계 안내소에 퍼지는 데 시간이 걸립니다. 그동안은 "Invalid Configuration" 또는 "사이트를 찾을 수 없음"이 떠도 정상입니다. 전파가 끝나면 Vercel이 HTTPS 인증서를 자동 발급해 주소창에 자물쇠(🔒)가 생깁니다. (별도 비용·설정 없음)

4번(301 통일)을 먼저 끝내야 활성화됩니다.

# 단계를 진행하면 Vercel/DNS에서 일어나는 일이 여기에 표시됩니다

6) 결과물 — 자물쇠 걸린 내이름.com 라이브 사이트

이번 실습의 결과물(Deliverable)

  • 커스텀 도메인 연결: https://내이름.com 으로 내 사이트가 열림
  • HTTPS 자물쇠: 주소창에 🔒 보안 연결 표시 (인증서 자동 발급)
  • 주소 통일(301): www.내이름.com → 내이름.com 으로 자동 이동

핵심: 도메인은 샀다고 바로 뜨지 않습니다. DNS 전파를 기다린 뒤에야 자물쇠가 채워집니다. "안 떠도 정상 → 기다림 → 자물쇠"의 순서를 몸에 익히는 것이 이번 실습의 목표입니다.
