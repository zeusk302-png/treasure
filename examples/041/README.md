# 041. auto-fit·minmax로 카드 수가 자동 조절되는 그리드

CSS Grid의 `repeat(auto-fit, minmax(...))` 한 줄로, 화면 너비에 따라 한 줄에 들어가는 카드 개수가 **자동으로** 늘고 주는 반응형 카드 그리드를 만드는 실습입니다. `@media`(미디어쿼리) 없이도 반응형이 되는, 실무에서 가장 많이 쓰는 카드 레이아웃 패턴입니다.

## 목표

- `repeat()`가 "같은 규칙의 열을 여러 번 반복"한다는 뜻임을 이해한다.
- `auto-fit`이 "화면을 보고 들어갈 수 있는 만큼 열 개수를 알아서 정해준다"는 점을 체감한다. (내가 열 개수를 직접 안 정해도 됨)
- `minmax(최소, 최대)`로 한 칸의 "최소 너비"와 "최대 너비(1fr)"를 동시에 정하는 법을 익힌다.
- 미디어쿼리 없이도 화면 크기에 반응하는 그리드를 만들 수 있다는 것을 눈으로 확인한다.

## 따라하는 단계

1. `index.html`과 `style.css`가 **같은 폴더(041)** 안에 있는지 확인합니다. HTML 위쪽의 `<link rel="stylesheet" href="style.css" />` 한 줄이 두 파일을 연결해 줍니다.
2. `index.html`을 더블클릭해 브라우저(크롬 등)로 엽니다. 맛집 카드 6장이 격자로 보이면 성공입니다.
3. **브라우저 창의 가로 너비를 천천히 줄였다 늘렸다** 해봅니다. 한 줄에 들어가는 카드 개수가 3개 → 2개 → 1개로 자동으로 바뀝니다. 이 한 줄이 전부입니다.
   ```css
   grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
   ```
4. `style.css`의 `.card-grid` 부분을 열어 각 단어의 뜻을 확인합니다.
   - `repeat(...)` → 같은 규칙의 열을 여러 개 반복해서 만든다.
   - `auto-fit` → 화면 너비를 보고 "들어갈 수 있는 만큼" 열 개수를 자동으로 정한다.
   - `minmax(220px, 1fr)` → 한 칸은 최소 220px, 최대 1fr(남는 공간 균등 분배). 즉 "220px보다 작아지진 말고, 공간 남으면 늘어나도 돼".
5. 직접 숫자를 바꿔보며 원리를 확인합니다. (확인 후 원래 값으로 되돌리세요.)
   - `minmax(220px, 1fr)`의 `220px`을 `320px`로 키우면, 카드가 더 넓어져서 같은 화면에 더 적은 개수가 한 줄에 들어갑니다.
   - `220px`을 `140px`로 줄이면, 카드가 더 좁아져서 한 줄에 더 많이 들어갑니다.
   - `auto-fit`을 `auto-fill`로 바꾸면 어떻게 다른지 비교해 봅니다. (카드가 적을 때 `auto-fit`은 카드를 늘려 빈칸을 채우고, `auto-fill`은 빈 칸을 그대로 남겨 둡니다.)
6. (선택) `index.html`에서 `<article class="card">...</article>` 블록 하나를 통째로 복사해 카드를 7번째, 8번째로 늘려 봅니다. 열 규칙은 그대로이므로 줄(행)만 자동으로 늘어납니다.

> 참고: 예제의 사진은 인터넷 연결 없이도 보이도록 SVG로 그린 색 블록을 사용했습니다. 실제 사진을 쓰려면 `img`의 `src`를 본인 이미지 파일 경로(예: `images/food.jpg`)나 이미지 주소로 바꾸면 됩니다.

## 검증법

- 브라우저로 `index.html`을 열면 카드 6장이 격자로 보인다.
- **창 너비를 줄이면** 한 줄의 카드 개수가 자동으로 줄고(좁으면 1개), **창 너비를 늘리면** 한 줄에 카드가 더 많이 들어간다. (이때 코드는 한 줄도 바꾸지 않았다 = 미디어쿼리 없이 반응형)
- 카드를 아무리 좁게 만들어도 한 칸이 220px보다 작아지지 않는다. (`minmax`의 최소값이 지켜짐)
- 개발자도구(F12) > Elements에서 `.card-grid` 요소를 선택하면 `display: grid`가 적용된 것을 확인할 수 있고, 칸 경계에 그리드 선이 표시된다.
