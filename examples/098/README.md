# 비밀번호 확인 일치 검사 (두 칸 비교)

회원가입 폼에는 보통 "비밀번호"와 "비밀번호 확인" 두 칸이 나란히 있습니다. 사용자가 오타를 내지 않도록 같은 값을 두 번 입력받아 비교하는 것이죠. 이 실습에서는 두 칸의 값을 **타이핑하는 즉시** 비교해서, 다르면 빨간 경고를, 같으면 초록 메시지를 띄우는 실시간 검증을 만들어 봅니다.

## 목표

- 입력칸의 `value`(적힌 글자)를 읽어 두 값을 `===`(정확히 같은가?)로 비교한다.
- `input` 이벤트로 글자가 바뀔 때마다 **실시간으로** 검사한다(버튼을 누를 때까지 기다리지 않음).
- 결과에 따라 안내 문구와 테두리 색을 빨강/초록으로 바꾸는 **에러 토글**을 익힌다.
- 두 칸이 일치할 때만 "가입하기" 버튼이 눌리도록 `disabled` 속성으로 제어한다.

## 따라하는 단계

1. `098` 폴더 안의 `index.html` 파일을 마우스로 더블클릭해 브라우저(크롬 등)로 엽니다. "비밀번호"와 "비밀번호 확인" 두 입력칸, 그리고 회색으로 잠긴 "가입하기" 버튼이 보입니다.
2. **비밀번호 칸**에 아무 값(예: `apple123`)을 입력합니다. 아직 확인 칸이 비어 있으므로 아무 메시지도 뜨지 않습니다.
3. **비밀번호 확인 칸**에 일부러 **다른 값**(예: `apple12`)을 입력해 봅니다. 곧바로 빨간 글씨로 "✗ 비밀번호가 일치하지 않습니다."가 뜨고, 두 칸의 테두리가 빨갛게 변하며, 가입 버튼은 계속 잠겨 있습니다.
4. 확인 칸을 지우고 비밀번호와 **똑같은 값**(`apple123`)을 입력합니다. 메시지가 초록색 "✓ 비밀번호가 일치합니다."로 바뀌고 테두리도 초록으로, 가입 버튼이 활성화(보라색)됩니다.
5. 활성화된 "가입하기" 버튼을 눌러 봅니다. "가입 완료!" 알림창이 뜨면 폼 제출 흐름까지 정상 작동하는 것입니다.
6. (코드 읽기) `script.js`의 `checkMatch` 함수를 천천히 읽어 보세요. (A) 확인 칸이 비었을 때, (B) 두 값이 같을 때, (C) 다를 때 — 이 세 경우로 나뉘어 있다는 점이 핵심입니다.
7. (응용) `script.js`에서 비교 조건 `pw === cf`를 보고, 비밀번호 칸을 나중에 고쳐도 다시 검사되도록 **양쪽 칸 모두**에 `input` 이벤트가 연결되어 있음을 확인합니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 프론트엔드 입문 강사야. 순수 HTML/CSS/JS(외부 라이브러리 없이)로
  "비밀번호 / 비밀번호 확인" 두 칸짜리 회원가입 폼을 만들어줘.
  요구사항:
  - 가운데에 흰 카드, 제목 "비밀번호 확인 일치 검사", 한 줄 설명
  - type="password" 입력칸 2개(id: password, confirm), 각각 라벨
  - 일치 안내 메시지를 띄울 빈 <p id="matchMsg">, 안내 메시지는 aria-live="polite"로
  - type="submit" 버튼 "가입하기"(id: submitBtn), 처음엔 disabled로 잠가둬
  파일은 index.html / style.css / script.js 세 개로 나눠줘.
  비전공자가 읽을 거니까 각 부분이 무슨 역할인지 한국어 주석을 달아줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 폼에 "두 칸이 같은지 실시간으로 검사"하는 기능을 script.js에 추가해줘.
  - 두 입력칸 모두에 input 이벤트를 걸어서 타이핑할 때마다 검사
  - 확인 칸이 비어 있으면: 메시지 없음, 버튼 잠금
  - 두 값이 ===로 같으면: 초록 "✓ 일치합니다" + 두 칸 테두리 초록 + 버튼 활성화
  - 다르면: 빨간 "✗ 일치하지 않습니다" + 두 칸 테두리 빨강 + 버튼 잠금
  색/테두리 변경은 CSS 클래스(ok, error) 토글로 처리하고,
  제출(submit) 시에는 새로고침을 막고 "가입 완료" alert만 띄워줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  비밀번호 칸을 나중에 고치면 일치 검사가 다시 안 돼.
  (또는 콘솔에 이런 에러가 떠: [여기에 F12 콘솔의 빨간 메시지를 그대로 붙여넣기])
  내 script.js는 아래와 같아: [코드 붙여넣기]
  무엇이 원인인지 한 단계씩 짚어주고, 비전공자가 이해하게 한 줄씩 풀어서
  고친 코드를 알려줘. 왜 그렇게 고쳤는지 주석도 달아줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- **불일치 → 일치**: 두 값을 다르게 적으면 빨간 경고가, 같게 맞추면 초록 메시지가 즉시(타이핑하는 순간) 바뀌면 실시간 검증이 작동하는 것입니다.
- **버튼 잠금**: 두 값이 다르거나 확인 칸이 비어 있는 동안에는 "가입하기" 버튼이 회색으로 눌리지 않고, 일치할 때만 보라색으로 눌리면 성공입니다.
- **되돌리기 검사**: 일치시켜 초록이 된 뒤, 비밀번호 칸의 글자 하나를 지워 보세요. 다시 빨간 경고로 바뀌고 버튼이 잠기면 양쪽 칸 검사가 제대로 연결된 것입니다.
- 브라우저 개발자 도구(F12)의 콘솔에 빨간 오류 메시지가 없으면 코드가 깨진 곳 없이 잘 작동하는 것입니다.
