# 실습 184 — 카톡·SNS 공유 미리보기용 OG 태그 만들기

카카오톡 대화방이나 페이스북에 사이트 링크를 붙였을 때, 그냥 파란 글씨만 뜨는 게 아니라 **제목 + 설명 + 큰 사진이 들어간 예쁜 미리보기 카드**가 뜨게 만드는 실습입니다. (난이도 2, 카테고리: SEO·성능·접근성)

> **OG(Open Graph) 태그란?** 링크를 받은 카톡·페북·슬랙 서버가 그 페이지의 `<head>`를 몰래 읽어, "이 링크는 제목이 뭐고, 설명이 뭐고, 대표 사진이 뭔지"를 알아내려고 약속해 둔 메타태그예요. 우리가 이 태그를 안 넣으면 미리보기가 안 뜨거나 엉뚱한 사진이 잡힙니다. 넣어주면 카드가 깔끔하게 떠서 클릭률이 올라갑니다.

이 폴더의 파일:
- `index.html` — OG 태그가 모두 들어간 정답 페이지
- `images/og.svg` — 대표 OG 이미지 견본 1장 (1200×630, SNS 카드 표준 크기)

## 목표
- `og:title`·`og:description`·`og:image`·`og:url` 4개의 핵심 OG 태그를 `<head>`에 넣는다.
- OG 태그가 `<meta name="...">`이 아니라 **`<meta property="...">`** 형식임을 안다. (가장 흔한 실수)
- `og:image`는 반드시 **`https://`로 시작하는 전체 주소(절대경로)**여야 함을 안다. (`images/og.png` 같은 상대경로는 미리보기에 안 뜬다.)
- 대표 이미지를 권장 비율 **1200×630**으로 1장 준비한다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 더블클릭해 브라우저로 연다. 화면은 단순하지만, 진짜 내용은 `<head>` 안에 있다.
2. 브라우저에서 우클릭 → "페이지 소스 보기"를 눌러, `<meta property="og:..."`로 시작하는 줄들을 직접 눈으로 찾아본다. (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`, `og:site_name` 순서로 들어 있다.)
3. `index.html`을 코드 편집기로 열어, `https://example.com` 으로 적힌 부분을 **여러분의 실제 배포 주소**로 바꾼다.
   - `og:url`의 `content`를 여러분 주소로 (예: `https://my-bakery.vercel.app/`).
   - `og:image`의 `content`를 대표 이미지의 **전체 주소**로 (예: `https://my-bakery.vercel.app/images/og.png`).
4. 대표 이미지를 준비한다. 견본 `images/og.svg`를 브라우저로 열어 캡처하거나, Canva 등에서 **1200×630** 크기로 만들어 `images/og.png`로 저장한다. (카톡·페북은 PNG/JPG를 가장 안정적으로 읽는다.)
5. 사이트를 Vercel 등으로 배포한다. (OG는 외부 서버가 우리 페이지를 "가져가서" 읽기 때문에, 내 컴퓨터의 `file://` 상태로는 테스트가 안 되고 인터넷에 올라가 있어야 한다.)
6. 배포된 실제 주소를 아래 디버거에 넣어 카드가 잘 뜨는지 확인한다. (검증법 참고)

## 검증법
- 코드에서 OG 태그가 `name=`이 아니라 **`property=`**로 적혀 있는지 확인한다. (`<meta property="og:title" ...>`)
- `og:image`의 주소가 **`https://`로 시작하는 전체 주소**인지 확인한다. 상대경로(`images/og.png`)면 미리보기에 그림이 안 뜬다.
- 대표 이미지가 **1200×630**(또는 1.91:1 비율)인지 확인한다. 너무 작거나 비율이 안 맞으면 카드에서 잘리거나 작게 뜬다.
- (실제 확인) 사이트를 배포한 뒤, 아래 도구에 배포 주소를 넣고 미리보기 카드를 본다.
  - 페이스북: [Sharing Debugger](https://developers.facebook.com/tools/debug/) — "Scrape Again"을 눌러 최신 상태로 갱신한다.
  - 카카오: [카카오 공유 디버거](https://developers.kakao.com/tool/clear/og) — 캐시를 지워야 바꾼 내용이 반영된다.
- (가장 쉬운 최종 확인) 배포된 링크를 **나에게 보내는 카톡**에 한 번 붙여넣어 본다. 제목·설명·대표 사진이 들어간 카드가 뜨면 성공이다.

> 자주 막히는 지점: 태그를 고쳤는데 카톡 미리보기가 그대로다 → 카톡/페북은 한 번 본 링크를 **캐시(저장)**해 둔다. 위 디버거에서 캐시를 지우거나 다시 긁어오기를 해야 새 카드가 보인다.
