# 실습 180 — 방문자수 측정 붙이고, n8n으로 매일 트래픽 알림 받기

내 사이트에 **방문 측정기**를 붙여 "어제 몇 명이 왔는지"를 보고, **n8n 자동화**가 매일 아침 그 요약을 **슬랙(또는 메일)**으로 보내 주게 만듭니다. 매번 대시보드를 들여다보지 않아도, 알림만 받으면 되는 **간단 모니터링**을 완성하는 것이 목표입니다.

> 한 줄 그림: **사람들이 페이지 방문 → Analytics가 방문수 기록 → n8n이 매일 9시에 그 숫자를 읽어 → "어제 방문 12명, 페이지뷰 30회" 같은 요약을 슬랙으로 발사**

> 비유: Analytics는 가게 입구의 **방문객 계수기**입니다. n8n은 매일 아침 그 계수기를 대신 확인해 주는 **성실한 알바**고요. 알바에게 "매일 9시에 어제 손님 수 적어서 단톡방에 올려 줘"라고 시켜 두는 셈입니다.

> 보안 메모 — 공개해도 되는 값 vs 절대 숨겨야 하는 값
> - **공개되어도 되는 값**: 페이지에 붙이는 **Analytics 측정 스니펫**(`<script src="/_vercel/insights/script.js">` 또는 Plausible 스니펫). 이건 "방문을 세 달라"는 신호일 뿐이라 누구에게 보여도 안전합니다. `index.html`에 그대로 둡니다.
> - **절대 노출하면 안 되는 비밀값**: 통계를 **읽어 오는 API 토큰**, **슬랙 수신 웹훅 주소** 등. 이걸 페이지 코드(`index.html`/JS)에 박으면 `F12`로 그대로 보여 도용당합니다. 그래서 이 값들은 **n8n의 Credentials/환경변수**에만 둡니다.
> - 이 폴더의 `workflow.json`에도 진짜 비밀값이 아니라 **자리표시자**(`REPLACE_WITH_CREDENTIAL_ID`, `$env.SLACK_WEBHOOK_URL`)만 들어 있습니다. 진짜 값은 `.env`(또는 n8n Credentials)에만 적고, `.env`는 `.gitignore`로 깃에서 빠집니다.

## 목표
- **방문자수를 측정**한다: 내 페이지에 Vercel Analytics(또는 Plausible) 측정기를 붙여, 대시보드에서 방문수·페이지뷰가 쌓이는 걸 본다.
- **자동 모니터링을 이해**한다: 흐름은 `매일 정해진 시각(Schedule) → 통계 읽기(HTTP) → 값 추리기(Set) → 문장 만들기(Set) → 슬랙 전송(HTTP)`. 사람이 매번 대시보드를 안 봐도 요약이 알아서 온다.
- **비밀값을 코드가 아니라 자격증명/환경변수에 둔다**: 통계 토큰·슬랙 웹훅은 `workflow.json`이 아니라 n8n의 Credentials/환경변수에 넣고, 워크플로우에는 **참조(자리표시자)**만 남긴다.
- **알림을 직접 한 번 받아 본다**: 워크플로우를 수동으로 한 번 실행해, 슬랙(또는 메일)에 요약 메시지가 실제로 도착하는 걸 확인한다.

## 따라하는 단계

### A. 방문 측정기 붙이고 대시보드 켜기
1. 이 폴더의 `index.html`을 Vercel에 배포합니다. (배포 방법이 낯설면 이 가이드의 배포 실습을 먼저 보세요.)
2. 배포한 페이지를 열고, `index.html` 맨 아래 **방문 측정기** 주석(`<!-- ... -->`)을 풀어 스니펫을 활성화합니다.
   - Vercel Analytics를 쓰면: Vercel 프로젝트 화면의 **Analytics** 탭을 **Enable** 합니다.
   - Plausible을 쓰면: 주석 안내대로 `data-domain`을 내 도메인으로 바꾼 한 줄짜리 스니펫을 씁니다.
3. 페이지를 새 탭/모바일/친구에게 보내 **몇 번 방문**하게 한 뒤, 대시보드에 방문수가 늘어나는지 확인합니다. (숫자 반영에 몇 분 걸릴 수 있습니다.)

### B. n8n에 워크플로우 올리기
4. n8n을 엽니다(클라우드 또는 직접 설치). 우상단 메뉴에서 **Import from File**로 이 폴더의 `workflow.json`을 불러옵니다.
5. 노드 5개가 보입니다: `매일 오전 9시(Schedule) → 방문 통계 가져오기(HTTP) → 필요한 값만 추리기(Set) → 알림 문장 만들기(Set) → 슬랙으로 보내기(HTTP)`.

### C. 비밀값은 자격증명/환경변수에만 넣기 (가장 중요)
6. **슬랙 웹훅 주소 넣기**: 슬랙에서 **Incoming Webhook**을 하나 만들어 주소(`https://hooks.slack.com/services/...`)를 받습니다. 그 값을 n8n의 **환경변수 `SLACK_WEBHOOK_URL`**에 넣습니다. (워크플로우는 `$env.SLACK_WEBHOOK_URL`로 이 값을 읽습니다 — 코드에 직접 적지 않습니다.)
7. **통계 읽기 토큰 넣기**: 통계 API에 토큰이 필요하면, n8n의 **Credentials**에서 **Header Auth** 자격증명을 새로 만들어 `Name = Authorization`, `Value = Bearer <진짜토큰>`으로 저장하고, **방문 통계 가져오기** 노드에 연결합니다. → 토큰은 `workflow.json`이 아니라 **자격증명 저장소**에만 들어갑니다.
8. **통계 주소 맞추기**: **방문 통계 가져오기** 노드의 `url`을 내 통계 주소로 바꿉니다. (예: Plausible `https://plausible.io/api/v1/stats/aggregate?site_id=내도메인&period=day`.) 그리고 **필요한 값만 추리기** 노드의 `$json.visitors` / `$json.pageviews`를 실제 응답 필드 이름에 맞춰 줍니다.

### D. 한 번 돌려 보고, 자동 예약 켜기
9. n8n 캔버스 우상단의 **Execute Workflow**(수동 실행)를 눌러 지금 한 번 돌립니다. 슬랙 채널에 `📊 ...-... 트래픽 요약 / 방문자: N명 / 페이지뷰: N회` 메시지가 오면 성공입니다.
10. 잘 되면 워크플로우를 **Active(활성)**로 켭니다. 이제 **매일 오전 9시**마다 자동으로 어제 요약이 옵니다. (시각을 바꾸려면 Schedule 노드의 `triggerAtHour`만 고치면 됩니다.)

> 메일로 받고 싶다면: 마지막 **슬랙으로 보내기** 노드를 지우고 n8n의 **Send Email**(또는 **Gmail**) 노드로 바꾼 뒤, 메일 본문에 `{{ $json.메시지 }}`를 넣으면 됩니다. 메일 계정 정보 역시 Credentials에만 저장합니다.

## 검증법
- **대시보드 반영 확인**: 내 페이지를 여러 번 방문한 뒤, Analytics 대시보드의 방문수/페이지뷰가 **0이 아니라 늘어나는지** 본다.
- **수동 실행으로 알림 도착 확인**: n8n에서 **Execute Workflow**를 누르면 슬랙(또는 메일)에 요약 메시지가 **실제로 도착**하는지 본다. 각 노드가 초록 체크로 통과하는지도 확인한다.
- **숫자 일치 확인**: 알림에 찍힌 방문수가 대시보드의 어제 숫자와 **대략 일치**하는지 비교한다. (집계 시점 차이로 약간 다를 수 있다.)
- **비밀값이 코드에 안 보이는지 확인**: 배포된 페이지에서 `Ctrl`+`U`(소스 보기)로 `index.html`을 열어 **슬랙 웹훅 주소나 통계 토큰이 한 글자도 없는지** 본다. (보이면 안 된다 — 그 값들은 n8n에만 있어야 한다.)
- **워크플로우 JSON에 비밀값이 없는지 확인**: 이 폴더에서 아래를 실행하면 **자리표시자만** 나와야 정상이다.
  - `grep -nE "hooks.slack.com/services/[A-Z0-9]|Bearer [A-Za-z0-9]{10}" workflow.json` → **진짜 값이 안 나와야** 정상이다. (`$env.SLACK_WEBHOOK_URL`, `REPLACE_...` 같은 참조만 있어야 한다.)
- **자동 예약 확인**: 워크플로우를 Active로 켠 다음 날 오전 9시 이후, 슬랙에 **사람이 누르지 않았는데도** 요약이 와 있으면 자동 모니터링이 완성된 것이다.

## 파일 구성
- `index.html` — 방문을 측정할 데모 페이지. 맨 아래 **공개 측정 스니펫**(비밀 아님)을 풀어 활성화한다.
- `workflow.json` — n8n 워크플로우(Schedule → HTTP → Set → Set → HTTP). 비밀값은 자리표시자만 들어 있다.
- `.env.example` — 필요한 비밀값 견본(자리표시자만). 복사해 `.env`를 만들고 진짜 값은 거기/또는 n8n Credentials에만 넣는다.
- `.gitignore` — `.env` 등 비밀 파일이 깃에 안 올라가게 막는다.
