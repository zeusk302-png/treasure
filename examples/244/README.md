# 제품 소개 랜딩페이지를 히어로·기능·CTA 섹션으로 만들기

마케팅용 제품 소개 페이지(랜딩페이지)를 **히어로 → 기능 → CTA** 세 개의 섹션으로 쌓아 만들어 봅니다. 가상의 집중 타이머 서비스 "FocusFlow"를 예시로 사용합니다.

## 목표

- 랜딩페이지의 기본 뼈대인 **3단 섹션 구조**(히어로 / 기능 / CTA)를 이해한다.
- 첫 화면(히어로)에서 한 줄로 가치를 전달하고, 행동 버튼(**CTA, Call To Action**)으로 자연스럽게 이어지는 흐름을 만든다.
- HTML과 CSS만으로 보기 좋고 모바일에서도 깨지지 않는 한 장짜리 페이지를 완성한다.

> CTA란? "Call To Action"의 줄임말로, "지금 시작하기", "무료 체험" 처럼 방문자가 눌러주길 바라는 **핵심 행동 버튼**을 말합니다.

## 따라하는 단계

1. `examples/244` 폴더 안에 `index.html`과 `style.css` 두 파일이 있는지 확인합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 보라색 배경의 첫 화면(히어로)이 보이면 성공입니다.
3. `index.html`을 메모장이나 VS Code로 열어 구조를 살펴봅니다. 페이지는 위에서부터 세 덩어리로 나뉩니다.
   - `<header class="hero">` : **히어로 섹션** — 큰 제목 + 한 줄 설명 + 시작 버튼.
   - `<section class="features">` : **기능 섹션** — 강점 3가지를 카드로 정리.
   - `<section class="cta">` : **CTA 섹션** — 마지막으로 한 번 더 행동을 유도하는 버튼.
4. `style.css`를 열어 맨 위 `:root`에 모아둔 색 변수를 봅니다. `--brand` 값(`#4f46e5`)을 다른 색(예: `#0ea5e9`)으로 바꾸고 저장한 뒤 새로고침하면 페이지 전체 포인트 색이 한 번에 바뀝니다.
5. 히어로의 제목 `<h1 class="hero-title">` 문구와 기능 카드 3개의 제목·설명을 **여러분만의 제품**으로 바꿔 봅니다.
6. 기능 카드는 `<article class="feature-card">` 한 덩어리가 카드 하나입니다. 통째로 복사해 붙여 넣으면 카드가 4개로 늘어나고, 줄이 좁아지면 자동으로 다음 줄로 넘어갑니다.

## 🤖 바이브코딩 프롬프트

이 랜딩페이지를 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 프론트엔드 멘토야. HTML과 CSS만으로(자바스크립트 없이) 한 장짜리 제품 소개 랜딩페이지를 만들어 줘.
  - 가상의 집중 타이머 서비스 "FocusFlow"를 소개하는 페이지야.
  - 위에서부터 세 덩어리로 구성해 줘:
    1) 히어로 섹션: 로고가 든 상단 내비, 큰 제목 한 줄, 한 문장 설명, "지금 무료로 써보기" 버튼.
    2) 기능 섹션: 강점 3가지를 카드 3개로(아이콘 이모지 + 제목 + 한 줄 설명).
    3) CTA 섹션: 마지막으로 행동을 유도하는 제목 + 버튼.
    그리고 맨 아래 간단한 푸터.
  - 파일은 index.html과 style.css 두 개로 나눠 줘.
  - 색은 style.css 맨 위 :root에 --brand 같은 CSS 변수로 모아서, 한 곳만 바꾸면 전체 포인트 색이 바뀌게 해 줘.
  - 비전공자가 읽을 수 있게 각 섹션이 무엇이고 왜 그렇게 했는지 한국어 주석을 달아 줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  앞에서 만든 랜딩페이지를 다음처럼 개선해 줘. 기존 구조와 색 변수는 그대로 유지하고, 바꾼 부분에는 왜 바꿨는지 주석을 달아 줘.
  - 기능 카드를 CSS 그리드의 auto-fit과 minmax로 배치해서, 화면이 좁아지면 3개 → 2개 → 1개로 자동 줄바꿈되게 해 줘.
  - 상단 내비의 "무료로 시작하기"와 히어로 버튼을 누르면 페이지 맨 아래 CTA 섹션으로 부드럽게(스무스 스크롤) 이동하게 해 줘.
  - 버튼에 마우스를 올리면 살짝 위로 떠오르는 hover 효과를 넣어 줘.
  - 모바일(폭 600px 이하)에서는 제목 글자 크기를 살짝 줄여서 안 깨지게 해 줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  랜딩페이지가 의도대로 안 나와. 아래 증상을 단계별로 진단하고, 원인과 고치는 법을 비전공자도 알게 한 줄씩 설명해 줘.
  - 증상: (예) 기능 카드가 가로로 안 펴지고 세로로만 쌓여요 / "무료로 시작하기"를 눌러도 아래로 이동을 안 해요 / --brand 색을 바꿔도 일부만 바뀌어요.
  - 내 현재 index.html과 style.css 전체를 붙여넣을게: (코드 붙여넣기)
  먼저 가장 의심되는 원인 한 가지부터 알려주고, 어디를 어떻게 고치면 되는지 짚어 줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- 브라우저 창 너비를 좁게 줄였다 늘렸다 해 봅니다. 기능 카드가 화면 너비에 맞춰 **3개 → 2개 → 1개**로 자동 정렬되면 반응형이 동작하는 것입니다.
- 히어로의 "지금 무료로 써보기" 버튼과 상단 "무료로 시작하기"를 누르면 페이지가 맨 아래 **CTA 섹션으로 부드럽게 이동**해야 합니다. (`href="#cta"`가 아래쪽 `id="cta"`로 연결되어 있기 때문)
- 버튼에 마우스를 올리면 살짝 위로 떠오르는 효과가 보여야 합니다.
- `--brand` 색 변수를 바꿨을 때 히어로 배경, 카드 강조, CTA 배경 색이 **일관되게 함께** 바뀌는지 확인합니다.
