# 헤더·메인·푸터로 페이지 영역 나누기

한 페이지를 **머리말(`<header>`)**, **본문(`<main>`)**, **꼬리말(`<footer>`)** 세 칸으로 나눠 봅니다. 지금까지는 글, 목록, 표를 "그냥 위에서 아래로" 쌓기만 했는데, 실제 웹페이지는 거의 다 "위에는 제목/메뉴, 가운데는 진짜 내용, 아래는 저작권/연락처" 구조로 되어 있습니다. 이 세 영역을 **이름에 의미가 담긴 태그(시맨틱 태그)** 로 표시하는 법을 배웁니다.

## 목표

- `<header>` 로 페이지 맨 위 **머리말**(제목·로고·메뉴 자리)을 만든다.
- `<main>` 으로 페이지의 **진짜 본문**(그 페이지에서 제일 중요한 내용)을 감싼다. (한 페이지에 **딱 1개만**)
- `<footer>` 로 페이지 맨 아래 **꼬리말**(저작권·연락처 자리)을 만든다.
- 이런 태그를 **시맨틱(semantic, "의미가 담긴") 태그** 라고 부르는 이유를 안다. 즉 `<div>`(의미 없는 빈 상자) 대신 "역할이 이름에 적힌 상자"를 쓰면, 사람도 검색엔진도 화면낭독기도 구조를 알아본다.

> 비전공자 눈높이 한 줄 요약: 신문 한 장을 떠올려 보세요. 맨 위 "신문 이름"이 `<header>`, 가운데 "기사 내용"이 `<main>`, 맨 아래 "발행처·연락처"가 `<footer>` 입니다. 페이지를 이 세 칸으로 나누는 게 오늘의 전부예요.

## 따라하는 단계

1. `examples/014/` 폴더 안의 `index.html` 파일을 메모장이나 VS Code 같은 편집기로 엽니다.
2. `<body>` 안이 위에서부터 `<header>`, `<main>`, `<footer>` 순서로 **세 덩어리**로 나뉘어 있는 걸 확인합니다. 이게 오늘의 핵심 구조예요.
3. `<header> ... </header>` 안을 봅니다. 사이트 제목(`<h1>`)과 한 줄 소개(`<p>`)가 들어 있습니다. → **머리말**
4. `<main> ... </main>` 안을 봅니다. 추천 메뉴·찾아오는 길·영업 시간 같은 "진짜 알맹이"가 들어 있습니다. → **본문**. `<main>` 은 한 페이지에 1개만 쓴다는 점을 기억하세요.
5. `<footer> ... </footer>` 안을 봅니다. 저작권 표시와 이메일이 들어 있습니다. → **꼬리말**
6. 나만의 내용으로 바꿔 봅니다. `<header>` 의 `<h1>` 제목을 내 가게/블로그 이름으로 고쳐 보세요.
7. `<main>` 안에 새 소제목 한 덩어리를 추가해 봅니다. 영업 시간 아래에 아래처럼 넣어 보세요.
   ```html
   <h2>사장님 한마디</h2>
   <p>오늘도 정성껏 한 잔 내려 드릴게요. 편하게 들러 주세요!</p>
   ```
8. 저장한 뒤, `index.html` 파일을 더블클릭해서 브라우저(크롬 등)로 엽니다.

> 주의 1: `<main>` 은 한 페이지에 **하나만** 둡니다. 본문이 여러 단락이어도 `<main>` 은 1개로 두고, 그 안에 `<h2>`·`<p>` 등을 여러 개 넣으면 됩니다.
> 주의 2: 머리말/꼬리말처럼 "모든 페이지에 똑같이 반복되는 부분"은 `<main>` 안에 넣지 않습니다. `<main>` 에는 그 페이지에만 있는 고유한 내용만 담아요.
> 주의 3: 색깔(배경색)은 `<style>`로 "영역이 눈에 보이게" 칠한 것뿐입니다. 색을 지워도 `<header>`/`<main>`/`<footer>` 의 의미와 구조는 그대로입니다. 오늘 배우는 건 색이 아니라 **구조**예요.

## 검증법

1. 브라우저에서 `index.html` 을 엽니다.
2. 화면이 위에서부터 **옅은 파랑(머리말) → 흰색(본문) → 옅은 회색(꼬리말)** 세 줄로 나뉘어 보이는지 확인합니다. → 세 영역이 제대로 나뉜 것입니다.
3. 맨 위 파란 영역에 큰 제목("부산 커피 한 잔")과 소개 문장이 있는지 확인합니다. → `<header>`
4. 가운데 흰 영역에 추천 메뉴·찾아오는 길·영업 시간이 있는지 확인합니다. → `<main>`
5. 맨 아래 회색 영역에 저작권(©)과 이메일이 있는지 확인합니다. → `<footer>`
6. 단계 6~7에서 직접 고친 제목과 추가한 "사장님 한마디"가 새로고침(F5) 후 제대로 나타나는지 확인합니다.
7. (확인 팁) 색 영역이 세 칸으로 안 나뉘고 뭉쳐 보인다면, `<header>`·`<main>`·`<footer>` 의 **닫는 태그**(`</header>` 등)가 빠졌거나 철자가 틀렸을 가능성이 높습니다. 여는 태그와 닫는 태그가 짝이 맞는지 확인하세요.
8. (확인 팁) 구조 검증의 정석: 브라우저에서 페이지 빈 곳을 마우스 오른쪽 클릭 → "검사(Inspect)"를 누르면, `<body>` 안에 `<header>`, `<main>`, `<footer>` 가 나란히 들어 있는 것을 직접 확인할 수 있습니다.
