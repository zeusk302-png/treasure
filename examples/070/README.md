# 070 · 드롭다운 메뉴 만들기 (바깥 클릭 시 닫힘)

웹사이트 오른쪽 위의 프로필 아이콘을 누르면 "내 프로필 / 설정 / 로그아웃" 같은 작은 목록이 펼쳐지고, 그 목록 바깥 아무 곳이나 누르면 스르륵 닫히는 것을 본 적 있을 겁니다. 이런 것을 **드롭다운 메뉴**라고 합니다. 이번 실습의 진짜 주인공은 메뉴 모양이 아니라, **"바깥을 클릭하면 닫힌다"를 어떻게 알아채는가** 입니다. 그 비밀은 클릭이 누른 곳에서 화면 전체(document)로 물결처럼 퍼져 나가는 **이벤트 버블링**과, 이를 막는 `stopPropagation()`에 있습니다.

## 목표

- 버튼을 누르면 메뉴가 펼쳐지고, **메뉴 바깥 아무 곳이나** 누르면 다시 닫히는 드롭다운을 만든다.
- "클릭이 화면 전체로 퍼진다(이벤트 버블링)"는 개념을 이해하고, `document`에 클릭 감지를 달아 "바깥 클릭"을 잡아낸다.
- 핵심 개념: 클래스를 켜고 끄는 `classList.toggle`, 클릭이 바깥으로 퍼지는 것을 멈추는 `event.stopPropagation()`, 그리고 문서 전체의 클릭을 듣는 `document.addEventListener("click", ...)`.

## 따라하는 단계

1. 폴더 `070` 안에 `index.html`, `style.css`, `script.js` 세 파일이 있는지 확인합니다. (이미 준비되어 있습니다.)
2. `index.html`을 더블클릭해 브라우저로 엽니다. "메뉴 열기 ▾" 버튼 하나가 보입니다.
3. 버튼을 눌러 봅니다. 버튼 바로 아래에 항목 목록이 펼쳐지고, 화살표가 ▾에서 ▴로 뒤집힙니다.
4. 이번엔 메뉴 **바깥**(예: 아래 회색 안내 영역)을 눌러 봅니다. 메뉴가 닫힙니다. 메뉴 **안의 항목**을 누르면(예: "설정") 잠깐 색이 바뀌며 선택됩니다.
5. `script.js`를 위에서부터 천천히 읽습니다. 동작 흐름은 딱 네 군데입니다.
   - **(2번 블록) 버튼 클릭** → `dropdown.classList.toggle("is-open")`으로 열고/닫기를 전환합니다. `is-open`이 붙으면 CSS가 메뉴를 보여 줍니다.
   - **(4번 블록) document 클릭** → "화면 어디든 클릭되면 메뉴를 닫아라"라고 미리 정해 둡니다. 이것이 바깥 클릭을 잡는 장치입니다.
   - **(2·3번 블록의 `event.stopPropagation()`)** → 버튼과 메뉴 안에서 일어난 클릭은 여기서 멈춥니다. 그래서 `document`까지 전해지지 않아, "방금 연 메뉴가 곧바로 닫히는" 사고를 막습니다.
6. **이벤트 버블링이 뭔지 눈으로 확인하기**: `event.stopPropagation();`이 적힌 줄(스크립트의 13번째 줄 부근, 버튼 클릭 안)을 잠시 `// event.stopPropagation();`처럼 주석 처리하고 저장한 뒤 새로고침합니다. 이제 버튼을 누르면 메뉴가 **열렸다가 즉시 닫혀** 아무 반응이 없는 것처럼 보입니다. 이는 "버튼 클릭 → 열기" 직후 같은 클릭이 화면 전체로 퍼져 "document 클릭 → 닫기"까지 연달아 실행되기 때문입니다. 확인했으면 주석을 다시 풀어 원래대로 되돌립니다.
7. 직접 바꿔 보기: `index.html`의 `<ul class="dropdown-menu">` 안에 `<li role="menuitem"><a href="#">고객센터</a></li>` 한 줄을 추가하고 저장 후 새로고침합니다. JS는 한 줄도 고치지 않아도 새 항목이 그대로 메뉴에 나타납니다.

## 검증법

- 버튼을 누르면 메뉴가 펼쳐지고, **메뉴 바깥**(회색 안내 영역, 빈 화면 등)을 누르면 닫히면 성공입니다.
- 메뉴 **안의 항목**을 클릭했을 때는 메뉴가 곧바로 닫히지 않아야 합니다(항목 자체가 동작해야 하므로). 안쪽 클릭으로 닫혀 버린다면 3번 블록의 `stopPropagation`이 빠진 것입니다.
- 메뉴가 열렸을 때 화살표가 ▴(위 방향)로 바뀌고, 닫히면 ▾(아래 방향)로 돌아오는지 확인합니다.
- 키보드 `Esc` 키를 누르면 열린 메뉴가 닫히는지 확인합니다(보너스 기능).
- 6단계 실험에서 `stopPropagation`을 빼면 메뉴가 열리자마자 닫혀 버리는 것을 직접 확인했다면, 이벤트 버블링을 제대로 이해한 것입니다.
- (보조기기 확인) 개발자 도구로 버튼을 살펴보면, 메뉴가 열렸을 때 `aria-expanded="true"`, 닫혔을 때 `false`로 바뀌는지 확인할 수 있습니다.
