# 전화번호 패턴 검증과 안내 메시지 (pattern·title)

입력값이 정해진 "형식"을 따르도록 JavaScript 없이 HTML 속성만으로 검사하는 실습입니다. `pattern` 속성에 형식 규칙(정규식)을 적으면, `010-1234-5678` 같은 모양이 아닐 때 브라우저가 제출을 막고 안내 풍선을 띄워줍니다. 이때 보여줄 안내 문장은 `title` 속성에 적습니다.

## 목표

- `pattern` 속성에 정규식을 적어 "숫자3개-숫자4개-숫자4개" 같은 형식을 강제하는 법을 익힌다.
- 정규식 기초 기호 `[0-9]`(숫자 한 글자), `{3}`(앞 규칙 3번 반복), `-`(하이픈 글자 그대로)의 의미를 읽을 수 있다.
- `title` 속성에 적은 글이 형식 오류 시 안내 풍선으로 뜨는 것을 직접 확인한다.

## 따라하는 단계

1. `index.html` 파일을 더블클릭해서 웹 브라우저로 엽니다. (별도 설치나 서버가 필요 없습니다.)
2. 전화번호 칸에 `01012345678`처럼 하이픈(-) 없이 숫자만 넣고 파란색 **제출하기** 버튼을 눌러봅니다. 형식이 맞지 않아 제출이 막히고, `title`에 적어둔 "010-1234-5678 형식으로, 숫자와 하이픈(-)만 사용해 입력하세요." 안내가 풍선으로 뜹니다.
3. 이번엔 `010-123-5678`처럼 가운데를 3자리로 넣고 눌러봅니다. `pattern`은 가운데를 4자리(`[0-9]{4}`)로 요구하므로 역시 막힙니다.
4. `010-1234-5678`처럼 올바른 형식으로 고쳐 적으면 칸 테두리가 초록색으로 바뀝니다.
5. 올바른 형식으로 채우고 제출하기를 누르면 "제출 완료!" 초록 메시지가 나타납니다.
6. `index.html`을 열어 `title` 속성의 문장을 다른 안내문으로 바꿔 저장하고 새로고침한 뒤, 형식이 틀린 값을 다시 제출해 풍선 메시지가 바뀌는 것을 확인해봅니다.

## 검증법

- 하이픈 없는 번호(`01012345678`)를 넣고 제출하면 제출이 막히고 안내 풍선이 뜬다 → `pattern`이 작동하는 것입니다.
- 가운데 자릿수가 다른 번호(`010-123-5678`)도 막힌다 → `[0-9]{4}`(정확히 4자리) 규칙이 작동하는 것입니다.
- 형식 오류 시 뜨는 풍선 문구가 `title`에 적은 문장과 같다 → `title`이 안내 메시지로 쓰인 것입니다.
- 올바른 형식(`010-1234-5678`)으로 채우면 테두리가 초록색이 되고, 제출 시 초록색 "제출 완료!" 메시지가 보인다.

## 핵심 정리

- `pattern`은 입력값이 따라야 할 형식 규칙(정규식)을 적는 속성입니다. 입력값 전체가 이 규칙과 정확히 일치해야 통과합니다.
  - `[0-9]` : 0부터 9까지 숫자 한 글자
  - `{3}` : 바로 앞 규칙을 정확히 3번 반복
  - `-` : 하이픈(-) 글자 그대로
  - 따라서 `[0-9]{3}-[0-9]{4}-[0-9]{4}`는 "숫자3개-숫자4개-숫자4개"(예: 010-1234-5678)를 뜻합니다.
- `title`은 `pattern`과 짝꿍입니다. 형식이 틀렸을 때 브라우저가 보여줄 안내 문장을 여기에 적어두면 사용자가 무엇이 잘못됐는지 알 수 있습니다. (적지 않으면 밋밋한 기본 메시지만 떠서 불친절합니다.)
- `pattern`은 빈 칸은 검사하지 않습니다. "비어 있으면 안 된다"는 별개로 `required`를 함께 붙여야 합니다.
- 이 검사는 **사용자 편의를 위한 1차 방어선**일 뿐입니다. 사용자가 개발자 도구로 속성을 지우거나 직접 데이터를 보내면 우회할 수 있습니다. 실제 서비스에서는 데이터를 받는 서버(예: Supabase) 쪽에서도 반드시 다시 검사해야 합니다. 브라우저 검증만으로 보안이 끝나지 않는다는 점을 기억하세요.
