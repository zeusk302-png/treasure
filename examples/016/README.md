# 페이지 안에서 이동하는 목차 링크(앵커) 만들기

긴 글의 맨 위에 목차를 두고, 목차 항목을 누르면 그 항목이 설명된 부분으로 화면이 '점프'하도록 만드는 실습입니다. 위키백과 글 맨 위에 있는 목차나, 긴 약관 페이지의 '바로가기' 같은 기능을 직접 만들어 봅니다.

## 목표

- 같은 페이지 안에서 특정 위치로 이동하는 **내부 앵커 링크**를 만든다.
- 이동할 목적지에 `id`를 붙이고, 링크의 `href`에 `#그id` 를 적으면 짝이 맞아 이동한다는 원리를 이해한다.
- 글 맨 위로 다시 올라가는 '맨 위로' 링크도 같은 방법으로 만든다.

## 따라하는 단계

1. `index.html` 파일을 웹 브라우저(크롬, 엣지 등)로 엽니다. 더블클릭하면 열립니다.
2. 페이지 맨 위에 있는 **목차** 박스에서 항목을 하나 눌러 봅니다. 예) "3. CSS 살펴보기".
3. 화면이 해당 섹션으로 부드럽게 이동하는 것을 확인합니다.
4. 코드를 열어 원리를 확인합니다. 이동할 곳(목적지)에는 다음처럼 `id`를 붙입니다.
   ```html
   <section id="css">
   ```
5. 목차의 링크에는 `#` 뒤에 그 `id`와 똑같은 이름을 적습니다. (`id="css"` ↔ `href="#css"`)
   ```html
   <a href="#css">3. CSS 살펴보기</a>
   ```
6. 즉, `href="#이름"` 의 `이름` 과 어딘가에 있는 `id="이름"` 이 짝을 이루면, 링크를 누를 때 그 위치로 이동합니다. 이름이 한 글자라도 다르면 이동하지 않으니 철자를 정확히 맞춰야 합니다.
7. 각 섹션 끝의 **↑ 맨 위로** 링크도 같은 원리입니다. 맨 위 제목에 `id="top"` 을 달아두고, 링크는 `href="#top"` 으로 적었습니다.
8. 새 섹션을 하나 추가해 보며 연습합니다. 섹션에 `id="new"` 를 붙이고, 목차에 `<li><a href="#new">5. 새 항목</a></li>` 를 추가하면 됩니다.

## 검증법

- 목차의 각 항목(1~4)을 눌렀을 때 화면이 해당 제목 위치로 이동하면 성공입니다.
- 브라우저 주소창을 보면 이동할 때마다 주소 끝이 `...index.html#css` 처럼 `#섹션이름` 으로 바뀝니다. 이것이 앵커가 작동했다는 신호입니다.
- 각 섹션 아래 **↑ 맨 위로** 를 누르면 페이지 맨 위 제목으로 돌아오면 성공입니다.
- 일부러 목차의 `href="#css"` 를 `href="#cssX"` 처럼 틀리게 바꾸면 눌러도 이동하지 않습니다. 이를 통해 `id` 와 `href` 의 이름이 정확히 같아야 한다는 점을 확인할 수 있습니다.
