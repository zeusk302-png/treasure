1. 웹이란 무엇인가

웹(Web)은 인터넷 위에서 서로 연결된 문서들의 거대한 그물망입니다. 우리가 매일 보는 웹페이지도 사실은 글자로 적힌 문서일 뿐이고, 브라우저가 그 문서를 읽어서 화면에 예쁘게 그려줍니다.

이 안내서를 따라 읽다 보면 웹페이지가 어떻게 만들어지는지 큰 그림을 잡을 수 있습니다. 위 목차에서 원하는 항목을 누르면 해당 부분으로 바로 이동합니다.

↑ 맨 위로

2. HTML 살펴보기

HTML은 웹페이지의 '뼈대'입니다. 제목, 문단, 목록, 이미지처럼 페이지에 무엇이 들어갈지를 태그(tag)로 표시합니다.

예를 들어 큰 제목은 <h1>, 문단은 <p> 태그로 적습니다. 태그는 대부분 여는 태그와 닫는 태그가 한 쌍을 이룹니다.

↑ 맨 위로

3. CSS 살펴보기

CSS는 웹페이지의 '옷'입니다. 색깔, 글꼴, 여백, 배치처럼 어떻게 보일지를 정합니다. HTML이 뼈대라면 CSS는 그 위에 입히는 디자인이라고 생각하면 쉽습니다.

같은 HTML이라도 CSS만 바꾸면 전혀 다른 느낌의 페이지가 됩니다.

↑ 맨 위로

4. 자바스크립트 살펴보기

자바스크립트는 웹페이지의 '동작'을 담당합니다. 버튼을 누르면 반응하거나, 입력한 값을 처리하는 등 페이지를 살아 움직이게 만듭니다.

HTML(뼈대) + CSS(디자인) + 자바스크립트(동작), 이 세 가지가 웹페이지를 이루는 기본 재료입니다. 여기까지 읽으셨다면 웹의 큰 그림을 모두 본 셈입니다!
