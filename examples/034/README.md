# 실습 034 — flexbox로 박스를 화면 정중앙에 놓기

"박스 하나를 화면 한가운데에 놓기." 말은 쉬워 보이지만, 웹을 처음 배우는 사람이 가장 오래 헤매는 것 중 하나가 바로 이 **세로 가운데 정렬**입니다. 가로 가운데는 그럭저럭 맞춰도, 위아래 한가운데로 박스를 옮기는 일은 막막하죠. 정답은 의외로 짧습니다. 가운데로 보내고 싶은 박스가 아니라, **그 박스를 감싸는 부모 상자**에 딱 세 줄이면 됩니다. `display: flex;`로 flex를 켜고, `justify-content: center;`로 가로 가운데를, `align-items: center;`로 세로 가운데를 잡습니다. 이번 실습에서는 화면 전체를 '무대(`.stage`)'로 삼고, 그 안에 카드 박스 하나(`.card`)를 넣어 어떤 창 크기에서도 항상 정중앙에 머무는 화면을 만듭니다. 파일은 `index.html` 하나뿐이고 서버도 인터넷도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 가운데 정렬은 **자식(가운데로 보낼 박스)이 아니라 부모(감싸는 상자)**에 설정한다는 핵심 규칙을 이해한다.
- `justify-content: center`(**가로** 가운데)와 `align-items: center`(**세로** 가운데)를 함께 써서 박스를 화면 **정중앙**에 두는 법을 마스터한다.
- 세로 가운데가 되려면 부모의 **높이가 있어야 한다**는 점(`min-height: 100vh` = 화면 세로 전체)을 이해한다. 초보가 가장 자주 빠지는 함정입니다.

핵심은 부모 상자의 딱 세 줄입니다.

```
부모 상자 .stage {
  display: flex;             ← flex 켜기 (이게 있어야 아래 두 줄이 동작함)
  justify-content: center;   ← 가로(좌우) 가운데
  align-items: center;       ← 세로(상하) 가운데
  min-height: 100vh;         ← 무대 높이를 화면 전체로 (세로 중앙의 전제 조건)
}
```

| 속성 | 방향 | 역할 |
|---|---|---|
| `justify-content: center` | 주축 = **가로(→)** | 좌우 가운데로 모음 |
| `align-items: center` | 교차축 = **세로(↓)** | 상하 가운데로 모음 |
| `min-height: 100vh` | — | 무대 높이를 화면만큼 확보 (없으면 세로 중앙이 안 됨) |

외우는 법: **justify = 가로, align = 세로.** 둘 다 `center`면 정중앙입니다.

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열립니다. (인터넷 연결이 필요 없습니다.)
2. 흰색 카드 박스가 파란 무대의 **정중앙(가로·세로 모두 가운데)**에 놓여 있는지 확인합니다.
3. 브라우저 창의 크기를 마우스로 **줄였다 늘렸다** 해 봅니다. → 창이 작아지든 커지든, 박스는 **항상 한가운데**에 머뭅니다. 위치를 고정 숫자로 정한 게 아니라 "가운데로 모아라"라고 시켰기 때문입니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어, `.stage` 규칙의 `align-items: center;` 줄을 주석으로 막아 봅니다. 즉 `align-items: center;` → `/* align-items: center; */` 로 바꾸고 저장한 뒤 브라우저에서 **새로고침(F5)** 합니다. → 박스가 **가로는 가운데지만 세로는 맨 위**로 올라붙습니다. 세로 가운데가 이 한 줄 덕분이었음을 알 수 있습니다. 확인 후 주석을 풀어 되돌립니다.
5. 이번엔 `justify-content: center;`를 주석으로 막고 새로고침합니다. → 박스가 **세로는 가운데지만 가로는 왼쪽**에 붙습니다. 가로 가운데가 이 줄 덕분임을 확인하고 되돌립니다.
6. 세로 중앙의 함정 체험: `.stage`의 `min-height: 100vh;`를 주석으로 막고 새로고침합니다. → `align-items: center;`가 그대로 있어도 박스가 화면 위쪽에 붙습니다. **무대의 높이가 없으면 세로 가운데를 잡을 공간 자체가 없기 때문**입니다. 다시 되돌립니다.
7. AI에게 시켜 보기:
   > "이 index.html의 `.stage` 안에 카드 박스를 2개로 늘리고, 두 박스가 **세로로 위아래 가운데에** 나란히 놓이도록 `flex-direction: column;`을 추가해줘. `justify-content`·`align-items`는 그대로 두고."

## 검증법
- **눈으로 확인**: 흰 카드가 화면의 **가로 가운데 + 세로 가운데**, 즉 정중앙에 보이면 성공입니다. 창 크기를 바꿔도 가운데를 유지하면 제대로 된 것입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 `<div class="stage">`를 클릭한 뒤, 오른쪽 `Styles`(스타일) 탭에서 `display: flex;`, `justify-content: center;`, `align-items: center;` 세 줄이 모두 적용돼 있는지 봅니다. 같은 자리에서 `align-items` 값을 `center` → `flex-start`로 바꿔 보면 박스가 위로 올라붙는 것을 즉시 확인할 수 있습니다.
- **속성 분리 검증**: 4·5번 단계처럼 `align-items`를 끄면 세로 중앙이 풀리고, `justify-content`를 끄면 가로 중앙이 풀리며, 6번처럼 `min-height: 100vh`를 끄면 세로 중앙이 안 되는 것을 직접 확인하면, 세 속성의 역할을 정확히 다루고 있는 것입니다.
