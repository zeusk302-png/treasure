재사용 컴포넌트(버튼·카드) 데모

같은 UI를 복붙하지 않고, 한 번 정의해 여러 곳에서 갖다 씁니다.

방법 1 — 웹 컴포넌트 <ui-button>, <ui-card>

아래 버튼들은 모두 <ui-button>이라는 "내가 만든 태그"입니다. 버튼 모양/색의 진짜 정의는 script.js에 한 벌만 있고, 여기서는 그냥 태그처럼 부릅니다. 색은 variant 속성으로 바꿉니다.

저장 취소 삭제

아래 카드도 마찬가지입니다. <ui-card>에 title·body 속성으로 내용만 다르게 넣으면, 같은 틀에서 다른 카드가 나옵니다.

방법 2 — 템플릿 함수로 카드 찍어내기

웹 컴포넌트가 어렵게 느껴지면, 더 쉬운 방법도 있습니다. 아래 카드들은 script.js의 cardHtml() 함수가 데이터 배열을 돌며 만들어 줍니다. 같은 모양이지만 만든 방식만 다릅니다.
