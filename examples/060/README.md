# 더보기 / 접기 텍스트 토글 만들기

긴 글의 앞부분만 먼저 보여주고, "더보기" 버튼을 누르면 나머지가 펼쳐지고 "접기"를 누르면 다시 숨겨지는 작은 페이지입니다. 자바스크립트로 화면 요소를 **보였다 숨겼다(show/hide)** 하는 가장 기본 패턴을 익힙니다.

## 목표

- 요소를 화면에서 숨기는 가장 쉬운 방법인 `hidden` 속성을 익힙니다.
- 버튼을 누를 때마다 "숨김 ↔ 보임" 상태가 번갈아 바뀌는 **토글(toggle)** 흐름을 이해합니다.
- 상태에 따라 버튼 글자도 "더보기 ↔ 접기"로 함께 바꿔 사용자에게 친절한 화면을 만듭니다.

## 따라하는 단계

1. 이 폴더(`060`)를 통째로 컴퓨터에 두고, 폴더 안의 `index.html`을 더블 클릭해 브라우저(크롬 등)로 엽니다.
2. 글의 앞부분(요약)과 그 아래에 "더보기" 버튼이 보이는지 확인합니다. 뒷부분 글은 처음엔 보이지 않아야 정상입니다.
3. `index.html`을 살펴봅니다. 숨겨질 글은 `<div id="moreText" hidden>` 안에 들어 있습니다. 여기 붙은 `hidden`이 "지금은 숨겨라"라는 뜻이라, 처음엔 화면에서 사라져 있습니다.
4. `script.js`를 엽니다. 코드는 세 단계입니다.
   - `document.getElementById("moreText")` 로 숨겨진 글을, `getElementById("toggleBtn")` 으로 버튼을 찾습니다.
   - 버튼에 `addEventListener("click", ...)` 로 클릭 동작을 연결합니다.
   - 클릭될 때 `moreText.hidden` 값을 확인해서, 숨김이면 펼치고(`hidden = false`) 보임이면 접습니다(`hidden = true`). 동시에 버튼 글자도 "더보기 ↔ 접기"로 바꿉니다.
5. 브라우저로 돌아가 "더보기" 버튼을 눌러봅니다. 뒷부분 글이 펼쳐지고 버튼 글자가 "접기"로 바뀌면 성공입니다.
6. "접기"를 다시 눌러 글이 사라지고 버튼이 "더보기"로 돌아오는지 확인합니다.
7. (더 해보기) `script.js`의 `if/else` 부분을 주석에 적힌 한 줄 `moreText.hidden = !moreText.hidden;` 로 바꿔도 똑같이 동작하는지 실험해 봅니다.

## 검증법

- 처음 화면: 요약 글 + "더보기" 버튼만 보이고, 뒷부분 글은 안 보이면 정상입니다.
- "더보기"를 누르면: 뒷부분 글이 나타나고 버튼 글자가 "접기"로 바뀌면 정상입니다.
- "접기"를 누르면: 뒷부분 글이 다시 사라지고 버튼이 "더보기"로 돌아오면 정상입니다.
- 여러 번 연달아 눌러도 펼침/접힘이 매번 정확히 번갈아 일어나면 토글이 제대로 된 것입니다.
- 만약 동작하지 않는다면: 세 파일(`index.html`, `style.css`, `script.js`)이 같은 폴더에 있는지, `index.html` 안의 `<script src="script.js"></script>`가 `</body>` 바로 위에 있는지, 그리고 `id`가 HTML(`moreText`, `toggleBtn`)과 자바스크립트에서 똑같이 적혔는지 확인하세요.

## 핵심 개념

- `hidden` 속성 : 요소에 `hidden`이 붙으면 브라우저가 기본으로 `display:none` 처리해 화면에서 숨깁니다. 자바스크립트에서 `요소.hidden = true`(숨김) / `false`(보임) 로 켜고 끌 수 있습니다.
- 토글(toggle) : "지금 상태를 반대로 뒤집기". `if`로 현재 상태를 확인해 바꾸거나, `!`(부정) 연산자로 `요소.hidden = !요소.hidden` 처럼 한 번에 뒤집을 수 있습니다.
- `textContent` : 버튼 안의 글자를 자바스크립트로 바꿉니다. 상태가 바뀌면 안내 문구도 함께 바꿔주는 게 사용자에게 친절합니다.
- `aria-expanded` : 지금 펼쳐졌는지(`true`)/접혔는지(`false`)를 화면 낭독기 같은 보조기기에 알려주는 접근성 표시입니다.
