# 내 포트폴리오 사이트 기획서 (PLAN.md)

> 이 파일이 이 실습의 **결과물(제출물)** 입니다.
> 아래는 예시 답(가상의 학생 "민지")으로 채워져 있습니다.
> **[ ]** 안의 내용을 지우고 **여러분이 AI 인터뷰에서 직접 답한 내용**으로 바꿔 주세요.
> ([`prompt.md`](prompt.md)로 AI를 인터뷰어로 만들고, [`conversation.md`](conversation.md)의 흐름을 참고)

---

## 목표

- 이 사이트로 이루고 싶은 것 한 줄:
  > 디자인 분야 취업 지원 시, 이력서 대신 **링크 하나로 내 작업물을 보여준다.**

## 대상 (누가 보는가)

- 주로 볼 사람:
  > 회사 채용 담당자 (휴대폰으로 열어볼 수도 있음)

## 페이지·섹션

- 형태: **한 장짜리(one-page)** — 위에서 아래로 스크롤
  1. 상단: 이름 + 한 줄 소개
  2. 소개: 나를 설명하는 한 문단
  3. 작업물: 프로젝트 3개 (이미지 + 제목 + 설명)
  4. 연락: 이메일 주소(텍스트로 표시)

## 꼭 들어갈 것

- [x] 내 소개 한 문단
- [x] 작업물 3개
- [x] 이메일 주소
- [x] 휴대폰에서도 안 깨지게(반응형)

## 범위 밖 (이번엔 안 함)

> 욕심을 줄여야 작은 사이트라도 **완성**할 수 있습니다. "안 할 것"을 정하는 게 이 실습의 핵심입니다.

- 연락처 수집 폼 / 자동 메일 보내기 (→ 다음 버전)
- 블로그, 방문자 통계
- 로그인 / 회원가입
- 다국어(영어 등)

## 다음에 정할 것 (미정)

> AI가 **지어내지 않고** 솔직히 "아직 안 정함"으로 남긴 항목입니다.

- 색/폰트 등 디자인 톤
- 작업물 3개의 실제 이미지·설명 문구

---

## 작성 후 자가 점검

- [ ] **목표**가 한 줄로 분명한가? ("멋지게" 같은 모호한 말 말고, "무엇을 위해"가 있는가)
- [ ] **대상**이 누구인지 적었는가?
- [ ] **꼭 들어갈 것**과 **범위 밖(안 할 것)** 이 둘 다 있는가? (범위 밖이 비어 있으면 욕심을 못 줄인 것)
- [ ] 내가 **분명히 말하지 않은 것**은 억지로 채우지 않고 "다음에 정할 것"에 두었는가?
- [ ] 한 줄씩 읽었을 때 **"이거 내가 진짜 정한 거 맞나?"** 가 전부 "맞다"인가? (AI가 상상으로 채운 게 없는가)
