# 실습 036 — flex-wrap으로 줄바꿈되는 태그 목록 만들기

블로그 글 밑에 붙는 **#해시태그**, 쇼핑몰의 **필터 키워드**, 이력서의 **기술 스택 뱃지**. 이런 작고 둥근 라벨을 흔히 **칩(chip)** 또는 **태그**라고 부릅니다. 문제는 칩의 개수가 들쭉날쭉하고, 화면 너비도 PC·태블릿·휴대폰마다 다르다는 점입니다. 한 줄에 7개가 들어가는 화면도 있고 3개밖에 못 넣는 화면도 있죠. 이때 칩이 한 줄에 다 안 들어가면 **알아서 아랫줄로 넘어가게** 만드는 것이 핵심입니다. 비밀은 칩들을 감싼 **부모 상자**에 주는 단 세 줄, `display: flex;` · `flex-wrap: wrap;` · `gap: 10px;` 입니다. `flex-wrap: wrap;`이 "한 줄에 안 들어가면 다음 줄로 접어라"를 담당하고, `gap`이 "칩끼리, 그리고 줄과 줄 사이의 틈"을 한 번에 책임집니다. 이번 실습에서는 기술 스택 칩 14개와 관심 분야 칩 9개로 진짜 같은 태그 목록을 만들어 봅니다. 파일은 `index.html` 하나뿐이고 서버도 인터넷도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 칩 목록은 **칩들을 한 줄로 펴는 flex 부모 + 자동 줄바꿈**이라는 구조임을 이해한다. (부모 `.tags` / 자식 `.tag` 여러 개)
- `flex-wrap: wrap;`이 "한 줄에 안 들어가면 아랫줄로 접는다"는 동작을 창 크기를 바꿔 가며 눈으로 확인한다.
- `gap`이 가로 간격뿐 아니라 **줄바꿈됐을 때 윗줄·아랫줄 사이 간격까지** 한 번에 챙겨 준다는 점을 익힌다. (옛날처럼 `margin`을 일일이 안 줘도 됨)
- 같은 구조(`flex-wrap`·`gap`)를 **색만 바꿔 재사용**하는 감각을 경험한다.

핵심은 부모 상자에 주는 딱 세 줄입니다.

```
.tags {
  display: flex;     ← 칩들을 가로 한 줄로 나란히 놓는다
  flex-wrap: wrap;   ← 한 줄에 안 들어가면 아랫줄로 넘긴다(핵심!)
  gap: 10px;         ← 칩 사이 + 줄 사이 틈을 한 번에 준다
}
```

| 항목 | 역할 | 없으면 / 끄면 |
|---|---|---|
| `display: flex;` | 칩을 가로 한 줄로 편다 | 칩이 세로로 쌓인다 |
| `flex-wrap: wrap;` | 넘치면 아랫줄로 접는다 | 한 줄에 욱여넣어 칩이 찌그러지거나 화면 밖으로 삐져나간다 |
| `gap: 10px;` | 칩·줄 사이 틈 | 칩들이 서로 딱 붙어 답답해 보인다 |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저에서 페이지가 열리고, 둥근 칩(태그)들이 보기 좋게 줄지어 나타납니다. (인터넷 연결이 필요 없습니다.)
2. 흰 상자 안의 칩들을 봅니다. → 칩 사이에 일정한 틈이 있고, 한 줄에 다 못 들어간 칩은 **자연스럽게 아랫줄로 넘어가** 있으면 정상입니다.
3. 브라우저 창 너비를 마우스로 **천천히 좁혔다 넓혔다** 해봅니다. → 창이 좁아지면 칩들이 알아서 줄을 바꿔 차곡차곡 쌓이고, 넓히면 다시 윗줄로 올라붙습니다. 이것이 `flex-wrap: wrap;`의 힘입니다.
4. `index.html`을 메모장(또는 VS Code)으로 열어, `.tags` 규칙의 `flex-wrap: wrap;` 줄을 잠시 주석으로 막아 봅니다. 즉 `/* flex-wrap: wrap; */` 로 바꾸고 저장한 뒤, 브라우저에서 **새로고침(F5)** 합니다. → 칩들이 줄바꿈을 못 하고 **한 줄에 억지로 욱여넣어져** 찌그러지거나 오른쪽으로 삐져나갑니다. 줄바꿈이 오직 이 한 줄 덕분이었음을 알 수 있습니다. 확인했으면 주석을 풀어 되돌리세요.
5. 이번엔 `gap: 10px;`의 숫자만 바꿔 가며 새로고침해 보세요. → `gap: 4px;`(칩이 다닥다닥), `gap: 24px;`(칩이 시원하게 떨어짐)처럼 틈이 달라집니다. 특히 칩이 여러 줄로 접힌 상태에서 **윗줄과 아랫줄 사이 간격까지** 함께 변하는 것을 확인하세요. 다 본 뒤 `10px`로 되돌립니다.
6. 칩을 직접 더 추가해 봅니다. → `<div class="tags">` 안에 `<span class="tag">새 태그</span>` 줄을 몇 개 복사해 붙여 넣고 저장 후 새로고침하면, 늘어난 칩이 알아서 줄을 더 만들어 접힙니다. 우리가 줄 수를 정해 줄 필요가 전혀 없습니다.
7. `.tag` 규칙의 `border-radius: 999px;` 숫자를 `4px`로 바꿔 새로고침해 보세요. → 알약 모양이던 칩이 각진 사각 라벨로 바뀝니다. 둥글기는 취향대로 조절할 수 있다는 걸 확인하고 되돌리세요.
8. AI에게 시켜 보기:
   > "이 index.html의 `.tag` 칩에 마우스를 올리면(`:hover`) 배경색이 살짝 진해지고 손가락 커서가 뜨도록 CSS를 추가해줘. 기존 `display: flex;`·`flex-wrap: wrap;`·`gap`은 그대로 두고."

## 🤖 바이브코딩 프롬프트
이 실습(자동 줄바꿈되는 칩/태그 목록)을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 비전공자를 가르치는 프런트엔드 멘토야.
  HTML 파일 하나(index.html)만으로, 서버나 인터넷 없이 더블클릭하면 바로 열리는
  '태그(칩) 목록' 페이지를 만들어줘.

  요구사항:
  - <style>를 같은 파일 안에 두고, CSS를 따로 빼지 마(한눈에 보게).
  - 칩들을 감싸는 부모 상자 .tags 에는 display: flex; flex-wrap: wrap; gap: 10px; 를 줘서,
    칩이 한 줄에 다 안 들어가면 자동으로 아랫줄로 넘어가게 해.
  - 칩 하나(.tag)는 알약 모양(border-radius를 아주 크게)이고, 안쪽 여백(padding)이 있어야 해.
  - "기술 스택" 칩 14개 정도를 <span class="tag">…</span> 형태로 넣어줘.
  - charset은 UTF-8, lang="ko" 로 한글이 안 깨지게 해줘.

  코드만 주지 말고, 초보가 막힐 만한 줄에는 '무엇을 하는지 + 왜 그렇게 했는지'를
  한국어 주석으로 한 줄씩 달아줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  좋아. 이제 같은 페이지를 다음처럼 개선해줘. 기존 display: flex; flex-wrap: wrap; gap 은 그대로 두고.

  1) 색만 다른 두 번째 칩 묶음을 추가해줘. .tag.green 클래스로 글자색·배경색만 바꾸고,
     구조(flex-wrap, gap)는 첫 번째 묶음과 똑같이 재사용해.
  2) 칩에 마우스를 올리면(:hover) 배경색이 살짝 진해지고 손가락 커서(cursor: pointer)가 뜨게 해줘.
  3) 휴대폰처럼 화면이 좁아져도 칩이 자연스럽게 여러 줄로 접히는지 설명해줘.

  바꾼 부분마다 '왜 이렇게 했는지'를 주석으로 남겨줘. 비전공자가 이해하게 한 줄씩 풀어서.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  칩이 자동으로 줄바꿈되지 않고 한 줄에 다 욱여넣어져서 찌그러지거나 화면 밖으로 삐져나가.
  아래는 내 .tags CSS 코드야. 무엇이 문제인지 한 가지씩 짚어주고,
  flex-wrap·display·gap 중 어디를 어떻게 고쳐야 하는지 알려줘.
  고친 이유도 비전공자가 알아듣게 설명해줘.

  [여기에 내 .tags { ... } 코드를 붙여넣기]
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면, 결과 코드가 곧 학습 교재가 됩니다.

## 검증법
- **눈으로 확인**: 칩들이 가로로 늘어서 있고, 한 줄에 안 들어간 칩이 **아랫줄로 가지런히 넘어가** 있으면 성공입니다. 칩이 세로로 한 줄씩 쌓여 있다면 `display: flex;`가 빠진 것이고, 한 줄에 다 욱여넣어져 찌그러져 있다면 `flex-wrap: wrap;`이 빠졌거나 오타가 난 것입니다.
- **창 크기 검증**: 3번 단계처럼 창 너비를 좁혔다 넓혔다 할 때, 줄 수가 자동으로 늘었다 줄었다 하면 `flex-wrap`이 제대로 동작하는 것입니다.
- **간격 검증**: 칩끼리, 그리고 윗줄·아랫줄 사이에 일정한 틈이 보이면 `gap`이 잘 적용된 것입니다. 칩들이 서로 딱 붙어 있다면 `gap` 값이 0이거나 오타입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 `<div class="tags">`를 클릭한 뒤, 오른쪽 `Styles`(스타일) 탭에서 `display: flex;`·`flex-wrap: wrap;`·`gap`이 적용돼 있는지 봅니다. 같은 자리에서 `flex-wrap` 값을 `nowrap`으로 바꿔보면 화면에서 칩이 즉시 한 줄로 욱여넣어지는 것도 확인할 수 있습니다.
