# 219. AI에게 "추정인지 확인된 사실인지 표시해줘" 요구하기

## 목표

AI에게 정보를 물을 때, **각 항목이 "공식 문서로 확인된 사실"인지 "AI 기억에 기댄 추정"인지
스스로 라벨을 붙이게** 만드는 연습입니다.

AI는 모르는 것도 아는 척, 없는 것도 있는 척 **그럴듯하게 지어냅니다.**
이걸 **'환각(hallucination)'**, 우리말로 "없는 걸 진짜처럼 지어냄"이라고 합니다.
특히 **함수 이름·API 주소(URL)** 는 한 글자만 틀려도 코드가 멈추기 때문에,
"이건 확실, 저건 추정"을 AI가 표시하게 해서 **어디를 직접 검증해야 할지** 가려냅니다.

이 실습에는 새로 짤 코드가 거의 없습니다. **환각을 거르도록 잘 지시하는 글쓰기**가 곧 실습입니다.
소재는 "오늘 날씨를 표시할 공개 API 찾기"이고,
결과물은 **각 항목에 `[공식문서 확인]` / `[추정]` 라벨이 붙은 답변 캡처**입니다.

이 폴더의 파일은 셋입니다.

- [`prompt.md`](prompt.md) — AI에게 그대로 붙여넣는 "라벨 붙여서 답해줘" 지시 프롬프트
- [`conversation.md`](conversation.md) — AI가 항목마다 라벨을 붙여 답한 대화 캡처(예시)
- `README.md` — 지금 읽는 이 안내문

## 따라하는 단계

1. [`prompt.md`](prompt.md)를 열어 **1단계 지시 프롬프트**를 통째로 복사합니다. 핵심은 "각 항목에 `[공식문서 확인]` / `[추정]` 라벨을 붙이고, URL을 지어내지 말라"는 제약입니다.
2. 복사한 프롬프트를 실제 Claude(또는 쓰는 AI)에 붙여넣습니다.
3. AI의 답을 봅니다. **모든 항목(이름·URL·무료 여부)에 라벨이 붙어 있는지** 확인합니다.
4. 만약 AI가 라벨을 빼먹고 URL을 단정하면, [`prompt.md`](prompt.md)의 **2단계 한 마디**("라벨 빼먹었어, 확실치 않으면 [추정]으로")로 다시 잡아 줍니다.
5. (선택) 가장 중요한 API 하나를 골라 [`prompt.md`](prompt.md)의 **3단계**로 "그 URL 어디서 봤어?"라고 출처를 캐물어 봅니다. AI가 "공식 문서 미확인, 추정"이라고 솔직히 말하면 잘 작동한 것입니다.
6. **가장 중요한 마무리:** `[추정]` 라벨이 붙은 URL을 **브라우저 주소창에 직접 붙여넣어** 진짜 존재하는지, AI가 말한 공식 문서 주소가 실제로 열리는지 사람이 직접 확인합니다.
7. (제출용) 항목마다 `[공식문서 확인]` / `[추정]` 라벨이 보이고, 맨 아래에 "사람이 직접 확인할 목록"이 정리된 **답변 화면을 캡처**해 두면 이 실습의 핵심 증거가 됩니다. (예시 흐름은 [`conversation.md`](conversation.md))

## 검증법

아래를 모두 만족하면 성공입니다.

- [ ] AI 답변의 **모든 항목(이름·URL·무료 여부)에 `[공식문서 확인]` 또는 `[추정]` 라벨**이 붙어 있다.
- [ ] 확실치 않은 **URL을 단정하지 않고** `[추정]`으로 표시하며, "공식 문서에서 확인 필요"라고 솔직히 밝혔다.
- [ ] 답변 끝에 **"사람이 직접 확인할 항목" 목록**이 따로 정리되어 있다.
- [ ] `[추정]` 라벨이 붙은 URL 중 하나라도 **브라우저에서 직접 열어** 진짜인지/가짜인지 사람이 확인했다.

> 빠르게 자가 점검: 답변을 훑었을 때 **"이건 확실, 저건 의심"이 한눈에 구분되면** 통과입니다.
> 모든 문장이 똑같이 단정적이라면 라벨링이 안 된 것이니, 2단계 한 마디로 다시 요구하세요.
