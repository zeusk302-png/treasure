# 219. "추정인지 확인된 사실인지 표시해줘" 지시 프롬프트

> 이 파일은 **AI에게 그대로 붙여넣는 지시문**입니다.
> 핵심은 한 가지 — AI에게 무언가를 물을 때
> **"각 항목이 공식 문서로 확인된 사실인지, 아니면 네 기억에 기댄 추정인지 라벨을 붙여줘"** 라고 못 박는 것입니다.
>
> AI는 모르는 것도 아는 척, 없는 것도 있는 척 **그럴듯하게 지어냅니다.**
> 이걸 **'환각(hallucination)'**, 우리말로 "없는 걸 진짜처럼 지어냄"이라고 합니다.
> 함수 이름·API 주소·URL은 한 글자만 틀려도 코드가 안 돌아가므로,
> **"이건 확실, 저건 추정"을 AI가 스스로 표시하게** 만들어 옥석을 가립니다.

---

## 1단계 — AI에게 보낼 지시 프롬프트 (그대로 복사해서 붙여넣기)

```
[맥락] 내 웹사이트에 "오늘 날씨"를 표시하려고 해. 회원가입·결제 없이
무료로 쓸 수 있는 "공개 날씨 API"를 찾고 있어. 순수 HTML/CSS/JS(fetch)로
호출할 거야.

[질문] 쓸 만한 공개 날씨 API를 2~3개 추천해줘. 각 API마다 아래를 알려줘:
- 서비스 이름
- 호출할 때 쓰는 기본 요청 주소(엔드포인트 URL)
- 무료로 쓸 수 있는지(가입/키 필요 여부)

[가장 중요한 제약 — 환각 방지]
1. 각 항목(이름·URL·무료 여부)마다 신뢰도 라벨을 반드시 붙여줘.
   - [공식문서 확인] : 공식 문서에서 본 기억이 또렷하고 사실이라고 확신하는 것
   - [추정]         : 기억에 기댄 짐작이라 직접 확인이 필요한 것
2. URL을 추측으로 지어내지 마. 정확한 주소가 확실치 않으면 그 자리에
   "정확한 엔드포인트는 공식 문서에서 확인 필요"라고 [추정] 라벨과 함께 적어.
3. 마지막에 "내가 직접 공식 문서에서 확인해야 할 항목" 목록을 따로 정리해줘.
4. 모르면 모른다고 솔직히 말해. 그럴듯하게 채우지 마.
```

---

## 2단계 — 라벨 없이 단정하듯 답하면 잡아주는 한 마디

AI가 라벨을 빼먹고 "이 URL이 맞아요"라고 단정하면 아래로 되돌립니다.

```
잠깐, 항목마다 [공식문서 확인] / [추정] 라벨을 빼먹었어.
특히 엔드포인트 URL은 확실치 않으면 [추정]으로 표시하고,
"공식 문서에서 확인 필요"라고 솔직히 적어줘. 지어내지 말고.
```

---

## 3단계 — 한 항목만 콕 집어 출처를 캐물어 검증 (선택)

가장 중요해 보이는 API 하나를 골라 출처를 되물어 봅니다.

```
방금 추천한 것 중 첫 번째 API의 엔드포인트 URL은 어디서 본 정보야?
공식 문서 주소를 알면 알려주고, 모르면 "공식 문서 미확인, 추정"이라고 정확히 말해줘.
```

> 주의: AI가 알려준 "공식 문서 주소" 역시 환각일 수 있습니다.
> **반드시 사람이 그 주소를 브라우저에서 직접 열어** 진짜 존재하는지 확인하세요.

---

## 왜 이렇게 시키나요? (비전공자용 한 줄 정리)

- AI는 모르는 것도 **그럴듯하게 지어냅니다(환각).** 함수 이름·URL은 한 글자만 틀려도 코드가 멈춥니다.
- "확인된 사실인지 추정인지 라벨 붙여줘"라고 시키면, **어디를 의심하고 직접 확인해야 할지** AI가 스스로 짚어 줍니다.
- 그래도 최종 검증은 사람 몫입니다. **[추정] 라벨이 붙은 것은 반드시 공식 문서(1차 출처)에서 직접 확인**하세요.
