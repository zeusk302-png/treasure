# 노드 사이로 데이터 흘려보내고 표현식으로 꺼내 쓰기

수동 실행 버튼을 누르면, **`값 만들기 (Set)` 노드**가 `name`(이름)과 `sentAt`(보낸 시각) 값을 만들고, 그 값을 **다음 메일 노드가 `{{$json.name}}` 같은 표현식으로 꺼내** 메일 제목과 본문에 끼워 넣어 보냅니다. n8n에서 **노드 간 데이터 전달**과 **표현식(Expression) 문법**을 처음 익히는 실습입니다.

## 목표

- 한 노드에서 만든 값이 **다음 노드로 그대로 흘러간다**는 것을 눈으로 확인한다. (노드 사이를 잇는 선 = 데이터가 지나가는 길)
- `={{ $json.필드이름 }}` 표현식으로 **앞 노드의 값을 꺼내** 글자(제목·본문) 사이에 끼워 넣는 법을 익힌다.
- 고정된 텍스트가 아니라, **입력 데이터에 따라 내용이 바뀌는 동적인 메일**을 만든다.

> 이 워크플로우는 노드 3개입니다.
> `수동 실행 (Manual Trigger)` → `값 만들기 (Set)` → `Gmail로 메일 보내기`
> 1번 노드가 "시작!" 신호를 주면, 2번 노드가 값을 만들고, 3번 노드가 그 값을 받아 메일에 끼워 보냅니다.

## 따라하는 단계

1. **n8n에 로그인**합니다. (n8n Cloud 가입형 또는 직접 설치한 n8n 모두 가능)
2. 화면 오른쪽 위 **`...`(점 3개) → `Import from File`** 을 눌러 이 폴더의 **`workflow.json`** 파일을 불러옵니다. 노드 3개가 한 줄로 연결되어 나타납니다.
3. **`값 만들기 (Set)` 노드를 더블클릭**해 어떤 값을 만드는지 봅니다.
   - `name` = `홍길동` (그냥 글자 값)
   - `sentAt` = `={{ $now.format('yyyy-MM-dd HH:mm') }}` (실행되는 순간의 날짜·시각을 자동으로 넣는 표현식)
   - `name` 값을 **내 이름이나 받는 사람 이름으로 바꿔** 봅니다.
4. **`Gmail로 메일 보내기` 노드를 더블클릭**해, 제목과 본문에 표현식이 들어 있는 것을 확인합니다.
   - 제목: `={{ $json.name }}님께 보내는 자동 알림`
   - 본문: `안녕하세요, {{ $json.name }}님!` 처럼 `{{ }}` 안에 앞 노드의 값을 꺼내 씁니다.
   - 표현식 칸 옆의 **`Expression`(fx) 모드**가 켜져 있어야 `{{ }}`가 글자가 아닌 "값"으로 해석됩니다. (`Fixed`로 두면 그냥 글자 그대로 나옵니다.)
5. **Gmail 자격증명을 등록**합니다. (한 번만 등록하면 다음부터 재사용됩니다)
   - `Gmail로 메일 보내기` 노드의 `Credential to connect with` → `Create New Credential` → `Sign in with Google` 로 본인 구글 계정 로그인 후 권한 허용.
   - 메일을 보낼 권한만 허용하면 됩니다(**최소 권한**).
6. **받는 사람 주소를 내 메일로 바꿉니다.** `To` 칸의 `YOUR_EMAIL@example.com` 을 내가 받아볼 실제 이메일 주소로 고칩니다.
7. 캔버스 아래쪽 **`Test workflow`(수동 실행)** 버튼을 누릅니다.
8. 내 메일함을 열어, 제목과 본문에 **이름과 시각이 채워진** 메일이 도착했는지 확인합니다.

## 검증법

1. 실행 직후 세 노드 모두에 **초록색 체크 표시**가 뜨면 정상 작동입니다.
2. **`값 만들기 (Set)` 노드를 클릭 → `OUTPUT`** 패널을 엽니다. `name`과 `sentAt` 두 값이 만들어져 나왔는지 확인합니다. (이 OUTPUT이 다음 노드의 INPUT이 됩니다.)
3. **`Gmail로 메일 보내기` 노드를 클릭 → `INPUT`** 패널을 엽니다. 앞 노드가 넘긴 `name`·`sentAt`가 그대로 들어왔는지 확인합니다.
4. 실제 **내 메일함(받은편지함 또는 스팸함)** 의 메일에서, `{{$json.name}}` 자리에 **이름이**, `{{$json.sentAt}}` 자리에 **시각이** 들어가 있는지 확인합니다. (`{{ }}` 글자가 그대로 보이면 4단계의 Expression 모드가 꺼진 것입니다.)
5. (실패 케이스 점검) Set 노드에서 필드 이름을 일부러 `name` → `username` 으로 바꾼 뒤, 메일 노드의 `{{$json.name}}` 은 그대로 두고 실행해 봅니다. 이름 자리가 **비어서(빈칸으로) 나오는** 것을 확인하세요 — 표현식은 "정확히 그 이름의 필드"만 꺼내 옵니다.

## 표현식, 핵심만 짚기 (디렉터 관점)

- **`$json` 은 "바로 앞 노드가 넘겨준 데이터 한 덩어리"** 를 가리킵니다. 그 안의 특정 값을 꺼낼 때 `$json.필드이름` 으로 점(`.`)을 찍어 접근합니다. 그래서 Set에서 만든 `name` 은 다음 노드에서 `$json.name` 이 됩니다.
- **`{{ }}` 는 "이 안은 값으로 계산해서 채워라"** 라는 표시입니다. 글자 한복판에도 `안녕하세요, {{ $json.name }}님` 처럼 섞어 쓸 수 있습니다.
- **맨 앞의 `=`** 는 n8n에 "이 칸 전체를 고정 글자가 아니라 표현식으로 다뤄라"라고 알려주는 신호입니다. 화면에서는 `Expression`(fx) 모드를 켜면 자동으로 붙습니다. (`workflow.json`에서는 값 앞에 `=`로 표시됩니다.)
- 값이 노드를 따라 흐르므로, 트리거(웹훅·폼)에서 들어온 **실제 사용자 입력**으로 `name` 을 바꾸면, 사람마다 다른 맞춤 메일을 자동으로 보낼 수 있습니다.

## 자격증명, 비밀값은 어떻게 다루나

- 메일 발송 키(구글 로그인 토큰)는 n8n의 **자격증명(Credential)** 금고에 따로 보관되고, 노드는 그 금고를 **참조만** 합니다.
- 그래서 `workflow.json` 안에는 실제 키 대신 자리표시자(`YOUR_GMAIL_CREDENTIAL_ID`)만 들어 있습니다. **이 파일을 공유해도 내 계정 비밀번호는 새어 나가지 않습니다.** 본인 n8n 화면에서 직접 새 자격증명을 연결해야 메일이 나갑니다.
