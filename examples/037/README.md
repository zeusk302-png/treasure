# 실습 037 — flexbox로 3단 가격표(프라이싱) 카드 만들기

거의 모든 서비스의 "요금제" 페이지에는 **요금제 카드 3개가 한 줄에 나란히** 놓여 있습니다 (예: 무료 / 프로 / 팀). 이때 세 카드의 **너비가 칼같이 똑같이** 나뉘는 게 핵심입니다. 안에 적힌 글자 수가 카드마다 달라도 폭은 항상 균등하지요. 이걸 만드는 비결은 두 가지입니다. 첫째, 카드 3개를 감싸는 **부모 상자**에 `display: flex;`를 줘서 가로 한 줄로 놓습니다. 둘째, 카드 하나하나에 `flex: 1;`을 줘서 **"남는 가로 공간을 형제들과 똑같은 비율로 나눠 가져라"**라고 시킵니다. 세 카드 모두 `flex: 1`이면 1:1:1 비율, 즉 너비가 정확히 3등분됩니다. 이번 실습에서 우리는 진짜 요금제 페이지처럼 생긴 3단 가격표를 만들며 `flex-grow`(=`flex`의 첫 번째 숫자)가 무슨 뜻인지 몸으로 익힙니다. 파일은 `index.html` 하나뿐이고 서버도 인터넷도 필요 없습니다. 더블클릭만 하면 됩니다.

## 목표
- 카드 여러 개를 한 줄에 나란히 놓을 때 부모에 `display: flex;`를 준다는 구조를 이해한다.
- `flex: 1;`이 **"남는 공간을 형제들과 똑같이 나눠 가져라"**라는 뜻임을 이해한다. (그래서 카드 너비가 균등해진다)
- `flex: 1`은 사실 `flex-grow: 1; flex-shrink: 1; flex-basis: 0;`의 줄임말이고, 그중 **첫 번째 숫자가 `flex-grow`(늘어나는 비율)**라는 것을 안다.
- 숫자를 바꾸면(예: 가운데만 `flex: 2`) 비율이 1:2:1로 변한다는 것을 눈으로 확인한다.

핵심은 부모와 자식에 각각 주는 한 줄씩입니다.

```
.pricing {           /* 부모(카드들을 감싸는 상자) */
  display: flex;     ← 카드 3개를 가로 한 줄로 놓는다
  gap: 24px;         ← 카드 사이 간격
}

.card {              /* 자식(카드 하나하나) */
  flex: 1;           ← 남는 공간을 1:1:1로 나눠 너비를 균등하게(핵심!)
}
```

| 부분 | 누가 | 무슨 역할 |
|---|---|---|
| `.pricing` | 부모 상자(`<section>`) | `display: flex`로 카드들을 가로 한 줄로 배치 |
| `.card` ×3 | 자식(`<div>` 3개) | 각자 `flex: 1`이라 너비를 1:1:1로 균등 분배 |
| `flex: 1` | = `flex-grow:1` + `flex-shrink:1` + `flex-basis:0` | 첫 숫자 1이 "늘어나는 비율"(`flex-grow`) |

## 따라하는 단계
1. 이 폴더의 `index.html`을 **더블클릭**합니다. → 기본 브라우저가 열리고, "무료 / 프로 / 팀" 카드 3개가 한 줄에 나란히, **너비가 똑같이** 나타나면 정상입니다. (인터넷 연결이 필요 없습니다.)
2. 세 카드의 **가로 폭**을 눈으로 비교합니다. → 가운데 '프로' 카드 안에는 혜택이 4줄, 양옆은 3줄로 글자 양이 다른데도 **카드 너비는 셋 다 똑같습니다.** 이게 `flex: 1`의 결과입니다.
3. `index.html`을 메모장(또는 VS Code)으로 열어, `.card` 규칙의 `flex: 1;` 줄을 잠시 주석으로 막아 봅니다. 즉 `/* flex: 1; */` 로 바꾸고 저장한 뒤, 브라우저에서 **새로고침(F5)** 합니다. → 카드들이 더 이상 화면을 3등분하지 않고 **각자 글자 길이만큼만** 차지해 폭이 제각각·왼쪽에 옹기종기 붙어버립니다. 균등 분배가 오직 이 한 줄 덕분이었음을 알 수 있습니다. 확인했으면 주석을 풀어 되돌리세요.
4. 이번엔 비율을 바꿔 봅니다. 가운데 '프로' 카드는 `class="card featured"`를 쓰고 있는데, CSS 맨 아래쪽에 다음 한 줄을 추가하고 저장 후 새로고침해 보세요.
   ```
   .card.featured { flex: 2; }
   ```
   → 이제 비율이 **1 : 2 : 1**이 되어 가운데 카드만 양옆의 **두 배 너비**로 넓어집니다. `flex`의 숫자가 곧 "공간을 나눠 갖는 비율"임을 확인했으면 그 줄을 지워 되돌립니다.
5. `.pricing` 부모의 `display: flex;`를 잠시 주석 처리하고 새로고침해 보세요. → 카드 3개가 가로 한 줄이 아니라 **위아래로 세로로 쌓입니다.** 가로 배치 자체가 부모의 `display: flex` 덕분이었음을 알 수 있습니다. 되돌리세요.
6. `.pricing`의 `align-items: stretch;`(기본값이라 적어 두었습니다)를 잠시 `align-items: flex-start;`로 바꿔 새로고침해 보세요. → 카드 높이가 더 이상 똑같이 맞춰지지 않고 **각자 내용 길이만큼**(가운데 카드만 더 길게) 들쭉날쭉해집니다. 카드 높이를 가지런히 맞춰 주던 게 `stretch`였음을 확인하고 되돌립니다.
7. AI에게 시켜 보기:
   > "이 index.html의 가격표에서, 화면 너비가 좁아지면(@media max-width: 700px) `.pricing`을 `flex-direction: column;`으로 바꿔 카드 3개가 세로로 쌓이도록 CSS를 추가해줘. 넓은 화면에서의 기존 `display: flex;`와 카드의 `flex: 1;`은 그대로 두고."

## 🤖 바이브코딩 프롬프트
이 실습(flexbox 3단 가격표)을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 HTML/CSS를 가르치는 친절한 강사야. 비전공 입문자가 읽을 거야.
  하나의 index.html 파일(서버·인터넷 불필요, 더블클릭으로 열림)로
  "요금제 가격표 페이지"를 만들어줘. 요구사항:
  - 제목 "요금제 안내"와 한 줄 설명을 위에 둔다.
  - 요금제 카드 3개(무료 / 프로 / 팀)를 한 줄에 나란히 배치한다.
  - 카드들을 감싸는 부모 .pricing 에 display: flex; gap; max-width; margin:0 auto 를 준다.
  - 카드 하나하나 .card 에 flex: 1; 을 줘서 너비가 정확히 1:1:1로 균등하게 나뉘게 한다.
  - 각 카드에는 요금제 이름, 가격(예: ₩9,900 /월), 혜택 목록, 신청 버튼을 넣는다.
  - CSS는 별도 파일 없이 <style> 안에 모은다.
  코드만 주지 말고, 왜 부모에 display:flex 를 주고 자식에 flex:1 을 주는지
  한국어 주석으로 한 줄씩 풀어서 설명해줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 가격표를 개선해줘. 기존 display:flex 와 .card의 flex:1 은 그대로 두고:
  1) 가운데 '프로' 카드만 .featured 클래스로 테두리·그림자를 강조하고 "인기" 배지를 단다.
  2) 카드 안을 세로 flex(flex-direction: column)로 만들어, 혜택 목록에 flex-grow:1 을 줘서
     신청 버튼이 카드 길이와 상관없이 항상 맨 아래에 정렬되도록 한다.
  3) 화면 너비가 좁아지면(@media max-width: 700px) .pricing 을 flex-direction: column 으로 바꿔
     카드 3개가 세로로 쌓이게 한다.
  바꾼 줄마다 "무엇을, 왜" 한국어 주석을 달아줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  카드 3개의 너비가 균등하게 나뉘지 않고 글자 길이만큼 제각각으로 보이거나
  왼쪽에 옹기종기 붙어 있어. 아래 코드를 보고 원인을 단계별로 짚어줘.
  특히 부모에 display:flex 가 빠졌는지, 자식 .card 에 flex:1 이 빠졌거나 오타가 났는지,
  선택자(.pricing / .card)가 실제 HTML의 class와 정확히 일치하는지 확인하는 순서로 알려줘.
  (여기에 내 index.html 전체를 붙여넣기)
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법
- **눈으로 확인**: 카드 3개가 한 줄에 나란히 있고 **가로 폭이 셋 다 똑같으면** 성공입니다. 카드마다 폭이 제각각이거나 왼쪽에 붙어 있다면 `.card`의 `flex: 1;`이 빠졌거나 오타가 난 것입니다.
- **창 크기 검증**: 브라우저 창 너비를 마우스로 **넓혔다 줄였다** 해보세요. 카드들은 늘 화면을 균등하게 3등분하며 같이 넓어지고 좁아집니다. 한 카드만 비정상적으로 커지면 어딘가 `flex` 값이 다른 것입니다.
- **비율 검증**: 4번 단계처럼 가운데 카드에 `flex: 2`를 주면 그 카드만 정확히 양옆의 두 배 폭이 됩니다. 이렇게 숫자대로 비율이 변하면 `flex-grow`가 제대로 동작하는 것입니다.
- **개발자 도구로 정확히 확인**: 브라우저에서 `F12 → Elements`로 카드 하나(`<div class="card">`)를 클릭한 뒤, 오른쪽 `Styles`(스타일) 탭에서 `flex: 1;`이 적용돼 있는지 봅니다. 같은 자리에서 값을 `flex: 2`로 바꿔 보면 그 카드만 즉시 넓어지는 것도 확인할 수 있습니다.
