# 구글 서치콘솔·네이버 서치어드바이저에 사이트 등록하고 사이트맵 제출하기

내가 만든 사이트를 검색엔진이 찾아오게 만드는 첫 단추입니다. 두 검색엔진(구글, 네이버)에 "이 사이트는 제 것입니다"라고 증명(**소유확인**)하고, 사이트의 페이지 목록인 `sitemap.xml`을 제출해 **색인(검색결과 등록) 요청**까지 끝냅니다. 한국에서는 검색 점유율이 높은 **네이버**도 반드시 등록해야 국내 사용자에게 노출됩니다.

## 목표

- 구글 **서치콘솔**과 네이버 **서치어드바이저** 두 곳에 사이트를 등록할 수 있다.
- **소유확인**을 메타태그 방법(또는 HTML 파일 업로드 방법)으로 완료할 수 있다.
- `sitemap.xml`과 `robots.txt`가 무엇인지 알고, 각 콘솔에 사이트맵을 제출할 수 있다.
- 두 콘솔의 "소유확인 완료" 화면과 "사이트맵 제출됨" 화면을 캡처해 제출물로 남긴다.

> 용어 한 줄 정리
> - **서치콘솔 / 서치어드바이저**: 각각 구글·네이버가 주는 "내 사이트 검색 관리 페이지". 검색에 어떻게 나오는지 보고, 색인을 요청하는 곳입니다.
> - **소유확인**: "이 사이트의 주인이 정말 당신인가요?"를 증명하는 절차. 콘솔이 준 코드를 사이트에 붙여 증명합니다.
> - **사이트맵(sitemap.xml)**: 내 사이트에 있는 페이지들의 목록표. 검색엔진이 이걸 보고 방문할 주소를 압니다.
> - **색인(인덱싱)**: 검색엔진이 페이지를 읽어 검색결과 데이터베이스에 등록하는 것. 색인돼야 검색에 나옵니다.

## 준비물

- **배포된 사이트 주소**(예: `https://내사이트.vercel.app` 또는 연결한 도메인). 소유확인은 실제로 인터넷에 올라간 사이트에서만 됩니다. 아직 배포 전이라면 먼저 Vercel 배포를 끝내세요.
- 이 폴더의 파일들: `index.html`(소유확인 메타태그 예시), `sitemap.xml`, `robots.txt`. 이 파일들을 내 사이트 프로젝트에 맞게 넣고 배포합니다.

## 따라하는 단계

### A. 파일 준비 (코드 쪽)

1. 이 폴더의 `sitemap.xml`을 열어 모든 `https://YOUR_DOMAIN.com` 자리표시자를 **내 실제 사이트 주소**로 바꾸고, 내 페이지에 맞게 `<url>` 블록을 추가/삭제합니다. 이 파일은 배포 후 `https://내도메인/sitemap.xml`로 열려야 합니다.
2. `robots.txt`도 `Sitemap:` 줄의 주소를 내 도메인으로 바꿉니다. 운영 사이트에 `Disallow: /`(전부 차단)가 남아 있지 않은지 꼭 확인합니다.
3. 이 두 파일을 사이트 **최상위(루트)** 에 두고 배포합니다.

### B. 구글 서치콘솔 등록

4. https://search.google.com/search-console 에 접속해 구글 계정으로 로그인합니다.
5. **속성 추가** → "URL 접두어"를 선택하고 내 사이트 주소(`https://내도메인`)를 입력합니다.
6. 소유확인 방법에서 **"HTML 태그"** 를 고릅니다. 화면에 나오는 `<meta name="google-site-verification" content="...">` 한 줄을 복사합니다.
7. 이 폴더의 `index.html`을 참고해, 복사한 메타태그를 내 사이트의 모든 페이지 `<head>` 안에 붙여넣고 **다시 배포**합니다. (이 폴더 `index.html`의 예시 메타태그 줄은 삭제하고 진짜 값으로 교체)
   - **대안(파일 방법)**: 메타태그 대신 구글이 주는 `googleXXXX.html` 파일을 사이트 루트에 올려도 됩니다. 이 폴더의 `googleXXXXXXXXXXXXXXXX.html`이 그 예시입니다. 둘 중 **하나만** 하면 됩니다.
8. 다시 서치콘솔로 돌아와 **"확인"** 버튼을 누릅니다. "소유권이 확인되었습니다" 화면이 나오면 **캡처**합니다. (제출물 1)
9. 왼쪽 메뉴 **Sitemaps(사이트맵)** 로 들어가 `sitemap.xml`을 입력하고 **제출**합니다. 상태가 "성공"으로 바뀐 화면을 **캡처**합니다. (제출물 2)

### C. 네이버 서치어드바이저 등록

10. https://searchadvisor.naver.com 에 접속해 네이버 계정으로 로그인합니다.
11. **웹마스터 도구 → 사이트 등록**에서 내 사이트 주소(`https://내도메인`)를 입력합니다.
12. **사이트 소유확인** 화면에서 **"HTML 태그"** 를 고르고, 나오는 `<meta name="naver-site-verification" content="...">` 한 줄을 복사해 내 사이트 `<head>`에 붙여넣고 **다시 배포**합니다.
    - **대안(파일 방법)**: 네이버가 주는 확인용 HTML 파일을 루트에 올려도 됩니다. 이 폴더의 `naverXXXXXXXXXXXXXXXX.html`이 그 예시입니다.
13. 서치어드바이저로 돌아와 **"소유확인"** 버튼을 누릅니다. "소유확인에 성공했습니다" 화면을 **캡처**합니다. (제출물 3)
14. 사이트 관리로 들어가 **요청 → 사이트맵 제출**에서 `sitemap.xml`을 입력하고 **확인**을 누릅니다. 제출 완료 목록 화면을 **캡처**합니다. (제출물 4)

> 메타태그 값은 **사람마다 다른 비밀스러운 코드**입니다. 이 폴더의 `REPLACE_WITH_...`, `googleXXXX...`, `naverXXXX...`는 모두 **자리표시자**이니 반드시 콘솔에서 발급받은 진짜 값으로 바꾸세요.

## 🤖 바이브코딩 프롬프트

이 실습(검색엔진 등록 + 사이트맵/robots 준비)을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 SEO 입문을 돕는 웹개발 멘토야. 비전공자가 이해하도록 설명을 곁들여줘.
  내 정적 사이트(배포 주소: https://내도메인)를 구글 서치콘솔과 네이버 서치어드바이저에
  등록할 준비 파일 3종을 만들어줘.
  - index.html: <head> 안에 google-site-verification, naver-site-verification 메타태그 두 줄
    (값은 REPLACE_WITH_... 자리표시자로 두고, 진짜 값으로 바꾸라는 주석을 달 것)
  - sitemap.xml: 홈/소개/블로그/글 예시 4개 <url> 블록 (loc는 https://YOUR_DOMAIN.com 자리표시자)
  - robots.txt: 전체 허용(Allow: /) + Sitemap 절대주소 줄
  제약: 각 파일 맨 위에 "이 파일이 무엇이고 왜 필요한지" 한국어 요약 주석을 달고,
        비전공자가 헷갈릴 곳(자리표시자, Disallow:/ 위험)에는 왜 그런지 이유 주석을 달아줘.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  위 파일들을 개선해줘.
  1) sitemap.xml에 changefreq/priority/lastmod 항목을 추가하고, 각 항목이 무슨 뜻인지 주석으로 설명해줘.
  2) robots.txt에 "운영 배포 시 Disallow: / 가 남아 있으면 사이트가 검색에서 통째로 사라진다"는
     경고 주석을 눈에 띄게 넣어줘.
  3) 메타태그 방법 말고 'HTML 파일 업로드' 소유확인 방법도 쓸 수 있게,
     구글/네이버 확인용 HTML 파일 예시(googleXXXX.html, naverXXXX.html)와
     루트에 올리라는 안내를 README에 추가해줘.
  비전공자가 한 줄씩 이해할 수 있게 왜 그렇게 했는지 주석으로 풀어서 설명해줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  서치콘솔/서치어드바이저에서 "소유확인 실패" 또는 "사이트맵을 가져올 수 없음" 오류가 떠.
  내 상황: (배포 주소, 어떤 방법으로 했는지, 콘솔이 보여준 에러 메시지를 여기 붙여넣기)
  가능한 원인을 우선순위 순서로 단계별 체크리스트로 알려줘.
  특히 (1) 메타태그가 실제 배포된 페이지 소스에 들어갔는지, (2) 배포가 끝났는지,
  (3) robots.txt에 Disallow: / 가 남아 있는지, (4) sitemap.xml이 https://내도메인/sitemap.xml로
  직접 열리는지를 어떻게 확인하는지 비전공자 눈높이로 알려줘.
  ```
> 프롬프트 팁: "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 좋습니다.

## 검증법

- **소유확인 검증**: 각 콘솔에서 "확인/소유확인" 버튼을 눌렀을 때 성공 메시지가 떠야 합니다. 실패하면 (1) 메타태그가 정말 배포된 사이트의 `<head>`에 들어갔는지, (2) 배포가 끝났는지(반영에 몇 분 걸릴 수 있음)를 확인합니다.
- **사이트맵 직접 열어보기**: 브라우저 주소창에 `https://내도메인/sitemap.xml`을 직접 쳐서 페이지 목록이 보이면 정상입니다. `https://내도메인/robots.txt`도 열어 `Disallow: /`가 없는지 확인합니다.
- **메타태그 들어갔는지 확인**: 사이트에서 우클릭 → "페이지 소스 보기"로 `google-site-verification`과 `naver-site-verification` 두 줄이 보이는지 확인합니다.
- **제출물 4장**: ① 구글 소유확인 성공, ② 구글 사이트맵 제출 성공, ③ 네이버 소유확인 성공, ④ 네이버 사이트맵 제출 성공 화면 캡처가 모두 있으면 완료입니다.

> 자주 하는 실수
> - 배포하지 않은 채(내 컴퓨터에서만 연 상태로) 확인 버튼을 누르면 실패합니다. 소유확인은 **인터넷에 올라간 사이트**에서만 됩니다.
> - `robots.txt`에 개발용 `Disallow: /`가 남아 있으면 사이트맵을 제출해도 색인이 안 됩니다. 가장 치명적인 실수입니다.
> - 사이트맵 주소를 상대경로(`sitemap.xml`)가 아니라 콘솔에서 요구하는 형태로 정확히 입력했는지 확인하세요. 보통 `sitemap.xml`만 넣으면 됩니다.
> - 색인은 즉시가 아닙니다. 제출 후 며칠 걸릴 수 있으니, `site:내도메인`으로 검색되는지는 시간을 두고 확인합니다.
