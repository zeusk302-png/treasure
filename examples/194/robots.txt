# robots.txt = 검색엔진 크롤러에게 주는 안내문입니다.
# "이 사이트는 봐도 됩니다(Allow), 그리고 사이트맵은 여기 있습니다" 라고 알려줍니다.
#
# ※ 아래 Sitemap 주소의 https://YOUR_DOMAIN.com 은 자리표시자입니다.
#   내 실제 도메인으로 바꾸세요.
# ※ 이 파일은 배포 후 https://내도메인/robots.txt 로 열려야 합니다.

# 모든 검색엔진(*)에게 전체 페이지 접근을 허용합니다.
User-agent: *
Allow: /

# 절대 주의: 운영(production)에서 아래 한 줄이 남아 있으면
#           사이트 전체가 검색에서 통째로 사라집니다. 반드시 비워 두세요.
# Disallow: /     <-- 개발 중 막아뒀다면 배포 전에 꼭 지우거나 주석 처리!

# 검색엔진에게 사이트맵 위치를 알려줍니다. (절대 주소로 적어야 합니다)
Sitemap: https://YOUR_DOMAIN.com/sitemap.xml
