# 040. fr 단위로 비율 나눈 대시보드 격자 만들기

CSS Grid의 `fr` 단위와 `gap`을 사용해 영역 크기를 **비율(1:2:1)** 로 나눈 대시보드형 격자를 만드는 실습입니다. 앞 실습(039)에서는 `1fr 1fr`로 똑같은 크기 2칸을 만들었다면, 이번에는 `1fr 2fr 1fr`처럼 칸마다 다른 비율을 줘서 "가운데는 넓고 양옆은 좁은" 실전 레이아웃을 만들어 봅니다.

## 목표

- `fr` 단위가 무엇인지(fraction = 비율) 이해한다. `px`처럼 고정값이 아니라 남은 공간을 숫자 비율대로 나눠 가진다.
- `grid-template-columns: 1fr 2fr 1fr`로 칸마다 다른 너비 비율(1:2:1)을 주는 법을 익힌다.
- `gap`으로 칸 사이 가로·세로 간격을 한 번에 주는 법을 익힌다.
- `grid-column: 1 / -1`로 한 칸이 가로 전체를 차지하게 만드는 법을 익힌다.

## 따라하는 단계

1. `index.html`과 `style.css`가 **같은 폴더(040)** 안에 있는지 확인합니다. HTML 위쪽의 `<link rel="stylesheet" href="style.css" />` 한 줄이 두 파일을 연결해 줍니다.
2. `index.html`을 더블클릭해 브라우저(크롬 등)로 엽니다. 윗줄에 카드 3개가 **1 : 2 : 1 너비 비율**(가운데가 양옆의 2배)로 보이고, 아랫줄에 큰 카드 하나가 가로 전체를 차지하면 성공입니다.
3. `style.css`를 열어 `.dashboard` 부분을 봅니다. 핵심은 세 줄입니다.
   - `display: grid;` -> 이 박스를 격자판으로 만든다.
   - `grid-template-columns: 1fr 2fr 1fr;` -> 가로를 3칸으로 나누되 비율을 1:2:1로 한다. (`fr`은 "비율 한 조각"이라는 뜻)
   - `gap: 16px;` -> 칸과 칸 사이 간격을 16px 준다.
4. 직접 숫자를 바꿔보며 `fr`의 원리를 확인합니다.
   - `1fr 2fr 1fr`을 `1fr 1fr 1fr`로 바꾸면 세 칸이 **똑같은 너비**가 됩니다. (가운데가 더 이상 넓지 않음)
   - `1fr 2fr 1fr`을 `1fr 3fr 1fr`로 바꾸면 가운데가 양옆의 **3배**로 더 넓어집니다.
   - `fr`을 `px`와 섞어 `200px 2fr 1fr`로 바꿔보면, 왼쪽은 항상 200px로 고정되고 **남은 공간만** 2:1로 나뉘는 것을 볼 수 있습니다. (이게 `fr`이 "남은 공간을 나눈다"는 의미입니다.) 확인 후 원래대로 되돌리세요.
   - `gap: 16px;`의 숫자를 `4px`나 `40px`로 바꿔 칸 사이 간격이 변하는 것을 봅니다.
5. (선택) 아랫줄 큰 카드의 `.card--full`에 있는 `grid-column: 1 / -1;`을 잠깐 지워보세요. 큰 카드도 1칸짜리(1fr)로 줄어들며 윗줄 옆에 끼어드는 것을 볼 수 있습니다. `1 / -1`은 "첫 칸 선부터 마지막 칸 선까지 = 가로 전체"라는 뜻입니다. 확인 후 다시 살려두세요.

> 참고: `fr`은 "fraction(분수·비율)"의 줄임말입니다. `1fr 2fr 1fr`은 전체 칸을 1+2+1 = 4조각으로 나눠 각각 1/4, 2/4(=절반), 1/4 너비를 가진다는 뜻입니다. 그래서 브라우저 창 너비를 바꿔도 비율은 그대로 유지됩니다.

## 🤖 바이브코딩 프롬프트

이 실습을 AI에게 시켜 만들 때 그대로 복사해 쓸 수 있는 프롬프트입니다. 상황에 맞게 숫자나 단어만 바꿔 쓰세요.

- **1단계(뼈대 만들기)** 프롬프트:
  ```text
  너는 CSS Grid를 가르치는 웹 강사야. 비전공자가 따라할 수 있는 "대시보드 격자" 예제를
  index.html과 style.css 두 파일로 만들어 줘.

  요구사항:
  - <section class="dashboard"> 박스에 display: grid 를 주고,
    grid-template-columns 를 1fr 2fr 1fr 로 해서 가로 3칸을 1:2:1 비율로 나눠.
  - 윗줄에 카드(.card) 3개를 넣어. 가운데 카드는 양옆보다 2배 넓게 보여야 해.
  - 칸 사이 간격은 gap: 16px 로 줘.
  - 각 카드 안에는 라벨(작은 글씨)과 숫자(큰 글씨)를 넣어 (예: "오늘 방문자" / 128).
  제약: 외부 라이브러리 없이 순수 HTML/CSS만. 한국어 텍스트로.
  산출물: index.html 전체 코드와 style.css 전체 코드.
  ```
- **2단계(기능 추가/개선)** 프롬프트:
  ```text
  방금 만든 대시보드에 아랫줄을 추가해 줘.
  - 아랫줄에 큰 카드 1개를 두고, 그 카드만 grid-column: 1 / -1 로 가로 전체(3칸)를 차지하게 해.
  - 그 큰 카드 안에 "최근 활동 로그"라는 제목과 함께 활동 내역을 <ul> 목록으로 3~4개 넣어.
  - 가운데 넓은 카드는 배경색을 살짝 다르게(연한 파랑) 해서 강조해 줘.
  바뀐 부분만 알려주지 말고, 어디에 무엇을 추가했는지 한 줄씩 설명도 같이 줘.
  ```
- **막혔을 때(디버깅)** 프롬프트:
  ```text
  CSS Grid로 1fr 2fr 1fr 비율 격자를 만들었는데 칸들이 비율대로 안 나뉘고
  세로로 쭉 쌓이기만 해. 아래가 내 style.css 와 index.html 인데,
  왜 grid가 적용이 안 되는지 원인을 단계별로 짚어 주고 고친 코드를 줘.
  (예상되는 원인: display: grid 를 빠뜨림 / 클래스 이름 오타 / link 태그 경로 문제 등도 점검해 줘.)

  [여기에 내 코드 붙여넣기]
  ```
> 프롬프트 팁: 마지막에 "코드만 주지 말고 왜 그렇게 했는지 주석으로 설명해줘", "비전공자가 이해하게 한 줄씩 풀어줘"를 덧붙이면 학습에 훨씬 좋습니다.

## 검증법

- 브라우저로 `index.html`을 열었을 때 윗줄 카드 3개가 **1 : 2 : 1** 너비(가운데가 양옆의 2배)로 보인다.
- 아랫줄의 "최근 활동 로그" 카드가 **가로 전체**(3칸 너비)를 차지한다.
- 브라우저 창의 너비를 줄였다 늘렸다 해도 세 칸의 너비 **비율(1:2:1)이 그대로 유지**된다. (px처럼 고정이 아니라 비율로 나누기 때문)
- `grid-template-columns`를 `1fr 1fr 1fr`로 바꾸면 세 칸이 같은 너비가 되고, `1fr 2fr 1fr`로 되돌리면 다시 가운데가 넓어진다.
- 개발자도구(F12) > Elements에서 `.dashboard` 요소를 선택하면 `display: grid`가 적용된 것을 확인할 수 있고, 칸 경계에 그리드 점선과 `1fr / 2fr / 1fr` 트랙 크기가 표시된다.
