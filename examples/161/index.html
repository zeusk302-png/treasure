실습 161 · API 키 보안

비밀 API 키를 프론트에 안 박고
서버로 숨기기 (프록시)

이 페이지(브라우저 코드)에는 비밀 키가 한 글자도 없습니다. AI에게 보낼 글을 입력하면, 브라우저는 우리 서버의 '중간 창구'(/api/ask)에만 부탁하고, 진짜 Claude 키는 서버 안에서만 쓰입니다.

1. 프록시로 AI에게 물어보기



      

        이 버튼이 부르는 곳은 Claude가 아니라 /api/ask(우리 서버)입니다.
        진짜 Claude 호출과 비밀 키 사용은 모두 그 서버 함수 안에서 일어납니다.

    sk-ant- 으로 시작하는 글자가 단 한 개도 없어야 정상입니다.

  2.

          (그 헤더는 서버에서만 붙습니다.)

  3.

          비밀 키가 없어야 합니다. 키는 코드가 아니라 Vercel · Settings · Environment Variables에 있습니다.
