# 대시보드에 차트 라이브러리로 추이 그래프 그리기

숫자 표는 한눈에 안 들어옵니다. 같은 데이터를 **선 그래프**와 **막대 그래프**로 그리면 "오, 주말에 사람이 몰리는구나" 같은 흐름이 바로 보입니다.
이 실습은 **Chart.js**라는 무료 차트 라이브러리로, 요일별 방문자 수를 그래프로 그리는 **한 단계짜리 미니 대시보드**입니다.

> 비유: 차트 라이브러리는 **'그래프 자판기'** 입니다.
> "이런 종류(선/막대), 이런 숫자로 그려 줘"라고 종이(설정)만 넣으면, 예쁜 그래프를 대신 그려 줍니다.
> 우리가 직접 선을 긋거나 막대를 칠할 필요가 없습니다.

## 목표

- Chart.js를 **CDN(인터넷 주소)** 으로 불러와서, 설치 없이 그래프를 그린다.
- `<canvas>`(그림판)와 `new Chart(...)` 한 덩어리로 **선 그래프**와 **막대 그래프**를 그린다.
- 같은 데이터에서 `type`만 `"line"` → `"bar"` 로 바꾸면 그래프 종류가 바뀐다는 걸 체험한다.
- 합계·평균·최고일 같은 **요약 숫자**를 위쪽 카드에 함께 보여 준다.

## 따라하는 단계

1. 이 폴더의 `index.html`을 **브라우저로 엽니다.** (파일을 더블클릭하면 됩니다. 인터넷은 연결돼 있어야 합니다 — Chart.js를 인터넷에서 불러오기 때문입니다.)
2. 화면에 **요약 카드 3개**(총 방문자·하루 평균·가장 많은 날), **선 그래프**, **막대 그래프**가 떠 있는지 확인합니다.
3. `index.html`을 메모장이나 편집기로 열어, 아래쪽 `sampleData` 부분을 찾습니다. 요일과 숫자가 적힌 목록입니다.
4. 숫자(`visitors` 값)를 내 마음대로 바꿔 저장한 뒤, 브라우저에서 **새로고침(F5)** 합니다. → 그래프 모양과 위쪽 카드 숫자가 같이 바뀝니다.
5. (선택) 막대 그래프를 선으로 바꿔 보고 싶다면, 아래쪽 `type: "bar"` 를 `type: "line"` 으로 바꿔 저장하고 새로고침합니다.

## 검증법

- **그래프가 보인다**: 빈 화면이 아니라, 선 그래프와 막대 그래프가 실제로 그려져 있어야 합니다.
- **숫자가 맞다**: 위쪽 카드의 "총 방문자"가 `sampleData`의 숫자를 다 더한 값과 같아야 합니다. (예: 기본값이면 1,860명)
- **바꾸면 같이 바뀐다**: `sampleData`의 숫자를 바꾸고 새로고침하면, 그래프 높이와 카드 숫자가 함께 달라집니다.
- **오류 없음**: F12 → **Console** 탭에 빨간 오류가 없어야 합니다. 만약 그래프가 안 보이고 `Chart is not defined` 오류가 뜨면, 인터넷 연결이 끊겼거나 맨 위 `<script src="...chart.umd.min.js">` 줄이 빠진 것입니다.

> 그래프가 안 보일 때 1순위로 확인: (1) 인터넷이 연결돼 있는지, (2) `<canvas id="lineChart">` 의 id와 `getElementById("lineChart")` 의 id 철자가 똑같은지.

> 보안 메모: 이번 실습은 비밀값이 필요 없습니다. 하지만 **나중에 진짜 데이터를 API에서 받아올 때**는 주의하세요.
> API 키 같은 비밀값(`YOUR_API_KEY`)을 브라우저 코드(`index.html`)에 그대로 적으면, 페이지를 연 누구나 그 키를 훔쳐볼 수 있습니다.
> 비밀 키가 필요한 호출은 브라우저가 아니라 **서버나 n8n** 쪽에서 처리하고, 브라우저에는 결과 숫자만 내려 주세요.
